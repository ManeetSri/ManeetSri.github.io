The everyday API of Swift's collections, with what each call costs. The lessons go deeper: [Creating and accessing arrays](/dsa/learn/swift-array-basics), [Sets](/dsa/learn/swift-sets), [Dictionaries](/dsa/learn/swift-dictionaries) and [String.Index](/dsa/learn/swift-string-index).

## Array

| You want to… | Write | Cost |
| --- | --- | --- |
| Make n copies of a value | `Array(repeating: 0, count: n)` | O(n) |
| Make a 2D grid | `Array(repeating: Array(repeating: 0, count: cols), count: rows)` | O(rows · cols) |
| Read or write by index | `items[i]`, `items[i] = x` | O(1) (crashes if out of range) |
| First or last, safely | `items.first`, `items.last` | O(1), optional |
| Add to the end | `items.append(x)` | O(1) amortised |
| Remove from the end | `items.removeLast()` / `popLast()` | O(1); `popLast` is nil when empty |
| Insert or remove in the middle | `items.insert(x, at: i)`, `items.remove(at: i)` | O(n) |
| Swap two elements | `items.swapAt(i, j)` | O(1) |
| Reverse in place / a reversed view | `items.reverse()` / `items.reversed()` | O(n) / O(1) view |
| Sort in place / a sorted copy | `items.sort()` / `items.sorted(by: >)` | O(n log n), stable |
| Find a value | `items.firstIndex(of: x)`, `items.contains(x)` | O(n) |
| Find by condition | `items.first(where: { $0 > 3 })` | O(n) |
| Smallest or largest | `items.min()`, `items.max(by:)` | O(n), optional |
| Sum | `items.reduce(0, +)` | O(n) |
| Count matches | `items.count(where: { $0 > 0 })` | O(n), Swift 6+ |
| Indexes with values | `for (i, x) in items.enumerated()` | O(n) |
| A range of elements | `items[2..<5]` | O(1); the slice keeps the original indexes |
| Reserve room up front | `items.reserveCapacity(n)` | Avoids repeated growth |

## Set

| You want to… | Write | Cost |
| --- | --- | --- |
| Make one | `var seen: Set<Int> = []`, `Set(items)` | O(n) to build |
| Add and remove | `seen.insert(x)`, `seen.remove(x)` | O(1) average |
| Membership | `seen.contains(x)` | O(1) average |
| Was it new? | `seen.insert(x).inserted` | O(1) average |
| Combine | `a.union(b)`, `a.intersection(b)`, `a.subtracting(b)`, `a.symmetricDifference(b)` | O(n) |
| Compare | `a.isSubset(of: b)`, `a.isDisjoint(with: b)` | O(n) |
| Iterate in a stable order | `seen.sorted()` | O(n log n): a Set has no order of its own |

## Dictionary

| You want to… | Write | Cost |
| --- | --- | --- |
| Make one | `var counts: [String: Int] = [:]` | |
| Look up (it might be missing) | `counts["a"]` | O(1) average, returns an optional |
| Look up with a fallback | `counts["a", default: 0]` | O(1) average |
| Count occurrences | `counts[word, default: 0] += 1` | O(1) average |
| Set or remove | `counts["a"] = 3`, `counts["a"] = nil` | O(1) average |
| Build from pairs | `Dictionary(uniqueKeysWithValues: pairs)` | O(n); crashes on duplicate keys |
| Group a list | `Dictionary(grouping: words, by: { $0.first! })` | O(n) |
| Transform the values | `counts.mapValues { $0 * 2 }` | O(n) |
| Iterate in a stable order | `for key in counts.keys.sorted()` | O(n log n): the order changes between runs |
| Highest count | `counts.max(by: { $0.value < $1.value })` | O(n) |

## String

| You want to… | Write | Cost |
| --- | --- | --- |
| Fast access by position | `let chars = Array(text)`, then `chars[i]` | O(n) once, then O(1) |
| Fast ASCII work | `let bytes = Array(text.utf8)` | O(n) once; work with `UInt8` |
| Length in characters | `text.count` | O(n) |
| Character tests | `ch.isLetter`, `ch.isNumber`, `ch.isWhitespace`, `ch.isUppercase` | O(1) |
| Letter index a–z | `Int(ch.asciiValue! - Character("a").asciiValue!)` | O(1), ASCII only |
| Digit value | `ch.wholeNumberValue` | O(1), optional |
| Split into words | `text.split(separator: " ")` | O(n); gives `Substring`s |
| Join | `words.joined(separator: " ")` | O(total length) |
| Repeat | `String(repeating: "-", count: 10)` | O(n) |
| Reverse | `String(text.reversed())` | O(n) |
| Prefix and suffix | `text.hasPrefix("ab")`, `text.hasSuffix("z")` | O(length of the prefix) |
| Trim spaces | `text.trimmingCharacters(in: .whitespaces)` | O(n); needs `import Foundation` |
| Number ↔ text | `Int("42")`, `String(42)`, `String(5, radix: 2)` | `Int(_:)` returns an optional |

## What the standard library doesn't have

| Structure | Where to get it |
| --- | --- |
| Stack | An `Array` with `append` and `popLast` |
| Queue, deque | Build one ([ring buffers](/dsa/learn/queue-ring-buffer)), or `Deque` from swift-collections |
| Heap / priority queue | Build one ([Build a generic Heap](/dsa/learn/heap-build)), or `Heap` from swift-collections |
| Ordered set / sorted map | Build one ([ordered set and map](/dsa/learn/bal-ordered-map)), or `TreeSet` / `TreeDictionary` from swift-collections |
| Linked list | Build one ([Build LinkedList](/dsa/learn/ll-build-singly)) |
| Graph | An adjacency list: `[[Int]]` or `[Node: [Node]]` |
