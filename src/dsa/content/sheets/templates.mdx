Skeletons you can adapt in a minute. Each one compiles as it stands, names the invariant that keeps it correct, and links to the lesson that explains it. Learn the idea from the lesson first: a template you don't understand is a template you'll misuse.

## Binary search: lower bound

The first index whose value is at least `target`, using a half-open range. Use it for "first position", "insert position" and "count of values below". See [Lower bound and first occurrence](/dsa/learn/bs-bounds).

**Invariant:** Everything before `low` is less than `target`, and everything from `high` on is at least `target`.

```swift check
func lowerBound(_ items: [Int], _ target: Int) -> Int {
    var low = 0
    var high = items.count              // the answer is in [low, high]
    while low < high {
        let mid = low + (high - low) / 2
        if items[mid] < target {
            low = mid + 1
        } else {
            high = mid
        }
    }
    return low
}
```

## Binary search on the answer

When the question is "the smallest x that works", and once x works every bigger x works too. See [The monotonic predicate idea](/dsa/learn/bsa-idea).

**Invariant:** Within the range, values below `low` are known to fail and values above `high` are known to work. `answer` is the smallest that has worked so far.

```swift check
/// The smallest value in low...high for which `works` is true, or nil if none is.
/// `works` must be false, false, …, true, true as the value grows.
func smallestThatWorks(from low: Int, to high: Int, _ works: (Int) -> Bool) -> Int? {
    var low = low
    var high = high
    var answer: Int?
    while low <= high {
        let mid = low + (high - low) / 2
        if works(mid) {
            answer = mid
            high = mid - 1
        } else {
            low = mid + 1
        }
    }
    return answer
}
```

## Two pointers from both ends

For sorted input, pairs and palindromes: move whichever pointer can improve things. See [Opposite ends](/dsa/learn/tp-opposite-ends).

**Invariant:** No pair that uses an index outside `left...right` can be the answer.

```swift check
func pairWithSum(_ sorted: [Int], _ target: Int) -> (Int, Int)? {
    var left = 0
    var right = sorted.count - 1
    while left < right {
        let sum = sorted[left] + sorted[right]
        if sum == target { return (left, right) }
        if sum < target { left += 1 } else { right -= 1 }
    }
    return nil
}
```

## Fast and slow pointers

Two pointers walk the same linked list, one twice as fast as the other. If the list loops, the fast one laps the slow one inside the loop; if not, it falls off the end. Use it for "does this list have a cycle", "where does the cycle start" and, stopping when fast reaches the end, "find the middle", all in O(1) extra memory. See [Fast and slow pointers: middle and cycles](/dsa/learn/ll-fast-slow).

**Invariant:** `fast` has taken exactly twice as many steps as `slow`. Once both are in the cycle, `fast` gains one node per step, so it can't jump over `slow`.

```swift check
final class ListNode {
    var value: Int
    var next: ListNode?

    init(_ value: Int, next: ListNode? = nil) {
        self.value = value
        self.next = next
    }
}

/// The node where the cycle starts, or nil if the list has an end.
func cycleStart(_ head: ListNode?) -> ListNode? {
    var slow = head
    var fast = head
    while let step = fast?.next {            // fast can take two steps
        slow = slow?.next
        fast = step.next
        if let meeting = fast, meeting === slow {
            // Restart one pointer at the head; at the same speed, they meet at the entry
            var outside = head
            var inside: ListNode? = meeting
            while outside !== inside {
                outside = outside?.next
                inside = inside?.next
            }
            return outside
        }
    }
    return nil
}
```

## Sliding window that grows and shrinks

Grow on the right; shrink on the left while the window breaks the rule. This one finds the longest subarray with at most `k` distinct values. See [A sliding window template](/dsa/learn/sw-template).

**Invariant:** After the inner loop, `items[left...right]` has at most `k` distinct values, and no valid window ending at `right` starts earlier.

```swift check
func longestWithAtMostKDistinct(_ items: [Int], _ k: Int) -> Int {
    var counts: [Int: Int] = [:]
    var left = 0
    var best = 0
    for right in 0..<items.count {
        counts[items[right], default: 0] += 1
        while counts.count > k {
            counts[items[left]]! -= 1
            if counts[items[left]] == 0 { counts[items[left]] = nil }
            left += 1
        }
        best = max(best, right - left + 1)
    }
    return best
}
```

## Prefix sums with a dictionary

Counts subarrays adding up to `k`, negatives included, in one pass. See [Prefix sum + hashmap](/dsa/learn/prefix-hashmap).

**Invariant:** `seen` counts the prefix sums of every earlier position, the empty prefix included, so each earlier `prefix - k` marks a subarray ending here that sums to `k`.

```swift check
func subarraysSumming(to k: Int, in items: [Int]) -> Int {
    var seen: [Int: Int] = [0: 1]       // prefix sum → how many times it has appeared
    var prefix = 0
    var count = 0
    for value in items {
        prefix += value
        count += seen[prefix - k, default: 0]
        seen[prefix, default: 0] += 1
    }
    return count
}
```

## Monotonic stack

The next greater value for every element, in O(n). See [Monotonic stack](/dsa/learn/stack-monotonic-intro).

**Invariant:** The stack holds the indexes still waiting for a greater value, and their values never increase from bottom to top.

```swift check
func nextGreater(_ items: [Int]) -> [Int] {
    var result = Array(repeating: -1, count: items.count)
    var stack: [Int] = []                // indexes, values decreasing from bottom to top
    for i in items.indices {
        while let top = stack.last, items[top] < items[i] {
            result[stack.removeLast()] = items[i]
        }
        stack.append(i)
    }
    return result
}
```

## Monotonic deque: sliding window maximum

The maximum of every window of size `k` in O(n), rather than O(n × k): each index joins and leaves the deque once. Flip the comparison for minimums. The same deque speeds up DP steps of the form "the best of the last k states". An array with a head index plays the deque, since it only grows at the back. See [Monotonic deque: sliding window maximum](/dsa/learn/queue-monotonic-deque).

**Invariant:** The deque holds indexes inside the current window, oldest at the front, with strictly decreasing values. So the front is the window's maximum.

```swift check
func windowMaxima(_ values: [Int], k: Int) -> [Int] {
    guard k > 0 else { return [] }
    var result: [Int] = []
    var window: [Int] = []                // indexes; their values decrease from window[head] to the end
    var head = 0                          // the front of the deque: we only ever add at the back
    for i in values.indices {
        if head < window.count, window[head] <= i - k {
            head += 1                     // the front index has slid out of the window
        }
        while head < window.count, values[window[window.count - 1]] <= values[i] {
            window.removeLast()           // older and no bigger: it can never be a maximum again
        }
        window.append(i)
        if i >= k - 1 {
            result.append(values[window[head]])
        }
    }
    return result
}
```

## Merging intervals

Sort by start, then sweep once: each interval either overlaps the last merged one or starts a new one. The same sort-then-scan shape solves inserting an interval, removing the fewest overlaps and finding free time. These are closed intervals, so `(1, 3)` and `(3, 5)` merge; for half-open ones, change `<=` to `<`. See [Merge and insert intervals](/dsa/learn/iv-merge-insert).

**Invariant:** `merged` is sorted, its intervals don't overlap, and together they cover exactly the intervals seen so far.

```swift check
func mergeIntervals(_ intervals: [(start: Int, end: Int)]) -> [(start: Int, end: Int)] {
    var merged: [(start: Int, end: Int)] = []
    for interval in intervals.sorted(by: { $0.start < $1.start }) {
        if let last = merged.last, interval.start <= last.end {
            merged[merged.count - 1].end = max(last.end, interval.end)    // overlaps the last one: extend it
        } else {
            merged.append(interval)                                       // a gap: start a new interval
        }
    }
    return merged
}
```

## Sweep-line events

Turn each interval into two events, +1 at its start and −1 at its end, sort them by time, and keep a running total. It answers "how many meeting rooms", "the busiest moment" and "does the car ever carry more than its capacity". The order of ties decides whether an interval ending at t overlaps one starting at t, so choose it on purpose. See [Sweep-line events](/dsa/learn/iv-sweep-line).

**Invariant:** Once every event at time t has been processed, `open` is the number of intervals that contain t.

```swift check
/// The most half-open intervals [start, end) open at the same moment: the meeting rooms needed.
func maxOverlap(_ intervals: [(start: Int, end: Int)]) -> Int {
    var events: [(time: Int, change: Int)] = []
    for interval in intervals {
        events.append((interval.start, 1))
        events.append((interval.end, -1))
    }
    // At the same time, ends (-1) sort before starts (+1), so [1, 3) and [3, 5) never overlap
    events.sort { $0.time != $1.time ? $0.time < $1.time : $0.change < $1.change }
    var open = 0
    var most = 0
    for event in events {
        open += event.change
        most = max(most, open)
    }
    return most
}
```

## Quickselect: the kth smallest

The kth smallest value without sorting: partition around a random pivot, then keep only the side that holds position `k`. That's O(n) on average, against O(n log n) for sorting, and the three-way partition stays fast when values repeat. For the kth largest, with k counting from 1, ask for position `count - k`. See [Quickselect](/dsa/learn/sort-quickselect).

**Invariant:** The answer is always inside `items[low...high]`: everything before `low` is no bigger than anything in that range, and everything after `high` is no smaller.

```swift check
/// The kth smallest value, counting from 0, in O(n) on average. nil if k is out of range.
func kthSmallest(_ numbers: [Int], _ k: Int) -> Int? {
    guard numbers.indices.contains(k) else { return nil }
    var items = numbers
    var low = 0
    var high = items.count - 1                // the answer is always in items[low...high]
    while true {
        let pivot = items[Int.random(in: low...high)]
        // Three-way partition: [low, less) < pivot, [less, index) == pivot, (greater, high] > pivot
        var less = low
        var index = low
        var greater = high
        while index <= greater {
            if items[index] < pivot {
                items.swapAt(less, index)
                less += 1
                index += 1
            } else if items[index] > pivot {
                items.swapAt(index, greater)
                greater -= 1
            } else {
                index += 1
            }
        }
        if k < less {
            high = less - 1
        } else if k > greater {
            low = greater + 1
        } else {
            return pivot                      // position k holds a copy of the pivot
        }
    }
}
```

## Top k with a heap

Swift has no built-in heap, so a small generic one comes along, with the same sift-up and sift-down as the Dijkstra one further down. To keep the `k` largest values, hold them in a min-heap and remove its top whenever it grows past `k`: O(n log k) time and O(k) memory, and it works on a stream. For the `k` smallest, push negated values and negate them back. See [Top K, kth largest and K closest](/dsa/learn/heap-top-k).

**Invariant:** The heap holds the `k` largest values seen so far, and its top is the smallest of them: the bar the next value has to beat.

```swift check
struct MinHeap<Element: Comparable> {
    private var items: [Element] = []
    var count: Int { items.count }
    var top: Element? { items.first }

    mutating func push(_ item: Element) {
        items.append(item)
        var child = items.count - 1
        while child > 0, items[(child - 1) / 2] > items[child] {
            items.swapAt(child, (child - 1) / 2)
            child = (child - 1) / 2
        }
    }

    @discardableResult
    mutating func pop() -> Element? {
        guard !items.isEmpty else { return nil }
        items.swapAt(0, items.count - 1)
        let smallest = items.removeLast()
        var parent = 0
        while true {
            let left = 2 * parent + 1
            let right = left + 1
            var next = parent
            if left < items.count, items[left] < items[next] { next = left }
            if right < items.count, items[right] < items[next] { next = right }
            if next == parent { break }
            items.swapAt(parent, next)
            parent = next
        }
        return smallest
    }
}

/// The k largest values, largest first, in O(n log k) time and O(k) memory.
func largest(_ k: Int, of numbers: [Int]) -> [Int] {
    var heap = MinHeap<Int>()                 // the k largest so far; the top is the smallest of them
    for value in numbers {
        heap.push(value)
        if heap.count > k { heap.pop() }      // too many: the smallest can't be in the top k
    }
    var result: [Int] = []
    while let value = heap.pop() { result.append(value) }
    return result.reversed()
}
```

## Trie: insert, search and prefix

A tree with one node per prefix, so inserting or finding a word of length L costs O(L), however many words are stored. Use it for prefix lookups, autocomplete, word search on a board and replacing words with their roots. Nodes are a class, so walking down with `var node` changes the real tree. See [Build a Trie: insert, search, startsWith](/dsa/learn/trie-build).

**Invariant:** The letters on the path from the root to a node spell that node's prefix, and `isWord` is true exactly where an inserted word ends.

```swift check
final class Trie {
    private final class Node {
        var children: [Character: Node] = [:]
        var isWord = false
    }

    private let root = Node()

    func insert(_ word: String) {
        var node = root
        for letter in word {
            let next = node.children[letter] ?? Node()
            node.children[letter] = next
            node = next
        }
        node.isWord = true
    }

    func search(_ word: String) -> Bool { node(for: word)?.isWord ?? false }

    func startsWith(_ prefix: String) -> Bool { node(for: prefix) != nil }

    private func node(for text: String) -> Node? {
        var node = root
        for letter in text {
            guard let next = node.children[letter] else { return nil }
            node = next
        }
        return node
    }
}
```

## BFS on a grid

Shortest path in steps, where `#` is a wall. A head index makes the array a fast queue. See [BFS](/dsa/learn/gt-bfs).

**Invariant:** Cells leave the queue in order of distance, so the first time a cell is reached is by a shortest path, and no cell is queued twice.

```swift check
func shortestPath(in grid: [[Character]], from start: (Int, Int), to goal: (Int, Int)) -> Int? {
    let rows = grid.count
    let cols = grid[0].count
    var distance = Array(repeating: Array(repeating: -1, count: cols), count: rows)
    var queue = [start]
    var head = 0
    distance[start.0][start.1] = 0
    let moves = [(1, 0), (-1, 0), (0, 1), (0, -1)]
    while head < queue.count {
        let (row, col) = queue[head]
        head += 1
        if (row, col) == goal { return distance[row][col] }
        for (dr, dc) in moves {
            let r = row + dr
            let c = col + dc
            guard r >= 0, r < rows, c >= 0, c < cols, grid[r][c] != "#", distance[r][c] == -1 else { continue }
            distance[r][c] = distance[row][col] + 1
            queue.append((r, c))
        }
    }
    return nil
}
```

## DFS: counting connected parts

On an adjacency list. Swap the recursion for an explicit stack if the graph can be very deep. See [DFS](/dsa/learn/gt-dfs).

**Invariant:** Each call of `explore` from the outer loop marks one whole component, and `visited` stops any node being counted twice.

```swift check
func countComponents(_ nodeCount: Int, _ edges: [(Int, Int)]) -> Int {
    var neighbours = Array(repeating: [Int](), count: nodeCount)
    for (a, b) in edges {
        neighbours[a].append(b)
        neighbours[b].append(a)
    }
    var visited = Array(repeating: false, count: nodeCount)
    func explore(_ node: Int) {
        visited[node] = true
        for next in neighbours[node] where !visited[next] {
            explore(next)
        }
    }
    var components = 0
    for node in 0..<nodeCount where !visited[node] {
        components += 1
        explore(node)
    }
    return components
}
```

## Topological sort (Kahn's algorithm)

An order that respects every "a before b" edge, or nil if there's a cycle. See [Kahn's algorithm](/dsa/learn/topo-kahn).

**Invariant:** A node joins `ready` only once everything that must come before it is already in `order`.

```swift check
func topologicalOrder(_ nodeCount: Int, _ edges: [(from: Int, to: Int)]) -> [Int]? {
    var outgoing = Array(repeating: [Int](), count: nodeCount)
    var inDegree = Array(repeating: 0, count: nodeCount)
    for edge in edges {
        outgoing[edge.from].append(edge.to)
        inDegree[edge.to] += 1
    }
    var ready = (0..<nodeCount).filter { inDegree[$0] == 0 }
    var order: [Int] = []
    while let node = ready.popLast() {
        order.append(node)
        for next in outgoing[node] {
            inDegree[next] -= 1
            if inDegree[next] == 0 { ready.append(next) }
        }
    }
    return order.count == nodeCount ? order : nil
}
```

## Union-Find

With path compression and union by size: near-constant time per operation. See [Path compression and union by rank](/dsa/learn/uf-optimisations).

**Invariant:** Following `parent` from any element ends at its set's root, and `size` is accurate at every root.

```swift check
struct UnionFind {
    private var parent: [Int]
    private var size: [Int]

    init(count: Int) {
        parent = Array(0..<count)
        size = Array(repeating: 1, count: count)
    }

    // Iterative, so a long chain can't overflow the stack before it's compressed
    mutating func find(_ x: Int) -> Int {
        var root = x
        while parent[root] != root { root = parent[root] }
        var node = x
        while node != root {
            let next = parent[node]
            parent[node] = root
            node = next
        }
        return root
    }

    @discardableResult
    mutating func union(_ a: Int, _ b: Int) -> Bool {
        var rootA = find(a)
        var rootB = find(b)
        if rootA == rootB { return false }
        if size[rootA] < size[rootB] { swap(&rootA, &rootB) }
        parent[rootB] = rootA
        size[rootA] += size[rootB]
        return true
    }
}
```

## Kruskal's minimum spanning tree

The cheapest set of edges that connects every node: sort the edges by weight, then take each one that joins two different groups. A compact union-find, with path halving, comes along inside. See [Kruskal's algorithm](/dsa/learn/mst-kruskal).

**Invariant:** The edges taken so far are part of some minimum spanning tree, and `parent` groups the nodes they connect.

```swift check
/// The total weight of a minimum spanning tree, or nil if the graph isn't connected.
func minimumSpanningTree(_ nodeCount: Int, _ edges: [(a: Int, b: Int, weight: Int)]) -> Int? {
    var parent = Array(0..<nodeCount)         // a compact union-find
    func find(_ x: Int) -> Int {
        var x = x
        while parent[x] != x {
            parent[x] = parent[parent[x]]     // path halving
            x = parent[x]
        }
        return x
    }
    var total = 0
    var taken = 0
    for edge in edges.sorted(by: { $0.weight < $1.weight }) {
        let rootA = find(edge.a)
        let rootB = find(edge.b)
        if rootA == rootB { continue }        // already connected: this edge would close a cycle
        parent[rootA] = rootB
        total += edge.weight
        taken += 1
        if taken == nodeCount - 1 { break }   // the tree is complete
    }
    return taken == max(nodeCount - 1, 0) ? total : nil
}
```

## Dijkstra with a binary heap

Swift has no built-in heap, so a small one comes along. See [Dijkstra's algorithm](/dsa/learn/sp-dijkstra).

**Invariant:** When a node comes off the heap with an up-to-date distance, that distance is final. That's why weights must not be negative.

```swift check
struct MinHeap {
    private var items: [(distance: Int, node: Int)] = []
    var isEmpty: Bool { items.isEmpty }

    mutating func push(_ item: (distance: Int, node: Int)) {
        items.append(item)
        var child = items.count - 1
        while child > 0, items[(child - 1) / 2].distance > items[child].distance {
            items.swapAt(child, (child - 1) / 2)
            child = (child - 1) / 2
        }
    }

    mutating func pop() -> (distance: Int, node: Int)? {
        guard !items.isEmpty else { return nil }
        items.swapAt(0, items.count - 1)
        let smallest = items.removeLast()
        var parent = 0
        while true {
            let left = 2 * parent + 1
            let right = left + 1
            var next = parent
            if left < items.count, items[left].distance < items[next].distance { next = left }
            if right < items.count, items[right].distance < items[next].distance { next = right }
            if next == parent { break }
            items.swapAt(parent, next)
            parent = next
        }
        return smallest
    }
}

func shortestDistances(from source: Int, _ graph: [[(to: Int, weight: Int)]]) -> [Int] {
    var distance = Array(repeating: Int.max, count: graph.count)
    var heap = MinHeap()
    distance[source] = 0
    heap.push((0, source))
    while let (dist, node) = heap.pop() {
        if dist > distance[node] { continue }          // a stale entry
        for edge in graph[node] where dist + edge.weight < distance[edge.to] {
            distance[edge.to] = dist + edge.weight
            heap.push((distance[edge.to], edge.to))
        }
    }
    return distance
}
```

## Floyd–Warshall: all-pairs shortest paths

Every pair's shortest distance at once in O(n³), so for graphs of up to a few hundred nodes. Negative edges are fine, and negative cycles show up on the diagonal. For one source on a big graph, use Dijkstra instead. See [Floyd–Warshall](/dsa/learn/sp-floyd-warshall).

**Invariant:** After the pass for `via`, `dist[i][j]` is the shortest path from i to j whose stops in between all come from `0...via`.

```swift check
/// Shortest distances between every pair of nodes, in O(n³); Int.max / 2 means "no path".
/// Negative edges are fine. Afterwards, dist[v][v] < 0 means v is on a negative cycle.
func allPairsShortestPaths(_ nodeCount: Int, _ edges: [(from: Int, to: Int, weight: Int)]) -> [[Int]] {
    let infinity = Int.max / 2
    var dist = Array(repeating: Array(repeating: infinity, count: nodeCount), count: nodeCount)
    for node in 0..<nodeCount { dist[node][node] = 0 }
    for edge in edges {
        dist[edge.from][edge.to] = min(dist[edge.from][edge.to], edge.weight)
    }
    for via in 0..<nodeCount {                // via must be the outermost loop
        for i in 0..<nodeCount where dist[i][via] < infinity {
            for j in 0..<nodeCount where dist[via][j] < infinity {
                dist[i][j] = min(dist[i][j], dist[i][via] + dist[via][j])
            }
        }
    }
    return dist
}
```

## Backtracking

Choose, explore, unchoose. This generates every subset. See [The backtracking template](/dsa/learn/bk-template).

**Invariant:** `chosen` always matches the path from the top of the decision tree to the current call: whatever you append, you remove before returning.

```swift check
func subsets(_ items: [Int]) -> [[Int]] {
    var result: [[Int]] = []
    var chosen: [Int] = []
    func explore(_ start: Int) {
        result.append(chosen)
        for i in start..<items.count {
            chosen.append(items[i])          // choose
            explore(i + 1)                   // explore
            chosen.removeLast()              // unchoose
        }
    }
    explore(0)
    return result
}
```

## Bitmask subsets and submasks

When there are at most about 20 items, an `Int` can stand for a subset: bit i is set when item i is in. Counting from 0 to `(1 << n) - 1` visits every subset with no recursion, and `(sub - 1) & mask` steps through every submask of a mask. See [Bitmasks for subsets and submasks](/dsa/learn/bits-subsets).

**Invariant:** `sub` only ever uses bits of `mask`, and it strictly decreases, so the loop meets every non-empty submask exactly once. Add 0 yourself if you need the empty one.

```swift check
/// Every subset of items, one per mask: bit i of mask says whether items[i] is in.
func allSubsets<T>(_ items: [T]) -> [[T]] {
    var result: [[T]] = []
    for mask in 0..<(1 << items.count) {
        result.append(items.indices.filter { mask & (1 << $0) != 0 }.map { items[$0] })
    }
    return result
}

/// Every non-empty submask of mask, largest first. Over all masks of n bits, that's O(3ⁿ) in total.
func submasks(of mask: Int) -> [Int] {
    var result: [Int] = []
    var sub = mask
    while sub > 0 {
        result.append(sub)
        sub = (sub - 1) & mask                // the next smaller number using only mask's bits
    }
    return result
}
```

## Dynamic programming, top-down

Write the recursion, then cache it. See [Top-down memoisation](/dsa/learn/dp-memoisation).

**Invariant:** `memo[step]` is only ever set to the finished answer for `step`, so a lookup can always stand in for the call.

```swift check
func waysToClimb(_ n: Int) -> Int {
    var memo: [Int: Int] = [:]
    func ways(_ step: Int) -> Int {
        if step <= 1 { return 1 }
        if let known = memo[step] { return known }
        let result = ways(step - 1) + ways(step - 2)
        memo[step] = result
        return result
    }
    return ways(n)
}
```

## Dynamic programming, bottom-up on a grid

Fill the table in an order where each cell's dependencies are already done. This is longest common subsequence. See [Longest common subsequence](/dsa/learn/dps-lcs).

**Invariant:** `table[i][j]` is the answer for the first `i` characters of `a` and the first `j` of `b`. Row 0 and column 0 stand for empty strings.

```swift check
func longestCommonSubsequence(_ a: String, _ b: String) -> Int {
    let x = Array(a)
    let y = Array(b)
    guard !x.isEmpty, !y.isEmpty else { return 0 }
    var table = Array(repeating: Array(repeating: 0, count: y.count + 1), count: x.count + 1)
    for i in 1...x.count {
        for j in 1...y.count {
            table[i][j] = x[i - 1] == y[j - 1] ? table[i - 1][j - 1] + 1 : max(table[i - 1][j], table[i][j - 1])
        }
    }
    return table[x.count][y.count]
}
```

## 0/1 knapsack in one row

Each item can be taken at most once. One row of `capacity + 1` cells replaces the whole table, as long as the inner loop runs from high `w` to low. Run it from low to high instead and each item can be reused: that's unbounded knapsack. Subset sum and target sum are the same loop with a `Bool` or a count in each cell. See [0/1 knapsack, from 2D to 1D](/dsa/learn/dpk-01).

**Invariant:** Before an item's pass, `best[w]` is the most value from the earlier items with room `w`. Walking `w` downwards means `best[w - weight]` hasn't been overwritten yet, so the item is used at most once.

```swift check
/// The most value that fits in capacity, using each item at most once: O(n × capacity) time.
func knapsack(_ weights: [Int], _ values: [Int], _ capacity: Int) -> Int {
    var best = Array(repeating: 0, count: capacity + 1)       // best[w]: the most value with room w
    for (weight, value) in zip(weights, values) {
        // Right to left, so best[w - weight] still means "without this item".
        // An item heavier than capacity gives an empty stride, so it's skipped.
        for w in stride(from: capacity, through: weight, by: -1) {
            best[w] = max(best[w], best[w - weight] + value)
        }
    }
    return best[capacity]
}
```

## Longest increasing subsequence in O(n log n)

The length of the longest strictly increasing subsequence, by patience sorting: a binary search over the tops of the piles. For non-decreasing subsequences, search for the first tail greater than x instead, by changing `tails[mid] < x` to `tails[mid] <= x`. See [LIS in O(n log n) with patience sorting](/dsa/learn/lis-n-log-n).

**Invariant:** `tails` is strictly increasing, and `tails[k]` is the smallest value an increasing subsequence of length `k + 1` can end with. `tails` itself isn't an LIS; only its length is the answer.

```swift check
/// The length of the longest strictly increasing subsequence, in O(n log n).
func lengthOfLIS(_ items: [Int]) -> Int {
    var tails: [Int] = []          // tails[k]: the smallest end of any increasing run of length k + 1
    for x in items {
        var low = 0
        var high = tails.count
        while low < high {         // lower bound: the first tail that is at least x
            let mid = low + (high - low) / 2
            if tails[mid] < x { low = mid + 1 } else { high = mid }
        }
        if low == tails.count {
            tails.append(x)        // x beats every tail: the longest run grows by one
        } else {
            tails[low] = x         // a run of length low + 1 can now end lower
        }
    }
    return tails.count
}
```

## Bitmask DP over subsets

When the state is "which of n things are done" and n is at most about 20, that set, as a bitmask, is the state. This is the travelling salesman problem: the shortest round trip from node 0 through every node. Assignment and "fewest groups" problems follow the same shape. See [Bitmask DP: TSP and assignment](/dsa/learn/dpa-bitmask).

**Invariant:** Every transition adds a bit, so it moves to a bigger mask. Processing masks in increasing order means `best[mask]` is final before anything reads it.

```swift check
/// The shortest round trip from node 0 through every node and back, in O(2ⁿ × n²) time.
func shortestTour(_ distance: [[Int]]) -> Int {
    let n = distance.count
    guard n > 1 else { return 0 }
    let full = 1 << n
    let unreached = Int.max / 2
    // best[mask][last]: the shortest path from 0 that visits exactly the nodes in mask and ends at last
    var best = Array(repeating: Array(repeating: unreached, count: n), count: full)
    best[1][0] = 0
    for mask in 1..<full where mask & 1 != 0 {
        for last in 0..<n where best[mask][last] < unreached {
            for next in 0..<n where mask & (1 << next) == 0 {
                let grown = mask | (1 << next)
                best[grown][next] = min(best[grown][next], best[mask][last] + distance[last][next])
            }
        }
    }
    return (1..<n).map { best[full - 1][$0] + distance[$0][0] }.min() ?? unreached
}
```

## Segment tree, bottom-up

Range sums with point updates, both O(log n), in an array of 2n slots with no recursion. For range minimums, swap `+` for `min` and the starting `0` of `total` for `Int.max`; any operation that's associative and ignores order (sum, min, max, gcd, xor) works the same way. Range updates need the recursive version with lazy propagation. See [Build, query and update](/dsa/learn/seg-build-query-update).

**Invariant:** Every internal node `tree[i]` equals `tree[2 * i] + tree[2 * i + 1]`, with the items themselves at `tree[n..<2n]`.

```swift check
/// Range sums with point updates, both O(log n). Leaves live at tree[n..<2n]; no recursion.
struct SegmentTree {
    private var tree: [Int]
    private let n: Int

    init(_ items: [Int]) {
        n = items.count
        tree = Array(repeating: 0, count: n) + items
        for node in stride(from: n - 1, through: 1, by: -1) {
            tree[node] = tree[2 * node] + tree[2 * node + 1]
        }
    }

    mutating func set(_ index: Int, to value: Int) {
        var node = index + n
        tree[node] = value
        while node > 1 {
            node /= 2
            tree[node] = tree[2 * node] + tree[2 * node + 1]
        }
    }

    /// The sum of items[range], for a half-open range such as 2..<5.
    func sum(_ range: Range<Int>) -> Int {
        var left = range.lowerBound + n
        var right = range.upperBound + n
        var total = 0
        while left < right {
            if left % 2 == 1 {                // a right child: its parent sticks out on the left
                total += tree[left]
                left += 1
            }
            if right % 2 == 1 {               // right - 1 is a left child: its parent sticks out on the right
                right -= 1
                total += tree[right]
            }
            left /= 2
            right /= 2
        }
        return total
    }
}
```

## Fenwick tree

Prefix sums that stay correct through updates. Both operations are O(log n), and the code is two short loops: smaller than a segment tree when all you need is sums. Use it for running totals, counting inversions and "how many smaller values so far". See [Point update and prefix query](/dsa/learn/bit-point-update).

**Invariant:** With 1-indexed positions, `tree[i]` holds the sum of the `i & -i` items that end at position i.

```swift check
/// Prefix sums with point updates, both O(log n). 0-indexed outside, 1-indexed inside.
struct FenwickTree {
    private var tree: [Int]                   // tree[i] covers positions i - (i & -i) + 1 ... i

    init(_ items: [Int]) {
        tree = [0] + items                    // an O(n) build: each slot passes its total up once
        for i in 1..<tree.count {
            let parent = i + (i & -i)
            if parent < tree.count { tree[parent] += tree[i] }
        }
    }

    /// Adds delta to items[index].
    mutating func add(_ delta: Int, at index: Int) {
        var i = index + 1
        while i < tree.count {
            tree[i] += delta
            i += i & -i
        }
    }

    /// The sum of items[0...index]; an index of -1 gives 0.
    func prefixSum(through index: Int) -> Int {
        var i = index + 1
        var total = 0
        while i > 0 {
            total += tree[i]
            i -= i & -i
        }
        return total
    }

    /// The sum of items[left...right].
    func sum(_ left: Int, _ right: Int) -> Int {
        prefixSum(through: right) - prefixSum(through: left - 1)
    }
}
```

## KMP: prefix function and matching

Every place a pattern occurs in a text, overlaps included, in O(n + m). The prefix function on its own also gives a string's shortest period and its longest prefix that's also a suffix. Pass `Array(text.utf8)` for speed, or `Array(text)` to compare whole Characters. See [KMP and the prefix function](/dsa/learn/sa-kmp).

**Invariant:** After reading `text[i]`, `j` is the length of the longest prefix of the pattern that ends at position i of the text.

```swift check
/// pi[i]: the length of the longest proper prefix of s[0...i] that is also a suffix of it.
func prefixFunction<T: Equatable>(_ s: [T]) -> [Int] {
    var pi = Array(repeating: 0, count: s.count)
    var k = 0                                 // the length of the border being extended
    for i in s.indices.dropFirst() {
        while k > 0 && s[i] != s[k] { k = pi[k - 1] }     // fall back to the next shorter border
        if s[i] == s[k] { k += 1 }
        pi[i] = k
    }
    return pi
}

/// Every index where pattern starts in text, overlaps included, in O(n + m).
func occurrences<T: Equatable>(of pattern: [T], in text: [T]) -> [Int] {
    guard !pattern.isEmpty else { return [] }
    let pi = prefixFunction(pattern)
    var result: [Int] = []
    var j = 0                                 // how many pattern characters match so far
    for (i, c) in text.enumerated() {
        while j > 0 && c != pattern[j] { j = pi[j - 1] }  // shift the pattern; the text stays put
        if c == pattern[j] { j += 1 }
        if j == pattern.count {
            result.append(i - j + 1)
            j = pi[j - 1]                     // keep the border, so overlapping matches count
        }
    }
    return result
}
```

## Modular power and inverse

For answers "modulo 1,000,000,007": powers in O(log n), and division, which means multiplying by an inverse. When m is prime, the inverse is also `modPow(a, m - 2, m)`, by Fermat's little theorem; extended Euclid works for any m. See [Fast exponentiation](/dsa/learn/math-fast-power) and [Extended Euclid and modular inverse](/dsa/learn/nt-extended-euclid).

**Invariant:** `result × square^e` stays equal to `base^exponent`, mod m, while `e` halves.

```swift check
/// base to the power exponent, mod m, in O(log exponent). Keep m below 2³¹ so products fit in an Int.
func modPow(_ base: Int, _ exponent: Int, _ m: Int) -> Int {
    var result = 1 % m                        // 1 % m, not 1, so m = 1 gives 0
    var square = ((base % m) + m) % m         // reduced, and never negative
    var e = exponent
    while e > 0 {
        if e & 1 == 1 { result = result * square % m }
        square = square * square % m
        e >>= 1
    }
    return result
}

/// The x in 0..<m with a × x ≡ 1 (mod m), or nil if gcd(a, m) isn't 1. Extended Euclid: any m works.
func modInverse(_ a: Int, _ m: Int) -> Int? {
    var (oldR, r) = (((a % m) + m) % m, m)
    var (oldX, x) = (1, 0)                    // throughout: oldR ≡ oldX × a and r ≡ x × a (mod m)
    while r != 0 {
        let q = oldR / r
        (oldR, r) = (r, oldR - q * r)
        (oldX, x) = (x, oldX - q * x)
    }
    guard oldR == 1 else { return nil }
    return ((oldX % m) + m) % m
}
```

## Matrix exponentiation

When each new term is a fixed linear mix of the previous k terms (Fibonacci, tribonacci, tilings, walks of length n in a graph), one step is a k × k matrix and n steps are its nth power: O(k³ log n) instead of O(n). Check the first few terms against a plain loop before you trust a huge n. See [Matrix exponentiation](/dsa/learn/nt-matrix-power).

**Invariant:** The same as for `modPow`: `result × square^e` always equals `base^exponent`, so O(log exponent) multiplications are enough.

```swift check
typealias Matrix = [[Int]]

/// a × b with every entry reduced mod m. Entries must be in 0..<m, and m below 2³¹.
func multiply(_ a: Matrix, _ b: Matrix, _ m: Int) -> Matrix {
    let columns = b.first?.count ?? 0
    var product = Array(repeating: Array(repeating: 0, count: columns), count: a.count)
    for i in a.indices {
        for t in b.indices where a[i][t] != 0 {
            for j in 0..<columns {
                product[i][j] = (product[i][j] + a[i][t] * b[t][j]) % m
            }
        }
    }
    return product
}

/// A square matrix to the power exponent, mod m, in O(k³ log exponent).
func matrixPower(_ base: Matrix, _ exponent: Int, _ m: Int) -> Matrix {
    var result = base.indices.map { i in base.indices.map { j in i == j ? 1 % m : 0 } }   // the identity
    var square = base
    var e = exponent
    while e > 0 {
        if e & 1 == 1 { result = multiply(result, square, m) }
        square = multiply(square, square, m)
        e >>= 1
    }
    return result
}

/// F(n) mod m, since [[1, 1], [1, 0]] to the power n is [[F(n + 1), F(n)], [F(n), F(n - 1)]].
func fibonacci(_ n: Int, _ m: Int) -> Int {
    matrixPower([[1, 1], [1, 0]], n, m)[0][1]
}
```

## Fast input for judges

Reads all of standard input at once and parses integers byte by byte: far faster than `readLine()` plus `split` for big inputs. See [Fast input for competitive programming](/dsa/learn/swift-fast-input).

**Invariant:** `index` always points at the first byte not yet read.

```swift check
import Foundation

struct FastReader {
    private let bytes = Array(FileHandle.standardInput.readDataToEndOfFile())
    private var index = 0

    mutating func int() -> Int {
        while index < bytes.count, bytes[index] == 32 || bytes[index] == 10 || bytes[index] == 13 { index += 1 }
        var sign = 1
        if index < bytes.count, bytes[index] == 45 { sign = -1; index += 1 }
        var value = 0
        while index < bytes.count, bytes[index] >= 48, bytes[index] <= 57 {
            value = value * 10 + Int(bytes[index] - 48)
            index += 1
        }
        return sign * value
    }
}
```
