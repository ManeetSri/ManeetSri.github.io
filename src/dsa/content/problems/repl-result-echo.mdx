When you type an expression into the Swift REPL without naming it, the REPL shows the result with a temporary name and its type, such as `$R0: Int = 3` after `7 / 2`. Rebuild that line for a whole-number result.

`ReplResultEcho.line(position: Int, value: Int) -> String`

- `position` says which unnamed result this is: 1 for the first, 2 for the second, and so on.
- The REPL counts its temporary names **from 0**, so the first unnamed result is `$R0`, the second is `$R1`, and so on.
- Return `"$R<number>: Int = <value>"`, with one space after the colon and one on each side of `=`.

As in the other early problems, the exercise file already has the function. `position` and `value` work like constants that hold the numbers; replace `return ""` with `return` followed by your text.

## Examples

| Call | Returns | Why |
| --- | --- | --- |
| `line(position: 1, value: 3)` | `"$R0: Int = 3"` | the first unnamed result, as for `7 / 2` |
| `line(position: 2, value: 36)` | `"$R1: Int = 36"` | the second one |
| `line(position: 11, value: -5)` | `"$R10: Int = -5"` | counting from 0, the 11th name is `$R10` |
| `line(position: 3, value: 0)` | `"$R2: Int = 0"` | zero is printed as `0` |

## Constraints

- `1 ≤ position ≤ 1,000`
- `-10⁹ ≤ value ≤ 10⁹`
- Spaces, colon and capitals must match exactly.

<Hints>
<Hint>
String interpolation puts a value inside text: `"Int = \(value)"`. The `$` is an ordinary character inside a Swift string, so you can type it as it is.
</Hint>
<Hint>
The number after `$R` isn't `position` itself. If the first result is called `$R0`, what do you need to do to `position` to get the REPL's number?
</Hint>
<Hint>
Interpolation accepts a calculation, not only a name: `\(position - 1)` works out the number and inserts it.
</Hint>
</Hints>

## Solutions

<Approach title="One interpolated string" time="O(1)" space="O(1)">

Two interpolations: one for the REPL's number, worked out inside the parentheses, and one for the value.

```swift
public enum ReplResultEcho {
    public static func line(position: Int, value: Int) -> String {
        return "$R\(position - 1): Int = \(value)"
    }
}
```

The line is at most about 30 characters, so building it takes constant time.

</Approach>

<Approach title="Name the REPL's number first" time="O(1)" space="O(1)">

If the off-by-one is the part you're likely to forget, give it a name of its own. The name explains the subtraction, so no comment is needed.

```swift
public enum ReplResultEcho {
    public static func line(position: Int, value: Int) -> String {
        let resultNumber = position - 1
        return "$R\(resultNumber): Int = \(value)"
    }
}
```

Counting from 0 is everywhere in programming, from the REPL's names to positions in an array, which you'll meet in M07. Converting between "the 1st, 2nd, 3rd" and "0, 1, 2" is a habit worth building now.

</Approach>
