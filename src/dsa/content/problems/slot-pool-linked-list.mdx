Build a doubly linked list of `Int`s without a single class: every node is a struct in one array, linked to its neighbours by `Int` indices. A node's position in that array, its **slot**, is its handle. Removed slots go on a free list and are reused, so a list that churns through millions of insertions and removals never grows beyond its largest size.

`SlotPoolList.List`, with `count`, `slotCount`, `values`, `valuesBackward`, `value(at:)`, `pushFront(_:)`, `pushBack(_:)`, `insert(_:after:)` and `remove(_:)`

- `pushFront`, `pushBack` and `insert(_:after:)` add a value and **return its handle**. `insert(_:after:)` puts it straight after the node with the given handle.
- `remove(_:)` removes the node with that handle and returns its value. Its slot becomes free.
- **Slot rule:** a new node always takes the **most recently freed** slot. Only when no slot is free does it take a new slot, numbered `slotCount`.
- `slotCount` is the number of slots created so far, used or free. `count` is the number of values.
- `values` lists the values front to back; `valuesBackward` lists them back to front by following the backward links, so it checks those links too.
- `value(at:)` reads the value of a node that's in the list.
- Copies of a `List` are independent values.

## Examples

| Code | Returns | `values` afterwards | `slotCount` |
| --- | --- | --- | --- |
| `pushBack(10)` | `0` | `[10]` | 1 |
| `pushBack(20)` | `1` | `[10, 20]` | 2 |
| `pushBack(30)` | `2` | `[10, 20, 30]` | 3 |
| `remove(1)` | `20` | `[10, 30]` | 3 |
| `pushFront(5)` | `1` (slot 1 reused) | `[5, 10, 30]` | 3 |
| `insert(15, after: 0)` | `3` (no free slot) | `[5, 10, 15, 30]` | 4 |

If slots 0, 2 and 4 are freed in that order, the next three new nodes get slots 4, 2 and 0.

## Constraints

- Up to 300,000 operations. Every handle passed to `value(at:)`, `insert(_:after:)` or `remove(_:)` belongs to a node currently in the list.
- Aim for O(1) per operation, except `values` and `valuesBackward`, which are O(count).
- The tests remove 50,000 nodes from the middle of a 100,000-node list and put them back, and run 200,000 rounds of removing the front and adding at the back with 1,000 nodes alive. Shifting array elements on removal would be billions of moves.

<Hints>
<Hint>
Store `struct Node { var value: Int; var previous: Int; var next: Int }` in a `[Node]`, with `-1` meaning "no node". Keep `head` and `tail` indices too. Linking and unlinking work exactly as in [Doubly linked and circular lists](/dsa/learn/ll-doubly-circular), with indices in place of references.
</Hint>
<Hint>
The free list is a stack of slots, and it needs no extra array: thread it through the free nodes' own `next` field, with a `freeHead` index. Freeing a slot pushes it (`nodes[slot].next = freeHead; freeHead = slot`); taking one pops it.
</Hint>
<Hint>
Write one private helper that creates a node, taking a free slot if `freeHead != -1` and appending otherwise. Then `pushBack` on a non-empty list is `insert(value, after: tail)`, and only `pushFront` needs its own linking code. Remember to update `tail` when inserting after the last node and when removing it.
</Hint>
</Hints>

## Solutions

<Approach title="An array of values, shifted on removal" time="O(n) per removal" space="O(n)">

Keeping the values in a plain array in list order, with a dictionary from handle to position, makes `remove` and `insert` shift every later element and renumber their positions: O(n) each. Removing 50,000 nodes from the middle of 100,000 is over a billion moves, and the slot rule still needs separate bookkeeping.

</Approach>

<Approach title="Nodes in an array, with a free list" time="O(1) per operation" space="O(peak count)">

Every node lives in `nodes`, linked both ways by index. Removal unlinks the node in O(1) and pushes its slot onto the free list; creation pops a free slot before ever growing the array. There's no reference counting and one allocation for the whole list (plus its occasional growth), and copying a `List` copies arrays and integers, so copies are independent for free.

```swift
public enum SlotPoolList {
    public struct List {
        private struct Node {
            var value: Int
            var previous: Int
            var next: Int
        }

        private static let none = -1

        private var nodes: [Node] = []
        private var head = none
        private var tail = none
        private var freeHead = none
        public private(set) var count = 0

        public init() {}

        public var slotCount: Int {
            nodes.count
        }

        public var values: [Int] {
            var result: [Int] = []
            result.reserveCapacity(count)
            var current = head
            while current != Self.none {
                result.append(nodes[current].value)
                current = nodes[current].next
            }
            return result
        }

        public var valuesBackward: [Int] {
            var result: [Int] = []
            result.reserveCapacity(count)
            var current = tail
            while current != Self.none {
                result.append(nodes[current].value)
                current = nodes[current].previous
            }
            return result
        }

        public func value(at handle: Int) -> Int {
            nodes[handle].value
        }

        /// Takes a slot from the free list, or adds a new one, and fills it
        private mutating func makeNode(_ value: Int, previous: Int, next: Int) -> Int {
            let node = Node(value: value, previous: previous, next: next)
            if freeHead != Self.none {
                let slot = freeHead
                freeHead = nodes[slot].next
                nodes[slot] = node
                return slot
            }
            nodes.append(node)
            return nodes.count - 1
        }

        @discardableResult
        public mutating func pushFront(_ value: Int) -> Int {
            let slot = makeNode(value, previous: Self.none, next: head)
            if head != Self.none {
                nodes[head].previous = slot
            } else {
                tail = slot
            }
            head = slot
            count += 1
            return slot
        }

        @discardableResult
        public mutating func pushBack(_ value: Int) -> Int {
            if tail == Self.none {
                return pushFront(value)
            }
            return insert(value, after: tail)
        }

        @discardableResult
        public mutating func insert(_ value: Int, after handle: Int) -> Int {
            let following = nodes[handle].next
            let slot = makeNode(value, previous: handle, next: following)
            nodes[handle].next = slot
            if following != Self.none {
                nodes[following].previous = slot
            } else {
                tail = slot
            }
            count += 1
            return slot
        }

        @discardableResult
        public mutating func remove(_ handle: Int) -> Int {
            let node = nodes[handle]
            if node.previous != Self.none {
                nodes[node.previous].next = node.next
            } else {
                head = node.next
            }
            if node.next != Self.none {
                nodes[node.next].previous = node.previous
            } else {
                tail = node.previous
            }
            nodes[handle].next = freeHead          // push the slot onto the free list
            nodes[handle].previous = Self.none
            freeHead = handle
            count -= 1
            return node.value
        }
    }
}
```

`nodes[handle].next = freeHead` changes the node inside the array, in place, without copying it out; that's the in-place element access from [Avoiding accidental copies](/dsa/learn/fs-avoiding-copies). A handle kept after its node is removed becomes stale: its slot may later hold a different node, which is why the constraints promise every handle you're given is live.

</Approach>
