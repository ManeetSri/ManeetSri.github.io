A conservation group wants to put one fence round every tree in a wood, using as little fencing as possible. A post goes at each corner of the fence and nowhere else. Return the trees where the corner posts go.

`FenceCornerPosts.corners(_ trees: [[Int]]) -> [[Int]]`

Each tree is `[x, y]`, and the same spot may be listed more than once. The shortest fence is the **convex hull** of the trees. Return its corners:

- **counterclockwise**, starting from the corner with the smallest x (and, among those, the smallest y);
- **corners only**: a tree on a straight stretch of fence between two corners doesn't get a post;
- each corner once, however many times it appears in the input.

If every tree is on one straight line, the "fence" is that line: return its two ends, the smaller `(x, y)` first. One distinct spot gives one corner, and no trees give `[]`.

## Examples

| `trees` | Output |
| --- | --- |
| `[[0, 0], [4, 0], [4, 4], [0, 4], [2, 2], [1, 3]]` | `[[0, 0], [4, 0], [4, 4], [0, 4]]` |
| `[[1, 1], [2, 2], [2, 0], [2, 4], [3, 3], [4, 2]]` | `[[1, 1], [2, 0], [4, 2], [2, 4]]` |
| `[[0, 3], [0, 1], [2, 0], [3, 2], [0, 2]]` | `[[0, 1], [2, 0], [3, 2], [0, 3]]` |
| `[[1, 1], [3, 3], [2, 2], [5, 5]]` | `[[1, 1], [5, 5]]` |
| `[[4, 4], [4, 4], [4, 4]]` | `[[4, 4]]` |
| `[]` | `[]` |

In the second example, (3, 3) lies on the fence between (4, 2) and (2, 4), so it isn't a corner, and (2, 2) is inside. In the third, three trees have x = 0: the lowest, (0, 1), starts the list, and (0, 2) is on the fence between (0, 3) and (0, 1).

## Constraints

- `0 ≤ trees.count ≤ 200,000`
- `-10⁹ ≤ x, y ≤ 10⁹`
- One test puts 60,001 trees on the curve y = x², so every one of them is a corner. An algorithm that does O(n) work per corner is far too slow there.

<Hints>
<Hint>
Sort the trees by x, then by y, and remove duplicates. The first tree is now the starting corner, and the last is the rightmost corner.
</Hint>
<Hint>
Build the bottom of the fence from left to right with a stack. Before pushing a tree, pop the top of the stack while the top two and the new tree don't make a strict left turn. "Straight on" counts as not turning left, so trees in the middle of a straight stretch get popped.
</Hint>
<Hint>
Build the top of the fence the same way from right to left, then join the two halves, dropping the last tree of each (it's the first tree of the other). Handle fewer than three distinct trees before any of this.
</Hint>
</Hints>

## Solutions

<Approach title="Gift wrapping" time="O(n · h)" space="O(h)">

Start at the first corner, and repeatedly find the tree that makes every other tree lie to the left of the line to it (taking the farthest one when several are collinear); that's the next corner. Each corner costs a pass over all n trees, so h corners cost O(n · h). That's fast when the fence has few corners and far too slow on the parabola test, where h is 60,001.

</Approach>

<Approach title="Andrew's monotone chain" time="O(n log n)" space="O(n)">

The lower and upper hulls, each built with one stack pass over the sorted trees. Popping on orientation ≤ 0 removes right turns and straight-on trees alike, which is exactly the corners-only rule. The output starts at the smallest `(x, y)` and runs counterclockwise with no extra work.

```swift
public enum FenceCornerPosts {
    struct Point: Comparable {
        var x: Int
        var y: Int
        static func < (lhs: Point, rhs: Point) -> Bool { (lhs.x, lhs.y) < (rhs.x, rhs.y) }
    }

    static func orientation(_ a: Point, _ b: Point, _ c: Point) -> Int {
        (b.x - a.x) * (c.y - a.y) - (b.y - a.y) * (c.x - a.x)
    }

    public static func corners(_ trees: [[Int]]) -> [[Int]] {
        var points: [Point] = []
        for p in trees.map({ Point(x: $0[0], y: $0[1]) }).sorted() where points.last != p {
            points.append(p)                            // sorted, so duplicates are neighbours
        }
        if points.count < 3 {
            return points.map { [$0.x, $0.y] }
        }
        func chain(_ ordered: [Point]) -> [Point] {
            var hull: [Point] = []
            for p in ordered {
                while hull.count >= 2 && orientation(hull[hull.count - 2], hull[hull.count - 1], p) <= 0 {
                    hull.removeLast()
                }
                hull.append(p)
            }
            return hull
        }
        let hull = chain(points).dropLast() + chain(points.reversed()).dropLast()
        return hull.map { [$0.x, $0.y] }
    }
}
```

When every tree is on one line, each chain shrinks to its two ends, so the result is the two ends of the line, as required. Orientation multiplies coordinate differences of up to 2 × 10⁹, so it reaches at most 8 × 10¹⁸ and fits in an `Int`.

</Approach>
