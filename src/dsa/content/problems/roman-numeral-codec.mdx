Convert between whole numbers and **Roman numerals**, in both directions.

The symbols are I = 1, V = 5, X = 10, L = 50, C = 100, D = 500 and M = 1000, written from largest to smallest and added up. Six pairs put a smaller symbol first to subtract it: IV = 4, IX = 9, XL = 40, XC = 90, CD = 400 and CM = 900. The standard form never uses four of the same symbol in a row, and uses those pairs instead.

`RomanNumeralCodec.roman(from number: Int) -> String`

`RomanNumeralCodec.value(of numeral: String) -> Int`

## Examples

| Call | Output |
| --- | --- |
| `roman(from: 2024)` | `"MMXXIV"` |
| `roman(from: 444)` | `"CDXLIV"` |
| `roman(from: 3888)` | `"MMMDCCCLXXXVIII"` |
| `value(of: "XIV")` | `14` |
| `value(of: "CMXCIX")` | `999` |
| `value(of: "MMMCMXCIX")` | `3999` |

`444` is 400 + 40 + 4, so it's CD, XL and IV. `"CMXCIX"` reads as CM (900), XC (90) and IX (9).

## Constraints

- `1 ≤ number ≤ 3999`
- `numeral` is always a valid numeral in standard form for a value from 1 to 3999.

<Hints>
<Hint>
Reading: add up the symbols' values, except that a symbol followed by a **larger** symbol is subtracted instead. In `"XIV"`, the I is followed by V, so it counts as −1.
</Hint>
<Hint>
Writing: repeatedly take the largest value that still fits, write its symbol and subtract it. That works if the table of values includes the six subtractive pairs.
</Hint>
<Hint>
A table of 13 `(value, symbol)` pairs from 1000 (`"M"`) down to 1 (`"I"`), including 900 (`"CM"`) and 4 (`"IV"`), does all the writing with two nested loops.
</Hint>
</Hints>

## Solutions

<Approach title="Look ahead to read, greedy table to write" time="O(1)" space="O(1)">

Numerals here are at most 15 symbols long, so both directions take constant time. In general they're linear in the numeral's length.

```swift
public enum RomanNumeralCodec {
    private static let table: [(value: Int, symbol: String)] = [
        (1000, "M"), (900, "CM"), (500, "D"), (400, "CD"),
        (100, "C"), (90, "XC"), (50, "L"), (40, "XL"),
        (10, "X"), (9, "IX"), (5, "V"), (4, "IV"), (1, "I"),
    ]

    public static func roman(from number: Int) -> String {
        var remaining = number
        var result = ""
        for (value, symbol) in table {
            while remaining >= value {
                result += symbol
                remaining -= value
            }
        }
        return result
    }

    public static func value(of numeral: String) -> Int {
        let values = numeral.map(symbolValue)
        var total = 0
        for index in values.indices {
            if index + 1 < values.count && values[index] < values[index + 1] {
                total -= values[index]
            } else {
                total += values[index]
            }
        }
        return total
    }

    private static func symbolValue(_ symbol: Character) -> Int {
        switch symbol {
        case "I": return 1
        case "V": return 5
        case "X": return 10
        case "L": return 50
        case "C": return 100
        case "D": return 500
        case "M": return 1000
        default: return 0
        }
    }
}
```

`numeral.map(symbolValue)` turns the string into an array of numbers first, so looking at the next symbol is a plain index.

</Approach>
