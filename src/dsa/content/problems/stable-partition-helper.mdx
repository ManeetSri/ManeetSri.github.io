The standard library's `partition(by:)` moves the matching elements to the back but scrambles the order inside each group. Write a **stable** partition: every element for which the predicate is false comes first, then every element for which it's true, and both groups keep their original relative order. Call the predicate exactly once per element, and return the index where the second group starts.

`StablePartitionHelper.stablePartition(_ items: inout [T], by belongsInSecondPartition: (T) -> Bool) -> Int`

## Examples

| `items` | Predicate | `items` afterwards | Returns |
| --- | --- | --- | --- |
| `[10, 20, 30, 40, 50, 60, 70, 80]` | multiple of 20 | `[10, 30, 50, 70, 20, 40, 60, 80]` | `4` |
| `[3, 6, 9, 1, 4]` | multiple of 3 | `[1, 4, 3, 6, 9]` | `2` |
| `["kiwi", "banana", "fig", "cherry", "plum", "apple"]` | more than 4 letters | `["kiwi", "fig", "plum", "banana", "cherry", "apple"]` | `3` |
| `[5, 10, 15]` | multiple of 5 | `[5, 10, 15]` | `0` |
| `[1, 2, 4]` | multiple of 7 | `[1, 2, 4]` | `3` |
| `[]` | anything | `[]` | `0` |

## Constraints

- `0 ≤ items.count ≤ 200,000`
- The function is generic: the tests use `Int`, `String` and a struct.
- The predicate may be expensive or count its calls: call it exactly once per element.

<Hints>
<Hint>
You don't have to work in place. What if you sorted every element into one of two piles as you met it?
</Hint>
<Hint>
Appending to an array keeps arrival order, so two arrays, one per group, are already in the right order. The answer's index is the size of the first one.
</Hint>
<Hint>
For an in-place version, think divide and conquer: stable-partition each half, and then the array looks like `[F1 T1 F2 T2]`. Rotating the middle `T1 F2` into `F2 T1` finishes the job.
</Hint>
</Hints>

## Solutions

<Approach title="Two buffers" time="O(n)" space="O(n)">

One pass asks about each element once and appends it to the matching buffer; then the array becomes the first buffer followed by the second.

```swift
public enum StablePartitionHelper {
    public static func stablePartition<T>(_ items: inout [T], by belongsInSecondPartition: (T) -> Bool) -> Int {
        var first: [T] = []
        var second: [T] = []
        first.reserveCapacity(items.count)
        for item in items {
            if belongsInSecondPartition(item) {
                second.append(item)
            } else {
                first.append(item)
            }
        }
        let pivot = first.count
        first.append(contentsOf: second)
        items = first
        return pivot
    }
}
```

</Approach>

<Approach title="Divide and conquer with rotation, in place" time="O(n log n)" space="O(log n)">

This is how swift-algorithms' `stablePartition(by:)` works. Partition a range by splitting it in half and partitioning each half recursively, which leaves `[F1 T1 F2 T2]`. Then rotate the middle so that `F2` comes before `T1`. A rotation is three reversals, as in [Reverse and rotate in place](/dsa/learn/arrays-reverse-rotate). Each level of the recursion does O(n) work in rotations, and there are log n levels. The predicate is only asked about single elements, at the bottom of the recursion, so it's still called once per element.

```swift
public enum StablePartitionHelper {
    public static func stablePartition<T>(_ items: inout [T], by belongsInSecondPartition: (T) -> Bool) -> Int {
        func reverse(_ low: Int, _ high: Int) {            // reverses items[low..<high]
            var (i, j) = (low, high - 1)
            while i < j {
                items.swapAt(i, j)
                i += 1
                j -= 1
            }
        }
        // Partitions items[low..<high] and returns where its second group starts
        func partition(_ low: Int, _ high: Int) -> Int {
            if high - low == 0 { return low }
            if high - low == 1 { return belongsInSecondPartition(items[low]) ? low : high }
            let middle = (low + high) / 2
            let leftSplit = partition(low, middle)          // [F1 T1] in low..<middle
            let rightSplit = partition(middle, high)        // [F2 T2] in middle..<high
            // Rotate T1 F2 into F2 T1: reverse each part, then reverse both together
            reverse(leftSplit, middle)
            reverse(middle, rightSplit)
            reverse(leftSplit, rightSplit)
            return leftSplit + (rightSplit - middle)
        }
        return partition(0, items.count)
    }
}
```

The nested functions modify `items` directly: they capture the `inout` parameter, which Swift allows because they don't escape.

</Approach>
