You have a row of stones with positive weights. A turn picks **any** two stones and smashes them together: if they weigh the same, both are destroyed; otherwise the lighter one is destroyed and the heavier one now weighs the difference. Turns continue until at most one stone is left. Return the smallest weight that last stone can have, or 0 if no stone is left.

`StoneSmashLeftover.smallestRemainder(_ stones: [Int]) -> Int`

## Examples

| `stones` | Output |
| --- | --- |
| `[2, 2, 2, 3, 3]` | `0` |
| `[10, 4]` | `6` |
| `[1, 2, 4, 8, 16]` | `1` |
| `[3, 3, 3, 4, 4]` | `1` |
| `[7]` | `7` |

In the first example, smash a 3 with a 2 (leaving 1), the other 3 with a 2 (leaving 1), the last 2 with a 1 (leaving 1), and then the two 1s destroy each other. Smashing the two 3s together first would leave a 2 at the end, so the order matters. In the third, the 16 outweighs all the others together (15), so the best you can do is wear it down to 1.

## Constraints

- `1 ≤ stones.count ≤ 100`
- `1 ≤ stones[i] ≤ 1,000`
- The tests use 100 stones, so trying every order of smashes, or every split, won't finish.

<Hints>
<Hint>
Follow one stone's weight through the smashes. Each time, it's either added to the result or subtracted from it.
</Hint>
<Hint>
So the last stone is the difference between two piles. The smallest possible difference can always be reached, so you're looking for the split into two piles that's as even as possible.
</Hint>
<Hint>
With total `S`, find the largest subset sum `P` that's at most `S / 2` (a Boolean subset sum, right to left). The answer is `S - 2P`.
</Hint>
</Hints>

## Solutions

<Approach title="Play every game" time="exponential" space="O(n)">

Try every pair at every turn, recursively, and keep the lightest ending. It's the most direct reading of the rules and a useful check for five or six stones, but the number of games explodes after that.

</Approach>

<Approach title="Two piles, as even as possible" time="O(n · S)" space="O(S)">

Each smash subtracts one stone's weight from another's, so the last stone is a sum of the weights with a `+` or `-` in front of each: the difference between two piles. The smallest difference is reachable: smash one stone from each pile at a time, returning the leftover to the heavier stone's pile, and the gap between the piles never changes. So minimise `S - 2P` with `P ≤ S / 2`.

```swift
public enum StoneSmashLeftover {
    public static func smallestRemainder(_ stones: [Int]) -> Int {
        let total = stones.reduce(0, +)
        let half = total / 2
        var reachable = Array(repeating: false, count: half + 1)
        reachable[0] = true
        for stone in stones where stone <= half {
            for s in stride(from: half, through: stone, by: -1) where reachable[s - stone] {
                reachable[s] = true
            }
        }
        var lighter = half
        while !reachable[lighter] {
            lighter -= 1
        }
        return total - 2 * lighter
    }
}
```

The `while` loop always stops, because `reachable[0]` is true. A stone heavier than half the total can never be in the lighter pile, so it's skipped.

</Approach>
