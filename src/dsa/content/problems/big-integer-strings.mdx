Some numbers are too big for any built-in integer type: a 64-bit `Int` stops at about 9.2 × 10¹⁸. Add and multiply integers written as decimal strings, digit by digit, the way you learned at school.

Each input is a decimal integer with an optional leading `-`, no leading zeros, and zero written as `"0"`. Your answers must follow the same format: no leading zeros, and never `"-0"`.

`BigIntegerStrings.add(_ a: String, _ b: String) -> String`

`BigIntegerStrings.multiply(_ a: String, _ b: String) -> String`

## Examples

| Call | Output |
| --- | --- |
| `add("999", "1")` | `"1000"` |
| `add("-15", "10")` | `"-5"` |
| `add("-15", "15")` | `"0"` |
| `add("1000", "-1")` | `"999"` |
| `multiply("12", "34")` | `"408"` |
| `multiply("-3", "7")` | `"-21"` |
| `multiply("-12345", "0")` | `"0"` |
| `multiply("99999999999999999999", "99999999999999999999")` | `"9999999999999999999800000000000000000001"` |

Adding numbers with different signs is a subtraction: −15 + 10 is −(15 − 10). A negative number times zero is `"0"`, not `"-0"`.

## Constraints

- Each number has at most 2,000 digits.
- Don't convert the whole number to `Int`, `Double` or `Decimal`; most inputs don't fit.

<Hints>
<Hint>
Split each number into a sign and an array of digits stored **least significant first**: `"-907"` becomes negative with `[7, 0, 9]`. Then index `i` is the 10ⁱ place in both numbers, and carries move towards higher indexes.
</Hint>
<Hint>
Multiplying: the digit at place `i` times the digit at place `j` belongs at place `i + j`. Add every product into an array of `m + n` zeros, then sweep once from place 0, keeping `% 10` and carrying `/ 10`. The sign is negative when exactly one input is.
</Hint>
<Hint>
Adding: equal signs add the digit arrays with a carry. Different signs subtract the smaller magnitude from the larger with a borrow, and take the sign of the larger. To find the larger, compare lengths first, then digits from the most significant end. Strip leading zeros at the end, and drop the sign if the result is zero.
</Hint>
</Hints>

## Solutions

<Approach title="Grade-school arithmetic on digit arrays" time="O(m + n) to add, O(m · n) to multiply" space="O(m + n)">

The helpers each do one schoolbook job. `format` is where the output rules live: it trims leading zeros and refuses to write `"-0"`.

```swift
public enum BigIntegerStrings {
    public static func add(_ a: String, _ b: String) -> String {
        let x = parse(a)
        let y = parse(b)
        if x.negative == y.negative {
            return format(negative: x.negative, digits: addMagnitudes(x.digits, y.digits))
        }
        switch compareMagnitudes(x.digits, y.digits) {
        case 0:
            return "0"
        case 1:
            return format(negative: x.negative, digits: subtractMagnitudes(x.digits, y.digits))
        default:
            return format(negative: y.negative, digits: subtractMagnitudes(y.digits, x.digits))
        }
    }

    public static func multiply(_ a: String, _ b: String) -> String {
        let x = parse(a)
        let y = parse(b)
        var product = [Int](repeating: 0, count: x.digits.count + y.digits.count)
        for i in x.digits.indices {
            for j in y.digits.indices {
                product[i + j] += x.digits[i] * y.digits[j]
            }
        }
        var carry = 0
        for place in product.indices {
            let total = product[place] + carry
            product[place] = total % 10
            carry = total / 10
        }
        return format(negative: x.negative != y.negative, digits: product)
    }

    private static func parse(_ text: String) -> (negative: Bool, digits: [Int]) {
        let bytes = Array(text.utf8)
        let negative = bytes.first == UInt8(ascii: "-")
        let digits = bytes.dropFirst(negative ? 1 : 0).reversed().map { Int($0 - UInt8(ascii: "0")) }
        return (negative, digits)
    }

    private static func addMagnitudes(_ x: [Int], _ y: [Int]) -> [Int] {
        var result: [Int] = []
        var carry = 0
        for place in 0..<max(x.count, y.count) {
            let total = (place < x.count ? x[place] : 0) + (place < y.count ? y[place] : 0) + carry
            result.append(total % 10)
            carry = total / 10
        }
        if carry > 0 {
            result.append(carry)
        }
        return result
    }

    // Requires x ≥ y
    private static func subtractMagnitudes(_ x: [Int], _ y: [Int]) -> [Int] {
        var result: [Int] = []
        var borrow = 0
        for place in 0..<x.count {
            var digit = x[place] - borrow - (place < y.count ? y[place] : 0)
            borrow = 0
            if digit < 0 {
                digit += 10
                borrow = 1
            }
            result.append(digit)
        }
        return result
    }

    // 1 if x > y, -1 if x < y, 0 if equal
    private static func compareMagnitudes(_ x: [Int], _ y: [Int]) -> Int {
        if x.count != y.count {
            return x.count > y.count ? 1 : -1
        }
        for place in stride(from: x.count - 1, through: 0, by: -1) where x[place] != y[place] {
            return x[place] > y[place] ? 1 : -1
        }
        return 0
    }

    private static func format(negative: Bool, digits: [Int]) -> String {
        var digits = digits
        while digits.count > 1 && digits.last == 0 {
            digits.removeLast()
        }
        let isZero = digits == [0]
        let body = digits.reversed().map { String($0) }.joined()
        return (negative && !isZero ? "-" : "") + body
    }
}
```

Why delay the carries in `multiply`? Each place collects at most 2,000 products of at most 81, so the totals stay tiny for an `Int`, and one sweep at the end is simpler than carrying inside the double loop. The product of an m-digit and an n-digit number has at most m + n digits, so the array is always big enough.

</Approach>
