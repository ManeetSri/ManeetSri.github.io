Turn a test score into a grade, with a plus for scores near the top of a band.

`GradeBands.grade(for score: Int) -> String`

| Score | Grade |
| --- | --- |
| 90 to 100 | `"A"` |
| 80 to 89 | `"B"` |
| 70 to 79 | `"C"` |
| 60 to 69 | `"D"` |
| 0 to 59 | `"F"` |
| anything else | `"Invalid"` |

In the B, C and D bands only, a score ending in 7, 8 or 9 earns a plus: 87 is `"B+"` and 69 is `"D+"`. There's no `"A+"` and no `"F+"`.

## Examples

| Input | Output |
| --- | --- |
| `95` | `"A"` |
| `84` | `"B"` |
| `88` | `"B+"` |
| `77` | `"C+"` |
| `59` | `"F"` |
| `101` | `"Invalid"` |
| `-3` | `"Invalid"` |

## Constraints

- `score` can be any `Int`, including negative numbers.

<Hints>
<Hint>
A `switch` with range cases, such as `case 80...89:`, picks the band. Don't forget the `default` for invalid scores.
</Hint>
<Hint>
`score % 10` is the last digit of a score from 0 to 100.
</Hint>
<Hint>
Declare `let letter: String` before the switch. Return straight away for `"A"`, `"F"` and `"Invalid"`; for the other bands set `letter`, and add the plus after the switch.
</Hint>
</Hints>

## Solutions

<Approach title="Switch on ranges, then add the plus" time="O(1)" space="O(1)">

The switch handles the bands, and returns early for the three results that never get a plus. The B, C and D cases only choose a letter; one line after the switch decides the plus for all three.

```swift
public enum GradeBands {
    public static func grade(for score: Int) -> String {
        let letter: String
        switch score {
        case 90...100:
            return "A"
        case 80...89:
            letter = "B"
        case 70...79:
            letter = "C"
        case 60...69:
            letter = "D"
        case 0...59:
            return "F"
        default:
            return "Invalid"
        }
        return score % 10 >= 7 ? letter + "+" : letter
    }
}
```

Swift checks that `letter` has a value on every path that reaches the last line. Paths that return early never get there.

</Approach>

<Approach title="Bind and test with where" time="O(1)" space="O(1)">

You can also give the plus grades their own cases, using `where` to test the last digit. It's longer, but every grade is visible in one place.

```swift
public static func grade(for score: Int) -> String {
    switch score {
    case 90...100: return "A"
    case let s where (80...89).contains(s) && s % 10 >= 7: return "B+"
    case 80...89: return "B"
    case let s where (70...79).contains(s) && s % 10 >= 7: return "C+"
    case 70...79: return "C"
    case let s where (60...69).contains(s) && s % 10 >= 7: return "D+"
    case 60...69: return "D"
    case 0...59: return "F"
    default: return "Invalid"
    }
}
```

The plus cases must come before their plain band, because the first matching case wins.

</Approach>
