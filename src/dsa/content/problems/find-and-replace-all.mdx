Write an editor's Replace All. Scan `text` from left to right. Wherever `pattern` starts at the current position, write `replacement` and jump past the whole match; otherwise copy one character and move on by one. So matches never overlap, and the text you write as a replacement is never searched again.

`LeftToRightReplace.replacingAll(_ pattern: String, with replacement: String, in text: String) -> String`

An empty `pattern` matches nothing, so the text comes back unchanged. Write the matching loop yourself rather than calling a library method such as `replacingOccurrences(of:with:)`.

## Examples

| `pattern` | `replacement` | `text` | Output |
| --- | --- | --- | --- |
| `"cat"` | `"dog"` | `"cat scatter"` | `"dog sdogter"` |
| `"aa"` | `"b"` | `"aaaaa"` | `"bba"` |
| `"aba"` | `"X"` | `"abababa"` | `"XbX"` |
| `"o"` | `"oo"` | `"foo"` | `"foooo"` |
| `"xyz"` | `"!"` | `"abc"` | `"abc"` |
| `""` | `"-"` | `"abc"` | `"abc"` |
| `"longer"` | `"?"` | `"short"` | `"short"` |

In the third example `"aba"` occurs at 0, 2 and 4 if overlaps count, but the match at 0 uses up positions 0 to 2, so the scan resumes at 3, copies the `b`, and finds the next match at 4. In the fourth, each `o` becomes `oo` exactly once: the new `o`s are never looked at again.

## Constraints

- `0 ≤ text.count ≤ 50,000`, `0 ≤ pattern.count ≤ 50` and `0 ≤ replacement.count ≤ 50`
- Compare whole characters. Upper and lower case are different.
- Naive matching is fast enough here: at most about 2.5 million character comparisons.

<Hints>
<Hint>
Turn `text` and `pattern` into arrays of characters once, so you can index them in O(1). Then keep a position `start` and loop while `start < text.count`.
</Hint>
<Hint>
At each position, compare the pattern character by character, stopping at the first mismatch, as long as there's room for the whole pattern: `start + pattern.count <= text.count`. On a full match, append the replacement and add `pattern.count` to `start`. Otherwise append `text[start]` and add 1.
</Hint>
<Hint>
Handle the empty pattern before the loop: an empty pattern "matches" everywhere without moving `start` forward, which would never end. Build the answer with `append`, not `result = result + piece`, so each step doesn't copy everything written so far.
</Hint>
</Hints>

## Solutions

<Approach title="Naive matching, jumping past each match" time="O(n · m)" space="O(n + output)">

At each position, compare up to m characters, where m is the pattern's length. A match moves the scan m places on; a mismatch moves it one. In the worst case, a text that nearly matches everywhere, that's about n · m comparisons, which is fine for these sizes.

```swift
public enum LeftToRightReplace {
    public static func replacingAll(_ pattern: String, with replacement: String, in text: String) -> String {
        guard !pattern.isEmpty else { return text }
        let t = Array(text)
        let p = Array(pattern)
        var result = ""
        var start = 0
        while start < t.count {
            var matched = 0
            if start + p.count <= t.count {
                while matched < p.count && t[start + matched] == p[matched] {
                    matched += 1
                }
            }
            if matched == p.count {
                result += replacement
                start += p.count             // jump past the match: no overlaps
            } else {
                result.append(t[start])
                start += 1
            }
        }
        return result
    }
}
```

When fewer than m characters are left, the comparison is skipped, `matched` stays at 0, and the rest of the text is copied one character at a time.

</Approach>

<Approach title="Compare slices" time="O(n · m)" space="O(n + output)">

The same scan, with the comparison done by `elementsEqual(_:)` on a slice of the text. It's shorter, and just as fast in the worst case, because `elementsEqual` also stops at the first mismatch.

```swift
public static func replacingAll(_ pattern: String, with replacement: String, in text: String) -> String {
    guard !pattern.isEmpty else { return text }
    let t = Array(text)
    let p = Array(pattern)
    var result = ""
    var start = 0
    while start < t.count {
        if start + p.count <= t.count && t[start..<start + p.count].elementsEqual(p) {
            result += replacement
            start += p.count
        } else {
            result.append(t[start])
            start += 1
        }
    }
    return result
}
```

</Approach>
