A teammate pasted a failing test's tree into a bug report, but only as the sideways drawing from [Printing trees](/dsa/learn/tree-printing): the right subtree printed first, then the node indented by four spaces per level of depth, then the left subtree. Turn the drawing back into a tree.

`SidewaysTreeReader.tree(fromLines lines: [String]) -> TreeNode?`

Each line is `4 × depth` spaces followed by one node's value, and the lines are in the order the drawing printed them. Return the root of the tree that prints exactly these lines, or `nil` for no lines.

## Examples

The drawing of `[1, 2, 3, 4, 5, nil, 6, nil, nil, 7]` (level order), one string per line:

```text
        6
    3
1
        5
            7
    2
        4
```

| `lines` | Output (level order) | Why |
| --- | --- | --- |
| the seven lines above | `[1, 2, 3, 4, 5, nil, 6, nil, nil, 7]` | 7 is one level deeper than 5 and sits below it, so it's 5's left child |
| `["    20", "10"]` | `[10, nil, 20]` | a child above its parent is a right child |
| `["10", "    -4"]` | `[10, -4]` | a child below its parent is a left child |
| `["42"]` | `[42]` | a single node |
| `[]` | `nil` | the empty tree |

## Constraints

- `0 ≤ lines.count ≤ 100,000`, and the lines always come from a real tree, drawn as described.
- Values can be negative and have any number of digits. The tree can be up to 1,000 levels deep.
- Use `TreeNode` from DSAKit.

<Hints>
<Hint>
The drawing prints right subtree, node, left subtree: inorder, backwards. So reading the lines from the **bottom** up gives the nodes in inorder, each with its depth. Parse each line into a pair: depth is the number of leading spaces divided by 4, and the rest is the value.
</Hint>
<Hint>
In any subtree, the root is the one node with the smallest depth. Everything above it in the drawing is its right subtree, and everything below is its left subtree. That gives a recursive solution, but finding the shallowest line again and again is slow for tall trees.
</Hint>
<Hint>
For one pass, walk the nodes in inorder (bottom line first) and keep a stack: the path from the root down to the node you placed last. For each new node, pop every stacked node that's deeper than it; the last one popped is its left child. If a node is left on the stack, the new node is that node's right child. Then push the new node. The bottom of the stack is the root.
</Hint>
</Hints>

## Solutions

<Approach title="Split at the shallowest line" time="O(n × h)" space="O(n)">

Parse every line, then build recursively: the shallowest line in a range is that subtree's root, the lines above it form its right subtree and the lines below form its left. Each level of recursion scans its range, so a tall tree makes this slow, though it's a fine way to check your understanding.

```swift
public static func tree(fromLines lines: [String]) -> TreeNode? {
    let nodes = lines.map { line -> (depth: Int, value: Int) in
        let spaces = line.prefix { $0 == " " }.count
        return (spaces / 4, Int(line.dropFirst(spaces))!)
    }
    func build(_ range: Range<Int>) -> TreeNode? {
        guard let rootIndex = range.min(by: { nodes[$0].depth < nodes[$1].depth }) else { return nil }
        return TreeNode(nodes[rootIndex].value,
                        left: build((rootIndex + 1)..<range.upperBound),     // below: the left subtree
                        right: build(range.lowerBound..<rootIndex))          // above: the right subtree
    }
    return build(0..<nodes.count)
}
```

</Approach>

<Approach title="One pass with a stack, in inorder" time="O(total characters)" space="O(h)">

Read the lines bottom to top, which is inorder. The stack holds the path from the root to the most recent node, so its depths increase from bottom to top. A new node shallower than some of them must be their ancestor: the shallowest of those becomes its left child. The node left below them on the stack is shallower than the new node and comes earlier in inorder, so the new node belongs in its right subtree, and since it's the next node on that path, it's the right child itself.

```swift
import DSAKit

public enum SidewaysTreeReader {
    public static func tree(fromLines lines: [String]) -> TreeNode? {
        var stack: [(node: TreeNode, depth: Int)] = []
        for line in lines.reversed() {                       // bottom up: inorder
            let spaces = line.prefix { $0 == " " }.count
            let node = TreeNode(Int(line.dropFirst(spaces))!)
            let depth = spaces / 4
            var lastPopped: TreeNode? = nil
            while let top = stack.last, top.depth > depth {
                lastPopped = stack.removeLast().node         // deeper nodes finish here
            }
            node.left = lastPopped                           // the shallowest of them
            stack.last?.node.right = node                    // the next node on its parent's right path
            stack.append((node, depth))
        }
        return stack.first?.node                             // depth 0: the root
    }
}
```

Every node is pushed once and popped at most once, so after parsing the lines the build is O(n), however tall the tree. No recursion is needed either.

</Approach>
