Place `n` queens on an n × n chessboard so that they're at peace: no two share a row, a column or a diagonal. Write two functions. `boards` returns every peaceful placement, each as `n` strings (one per row, top to bottom) with `"Q"` for a queen and `"."` for an empty square. `count` returns how many peaceful placements there are, without building them.

`PeacefulQueens.boards(n: Int) -> [[String]]`

`PeacefulQueens.count(n: Int) -> Int`

The boards may come in any order: the tests sort them before comparing.

## Examples

| `n` | `boards(n:)` | `count(n:)` |
| --- | --- | --- |
| `4` | `[[".Q..", "...Q", "Q...", "..Q."], ["..Q.", "Q...", "...Q", ".Q.."]]` | `2` |
| `1` | `[["Q"]]` | `1` |
| `3` | `[]` | `0` |
| `8` | 92 boards | `92` |

The two boards for n = 4 are mirror images of each other. For n = 2 and n = 3 there's no peaceful placement at all.

## Constraints

- `boards`: `1 ≤ n ≤ 9`. `count`: `1 ≤ n ≤ 12`.
- For n = 12 there are 14,200 placements. Trying all 12! ≈ 479 million orders of columns and checking each at the end is far too slow: check every queen as it's placed.

<Hints>
<Hint>
Every row holds exactly one queen, so decide one column per row, top to bottom. That makes row clashes impossible.
</Hint>
<Hint>
Squares on the same down-right diagonal share `row - column`, and squares on the same down-left diagonal share `row + column`. Keep three Bool arrays, for the columns and both kinds of diagonal, so checking a square is O(1). Add `n - 1` to `row - column` to make it a valid index.
</Hint>
<Hint>
For `count`, let the recursive function return the number of placements below it instead of building boards. For speed, keep the three sets as bitmasks relative to the current row: the free squares are `full & ~(columns | downRight | downLeft)`, and moving down a row shifts the diagonal masks one place each way.
</Hint>
</Hints>

## Solutions

<Approach title="Every order of columns, checked at the end" time="O(n · n!)" space="O(n)">

Generate all n! permutations of the columns (one queen per row and per column), then check the diagonals of each. For n = 12 that's 479 million permutations.

</Approach>

<Approach title="Backtracking with O(1) checks, and bitmasks for counting" time="far fewer than n! nodes; about 856,000 for n = 12" space="O(n)">

Both functions explore the same pruned tree. `boards` keeps three Bool arrays and builds a board at each leaf. `count` keeps the same information as three integers passed down as parameters, so there's nothing to undo, and picks the free squares with the lowest-set-bit trick.

```swift
public enum PeacefulQueens {
    public static func boards(n: Int) -> [[String]] {
        var result: [[String]] = []
        var queenColumn: [Int] = []
        var columnTaken = Array(repeating: false, count: n)
        var downTaken = Array(repeating: false, count: 2 * n - 1)  // index row - column + n - 1
        var upTaken = Array(repeating: false, count: 2 * n - 1)    // index row + column

        func place(_ row: Int) {
            if row == n {
                result.append(queenColumn.map { column in
                    String(repeating: ".", count: column) + "Q" + String(repeating: ".", count: n - column - 1)
                })
                return
            }
            for column in 0..<n where !columnTaken[column] && !downTaken[row - column + n - 1] && !upTaken[row + column] {
                queenColumn.append(column)                          // choose
                columnTaken[column] = true
                downTaken[row - column + n - 1] = true
                upTaken[row + column] = true
                place(row + 1)                                      // explore
                queenColumn.removeLast()                            // unchoose
                columnTaken[column] = false
                downTaken[row - column + n - 1] = false
                upTaken[row + column] = false
            }
        }

        place(0)
        return result
    }

    public static func count(n: Int) -> Int {
        let full = (1 << n) - 1

        func place(_ columns: Int, _ left: Int, _ right: Int) -> Int {
            if columns == full { return 1 }                         // a queen in every column
            var total = 0
            var free = full & ~(columns | left | right)
            while free != 0 {
                let square = free & -free                           // the lowest free square
                free &= free - 1
                total += place(columns | square, ((left | square) << 1) & full, (right | square) >> 1)
            }
            return total
        }

        return place(0, 0, 0)
    }
}
```

The known counts for n = 1 to 12 are 1, 0, 0, 2, 10, 4, 40, 92, 352, 724, 2,680 and 14,200: handy for checking. Only trying columns in the left half of the first row and doubling (with care for the middle column when n is odd) halves the work again.

</Approach>
