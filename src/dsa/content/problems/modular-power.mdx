Return `base` raised to the power `exponent`, modulo `m`: the remainder when that power is divided by m, as a number from 0 to m − 1. The exponent can be as large as 10¹⁸, so multiplying in a loop is far too slow.

`ModularPower.power(_ base: Int, _ exponent: Int, modulo m: Int) -> Int`

The base may be negative: the answer is still the remainder from 0 to m − 1, not Swift's negative `%`. Any number to the power 0 is 1, including 0⁰.

## Examples

| Call | Returns | Why |
| --- | --- | --- |
| `power(2, 10, modulo: 1000)` | `24` | 2¹⁰ = 1,024 |
| `power(3, 200, modulo: 1000)` | `1` | 3²⁰⁰ ends in 001 |
| `power(-2, 3, modulo: 5)` | `2` | (−2)³ = −8, and −8 = −2 × 5 + 2 |
| `power(5, 0, modulo: 7)` | `1` | anything to the power 0 is 1 |
| `power(7, 123, modulo: 1)` | `0` | every remainder modulo 1 is 0 |
| `power(2, 1_000_000_000_000_000_000, modulo: 1_000_000_007)` | `719476260` | far too big to compute directly |

## Constraints

- `-10¹⁸ ≤ base ≤ 10¹⁸`
- `0 ≤ exponent ≤ 10¹⁸`
- `1 ≤ m ≤ 2,000,000,000`

<Hints>
<Hint>
Square your way up: base¹, base², base⁴, base⁸… Write the exponent in binary, and multiply into the result the squares where the exponent has a 1 bit. That's about 60 steps for 10¹⁸.
</Hint>
<Hint>
Reduce the base first with `((base % m) + m) % m`. That handles negative bases, and makes every value smaller than m. Then take `% m` after every multiplication.
</Hint>
<Hint>
With every value below m ≤ 2 × 10⁹, a product of two is below 4 × 10¹⁸, which fits in an `Int`. Start the result at `1 % m`, not 1, so that m = 1 gives 0.
</Hint>
</Hints>

## Solutions

<Approach title="Multiply in a loop" time="O(exponent)" space="O(1)">

Multiply by the base `exponent` times, reducing each time. It's correct and never overflows, but for an exponent of 10¹⁸ it would run for centuries.

```swift
public static func power(_ base: Int, _ exponent: Int, modulo m: Int) -> Int {
    let b = ((base % m) + m) % m
    var result = 1 % m
    for _ in 0..<exponent {
        result = result * b % m
    }
    return result
}
```

</Approach>

<Approach title="Binary exponentiation" time="O(log exponent)" space="O(1)">

Read the exponent's bits from right to left with `% 2` and `/ 2`. `square` holds base¹, base², base⁴… in turn, and is multiplied into `result` whenever the current bit is 1. Every value stays below m, so no multiplication can overflow.

```swift
public enum ModularPower {
    public static func power(_ base: Int, _ exponent: Int, modulo m: Int) -> Int {
        var result = 1 % m
        var square = ((base % m) + m) % m
        var e = exponent
        while e > 0 {
            if e % 2 == 1 {
                result = result * square % m
            }
            square = square * square % m
            e /= 2
        }
        return result
    }
}
```

For `power(3, 13, modulo: 1000)`, 13 is 1101 in binary, so the result collects 3¹, 3⁴ and 3⁸: 3 × 81 × 6,561 = 1,594,323, which leaves 323.

A recursive version works too: compute `half = power(base, exponent / 2, modulo: m)` once, square it, and multiply by the base once more if the exponent is odd. Calling the function twice on `exponent / 2` instead of storing `half` would make it O(exponent) again.

</Approach>
