Reverse a singly linked list and return its new head, twice: once with a loop and once with recursion. Rearrange the existing nodes; don't create new ones.

`ReverseLinkedList.reversed(_ head: ListNode?) -> ListNode?` and `ReverseLinkedList.reversedRecursively(_ head: ListNode?) -> ListNode?`

`ListNode` comes from DSAKit: a class with `value` and `next`. `nil` is the empty list.

## Examples

| Input | Output |
| --- | --- |
| `1 -> 2 -> 3 -> 4 -> 5` | `5 -> 4 -> 3 -> 2 -> 1` |
| `1 -> 2` | `2 -> 1` |
| `7` | `7` |
| empty (`nil`) | empty (`nil`) |

After reversing, the node that held 1 is the last node and must point at `nil`.

## Constraints

- `reversed` gets lists of up to 100,000 nodes.
- `reversedRecursively` gets lists of up to 1,000 nodes. (One stack frame per node: much longer lists can overflow the small stacks that tests run on.)
- Values are any `Int`.

<Hints>
<Hint>
Draw `1 -> 2 -> 3` and turn the arrows round by hand. Notice that the moment you point 2 back at 1, nothing refers to 3 any more, unless you saved it first.
</Hint>
<Hint>
For the loop, keep three references: `previous` (the reversed part, starting at `nil`), `current`, and `next`, saved before `current.next` changes. When `current` becomes `nil`, `previous` is the new head.
</Hint>
<Hint>
For the recursion: a list of zero or one nodes is already reversed. Otherwise, reverse everything after the head. The head's old `next` node is now the last node of that reversed part, so point it back at the head, and point the head at `nil`.
</Hint>
</Hints>

## Solutions

<Approach title="Copy the values into a new list" time="O(n)" space="O(n)">

Walking the list and prepending each value to a new list reverses the order, because each value goes in front of the ones before it. It's easy and correct about values, but it builds n new nodes, and the tests check that the original nodes were reused, so it doesn't pass.

```swift
public static func reversed(_ head: ListNode?) -> ListNode? {
    var result: ListNode? = nil
    var current = head
    while let node = current {
        result = ListNode(node.value, next: result)   // a brand-new node
        current = node.next
    }
    return result
}
```

</Approach>

<Approach title="Three pointers, and recursion" time="O(n)" space="O(1) for the loop, O(n) for the recursion">

The loop moves one node per pass from the front of the remaining list to the front of the reversed part. The recursive version reverses the rest first and then hooks the head on the end; its stack holds one frame per node.

```swift
import DSAKit

public enum ReverseLinkedList {
    public static func reversed(_ head: ListNode?) -> ListNode? {
        var previous: ListNode? = nil
        var current = head
        while let node = current {
            let next = node.next      // remember the rest before the arrow turns
            node.next = previous
            previous = node
            current = next
        }
        return previous
    }

    public static func reversedRecursively(_ head: ListNode?) -> ListNode? {
        guard let head, let second = head.next else {
            return head               // empty or one node: already reversed
        }
        let newHead = reversedRecursively(second)
        second.next = head            // second is now the last node of the reversed rest
        head.next = nil
        return newHead
    }
}
```

Both return the old last node as the new head. In the recursion, `newHead` is found at the deepest call and passed back up unchanged.

</Approach>
