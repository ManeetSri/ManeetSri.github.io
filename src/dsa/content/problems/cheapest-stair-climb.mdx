You stand on the ground in front of a staircase. Stair `i` (counting from 0 at the bottom) charges a toll of `tolls[i]` every time you land on it. Each move climbs anywhere from 1 to `maxStep` stairs. The landing at the top, just above the last stair, is free. Return the least total toll you must pay to reach the landing.

`CheapestStairClimb.minimumToll(tolls: [Int], maxStep: Int) -> Int`

## Examples

| `tolls` | `maxStep` | Output | Why |
| --- | --- | --- | --- |
| `[4, 2, 7, 1, 8, 3]` | `2` | `6` | land on stairs 1, 3 and 5: 2 + 1 + 3 |
| `[4, 2, 7, 1, 8, 3]` | `3` | `3` | land on stairs 1 and 3, then jump three to the landing |
| `[9, 9, 9, 9]` | `4` | `9` | the landing is five moves up, so one stair must be used |
| `[9, 9, 9, 9]` | `5` | `0` | straight from the ground to the landing |
| `[5]` | `1` | `5` | |
| `[]` | `3` | `0` | no stairs: the landing is one step up |

## Constraints

- `0 ≤ tolls.count ≤ 100,000`
- `0 ≤ tolls[i] ≤ 10,000`
- `1 ≤ maxStep ≤ 50`
- The tests climb 100,000 stairs. Recursion that deep would overflow a test's stack, so fill a table with a loop.

<Hints>
<Hint>
Number the positions: the ground is 0, stair i is position i + 1, and the landing is position `tolls.count + 1`, with a toll of 0. Now define `cost[p]` = the least you can have paid when you're standing on position p, including p's own toll.
</Hint>
<Hint>
The last move onto position p came from one of the `maxStep` positions just below it (those that exist). So `cost[p]` = p's toll + the smallest `cost` among them. The base case is `cost[0] = 0`.
</Hint>
<Hint>
Fill `cost` upwards, from position 1 to the landing, and return the landing's entry. That's O(n × maxStep), about 5 million steps at most.
</Hint>
</Hints>

## Solutions

<Approach title="Bottom-up table" time="O(n · maxStep)" space="O(n)">

The recipe from [The DP recipe](/dsa/learn/dp-recipe): the state is `cost[p]`, the transition takes the cheapest of the positions one to `maxStep` below, the base case is the free ground, the order is upwards, and the answer is the landing.

```swift
public enum CheapestStairClimb {
    public static func minimumToll(tolls: [Int], maxStep: Int) -> Int {
        let landing = tolls.count + 1
        var cost = Array(repeating: 0, count: landing + 1)
        for position in stride(from: 1, through: landing, by: 1) {
            var cheapestBefore = Int.max
            for step in 1...maxStep where step <= position {
                cheapestBefore = min(cheapestBefore, cost[position - step])
            }
            let toll = position == landing ? 0 : tolls[position - 1]
            cost[position] = cheapestBefore + toll
        }
        return cost[landing]
    }
}
```

`cheapestBefore` is never left at `Int.max`, because `step = 1` always fits. With `maxStep = 2` this is the classic min-cost stairs problem from [Climbing stairs and min-cost stairs](/dsa/learn/dp-stairs): starting from the ground with a move of 1 or 2 is the same as starting on stair 0 or stair 1.

</Approach>

<Approach title="Sliding window minimum" time="O(n)" space="O(n)">

Each entry needs the minimum of the last `maxStep` entries, a sliding window that moves up one position at a time. The monotonic deque from [Monotonic deque: sliding window maximum](/dsa/learn/queue-monotonic-deque), flipped to keep the minimum, answers each window in amortised O(1). It's worth knowing for much larger step limits; for `maxStep ≤ 50` the simple table is plenty.

```swift
public static func minimumToll(tolls: [Int], maxStep: Int) -> Int {
    let landing = tolls.count + 1
    var cost = Array(repeating: 0, count: landing + 1)
    var window = [0]                 // positions whose costs increase from front to back
    var head = 0
    for position in 1...landing {
        if window[head] < position - maxStep {
            head += 1                // the front is out of reach
        }
        let toll = position == landing ? 0 : tolls[position - 1]
        cost[position] = cost[window[head]] + toll
        while window.count > head && cost[window[window.count - 1]] >= cost[position] {
            window.removeLast()
        }
        window.append(position)
    }
    return cost[landing]
}
```

</Approach>
