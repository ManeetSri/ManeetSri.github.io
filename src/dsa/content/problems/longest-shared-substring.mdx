A plagiarism checker wants the longest passage two texts share exactly: a run of consecutive characters that appears in both. Return that run. If several runs are equally long, return the one that starts earliest in `first`. If the texts share no character at all, return `""`.

`LongestSharedSubstring.longest(_ first: String, _ second: String) -> String`

## Examples

| `first` | `second` | Output |
| --- | --- | --- |
| `"photograph"` | `"tomography"` | `"ograph"` |
| `"ABAB"` | `"BABA"` | `"ABA"` |
| `"swift"` | `"shift"` | `"ift"` |
| `"xyab"` | `"abxy"` | `"xy"` |
| `"abc"` | `"xyz"` | `""` |

In the second example, `"ABA"` and `"BAB"` are both shared and both 3 long; `"ABA"` starts at index 0 of `first`, `"BAB"` at index 1. In the fourth, `"xy"` starts earlier in `first` than `"ab"`.

## Constraints

- Each string has 0 to 2,000 characters. Compare `Character`s.
- The tests include strings of 2,000 characters, so trying every substring of one string and searching the other is too slow.

<Hints>
<Hint>
Unlike a subsequence, a substring can't skip characters. Define the state as the longest shared run that **ends exactly** at `first[i - 1]` and `second[j - 1]`.
</Hint>
<Hint>
If those two characters are equal, the run ending at the previous pair grows by one; if they differ, the run is 0. The answer can end anywhere, so track the largest cell, and where it ends, as you fill.
</Hint>
<Hint>
Visit rows in order of `first`'s index and replace the best only when a run is **strictly** longer. Then the first maximal run you find is the one that ends, and starts, earliest in `first`.
</Hint>
</Hints>

## Solutions

<Approach title="Every substring" time="O(n² · m)" space="O(n)">

For each length from longest down, try each start in `first` from the left, and check whether `second` contains that piece. The first hit is the answer, with the right tie rule. It's the test's reference, and far too slow for 2,000 characters.

</Approach>

<Approach title="Runs ending here, one row" time="O(n · m)" space="O(m)">

Each cell reads only its upper-left neighbour, so keep one row and sweep j from right to left: `run[j - 1]` still holds the previous row's value when you read it.

```swift
public enum LongestSharedSubstring {
    public static func longest(_ first: String, _ second: String) -> String {
        let a = Array(first), b = Array(second)
        var run = Array(repeating: 0, count: b.count + 1)
        var bestLength = 0
        var bestEnd = 0                                   // the best substring is a[bestEnd - bestLength..<bestEnd]
        for i in 0..<a.count {
            for j in stride(from: b.count, through: 1, by: -1) {
                if a[i] == b[j - 1] {
                    run[j] = run[j - 1] + 1
                    if run[j] > bestLength {
                        bestLength = run[j]
                        bestEnd = i + 1
                    }
                } else {
                    run[j] = 0
                }
            }
        }
        return String(a[(bestEnd - bestLength)..<bestEnd])
    }
}
```

Within one row, several runs can reach the same new best; any of them ends at the same place in `first`, so the answer's text is the same.

</Approach>
