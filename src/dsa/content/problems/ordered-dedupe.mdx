Given an array of whole numbers, return a new array with every repeated value removed. Keep the **first** appearance of each value, and keep those values in the order they first appeared.

`OrderedDedupe.dedupe(_ numbers: [Int]) -> [Int]`

## Examples

| Input | Output |
| --- | --- |
| `[3, 1, 3, 2, 1]` | `[3, 1, 2]` |
| `[5, 5, 5, 5]` | `[5]` |
| `[9, 2, 9, 7, 2]` | `[9, 2, 7]` |
| `[]` | `[]` |

Note that the result is **not** sorted: `[9, 2, 7]`, not `[2, 7, 9]`.

## Constraints

- `0 ≤ numbers.count ≤ 100,000`
- `-10⁹ ≤ numbers[i] ≤ 10⁹`

<Hints>
<Hint>
Walk through `numbers` once, appending each value to a result array, unless you've already kept it.
</Hint>
<Hint>
Checking "have I already kept it?" with `result.contains(number)` is correct but searches the whole result every time. What collection answers that question in O(1)?
</Hint>
<Hint>
Keep a `Set<Int>` of the values you've kept. `seen.insert(number).inserted` is `true` only the first time a value is inserted, so it can decide whether to append.
</Hint>
</Hints>

## Solutions

<Approach title="Brute force: search the result each time" time="O(n²)" space="O(n)">

For each number, check whether the result already contains it. `contains` on an array looks at every element, so with many distinct values this does about n²/2 comparisons.

```swift
public static func dedupe(_ numbers: [Int]) -> [Int] {
    var result: [Int] = []
    for number in numbers where !result.contains(number) {
        result.append(number)
    }
    return result
}
```

</Approach>

<Approach title="A set of seen values" time="O(n)" space="O(n)">

A set answers "have I kept this?" in O(1) on average, while the array keeps the order the set can't. Two collections, each doing the job it's good at.

```swift
public enum OrderedDedupe {
    public static func dedupe(_ numbers: [Int]) -> [Int] {
        var seen = Set<Int>()
        var result: [Int] = []
        for number in numbers where seen.insert(number).inserted {
            result.append(number)
        }
        return result
    }
}
```

`Array(Set(numbers))` would also remove duplicates in one line, but it loses the order, so it fails this problem.

</Approach>
