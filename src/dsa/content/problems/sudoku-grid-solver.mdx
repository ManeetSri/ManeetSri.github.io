Solve a Sudoku. The puzzle is 9 strings of 9 characters, one string per row: `"1"` to `"9"` for a given digit and `"."` for an empty cell. Fill every empty cell so that each row, each column and each of the nine 3 × 3 boxes contains every digit from 1 to 9 exactly once, and return the solved grid in the same format.

`SudokuGridSolver.solve(_ rows: [String]) -> [String]`

Every puzzle in the tests has exactly one solution, and the given digits never break the rules.

## Examples

| `rows` | Output |
| --- | --- |
| `["..53.....", "8......2.", ".7..1.5..", "4....53..", ".1..7...6", "..32...8.", ".6.5....9", "..4....3.", ".....97.."]` | `["145327698", "839654127", "672918543", "496185372", "218473956", "753296481", "367542819", "984761235", "521839764"]` |
| the solved grid above, with one digit replaced by `"."` | the solved grid |
| a grid with no empty cells | the same grid |

## Constraints

- `rows.count == 9` and `rows[i].count == 9`.
- The tests include some of the best-known hard puzzles, and a 17-clue puzzle designed to defeat solvers that fill cells in reading order: trying digits 1 to 9 cell by cell from the top left takes over 69 million placements on it. Choose which cell to fill next wisely.

<Hints>
<Hint>
Convert the puzzle to a 9 × 9 array of `Int`, with 0 for empty. Keep a record of which digits each row, column and box already holds, so checking whether a digit fits is O(1). Box `row / 3 * 3 + column / 3` holds cell (row, column).
</Hint>
<Hint>
Backtracking: pick an empty cell, try each digit that fits, recurse, and undo if the recursion fails. Return as soon as a full grid is reached, without undoing anything.
</Hint>
<Hint>
Don't take the empty cells in reading order. At every step, fill the empty cell with the **fewest** candidates: a cell with none means this branch is already dead, and a cell with one is a forced move. With a bitmask per row, column and box, a cell's candidates are `~(row | column | box) & 0b11_1111_1110`, and `nonzeroBitCount` counts them.
</Hint>
</Hints>

## Solutions

<Approach title="Reading order, digits 1 to 9" time="exponential; 69 million placements on the hardest test" space="O(81)">

Walk the cells from the top left, try each digit that doesn't clash with its row, column or box, and back up when a cell has none left. It solves gentle puzzles quickly, but a puzzle whose first rows need large digits makes it try nearly everything before reaching them.

</Approach>

<Approach title="Bitmasks and the most constrained cell" time="exponential in theory; about 11,000 placements on the hardest test" space="O(81)">

The empty cells live in an array. At each level, scan the cells still to fill, move the one with the fewest candidates to the end of that range, try its candidates one bit at a time, and recurse on the shorter range. Dead ends and forced moves are found at once, near the top of the tree.

```swift
public enum SudokuGridSolver {
    public static func solve(_ rows: [String]) -> [String] {
        var grid = rows.map { row in row.map { $0.wholeNumberValue ?? 0 } }
        var rowDigits = Array(repeating: 0, count: 9)
        var columnDigits = Array(repeating: 0, count: 9)
        var boxDigits = Array(repeating: 0, count: 9)
        var empties: [(row: Int, column: Int)] = []
        for row in 0..<9 {
            for column in 0..<9 {
                let digit = grid[row][column]
                if digit == 0 {
                    empties.append((row, column))
                } else {
                    rowDigits[row] |= 1 << digit
                    columnDigits[column] |= 1 << digit
                    boxDigits[row / 3 * 3 + column / 3] |= 1 << digit
                }
            }
        }

        // empties[0..<remaining] are still to fill
        func fill(_ remaining: Int) -> Bool {
            if remaining == 0 { return true }
            var best = 0
            var bestCandidates = 0
            var bestCount = 10
            for index in 0..<remaining {
                let (row, column) = empties[index]
                let candidates = ~(rowDigits[row] | columnDigits[column] | boxDigits[row / 3 * 3 + column / 3]) & 0b11_1111_1110
                let count = candidates.nonzeroBitCount
                if count < bestCount {
                    (best, bestCandidates, bestCount) = (index, candidates, count)
                    if count <= 1 { break }                         // dead or forced: no need to look further
                }
            }
            if bestCount == 0 { return false }
            empties.swapAt(best, remaining - 1)                     // the chosen cell moves out of the way
            let (row, column) = empties[remaining - 1]
            let box = row / 3 * 3 + column / 3
            var candidates = bestCandidates
            while candidates != 0 {
                let bit = candidates & -candidates
                candidates &= candidates - 1
                rowDigits[row] |= bit                               // choose
                columnDigits[column] |= bit
                boxDigits[box] |= bit
                grid[row][column] = bit.trailingZeroBitCount
                if fill(remaining - 1) { return true }              // explore
                rowDigits[row] &= ~bit                              // unchoose
                columnDigits[column] &= ~bit
                boxDigits[box] &= ~bit
            }
            grid[row][column] = 0
            return false
        }

        _ = fill(empties.count)
        return grid.map { row in String(row.map { Character(String($0)) }) }
    }
}
```

Swapping the chosen cell to the end of the range is safe even without swapping it back: deeper levels only rearrange the cells before it, and the set of cells still to fill is the same either way. The recursion is at most 81 levels deep.

</Approach>
