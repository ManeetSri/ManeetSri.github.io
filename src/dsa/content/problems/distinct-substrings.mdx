Count the different non-empty substrings of `text`. A substring is a run of consecutive letters, and two substrings that spell the same letters count once, wherever they appear.

`DistinctSubstringCount.count(in text: String) -> Int`

## Examples

| `text` | Output |
| --- | --- |
| `"aba"` | `5`: a, b, ab, ba, aba |
| `"abab"` | `7`: a, b, ab, ba, aba, bab, abab |
| `"aaaa"` | `4`: a, aa, aaa, aaaa |
| `"abc"` | `6` |
| `"a"` | `1` |
| `""` | `0` |

## Constraints

- `text` holds 0 to 1,000 lowercase letters, a to z.
- The tests include random texts of 1,000 letters.

<Hints>
<Hint>
A text of length n has n(n + 1)/2 substrings counted with repeats. Putting them all in a `Set<String>` works, but builds hundreds of thousands of strings averaging hundreds of letters each.
</Hint>
<Hint>
Every substring is the start of some suffix: "ba" in "abab" is the start of the suffix "bab". So insert every suffix of the text into a trie.
</Hint>
<Hint>
In that trie (a suffix trie), each node below the root spells one substring, and no substring has two nodes. So the answer is the number of nodes created.
</Hint>
</Hints>

## Solutions

<Approach title="A set of every substring" time="O(n³)" space="O(n³)">

Correct, and fine for short texts, but each of the n(n + 1)/2 substrings is built and hashed letter by letter.

```swift
public enum DistinctSubstringCount {
    public static func count(in text: String) -> Int {
        let letters = Array(text)
        var seen = Set<String>()
        for start in letters.indices {
            for end in start..<letters.count {
                seen.insert(String(letters[start...end]))
            }
        }
        return seen.count
    }
}
```

</Approach>

<Approach title="A suffix trie" time="O(n²)" space="O(n²)">

Insert the suffixes one by one. Walking a suffix down the trie costs one step per letter, and each step that creates a node has found a substring never seen before. The trie lives in one flat array of 26 slots per node, allocated up front for the worst case of n(n + 1)/2 nodes.

```swift
public enum DistinctSubstringCount {
    public static func count(in text: String) -> Int {
        let letters = Array(text.utf8)
        let n = letters.count
        var children = [Int32](repeating: 0, count: 26 * (n * (n + 1) / 2 + 1))
        var nodes = 0
        for start in 0..<n {
            var node = 0                                 // the root
            for index in start..<n {
                let slot = 26 * node + Int(letters[index] - 97)
                if children[slot] == 0 {
                    nodes += 1                           // a substring never seen before
                    children[slot] = Int32(nodes)
                }
                node = Int(children[slot])
            }
        }
        return nodes
    }
}
```

`Int32` halves the memory compared with `Int`: for 1,000 letters the array has about 13 million slots, 52 MB. That quadratic growth is the suffix trie's weakness. Suffix arrays (n log n) and suffix automata (linear) answer the same question for texts of millions of letters; they come later in the course.

</Approach>
