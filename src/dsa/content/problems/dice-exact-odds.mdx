Roll `dice` fair dice, each with faces numbered 1 to `faces`. Answer two questions **exactly**, as fractions in lowest terms, with no floating point anywhere.

`DiceExactOdds.sumChance(of target: Int, dice: Int, faces: Int) -> Fraction` returns the probability that the faces add up to `target`.

`DiceExactOdds.expectedHighest(dice: Int, faces: Int) -> Fraction` returns the expected value of the **largest** face showing.

A `Fraction` has a `numerator` and a `denominator`. Return it reduced, so the two share no common factor, with a positive denominator. Zero is 0/1.

## Examples

| Call | Output | Why |
| --- | --- | --- |
| `sumChance(of: 7, dice: 2, faces: 6)` | 1/6 | 6 of the 36 outcomes add up to 7 |
| `sumChance(of: 10, dice: 3, faces: 6)` | 1/8 | 27 of 216 |
| `sumChance(of: 1, dice: 2, faces: 6)` | 0/1 | two dice show at least 2 |
| `expectedHighest(dice: 1, faces: 6)` | 7/2 | one die averages 3.5 |
| `expectedHighest(dice: 2, faces: 6)` | 161/36 | about 4.47 |
| `expectedHighest(dice: 4, faces: 2)` | 31/16 | the highest is 1 only if all four show 1 |

## Constraints

- `1 ≤ dice ≤ 10` and `2 ≤ faces ≤ 20`, so there are at most 20¹⁰ ≈ 10¹³ outcomes: far too many to list one by one, but few enough that the count of outcomes fits in an `Int`.
- `target` can be any `Int`.

<Hints>
<Hint>
Count instead of listing. Keep an array `ways` where `ways[s]` is the number of outcomes of the dice rolled so far that add up to s. Before any dice, `ways[0] = 1`. Adding one more die, each old total s spreads its count to s + 1, s + 2, …, s + faces. After all the dice, the probability is `ways[target]` over faces^dice.
</Hint>
<Hint>
For the highest face: the highest is at most m exactly when every die shows at most m, which happens in mᵈ of the fᵈ outcomes. So the number of outcomes whose highest face is **exactly** m is mᵈ − (m − 1)ᵈ. The expected value is the sum of m × (mᵈ − (m − 1)ᵈ) over m, divided by fᵈ.
</Hint>
<Hint>
Reduce at the end with Euclid's algorithm: divide the numerator and denominator by their gcd. The gcd of 0 and d is d, so 0/d becomes 0/1 automatically.
</Hint>
</Hints>

## Solutions

<Approach title="List every outcome" time="O(faces^dice)" space="O(dice)">

Nested loops, or a recursion that picks one die at a time, can visit every outcome and count the ones you want, just as the lesson enumerates two and four dice. It's a perfect check for small cases, but 10 dice with 20 faces have about 10¹³ outcomes.

</Approach>

<Approach title="Count totals one die at a time" time="O(dice² × faces²)" space="O(dice × faces)">

The counting table never stores outcomes, only how many outcomes reach each total, and the largest total is dice × faces = 200. Adding a die multiplies the number of outcomes by `faces` without making the table any longer than 200 entries.

The expected highest face uses the "at most m" trick, a cousin of the complement rule: counting outcomes where everything is at most m is a single power, and subtracting neighbouring powers gives "exactly m".

```swift
public enum DiceExactOdds {
    public struct Fraction: Equatable, CustomStringConvertible {
        public var numerator: Int
        public var denominator: Int

        public init(numerator: Int, denominator: Int) {
            self.numerator = numerator
            self.denominator = denominator
        }

        public var description: String { "\(numerator)/\(denominator)" }
    }

    static func gcd(_ a: Int, _ b: Int) -> Int {
        b == 0 ? a : gcd(b, a % b)
    }

    static func reduced(_ numerator: Int, _ denominator: Int) -> Fraction {
        let g = gcd(numerator, denominator)
        return Fraction(numerator: numerator / g, denominator: denominator / g)
    }

    static func power(_ base: Int, _ exponent: Int) -> Int {
        var result = 1
        for _ in 0..<exponent {
            result *= base
        }
        return result
    }

    public static func sumChance(of target: Int, dice: Int, faces: Int) -> Fraction {
        var ways = [1]
        for _ in 0..<dice {
            var next = Array(repeating: 0, count: ways.count + faces)
            for (total, count) in ways.enumerated() where count > 0 {
                for face in 1...faces {
                    next[total + face] += count
                }
            }
            ways = next
        }
        let favourable = (0..<ways.count).contains(target) ? ways[target] : 0
        return reduced(favourable, power(faces, dice))
    }

    public static func expectedHighest(dice: Int, faces: Int) -> Fraction {
        var weighted = 0
        for m in 1...faces {
            weighted += m * (power(m, dice) - power(m - 1, dice))
        }
        return reduced(weighted, power(faces, dice))
    }
}
```

Every count stays exact: the largest numerator is below 20 × 20¹⁰ ≈ 2 × 10¹⁴. If you converted to `Double` along the way, 161/36 would come back as 4.472222… and you'd lose the exact answer.

</Approach>
