You're given strings made only of the characters `0` and `1`, and a budget of `zeros` 0s and `ones` 1s. Choose as many strings as you can, each at most once, so that together they contain at most `zeros` 0s and at most `ones` 1s. Return how many you can choose.

`ZeroOneStringBudget.mostStrings(_ strings: [String], zeros: Int, ones: Int) -> Int`

## Examples

| `strings` | `zeros` | `ones` | Output |
| --- | --- | --- | --- |
| `["01", "1100", "0", "111", "00"]` | `3` | `3` | `3` |
| `["01", "1100", "0", "111", "00"]` | `4` | `2` | `3` |
| `["11", "11", "0"]` | `0` | `3` | `1` |
| `["000"]` | `2` | `5` | `0` |

In the first example, `"0"`, `"111"` and `"00"` use exactly 3 of each. Taking the shortest strings first (`"0"`, `"01"`) leaves too little for anything else. In the second, `"01"`, `"0"` and `"00"` use 4 zeros and 1 one. In the third, no 0s are allowed and the two `"11"`s together need 4 ones.

## Constraints

- `1 ≤ strings.count ≤ 600`
- `1 ≤ strings[i].count ≤ 100`, and every character is `0` or `1`
- `0 ≤ zeros ≤ 100` and `0 ≤ ones ≤ 100`

<Hints>
<Hint>
Each string is a knapsack item with **two** weights, its number of 0s and its number of 1s, and a value of 1.
</Hint>
<Hint>
Let `best[z][o]` be the most strings that fit in `z` zeros and `o` ones. A string costing `a` zeros and `b` ones gives `best[z][o] = max(best[z][o], best[z - a][o - b] + 1)`.
</Hint>
<Hint>
Each string is used at most once, so run **both** loops downward. A string like `"11"` costs no zeros, so its update reads from its own row: if the ones loop went up, it could be chosen twice.
</Hint>
</Hints>

## Solutions

<Approach title="Try every subset" time="O(2ⁿ · n)" space="O(n)">

Count each string's 0s and 1s, then try every subset with a bitmask and keep the largest that fits both budgets. Fine for a dozen strings, impossible for 600.

</Approach>

<Approach title="Knapsack with two capacities" time="O(L + n · zeros · ones)" space="O(zeros · ones)">

Count each string's two costs once, skip strings that can never fit, and update the 2D table with both loops downward. Here `L` is the total length of the strings.

```swift
public enum ZeroOneStringBudget {
    public static func mostStrings(_ strings: [String], zeros: Int, ones: Int) -> Int {
        var best = Array(repeating: Array(repeating: 0, count: ones + 1), count: zeros + 1)
        for string in strings {
            var a = 0
            var b = 0
            for character in string.utf8 {
                if character == UInt8(ascii: "0") { a += 1 } else { b += 1 }
            }
            if a > zeros || b > ones { continue }
            for z in stride(from: zeros, through: a, by: -1) {
                for o in stride(from: ones, through: b, by: -1) {
                    best[z][o] = max(best[z][o], best[z - a][o - b] + 1)
                }
            }
        }
        return best[zeros][ones]
    }
}
```

Reading the string's `utf8` bytes is a fast way to count characters that are all ASCII; `string.filter { $0 == "0" }.count` works too. With 600 strings and budgets of 100, the table is updated about six million times.

</Approach>
