A row of fence panels is painted in colours named by the letters `A` to `Z`. You may repaint at most `k` panels, choosing any colour for each. Return the length of the longest run of neighbouring panels you can make all the same colour.

`RepaintLongestRun.longest(_ text: String, changes k: Int) -> Int`

## Examples

| `text` | `k` | Output |
| --- | --- | --- |
| `"BAAAB"` | `1` | `4` |
| `"QQXQQYQQ"` | `1` | `5` |
| `"QQXQQYQQ"` | `2` | `8` |
| `"ABCDE"` | `1` | `2` |
| `"ZZZZ"` | `0` | `4` |

In the second example, repainting the `X` gives `"QQQQQ"` followed by `YQQ`, a run of 5. With two repaints, the `X` and the `Y` both become `Q`, and the whole fence matches.

## Constraints

- `0 ≤ text.count ≤ 100,000`
- `text` uses only the uppercase letters `A` to `Z`.
- `0 ≤ k ≤ text.count`

<Hints>
<Hint>
For one window, the cheapest plan is to keep its most common letter and repaint everything else. That costs `length - maxCount`, where `maxCount` is the count of its most common letter.
</Hint>
<Hint>
So a window works when `length - maxCount ≤ k`. Keep 26 counts for the window, grow it on the right, and shrink from the left when it stops working.
</Hint>
<Hint>
You don't need to recompute `maxCount` when the window shrinks. If the window is too costly, slide it (move `left` once) instead of shrinking it further. Its length then never drops below the best you've found, and only a bigger `maxCount` can make it grow.
</Hint>
</Hints>

## Solutions

<Approach title="One target letter at a time" time="O(26 · n)" space="O(1)">

Fix the colour you'll end with, say `A`. Now the question is: what's the longest window with at most `k` letters that aren't `A`? That's a plain sliding window with one counter. Try all 26 letters and keep the best.

```swift
public static func longest(_ text: String, changes k: Int) -> Int {
    let bytes = Array(text.utf8)
    var best = 0
    for target in UInt8(ascii: "A")...UInt8(ascii: "Z") {
        var left = 0
        var others = 0                       // letters in the window that need repainting
        for right in 0..<bytes.count {
            if bytes[right] != target { others += 1 }
            while others > k {
                if bytes[left] != target { others -= 1 }
                left += 1
            }
            best = max(best, right - left + 1)
        }
    }
    return best
}
```

</Approach>

<Approach title="One pass with maxCount" time="O(n)" space="O(1)">

Keep 26 counts and the largest count seen so far. If the window would need more than `k` repaints, slide it right by one instead of growing: the window never gets shorter, so its length is always the best valid length found so far.

```swift
public enum RepaintLongestRun {
    public static func longest(_ text: String, changes k: Int) -> Int {
        let bytes = Array(text.utf8)
        let a = UInt8(ascii: "A")
        var counts = [Int](repeating: 0, count: 26)
        var maxCount = 0
        var left = 0
        var best = 0
        for right in 0..<bytes.count {
            let slot = Int(bytes[right] - a)
            counts[slot] += 1
            maxCount = max(maxCount, counts[slot])
            if (right - left + 1) - maxCount > k {
                counts[Int(bytes[left] - a)] -= 1
                left += 1
            }
            best = max(best, right - left + 1)
        }
        return best
    }
}
```

`maxCount` can be stale after a slide: the window's real most-common count may be lower. That's harmless. A stale value only stops the window from shrinking below a length that was already valid, and the window can only grow when some letter's count beats `maxCount`, at which point the value is accurate again.

</Approach>
