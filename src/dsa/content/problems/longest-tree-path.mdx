Return the number of edges on the longest path between any two nodes of a binary tree. A path never uses a node twice, and it doesn't have to pass through the root.

`LongestTreePath.diameter(of root: TreeNode?) -> Int`

`TreeNode` comes from DSAKit. Trees in the examples are written in level order, with `nil` for a missing child, the way `TreeNode.make` takes them.

## Examples

| `root` | Output |
| --- | --- |
| `[1, 2, 3, 4, 5]` | `3` |
| `[1, 2, nil, 3, 4, 5, nil, nil, 6, 7, nil, nil, 8]` | `6` |
| `[4, 2]` | `1` |
| `[9]` | `0` |
| `[]` (the empty tree, `nil`) | `0` |

In the first tree, 4 → 2 → 1 → 3 has 3 edges. The second tree looks like this:

```text
        1
       /
      2
     / \
    3   4
   /     \
  5       6
 /         \
7           8
```

Its longest path, 7 → 5 → 3 → 2 → 4 → 6 → 8, bends at 2 and never visits the root.

## Constraints

- The tree has at most 150,000 nodes.
- It's at most about 400 levels deep, so a recursive solution is fine.
- Values don't affect the answer.

<Hints>
<Hint>
Every path has one highest node, where it bends. If that node's left subtree has height a and its right subtree has height b, counting levels, the longest path bending there has a + b edges.
</Hint>
<Hint>
Working out both heights from scratch at every node is O(n²) on a long chain. Each height can be computed once, in a single postorder pass, because a node's height comes from its children's.
</Hint>
<Hint>
Write a nested `height` function. Before it returns `1 + max(left, right)`, let it update a variable outside it with `left + right`: return a height, update a global best.
</Hint>
</Hints>

## Solutions

<Approach title="Heights at every node" time="O(n²) worst case" space="O(h)">

Try every node as the bend, measuring both subtrees' heights each time. It's correct and a useful check on small trees, but each node's height is measured again by every ancestor: about n²/2 steps on a chain of n nodes, and O(n log n) even on a balanced tree.

```swift
static func height(_ node: TreeNode?) -> Int {
    guard let node else { return 0 }
    return 1 + max(height(node.left), height(node.right))
}

public static func diameter(of root: TreeNode?) -> Int {
    guard let root else { return 0 }
    let bendingHere = height(root.left) + height(root.right)
    return max(bendingHere, diameter(of: root.left), diameter(of: root.right))
}
```

</Approach>

<Approach title="One pass: return a height, record the best bend" time="O(n)" space="O(h)">

While computing each node's height, the recursion already holds both children's heights, which is all the bend formula needs. So each call returns its height to its parent and records `left + right` in `best`.

```swift
import DSAKit

public enum LongestTreePath {
    public static func diameter(of root: TreeNode?) -> Int {
        var best = 0
        func height(_ node: TreeNode?) -> Int {
            guard let node else { return 0 }
            let left = height(node.left)
            let right = height(node.right)
            best = max(best, left + right)       // the longest path bending at node, in edges
            return 1 + max(left, right)
        }
        _ = height(root)
        return best
    }
}
```

A call returns the height, not the diameter, because a parent can only extend a path that goes straight down one side.

</Approach>
