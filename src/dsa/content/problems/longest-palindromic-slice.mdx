Return the longest substring of `text` that reads the same forwards and backwards. If several are equally long, return the one that starts first. An empty string gives `""`.

`LongestPalindromicSlice.longest(in text: String) -> String`

## Examples

| `text` | Output |
| --- | --- |
| `"abracadabra"` | `"aca"` |
| `"noonday"` | `"noon"` |
| `"banana"` | `"anana"` |
| `"12321abc"` | `"12321"` |
| `"ab"` | `"a"` |
| `""` | `""` |

In `"abracadabra"`, both `"aca"` and `"ada"` have length 3 and nothing longer is a palindrome, so the earlier one, `"aca"`, wins. In `"ab"`, every single character is a palindrome of length 1.

## Constraints

- `0 ≤ text.count ≤ 2,000`
- `text` uses only lowercase letters `a` to `z` and digits `0` to `9`.

<Hints>
<Hint>
Checking every substring is O(n²) substrings times O(n) per check: O(n³), about a billion steps for 2,000 characters. Turn it round: instead of checking candidates, grow palindromes.
</Hint>
<Hint>
Every palindrome has a middle. Start at a middle and step outwards while the characters on both sides match. Odd-length palindromes are centred on a character, and even-length ones on the gap between two characters, so there are 2n − 1 middles to try.
</Hint>
<Hint>
Write a helper `expand(low, high)` that moves `low` left and `high` right while `chars[low] == chars[high]`. When it stops, the palindrome is `chars[low + 1 ..< high]`. Call it with `(i, i)` and `(i, i + 1)` for every `i`, and replace the best only when a palindrome is strictly longer.
</Hint>
</Hints>

## Solutions

<Approach title="Check every substring" time="O(n³)" space="O(n)">

Try every start and end, check each piece with two pointers, and keep the longest. Simple and correct, and the right thing to test faster versions against.

```swift
public static func longest(in text: String) -> String {
    let chars = Array(text)
    var bestStart = 0
    var bestLength = 0
    for start in chars.indices {
        for end in start..<chars.count where end - start + 1 > bestLength {
            var low = start
            var high = end
            while low < high && chars[low] == chars[high] {
                low += 1
                high -= 1
            }
            if low >= high {
                bestStart = start
                bestLength = end - start + 1
            }
        }
    }
    return String(chars[bestStart..<bestStart + bestLength])
}
```

</Approach>

<Approach title="Expand around every centre" time="O(n²)" space="O(1)">

Each centre grows its palindrome outwards until the ends differ. The worst case is a string of one repeated letter, where every centre expands a long way: about n²/2 steps in all, which is a few million for 2,000 characters.

```swift
public enum LongestPalindromicSlice {
    public static func longest(in text: String) -> String {
        let chars = Array(text.utf8)
        var bestStart = 0
        var bestLength = 0

        func expand(_ low: Int, _ high: Int) {
            var low = low
            var high = high
            while low >= 0 && high < chars.count && chars[low] == chars[high] {
                low -= 1
                high += 1
            }
            let length = high - low - 1
            if length > bestLength {
                bestLength = length
                bestStart = low + 1
            }
        }

        for centre in 0..<chars.count {
            expand(centre, centre)
            expand(centre, centre + 1)
        }
        return String(decoding: chars[bestStart..<bestStart + bestLength], as: UTF8.self)
    }
}
```

The input is ASCII, so bytes are safe and fast. Centres are tried left to right, so the first of several equally long palindromes is found first and never replaced. An O(n) method, Manacher's algorithm, exists; you'll meet it in M63.

</Approach>
