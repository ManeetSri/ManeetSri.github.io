Two in-place rewirings of a binary tree:

- `FlattenAndLinkLevels.flatten(_ root: TreeNode?)`: turn the tree into a chain along `right` links in **preorder**. Every `left` becomes `nil`, and each node's `right` is the node that follows it in preorder. Reuse the nodes; don't create any.
- `FlattenAndLinkLevels.linkLevels(_ root: LevelNode?)`: set every node's `next` to the node directly to its right on the same level, or `nil` for the last node of each level. Leave `left` and `right` alone.

`TreeNode` comes from DSAKit. `LevelNode` is nested inside `FlattenAndLinkLevels`, already written for you: like `TreeNode`, with `value`, `left` and `right`, plus `var next: LevelNode?`, which starts as `nil`. Trees are written in level order, the way `TreeNode.make` takes them.

## Examples

**Flatten.** The tree `[1, 2, 6, 3, 4, nil, 7, nil, nil, 5]` has preorder 1, 2, 3, 4, 5, 6, 7:

```text
        1
       / \
      2   6            1 → 2 → 3 → 4 → 5 → 6 → 7
     / \   \     →     (all right links; every left is nil)
    3   4   7
       /
      5
```

In level order, the result is `[1, nil, 2, nil, 3, nil, 4, nil, 5, nil, 6, nil, 7]`.

**Link levels.** For `[1, 2, 3, 4, nil, nil, 5]`:

```text
        1 → nil
       / \
      2 → 3 → nil
     /     \
    4  →  5 → nil
```

4's `next` is 5, a cousin, jumping over the places where 2's right child and 3's left child would be.

| Call | Result |
| --- | --- |
| `flatten([1, 2])` | `[1, nil, 2]` |
| `flatten([4, 3, nil, 2, nil, 1])` | `[4, nil, 3, nil, 2, nil, 1]` |
| `flatten(nil)` | nothing happens |
| `linkLevels` on `[1, 2, 3, 4, 5, 6, 7]` | levels 1; 2 → 3; 4 → 5 → 6 → 7 |
| `linkLevels(nil)` | nothing happens |

## Constraints

- Trees have at most 150,000 nodes, of any shape, and are at most 500 levels deep.
- Aim for O(n) time. O(1) extra space is possible for both.

<Hints>
<Hint>
For `flatten`, a simple first version collects the nodes in preorder into an array, then links each one to the next. For O(1) extra space: at a node with a left child, the left subtree's preorder ends at its rightmost node (keep going right from the left child).
</Hint>
<Hint>
Hang the node's right subtree off that rightmost node, move the left subtree over to the right, set `left` to `nil`, and continue down the `right` link. Save the old right subtree before you overwrite `node.right`.
</Hint>
<Hint>
For `linkLevels`, a level-order walk with a queue works. For O(1) extra space: a level that's already linked is a linked list. Walk it along `next`, and append each child you meet behind a dummy node; afterwards `dummy.next` is the first node of the level below.
</Hint>
</Hints>

## Solutions

<Approach title="Collect, then relink; and a queue per level" time="O(n)" space="O(n)">

Both are direct: an array of nodes in preorder for `flatten`, and level-by-level lists for `linkLevels`.

```swift
public static func flatten(_ root: TreeNode?) {
    var order: [TreeNode] = []
    var pending: [TreeNode] = root.map { [$0] } ?? []
    while let node = pending.popLast() {             // preorder with a stack
        order.append(node)
        if let right = node.right { pending.append(right) }
        if let left = node.left { pending.append(left) }
    }
    for (index, node) in order.enumerated() {
        node.left = nil
        node.right = index + 1 < order.count ? order[index + 1] : nil
    }
}

public static func linkLevels(_ root: LevelNode?) {
    var level: [LevelNode] = root.map { [$0] } ?? []
    while !level.isEmpty {
        for index in 0..<(level.count - 1) {
            level[index].next = level[index + 1]
        }
        level = level.flatMap { [$0.left, $0.right].compactMap { $0 } }
    }
}
```

</Approach>

<Approach title="Rewire as you go, with O(1) extra space" time="O(n)" space="O(1)">

The flatten loop's inner search for the rightmost node walks each node at most once in the whole run, because each node is on the right edge of exactly one left subtree. The level linking uses the level above, already linked, to reach the level below in order.

```swift
import DSAKit

public enum FlattenAndLinkLevels {
    /// A binary tree node with one more link: `next`, the node to its right on the same level.
    public final class LevelNode {
        public var value: Int
        public var left: LevelNode?
        public var right: LevelNode?
        public var next: LevelNode?

        public init(_ value: Int, left: LevelNode? = nil, right: LevelNode? = nil) {
            self.value = value
            self.left = left
            self.right = right
        }
    }

    public static func flatten(_ root: TreeNode?) {
        var current = root
        while let node = current {
            if let left = node.left {
                var last = left                      // the end of the left subtree's preorder
                while let next = last.right {
                    last = next
                }
                last.right = node.right
                node.right = left
                node.left = nil
            }
            current = node.right
        }
    }

    public static func linkLevels(_ root: LevelNode?) {
        var levelStart = root
        while let start = levelStart {
            let dummy = LevelNode(0)                 // the level below is linked up behind this
            var tail = dummy
            var current: LevelNode? = start
            while let node = current {
                if let left = node.left {
                    tail.next = left
                    tail = left
                }
                if let right = node.right {
                    tail.next = right
                    tail = right
                }
                current = node.next
            }
            levelStart = dummy.next
        }
    }
}
```

</Approach>
