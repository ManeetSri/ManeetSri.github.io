Mounting points along a straight pipeline sit at given distances from its start, in metres, all different and in no particular order. Install `sensors` sensors at distinct mounting points so that the closest pair of sensors is as far apart as possible. Return that largest possible minimum distance.

`SensorSpacing.widestMinimumGap(points: [Int], sensors: Int) -> Int`

## Examples

| `points` | `sensors` | Output |
| --- | --- | --- |
| `[10, 1, 5, 22, 13]` | `3` | `9` |
| `[10, 1, 5, 22, 13]` | `2` | `21` |
| `[10, 1, 5, 22, 13]` | `5` | `3` |
| `[4, 2, 8, 6]` | `3` | `2` |
| `[0, 1000000000]` | `2` | `1000000000` |

In the first example, sensors at 1, 10 and 22 are 9 and 12 apart, so the closest pair is 9 apart. No placement keeps every pair 10 apart. With all five points used, the answer is the smallest distance between neighbours, 13 − 10 = 3.

## Constraints

- `2 ≤ sensors ≤ points.count ≤ 100,000`
- `0 ≤ points[i] ≤ 10⁹`, all different

<Hints>
<Hint>
Turn it into a yes/no question: can the sensors be placed so that every pair is at least d apart? If a distance d works, every smaller distance works too, with the same placement.
</Hint>
<Hint>
To check a distance d, sort the points first. Put a sensor at the first point, then walk right and put each next sensor at the first point at least d past the previous one. If that places them all, d works.
</Hint>
<Hint>
You want the largest d that works: search for the first d that fails, then subtract 1. A gap of 1 always works. The sensors make `sensors - 1` gaps that fit inside the span from the first point to the last, so any d above span / (sensors − 1) fails.
</Hint>
</Hints>

## Solutions

<Approach title="Try every distance" time="O(n log n + n · D)" space="O(n)">

Sort, then try d = 1, 2, 3, … until the greedy check fails, and return the last distance that worked. D is the answer itself, which can be as large as a billion, so this only suits tiny ranges.

```swift
public static func widestMinimumGap(points: [Int], sensors: Int) -> Int {
    let sorted = points.sorted()
    var gap = 1
    while canPlace(sensors, in: sorted, gap: gap + 1) {
        gap += 1
    }
    return gap
}
```

`canPlace` is the greedy check from the next approach.

</Approach>

<Approach title="Sort, then binary search on the gap" time="O(n log n + n log R)" space="O(n)">

The greedy placement is the best possible for a fixed gap: its sensors are never to the right of the matching sensors in any valid placement, so it fits at least as many. The predicate "the sensors fit with gap d" is true, …, true, false, …, so search the gaps for the first failure and step back one. The pigeonhole bound gives a gap that's sure to fail, which makes a tidy exclusive top for the half-open search.

```swift
public enum SensorSpacing {
    public static func widestMinimumGap(points: [Int], sensors: Int) -> Int {
        let sorted = points.sorted()
        let span = sorted[sorted.count - 1] - sorted[0]
        var low = 1                                      // a gap of 1 always works
        var high = span / (sensors - 1) + 1              // sensors - 1 gaps fit in the span
        while low < high {
            let mid = low + (high - low) / 2
            if canPlace(sensors, in: sorted, gap: mid) {
                low = mid + 1                            // mid works: the first failure is later
            } else {
                high = mid
            }
        }
        return low - 1                                   // the last gap that works
    }

    /// True if `count` sensors fit in the sorted points with every pair at least `gap` apart.
    private static func canPlace(_ count: Int, in sorted: [Int], gap: Int) -> Bool {
        var placed = 1
        var last = sorted[0]
        for point in sorted.dropFirst() where point - last >= gap {
            placed += 1
            last = point
            if placed == count { return true }
        }
        return placed >= count
    }
}
```

The sort costs O(n log n). R is the span, at most 10⁹, so the search makes at most about 30 checks of O(n) each. This is the aggressive cows problem, also known as magnetic force between balls.

</Approach>
