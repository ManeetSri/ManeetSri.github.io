A hashtag has lost its spaces. Given the text and a dictionary, first decide whether the text can be cut into pieces that are all dictionary words (each word can be used any number of times). Then list every way to do it, each as the words joined by single spaces.

`DictionarySentenceSplitter.canSplit(_ text: String, words: [String]) -> Bool`

`DictionarySentenceSplitter.allSentences(_ text: String, words: [String]) -> [String]`

## Examples

| `text` | `words` | `canSplit` | `allSentences` |
| --- | --- | --- | --- |
| `"nowhere"` | `["no", "now", "where", "here", "w", "he", "re"]` | `true` | `"no w he re"`, `"no w here"`, `"no where"`, `"now he re"`, `"now here"` |
| `"icecreamcone"` | `["ice", "cream", "icecream", "cone", "con"]` | `true` | `"ice cream cone"`, `"icecream cone"` |
| `"icecreamcones"` | `["ice", "cream", "icecream", "cone"]` | `false` | none |
| `"aaa"` | `["a", "aa"]` | `true` | `"a a a"`, `"a aa"`, `"aa a"` |

`allSentences` may return the sentences in any order, but each one exactly once, even if `words` lists a word twice.

## Constraints

- `text` has 1 to 1,000 lowercase letters for `canSplit`, and `words` holds up to 300 non-empty words of up to 20 letters.
- For `allSentences`, the tests keep the answer to at most 11,000 sentences, but the text can still be long: 500 a's and a b, with no sentence at all, must come back empty quickly.
- The number of sentences can grow exponentially: 20 a's with the words `"a"` and `"aa"` have 10,946.

<Hints>
<Hint>
For `canSplit`, let `ok[i]` say whether the first i characters can be split. `ok[0]` is true. `ok[end]` is true if some `ok[start]` is true and `text[start..<end]` is a word. Only starts within the longest word's length of `end` can work.
</Hint>
<Hint>
For `allSentences`, write a recursive function "every sentence for `text[start...]`": try each word that starts at `start`, and put it in front of every sentence for the rest. At the end of the text, return `[""]`, one sentence with no more words.
</Hint>
<Hint>
Memoise that function by `start`. Then a position with no way to finish is explored once and returns `[]` immediately afterwards, which is what makes the long text with no answer fast.
</Hint>
</Hints>

## Solutions

<Approach title="Plain backtracking" time="exponential" space="O(n)">

Try every word at every position. It's what the tests compare against on short texts, but on 500 a's and a b it tries every way of cutting the a's before failing.

</Approach>

<Approach title="DP for the yes/no, memoised backtracking for the sentences" time="O(n · L²) + output" space="O(n) + output">

Words have at most L characters. `canSplit` checks O(n · L) pieces, each built and hashed in O(L). `allSentences` computes each start's sentences once; beyond that, its time is the size of the output, which no algorithm can beat.

```swift
public enum DictionarySentenceSplitter {
    public static func canSplit(_ text: String, words: [String]) -> Bool {
        let characters = Array(text)
        let dictionary = Set(words)
        let longest = words.map(\.count).max() ?? 0
        var ok = Array(repeating: false, count: characters.count + 1)
        ok[0] = true
        for end in stride(from: 1, through: characters.count, by: 1) {
            for start in stride(from: end - 1, through: max(0, end - longest), by: -1)
            where ok[start] && dictionary.contains(String(characters[start..<end])) {
                ok[end] = true
                break
            }
        }
        return ok[characters.count]
    }

    public static func allSentences(_ text: String, words: [String]) -> [String] {
        let characters = Array(text)
        let dictionary = Set(words)
        let longest = words.map(\.count).max() ?? 0
        var memo: [Int: [String]] = [:]

        func sentences(from start: Int) -> [String] {
            if start == characters.count {
                return [""]
            }
            if let known = memo[start] {
                return known
            }
            var result: [String] = []
            for end in stride(from: start + 1, through: min(characters.count, start + longest), by: 1) {
                let word = String(characters[start..<end])
                guard dictionary.contains(word) else { continue }
                for rest in sentences(from: end) {
                    result.append(rest.isEmpty ? word : word + " " + rest)
                }
            }
            memo[start] = result
            return result
        }

        return sentences(from: 0)
    }
}
```

The `Set` takes care of duplicate words. A trie of the words works for both parts too: walk it forwards from each start and every end-of-word flag you pass is a word ending there.

</Approach>
