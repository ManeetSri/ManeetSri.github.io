For each day in a list of daily temperatures, work out how many days you'd have to wait for a strictly warmer day.

`WarmerDayWait.daysToWait(_ temperatures: [Int]) -> [Int]`

Return an array of the same length. Entry `d` is the number of days from day `d` to the first later day with a higher temperature, or 0 if no later day is warmer.

## Examples

| `temperatures` | Result |
| --- | --- |
| `[15, 17, 16, 14, 18, 13]` | `[1, 3, 2, 1, 0, 0]` |
| `[10, 20, 30]` | `[1, 1, 0]` |
| `[30, 20, 10]` | `[0, 0, 0]` |
| `[21, 21, 22]` | `[2, 1, 0]` |
| `[]` | `[]` |

In the fourth example, the second 21 isn't warmer than the first, so the first day waits until the 22.

## Constraints

- `0 ≤ temperatures.count ≤ 100,000`
- `-100 ≤ temperatures[i] ≤ 100,000`
- Aim for O(n). One test has 100,000 days that keep getting colder until the last, where looking ahead from every day takes about five billion steps.

Day indexes. Keep a stack of days still waiting for a warmer one. Their temperatures never rise from bottom to top.
</Hint>
<Hint>
When a new day arrives, pop every waiting day that's strictly colder and record `today - thatDay` for it. Then push today. Days left waiting at the end keep 0.
</Hint>

## Solutions

<Approach title="Look ahead from every day" time="O(n²)" space="O(1) extra">

For each day, scan forward until a warmer day appears. Simple and correct, and a useful brute force for testing, but a falling sequence makes every scan run to the end.

```swift
public static func daysToWait(_ temperatures: [Int]) -> [Int] {
    var waits = Array(repeating: 0, count: temperatures.count)
    for day in temperatures.indices {
        for later in (day + 1)..<temperatures.count where temperatures[later] > temperatures[day] {
            waits[day] = later - day
            break
        }
    }
    return waits
}
```

</Approach>

<Approach title="A monotonic stack of waiting days" time="O(n)" space="O(n)">

Each day waits on the stack until a warmer day pops it. A day that's colder than everything waiting can't answer anyone, so the waiting temperatures never increase from bottom to top, and popping stops at the first waiting day that's at least as warm.

```swift
public enum WarmerDayWait {
    public static func daysToWait(_ temperatures: [Int]) -> [Int] {
        var waits = Array(repeating: 0, count: temperatures.count)
        var waiting: [Int] = []
        for (day, temperature) in temperatures.enumerated() {
            while let colder = waiting.last, temperatures[colder] < temperature {
                waits[colder] = day - colder
                waiting.removeLast()
            }
            waiting.append(day)
        }
        return waits
    }
}
```

The comparison is strict, `<`, because an equally warm day doesn't count. Each day is pushed once and popped at most once, so the total work is O(n).

</Approach>
