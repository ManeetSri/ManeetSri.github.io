Decide whether a list's values read the same from back to front as from front to back. Use O(1) extra space if you can, and whatever you do, leave the list exactly as you found it.

`PalindromeLinkedList.isPalindrome(_ head: ListNode?) -> Bool`

## Examples

| List | Output |
| --- | --- |
| `1 -> 2 -> 3 -> 2 -> 1` | `true` |
| `4 -> 9 -> 9 -> 4` | `true` |
| `1 -> 2 -> 2 -> 3` | `false` |
| `5` | `true` |
| empty | `true` |

## Constraints

- Up to 100,001 nodes.
- Values are any `Int`.
- After the call, every node must have the same `next` as before. The tests check.

<Hints>
<Hint>
A correct first version: copy the values into an array and compare it with `values.reversed()`. That's O(n) extra space.
</Hint>
<Hint>
For O(1) space, find the end of the first half with fast and slow pointers (the first middle), reverse the part after it, and compare the two halves node by node. Stop when the reversed second half runs out: the first half may be one node longer.
</Hint>
<Hint>
Before returning, reverse the second half again and reattach it to the end of the first half. Record the answer in a variable and break out of the comparison loop rather than returning from inside it, so the restore always runs.
</Hint>
</Hints>

## Solutions

<Approach title="Copy the values out" time="O(n)" space="O(n)">

Simple and clearly correct, and it never touches the list.

```swift
public static func isPalindrome(_ head: ListNode?) -> Bool {
    var values: [Int] = []
    var current = head
    while let node = current {
        values.append(node.value)
        current = node.next
    }
    return values == values.reversed()
}
```

</Approach>

<Approach title="Reverse the second half, then put it back" time="O(n)" space="O(1)">

With the second half reversed, both halves can be walked forwards together. The middle node of an odd-length list stays in the first half and is never compared, which is fine: it matches itself.

```swift
import DSAKit

public enum PalindromeLinkedList {
    private static func reverse(_ head: ListNode?) -> ListNode? {
        var previous: ListNode? = nil
        var current = head
        while let node = current {
            let next = node.next
            node.next = previous
            previous = node
            current = next
        }
        return previous
    }

    public static func isPalindrome(_ head: ListNode?) -> Bool {
        guard let head else { return true }

        // slow stops on the last node of the first half (the middle node, for an odd length)
        var slow = head
        var fast = head
        while let second = fast.next, let third = second.next {
            slow = slow.next!
            fast = third
        }

        let secondHalf = reverse(slow.next)
        var left: ListNode? = head
        var right = secondHalf
        var matches = true
        while let r = right, let l = left {
            if l.value != r.value {
                matches = false
                break
            }
            left = l.next
            right = r.next
        }

        slow.next = reverse(secondHalf)   // put the list back as it was
        return matches
    }
}
```

Reversing `secondHalf` again returns the original first node of the second half, which goes straight back after `slow`.

</Approach>
