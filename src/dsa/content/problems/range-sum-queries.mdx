Build a table that answers "what's the sum of the values from index `start` through index `end`?" for a fixed array, as many times as it's asked. Preparing the table may take one pass over the array; after that, every query must be O(1).

`RangeSumQueries.Table`, with `init(_ values: [Int])` and `sum(from start: Int, through end: Int) -> Int`

Both ends of a query are **inclusive**: `sum(from: 2, through: 5)` adds `values[2]`, `values[3]`, `values[4]` and `values[5]`.

## Examples

For `Table([3, 1, 4, 1, 5, 9, 2])`:

| Query | Output | Why |
| --- | --- | --- |
| `sum(from: 2, through: 5)` | `19` | 4 + 1 + 5 + 9 |
| `sum(from: 0, through: 6)` | `25` | the whole array |
| `sum(from: 4, through: 4)` | `5` | a single value |
| `sum(from: 0, through: 0)` | `3` | a range that starts at index 0 |

For `Table([-4, 7, 0, -3, -3, 10])`, `sum(from: 3, through: 4)` is `-6`.

## Constraints

- `0 ≤ values.count ≤ 100,000`, and `-10⁹ ≤ values[i] ≤ 10⁹`
- Every query has `0 ≤ start ≤ end < values.count`.
- Up to 100,000 queries on one table. Building should be O(n) and each query O(1).

<Hints>
<Hint>
Adding up the range inside `sum` is correct but O(n) per query, so 100,000 queries over 100,000 values could take 10¹⁰ steps. Do the adding once, in `init`, and store the result in a private property.
</Hint>
<Hint>
Store a prefix array that starts with `0`, where `prefix[i]` is the sum of the first `i` values. It has one more element than `values`.
</Hint>
<Hint>
`prefix[end + 1]` covers `values[0...end]` and `prefix[start]` covers `values[0..<start]`. Subtract them. Check a query that starts at 0 and one that ends at the last index.
</Hint>
</Hints>

## Solutions

<Approach title="Add up the range on every query" time="O(n) per query" space="O(n)">

Keep a copy of the values and loop over the range each time. It's a useful baseline for testing, but too slow for many queries.

```swift
public struct Table {
    private let values: [Int]

    public init(_ values: [Int]) {
        self.values = values
    }

    public func sum(from start: Int, through end: Int) -> Int {
        values[start...end].reduce(0, +)
    }
}
```

</Approach>

<Approach title="Prefix sums with a leading zero" time="O(n) to build, O(1) per query" space="O(n)">

Build the running totals once. The leading `0` is the sum of no values, so a query starting at index 0 uses the same formula as every other query. The shared beginning of `prefix[end + 1]` and `prefix[start]` cancels, leaving exactly `values[start...end]`.

```swift
public enum RangeSumQueries {
    public struct Table {
        private let prefix: [Int]

        public init(_ values: [Int]) {
            var prefix = [0]
            prefix.reserveCapacity(values.count + 1)
            for value in values {
                prefix.append(prefix[prefix.count - 1] + value)
            }
            self.prefix = prefix
        }

        public func sum(from start: Int, through end: Int) -> Int {
            prefix[end + 1] - prefix[start]
        }
    }
}
```

The prefix values can reach 10¹⁴, far more than any single value, but that fits comfortably in Swift's 64-bit `Int`.

</Approach>
