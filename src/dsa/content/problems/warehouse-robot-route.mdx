A warehouse robot drives across a grid of floor tiles, moving up, down, left or right. `floor[r][c]` is the cost of driving onto that tile, from 1 (smooth concrete) to 9 (a crowded aisle), or `0` for a shelf the robot can't enter. Return the cheapest total cost from `start` to `goal` (each `[row, column]`), or `-1` if the goal can't be reached. The robot is already on the start tile, so its cost isn't paid; the goal's cost is.

`WarehouseRobotRoute.cheapestRoute(_ floor: [[Int]], start: [Int], goal: [Int]) -> Int`

## Examples

| `floor` | `start` | `goal` | Output |
| --- | --- | --- | --- |
| `[[1, 1, 1, 1], [1, 0, 0, 1], [1, 9, 1, 1]]` | `[0, 0]` | `[2, 2]` | `6` |
| `[[1, 6, 1], [1, 6, 1], [1, 1, 1]]` | `[0, 0]` | `[0, 2]` | `6` |
| `[[9, 4]]` | `[0, 1]` | `[0, 0]` | `9` |
| `[[1, 0, 1]]` | `[0, 0]` | `[0, 2]` | `-1` |
| `[[3]]` | `[0, 0]` | `[0, 0]` | `0` |

In the first example, going down the left side means driving onto the 9, for 12 in total. Going round the top and down the right side costs 1 per tile for 6 tiles. In the second, crossing the 6 directly costs 7, while the long way round the bottom costs 6.

## Constraints

- `1 ≤ rows, columns ≤ 400`
- `0 ≤ floor[r][c] ≤ 9`
- `start` and `goal` are inside the grid and never on a shelf.
- The tests use 400 × 400 floors.

<Hints>
<Hint>
Every move has a non-negative cost (the tile you drive onto), so Dijkstra over the tiles gives the right answer. Can you make it explore fewer tiles when the goal is in a known direction?
</Hint>
<Hint>
A\* orders the heap by f = g + h, where h estimates the remaining cost. It must never overestimate. The Manhattan distance to the goal counts the fewest moves still needed, but each move costs at least the cheapest tile on the floor, not necessarily 1.
</Hint>
<Hint>
Use h = Manhattan distance × the smallest non-zero tile cost. Store (f, h, row, column) in the heap, break ties on f by the smaller h, and stop when the goal is popped.
</Hint>
</Hints>

## Solutions

<Approach title="Dijkstra" time="O(R · C · log(R · C))" space="O(R · C)">

Treat each open tile as a vertex with up to four edges, weighted by the destination tile's cost. Run Dijkstra from `start` and stop when `goal` is popped.

</Approach>

<Approach title="A* with a scaled Manhattan heuristic" time="O(R · C · log(R · C)) worst case" space="O(R · C)">

The heuristic changes by at most one tile's minimum cost per move, and every move costs at least that, so it's consistent: each tile's cost is final the first time it's popped, exactly as in Dijkstra. When the route is fairly direct, A\* pops far fewer tiles.

```swift
import DSAKit

public enum WarehouseRobotRoute {
    public static func cheapestRoute(_ floor: [[Int]], start: [Int], goal: [Int]) -> Int {
        let rows = floor.count, cols = floor[0].count
        let cheapestCell = floor.joined().filter { $0 > 0 }.min() ?? 1
        func estimate(_ row: Int, _ col: Int) -> Int {
            (abs(row - goal[0]) + abs(col - goal[1])) * cheapestCell
        }
        var best = Array(repeating: Array(repeating: Int.max, count: cols), count: rows)
        best[start[0]][start[1]] = 0
        var open = Heap<(f: Int, h: Int, row: Int, col: Int)>(areInIncreasingOrder: { ($0.f, $0.h) < ($1.f, $1.h) })
        let startEstimate = estimate(start[0], start[1])
        open.insert((startEstimate, startEstimate, start[0], start[1]))
        let steps = [(0, 1), (1, 0), (0, -1), (-1, 0)]
        while let (f, h, row, col) = open.pop() {
            let g = f - h
            if g > best[row][col] { continue }          // stale entry
            if row == goal[0] && col == goal[1] { return g }
            for (dr, dc) in steps {
                let r = row + dr, c = col + dc
                guard r >= 0, r < rows, c >= 0, c < cols, floor[r][c] > 0 else { continue }
                let candidate = g + floor[r][c]
                if candidate < best[r][c] {
                    best[r][c] = candidate
                    let guess = estimate(r, c)
                    open.insert((candidate + guess, guess, r, c))
                }
            }
        }
        return -1
    }
}
```

`g` isn't stored: it's recovered as `f - h` when an entry is popped. If every tile cost 9, the heuristic would be 9 × Manhattan, which is exact on an open floor and makes A\* walk almost straight to the goal.

</Approach>
