Every value in the array appears exactly twice, except for two different values that appear once each. Return those two values, smaller first.

`TwoUnpairedNumbers.find(in numbers: [Int]) -> [Int]`

The result always has two elements. Aim for O(n) time and O(1) extra space.

## Examples

| Input | Output |
| --- | --- |
| `[4, 7, 2, 4, 9, 2]` | `[7, 9]` |
| `[1, 5]` | `[1, 5]` |
| `[-6, 3, 8, 3, 8, 0]` | `[-6, 0]` |
| `[10, 2, 10, 2, 6, 5]` | `[5, 6]` |

## Constraints

- `2 ≤ numbers.count ≤ 100,000`
- `-10⁹ ≤ numbers[i] ≤ 10⁹`
- Exactly two values appear once; every other value appears exactly twice.

<Hints>
<Hint>
XOR everything together. The pairs cancel, leaving `a ^ b`, where `a` and `b` are the two values you want. It isn't 0, because `a` and `b` are different.
</Hint>
<Hint>
Every set bit of `a ^ b` marks a position where `a` and `b` differ: one has a 1 there and the other a 0. Pick any one of those bits. `x & -x` gives you the lowest.
</Hint>
<Hint>
Split all the numbers into two groups: those with that bit set and those without. `a` and `b` land in different groups, and both copies of every paired value land in the same group. So XORing each group gives one of the answers.
</Hint>
</Hints>

## Solutions

<Approach title="Count with a dictionary" time="O(n)" space="O(n)">

Count how often each value appears, then keep the two that appear once. It's direct and correct, but the dictionary can hold up to n / 2 entries.

```swift
public static func find(in numbers: [Int]) -> [Int] {
    var counts: [Int: Int] = [:]
    for number in numbers {
        counts[number, default: 0] += 1
    }
    return counts.filter { $0.value == 1 }.map(\.key).sorted()
}
```

Sorting the two keys puts the smaller first, and makes the answer independent of the dictionary's unpredictable order.

</Approach>

<Approach title="XOR, then split by one differing bit" time="O(n)" space="O(1)">

XORing everything leaves `both = a ^ b`. Its lowest set bit, `both & -both`, is a position where `a` and `b` differ. XOR together only the numbers with that bit set: the pairs among them cancel, and exactly one of `a` and `b` is among them, so that's what remains. The other answer is `both ^ first`, since XORing `a` back out of `a ^ b` leaves `b`.

```swift
public enum TwoUnpairedNumbers {
    public static func find(in numbers: [Int]) -> [Int] {
        let both = numbers.reduce(0, ^)
        let bit = both & -both
        var first = 0
        for number in numbers where number & bit != 0 {
            first ^= number
        }
        let second = both ^ first
        return [min(first, second), max(first, second)]
    }
}
```

Two passes over the array and three variables. `-both` can't overflow here: `both` would have to be `Int.min`, and two values within ±10⁹ can't differ in the sign bit alone.

</Approach>
