A sign maker has printed a long banner of letters and wants to cut it into pieces that each read the same forwards and backwards. Return the fewest cuts needed. A single letter is always a palindrome, so it can always be done.

`PalindromeBannerCuts.fewestCuts(_ banner: String) -> Int`

## Examples

| `banner` | Output | Pieces |
| --- | --- | --- |
| `"noonabbad"` | `2` | noon · abba · d |
| `"racecarannakayak"` | `2` | racecar · anna · kayak |
| `"abaab"` | `1` | a · baab |
| `"abcd"` | `3` | a · b · c · d |
| `"level"` | `0` | already a palindrome |
| `""` | `0` | |

## Constraints

- `0 ≤ banner.count ≤ 1,000`
- The banner holds only lowercase letters `a` to `z`.
- The tests use 1,000-letter banners, so checking each candidate piece letter by letter inside the main loop (O(n³)) is too slow.

<Hints>
<Hint>
First build a table `isPal[i][j]` saying whether letters i through j form a palindrome. A piece is a palindrome when its two end letters match and the piece inside them is a palindrome.
</Hint>
<Hint>
`isPal[i][j]` depends on `isPal[i + 1][j - 1]`, so fill rows from the bottom up. Then think about the **last** piece of the first j + 1 letters: it's some palindrome from i to j.
</Hint>
<Hint>
Let `cuts[j]` be the fewest cuts for letters 0 through j. It's 0 if that whole prefix is a palindrome; otherwise it's the minimum over i with `isPal[i][j]` of `cuts[i - 1] + 1`. Convert the banner with `Array(banner)` so you can index letters by position.
</Hint>
</Hints>

## Solutions

<Approach title="Interval DP over every piece" time="O(n³)" space="O(n²)">

`cuts[i][j]`, the fewest cuts for letters i through j, is 0 if the piece is a palindrome and otherwise the best of every split point. It works, with a palindrome table, but it does a factor of n more work than needed.

</Approach>

<Approach title="Palindrome table, then cuts by prefix" time="O(n²)" space="O(n²)">

Every split of a prefix ends with one palindromic piece and leaves a shorter prefix, so one index is enough for the cuts.

```swift
public enum PalindromeBannerCuts {
    public static func fewestCuts(_ banner: String) -> Int {
        let s = Array(banner)
        let n = s.count
        guard n > 1 else { return 0 }
        var isPal = Array(repeating: Array(repeating: false, count: n), count: n)
        for i in stride(from: n - 1, through: 0, by: -1) {
            for j in i..<n {
                isPal[i][j] = s[i] == s[j] && (j - i < 2 || isPal[i + 1][j - 1])
            }
        }
        var cuts = Array(repeating: 0, count: n)
        for j in 0..<n where !isPal[0][j] {
            var fewest = j                                  // a cut before every letter but the first
            for i in 1...j where isPal[i][j] {
                fewest = min(fewest, cuts[i - 1] + 1)
            }
            cuts[j] = fewest
        }
        return cuts[n - 1]
    }
}
```

</Approach>

<Approach title="Expand around centres" time="O(n²)" space="O(n)">

Skip the table: visit every centre from left to right and expand outwards while the letters match. Each palindrome `s[l...r]` found offers `cuts[r] = cuts[l - 1] + 1`, or 0 when it starts at the beginning. Any palindrome ending at `l - 1` has its centre further left, so `cuts[l - 1]` is already final when it's used.

</Approach>
