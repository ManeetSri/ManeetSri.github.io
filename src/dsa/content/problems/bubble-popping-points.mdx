A puzzle game shows a row of bubbles, each with a number. Popping a bubble scores its number times the numbers of the bubbles currently on its left and right. If there's no bubble on one side, that side counts as 1. The popped bubble disappears, so its two neighbours become next to each other. You pop every bubble, in any order. Return the highest total score possible.

`BubblePoppingPoints.maxPoints(_ bubbles: [Int]) -> Int`

## Examples

| `bubbles` | Output | A best order |
| --- | --- | --- |
| `[4, 2, 6]` | `78` | 2 (4·2·6 = 48), then 4 (1·4·6 = 24), then 6 (6) |
| `[7, 1, 8, 2]` | `189` | 1 (56), then 8 (112), then 2 (14), then 7 (7) |
| `[2, 3]` | `9` | 2 (1·2·3 = 6), then 3 (3) |
| `[9]` | `9` | |
| `[0, 0, 0]` | `0` | |
| `[]` | `0` | |

## Constraints

- `0 ≤ bubbles.count ≤ 200`
- `0 ≤ bubbles[i] ≤ 100`
- The tests use 150 bubbles with random numbers, and 200 with all numbers equal, so trying every order is impossible.

<Hints>
<Hint>
Choosing which bubble to pop **first** doesn't split the row nicely: once it's gone, the bubbles on its two sides become neighbours and affect each other's scores. Try choosing the bubble popped **last** instead.
</Hint>
<Hint>
Add a bubble worth 1 at each end; they're never popped and act like the missing neighbours. If k is the last bubble popped strictly between positions `left` and `right`, then when it pops its neighbours are exactly `left` and `right`, and until then it keeps the two sides apart.
</Hint>
<Hint>
Let `best[left][right]` be the most points from popping everything strictly between them. It's the maximum over k of `best[left][k] + best[k][right] + values[left] * values[k] * values[right]`. Fill by increasing gap `right - left`, starting at 2.
</Hint>
</Hints>

## Solutions

<Approach title="Try every order" time="O(n!)" space="O(n)">

Recursively pop each bubble in turn and recurse on the shorter row. Remembering rows already seen helps a little, but there are still 2ⁿ possible rows, which is hopeless for 150 bubbles.

</Approach>

<Approach title="Interval DP on the last bubble popped" time="O(n³)" space="O(n²)">

The two padding bubbles turn "missing neighbour counts as 1" into an ordinary range. Ranges are open: `left` and `right` are walls that stay put.

```swift
public enum BubblePoppingPoints {
    public static func maxPoints(_ bubbles: [Int]) -> Int {
        let values = [1] + bubbles + [1]
        let n = values.count
        guard n >= 3 else { return 0 }
        var best = Array(repeating: Array(repeating: 0, count: n), count: n)
        for gap in 2..<n {
            for left in 0..<(n - gap) {
                let right = left + gap
                let ends = values[left] * values[right]
                var top = 0
                for last in (left + 1)..<right {
                    top = max(top, best[left][last] + best[last][right] + ends * values[last])
                }
                best[left][right] = top
            }
        }
        return best[0][n - 1]
    }
}
```

The largest possible total is 200 · 100³ = 2 × 10⁸, comfortably inside an `Int`.

</Approach>
