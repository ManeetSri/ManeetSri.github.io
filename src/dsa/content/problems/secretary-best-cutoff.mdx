A studio auditions n singers for one role. They arrive in random order, and after each audition the director must cast that singer or let them go for good. The director's plan: **watch** the first r singers without casting anyone, then cast the first singer who beats everyone seen so far. Write the plan, its exact chance of casting the very best singer, and the r that makes that chance as large as possible.

`SecretaryCutoffPlanner.hire(scores:watch:) -> Int?`, `SecretaryCutoffPlanner.successChance(candidates:watch:) -> Double` and `SecretaryCutoffPlanner.bestWatchCount(candidates:) -> Int`

- `hire(scores: s, watch: r)`: the singers arrive in the order of `s`, with distinct scores. Return the index of the singer the plan casts: the first index i ≥ r whose score is higher than every score before it. If nobody qualifies, return `nil`. With r = 0, the first singer is cast.
- `successChance(candidates: n, watch: r)`: the probability that the plan casts the best of n singers, when all n! arrival orders are equally likely.
- `bestWatchCount(candidates: n)`: the r from 0 to n with the largest success chance. If several tie, the smallest.

## Examples

| Call | Output |
| --- | --- |
| `hire(scores: [3, 7, 2, 9, 8], watch: 2)` | `3` |
| `hire(scores: [3, 7, 2, 9, 8], watch: 0)` | `0` |
| `hire(scores: [9, 7, 2, 3], watch: 1)` | `nil` |
| `successChance(candidates: 3, watch: 1)` | `0.5` |
| `successChance(candidates: 4, watch: 1)` | `0.4583…` (11 / 24) |
| `successChance(candidates: 5, watch: 5)` | `0.0` |
| `bestWatchCount(candidates: 3)` | `1` |
| `bestWatchCount(candidates: 2)` | `0` |
| `bestWatchCount(candidates: 100)` | `37` |

In the first example, the director watches 3 and 7, lets 2 go (worse than 7), and casts 9, the first singer to beat 7. In the third, the best singer arrived first, during the watching, so nobody later beats them.

For three singers watching one: of the 6 orders, the plan casts the best in 3. If the best arrives first, it's watched and lost. If the best is second, it's cast. If the best is last, it's cast only when the second-best arrived first. That's 2 + 1 = 3 orders out of 6. With two singers, watching 0 or 1 both succeed half the time, so the smaller, 0, is the answer.

## Constraints

- `scores` has up to 100,000 distinct values, and `0 ≤ watch ≤ scores.count`.
- `1 ≤ n ≤ 1,000,000` and `0 ≤ r ≤ n` for the other two. Answers within 10⁻⁹ pass.
- `successChance` and `bestWatchCount` must each be O(n). The tests ask about a million singers.

<Hints>
<Hint>
The plan casts the best singer, at position i (counting from 1), exactly when i > r and nobody between positions r + 1 and i − 1 was cast. That happens when the best of the first i − 1 singers is among the first r, so that no one after the watching beat the benchmark before position i.
</Hint>
<Hint>
The best singer is at position i with probability 1 / n, and, given that, the best of the first i − 1 is among the first r with probability r / (i − 1). So for r ≥ 1 the chance is (r / n) × (1/r + 1/(r + 1) + … + 1/(n − 1)), and for r = 0 it's 1 / n.
</Hint>
<Hint>
For the best r, compare neighbours: the chance goes up from r to r + 1 exactly when 1/(r + 1) + … + 1/(n − 1) is greater than 1. So build that sum from the top down, or compute every r's chance from a running suffix sum, and keep the first maximum. Don't forget r = 0 for small n.
</Hint>
</Hints>

## Solutions

<Approach title="Try every arrival order" time="O(n! · n)" space="O(n)">

For tiny n, list all n! orders, run the plan on each and count how often it casts the best. It's how the tests check the formula up to n = 8, but 8! is already 40,320 orders.

</Approach>

<Approach title="The formula, with suffix sums of 1/j" time="O(n)" space="O(1)">

```swift
public enum SecretaryCutoffPlanner {
    public static func hire(scores: [Int], watch r: Int) -> Int? {
        var benchmark = Int.min
        for score in scores.prefix(r) { benchmark = max(benchmark, score) }
        for i in r..<scores.count where scores[i] > benchmark {
            return i
        }
        return nil
    }

    public static func successChance(candidates n: Int, watch r: Int) -> Double {
        if r == 0 { return 1.0 / Double(n) }
        var tail = 0.0                         // 1/r + 1/(r + 1) + … + 1/(n − 1)
        for j in stride(from: n - 1, through: r, by: -1) { tail += 1.0 / Double(j) }
        return Double(r) / Double(n) * tail
    }

    public static func bestWatchCount(candidates n: Int) -> Int {
        var best = 0
        var bestChance = 1.0 / Double(n)
        var tail = 0.0
        var chances = [Double](repeating: 0, count: n + 1)
        for r in stride(from: n, through: 1, by: -1) {
            if r <= n - 1 { tail += 1.0 / Double(r) }
            chances[r] = Double(r) / Double(n) * tail
        }
        for r in stride(from: 1, through: n, by: 1) where chances[r] > bestChance {
            best = r
            bestChance = chances[r]
        }
        return best
    }
}
```

The best r is about n / e, and the chance it gives approaches 1 / e ≈ 0.368: for a million singers, watch 367,879 and you cast the very best about 36.8% of the time. Summing from the smallest terms upwards, as here, also keeps the floating-point error tiny.

</Approach>
