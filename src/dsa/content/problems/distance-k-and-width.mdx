Two questions about distances and levels in a binary tree:

- `DistanceKAndWidth.values(atDistance distance: Int, from target: TreeNode, in root: TreeNode?) -> [Int]`: the values of every node exactly `distance` edges from `target`, moving through parents as well as children, in increasing order. `target` is a node of the tree.
- `DistanceKAndWidth.maximumWidth(_ root: TreeNode?) -> Int`: the width of the widest level. A level's width counts the places from its leftmost node to its rightmost node, **including** the places in between where a complete tree would have a node but this one doesn't.

`TreeNode` comes from DSAKit. Trees are written in level order, the way `TreeNode.make` takes them.

## Examples

Most rows use the tree `[7, 3, 9, 1, 5, nil, 12, nil, nil, 4, 6]`:

```text
            7
          /   \
         3     9
        / \     \
       1   5     12
          / \
         4   6
```

| Call | Output |
| --- | --- |
| `values(atDistance: 1, from: 5)` | `[3, 4, 6]` |
| `values(atDistance: 2, from: 5)` | `[1, 7]` |
| `values(atDistance: 4, from: 4)` | `[9]` |
| `values(atDistance: 0, from: 9)` | `[9]` |
| `values(atDistance: 6, from: 4)` | `[]` |
| `maximumWidth` of this tree | `4` |
| `maximumWidth([1, 2, 3, 4, nil, nil, 5])` | `4` |
| `maximumWidth([1, 2, nil, 3])` | `1` |
| `maximumWidth([])` | `0` |

In this tree, the third level holds 1, 5 and 12, with an empty place between 5 and 12 where 9's left child would be: width 4. In `[1, 2, 3, 4, nil, nil, 5]`, the bottom level has only 4 and 5, but they're four places apart.

## Constraints

- Trees have at most 150,000 nodes and are at most about 300 levels deep.
- `0 ≤ distance ≤ 150,000`.
- Every level's width is at most 2³⁰. But place numbers counted from the root can overflow `Int` long before that: some test trees are 300 levels deep, and Swift stops the program on overflow.

<Hints>
<Hint>
A tree's links only point down. Walk the tree once and record each node's parent in a dictionary keyed by `ObjectIdentifier`. Now each node has up to three neighbours: left, right and parent.
</Hint>
<Hint>
Search outwards from the target one distance at a time, keeping a set of visited nodes so you never walk back. After `distance` rounds, the nodes you're holding are the answer.
</Hint>
<Hint>
For the width, give each node a place: the children of place p are 2p and 2p + 1, and a level's width is last − first + 1. Before computing a level's children, subtract the level's first place from every place on it, so the numbers stay small however deep the tree is.
</Hint>
</Hints>

## Solutions

<Approach title="A parent map with a breadth-first search, and renormalised places" time="O(n)" space="O(n)">

The parent map turns the tree into an undirected graph, and each round of the search moves one edge further from the target. The width walk goes level by level, carrying each node's place measured from its level's first node.

```swift
import DSAKit

public enum DistanceKAndWidth {
    public static func values(atDistance distance: Int, from target: TreeNode, in root: TreeNode?) -> [Int] {
        var parent: [ObjectIdentifier: TreeNode] = [:]
        var pending: [TreeNode] = root.map { [$0] } ?? []
        while let node = pending.popLast() {
            for child in [node.left, node.right] {
                if let child {
                    parent[ObjectIdentifier(child)] = node
                    pending.append(child)
                }
            }
        }
        var visited: Set<ObjectIdentifier> = [ObjectIdentifier(target)]
        var frontier = [target]                      // every node exactly `step` edges away
        var step = 0
        while step < distance && !frontier.isEmpty {
            var next: [TreeNode] = []
            for node in frontier {
                for neighbour in [node.left, node.right, parent[ObjectIdentifier(node)]] {
                    if let neighbour, visited.insert(ObjectIdentifier(neighbour)).inserted {
                        next.append(neighbour)
                    }
                }
            }
            frontier = next
            step += 1
        }
        return frontier.map(\.value).sorted()
    }

    public static func maximumWidth(_ root: TreeNode?) -> Int {
        guard let root else { return 0 }
        var level: [(node: TreeNode, position: Int)] = [(root, 0)]
        var widest = 0
        while let first = level.first, let last = level.last {
            widest = max(widest, last.position - first.position + 1)
            var below: [(node: TreeNode, position: Int)] = []
            for (node, position) in level {
                let offset = position - first.position     // renormalise: the level now starts at 0
                if let left = node.left { below.append((left, 2 * offset)) }
                if let right = node.right { below.append((right, 2 * offset + 1)) }
            }
            level = below
        }
        return widest
    }
}
```
