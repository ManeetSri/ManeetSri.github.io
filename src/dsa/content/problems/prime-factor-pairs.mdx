Break a whole number into its prime factors, reported as (prime, exponent) pairs with the primes in increasing order. Then use those pairs to count how many divisors the number has.

`PrimeFactorPairs.factorise(_ n: Int) -> [(prime: Int, exponent: Int)]`

`PrimeFactorPairs.divisorCount(of n: Int) -> Int`

For example, 360 = 2³ × 3² × 5, so `factorise(360)` returns `[(2, 3), (3, 2), (5, 1)]`. The number 1 has no prime factors, so its list is empty, but it does have one divisor: itself.

## Examples

| n | `factorise(n)` | `divisorCount(of: n)` |
| --- | --- | --- |
| `360` | `[(2, 3), (3, 2), (5, 1)]` | `24` |
| `97` | `[(97, 1)]` | `2` |
| `1024` | `[(2, 10)]` | `11` |
| `1` | `[]` | `1` |
| `1_000_000_000_000` | `[(2, 12), (5, 12)]` | `169` |

## Constraints

- `1 ≤ n ≤ 1,000,000,000,000` (10¹²)

<Hints>
<Hint>
Try divisors d = 2, 3, 4, … in order. When d divides n, divide it out as many times as it goes, counting how many. Composite values of d never divide, because their prime factors are already gone.
</Hint>
<Hint>
Stop when `d * d` is bigger than what's left of n. If what's left is still bigger than 1, it's a prime factor on its own, with exponent 1. That's how 97, and the 5 in 360, get found.
</Hint>
<Hint>
For the divisor count, every divisor picks an exponent from 0 up to e for each prime, independently. So add 1 to each exponent and multiply.
</Hint>
</Hints>

## Solutions

<Approach title="Count every divisor directly" time="O(√n)" space="O(1)">

`divisorCount` on its own can use the pairing loop from the divisors lesson: every d up to √n that divides n gives two divisors, d and n / d, unless they're equal. It's also O(√n), but it doesn't give you the factorisation.

```swift
public static func divisorCount(of n: Int) -> Int {
    var count = 0
    var d = 1
    while d * d <= n {
        if n % d == 0 {
            count += d == n / d ? 1 : 2
        }
        d += 1
    }
    return count
}
```

</Approach>

<Approach title="Trial division, then multiply (exponent + 1)" time="O(√n)" space="O(log n)">

Divide out each factor completely before moving on. The loop stops once `d * d` passes the shrinking `n`, which makes it fast when n has small factors. The leftover, if any, is a prime. The list itself is tiny: a number up to 10¹² has at most 11 different prime factors, and never more than log₂ n.

```swift
public enum PrimeFactorPairs {
    public static func factorise(_ n: Int) -> [(prime: Int, exponent: Int)] {
        var rest = n
        var factors: [(prime: Int, exponent: Int)] = []
        var d = 2
        while d * d <= rest {
            if rest % d == 0 {
                var exponent = 0
                while rest % d == 0 {
                    rest /= d
                    exponent += 1
                }
                factors.append((prime: d, exponent: exponent))
            }
            d += 1
        }
        if rest > 1 {
            factors.append((prime: rest, exponent: 1))
        }
        return factors
    }

    public static func divisorCount(of n: Int) -> Int {
        factorise(n).reduce(1) { count, factor in count * (factor.exponent + 1) }
    }
}
```

The worst case is a large prime, or the square of one, such as 999,983² = 999,966,000,289: the loop then runs all the way to about a million. You could halve that by handling 2 separately and trying only odd d.

</Approach>
