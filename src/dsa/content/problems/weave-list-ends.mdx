Rearrange a list so it alternates between its front and its back: the first node, then the last, then the second, then the second-to-last, and so on until they meet in the middle. Rewire the existing nodes in place; don't create new ones or change any values. The head stays the head, so the function returns nothing.

`WeaveListEnds.reorder(_ head: ListNode?)`

## Examples

| List before | List after |
| --- | --- |
| `1 -> 2 -> 3 -> 4 -> 5` | `1 -> 5 -> 2 -> 4 -> 3` |
| `10 -> 20 -> 30 -> 40` | `10 -> 40 -> 20 -> 30` |
| `8 -> 9` | `8 -> 9` |
| `4` | `4` |
| empty (`nil`) | empty |

## Constraints

- 0 to 20,000 nodes.
- O(n) time and O(1) extra space: no array of nodes or values.

<Hints>
<Hint>
The back half is needed in reverse order, and a singly linked list only goes forwards. Break the job into three tools you already have: find the middle, reverse a list, and merge two lists by taking a node from each in turn.
</Hint>
<Hint>
Find the first middle with fast and slow pointers: move `slow` one step and `fast` two while `fast.next?.next` exists. The back half starts at `slow.next`. Cut the list there with `slow.next = nil`, or the halves stay joined and the weave builds a cycle.
</Hint>
<Hint>
Reverse the back half, then weave: take the next front node and the next back node, save both of their `next` references, link front to back and back to the saved front `next`, and move on. Stop when the back half runs out. The front half is the same length or one longer, so any extra front node is already last.
</Hint>
</Hints>

## Solutions

<Approach title="Collect the nodes in an array" time="O(n)" space="O(n)">

With every node in an array you can index the back directly, so two indexes walking inwards relink the nodes in the new order. It's simple, and a good check for the faster version, but the array is O(n) extra space.

```swift
public static func reorder(_ head: ListNode?) {
    var nodes: [ListNode] = []
    var current = head
    while let node = current {
        nodes.append(node)
        current = node.next
    }
    var left = 0
    var right = nodes.count - 1
    while left < right {
        nodes[left].next = nodes[right]
        left += 1
        if left == right { break }
        nodes[right].next = nodes[left]
        right -= 1
    }
    if !nodes.isEmpty {
        nodes[left].next = nil              // the middle node ends the list
    }
}
```

</Approach>

<Approach title="Split, reverse the back, weave" time="O(n)" space="O(1)">

Each step uses a tool from earlier in the module. The middle is found in one pass, the back half is reversed in another, and the weave visits each node once more.

```swift
import DSAKit

public enum WeaveListEnds {
    public static func reorder(_ head: ListNode?) {
        guard let head else { return }
        // 1. Find the first middle and cut the list after it
        var slow = head
        var fast = head
        while let next = fast.next?.next {
            slow = slow.next!
            fast = next
        }
        var back = reverse(slow.next)
        slow.next = nil

        // 2. Weave: front node, back node, front node, ...
        var front: ListNode? = head
        while let f = front, let b = back {
            let frontNext = f.next
            let backNext = b.next
            f.next = b
            b.next = frontNext
            front = frontNext
            back = backNext
        }
    }

    private static func reverse(_ head: ListNode?) -> ListNode? {
        var previous: ListNode? = nil
        var current = head
        while let node = current {
            let next = node.next
            node.next = previous
            previous = node
            current = next
        }
        return previous
    }
}
```

</Approach>
