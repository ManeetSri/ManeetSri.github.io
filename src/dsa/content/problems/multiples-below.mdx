Add up every positive whole number below a limit that is divisible by at least one of two given numbers.

`MultiplesBelow.sum(below limit: Int, divisibleBy a: Int, or b: Int) -> Int`

A number divisible by both `a` and `b` is still counted only once. The limit itself is never included.

## Examples

| Input | Output | Why |
| --- | --- | --- |
| `limit: 10, a: 3, b: 5` | `23` | 3 + 5 + 6 + 9 |
| `limit: 20, a: 4, b: 6` | `64` | 4 + 6 + 8 + 12 + 16 + 18, with 12 counted once |
| `limit: 10, a: 2, b: 2` | `20` | 2 + 4 + 6 + 8 |
| `limit: 1, a: 3, b: 5` | `0` | there are no positive numbers below 1 |

## Constraints

- `0 ≤ limit ≤ 1,000,000`
- `1 ≤ a, b ≤ 1,000`

<Hints>
<Hint>
Visit every candidate with a `for-in` loop and keep a running total: the accumulator pattern.
</Hint>
<Hint>
One condition, `n % a == 0 || n % b == 0`, counts a number divisible by both exactly once.
</Hint>
<Hint>
Careful with the range when `limit` is 0: `1..<0` is a backwards range and crashes. `stride(from: 1, to: limit, by: 1)` is simply empty instead, or check for small limits first.
</Hint>
</Hints>

## Solutions

<Approach title="Check every number" time="O(limit)" space="O(1)">

Loop over every number below the limit, and add it if either divisor goes into it. A `where` clause keeps the filter on the loop line.

```swift
public enum MultiplesBelow {
    public static func sum(below limit: Int, divisibleBy a: Int, or b: Int) -> Int {
        var total = 0
        for n in stride(from: 1, to: limit, by: 1) where n % a == 0 || n % b == 0 {
            total += n
        }
        return total
    }
}
```

A million checks take a moment, which is fine for these constraints.

</Approach>

<Approach title="Arithmetic series, no loop over the numbers" time="O(log(min(a, b)))" space="O(1)">

There's a shortcut. The multiples of 3 below 10 are 3 + 6 + 9 = 3 × (1 + 2 + 3), and 1 + 2 + … + k is `k * (k + 1) / 2`. So the sum of the multiples of `d` below the limit is `d * k * (k + 1) / 2`, where `k = (limit - 1) / d`.

Adding the multiples of `a` and of `b` counts numbers divisible by both twice, so subtract the multiples of their **least common multiple** once. This is called *inclusion–exclusion*. The least common multiple comes from the greatest common divisor, which Euclid's algorithm finds with a `while` loop:

```swift
public static func sum(below limit: Int, divisibleBy a: Int, or b: Int) -> Int {
    guard limit > 1 else { return 0 }

    func sumOfMultiples(of d: Int) -> Int {
        let k = (limit - 1) / d
        return d * k * (k + 1) / 2
    }

    var x = a, y = b
    while y != 0 {
        (x, y) = (y, x % y)
    }
    let lcm = a / x * b

    return sumOfMultiples(of: a) + sumOfMultiples(of: b) - sumOfMultiples(of: lcm)
}
```

Don't worry if the maths is new: Part II covers it. It's here to show that the right idea can replace a million steps with a handful.

</Approach>
