Multiply two non-negative whole numbers given as decimal strings, and return the product as a decimal string. Each number can have up to 100,000 digits, far beyond any built-in integer type.

`DigitStringProduct.multiply(_ a: String, _ b: String) -> String`

Neither input has leading zeros, except the number zero itself, written `"0"`. The answer mustn't have leading zeros either.

## Examples

| `a` | `b` | Output |
| --- | --- | --- |
| `"123"` | `"45"` | `"5535"` |
| `"99"` | `"99"` | `"9801"` |
| `"0"` | `"98765"` | `"0"` |
| `"123456789"` | `"987654321"` | `"121932631112635269"` |
| `"18446744073709551615"` | `"18446744073709551615"` | `"340282366920938463426481119284349108225"` |

## Constraints

- `1 ≤ a.count, b.count ≤ 100,000`
- Both contain only the digits 0 to 9, with no leading zeros unless the number is 0.
- The tests multiply two random 100,000-digit numbers. Long multiplication would need 10¹⁰ digit products.

<Hints>
<Hint>
Read each number's digits, lowest first, as polynomial coefficients. Before carrying, digit k of the product is the convolution c[k] = Σ a[i] × b[k − i]. Compute the convolution fast, then carry.
</Hint>
<Hint>
Use the number-theoretic transform modulo 998,244,353. Pad both digit lists with zeros to a power of two at least a.count + b.count − 1, transform both, multiply pointwise, and transform back with the inverse root, dividing by the length. Every true coefficient is at most 9 × 9 × 100,000, well below the prime, so the result is exact.
</Hint>
<Hint>
Carry from the lowest digit up, appending more digits while a carry remains, then remove leading zeros so that a zero factor gives "0". `swift test` builds without optimisation, so write the transform's inner loops as `while` loops and compute each level's powers of the root once into a table; it makes a big difference in debug builds.
</Hint>
</Hints>

## Solutions

<Approach title="Long multiplication" time="O(a · b)" space="O(a + b)">

Multiply every digit of a by every digit of b, as on paper, adding into the right column and carrying. It's the reference the tests use for small inputs, and about 10¹⁰ steps for two 100,000-digit numbers.

</Approach>

<Approach title="NTT convolution" time="O((a + b) log(a + b))" space="O(a + b)">

Convert to digit arrays, convolve with three transforms, then carry and convert back.

```swift
public enum DigitStringProduct {
    private static let mod = 998_244_353

    public static func multiply(_ a: String, _ b: String) -> String {
        let x = a.utf8.reversed().map { Int($0) - 48 }      // "0" is UTF-8 byte 48
        let y = b.utf8.reversed().map { Int($0) - 48 }
        let size = x.count + y.count - 1
        var n = 1
        while n < size { n <<= 1 }
        var fx = x + Array(repeating: 0, count: n - x.count)
        var fy = y + Array(repeating: 0, count: n - y.count)
        transform(&fx, invert: false)
        transform(&fy, invert: false)
        for i in 0..<n { fx[i] = fx[i] * fy[i] % mod }
        transform(&fx, invert: true)

        var digits: [UInt8] = []                             // lowest first
        digits.reserveCapacity(size + 1)
        var carry = 0
        for i in 0..<size {
            let value = fx[i] + carry
            digits.append(UInt8(value % 10) + 48)
            carry = value / 10
        }
        while carry > 0 {
            digits.append(UInt8(carry % 10) + 48)
            carry /= 10
        }
        while digits.count > 1 && digits.last == 48 { digits.removeLast() }   // a zero factor
        return String(decoding: digits.reversed(), as: UTF8.self)
    }

    private static func transform(_ a: inout [Int], invert: Bool) {
        let n = a.count
        var j = 0
        var i = 1
        while i < n {                                        // bit-reversal permutation
            var bit = n >> 1
            while j & bit != 0 {
                j ^= bit
                bit >>= 1
            }
            j ^= bit
            if i < j { a.swapAt(i, j) }
            i += 1
        }
        var twiddles = Array(repeating: 1, count: max(n / 2, 1))
        var length = 2
        while length <= n {
            var root = power(3, (mod - 1) / length)          // a root of unity of order `length`
            if invert { root = power(root, mod - 2) }
            let half = length / 2
            for k in stride(from: 1, to: half, by: 1) {
                twiddles[k] = twiddles[k - 1] * root % mod
            }
            var start = 0
            while start < n {
                var k = 0
                while k < half {
                    let u = a[start + k]
                    let v = a[start + k + half] * twiddles[k] % mod
                    let sum = u + v
                    a[start + k] = sum < mod ? sum : sum - mod
                    let difference = u - v
                    a[start + k + half] = difference >= 0 ? difference : difference + mod
                    k += 1
                }
                start += length
            }
            length <<= 1
        }
        if invert {
            let nInverse = power(n, mod - 2)
            for i in 0..<n { a[i] = a[i] * nInverse % mod }
        }
    }

    private static func power(_ base: Int, _ exponent: Int) -> Int {
        var result = 1
        var square = base % mod
        var e = exponent
        while e > 0 {
            if e & 1 == 1 { result = result * square % mod }
            square = square * square % mod
            e >>= 1
        }
        return result
    }
}
```

Working with the strings' UTF-8 bytes avoids creating a `Character` or `String` per digit, which matters at 100,000 digits. For more speed, group the digits in pairs (base 100): each list halves in length, and coefficients stay below 99 × 99 × 50,000, still far below the prime.

</Approach>
