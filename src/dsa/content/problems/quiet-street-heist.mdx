A burglar is planning a night on a quiet, straight street. `houses[i]` is the cash hidden in house `i`. Every house is wired to its neighbours, so robbing two houses side by side sets off the alarm. Return the most cash the burglar can take without setting it off.

`QuietStreetHeist.maximumLoot(houses: [Int]) -> Int`

## Examples

| `houses` | Output | Why |
| --- | --- | --- |
| `[3, 10, 3, 1, 2]` | `12` | houses 1 and 4: 10 + 2 |
| `[6, 2, 3, 8]` | `14` | houses 0 and 3: 6 + 8, skipping two in a row |
| `[2, 1, 1, 2]` | `4` | the two ends |
| `[7]` | `7` | |
| `[]` | `0` | |

## Constraints

- `0 ≤ houses.count ≤ 100,000`
- `0 ≤ houses[i] ≤ 10,000`
- The tests use streets of 100,000 houses, so the plan can't be found by trying every combination.

<Hints>
<Hint>
Taking the richest house first, or every other house, both fail on some streets. Think about the last house instead: either it's robbed, or it isn't.
</Hint>
<Hint>
Let `best[i]` be the most you can take from the first i houses. If house i − 1 is left alone, that's `best[i − 1]`. If it's robbed, its neighbour isn't, so it's `best[i − 2] + houses[i − 1]`. Take the larger.
</Hint>
<Hint>
Each entry only reads the two before it, so keep two variables and shift them along with a tuple assignment: `(twoBack, oneBack) = (oneBack, max(oneBack, twoBack + cash))`.
</Hint>
</Hints>

## Solutions

<Approach title="Table of best totals" time="O(n)" space="O(n)">

The recipe from [House robber I and II](/dsa/learn/dp-house-robber). **State:** `best[i]`, the most from the first i houses. **Transition:** `max(best[i − 1], best[i − 2] + houses[i − 1])`. **Base case:** `best[0] = 0`. **Order:** upwards. **Answer:** `best[n]`.

```swift
public static func maximumLoot(houses: [Int]) -> Int {
    let n = houses.count
    var best = Array(repeating: 0, count: n + 1)
    for i in stride(from: 1, through: n, by: 1) {
        best[i] = max(best[i - 1], (i >= 2 ? best[i - 2] : 0) + houses[i - 1])
    }
    return best[n]
}
```

</Approach>

<Approach title="Two rolling variables" time="O(n)" space="O(1)">

As in [Saving space](/dsa/learn/dp-space), only the last two entries are ever read. The tuple assignment computes the new pair from the old values before changing either.

```swift
public enum QuietStreetHeist {
    public static func maximumLoot(houses: [Int]) -> Int {
        var (twoBack, oneBack) = (0, 0)
        for cash in houses {
            (twoBack, oneBack) = (oneBack, max(oneBack, twoBack + cash))
        }
        return oneBack
    }
}
```

</Approach>
