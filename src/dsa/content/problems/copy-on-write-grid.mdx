Finish a grid of `Int`s that keeps its cells in a shared class and behaves as a value: copies are independent, copying is free, and storage is duplicated only when a shared grid changes, at most once. A `CopyCounter` given to each grid records every duplicate, so the tests can count them.

`CopyOnWriteGrid.Grid`, with `subscript(row:column:)`, `row(_:)`, `fill(_:)`, `add(_:toRow:)`, `swapRows(_:_:)` and `isSharingStorage(with:)`

The starter code gives you `CopyCounter`, the `Storage` class (whose `duplicate()` makes a copy and records it), the initialiser and `storageID`. Implement the rest:

- **Reading** (the subscript's `get`, `row(_:)`) never duplicates. Cells are stored row by row: cell `(row, column)` is `storage.cells[row * columns + column]`.
- **Writing a cell**, `add(_:toRow:)` and `swapRows(_:_:)` must never change another grid. If the storage is shared, call `storage.duplicate()` once first; if it isn't, change it in place, so `storageID` stays the same. Check uniqueness once per operation, not once per cell.
- **`fill(_:)`** overwrites every cell, so copying the old cells first would be wasted work. It must **never** call `duplicate()`: when the storage is shared, build new `Storage` directly, filled with the value, using the same counter.
- **`swapRows(r, r)`** changes nothing, so it never duplicates.
- **`isSharingStorage(with:)`** is `true` exactly when both grids use the same storage object.

## Examples

| Code | Result |
| --- | --- |
| `var a = Grid(rows: 2, columns: 2, repeating: 0, counter: counter)`, `var b = a` | `a.isSharingStorage(with: b)` is `true`, `counter.copies` is 0 |
| then `b[0, 0] = 1` | `counter.copies` is 1; `a[0, 0]` is 0, `b[0, 0]` is 1 |
| then `b[1, 1] = 5` and `b.add(2, toRow: 0)` | `counter.copies` is still 1; `b.row(0)` is `[3, 2]` |
| `var c = a`, then `c.fill(7)` | `counter.copies` is still 1; `c.row(1)` is `[7, 7]`, `a.row(1)` is `[0, 0]` |
| `var d = a`, then `d.swapRows(0, 0)` | nothing changes, and `d` still shares `a`'s storage |

## Constraints

- `1 ≤ rows, columns ≤ 500`; every index you're given is valid.
- Use the `Storage` class for the cells, and duplicate it only with `duplicate()`.
- The tests copy a 300 × 300 grid and write all 90,000 cells of the copy. They expect exactly one duplicate; duplicating on every write would copy 8 billion cells.

## Solutions

<Approach title="Duplicate on every change" time="O(rows × columns) per write" space="O(rows × columns)">

Always calling `duplicate()` before a change keeps grids independent, so the values are right. But it copies every cell on every write, even when nobody shares the storage. The counter catches it immediately, and filling a 300 × 300 copy cell by cell would copy 90,000 cells 90,000 times.

```swift
set {
    storage = storage.duplicate()        // even when not shared
    storage.cells[row * columns + column] = newValue
}
```

</Approach>

<Approach title="Copy-on-write, checked once per operation" time="O(1) per cell write, O(columns) per row operation" space="O(rows × columns)">

The first change after sharing duplicates once (O(rows × columns)); every later change is in place. Row operations check once and then loop over the storage, and `fill` replaces shared storage without copying it.

```swift
public enum CopyOnWriteGrid {
    public final class CopyCounter {
        public private(set) var copies = 0

        public init() {}

        func recordCopy() {
            copies += 1
        }
    }

    final class Storage {
        var cells: [Int]
        let counter: CopyCounter

        init(cells: [Int], counter: CopyCounter) {
            self.cells = cells
            self.counter = counter
        }

        func duplicate() -> Storage {
            counter.recordCopy()
            return Storage(cells: cells, counter: counter)
        }
    }

    public struct Grid {
        private var storage: Storage
        public let rows: Int
        public let columns: Int

        public init(rows: Int, columns: Int, repeating value: Int, counter: CopyCounter) {
            self.rows = rows
            self.columns = columns
            storage = Storage(cells: Array(repeating: value, count: rows * columns), counter: counter)
        }

        public var storageID: ObjectIdentifier {
            ObjectIdentifier(storage)
        }

        private mutating func makeUnique() {
            if !isKnownUniquelyReferenced(&storage) {
                storage = storage.duplicate()
            }
        }

        public subscript(row: Int, column: Int) -> Int {
            get {
                storage.cells[row * columns + column]
            }
            set {
                makeUnique()
                storage.cells[row * columns + column] = newValue
            }
        }

        public func row(_ row: Int) -> [Int] {
            Array(storage.cells[(row * columns)..<((row + 1) * columns)])
        }

        public mutating func fill(_ value: Int) {
            if isKnownUniquelyReferenced(&storage) {
                for index in storage.cells.indices {
                    storage.cells[index] = value
                }
            } else {
                storage = Storage(cells: Array(repeating: value, count: rows * columns), counter: storage.counter)
            }
        }

        public mutating func add(_ delta: Int, toRow row: Int) {
            makeUnique()
            for index in (row * columns)..<((row + 1) * columns) {
                storage.cells[index] += delta
            }
        }

        public mutating func swapRows(_ first: Int, _ second: Int) {
            guard first != second else { return }
            makeUnique()
            for column in 0..<columns {
                storage.cells.swapAt(first * columns + column, second * columns + column)
            }
        }

        public func isSharingStorage(with other: Grid) -> Bool {
            storageID == other.storageID
        }
    }
}
```

`grid[r, c] += 1` reads through `get` and writes through `set`, so it runs one uniqueness check, the same as a plain assignment. With three grids sharing one storage, the first two to change each duplicate; the last one finds itself the only owner of the original and changes it in place, so three independent grids cost two copies.

</Approach>
