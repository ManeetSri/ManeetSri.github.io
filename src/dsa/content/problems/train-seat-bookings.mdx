A train runs past stations 0, 1, …, n. The stretch from station i to station i + 1 has `seats[i]` free seats. Groups ask, one after another, for seats from one station to a later one. Accept a request only if **every** stretch it rides still has enough free seats, and then take those seats; otherwise reject it and change nothing. Return whether each request was accepted.

`TrainSeatBookings.process(seats: [Int], requests: [[Int]]) -> [Bool]`

A request `[from, to, people]` needs `people` seats on stretches `from`, `from + 1`, …, `to − 1`: the group gets on at station `from` and off at station `to`, so the seat is free again from station `to` onwards.

## Examples

With `seats = [3, 5, 2, 4]` (stretches 0 to 3):

| Request | Output | Free seats afterwards |
| --- | --- | --- |
| `[0, 2, 3]` | `true` | `[0, 2, 2, 4]` |
| `[1, 4, 2]` | `true` | `[0, 0, 0, 2]` |
| `[1, 3, 1]` | `false` | unchanged: stretches 1 and 2 are full |
| `[3, 4, 4]` | `false` | unchanged: stretch 3 has only 2 |
| `[3, 4, 2]` | `true` | `[0, 0, 0, 0]` |

So the result is `[true, true, false, false, true]`.

## Constraints

- `1 ≤ seats.count ≤ 100,000`, and `0 ≤ seats[i] ≤ 10⁹`
- `0 ≤ requests.count ≤ 100,000`
- Every request has `0 ≤ from < to ≤ seats.count` and `1 ≤ people ≤ 10⁹`.
- The tests use 100,000 stretches and 100,000 long requests, so checking each stretch of each request is too slow.

<Hints>
<Hint>
A request fits exactly when the **smallest** number of free seats among its stretches is at least `people`. So each request is a range-minimum question, followed, if it fits, by subtracting `people` from every stretch in the range.
</Hint>
<Hint>
Subtracting from a whole range, one stretch at a time, is O(length). You need range updates as cheap as range queries: lazy propagation.
</Hint>
<Hint>
A segment tree of minimums with a pending "add this to everything below" on each node. When every stretch in a block loses `people` seats, the block's minimum drops by exactly `people`, whatever its length. Push the pending amount to the children before going below a node.
</Hint>
</Hints>

## Solutions

<Approach title="Check every stretch" time="O(n · q)" space="O(n)">

Keep the free seats in an array, check every stretch of a request, then subtract. It's the clearest statement of the rules, but 100,000 requests of tens of thousands of stretches each is billions of steps.

```swift
public static func process(seats: [Int], requests: [[Int]]) -> [Bool] {
    var free = seats
    return requests.map { request in
        let stretches = request[0]..<request[1]
        guard stretches.allSatisfy({ free[$0] >= request[2] }) else { return false }
        for stretch in stretches { free[stretch] -= request[2] }
        return true
    }
}
```

</Approach>

<Approach title="Lazy segment tree: range add, range minimum" time="O(n + q log n)" space="O(n)">

Exactly the tree from [Lazy propagation](/dsa/learn/seg-lazy), with minimums in place of sums. `apply` lowers a node's minimum and records the amount for its children; `push` hands it down before an operation descends.

```swift
public enum TrainSeatBookings {
    public static func process(seats: [Int], requests: [[Int]]) -> [Bool] {
        var free = FreeSeats(seats)
        return requests.map { request in
            let first = request[0], last = request[1] - 1, people = request[2]
            guard free.minimum(first, last) >= people else { return false }
            free.add(-people, first, last)
            return true
        }
    }

    private struct FreeSeats {
        private var minimums: [Int]
        private var pending: [Int]               // added to a whole node, not yet to its children
        private let count: Int

        init(_ values: [Int]) {
            count = values.count
            minimums = Array(repeating: 0, count: 4 * values.count)
            pending = Array(repeating: 0, count: 4 * values.count)
            build(values, 1, 0, count - 1)
        }

        mutating func minimum(_ left: Int, _ right: Int) -> Int {
            minimum(left, right, 1, 0, count - 1)
        }

        mutating func add(_ delta: Int, _ left: Int, _ right: Int) {
            add(delta, left, right, 1, 0, count - 1)
        }

        private mutating func build(_ values: [Int], _ node: Int, _ low: Int, _ high: Int) {
            if low == high {
                minimums[node] = values[low]
                return
            }
            let mid = (low + high) / 2
            build(values, 2 * node, low, mid)
            build(values, 2 * node + 1, mid + 1, high)
            minimums[node] = min(minimums[2 * node], minimums[2 * node + 1])
        }

        private mutating func apply(_ delta: Int, _ node: Int) {
            minimums[node] += delta              // every stretch below drops by the same amount
            pending[node] += delta
        }

        private mutating func push(_ node: Int) {
            if pending[node] == 0 { return }
            apply(pending[node], 2 * node)
            apply(pending[node], 2 * node + 1)
            pending[node] = 0
        }

        private mutating func minimum(_ left: Int, _ right: Int, _ node: Int, _ low: Int, _ high: Int) -> Int {
            if right < low || high < left { return Int.max }
            if left <= low && high <= right { return minimums[node] }
            push(node)
            let mid = (low + high) / 2
            return min(minimum(left, right, 2 * node, low, mid), minimum(left, right, 2 * node + 1, mid + 1, high))
        }

        private mutating func add(_ delta: Int, _ left: Int, _ right: Int, _ node: Int, _ low: Int, _ high: Int) {
            if right < low || high < left { return }
            if left <= low && high <= right {
                apply(delta, node)
                return
            }
            push(node)
            let mid = (low + high) / 2
            add(delta, left, right, 2 * node, low, mid)
            add(delta, left, right, 2 * node + 1, mid + 1, high)
            minimums[node] = min(minimums[2 * node], minimums[2 * node + 1])
        }
    }
}
```

The stretch range is `from...to − 1`, closed, which is what the recursive tree expects. With DSAKit, `LazySegmentTree(seats)` gives the same two operations as `minimum(in: from..<to)` and `add(-people, to: from..<to)`. A Fenwick tree can't do this one: it has no way to answer range minimums.

</Approach>
