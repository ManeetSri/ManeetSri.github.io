You have a list of scores in the order they happened. A score **sets a record** if it's strictly greater than every score before it. The first score always sets a record, because nothing came before it. Return the indices of every record, in order.

`RecordBreakers.recordIndices(in scores: [Int]) -> [Int]`

## Examples

| Input | Output |
| --- | --- |
| `[3, 1, 4, 1, 5, 9, 2, 6]` | `[0, 2, 4, 5]` |
| `[5, 5, 5]` | `[0]` |
| `[-8, -3, -5]` | `[0, 1]` |
| `[]` | `[]` |

In the first example, the records are 3, 4, 5 and 9. A tie doesn't break a record, which is why `[5, 5, 5]` has only one.

## Constraints

- `0 ≤ scores.count ≤ 100,000`
- `-10⁹ ≤ scores[i] ≤ 10⁹`

<Hints>
<Hint>
Dry run the first example. Next to each score, write down the best score seen *before* it. When is a score a record?
</Hint>
<Hint>
An invariant to aim for: before you look at index `i`, `best` holds the largest of the scores before `i`. Then a score is a record exactly when it's greater than `best`.
</Hint>
<Hint>
The first score has nothing before it, so there's no `best` yet. Handle it with `guard let first = scores.first`, which also deals with the empty array, then loop over the remaining indices.
</Hint>
</Hints>

## Solutions

<Approach title="Brute force: compare with everything before" time="O(n²)" space="O(1)">

Straight from the definition: a score is a record if no earlier score is greater than or equal to it. `prefix(i)` is the scores before index `i`, and for `i = 0` it's empty, so the first score is always a record.

```swift
public static func recordIndices(in scores: [Int]) -> [Int] {
    var records: [Int] = []
    for i in scores.indices {
        if scores.prefix(i).allSatisfy({ $0 < scores[i] }) {
            records.append(i)
        }
    }
    return records
}
```

Correct, but each score rescans everything before it: about n² / 2 comparisons, five billion for 100,000 scores.

</Approach>

<Approach title="One pass with a running best" time="O(n)" space="O(1)">

Keep the best score so far. The invariant: at the start of each pass, `best` is the largest score before `i`. A score beats it exactly when it sets a record, and then it becomes the new best, which keeps the invariant true for the next pass. When the loop finishes, every record has been found.

```swift
public enum RecordBreakers {
    public static func recordIndices(in scores: [Int]) -> [Int] {
        guard var best = scores.first else { return [] }
        var records = [0]
        for i in scores.indices.dropFirst() where scores[i] > best {
            records.append(i)
            best = scores[i]
        }
        return records
    }
}
```

The space is O(1) apart from the answer itself. Using `>` rather than `>=` is what stops ties counting as records.

</Approach>
