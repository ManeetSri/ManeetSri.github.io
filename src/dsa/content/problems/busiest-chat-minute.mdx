A support team wants to know when its chat is busiest. Every message carries the time it was sent, typed as text by whichever device sent it. Return the minute of the day with the most messages.

`BusiestChatMinute.busiest(_ stamps: [String]) -> String?`

That's all the interviewer said at first. The details below came from asking, and each answer changes the code:

| You ask | The interviewer says | What it changes |
| --- | --- | --- |
| How many stamps? | Up to a million. | Aim for O(n). |
| Are they in order? | No: devices sync at different times. | No sorting tricks; count instead. |
| What format? | 24-hour `H:MM` or `HH:MM`: `"9:05"` and `"09:05"` are the same minute. | Parse both forms to one key. |
| Can a stamp be malformed? | Yes, a few are garbled. Skip anything that isn't 1 or 2 digits, a colon and exactly 2 digits, with the hour 0 to 23 and the minute 00 to 59. | Validate before counting, and never crash. |
| What counts as a digit? | Only ASCII `0` to `9`. | `Character.isNumber` is wrong: it accepts `"١"` and `"５"`. So is a bare `Int(_:)`, which accepts `"+9"`. |
| What if the list is empty, or nothing is valid? | Return `nil`. | The return type is optional. |
| What if two minutes tie? | The earliest minute of the day. | A tie-break rule in the comparison. |
| What should I return? | Always `HH:MM`, with a two-digit hour. | Format the answer, don't echo an input. |

## Examples

| `stamps` | Output | Why |
| --- | --- | --- |
| `["9:05", "10:30", "09:05", "10:30", "9:05"]` | `"09:05"` | three messages at 09:05, two at 10:30 |
| `["23:59", "00:00"]` | `"00:00"` | a tie: midnight comes first in the day |
| `["12:00", "12:00", "24:00", "24:00", "24:00", "13:00"]` | `"12:00"` | `24:00` isn't a time, however often it appears |
| `["7:7", "noon", "07:07"]` | `"07:07"` | only the last stamp is valid |
| `["25:00", "12:60", ""]` | `nil` | nothing valid |
| `[]` | `nil` | |

## Constraints

- `0 ≤ stamps.count ≤ 1,000,000`, each up to 20 characters of any Unicode.
- Leading or trailing spaces, signs, seconds (`"12:05:30"`) and non-ASCII digits all make a stamp invalid.

<Hints>
<Hint>
There are only 24 × 60 = 1,440 minutes in a day. Turn each valid stamp into a number from 0 to 1,439 and count in an array of 1,440 slots.
</Hint>
<Hint>
Work on `Array(stamp.utf8)`. Find the colon, then check that the part before it has 1 or 2 bytes and the part after it has exactly 2, all between `UInt8(ascii: "0")` and `UInt8(ascii: "9")`. Any non-ASCII character is several bytes of 128 or more, so it fails that check by itself.
</Hint>
<Hint>
For the tie-break, scan the 1,440 slots from 0 upwards and replace the best only when a count is strictly greater: the earliest minute keeps a tie.
</Hint>
</Hints>

## Solutions

<Approach title="Count into 1,440 slots" time="O(total length of the stamps)" space="O(1)">

Validating bytes rather than `Character`s answers the "what is a digit?" question exactly as agreed, and keeps every check O(1) per byte. The count array has a fixed size, whatever the input.

```swift
public enum BusiestChatMinute {
    public static func busiest(_ stamps: [String]) -> String? {
        var counts = [Int](repeating: 0, count: 24 * 60)
        var sawValid = false
        for stamp in stamps {
            guard let minute = minuteOfDay(stamp) else { continue }
            counts[minute] += 1
            sawValid = true
        }
        guard sawValid else { return nil }
        var best = 0
        for minute in counts.indices where counts[minute] > counts[best] {
            best = minute                        // strictly greater: ties keep the earlier minute
        }
        return twoDigits(best / 60) + ":" + twoDigits(best % 60)
    }

    /// The minute of the day for a valid stamp such as "9:05" or "09:05", or nil.
    private static func minuteOfDay(_ stamp: String) -> Int? {
        let bytes = Array(stamp.utf8)
        guard let colon = bytes.firstIndex(of: UInt8(ascii: ":")) else { return nil }
        let hourDigits = bytes[..<colon]
        let minuteDigits = bytes[(colon + 1)...]
        guard (1...2).contains(hourDigits.count), minuteDigits.count == 2,
              hourDigits.allSatisfy(isDigit), minuteDigits.allSatisfy(isDigit) else { return nil }
        let hour = number(hourDigits)
        let minute = number(minuteDigits)
        guard hour < 24, minute < 60 else { return nil }
        return hour * 60 + minute
    }

    private static func isDigit(_ byte: UInt8) -> Bool {
        byte >= UInt8(ascii: "0") && byte <= UInt8(ascii: "9")
    }

    private static func number(_ digits: ArraySlice<UInt8>) -> Int {
        digits.reduce(0) { $0 * 10 + Int($1 - UInt8(ascii: "0")) }
    }

    private static func twoDigits(_ value: Int) -> String {
        value < 10 ? "0\(value)" : "\(value)"
    }
}
```

A dictionary from minute to count works too, and is what you'd reach for if the keys weren't so few. Notice how much of the code exists because of an answer in the table: the optional return, the byte checks, the strict `>`, the two-digit formatting. None of it would be there if you'd started coding after the first sentence.

</Approach>
