Decide whether a year is a leap year, a year with a 29th of February.

`LeapYearRule.isLeapYear(_ year: Int) -> Bool`

The Gregorian calendar's rule has three parts:

1. A year divisible by 4 is a leap year,
2. **except** a year divisible by 100, which isn't,
3. **except** a year divisible by 400, which is after all.

## Examples

| Input | Output | Why |
| --- | --- | --- |
| `2024` | `true` | divisible by 4 |
| `2023` | `false` | not divisible by 4 |
| `1900` | `false` | divisible by 100, but not by 400 |
| `2000` | `true` | divisible by 400 |

## Constraints

- `1 ≤ year ≤ 9999`

<Hints>
<Hint>
"Divisible by 4" means `year % 4 == 0`.
</Hint>
<Hint>
The rules are exceptions to each other, so the order you check them in matters. Which rule is the most specific?
</Hint>
<Hint>
Check 400 first, then 100, then 4. Each `else if` can rely on the earlier checks having failed.
</Hint>
</Hints>

## Solutions

<Approach title="Most specific rule first" time="O(1)" space="O(1)">

An `if` / `else if` chain, strictest rule at the top. If the year is divisible by 400 it's a leap year, whatever else is true. Otherwise, if it's divisible by 100 it isn't. Otherwise, divisibility by 4 decides.

```swift
public enum LeapYearRule {
    public static func isLeapYear(_ year: Int) -> Bool {
        if year % 400 == 0 {
            return true
        } else if year % 100 == 0 {
            return false
        } else {
            return year % 4 == 0
        }
    }
}
```

Checking 4 first would be the classic bug: 1900 is divisible by 4, so the chain would stop there and wrongly say `true`.

</Approach>

<Approach title="One combined condition" time="O(1)" space="O(1)">

The same rule as a single `Bool` expression: divisible by 4 and not by 100, or divisible by 400.

```swift
public static func isLeapYear(_ year: Int) -> Bool {
    (year % 4 == 0 && year % 100 != 0) || year % 400 == 0
}
```

A function whose body is a single expression can leave out `return`. Shorter, but the chain above is easier to check against the rule as it's written.

</Approach>
