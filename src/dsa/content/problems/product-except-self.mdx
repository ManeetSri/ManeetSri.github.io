Return an array where element `i` is the product of every element of `numbers` **except** `numbers[i]`. Don't use division, and aim for O(n) time.

`ProductExceptSelf.products(of numbers: [Int]) -> [Int]`

## Examples

| Input | Output |
| --- | --- |
| `[2, 3, 4, 5]` | `[60, 40, 30, 24]` |
| `[-1, 2, -3]` | `[-6, 3, -2]` |
| `[1, 0, 3, 4]` | `[0, 12, 0, 0]` |
| `[0, 2, 0]` | `[0, 0, 0]` |
| `[9]` | `[1]` |
| `[]` | `[]` |

For a single element, "everything else" is nothing at all, and the product of nothing is `1`.

## Constraints

- `0 ≤ numbers.count ≤ 100,000`
- The product of any selection of the numbers fits in an `Int`.
- No division. O(n) time; for the full solution, O(1) extra space besides the array you return.

<Hints>
<Hint>
Dividing the total by each element breaks as soon as there's a zero. Instead, split "everything except `i`" into two parts: everything to the left of `i`, and everything to the right of it.
</Hint>
<Hint>
Build `left[i]`, the product of `numbers[0..<i]`, starting from `left[0] = 1`. Build `right[i]` the same way from the other end. The answer at `i` is `left[i] * right[i]`.
</Hint>
<Hint>
To drop the extra arrays, write the left products straight into the answer. Then walk from the right with a single running `suffix` product, multiplying it into each answer **before** multiplying `numbers[i]` into it.
</Hint>
</Hints>

## Solutions

<Approach title="Left and right product arrays" time="O(n)" space="O(n)">

Two prefix-style arrays, one from each end. Each starts at `1`, the product of nothing, which handles the first and last positions without special cases.

```swift
public static func products(of numbers: [Int]) -> [Int] {
    let n = numbers.count
    var left = Array(repeating: 1, count: n)
    var right = Array(repeating: 1, count: n)
    for i in stride(from: 1, to: n, by: 1) {
        left[i] = left[i - 1] * numbers[i - 1]
    }
    for i in stride(from: n - 2, through: 0, by: -1) {
        right[i] = right[i + 1] * numbers[i + 1]
    }
    return (0..<n).map { left[$0] * right[$0] }
}
```

`stride(from: 1, to: n, by: 1)` is used rather than `1..<n` because `1..<0` would crash for an empty array, while the stride produces nothing.

</Approach>

<Approach title="Reuse the answer array" time="O(n)" space="O(1) extra">

The first pass stores the left products in the answer. The second pass never needs the whole `right` array, only one value at a time, so a running `suffix` replaces it. In both passes, each position is used before its own number joins the running product, which keeps `numbers[i]` out of `answer[i]`.

```swift
public enum ProductExceptSelf {
    public static func products(of numbers: [Int]) -> [Int] {
        let n = numbers.count
        var answer = Array(repeating: 1, count: n)
        var prefix = 1
        for i in 0..<n {
            answer[i] = prefix
            prefix *= numbers[i]
        }
        var suffix = 1
        for i in stride(from: n - 1, through: 0, by: -1) {
            answer[i] *= suffix
            suffix *= numbers[i]
        }
        return answer
    }
}
```

Zeros need no special handling. With one zero, every other position's product includes it, and the zero's own position gets the product of everything else. With two or more zeros, every answer is `0`.

</Approach>
