Given a list of words, return the `k` most frequent ones, most frequent first. Words that appear the same number of times go in alphabetical order. If there are fewer than `k` different words, return all of them, in the same order.

`WordFrequencyRanking.mostFrequent(_ words: [String], count k: Int) -> [String]`

## Examples

| `words` | `k` | Returns |
| --- | --- | --- |
| `["apple", "banana", "apple", "cherry", "banana", "apple"]` | `2` | `["apple", "banana"]` |
| `["pear", "fig", "kiwi", "fig", "pear", "kiwi", "date"]` | `2` | `["fig", "kiwi"]` |
| `["zebra", "zebra", "aardvark"]` | `2` | `["zebra", "aardvark"]` |
| `["b", "a", "b"]` | `10` | `["b", "a"]` |
| `[]` | `3` | `[]` |

In the second example, fig, kiwi and pear each appear twice. They tie, so alphabetical order decides, and only the first two are returned.

## Constraints

- `0 ≤ words.count ≤ 100,000`
- Every word is non-empty and uses only lowercase letters `a` to `z`.
- `0 ≤ k ≤ 100,000`

<Hints>
<Hint>
Split the problem in two: first count how many times each word appears, then put the different words in order and take the first `k`.
</Hint>
<Hint>
Counting is a job for `reduce(into:)` with a `[String: Int]` dictionary and `tally[word, default: 0] += 1`. Then `counts.keys` gives you each different word once.
</Hint>
<Hint>
Sort the keys with a two-rule closure: the bigger count first, and for equal counts, the alphabetically smaller word first. `prefix(k)` takes at most `k` elements, so it handles a large `k` for you. Wrap it in `Array(...)`.
</Hint>
</Hints>

## Solutions

<Approach title="Brute force: count each word by scanning" time="O(n · u)" space="O(u)">

Here n is the number of words and u the number of different words. For each different word, count its appearances by scanning the whole list. It's correct, but with 100,000 words that are mostly different, that's billions of steps. The work being repeated is the scanning: every count walks the whole list again.

```swift
public static func mostFrequent(_ words: [String], count k: Int) -> [String] {
    var distinct: [String] = []
    for word in words where !distinct.contains(word) {
        distinct.append(word)
    }
    let ranked = distinct.sorted { first, second in
        let firstCount = words.count(where: { $0 == first })
        let secondCount = words.count(where: { $0 == second })
        if firstCount != secondCount {
            return firstCount > secondCount
        }
        return first < second
    }
    return Array(ranked.prefix(k))
}
```

It's even worse than it looks: `distinct.contains` is a hidden loop, and the sort recounts both words on every comparison.

</Approach>

<Approach title="Count once, then sort the different words" time="O(n + u log u)" space="O(u)">

Count every word in one pass with `reduce(into:)`, so each count is ready to look up. Then sort only the u different words, using the counts as the first rule and the words themselves to break ties.

```swift
public enum WordFrequencyRanking {
    public static func mostFrequent(_ words: [String], count k: Int) -> [String] {
        let counts = words.reduce(into: [String: Int]()) { tally, word in
            tally[word, default: 0] += 1
        }
        let ranked = counts.keys.sorted { first, second in
            let firstCount = counts[first]!
            let secondCount = counts[second]!
            if firstCount != secondCount {
                return firstCount > secondCount       // more frequent first
            }
            return first < second                     // then A to Z
        }
        return Array(ranked.prefix(k))
    }
}
```

The `!` is safe here: every key came from `counts`, so looking it up always succeeds. Counting is O(n), sorting the keys is O(u log u), and the dictionary holds u entries. In Part V you'll meet a **heap**, which finds the top `k` without sorting all u words.

</Approach>
