A grid of numbers is sorted so that reading it row by row, left to right, gives one increasing list: each row is sorted, and each row starts with a value bigger than the last value of the row above. Return the row and column of `target`, or `nil` if it isn't in the grid.

`SortedMatrixSearch.position(of target: Int, in grid: [[Int]]) -> (row: Int, column: Int)?`

Aim for O(log(rows × columns)).

## Examples

With this grid:

| | col 0 | col 1 | col 2 | col 3 |
| --- | --- | --- | --- | --- |
| **row 0** | 2 | 4 | 7 | 11 |
| **row 1** | 14 | 18 | 21 | 25 |
| **row 2** | 30 | 33 | 41 | 49 |

| `target` | Output |
| --- | --- |
| `21` | `(row: 1, column: 2)` |
| `2` | `(row: 0, column: 0)` |
| `49` | `(row: 2, column: 3)` |
| `26` | `nil` |
| `1` | `nil` |

An empty grid, `[]`, or a grid of empty rows, `[[]]`, holds nothing: return `nil`.

## Constraints

- `0 ≤ rows`, `0 ≤ columns`, and `rows × columns ≤ 1,000,000`
- Every row has the same length.
- All values are distinct, and the grid is sorted as described.

<Hints>
<Hint>
This isn't the staircase grid from M19, where only rows and columns were sorted. Here the whole grid, read row by row, is one sorted list, so you can binary search it as if it were a flat array.
</Hint>
<Hint>
Number the cells 0 to `rows × columns − 1` in reading order. With `columns` columns, cell number i is in row `i / columns` and column `i % columns`.
</Hint>
<Hint>
Run an ordinary closed binary search over cell numbers, converting each middle number to a row and column to read its value. Check for an empty grid, or an empty first row, before computing `columns`.
</Hint>
</Hints>

## Solutions

<Approach title="Staircase search" time="O(rows + columns)" space="O(1)">

The staircase from M19 works on this grid too, since its rows and columns are sorted. Start at the top-right corner: if the value is too big, move left; if it's too small, move down. It ignores the stronger promise, though, and on a grid 100,000 rows tall it takes up to 100,000 steps per search.

```swift
public static func position(of target: Int, in grid: [[Int]]) -> (row: Int, column: Int)? {
    guard let firstRow = grid.first, !firstRow.isEmpty else { return nil }
    var row = 0
    var column = firstRow.count - 1
    while row < grid.count && column >= 0 {
        let value = grid[row][column]
        if value == target { return (row, column) }
        if value > target { column -= 1 } else { row += 1 }
    }
    return nil
}
```

</Approach>

<Approach title="Binary search a virtual list" time="O(log(rows × columns))" space="O(1)">

Treat the grid as one sorted list without building it. Each probe turns a cell number into a row and column with `/` and `%`. A million cells take about 20 probes.

```swift
public enum SortedMatrixSearch {
    public static func position(of target: Int, in grid: [[Int]]) -> (row: Int, column: Int)? {
        guard let firstRow = grid.first, !firstRow.isEmpty else { return nil }
        let columns = firstRow.count
        var low = 0
        var high = grid.count * columns - 1
        while low <= high {
            let mid = low + (high - low) / 2
            let value = grid[mid / columns][mid % columns]
            if value == target {
                return (mid / columns, mid % columns)
            } else if value < target {
                low = mid + 1
            } else {
                high = mid - 1
            }
        }
        return nil
    }
}
```

Two binary searches also work: one over the first column to find the last row starting at or below `target`, then one inside that row. It's the same complexity, with a little more code.

</Approach>
