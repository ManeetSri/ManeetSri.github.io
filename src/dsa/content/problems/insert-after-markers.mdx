After every node holding `marker`, insert a new node holding `value`. Change the list in place: keep every original node, in its original order, and link each new node in straight after its marker. The head never changes, so the function returns nothing.

`InsertAfterMarkers.insert(_ value: Int, afterEvery marker: Int, in head: ListNode?)`

Only the original nodes count as markers. A new node is never a marker, even when `value` equals `marker`.

## Examples

| List before | `marker` | `value` | List after |
| --- | --- | --- | --- |
| `1 -> 2 -> 3 -> 2` | `2` | `9` | `1 -> 2 -> 9 -> 3 -> 2 -> 9` |
| `4` | `4` | `7` | `4 -> 7` |
| `5 -> 5` | `5` | `5` | `5 -> 5 -> 5 -> 5` |
| `1 -> 3` | `2` | `0` | `1 -> 3` |
| empty (`nil`) | `1` | `1` | empty |

In the third example each original `5` gets one new `5` after it. If the walk treated the new node as a marker too, it would insert after it, then after that one, and never finish.

## Constraints

- 0 to 20,000 nodes. Values are any `Int`.
- O(n) time. Apart from the new nodes, O(1) extra space.

<Hints>
<Hint>
Walk the list with `var current = head` and `while let node = current`. Every pass must move `current` on, or the loop never ends.
</Hint>
<Hint>
Inserting after `node` takes two steps, in this order: create the new node pointing at `node.next`, then set `node.next` to the new node. Swap them and the new node points at itself, and the rest of the list is lost.
</Hint>
<Hint>
After inserting, the next node to look at is the one **after** the new node, not the new node itself. Moving to `newNode.next` skips it, which is what stops a new node from being treated as a marker.
</Hint>
</Hints>

## Solutions

<Approach title="Collect the markers, then insert" time="O(n)" space="O(n)">

First walk the list and collect every marker node in an array. Then insert after each one. Because the array only ever held original nodes, a new node can't be mistaken for a marker. It works, but the array is extra space the walk doesn't need.

```swift
public static func insert(_ value: Int, afterEvery marker: Int, in head: ListNode?) {
    var markers: [ListNode] = []
    var current = head
    while let node = current {
        if node.value == marker {
            markers.append(node)
        }
        current = node.next
    }
    for node in markers {
        node.next = ListNode(value, next: node.next)
    }
}
```

</Approach>

<Approach title="Insert and skip, in one walk" time="O(n)" space="O(1) extra">

Each insertion changes two arrows and costs O(1), because the walk is already holding the node to insert after. Jumping straight past the new node keeps the walk on original nodes only.

```swift
import DSAKit

public enum InsertAfterMarkers {
    public static func insert(_ value: Int, afterEvery marker: Int, in head: ListNode?) {
        var current = head
        while let node = current {
            if node.value == marker {
                let added = ListNode(value, next: node.next)   // grab the rest of the list first
                node.next = added
                current = added.next                           // skip the node just added
            } else {
                current = node.next
            }
        }
    }
}
```

</Approach>
