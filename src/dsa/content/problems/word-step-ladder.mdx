A word ladder turns one word into another by changing **one letter at a time**, and every word along the way must be a real word. Given a `start` word, a `target` and the list of allowed `words`, return the fewest steps (letter changes) that turn `start` into `target`, or `-1` if no ladder exists.

Every word after `start`, including `target`, must be in `words`; `start` itself doesn't have to be. If `start` and `target` are the same word, the answer is `0`.

`WordStepLadder.fewestSteps(from start: String, to target: String, words: [String]) -> Int`

## Examples

| `start` | `target` | `words` | Returns |
| --- | --- | --- | --- |
| `"cold"` | `"warm"` | `["cord", "card", "ward", "warm", "worm", "word", "wore", "core"]` | `4` |
| `"ape"` | `"man"` | `["apt", "opt", "oat", "mat", "man"]` | `5` |
| `"ship"` | `"shop"` | `["chip", "shot"]` | `-1` |
| `"cat"` | `"dog"` | `["bat", "bag", "dog"]` | `-1` |
| `"same"` | `"same"` | `[]` | `0` |

In the first, cold → cord → card → ward → warm (or cold → cord → word → worm → warm). All four letters differ, so no ladder can be shorter. In the second, every step changes one letter: ape → apt → opt → oat → mat → man. In the third, "shop" is one letter from "ship", but it isn't in the list.

## Constraints

- All words, including `start` and `target`, have the same length, from 1 to 10, and use only the letters a to z.
- `0 ≤ words.count ≤ 30,000`, and the list may contain duplicates.
- The tests hide a 50-step ladder among 30,000 words. Comparing every pair of words there means about 450 million comparisons, far too slow.

<Hints>
<Hint>
The words are the vertices of a graph, and two words are joined when they differ in exactly one letter. BFS from `start` finds the fewest steps. The graph isn't given to you: you discover each word's neighbours when you dequeue it.
</Hint>
<Hint>
Comparing a word with every other word to find its neighbours costs O(n) per word. Instead, for each position, try all 26 letters and check whether the result is in a `Set` of the words: 26 × L lookups per word.
</Hint>
<Hint>
Or group the words by **wildcard pattern** before the search: "cold" belongs to `*old`, `c*ld`, `co*d` and `col*`. Two words are neighbours exactly when they share a pattern. Once a pattern's bucket has been scanned, every word in it has been seen, so empty it.
</Hint>
</Hints>

## Solutions

<Approach title="Compare every pair" time="O(n² · L)" space="O(n²) for the edges">

Build the graph by comparing every pair of words letter by letter, then BFS. The comparisons dominate: about n²/2 of them, each costing up to L character checks.

</Approach>

<Approach title="Try every letter at every position" time="O(n · L² · 26)" space="O(n · L)">

When a word is dequeued, make each of its 26 × L one-letter variants and look each one up in a `Set` of the words (each lookup hashes a string of length L). Remove words from the set when they're enqueued, so the set doubles as the visited mark. This is often the quickest to write.

</Approach>

<Approach title="BFS over wildcard buckets" time="O(n · L²)" space="O(n · L)">

Each word is filed under its L patterns before the search. Neighbours are then the other words in a word's buckets, and emptying a bucket after scanning it means no bucket is scanned twice.

```swift
public enum WordStepLadder {
    public static func fewestSteps(from start: String, to target: String, words: [String]) -> Int {
        if start == target { return 0 }
        let dictionary = Set(words)
        guard dictionary.contains(target) else { return -1 }

        var buckets: [String: [String]] = [:]
        for word in dictionary {
            for pattern in patterns(of: word) {
                buckets[pattern, default: []].append(word)
            }
        }

        var steps: [String: Int] = [start: 0]
        var queue = [start]
        var head = 0
        while head < queue.count {
            let word = queue[head]
            head += 1
            let nextSteps = steps[word]! + 1
            for pattern in patterns(of: word) {
                for next in buckets[pattern] ?? [] where steps[next] == nil {
                    if next == target { return nextSteps }
                    steps[next] = nextSteps
                    queue.append(next)
                }
                buckets[pattern] = nil                   // everything in it is seen now
            }
        }
        return -1
    }

    /// The word with each letter in turn replaced by "*"
    private static func patterns(of word: String) -> [String] {
        let letters = Array(word)
        return letters.indices.map { index in
            var pattern = letters
            pattern[index] = "*"
            return String(pattern)
        }
    }
}
```

`start` doesn't need to be in the dictionary: its patterns are only used to look buckets up. Searching from both ends at once, as in [Bidirectional BFS](/dsa/learn/gt-bidirectional), explores far fewer words when the dictionary is large and both ends are known.

</Approach>
