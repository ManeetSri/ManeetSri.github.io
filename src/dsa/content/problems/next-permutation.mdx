List every arrangement of some numbers in dictionary order and each one has a successor: the next arrangement in the list. Rearrange `numbers` **in place** into its successor and return `true`. If `numbers` is already the last arrangement, wrap round: rearrange it into the first (smallest) arrangement and return `false`.

`NextPermutation.advance(_ numbers: inout [Int]) -> Bool`

Dictionary order compares arrays the way a dictionary compares words: by the first position where they differ. Values can repeat, and repeated arrangements count once.

## Examples

| `numbers` before | Returns | `numbers` after |
| --- | --- | --- |
| `[1, 2, 3]` | `true` | `[1, 3, 2]` |
| `[1, 3, 2]` | `true` | `[2, 1, 3]` |
| `[1, 5, 8, 4, 7, 6, 5, 3, 1]` | `true` | `[1, 5, 8, 5, 1, 3, 4, 6, 7]` |
| `[1, 1, 2]` | `true` | `[1, 2, 1]` |
| `[3, 2, 1]` | `false` | `[1, 2, 3]` |
| `[5, 5, 5]` | `false` | `[5, 5, 5]` |

Calling `advance` on `[1, 2, 3]` until it returns `false` visits all six arrangements and ends back at `[1, 2, 3]`.

## Constraints

- `0 ≤ numbers.count ≤ 100,000`
- O(n) time and O(1) extra space. Generating all arrangements is far too slow: there are n! of them.

<Hints>
<Hint>
Look at the end of the array. If the last few elements are in non-increasing order, like `7, 6, 5, 3, 1`, they're already arranged as large as they can be. To get a bigger arrangement you must change something to their left.
</Hint>
<Hint>
Find the **pivot**: the rightmost index `i` with `numbers[i] < numbers[i + 1]`. If there's none, the whole array is non-increasing: it's the last arrangement, so reverse it and return `false`.
</Hint>
<Hint>
Swap the pivot with the rightmost element to its right that's strictly bigger than it. That makes the smallest possible increase at the pivot. The part after the pivot is still non-increasing, so reverse it to make it as small as possible.
</Hint>
</Hints>

## Solutions

<Approach title="Pivot, swap, reverse" time="O(n)" space="O(1)">

Three steps, each a single scan:

1. **Find the pivot** from the right: the first place where a value is smaller than the one after it. Everything after the pivot is non-increasing.
2. **Swap** the pivot with the rightmost element bigger than it. Because the suffix is non-increasing, scanning from the right finds the smallest such element.
3. **Reverse the suffix.** It's still non-increasing after the swap, so reversing turns it into its smallest arrangement.

```swift
public enum NextPermutation {
    public static func advance(_ numbers: inout [Int]) -> Bool {
        let count = numbers.count

        // Reverses numbers[low...] in place
        func reverseSuffix(from low: Int) {
            var left = low
            var right = count - 1
            while left < right {
                numbers.swapAt(left, right)
                left += 1
                right -= 1
            }
        }

        // 1. The pivot: the rightmost index with numbers[pivot] < numbers[pivot + 1]
        var pivot = count - 2
        while pivot >= 0 && numbers[pivot] >= numbers[pivot + 1] {
            pivot -= 1
        }
        guard pivot >= 0 else {
            reverseSuffix(from: 0)        // the last arrangement: wrap to the first
            return false
        }

        // 2. The rightmost element bigger than the pivot (the suffix is non-increasing)
        var successor = count - 1
        while numbers[successor] <= numbers[pivot] {
            successor -= 1
        }
        numbers.swapAt(pivot, successor)

        // 3. The suffix is still non-increasing: reverse it to make it as small as possible
        reverseSuffix(from: pivot + 1)
        return true
    }
}
```

The `>=` and `<=` comparisons are what make repeated values work. With `>` in step 1, `[1, 2, 2]` would stop between the two 2s. That isn't a real pivot: nothing after it is bigger, so step 2 would run off the front of the array and crash.

For an empty or one-element array, `pivot` starts at −2 or −1, the loop doesn't run, and the guard reverses an array that's too short to change. Both cases return `false`.

</Approach>
