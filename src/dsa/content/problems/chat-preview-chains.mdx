A messaging app keeps each chat's messages in a dictionary, oldest first: `chats["family"]` is the list of messages in the family chat. The chat list shows a preview built from each chat's **newest** message. Write three small helpers for it. Each can meet a chat that doesn't exist, or one that has no messages yet, and none of them may crash.

- `ChatPreviewChains.newestMessage(in chat: String, from chats: [String: [String]]) -> String?` returns the chat's newest message, or `nil` if there isn't one.
- `ChatPreviewChains.newestLength(in chat: String, from chats: [String: [String]]) -> Int` returns how many characters the newest message has, or 0 if there isn't one.
- `ChatPreviewChains.newestMentions(_ name: String, in chat: String, from chats: [String: [String]]) -> Bool` returns `true` when the newest message contains `"@"` followed directly by `name`, such as `"@Ana"`, and `false` otherwise, including when there's no newest message.

## Examples

With `chats = ["family": ["Dinner at 7?", "@Ana can you bring dessert"], "work": ["Standup moved"], "book club": []]`:

| Call | Returns | Why |
| --- | --- | --- |
| `newestMessage(in: "work", from: chats)` | `"Standup moved"` | the only message is the newest |
| `newestMessage(in: "book club", from: chats)` | `nil` | the chat has no messages yet |
| `newestMessage(in: "gym", from: chats)` | `nil` | there's no such chat |
| `newestLength(in: "work", from: chats)` | `13` | the space counts as a character |
| `newestLength(in: "gym", from: chats)` | `0` | nothing to count |
| `newestMentions("Ana", in: "family", from: chats)` | `true` | the newest message contains `"@Ana"` |
| `newestMentions("Ana", in: "work", from: chats)` | `false` | no `"@Ana"` in `"Standup moved"` |
| `newestMentions("Ana", in: "gym", from: chats)` | `false` | no message at all |

## Constraints

- At most 1,000 chats, each with at most 10,000 messages of at most 500 characters.
- Chat names, messages and `name` are case-sensitive: `"@ana"` doesn't mention `"Ana"`.
- `name` is never empty. Only the newest message counts, even if an older one mentions `name`.

<Hints>
<Hint>
Looking up `chats[chat]` gives a `[String]?`, and an array's `last` is optional too, because the array might be empty. `chats[chat]?.last` chains the two: it's nil if either step finds nothing.
</Hint>
<Hint>
Add another link for the count: `chats[chat]?.last?.count`. A chain always gives an optional, so finish it with `?? 0` to get a plain `Int`.
</Hint>
<Hint>
`== true` turns a `Bool?` into a `Bool`, because nil isn't equal to `true`. So `chats[chat]?.last?.contains("@\(name)") == true` handles a missing chat, an empty chat and a message without the mention all at once.
</Hint>
</Hints>

## Solutions

<Approach title="One chain per question" time="O(m)" space="O(1)">

Each helper is a single optional chain. The first link looks up the chat, the second takes its newest message, and any further link asks something about that message. If any link finds nothing, the rest of the chain is skipped, and the end of the line decides what "nothing" should mean: `nil` itself, 0, or `false`.

```swift
public enum ChatPreviewChains {
    public static func newestMessage(in chat: String, from chats: [String: [String]]) -> String? {
        return chats[chat]?.last
    }

    public static func newestLength(in chat: String, from chats: [String: [String]]) -> Int {
        return chats[chat]?.last?.count ?? 0
    }

    public static func newestMentions(_ name: String, in chat: String, from chats: [String: [String]]) -> Bool {
        return chats[chat]?.last?.contains("@\(name)") == true
    }
}
```

The dictionary lookup and `last` are both quick. Counting the characters of the newest message, or searching it for the mention, takes time proportional to its length *m*.

</Approach>

<Approach title="Reuse the first helper" time="O(m)" space="O(1)">

The second and third helpers both start with "the newest message, if any", which the first helper already gives you. Building on it keeps each line short, and `?? false` is another way to finish a chain that ends in a `Bool?`:

```swift
public enum ChatPreviewChains {
    public static func newestMessage(in chat: String, from chats: [String: [String]]) -> String? {
        return chats[chat]?.last
    }

    public static func newestLength(in chat: String, from chats: [String: [String]]) -> Int {
        return newestMessage(in: chat, from: chats)?.count ?? 0
    }

    public static func newestMentions(_ name: String, in chat: String, from chats: [String: [String]]) -> Bool {
        return newestMessage(in: chat, from: chats)?.contains("@\(name)") ?? false
    }
}
```

Notice that none of the three versions ever distinguishes "no such chat" from "an empty chat". The chain flattens both into one nil, which is exactly what a preview needs. When the difference matters, unwrap the lookup on its own first.

</Approach>
