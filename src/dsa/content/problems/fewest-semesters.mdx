A university offers `courseCount` courses, labelled 0 to `courseCount - 1`. Each pair `[before, after]` means `before` must be passed in an **earlier** semester than `after`. There's no limit on how many courses you take in one semester. Return the fewest semesters needed to pass every course, or -1 if it can't be done.

`FewestSemesters.minimum(courseCount: Int, prerequisites: [[Int]]) -> Int`

## Examples

| `courseCount` | `prerequisites` | Returns | Why |
| --- | --- | --- | --- |
| 3 | `[[0, 2], [1, 2]]` | 2 | 0 and 1 together, then 2 |
| 4 | `[[0, 1], [1, 2], [2, 3]]` | 4 | a chain: one course per semester |
| 5 | `[[0, 1], [1, 2], [0, 3], [3, 4], [4, 2]]` | 4 | 0; then 1 and 3; then 4; then 2 |
| 6 | `[[5, 0], [0, 1], [2, 3]]` | 3 | separate groups run side by side |
| 7 | `[]` | 1 | everything at once |
| 2 | `[[0, 1], [1, 0]]` | -1 | a cycle |

## Constraints

- `1 ≤ courseCount ≤ 100,000` and `0 ≤ prerequisites.count ≤ 200,000`.
- Labels are in range. A pair may appear more than once, and `[a, a]` is possible (that course can never be taken).
- The tests use 100,000 courses, so the answer must be O(n + p). Every chain of prerequisites in them is shorter than 1,000 courses.

<Hints>
<Hint>
Taking every course you're allowed to take, as early as possible, is never worse than holding one back. So semester 1 is every course with no prerequisites.
</Hint>
<Hint>
Run Kahn's algorithm a whole layer at a time: process all of this semester's courses, and collect the courses whose last prerequisite was among them. Those are next semester. Count the layers.
</Hint>
<Hint>
If the layers run out before every course has been taken, the rest are stuck behind a cycle: return -1. The answer is also the number of courses on the longest chain of prerequisites.
</Hint>
</Hints>

## Solutions

<Approach title="Kahn's algorithm in layers" time="O(n + p)" space="O(n + p)">

Each course is in exactly one layer, and each pair is used once.

```swift
public enum FewestSemesters {
    public static func minimum(courseCount: Int, prerequisites: [[Int]]) -> Int {
        var unlocks = Array(repeating: [Int](), count: courseCount)
        var waitingOn = Array(repeating: 0, count: courseCount)
        for pair in prerequisites {
            unlocks[pair[0]].append(pair[1])
            waitingOn[pair[1]] += 1
        }
        var semester = (0..<courseCount).filter { waitingOn[$0] == 0 }
        var semesters = 0
        var taken = 0
        while !semester.isEmpty {
            semesters += 1
            taken += semester.count
            var next: [Int] = []
            for course in semester {
                for after in unlocks[course] {
                    waitingOn[after] -= 1
                    if waitingOn[after] == 0 {
                        next.append(after)
                    }
                }
            }
            semester = next
        }
        return taken == courseCount ? semesters : -1
    }
}
```

A course lands in semester k + 1 exactly when its latest prerequisite is in semester k, which is the earliest it could ever be taken.

</Approach>

<Approach title="Longest chain with memoised DFS" time="O(n + p)" space="O(n + p)">

The semester of a course is 1 plus the largest semester among its prerequisites, or 1 if it has none. Compute that with a memoised depth-first search over the prerequisites, using three colours to spot a cycle, and return the largest value. It's the same answer seen as a longest path in a DAG, and its recursion depth is the longest chain, so it relies on the tests' promise that chains stay short.

</Approach>
