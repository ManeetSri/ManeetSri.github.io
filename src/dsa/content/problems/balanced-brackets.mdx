Check whether the brackets in a piece of text are balanced: every opening bracket is closed by a bracket of the same kind, and pairs are properly nested.

`BracketCheck.isBalanced(_ text: String) -> Bool`

There are three kinds: `()`, `[]` and `{}`. Every other character is ignored, so the text can be a line of code.

## Examples

| `text` | Result |
| --- | --- |
| `"{[()()]}"` | `true` |
| `"if (a[i] > b) { print(a) }"` | `true` |
| `""` | `true` |
| `"([)]"` | `false` |
| `"(()"` | `false` |
| `"())("` | `false` |

In `"([)]"`, every bracket has a partner of the same kind, but the `)` closes while the `[` opened after it is still open.

## Constraints

- `0 ≤ text.count ≤ 200,000`
- Aim for O(n). The tests include 100,000 nested openers followed by their closers.

<Hints>
<Hint>
Counting each kind separately can't work: `"([)]"` has balanced counts. When a closing bracket arrives, which opening bracket must it match?
</Hint>
<Hint>
The most recent one that's still open. Keep the open brackets on a stack: push openers, and for each closer, pop and check the kinds match.
</Hint>
<Hint>
Two ways to fail are easy to miss: a closer when the stack is empty (`popLast()` gives `nil`), and openers left on the stack at the end.
</Hint>
</Hints>

## Solutions

<Approach title="A stack of open brackets" time="O(n)" space="O(n)">

A dictionary from each closer to its opener keeps the matching in one place. Comparing `open.popLast()`, an optional, with `opener[character]` catches both an empty stack and the wrong kind in one test.

```swift
public enum BracketCheck {
    private static let opener: [Character: Character] = [")": "(", "]": "[", "}": "{"]

    public static func isBalanced(_ text: String) -> Bool {
        var open: [Character] = []
        for character in text {
            switch character {
            case "(", "[", "{":
                open.append(character)
            case ")", "]", "}":
                guard open.popLast() == opener[character] else {
                    return false
                }
            default:
                continue
            }
        }
        return open.isEmpty
    }
}
```

Each character is pushed or popped at most once. In the worst case, a string of openers, the stack holds everything: O(n) space.

</Approach>
