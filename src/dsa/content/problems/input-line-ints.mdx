Judges give you input as lines of text. Write the two helpers almost every solution needs: turn one line into its integers, and read the classic "count, then that many numbers" format. Both return `nil` when the text doesn't match.

`InputLineInts.integers(in line: String) -> [Int]?` and `InputLineInts.readArray(from lines: [String]) -> [Int]?`

**`integers(in:)`** splits the line wherever there are one or more spaces or tabs and converts every piece with `Int(_:)`. If any piece isn't a valid `Int`, return `nil`. A line with no pieces gives `[]`.

**`readArray(from:)`** reads two lines: `lines[0]` must hold exactly one integer `n ≥ 0`, and `lines[1]` must hold exactly `n` integers. Return those integers, or `nil` if anything doesn't match. When `n` is 0, the second line may be missing or blank. Lines after the second are ignored.

These take strings rather than calling `readLine()` so they can be tested. In a real solution you'd pass them lines you've read.

## Examples

| Call | Result |
| --- | --- |
| `integers(in: "3 9 4")` | `[3, 9, 4]` |
| `integers(in: "  7   8  ")` | `[7, 8]` |
| `integers(in: "")` | `[]` |
| `integers(in: "1 two 3")` | `nil` |
| `integers(in: "4.5")` | `nil` |
| `readArray(from: ["3", "10 20 30"])` | `[10, 20, 30]` |
| `readArray(from: ["0"])` | `[]` |
| `readArray(from: ["3", "1 2"])` | `nil` |

## Constraints

- Lines have at most 10⁶ characters.
- Pieces that don't fit in an `Int` count as invalid.

<Hints>
<Hint>
`line.split(whereSeparator: { $0 == " " || $0 == "\t" })` cuts at runs of spaces and tabs, and never returns empty pieces.
</Hint>
<Hint>
`compactMap` would silently drop bad pieces, which isn't what you want here. Loop over the pieces and `return nil` as soon as `Int(piece)` fails.
</Hint>
<Hint>
For `readArray`, reuse `integers(in:)` on both lines. Treat a missing second line as `""`, which gives `[]`: then the rule "exactly `n` numbers" handles the `n = 0` case for free.
</Hint>
</Hints>

## Solutions

<Approach title="Split, convert, and bail out on the first failure" time="O(L)" space="O(k)">

Each character is looked at a constant number of times, so the time is proportional to the input's length, L. The result holds the k numbers found.

```swift
public enum InputLineInts {
    public static func integers(in line: String) -> [Int]? {
        var result: [Int] = []
        for piece in line.split(whereSeparator: { $0 == " " || $0 == "\t" }) {
            guard let number = Int(piece) else { return nil }
            result.append(number)
        }
        return result
    }

    public static func readArray(from lines: [String]) -> [Int]? {
        guard let first = lines.first,
              let header = integers(in: first),
              header.count == 1,
              header[0] >= 0 else {
            return nil
        }
        let count = header[0]
        let second = lines.count > 1 ? lines[1] : ""
        guard let numbers = integers(in: second), numbers.count == count else {
            return nil
        }
        return numbers
    }
}
```

A guard with several conditions separated by commas passes only if every one of them does, and it can unwrap optionals along the way, as `let header = integers(in: first)` does here.

</Approach>
