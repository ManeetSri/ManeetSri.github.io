Rugs have been thrown down on the floor of a huge exhibition hall, many of them overlapping. How much of the floor is covered by at least one rug?

`CoveredFloorArea.coveredArea(_ rugs: [[Int]]) -> Int`

Each rug is an axis-aligned rectangle `[x1, y1, x2, y2]`, with bottom-left corner (x1, y1) and top-right corner (x2, y2), where `x1 ≤ x2` and `y1 ≤ y2`. A rug with zero width or height covers nothing. Floor covered by several rugs counts once.

## Examples

| `rugs` | Output |
| --- | --- |
| `[[0, 0, 2, 2], [1, 1, 3, 3]]` | `7` |
| `[[0, 2, 6, 4], [2, 0, 4, 6]]` | `20` |
| `[[0, 0, 10, 10], [2, 2, 5, 5]]` | `100` |
| `[[0, 0, 2, 1], [2, 0, 4, 1]]` | `4` |
| `[[1, 1, 1, 5], [3, 2, 7, 2]]` | `0` |
| `[[0, 0, 1000000000, 1000000000]]` | `1000000000000000000` |

The first two squares overlap in a 1 × 1 square, so the area is 4 + 4 − 1. The second example is a plus sign: two 6 × 2 rugs crossing in a 2 × 2 square. In the fourth, the rugs only share an edge. In the fifth, both rugs are flat.

## Constraints

- `0 ≤ rugs.count ≤ 20,000`
- `0 ≤ x1 ≤ x2 ≤ 10⁹` and `0 ≤ y1 ≤ y2 ≤ 10⁹`
- The answer is at most 10¹⁸, which fits in an `Int`.
- One test has 20,000 rugs with about 30,000 distinct y-values: re-measuring every slab at every event takes around a billion steps, which is too slow.

<Hints>
<Hint>
Sweep a vertical line from left to right. Each rug becomes two events: at x1 its y-range starts being covered once more, and at x2 once less. Between two consecutive event positions, the covered length of the line doesn't change, so that strip adds covered length × width.
</Hint>
<Hint>
Only the y-values where rugs have edges matter. Sort the distinct ones and number them: the gaps between neighbours are slabs, and each event adds +1 or −1 to a contiguous range of slabs.
</Hint>
<Hint>
A segment tree over the slabs can do each event in O(log n). Store, for each node, how many rugs cover its whole range, and how much of its range is covered. If the count is positive, the whole range is covered; otherwise the covered length is the sum of the children's (or 0 at a leaf). Every +1 is later undone by a −1 on the same range, so counts never need pushing down.
</Hint>
</Hints>

## Solutions

<Approach title="Compressed grid" time="O(n³)" space="O(n)">

Compress both axes and check every cell of the compressed grid, about 2n by 2n of them, against every rug. It's a reliable way to test a faster version on small inputs, and about 10¹³ steps on the largest test.

</Approach>

<Approach title="Sweep with a cover count per slab" time="O(n²)" space="O(n)">

Compress y, sort the events by x, and keep an array with one cover count per slab. For each event, add the previous strip's area (covered length × width), then update the counts in its range. Each event can touch every slab, so it's O(n²): fine for a few thousand rugs, too slow for the largest test.

</Approach>

<Approach title="Sweep with a segment tree" time="O(n log n)" space="O(n)">

The same sweep, with the slabs in a segment tree that keeps the covered length at its root.

```swift
public enum CoveredFloorArea {
    public static func coveredArea(_ rugs: [[Int]]) -> Int {
        var ys: [Int] = []
        var events: [(x: Int, low: Int, high: Int, change: Int)] = []
        for rug in rugs where rug[0] < rug[2] && rug[1] < rug[3] {
            ys += [rug[1], rug[3]]
            events.append((rug[0], rug[1], rug[3], 1))
            events.append((rug[2], rug[1], rug[3], -1))
        }
        guard !events.isEmpty else { return 0 }
        ys = Array(Set(ys)).sorted()
        var slabOf: [Int: Int] = [:]
        for (index, y) in ys.enumerated() {
            slabOf[y] = index
        }
        events.sort { $0.x < $1.x }

        // Node `node` covers slabs lo..<hi, which span ys[lo] to ys[hi]
        let slabs = ys.count - 1
        var cover = [Int](repeating: 0, count: 4 * slabs)
        var covered = [Int](repeating: 0, count: 4 * slabs)
        func update(_ node: Int, _ lo: Int, _ hi: Int, _ from: Int, _ to: Int, _ change: Int) {
            if to <= lo || hi <= from { return }
            if from <= lo && hi <= to {
                cover[node] += change
            } else {
                let mid = (lo + hi) / 2
                update(2 * node, lo, mid, from, to, change)
                update(2 * node + 1, mid, hi, from, to, change)
            }
            if cover[node] > 0 {
                covered[node] = ys[hi] - ys[lo]
            } else if hi - lo == 1 {
                covered[node] = 0
            } else {
                covered[node] = covered[2 * node] + covered[2 * node + 1]
            }
        }

        var area = 0
        var previousX = events[0].x
        for event in events {
            area += covered[1] * (event.x - previousX)  // the strip since the last event
            previousX = event.x
            update(1, 0, slabs, slabOf[event.low]!, slabOf[event.high]!, event.change)
        }
        return area
    }
}
```

Events at the same x can go in any order: the strip between them has width 0. The nested function captures `cover` and `covered` and changes them in place.

</Approach>
