A maze is a grid where `1` is an open cell and `0` is a wall. A runner starts in the top-left cell and must reach the bottom-right cell, moving one cell at a time down (`D`), left (`L`), right (`R`) or up (`U`), only through open cells, and never visiting the same cell twice on one route. Return every route as its string of moves, in alphabetical order.

`MazeRunnerPaths.paths(_ maze: [[Int]]) -> [String]`

If the start or the exit is a wall, there are no routes. If the maze is a single open cell, the runner is already there, and the one route is the empty string.

## Examples

| `maze` | Output |
| --- | --- |
| `[[1, 0, 0], [1, 1, 0], [0, 1, 1]]` | `["DRDR"]` |
| `[[1, 1], [1, 1]]` | `["DR", "RD"]` |
| `[[1, 1, 1], [1, 1, 1]]` | `["DRR", "DRURD", "RDR", "RRD"]` |
| `[[1, 0], [0, 1]]` | `[]` |
| `[[1]]` | `[""]` |

In the third example, the route `DRURD` goes down, right, back up, right and down again: moving up is allowed as long as no cell is visited twice.

## Constraints

- `1 ≤ maze.count ≤ 6` rows and `1 ≤ maze[i].count ≤ 6` columns, every row the same length.
- There are at most 20,000 routes. An open 5 × 5 maze has 8,512.

<Hints>
<Hint>
Depth-first search from the top-left cell. Keep the moves so far in an array, and a grid of visited cells.
</Hint>
<Hint>
Mark a cell as visited when you step onto it and unmark it when you step back off. Routes may share cells; what they can't do is reuse a cell within one route.
</Hint>
<Hint>
Try the moves in the order D, L, R, U. Because that's alphabetical, and a route stops as soon as it reaches the exit, the routes come out already sorted.
</Hint>
</Hints>

## Solutions

<Approach title="Backtracking with a visited grid" time="exponential in the worst case" space="O(rows · columns)">

Check the exit before marking, so the exit itself never needs marking. The direction table holds each move's letter and offsets.

```swift
public enum MazeRunnerPaths {
    public static func paths(_ maze: [[Int]]) -> [String] {
        guard let columns = maze.first?.count, columns > 0 else { return [] }
        let rows = maze.count
        guard maze[0][0] == 1, maze[rows - 1][columns - 1] == 1 else { return [] }
        let moves: [(letter: Character, dRow: Int, dColumn: Int)] = [("D", 1, 0), ("L", 0, -1), ("R", 0, 1), ("U", -1, 0)]
        var visited = Array(repeating: Array(repeating: false, count: columns), count: rows)
        var route: [Character] = []
        var result: [String] = []

        func walk(_ row: Int, _ column: Int) {
            if row == rows - 1 && column == columns - 1 {
                result.append(String(route))
                return
            }
            visited[row][column] = true                             // choose this cell
            for move in moves {
                let nextRow = row + move.dRow
                let nextColumn = column + move.dColumn
                guard nextRow >= 0, nextRow < rows, nextColumn >= 0, nextColumn < columns,
                      maze[nextRow][nextColumn] == 1, !visited[nextRow][nextColumn] else { continue }
                route.append(move.letter)
                walk(nextRow, nextColumn)                           // explore
                route.removeLast()
            }
            visited[row][column] = false                            // unchoose
        }

        walk(0, 0)
        return result
    }
}
```

Collecting routes in any order and calling `sorted()` at the end is equally correct; the move order only saves that last step.

</Approach>
