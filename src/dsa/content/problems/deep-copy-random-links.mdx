Each node of this list has the usual `next`, plus a `random` link that can point at any node of the same list, itself included, or be `nil`. Make a **deep copy**: a brand-new list with the same values, whose `next` and `random` links point at the matching nodes of the copy, never back into the original. Return the copy's head, and leave the original exactly as it was.

`RandomLinkListCopy.deepCopy(_ head: RandomLinkListCopy.Node?) -> RandomLinkListCopy.Node?`

The node type is given. `random` is `weak`, because the `next` chain already owns every node and a backward `random` would otherwise make a retain cycle:

```swift
public final class Node {
    public var value: Int
    public var next: Node?
    public weak var random: Node?
    public init(_ value: Int) { self.value = value }
}
```

## Examples

Each list is written as values, with the index of each node's `random` target (`nil` for none).

| Original values | Original randoms | Copy |
| --- | --- | --- |
| `[3, 8, 5, 8]` | `[2, 0, nil, 1]` | values `[3, 8, 5, 8]`, randoms `[2, 0, nil, 1]` |
| `[6]` | `[0]` | values `[6]`, random `[0]`: the copy points at itself |
| `[1, 2]` | `[nil, nil]` | values `[1, 2]`, randoms `[nil, nil]` |
| empty | empty | `nil` |

In the first example two nodes hold 8. The copy of the last node must point at the copy of the **second** node, not just at any node holding 8.

## Constraints

- 0 to 10,000 nodes. Values are any `Int` and can repeat.
- Every `random` target is a node of the same list.
- O(n) time.

<Hints>
<Hint>
You can't set a copy's `random` as you go, because its target's copy may not exist yet. Create every copy first, and wire the links up in a second pass.
</Hint>
<Hint>
The second pass needs to answer "which copy belongs to this original node?". A dictionary keyed by `ObjectIdentifier(node)` does it. Key by identity, never by value: two nodes can hold the same value.
</Hint>
<Hint>
For each original `node`, set `copy.next` to the copy of `node.next` and `copy.random` to the copy of `node.random`. `flatMap` on an optional handles the `nil` cases in one step: `node.random.flatMap { copies[ObjectIdentifier($0)] }`.
</Hint>
</Hints>

## Solutions

<Approach title="A dictionary from original to copy" time="O(n)" space="O(n)">

Two passes: make a copy of every node and file it under its original's identity, then wire each copy's `next` and `random` through the dictionary. The original is only read.

```swift
public enum RandomLinkListCopy {
    public final class Node {
        public var value: Int
        public var next: Node?
        public weak var random: Node?
        public init(_ value: Int) { self.value = value }
    }

    public static func deepCopy(_ head: Node?) -> Node? {
        var copies: [ObjectIdentifier: Node] = [:]
        var current = head
        while let node = current {
            copies[ObjectIdentifier(node)] = Node(node.value)
            current = node.next
        }
        current = head
        while let node = current {
            let copy = copies[ObjectIdentifier(node)]!
            copy.next = node.next.flatMap { copies[ObjectIdentifier($0)] }
            copy.random = node.random.flatMap { copies[ObjectIdentifier($0)] }
            current = node.next
        }
        return head.flatMap { copies[ObjectIdentifier($0)] }
    }
}
```

The copies stay alive between the passes because the dictionary holds them, and afterwards because the copy's own `next` chain does.

</Approach>

<Approach title="Weave the copies into the original" time="O(n)" space="O(1) extra">

Put each copy straight after its original, so the copy of any node is simply `node.next`. Then a copy's `random` is `node.random?.next`, and a final pass unweaves the two lists, restoring every original `next`.

```swift
public static func deepCopy(_ head: Node?) -> Node? {
    guard let head else { return nil }
    var current: Node? = head
    while let node = current {                     // 1. original, copy, original, copy, ...
        let copy = Node(node.value)
        copy.next = node.next
        node.next = copy
        current = copy.next
    }
    current = head
    while let node = current {                     // 2. the copy of the random target is right after it
        node.next!.random = node.random?.next
        current = node.next!.next
    }
    let copyHead = head.next!
    current = head
    while let node = current {                     // 3. unweave
        let copy = node.next!
        node.next = copy.next
        copy.next = copy.next?.next
        current = node.next
    }
    return copyHead
}
```

No dictionary, but the original is taken apart while it runs, so this version is only safe when nothing else is using the list at the same time.

</Approach>
