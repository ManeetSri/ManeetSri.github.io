Two questions about paths that add up to a target in a binary tree:

- `TargetSumPaths.rootToLeafPaths(in root: TreeNode?, summingTo target: Int) -> [[Int]]`: every path from the root down to a **leaf** whose values add up to `target`, each as its values from the root down, listed in the order of their leaves from left to right.
- `TargetSumPaths.downwardPathCount(in root: TreeNode?, summingTo target: Int) -> Int`: how many **downward** paths add up to `target`. A downward path starts at any node and follows children down to any node below it, or stops where it started.

`TreeNode` comes from DSAKit. Trees are written in level order, with `nil` for a missing child, the way `TreeNode.make` takes them.

## Examples

All but the last two rows use this tree, `[6, 3, 9, 4, 1, nil, -2, nil, nil, 5]`:

```text
        6
       / \
      3   9
     / \   \
    4   1   -2
       /
      5
```

| Call | Output |
| --- | --- |
| `rootToLeafPaths(target: 13)` | `[[6, 3, 4], [6, 9, -2]]` |
| `rootToLeafPaths(target: 15)` | `[[6, 3, 1, 5]]` |
| `rootToLeafPaths(target: 9)` | `[]` |
| `downwardPathCount(target: 9)` | `3` |
| `downwardPathCount(target: 7)` | `2` |
| `downwardPathCount(target: 13)` | `2` |
| `[0, 0, 0]`, target 0 | paths `[[0, 0], [0, 0]]`, count `5` |
| `[]`, any target | paths `[]`, count `0` |

For target 9 there's no root-to-leaf path (6 + 3 stops at 3, which isn't a leaf), but there are three downward paths: 6 → 3, 3 → 1 → 5, and 9 on its own. For target 7, they're 3 → 4 and 9 → −2.

## Constraints

- The tree has at most 150,000 nodes and is at most 50 levels deep.
- `-1,000,000,000 ≤ value ≤ 1,000,000,000`, and `|target| ≤ 1,000,000,000`.
- Aim for O(n) for `downwardPathCount`.

<Hints>
<Hint>
For root-to-leaf paths, keep one array for the path from the root to the current node. Append a value when you arrive at a node and remove it when you leave. At a leaf (no children at all), store a copy if the sum matches.
</Hint>
<Hint>
For downward paths, look at the single path from the root to the current node as an array. Downward paths ending here are its stretches that end at its last element, so this is subarray sum equals k: a running sum, and a dictionary counting earlier running sums, starting with `[0: 1]`.
</Hint>
<Hint>
The dictionary must only hold running sums of the nodes **above** the current one. Add a node's running sum before visiting its children, and subtract it again after both children are done.
</Hint>
</Hints>

## Solutions

<Approach title="Downward paths by brute force" time="O(n · h)" space="O(h)">

From every node, walk every path down and count those that hit the target. Each node is visited once for each of its ancestors: fine for balanced trees, O(n²) for a long chain, and a good check for the fast version.

```swift
public static func downwardPathCount(in root: TreeNode?, summingTo target: Int) -> Int {
    func countFrom(_ node: TreeNode?, _ remaining: Int) -> Int {
        guard let node else { return 0 }
        let left = remaining - node.value
        return (left == 0 ? 1 : 0) + countFrom(node.left, left) + countFrom(node.right, left)
    }
    guard let root else { return 0 }
    return countFrom(root, target)
        + downwardPathCount(in: root.left, summingTo: target)
        + downwardPathCount(in: root.right, summingTo: target)
}
```

</Approach>

<Approach title="Backtracking path, and prefix sums along the path" time="O(n) for the count; O(n · h) for the paths" space="O(h)">

Both functions walk the tree once and undo their changes on the way back up: `removeLast()` for the shared path, and a decrement for the running sum's count.

```swift
import DSAKit

public enum TargetSumPaths {
    public static func rootToLeafPaths(in root: TreeNode?, summingTo target: Int) -> [[Int]] {
        var result: [[Int]] = []
        var path: [Int] = []
        func walk(_ node: TreeNode?, remaining: Int) {
            guard let node else { return }
            path.append(node.value)
            let stillNeeded = remaining - node.value
            if node.left == nil && node.right == nil {
                if stillNeeded == 0 {
                    result.append(path)              // a copy: arrays are values
                }
            } else {
                walk(node.left, remaining: stillNeeded)
                walk(node.right, remaining: stillNeeded)
            }
            path.removeLast()                        // backtrack
        }
        walk(root, remaining: target)
        return result
    }

    public static func downwardPathCount(in root: TreeNode?, summingTo target: Int) -> Int {
        var seen: [Int: Int] = [0: 1]                // running sums above the current node
        var count = 0
        func walk(_ node: TreeNode?, runningAbove: Int) {
            guard let node else { return }
            let running = runningAbove + node.value
            count += seen[running - target, default: 0]
            seen[running, default: 0] += 1
            walk(node.left, runningAbove: running)
            walk(node.right, runningAbove: running)
            seen[running, default: 0] -= 1           // this sum leaves the path
        }
        walk(root, runningAbove: 0)
        return count
    }
}
```

Copying each matching path costs up to h, which is where O(n · h) comes from when many paths match. The count never copies anything.

</Approach>
