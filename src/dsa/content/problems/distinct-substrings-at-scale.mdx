Count the different non-empty substrings of `text`. Two substrings that spell the same letters count once, wherever they appear.

`DistinctSubstringsAtScale.count(in text: String) -> Int`

This is **Count distinct substrings** from M40 again, now with texts a hundred times longer. A suffix trie of a 100,000-letter text would need billions of nodes.

## Examples

| `text` | Output |
| --- | --- |
| `"aba"` | `5`: a, b, ab, ba, aba |
| `"abab"` | `7`: a, b, ab, ba, aba, bab, abab |
| `"aaaa"` | `4`: a, aa, aaa, aaaa |
| `"banana"` | `15` |
| `"mississippi"` | `53` |
| `""` | `0` |

## Constraints

- `text` holds 0 to 100,000 lowercase letters, a to z.
- The answer can be about 5 × 10⁹, which fits in Swift's 64-bit `Int`.
- The tests include 100,000-letter texts, where anything that touches each substring, or each suffix trie node, is far too slow.

<Hints>
<Hint>
Every substring is a prefix of some suffix. Sort the suffixes: a suffix's prefixes that also start some earlier suffix in sorted order are exactly the ones it shares with its sorted neighbour.
</Hint>
<Hint>
So, with the suffix array and the LCP array, the suffix at sorted position p contributes `n - sa[p] - lcp[p]` new substrings. Adding these up gives n(n + 1)/2 minus the sum of the LCP array.
</Hint>
<Hint>
Or build a suffix automaton: each state holds the substrings with lengths `len[link] + 1` up to `len`, every substring is in exactly one state, so the answer is the sum of `len[v] - len[link[v]]`.
</Hint>
</Hints>

## Solutions

<Approach title="A suffix trie" time="O(n²)" space="O(n²)">

M40's solution: insert every suffix into a trie and count the nodes. Each node is one distinct substring, so at 100,000 random letters that's billions of nodes. Fine for the old limit of 1,000 letters, hopeless here.

</Approach>

<Approach title="Suffix array and LCP" time="O(n log n)" space="O(n)">

Build the suffix array and Kasai's LCP array, exactly as in [Suffix arrays and LCP](/dsa/learn/sa-suffix-array), then subtract.

```swift
public enum DistinctSubstringsAtScale {
    public static func count(in text: String) -> Int {
        let s = Array(text.utf8)
        let n = s.count
        guard n > 1 else { return n }
        // Prefix doubling with a plain sort: O(n log² n), short and fast enough here
        var sa = Array(0..<n)
        var rank = s.map { Int($0) }
        var newRank = [Int](repeating: 0, count: n)
        var k = 1
        while true {
            let current = rank
            func key(_ i: Int) -> (Int, Int) { (current[i], i + k < n ? current[i + k] : -1) }
            sa.sort { key($0) < key($1) }
            newRank[sa[0]] = 0
            for p in 1..<n { newRank[sa[p]] = newRank[sa[p - 1]] + (key(sa[p - 1]) < key(sa[p]) ? 1 : 0) }
            rank = newRank
            if rank[sa[n - 1]] == n - 1 { break }
            k *= 2
        }
        // Kasai: add up the common prefix of each suffix with its sorted neighbour
        var shared = 0, h = 0
        for i in 0..<n {
            if rank[i] == 0 { h = 0; continue }
            let j = sa[rank[i] - 1]
            while i + h < n && j + h < n && s[i + h] == s[j + h] { h += 1 }
            shared += h
            if h > 0 { h -= 1 }
        }
        return n * (n + 1) / 2 - shared
    }
}
```

After the loop, `rank` is exactly the inverse of `sa` (every rank is different), so Kasai can use it directly. For a string of one repeated letter this sort-based version takes about 17 rounds; the counting-sort version from the lesson makes each round O(n).

</Approach>

<Approach title="Suffix automaton" time="O(n)" space="O(n)">

Build the automaton one letter at a time, with transitions in one flat array of 26 slots per state, then add up `len[v] - len[link[v]]`.

```swift
public enum DistinctSubstringsAtScale {
    public static func count(in text: String) -> Int {
        let s = Array(text.utf8)
        let capacity = 2 * s.count + 1
        var len = [Int](repeating: 0, count: capacity)
        var link = [Int](repeating: -1, count: capacity)
        var next = [Int32](repeating: -1, count: 26 * capacity)
        var states = 1
        var last = 0

        for byte in s {
            let c = Int(byte - 97)
            let cur = states
            states += 1
            len[cur] = len[last] + 1
            link[cur] = 0
            var p = last
            while p != -1 && next[26 * p + c] == -1 {
                next[26 * p + c] = Int32(cur)
                p = link[p]
            }
            if p != -1 {
                let q = Int(next[26 * p + c])
                if len[p] + 1 == len[q] {
                    link[cur] = q
                } else {
                    let clone = states
                    states += 1
                    len[clone] = len[p] + 1
                    link[clone] = link[q]
                    for letter in 0..<26 { next[26 * clone + letter] = next[26 * q + letter] }
                    while p != -1 && next[26 * p + c] == Int32(q) {
                        next[26 * p + c] = Int32(clone)
                        p = link[p]
                    }
                    link[q] = clone
                    link[cur] = clone
                }
            }
            last = cur
        }

        var total = 0
        for v in 1..<states {
            total += len[v] - len[link[v]]
        }
        return total
    }
}
```

At most 2n states, so the table is at most 2n × 26 `Int32`s: about 20 MB for 100,000 letters. `Int32` halves that compared with `Int`.

</Approach>
