Two related questions about fractions. First, `phi(n)` returns Euler's totient: how many of the numbers 1 to n share no factor with n. Second, `count(maxDenominator:)` returns how many fractions p/q with `0 < p < q ≤ n` are already in lowest terms, so 2/4 doesn't count but 1/2 does.

`LowestTermsFractions.phi(_ n: Int) -> Int`

`LowestTermsFractions.count(maxDenominator n: Int) -> Int`

## Examples

| Call | Returns | Why |
| --- | --- | --- |
| `phi(12)` | `4` | 1, 5, 7 and 11 share no factor with 12 |
| `phi(97)` | `96` | 97 is prime |
| `phi(1)` | `1` | gcd(1, 1) = 1 |
| `phi(1_000_000_000_000)` | `400000000000` | 10¹² = 2¹² × 5¹², and 10¹² × 1/2 × 4/5 = 4 × 10¹¹ |
| `count(maxDenominator: 5)` | `9` | 1/2, 1/3, 2/3, 1/4, 3/4, 1/5, 2/5, 3/5, 4/5 |
| `count(maxDenominator: 8)` | `21` | |
| `count(maxDenominator: 1)` | `0` | no fraction has `0 < p < 1` |

## Constraints

- For `phi`: `1 ≤ n ≤ 10¹²`
- For `count`: `1 ≤ n ≤ 1,000,000`
- The tests ask for `count(maxDenominator: 1_000_000)`. Factorising every denominator separately takes about 7 × 10⁸ trial divisions, which is far too slow.

<Hints>
<Hint>
φ(n) = n × (1 − 1/p₁) × (1 − 1/p₂) × … over the distinct primes dividing n. Find them by trial division up to √n, and for each one do `result -= result / p`. Don't forget a leftover prime above √n.
</Hint>
<Hint>
p/q is in lowest terms exactly when gcd(p, q) = 1. So for each denominator q, there are φ(q) good numerators, and the count is φ(2) + φ(3) + … + φ(n).
</Hint>
<Hint>
Compute every φ at once with a sieve: start with phi[i] = i. Going up from 2, any i with phi[i] still equal to i is prime; apply phi[m] -= phi[m] / i to every multiple m of i. By the time you reach i, phi[i] is final, so you can add it to the total in the same loop.
</Hint>
</Hints>

## Solutions

<Approach title="φ by trial division" time="O(√n)" space="O(1)">

Factorise n, applying one factor of (1 − 1/p) for each distinct prime. `result` is always divisible by p when you subtract, because it still contains every factor of p from n.

```swift
public static func phi(_ n: Int) -> Int {
    var rest = n
    var result = n
    var p = 2
    while p * p <= rest {
        if rest % p == 0 {
            while rest % p == 0 { rest /= p }
            result -= result / p
        }
        p += 1
    }
    if rest > 1 { result -= result / rest }        // one prime factor above √n
    return result
}
```

Summing `phi(q)` for every q up to a million this way works, but costs about n^1.5 steps in total.

</Approach>

<Approach title="A totient sieve" time="O(n log log n)" space="O(n)">

The sieve version applies each prime's factor to all its multiples at once, exactly like crossing out multiples in the Sieve of Eratosthenes.

```swift
public static func count(maxDenominator n: Int) -> Int {
    guard n >= 2 else { return 0 }
    var phi = Array(0...n)
    var total = 0
    var i = 2
    while i <= n {
        if phi[i] == i {                            // untouched, so i is prime
            var multiple = i
            while multiple <= n {
                phi[multiple] -= phi[multiple] / i
                multiple += i
            }
        }
        total += phi[i]                             // every prime factor of i has been applied by now
        i += 1
    }
    return total
}
```

The loops are `while` loops on purpose. `swift test` builds without optimisation, and in that mode `for … in stride` is about twice as slow. A linear sieve that fills φ as it goes, as in the lesson, works just as well.

</Approach>
