Do ARC's job by hand. Objects are created, stored in variables and linked to each other through a `next` property. Track every object's reference count, and report which objects are freed, in order, and which are still alive at the end.

`RefCountSimulator.simulate(_ commands: [String]) -> RefCountSimulator.Outcome`

Each object has one optional strong property, `next`. Commands are words separated by single spaces:

| Command | Means |
| --- | --- |
| `new a 1` | create object 1 and store it in variable `a` |
| `set b a` | `b = a` (so `b` becomes empty if `a` is) |
| `clear a` | `a = nil` |
| `link a b` | `a.next = b`, for the object in `a` |
| `unlink a` | `a.next = nil` |
| `follow a` | `a = a.next`, the way `head = head?.next` moves along a list |

Every strong reference, from a variable or from a `next` property, counts one. The rules:

- When a reference is replaced, the new object gains its reference **before** the old one loses its own.
- An object whose count reaches zero is freed at once. Then its `next` lets go of the object it pointed at, which may free that one too, and so on down a chain.

Return an `Outcome` whose `freed` lists the ids in the order they were freed, and whose `alive` lists the ids still alive at the end, smallest first.

## Examples

| Commands | `freed` | `alive` |
| --- | --- | --- |
| `new a 7`, `set b a`, `clear a` | `[]` | `[7]` |
| `new a 7`, `set b a`, `clear a`, `clear b` | `[7]` | `[]` |
| `new a 1`, `new a 2` | `[1]` | `[2]` |
| `new head 1`, `new b 2`, `new c 3`, `link b c`, `link head b`, `clear b`, `clear c`, `clear head` | `[1, 2, 3]` | `[]` |
| `new a 1`, `new b 2`, `link a b`, `link b a`, `clear a`, `clear b` | `[]` | `[1, 2]` |
| `new a 5`, `link a a`, `clear a` | `[]` | `[5]` |

The last two are retain cycles: no variable can reach the objects any more, but they keep each other alive, so ARC never frees them.

## Constraints

- Up to 100,000 commands. Object ids are unique and never reused.
- `link`, `unlink` and `follow` are only used on a variable that holds an object.

<Hints>
<Hint>
Keep three dictionaries: object id to reference count, object id to the id its `next` points at, and variable name to the object it holds. Every command is then "add a reference here, remove one there".
</Hint>
<Hint>
Write two helpers, `retain` and `release`, that each take an optional id and do nothing for `nil`. For every replacement, call `retain(new)` first, then `release(old)`. That order is what makes `set a a` and linking an object to itself work.
</Hint>
<Hint>
`release` lowers the count. If it reaches zero, record the id as freed, remove its count, and then release the object its `next` pointed at. Do that last step with a loop rather than recursion, so a chain of 100,000 nodes can't overflow the stack.
</Hint>
</Hints>

## Solutions

<Approach title="Count every reference, release in a loop" time="O(n) for n commands" space="O(n)">

Each command retains at most one object and releases at most one. A release can free a whole chain, but every object is freed only once, so all the freeing across the whole run adds up to O(n).

```swift
public enum RefCountSimulator {
    // Outcome as in the starter code

    public static func simulate(_ commands: [String]) -> Outcome {
        var count: [Int: Int] = [:]
        var next: [Int: Int] = [:]
        var holds: [String: Int] = [:]
        var freed: [Int] = []

        func retain(_ object: Int?) {
            if let object {
                count[object]! += 1
            }
        }

        func release(_ object: Int?) {
            var current = object
            while let object = current {
                count[object]! -= 1
                guard count[object]! == 0 else {
                    return
                }
                count[object] = nil
                freed.append(object)
                current = next.removeValue(forKey: object)
            }
        }

        for command in commands {
            let words = command.split(separator: " ").map(String.init)
            let name = words[1]
            switch words[0] {
            case "new":
                let object = Int(words[2])!
                count[object] = 1
                release(holds[name])
                holds[name] = object
            case "set":
                let object = holds[words[2]]
                retain(object)
                release(holds[name])
                holds[name] = object
            case "clear":
                release(holds[name])
                holds[name] = nil
            case "link":
                let owner = holds[name]!
                let object = holds[words[2]]
                retain(object)
                release(next[owner])
                next[owner] = object
            case "unlink":
                let owner = holds[name]!
                release(next[owner])
                next[owner] = nil
            default:
                let object = next[holds[name]!]
                retain(object)
                release(holds[name])
                holds[name] = object
            }
        }
        return Outcome(freed: freed, alive: count.keys.sorted())
    }
}
```

`next.removeValue(forKey:)` returns the id the freed object pointed at, if any, and forgets the link in the same step. Sorting the alive ids at the end costs O(k log k) for k survivors.

</Approach>
