Two non-negative numbers are stored as linked lists of digits, one digit per node, with the **units digit first**: 342 is `2 -> 4 -> 3`. Return their sum as a new list in the same format. Build new nodes for the answer and leave both input lists exactly as they were.

`UnitsFirstListSum.add(_ first: ListNode?, _ second: ListNode?) -> ListNode?`

## Examples

| `first` | `second` | Result | As numbers |
| --- | --- | --- | --- |
| `2 -> 4 -> 3` | `5 -> 6 -> 4` | `7 -> 0 -> 8` | 342 + 465 = 807 |
| `9 -> 9` | `1` | `0 -> 0 -> 1` | 99 + 1 = 100 |
| `5` | `5` | `0 -> 1` | 5 + 5 = 10 |
| `1 -> 8` | `0` | `1 -> 8` | 81 + 0 = 81 |
| `0` | `0` | `0` | 0 + 0 = 0 |
| `9 -> 9 -> 9 -> 9` | `2 -> 1` | `1 -> 1 -> 0 -> 0 -> 1` | 9,999 + 12 = 10,011 |

## Constraints

- Each list has 1 to 10,000 nodes, each holding a digit from 0 to 9.
- Neither number has leading zeros, except the number 0 itself, which is the single node `0`.
- The numbers can be far too big for an `Int`, so don't convert them.

<Hints>
<Hint>
With the units first, walking both lists from the head visits the columns in the order you add them by hand: units, then tens, then hundreds. Each column's digit is `sum % 10` and the carry into the next column is `sum / 10`.
</Hint>
<Hint>
Build the answer with a dummy node and a `tail` you append to, so the first digit needs no special case. A list that has run out counts as 0: `a?.value ?? 0`, with `a = a?.next` staying `nil` once it's `nil`.
</Hint>
<Hint>
Keep looping while either list has digits left **or** the carry is 1. Stopping when both lists end loses the final carry and turns 99 + 1 into 00.
</Hint>
</Hints>

## Solutions

<Approach title="Column addition with a dummy head" time="O(max(m, n))" space="O(max(m, n)) for the answer">

One pass adds a column per step. Nothing ever overflows, because a column is at most 9 + 9 + 1 = 19, however long the numbers are. The inputs are only read, never changed.

```swift
import DSAKit

public enum UnitsFirstListSum {
    public static func add(_ first: ListNode?, _ second: ListNode?) -> ListNode? {
        let dummy = ListNode(0)
        var tail = dummy
        var a = first
        var b = second
        var carry = 0
        while a != nil || b != nil || carry > 0 {
            let sum = (a?.value ?? 0) + (b?.value ?? 0) + carry
            tail.next = ListNode(sum % 10)
            tail = tail.next!
            carry = sum / 10
            a = a?.next
            b = b?.next
        }
        return dummy.next
    }
}
```

</Approach>
