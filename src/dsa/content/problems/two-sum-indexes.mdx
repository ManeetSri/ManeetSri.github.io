Find two different positions in an unsorted array whose values add up to a target, and return them.

`TwoSumIndexes.indexes(in numbers: [Int], summingTo target: Int) -> [Int]?`

Return `[i, j]` with `i < j` and `numbers[i] + numbers[j] == target`, or `nil` if no pair works. If several pairs work, return the one whose second index `j` is smallest, and among those, the smallest `i`.

## Examples

| `numbers` | `target` | Result |
| --- | --- | --- |
| `[8, 3, 11, 5]` | `16` | `[2, 3]` |
| `[5, 5]` | `10` | `[0, 1]` |
| `[1, 3, 5, 3]` | `6` | `[0, 2]` |
| `[2, 2, 4]` | `6` | `[0, 2]` |
| `[3, 4]` | `6` | `nil` |
| `[]` | `5` | `nil` |

In the third example, both 1 + 5 and 3 + 3 make 6, but 1 + 5 finishes at index 2, before the second 3 at index 3. In the fifth, the 3 can't be used twice.

## Constraints

- `0 ≤ numbers.count ≤ 100,000`
- `-10⁹ ≤ numbers[i] ≤ 10⁹` and `-2 × 10⁹ ≤ target ≤ 2 × 10⁹`
- Aim for O(n). A test with 100,000 numbers has its only pair at the very end.

<Hints>
<Hint>
For each number, the only value that can complete a pair is `target - number`. Have you seen it already?
</Hint>
<Hint>
Keep a dictionary from value to index. At position j, look up `target - numbers[j]` first, and only then record `numbers[j]`, so a number can't pair with itself.
</Hint>
<Hint>
The first j that finds a partner is the smallest j. To get the smallest i too, record each value's **first** index and don't overwrite it.
</Hint>
</Hints>

## Solutions

<Approach title="Check every pair" time="O(n²)" space="O(1)">

Try each j in order, and for each, every earlier i in order. The first match is the pair the statement asks for. It's a good reference for testing, but 100,000 numbers means about 5 billion pairs.

```swift
public static func indexes(in numbers: [Int], summingTo target: Int) -> [Int]? {
    for j in numbers.indices {
        for i in 0..<j where numbers[i] + numbers[j] == target {
            return [i, j]
        }
    }
    return nil
}
```

</Approach>

<Approach title="One pass with a dictionary" time="O(n)" space="O(n)">

Walk the array once, remembering the first index of every value seen so far. At position j, if `target - numbers[j]` has been seen, its first index is the smallest valid i, and since this is the first j to find any partner, the pair is the one wanted.

```swift
public enum TwoSumIndexes {
    public static func indexes(in numbers: [Int], summingTo target: Int) -> [Int]? {
        var firstIndex: [Int: Int] = [:]
        for (j, number) in numbers.enumerated() {
            if let i = firstIndex[target - number] {
                return [i, j]
            }
            if firstIndex[number] == nil {
                firstIndex[number] = j
            }
        }
        return nil
    }
}
```

Checking before recording handles the `[3, 4]` case: the 3 looks for another 3 before it has recorded itself. And because later copies never overwrite the first index, `[2, 2, 4]` returns `[0, 2]`, not `[1, 2]`.

</Approach>
