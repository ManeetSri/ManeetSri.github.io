A value is the **majority** of an array if it appears more than half the time: more than `numbers.count / 2` times. Return the majority value, or `nil` if there isn't one. Aim for one or two passes with O(1) extra space.

`MajorityVote.majority(in numbers: [Int]) -> Int?`

## Examples

| `numbers` | Result |
| --- | --- |
| `[3, 1, 3]` | `3` |
| `[2, 2, 1, 1, 2]` | `2` |
| `[1, 9, 9, 4, 9, 9, 2]` | `9` |
| `[4, 4, 1, 1]` | `nil` |
| `[1, 2, 3]` | `nil` |
| `[]` | `nil` |

In the fourth example, 4 appears exactly half the time. That isn't more than half, so there's no majority.

## Constraints

- `0 ≤ numbers.count ≤ 100,000`
- Values are any `Int`.
- O(n) time and O(1) extra space for the full solution. A dictionary of counts works, but uses O(n) space.

<Hints>
<Hint>
Correct first: count every value in a `[Int: Int]` dictionary, then look for a count above `numbers.count / 2`. That's O(n) time and O(n) space.
</Hint>
<Hint>
For O(1) space, use Boyer–Moore voting: keep a `candidate` and a `votes` count. When `votes` is 0, the current value becomes the candidate. A value equal to the candidate adds a vote; any other value takes one away.
</Hint>
<Hint>
The vote only promises that **if** a majority exists, it's the final candidate. With an array like `[1, 2, 3]` there's still a final candidate. Count how often it really appears in a second pass before returning it.
</Hint>
</Hints>

## Solutions

<Approach title="Count with a dictionary" time="O(n)" space="O(n)">

Count every value, then return the one whose count is more than half. The answer is unique, because two different values can't both appear more than half the time.

```swift
public static func majority(in numbers: [Int]) -> Int? {
    var counts: [Int: Int] = [:]
    for number in numbers {
        counts[number, default: 0] += 1
    }
    for (value, count) in counts where count > numbers.count / 2 {
        return value
    }
    return nil
}
```

</Approach>

<Approach title="Boyer–Moore voting, then confirm" time="O(n)" space="O(1)">

Each decrement cancels one copy of the candidate against one different value. A true majority has more copies than all other values put together, so it can never be cancelled out completely: it must be the candidate at the end. The second pass rules out arrays with no majority at all.

```swift
public enum MajorityVote {
    public static func majority(in numbers: [Int]) -> Int? {
        var candidate = 0
        var votes = 0
        for number in numbers {
            if votes == 0 {
                candidate = number
                votes = 1
            } else if number == candidate {
                votes += 1
            } else {
                votes -= 1
            }
        }

        // The vote only guarantees: if there is a majority, it's the candidate. Check it.
        var occurrences = 0
        for number in numbers where number == candidate {
            occurrences += 1
        }
        return occurrences > numbers.count / 2 ? candidate : nil
    }
}
```

For an empty array the loop never runs, `occurrences` is 0, and `0 > 0` is false, so it correctly returns `nil`.

</Approach>
