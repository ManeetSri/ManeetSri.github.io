Given two values in a binary search tree, return their **lowest common ancestor**: the deepest node that has both values in its subtree. A node counts as part of its own subtree, so if one value is an ancestor of the other, it's the answer.

`BSTCommonAncestor.lowest(of first: Int, and second: Int, in root: TreeNode?) -> TreeNode?`

Return the node itself. Both values are in the tree, and they may be equal. Use the BST ordering: aim for O(h), where h is the height.

## Examples

The tree `[40, 20, 60, 10, 30, 50, 70, nil, 15, nil, nil, 45]` has 15 as the right child of 10 and 45 as the left child of 50.

| `first`, `second` | Output |
| --- | --- |
| `10, 30` | the node holding `20` |
| `15, 45` | the node holding `40` |
| `45, 70` | the node holding `60` |
| `10, 15` | the node holding `10` |
| `50, 50` | the node holding `50` |

## Constraints

- `1 ≤` number of nodes `≤ 200,000`
- `root` is a valid binary search tree with no repeated values.
- Both values are in the tree.

<Hints>
<Hint>
Stand at the root. If both values are smaller than it, where must they both be? And where is their lowest common ancestor?
</Hint>
<Hint>
Both smaller: go left. Both bigger: go right. Otherwise the values are on different sides of this node, or one of them **is** this node. Either way, no deeper node has both below it.
</Hint>
<Hint>
That's one path down from the root, like a search. A `while let node = current` loop does it with no extra space.
</Hint>
</Hints>

## Solutions

<Approach title="Walk down until the values split" time="O(h)" space="O(1)">

At each node the values are either both on one side, and the answer is down that side, or they split here. The general binary-tree method visits every node; the ordering lets you discard a whole subtree at each step.

```swift
public enum BSTCommonAncestor {
    public static func lowest(of first: Int, and second: Int, in root: TreeNode?) -> TreeNode? {
        var current = root
        while let node = current {
            if first < node.value && second < node.value {
                current = node.left
            } else if first > node.value && second > node.value {
                current = node.right
            } else {
                return node
            }
        }
        return nil
    }
}
```

</Approach>
