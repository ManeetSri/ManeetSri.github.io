Multiply two non-negative whole numbers that are far too long for an `Int`. Each arrives as a string of decimal digits, possibly thousands long, and the product should come back the same way, with no leading zeros. Use Karatsuba's method.

`KaratsubaLongProduct.multiply(_ a: String, _ b: String) -> String`

## Examples

| `a` | `b` | Output |
| --- | --- | --- |
| `"12"` | `"34"` | `"408"` |
| `"999"` | `"999"` | `"998001"` |
| `"0"` | `"98765"` | `"0"` |
| `"123456789"` | `"987654321"` | `"121932631112635269"` |
| `"99999999999999999999"` | `"2"` | `"199999999999999999998"` |

The last example's first number has 20 digits, already too big for an `Int`, whose largest value is about 9.2 × 10¹⁸.

## Constraints

- `1 ≤ a.count, b.count ≤ 10,000`
- Both strings contain only the digits 0 to 9, with no leading zeros unless the number is exactly `"0"`.
- The tests square a 10,000-digit number. Schoolbook multiplication needs 10⁸ digit products for that, which takes many seconds in a debug build.

<Hints>
<Hint>
Convert each string to an array of digits, **least significant first**, and write small helpers to add, subtract and shift (multiply by a power of 10) such arrays. Multiply short numbers the schoolbook way.
</Hint>
<Hint>
Split both numbers at m digits, where m is half the length of the longer one: x = x₁ · 10^m + x₀. Then compute just three products recursively: high = x₁y₁, low = x₀y₀ and both = (x₁ + x₀)(y₁ + y₀). The middle term is both − high − low.
</Hint>
<Hint>
Recombine as high shifted by 2m, plus the middle term shifted by m, plus low, and trim leading zeros. Switch to schoolbook below about 32 digits. For extra speed, store four digits per array element (base 10,000) instead of one.
</Hint>
</Hints>

## Solutions

<Approach title="Schoolbook" time="O(n · m)" space="O(n + m)">

Multiply every digit of one number by every digit of the other, adding each product into position `i + j`, then carry. It's correct and simple, and it's the base case for the faster method, but for two 10,000-digit numbers it's 10⁸ digit products.

</Approach>

<Approach title="Karatsuba on digit arrays" time="O(n^1.585)" space="O(n)">

The lesson's version: split at m digits, three recursive products, and schoolbook below a cutoff. T(n) = 3T(n/2) + O(n). With one decimal digit per element, it squares a 10,000-digit number about six times faster than schoolbook in a debug build.

</Approach>

<Approach title="Karatsuba on limbs of four digits" time="O(n^1.585)" space="O(n)">

Store four decimal digits per element, base 10,000, so there are a quarter as many pieces. A product of two limbs is below 10⁸, so even a schoolbook column of 24 such products fits comfortably in an `Int`. The three products are added into one array, which can leave some limbs briefly negative where the middle term subtracts; one carry pass at the end puts every limb back between 0 and 9,999.

```swift
public enum KaratsubaLongProduct {
    private static let base = 10_000              // each limb holds four decimal digits
    private static let cutoff = 24

    public static func multiply(_ a: String, _ b: String) -> String {
        let product = karatsuba(limbs(a), limbs(b))
        var text = String(product.last!)
        for limb in product.dropLast().reversed() {
            let digits = String(limb)
            text += String(repeating: "0", count: 4 - digits.count) + digits
        }
        return text
    }

    private static func limbs(_ text: String) -> [Int] {
        let digits = Array(text.utf8).map { Int($0) - 48 }
        var result: [Int] = []
        var end = digits.count
        while end > 0 {
            let start = max(0, end - 4)
            var limb = 0
            for index in start..<end {
                limb = limb * 10 + digits[index]
            }
            result.append(limb)
            end = start
        }
        return trimmed(result)
    }

    private static func karatsuba(_ a: [Int], _ b: [Int]) -> [Int] {
        if a.count <= cutoff || b.count <= cutoff {
            return schoolbook(a, b)
        }
        let m = max(a.count, b.count) / 2
        let a0 = trimmed(Array(a.prefix(m))), a1 = a.count > m ? Array(a.dropFirst(m)) : [0]
        let b0 = trimmed(Array(b.prefix(m))), b1 = b.count > m ? Array(b.dropFirst(m)) : [0]
        let high = karatsuba(a1, b1)
        let low = karatsuba(a0, b0)
        let both = karatsuba(add(a1, a0), add(b1, b0))
        var result = Array(repeating: 0, count: max(both.count + m, high.count + 2 * m, low.count) + 1)
        // low + (both - high - low)·B^m + high·B^(2m), limb by limb; the carry pass tidies up
        for (index, limb) in low.enumerated() {
            result[index] += limb
            result[index + m] -= limb
        }
        for (index, limb) in high.enumerated() {
            result[index + 2 * m] += limb
            result[index + m] -= limb
        }
        for (index, limb) in both.enumerated() {
            result[index + m] += limb
        }
        return normalised(result)
    }

    private static func schoolbook(_ a: [Int], _ b: [Int]) -> [Int] {
        var result = Array(repeating: 0, count: a.count + b.count)
        for i in a.indices where a[i] != 0 {
            for j in b.indices {
                result[i + j] += a[i] * b[j]
            }
        }
        return normalised(result)
    }

    private static func add(_ a: [Int], _ b: [Int]) -> [Int] {
        var result = Array(repeating: 0, count: max(a.count, b.count) + 1)
        for (index, limb) in a.enumerated() {
            result[index] += limb
        }
        for (index, limb) in b.enumerated() {
            result[index] += limb
        }
        return normalised(result)
    }

    /// Carries every limb into 0..<base, borrowing where a limb is negative
    private static func normalised(_ number: [Int]) -> [Int] {
        var result = number
        var carry = 0
        for index in result.indices {
            var total = result[index] + carry
            carry = total / base
            total %= base
            if total < 0 {
                total += base
                carry -= 1
            }
            result[index] = total
        }
        return trimmed(result)
    }

    private static func trimmed(_ number: [Int]) -> [Int] {
        var number = number
        while number.count > 1 && number.last == 0 {
            number.removeLast()
        }
        return number.isEmpty ? [0] : number
    }
}
```

Converting back to text pads every limb except the top one to four digits: the limb 7 in the middle of a number stands for "0007".

</Approach>
