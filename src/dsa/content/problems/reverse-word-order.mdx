Given a sentence, return its words in reverse order. Words are separated by one or more spaces, and the sentence may start or end with spaces. The result must have exactly one space between words and no spaces at the start or end. Each word itself stays exactly as it was.

`ReverseWordOrder.reverse(_ sentence: String) -> String`

## Examples

| Input | Output |
| --- | --- |
| `"the sky is blue"` | `"blue is sky the"` |
| `"  learn   swift  today "` | `"today swift learn"` |
| `"Hello, World!"` | `"World! Hello,"` |
| `"one"` | `"one"` |
| `"     "` | `""` |

## Constraints

- `0 ≤ sentence.count ≤ 100,000`
- Only the space character `" "` separates words. Words may contain letters, digits and punctuation.

<Hints>
<Hint>
This is split, transform, join. Which step deals with the extra spaces?
</Hint>
<Hint>
`sentence.split(separator: " ")` returns only the words: by default it omits the empty pieces that repeated, leading and trailing spaces would create.
</Hint>
<Hint>
Between splitting and joining you have an ordinary array, so `reversed()` works on it. Then `joined(separator: " ")` puts single spaces back.
</Hint>
</Hints>

## Solutions

<Approach title="Split, reverse, join" time="O(n)" space="O(n)">

`split` finds the words and throws away the empty pieces, `reversed()` flips their order, and `joined(separator:)` rebuilds the sentence with single spaces.

```swift
public enum ReverseWordOrder {
    public static func reverse(_ sentence: String) -> String {
        sentence.split(separator: " ").reversed().joined(separator: " ")
    }
}
```

`split` returns substrings, so no word is copied until `joined` builds the final string.

</Approach>

<Approach title="Collect words by hand" time="O(n)" space="O(n)">

Without `split`, walk the characters, building the current word and adding it to an array whenever a space ends it. This is what `split` does for you.

```swift
public static func reverse(_ sentence: String) -> String {
    var words: [String] = []
    var current = ""
    for character in sentence {
        if character == " " {
            if !current.isEmpty {
                words.append(current)
                current = ""
            }
        } else {
            current.append(character)
        }
    }
    if !current.isEmpty {
        words.append(current)
    }
    return words.reversed().joined(separator: " ")
}
```

The final `if` catches the last word, which isn't followed by a space.

</Approach>
