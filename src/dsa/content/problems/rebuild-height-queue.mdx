People were standing in a queue, and each wrote down two numbers: their height, and how many people **in front of them** were at least as tall. The notes `[height, k]` have been shuffled. Put them back in queue order, front first.

`HeightQueueRebuild.rebuild(_ people: [[Int]]) -> [[Int]]`

## Examples

| `people` | Output |
| --- | --- |
| `[[4, 4], [7, 0], [5, 2], [6, 0], [4, 1], [6, 2]]` | `[[6, 0], [4, 1], [7, 0], [5, 2], [4, 4], [6, 2]]` |
| `[[5, 0], [3, 1], [5, 1]]` | `[[5, 0], [3, 1], [5, 1]]` |
| `[[2, 2], [2, 0], [2, 1]]` | `[[2, 0], [2, 1], [2, 2]]` |
| `[[3, 0], [1, 0], [2, 0]]` | `[[1, 0], [2, 0], [3, 0]]` |
| `[]` | `[]` |

In the first example, `[4, 4]` ends up behind 6, 4, 7 and 5: four people at least as tall. People of equal height count each other.

## Constraints

- `0 ≤ people.count ≤ 2,000`
- `1 ≤ height ≤ 1,000,000`
- The notes always come from a real queue, so exactly one order matches them.

<Hints>
<Hint>
Who can the tallest people "see"? Shorter people standing in front of them don't count towards their k at all.
</Hint>
<Hint>
Place people from the tallest down. When you place someone, everyone already placed is at least as tall, so they all count. Where must the new person stand?
</Hint>
<Hint>
Sort by height descending, and equal heights by k ascending. Insert each person at index k of the queue built so far.
</Hint>
</Hints>

## Solutions

<Approach title="Fill the free spots from the shortest up" time="O(n²)" space="O(n)">

A different view: start with n empty spots and place people from the **shortest** up. When it's someone's turn, everyone not yet placed is at least as tall (or the same height and further back), so they need exactly k empty spots in front of them. Count k empty spots from the front and take the next one. For equal heights, place the larger k first, so the people already placed don't take a spot that someone of the same height should have counted.

```swift
public static func rebuild(_ people: [[Int]]) -> [[Int]] {
    let order = people.sorted { $0[0] != $1[0] ? $0[0] < $1[0] : $0[1] > $1[1] }
    var queue: [[Int]?] = Array(repeating: nil, count: people.count)
    for person in order {
        var emptyLeft = person[1]
        for spot in queue.indices where queue[spot] == nil {
            if emptyLeft == 0 {
                queue[spot] = person
                break
            }
            emptyLeft -= 1
        }
    }
    return queue.compactMap { $0 }
}
```

</Approach>

<Approach title="Tallest first, insert at k" time="O(n²)" space="O(n)">

When a person is inserted, everyone already in the queue is at least as tall, so standing at index k puts exactly k of them in front. Later people are shorter, so they never change a taller person's count, and people of the same height already placed have a smaller k, so they stay in front. Each insert shifts up to n elements, which is fine for 2,000 people.

```swift
public enum HeightQueueRebuild {
    public static func rebuild(_ people: [[Int]]) -> [[Int]] {
        let order = people.sorted { $0[0] != $1[0] ? $0[0] > $1[0] : $0[1] < $1[1] }
        var queue: [[Int]] = []
        queue.reserveCapacity(people.count)
        for person in order {
            queue.insert(person, at: person[1])
        }
        return queue
    }
}
```

With an order-statistics structure, such as the Fenwick tree in M61, either approach becomes O(n log n).

</Approach>
