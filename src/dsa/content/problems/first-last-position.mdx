A sorted array of sensor readings can repeat values. Given a value, return the range of indexes where it appears, from its first copy to its last, or `nil` if it doesn't appear at all.

`FirstLastPosition.span(of target: Int, in numbers: [Int]) -> ClosedRange<Int>?`

Aim for O(log n), however many copies there are.

## Examples

| `target` | `numbers` | Output |
| --- | --- | --- |
| `3` | `[1, 3, 3, 3, 5, 8, 8, 9]` | `1...3` |
| `8` | `[1, 3, 3, 3, 5, 8, 8, 9]` | `5...6` |
| `9` | `[1, 3, 3, 3, 5, 8, 8, 9]` | `7...7` |
| `4` | `[1, 3, 3, 3, 5, 8, 8, 9]` | `nil` |
| `7` | `[7, 7, 7, 7, 7]` | `0...4` |
| `3` | `[]` | `nil` |

A value that appears once gives a range with one index, like `7...7`.

## Constraints

- `0 ≤ numbers.count ≤ 1,000,000`
- `numbers` is sorted in non-decreasing order.
- A value can appear any number of times, up to the whole array.

<Hints>
<Hint>
Finding one copy and then walking left and right to the ends of the run is correct, but it's O(n) when the run is long. The tests include runs of 100,000 copies.
</Hint>
<Hint>
Find two boundaries with binary search: the first index whose value is ≥ `target` (the lower bound), and the first index whose value is > `target` (the upper bound). Both can equal `numbers.count`.
</Hint>
<Hint>
Write one helper, "the first index where a condition becomes true", with a half-open range: `high = numbers.count`, `while low < high`, `high = mid` when the condition holds and `low = mid + 1` when it doesn't. If the lower bound is past the end or doesn't hold `target`, return `nil`; otherwise the answer is `lower...(upper - 1)`.
</Hint>
</Hints>

## Solutions

<Approach title="Find one copy, then expand" time="O(log n + k) for k copies" space="O(1)">

A binary search finds some copy, then two loops walk outwards to the ends of the run. It's fast when values rarely repeat, but when the whole array is one value, the walking is O(n).

```swift
public static func span(of target: Int, in numbers: [Int]) -> ClosedRange<Int>? {
    var low = 0
    var high = numbers.count - 1
    while low <= high {
        let mid = low + (high - low) / 2
        if numbers[mid] == target {
            var first = mid
            var last = mid
            while first > 0 && numbers[first - 1] == target { first -= 1 }
            while last < numbers.count - 1 && numbers[last + 1] == target { last += 1 }
            return first...last
        } else if numbers[mid] < target {
            low = mid + 1
        } else {
            high = mid - 1
        }
    }
    return nil
}
```

</Approach>

<Approach title="Lower bound and upper bound" time="O(log n)" space="O(1)">

Both boundaries are "the first index where a condition becomes true": the conditions `value >= target` and `value > target` each go false…false true…true on sorted data. The copies of `target` occupy exactly the half-open range between them.

```swift
public enum FirstLastPosition {
    public static func span(of target: Int, in numbers: [Int]) -> ClosedRange<Int>? {
        let first = firstIndex(in: numbers) { $0 >= target }
        guard first < numbers.count, numbers[first] == target else { return nil }
        let pastLast = firstIndex(in: numbers) { $0 > target }
        return first...(pastLast - 1)
    }

    /// The first index whose value makes `isTrue` return true, or `numbers.count` if none does.
    private static func firstIndex(in numbers: [Int], where isTrue: (Int) -> Bool) -> Int {
        var low = 0
        var high = numbers.count                 // half-open: the answer is in [low, high]
        while low < high {
            let mid = low + (high - low) / 2
            if isTrue(numbers[mid]) {
                high = mid                       // mid could be the first true: keep it
            } else {
                low = mid + 1
            }
        }
        return low
    }
}
```

The `guard` handles both kinds of miss: a target bigger than everything (the lower bound is `count`) and a target that falls in a gap (the lower bound holds a bigger value). If the target is present, `pastLast` is at least `first + 1`, so the range is never empty.

</Approach>

<Approach title="DSAKit's bounds" time="O(log n)" space="O(1)">

With DSAKit, the two helper searches are already written and tested.

```swift
import DSAKit

public static func span(of target: Int, in numbers: [Int]) -> ClosedRange<Int>? {
    let first = numbers.lowerBound(of: target)
    guard first < numbers.count, numbers[first] == target else { return nil }
    return first...(numbers.upperBound(of: target) - 1)
}
```

</Approach>
