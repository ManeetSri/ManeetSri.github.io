A spell checker needs to know how far a typo is from a real word, and to show the changes. An edit inserts one character, deletes one, or replaces one with a different character. Return the fewest edits that turn `source` into `target`, and a script that does it in exactly that many.

`WordEditScript.distance(from source: String, to target: String) -> Int`

`WordEditScript.script(from source: String, to target: String) -> [WordEditScript.Step]`

A script is read left to right across the source. Each step is one of:

| Step | Meaning |
| --- | --- |
| `.keep(c)` | the next source character is `c`; copy it unchanged |
| `.replace(c, with: d)` | the next source character is `c`; write `d` instead (`d` must differ from `c`) |
| `.delete(c)` | the next source character is `c`; drop it |
| `.insert(d)` | write `d` without using a source character |

## Examples

| `source` | `target` | `distance` | One shortest script |
| --- | --- | --- | --- |
| `"kitten"` | `"sitting"` | `3` | replace k with s, keep i, keep t, keep t, replace e with i, keep n, insert g |
| `"flaw"` | `"lawn"` | `2` | delete f, keep l, keep a, keep w, insert n |
| `"cat"` | `"cut"` | `1` | keep c, replace a with u, keep t |
| `""` | `"ab"` | `2` | insert a, insert b |
| `"swift"` | `"swift"` | `0` | keep every character |

The tests replay your script on the source. It must consume every source character, produce exactly the target, and contain exactly `distance` steps that aren't `.keep`. Any such script is accepted.

## Constraints

- Each string has 0 to 1,500 characters. Compare `Character`s.
- The tests include a 1,500-character text against a copy with 100 random edits, so build the table bottom-up rather than recursing 3,000 calls deep.

<Hints>
<Hint>
Let `D(i, j)` be the fewest edits turning the first i characters of `source` into the first j of `target`. Turning i characters into nothing takes i deletions; building j characters from nothing takes j insertions. Those are row 0 and column 0.
</Hint>
<Hint>
If `source[i - 1] == target[j - 1]`, it's `D(i - 1, j - 1)`. Otherwise it's 1 plus the smallest of `D(i - 1, j - 1)` (replace), `D(i - 1, j)` (delete) and `D(i, j - 1)` (insert).
</Hint>
<Hint>
For the script, walk back from the bottom-right cell. At each cell, pick an arrow that explains its value (equal characters and the same value as the diagonal: keep; diagonal + 1: replace; above + 1: delete; left + 1: insert), record the step, and move. Reverse at the end.
</Hint>
</Hints>

## Solutions

<Approach title="Plain recursion" time="O(3ⁿ⁺ᵐ)" space="O(n + m)">

Try all three edits at every position. It's the clearest statement of the problem and the tests' reference on short words, but it explodes beyond a handful of characters.

</Approach>

<Approach title="Levenshtein table and traceback" time="O(n · m)" space="O(n · m)">

Fill the table once, read the corner for the distance, and walk back through it for the script. The checks are tried in the order keep, replace, delete, insert; the guards `i > 0` and `j > 0` handle the edges, where only insertions or only deletions remain.

```swift
public enum WordEditScript {
    public enum Step: Equatable {
        case keep(Character)
        case replace(Character, with: Character)
        case delete(Character)
        case insert(Character)
    }

    private static func table(_ a: [Character], _ b: [Character]) -> [[Int]] {
        let n = a.count, m = b.count
        var table = Array(repeating: Array(repeating: 0, count: m + 1), count: n + 1)
        for i in 0...n {
            for j in 0...m {
                if i == 0 {
                    table[i][j] = j
                } else if j == 0 {
                    table[i][j] = i
                } else if a[i - 1] == b[j - 1] {
                    table[i][j] = table[i - 1][j - 1]
                } else {
                    table[i][j] = 1 + min(table[i - 1][j - 1], table[i - 1][j], table[i][j - 1])
                }
            }
        }
        return table
    }

    public static func distance(from source: String, to target: String) -> Int {
        let a = Array(source), b = Array(target)
        return table(a, b)[a.count][b.count]
    }

    public static func script(from source: String, to target: String) -> [Step] {
        let a = Array(source), b = Array(target)
        let table = table(a, b)
        var steps: [Step] = []
        var i = a.count, j = b.count
        while i > 0 || j > 0 {
            if i > 0 && j > 0 && a[i - 1] == b[j - 1] && table[i][j] == table[i - 1][j - 1] {
                steps.append(.keep(a[i - 1]))
                i -= 1
                j -= 1
            } else if i > 0 && j > 0 && table[i][j] == table[i - 1][j - 1] + 1 {
                steps.append(.replace(a[i - 1], with: b[j - 1]))
                i -= 1
                j -= 1
            } else if i > 0 && table[i][j] == table[i - 1][j] + 1 {
                steps.append(.delete(a[i - 1]))
                i -= 1
            } else {
                steps.append(.insert(b[j - 1]))
                j -= 1
            }
        }
        return steps.reversed()
    }
}
```

The replace branch can never produce a replace with the same character: equal characters always satisfy the keep branch first, because their cell equals the diagonal. For `distance` alone, two rows are enough, giving O(m) memory.

</Approach>
