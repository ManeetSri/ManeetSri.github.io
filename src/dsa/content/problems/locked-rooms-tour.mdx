A building has n rooms numbered 0 to n − 1. Room 0 is open and every other room is locked. Each room contains some keys: `keys[i]` lists the rooms that the keys lying in room i open. You can pick up every key in a room you're in, and visit rooms you've unlocked in any order. Return `true` if you can get into every room.

`LockedRoomsTour.canOpenAll(_ keys: [[Int]]) -> Bool`

## Examples

| `keys` | Returns |
| --- | --- |
| `[[1], [2], [3], []]` | `true` |
| `[[1, 3], [3, 0, 1], [2], [0]]` | `false` |
| `[[2], [], [1]]` | `true` |
| `[[]]` | `true` |
| `[[], [0]]` | `false` |

In the first example, room 0 has the key to room 1, which has the key to room 2, which has the key to room 3. In the second, the only key to room 2 is inside room 2. In the third, you go from room 0 to room 2, pick up the key to room 1, and go back for it.

## Constraints

- `1 ≤ n ≤ 100,000`, with up to 1,000,000 keys in total.
- Every key opens a room from 0 to n − 1. A room may hold several keys to the same room, keys to rooms already open, or its own key.
- The tests include a chain of 100,000 rooms, each holding the next room's key. A recursive search would go 100,000 calls deep and crash the test thread: use an explicit stack or a queue.

<Hints>
<Hint>
The rooms are vertices, and a key in room i that opens room j is a directed edge from i to j. The question is whether every vertex is reachable from vertex 0.
</Hint>
<Hint>
Search from room 0 with DFS or BFS, keeping an `opened` array. Mark a room as opened the moment you find its key, so it's only pushed once.
</Hint>
<Hint>
Count the rooms as you open them. At the end, compare the count with `keys.count`.
</Hint>
</Hints>

## Solutions

<Approach title="Iterative DFS from room 0" time="O(n + k) for k keys" space="O(n)">

Each room is pushed once, when its first key is found, and each key is looked at once, when its room is popped.

```swift
public enum LockedRoomsTour {
    public static func canOpenAll(_ keys: [[Int]]) -> Bool {
        var opened = Array(repeating: false, count: keys.count)
        opened[0] = true
        var openedCount = 1
        var stack = [0]
        while let room = stack.popLast() {
            for key in keys[room] where !opened[key] {
                opened[key] = true                       // mark when found, so it's pushed once
                openedCount += 1
                stack.append(key)
            }
        }
        return openedCount == keys.count
    }
}
```

A BFS with a head-index queue works just as well. Only reachability matters here, so the order rooms are opened in makes no difference.

</Approach>
