Houses stand along a straight road at the given positions. A survey lists the distance between **every pair** of houses, sorted from smallest to largest. Return the kth distance on that list, counting from 1, without building the list.

`KthSmallestHouseGap.kthGap(_ houses: [Int], k: Int) -> Int`

With n houses there are n(n − 1) / 2 pairs. Two houses may share a position, and their distance is 0.

## Examples

| `houses` | `k` | Output |
| --- | --- | --- |
| `[1, 3, 1]` | `1` | `0` |
| `[1, 6, 1]` | `3` | `5` |
| `[1, 3, 7, 10]` | `4` | `6` |
| `[5, 5, 5]` | `3` | `0` |
| `[10, 1]` | `1` | `9` |

For `[1, 3, 7, 10]`, the six distances are 2, 6, 9, 4, 7 and 3. Sorted, they're 2, 3, 4, 6, 7, 9, so the 4th is 6.

## Constraints

- `2 ≤ houses.count ≤ 100,000`, positions between 0 and 10⁹.
- `1 ≤ k ≤ houses.count × (houses.count − 1) / 2`.
- The tests use 100,000 houses: about 5 × 10⁹ pairs, far too many to list or to push through a heap.

<Hints>
<Hint>
Flip the question. Instead of "what's the kth distance?", ask "how many pairs are at most d apart?". That count only grows as d grows, so the answer is the smallest d whose count reaches k.
</Hint>
<Hint>
Binary search on d over the range of possible distances, from 0 to the largest position minus the smallest. The search needs a fast way to count the pairs at most d apart.
</Hint>
<Hint>
Sort the houses first. Then, for each right end j, the houses at most d to its left form a contiguous block ending at j, and its left edge only ever moves right as j does. So two pointers count all the pairs for one d in O(n): add `j − left` for each j after moving `left` past every house more than d away.
</Hint>
</Hints>

## Solutions

<Approach title="List and sort every distance" time="O(n² log n)" space="O(n²)">

Compute all n(n − 1) / 2 distances, sort them and pick index k − 1. Fine for a few hundred houses, and it's how the tests check small cases, but 100,000 houses would need about 40 GB to hold the list alone.

</Approach>

<Approach title="Binary search on the distance, two pointers to count" time="O(n log n + n log D)" space="O(n)">

```swift
public enum KthSmallestHouseGap {
    public static func kthGap(_ houses: [Int], k: Int) -> Int {
        let sorted = houses.sorted()

        // How many pairs are at most d apart?
        func pairs(within d: Int) -> Int {
            var count = 0
            var left = 0
            for right in sorted.indices {
                while sorted[right] - sorted[left] > d { left += 1 }
                count += right - left
            }
            return count
        }

        var low = 0
        var high = sorted[sorted.count - 1] - sorted[0]   // every pair is within this
        while low < high {
            let mid = low + (high - low) / 2
            if pairs(within: mid) >= k {
                high = mid                                  // mid works: the answer is mid or smaller
            } else {
                low = mid + 1
            }
        }
        return low
    }
}
```

The answer is always a real distance: the smallest d with at least k pairs within it must be the distance of some pair, or the count would already have reached k at d − 1. D is the spread of the positions, so the search takes about 30 counting passes for positions up to 10⁹.

</Approach>
