Two words are **anagrams** if one can be made by rearranging the letters of the other, using every letter exactly once. Given two strings of lowercase English letters, return whether they're anagrams. Two empty strings are anagrams of each other.

`AnagramSlots.areAnagrams(_ first: String, _ second: String) -> Bool`

## Examples

| `first` | `second` | Output |
| --- | --- | --- |
| `"listen"` | `"silent"` | `true` |
| `"rat"` | `"car"` | `false` |
| `"aab"` | `"abb"` | `false` |
| `"abc"` | `"abcd"` | `false` |
| `""` | `""` | `true` |

`"aab"` and `"abb"` use the same letters, but not the same number of times, so they aren't anagrams.

## Constraints

- `0 ≤ first.count, second.count ≤ 50,000`
- Both strings contain only the lowercase letters `a` to `z`.

<Hints>
<Hint>
Anagrams have exactly the same letter counts. If the lengths differ, you can answer straight away.
</Hint>
<Hint>
Count each word's letters in a `[Int](repeating: 0, count: 26)` array, using `Int(ch.asciiValue! - 97)` (or `Int(byte - 97)` over `utf8`) to find each letter's slot. Then compare the two arrays with `==`.
</Hint>
<Hint>
With one array: count `first`'s letters up and `second`'s letters down. They're anagrams exactly when every slot ends at 0, which `counts.allSatisfy { $0 == 0 }` checks.
</Hint>
</Hints>

## Solutions

<Approach title="Brute force: sort both" time="O(n log n)" space="O(n)">

Sorting puts each word's letters in a standard order, so anagrams become identical. Correct and short, but sorting does more work than needed.

```swift
public static func areAnagrams(_ first: String, _ second: String) -> Bool {
    first.sorted() == second.sorted()
}
```

</Approach>

<Approach title="Two count arrays" time="O(n)" space="O(1)">

Count each word into its own 26-slot array, then compare. Each array has 26 elements however long the words are, so the extra space is constant.

```swift
public static func areAnagrams(_ first: String, _ second: String) -> Bool {
    func counts(_ word: String) -> [Int] {
        var result = [Int](repeating: 0, count: 26)
        for byte in word.utf8 {
            result[Int(byte - 97)] += 1
        }
        return result
    }
    return counts(first) == counts(second)
}
```

`counts` is a nested helper function, from M05.

</Approach>

<Approach title="One array, counting up and down" time="O(n)" space="O(1)">

Check the lengths first, then let the second word cancel out the first. Any slot left non-zero is a letter that doesn't balance.

```swift
public enum AnagramSlots {
    public static func areAnagrams(_ first: String, _ second: String) -> Bool {
        guard first.utf8.count == second.utf8.count else { return false }
        var counts = [Int](repeating: 0, count: 26)
        for byte in first.utf8 {
            counts[Int(byte - 97)] += 1
        }
        for byte in second.utf8 {
            counts[Int(byte - 97)] -= 1
        }
        return counts.allSatisfy { $0 == 0 }
    }
}
```

`utf8.count` is O(1) for a native Swift string, so the early length check is cheap.

</Approach>
