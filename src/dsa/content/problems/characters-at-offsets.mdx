Given a string and a list of offsets, return the characters at those offsets, in the order the offsets are listed, joined into a new string. Offsets count `Character`s from 0, the way `Array(text)` numbers them, and every offset is valid. Offsets can repeat and can come in any order.

`CharactersAtOffsets.characters(in text: String, at offsets: [Int]) -> String`

The direct way finds each character with `text.index(text.startIndex, offsetBy: offset)`, which walks `offset` characters from the start every time. For a string of n characters and q offsets, that's O(n · q). Make it **O(n + q)**.

## Examples

| Text | Offsets | Output |
| --- | --- | --- |
| `"swift"` | `[0, 4, 2]` | `"sti"` |
| `"banana"` | `[1, 3, 5]` | `"aaa"` |
| `"abc"` | `[2, 2, 0]` | `"cca"` |
| `"café 🇬🇧!"` | `[3, 5, 6]` | `"é🇬🇧!"` |
| `"hello"` | `[]` | `""` |

## Constraints

- `0 ≤ text.count ≤ 100,000`
- `0 ≤ offsets.count ≤ 100,000`
- `0 ≤ offsets[i] < text.count`

<Hints>
<Hint>
Where does the slow version repeat work? Every lookup walks from the very start of the string, so the same characters get walked past over and over.
</Hint>
<Hint>
Pay for the walk once. `Array(text)` builds a `[Character]` in O(n), and indexing an array is O(1).
</Hint>
<Hint>
Append each character to a result string with `result.append(character)`, or collect a `[Character]` and turn it into a string at the end with `String(characters)`.
</Hint>
</Hints>

## Solutions

<Approach title="Index the String for every offset" time="O(n · q)" space="O(q) for the result">

Correct, and it looks innocent, but `index(_:offsetBy:)` is O(offset). On the test with 50,000 characters and 50,000 offsets it takes about 2 seconds, compared with about a hundredth of a second for the next approach.

```swift
public static func characters(in text: String, at offsets: [Int]) -> String {
    var result = ""
    for offset in offsets {
        result.append(text[text.index(text.startIndex, offsetBy: offset)])
    }
    return result
}
```

</Approach>

<Approach title="Convert to an array once" time="O(n + q)" space="O(n)">

One O(n) pass turns the string into an array of characters, and every lookup after that is O(1). It trades O(n) extra memory for a huge saving in time, the space-for-time trade from the space complexity lesson.

```swift
public enum CharactersAtOffsets {
    public static func characters(in text: String, at offsets: [Int]) -> String {
        let characters = Array(text)
        var result = ""
        for offset in offsets {
            result.append(characters[offset])
        }
        return result
    }
}
```

Converting to `[Character]` keeps whole characters together, so an accented letter or a flag emoji counts as one, exactly as the offsets do. `Array(text.utf8)` would be even faster, but it numbers bytes, not characters, and would split "é" and "🇬🇧" apart.

</Approach>
