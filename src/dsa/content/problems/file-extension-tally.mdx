Given a list of file names, count how many files have each extension. The extension is the text after the **last** `.` in the name. Return a dictionary from each extension to its count.

`FileExtensionTally.tally(_ fileNames: [String]) -> [String: Int]`

A name has no extension, and isn't counted, when:

- it contains no `.` at all, like `"README"`;
- its only `.` is the very first character, like `".gitignore"` (a hidden file, not an extension);
- it ends with `.`, like `"notes."`, so nothing comes after the last dot.

Extensions are compared exactly as written, so `"JPG"` and `"jpg"` are counted separately.

## Examples

| `fileNames` | Output |
| --- | --- |
| `["photo.jpg", "notes.txt", "report.final.txt", "song.mp3", "beach.jpg"]` | `["jpg": 2, "txt": 2, "mp3": 1]` |
| `["archive.tar.gz", ".config.json", "data.JSON"]` | `["gz": 1, "json": 1, "JSON": 1]` |
| `["README", ".gitignore", "notes."]` | `[:]` |
| `[]` | `[:]` |

`"report.final.txt"` counts as `txt`, because only the last dot matters. `".config.json"` has two dots; the last one isn't the first character, so its extension is `json`.

## Constraints

- `0 ≤ fileNames.count ≤ 10,000`
- Each name has at most 255 characters.

<Hints>
<Hint>
`name.lastIndex(of: ".")` gives the position of the last dot, or `nil` if there isn't one. Compare it with `name.startIndex` to spot names like `".gitignore"`.
</Hint>
<Hint>
The extension starts one character after the dot: `name[name.index(after: dot)...]`. That's a `Substring`, a view into `name`, and it might be empty.
</Hint>
<Hint>
Try `counts[ext, default: 0] += 1` with the substring and Swift refuses: the dictionary's keys are `String`s. Convert with `String(ext)`. That copy is what the function should return anyway: keys that outlive the function shouldn't keep every file name alive.
</Hint>
</Hints>

## Solutions

<Approach title="Find the last dot, slice, convert" time="O(L)" space="O(E)">

Here L is the total length of all the names, and E the total length of the distinct extensions kept in the result. For each name, find its last dot, rule out the three cases with no extension, and take the substring after the dot. Slicing is O(1), because the substring just points into `name`. The only copy is `String(ext)`, made at the moment the extension is stored in the dictionary.

```swift
public enum FileExtensionTally {
    public static func tally(_ fileNames: [String]) -> [String: Int] {
        var counts: [String: Int] = [:]
        for name in fileNames {
            guard let dot = name.lastIndex(of: "."), dot != name.startIndex else {
                continue
            }
            let ext = name[name.index(after: dot)...]
            if !ext.isEmpty {
                counts[String(ext), default: 0] += 1
            }
        }
        return counts
    }
}
```

`name.index(after: dot)` is always safe, even when the dot is the last character: stepping after it lands on `name.endIndex`, and `name[endIndex...]` is an empty substring, which the `isEmpty` check rejects.

Splitting at dots, as in `name.split(separator: ".")`, looks tempting but gets the edge cases wrong: `split` drops empty pieces, so `"notes."` and `"notes"` split the same way, and you'd need extra checks to tell them apart. Finding the last dot answers the question directly.

</Approach>
