Words here are made of 62 symbols: the lowercase letters, the uppercase letters and the digits, with `a` and `A` counting as different symbols. Find two words that share **no** symbol and make the product of their lengths as large as possible. A `UInt64` has room for all 62 symbols, so each word's symbols fit in one integer used as a set.

`DisjointLetterWords.symbolSet(_ word: String) -> UInt64` returns the set of symbols in `word`, with `a`…`z` as bits 0…25, `A`…`Z` as bits 26…51 and `0`…`9` as bits 52…61.

`DisjointLetterWords.bestProduct(_ words: [String]) -> Int` returns the largest length × length over two different positions in `words` whose words share no symbol, or 0 if there's no such pair.

## Examples

| Call | Output | Why |
| --- | --- | --- |
| `symbolSet("ba")` | `3` | bits 0 and 1 |
| `symbolSet("A")` | `67108864` | bit 26, which is 1 shifted left 26 times |
| `bestProduct(["stack", "queue", "heap", "trie", "graph"])` | `25` | "stack" and "queue" share nothing |
| `bestProduct(["zebra", "MOON", "42"])` | `20` | "zebra" and "MOON" |
| `bestProduct(["aa", "AA", "a1"])` | `4` | case matters: "aa" and "AA" share nothing |
| `bestProduct(["abc", "cab", "bca"])` | `0` | every pair shares a letter |

## Constraints

- `0 ≤ words.count ≤ 2000`, and each word has 0 to 100 symbols, all ASCII letters or digits.
- With 2,000 words there are about 2 million pairs. Make each pair's check a single operation.

<Hints>
<Hint>
For `symbolSet`, work out each character's bit from its ASCII value: `character.asciiValue` gives a `UInt8`. Lowercase letters start at 97, uppercase at 65 and digits at 48. Set the bit with `set |= 1 << bit`, on a `UInt64`.
</Hint>
<Hint>
Two words share no symbol exactly when their sets have no bit in common, which is when `first & second == 0`. That's one AND, however long the words are.
</Hint>
<Hint>
Compute every word's set and length once, before the pair loop. Then check each pair i, j with j after i, and keep the best product among the pairs whose sets AND to zero.
</Hint>
</Hints>

## Solutions

<Approach title="Compare the words letter by letter" time="O(n² × L)" space="O(L)">

For each pair, build a `Set<Character>` from one word and check whether any character of the other is in it. It's correct, but it allocates a set and scans characters for each of the 2 million pairs.

</Approach>

<Approach title="One UInt64 per word" time="O(n × L + n²)" space="O(n)">

Each word becomes one 64-bit set, so testing a pair is a single AND, as in the lesson's "do these words share a letter?" check. A word's length counts its characters, and since every symbol is ASCII, `utf8.count` gives it without walking grapheme clusters.

```swift
public enum DisjointLetterWords {
    public static func symbolSet(_ word: String) -> UInt64 {
        var set: UInt64 = 0
        for character in word {
            guard let ascii = character.asciiValue else { continue }
            let bit: UInt8
            switch ascii {
            case 97...122: bit = ascii - 97
            case 65...90: bit = ascii - 65 + 26
            default: bit = ascii - 48 + 52
            }
            set |= 1 << bit
        }
        return set
    }

    public static func bestProduct(_ words: [String]) -> Int {
        let sets = words.map(symbolSet)
        let lengths = words.map { $0.utf8.count }
        var best = 0
        for i in 0..<words.count {
            for j in (i + 1)..<words.count where sets[i] & sets[j] == 0 {
                best = max(best, lengths[i] * lengths[j])
            }
        }
        return best
    }
}
```

An empty word has the empty set, which shares nothing with anything, but its length is 0, so it never improves the answer. If many words have the same set, only the longest of them matters, which is a neat way to cut the number of pairs when words repeat letters a lot.

</Approach>
