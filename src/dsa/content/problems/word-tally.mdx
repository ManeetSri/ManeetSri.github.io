Given an array of words, return a dictionary that maps each word to the number of times it appears. Words are compared exactly, so `"Cat"` and `"cat"` are different words. Words that never appear have no entry.

`WordTally.tally(_ words: [String]) -> [String: Int]`

## Examples

| Input | Output |
| --- | --- |
| `["red", "blue", "red", "green", "red", "blue"]` | `["red": 3, "blue": 2, "green": 1]` |
| `["Cat", "cat", "cat"]` | `["Cat": 1, "cat": 2]` |
| `["swift"]` | `["swift": 1]` |
| `[]` | `[:]` |

The tests compare whole dictionaries, so the order you add keys in doesn't matter.

## Constraints

- `0 ≤ words.count ≤ 100,000`
- Each word has 1 to 20 characters.

<Hints>
<Hint>
Start with an empty dictionary, `var counts: [String: Int] = [:]`, and loop over the words.
</Hint>
<Hint>
For each word you want to add one to its count, treating a word you haven't seen yet as having a count of 0.
</Hint>
<Hint>
`counts[word, default: 0] += 1` does exactly that in one line.
</Hint>
</Hints>

## Solutions

<Approach title="Loop with the default: subscript" time="O(n)" space="O(u)">

Each update is an O(1) dictionary operation on average, so n words take O(n). The dictionary holds one entry per distinct word, u of them.

```swift
public enum WordTally {
    public static func tally(_ words: [String]) -> [String: Int] {
        var counts: [String: Int] = [:]
        for word in words {
            counts[word, default: 0] += 1
        }
        return counts
    }
}
```

</Approach>

<Approach title="reduce(into:)" time="O(n)" space="O(u)">

The same work as one expression, using `reduce(into:)` from M06:

```swift
public static func tally(_ words: [String]) -> [String: Int] {
    words.reduce(into: [:]) { counts, word in
        counts[word, default: 0] += 1
    }
}
```

</Approach>
