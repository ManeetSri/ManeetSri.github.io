Two players face a row of coins. They take turns, and on each turn a player removes **one coin from either end** of the row and keeps it. When the row is empty, the game is over. Both players play perfectly, each trying to finish as far ahead of the other as possible. Return the first player's total minus the second player's total.

`CoinRowDuel.bestMargin(_ coins: [Int]) -> Int`

A positive answer means the first player wins, 0 is a tie, and a negative answer means the second player wins.

## Examples

| `coins` | Output | How perfect play goes |
| --- | --- | --- |
| `[3, 9, 1, 2]` | `7` | first takes 2, and the 9 falls to them next: 11 to 4 |
| `[2, 7, 3]` | `-2` | whichever end the first player takes, the 7 goes to the second |
| `[5, 1, 4]` | `2` | first takes 5, second takes 4, first takes 1 |
| `[8, 8]` | `0` | |
| `[6]` | `6` | |
| `[]` | `0` | |

Taking the bigger end isn't always best: in the first example, greedily taking 3 hands the 9 to the opponent and loses 5 to 10.

## Constraints

- `0 ≤ coins.count ≤ 1,000`
- `0 ≤ coins[i] ≤ 1,000,000`
- The tests use 1,000 coins, so playing out every possible game is impossible.

<Hints>
<Hint>
Whatever coins have already gone, the rest of the game only depends on which coins remain, and those always form a contiguous range i...j.
</Hint>
<Hint>
Instead of tracking two scores, track one number: the margin, the mover's total minus the other player's total from here on. Let `margin[i][j]` be the best margin the player about to move can guarantee on coins i...j.
</Hint>
<Hint>
If you take `coins[i]`, your opponent moves next on i + 1...j and gets `margin[i + 1][j]` over you. So `margin[i][j] = max(coins[i] - margin[i + 1][j], coins[j] - margin[i][j - 1])`, with `margin[i][i] = coins[i]`. Fill i from the bottom up.
</Hint>
</Hints>

## Solutions

<Approach title="Play out every game" time="O(2ⁿ)" space="O(n)">

Recursively let the mover try both ends and keep whichever leaves them best off. It's exactly the minimax recurrence without a memo, so the same ranges are solved again and again.

</Approach>

<Approach title="Minimax over ranges" time="O(n²)" space="O(n)">

The range i...j is the whole state. Row i of the table only needs row i + 1, so a single array is enough: before it's overwritten, `margin[j]` still holds the range i + 1...j, and `margin[j - 1]` already holds the range i...j − 1.

```swift
public enum CoinRowDuel {
    public static func bestMargin(_ coins: [Int]) -> Int {
        let n = coins.count
        guard n > 0 else { return 0 }
        var margin = Array(repeating: 0, count: n)
        for i in stride(from: n - 1, through: 0, by: -1) {
            margin[i] = coins[i]
            for j in stride(from: i + 1, to: n, by: 1) {
                margin[j] = max(coins[i] - margin[j], coins[j] - margin[j - 1])
            }
        }
        return margin[n - 1]
    }
}
```

The minus sign is what makes one table serve both players: each margin is measured from the point of view of whoever is about to move.

</Approach>
