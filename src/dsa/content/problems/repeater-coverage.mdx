Mobile repeaters along a motorway each cover a stretch `[start, end)`, in metres from the start of the road: positions from `start` up to, but not including, `end`. A stretch of road has a reliable signal when **at least `k`** repeaters cover it. Return the length of the **longest unbroken** stretch with a reliable signal, or `0` if there's none.

`RepeaterCoverage.longestReliableStretch(repeaters: [[Int]], atLeast k: Int) -> Int`

Two reliable pieces that touch, such as `[10, 20)` and `[20, 35)`, form one unbroken stretch.

## Examples

| `repeaters` | `k` | Output |
| --- | --- | --- |
| `[[10, 50], [30, 1000000], [40, 60], [999990, 2000000000]]` | `2` | `30` |
| `[[10, 50], [30, 1000000], [40, 60], [999990, 2000000000]]` | `1` | `1999999990` |
| `[[10, 50], [30, 1000000], [40, 60], [999990, 2000000000]]` | `3` | `10` |
| `[[0, 10], [10, 20], [25, 30]]` | `1` | `20` |
| `[[0, 5], [3, 8]]` | `3` | `0` |
| `[]` | `1` | `0` |

In the first example, two repeaters overlap on `[30, 60)` (first the stretches `[10, 50)` and `[30, 1000000)`, then `[40, 60)` and `[30, 1000000)`) and again on `[999990, 1000000)`. The longer of those is 30 metres.

## Constraints

- `0 ≤ repeaters.count ≤ 100,000` and `1 ≤ k ≤ 100,000`
- `0 ≤ start < end ≤ 2,000,000,000`
- The tests use 50,000 repeaters spread over two billion metres, so an array with one slot per metre is impossible.

<Hints>
<Hint>
The number of repeaters covering a point can only change at a `start` or an `end`. Between two neighbouring endpoints, it's constant.
</Hint>
<Hint>
Compress the endpoints: sort and dedupe them. Put +1 at each `start`'s rank and −1 at each `end`'s rank in a difference array, and a running sum gives the coverage of the piece from `points[i]` to `points[i + 1]`.
</Hint>
<Hint>
Sweep the pieces in order with a running length: add a reliable piece's real length (`points[i + 1] - points[i]`) to it, and reset it to 0 at an unreliable piece. Pieces are consecutive, so touching reliable pieces join up automatically. Track the largest running length.
</Hint>
</Hints>

## Solutions

<Approach title="Check every metre" time="O(n · L)" space="O(1)">

For every position up to the largest `end`, count the repeaters covering it. With L = two billion metres, this never finishes.

</Approach>

<Approach title="Compress and sweep" time="O(n log n)" space="O(n)">

```swift
public enum RepeaterCoverage {
    public static func longestReliableStretch(repeaters: [[Int]], atLeast k: Int) -> Int {
        let points = Array(Set(repeaters.flatMap { [$0[0], $0[1]] })).sorted()
        var rankOf: [Int: Int] = [:]
        for (rank, point) in points.enumerated() { rankOf[point] = rank }

        var change = [Int](repeating: 0, count: points.count)
        for repeater in repeaters {
            change[rankOf[repeater[0]]!] += 1
            change[rankOf[repeater[1]]!] -= 1
        }

        var covering = 0
        var running = 0
        var longest = 0
        for i in points.indices.dropLast() {
            covering += change[i]                     // the coverage of points[i] ..< points[i + 1]
            if covering >= k {
                running += points[i + 1] - points[i]
                longest = max(longest, running)
            } else {
                running = 0
            }
        }
        return longest
    }
}
```

The pieces between neighbouring compressed points tile the road from the first endpoint to the last with no gaps, so a stretch only breaks at a piece whose coverage is below `k`. Lengths always come from `points`, never from ranks.

An equivalent approach without compression: make a list of events `(position, +1 or −1)`, sort it, and sweep it, measuring the distance between consecutive event positions. Compression is the same idea with the events grouped by position.

</Approach>
