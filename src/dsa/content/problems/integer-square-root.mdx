Return the integer square root of `x`: the largest whole number whose square is at most `x`. Don't use `Double`, `sqrt` or `pow`.

`IntegerSquareRoot.floorRoot(of x: Int) -> Int`

It must be exact and must never overflow, for every `x` from 0 to `Int.max`. Aim for O(log x).

## Examples

| `x` | Output | Why |
| --- | --- | --- |
| `0` | `0` | 0 × 0 = 0 |
| `8` | `2` | 2 × 2 = 4 ≤ 8, but 3 × 3 = 9 > 8 |
| `16` | `4` | a perfect square |
| `26` | `5` | 5 × 5 = 25 ≤ 26 < 36 |
| `999_999_999_999_999_999` | `999_999_999` | one less than 10¹⁸ |
| `Int.max` | `3_037_000_499` | its square is a little below `Int.max` |

## Constraints

- `0 ≤ x ≤ Int.max`

<Hints>
<Hint>
Searching the numbers 0, 1, 2, …, x, the question "is r × r ≤ x?" answers yes, yes, …, yes, no, no. You want the last yes, so binary search for it.
</Hint>
<Hint>
For large x, `mid * mid` overflows, and Swift traps. For whole numbers mid ≥ 1, `mid <= x / mid` means exactly the same as `mid * mid <= x`, and division can't overflow.
</Hint>
<Hint>
Return x itself for 0 and 1. Otherwise search `low = 1`, `high = x / 2` with a closed range: if `mid <= x / mid`, move `low = mid + 1`, else `high = mid - 1`. When the loop ends, `high` is the last value that passed.
</Hint>
</Hints>

## Solutions

<Approach title="Count up" time="O(√x)" space="O(1)">

Try 1, 2, 3, … until the next square is too big. The test uses division, so it doesn't overflow, but for `Int.max` it would take about three billion steps.

```swift
public static func floorRoot(of x: Int) -> Int {
    var root = 0
    while root + 1 <= x / (root + 1) {
        root += 1
    }
    return root
}
```

</Approach>

<Approach title="Binary search with a division test" time="O(log x)" space="O(1)">

Squares grow as r grows, so "r × r ≤ x" is monotonic. A closed binary search over 1 to x / 2 (enough for any x ≥ 2) finds the last r that passes in at most 62 steps. Writing the test as `mid <= x / mid` keeps every intermediate value within range.

```swift
public enum IntegerSquareRoot {
    public static func floorRoot(of x: Int) -> Int {
        if x < 2 {
            return x                             // 0 and 1 are their own roots
        }
        var low = 1
        var high = x / 2                         // for x ≥ 2, the root is at most x / 2
        while low <= high {
            let mid = low + (high - low) / 2
            if mid <= x / mid {
                low = mid + 1                    // mid × mid ≤ x: look higher
            } else {
                high = mid - 1                   // mid × mid > x: too big
            }
        }
        return high                              // the last value that passed
    }
}
```

`Int(Double(x).squareRoot())` fails this problem: a `Double` keeps only about 16 significant digits, so 999,999,999,999,999,999 is rounded up to 10¹⁸ and the answer comes out one too big.

</Approach>
