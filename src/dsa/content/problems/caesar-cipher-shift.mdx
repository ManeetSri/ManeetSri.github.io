A Caesar shift moves every letter a fixed number of places along the alphabet, wrapping from `z` back round to `a`. Given a string and a whole number `k`, move every **lowercase** letter `a` to `z` forward by `k` places. A negative `k` moves letters backwards. Every other character, including uppercase letters, digits, spaces and punctuation, stays exactly as it is.

`CaesarCipherShift.shift(_ text: String, by k: Int) -> String`

## Examples

| `text` | `k` | Output |
| --- | --- | --- |
| `"hello"` | `3` | `"khoor"` |
| `"xyz"` | `3` | `"abc"` |
| `"abc"` | `-1` | `"zab"` |
| `"abc"` | `27` | `"bcd"` |
| `"Hello, World! 42"` | `1` | `"Hfmmp, Wpsme! 42"` |

## Constraints

- `0 ≤ text.count ≤ 100,000`
- `-10⁹ ≤ k ≤ 10⁹`
- `text` contains printable ASCII characters.

<Hints>
<Hint>
Shifting by 26 brings every letter back to itself. So only `k % 26` matters, and you can work it out once before the loop.
</Hint>
<Hint>
Watch out: in Swift, `-1 % 26` is `-1`, not `25`. `((k % 26) + 26) % 26` always gives a step from 0 to 25, and moving forward 25 is the same as moving back 1.
</Hint>
<Hint>
For each character: if its `asciiValue` is between 97 and 122, turn it into a position with `Int(ascii) - 97`, add the step, wrap with `% 26`, and turn it back with `Character(UnicodeScalar(UInt8(97 + position)))`. Otherwise append it unchanged. Build the result with `append`.
</Hint>
</Hints>

## Solutions

<Approach title="Shift each letter in turn" time="O(n)" space="O(n)">

Reduce `k` to a step in `0..<26` once, which handles negative and huge shifts in one go. Then convert each lowercase letter to a position, shift and wrap it, and convert it back. Everything else is copied across unchanged.

```swift
public enum CaesarCipherShift {
    public static func shift(_ text: String, by k: Int) -> String {
        let step = ((k % 26) + 26) % 26
        var result = ""
        result.reserveCapacity(text.utf8.count)
        for character in text {
            guard let ascii = character.asciiValue, ascii >= 97, ascii <= 122 else {
                result.append(character)
                continue
            }
            let position = (Int(ascii) - 97 + step) % 26
            result.append(Character(UnicodeScalar(UInt8(97 + position))))
        }
        return result
    }
}
```

What to notice:

- `guard let ... else` handles both non-ASCII characters (where `asciiValue` is `nil`) and ASCII characters that aren't lowercase letters.
- `Int(ascii) - 97` converts to `Int` before doing arithmetic, so nothing can overflow a `UInt8`.
- Reducing `k` once, before the loop, means the loop only ever adds a step from 0 to 25, so a position can never go negative.

</Approach>

<Approach title="Work on bytes" time="O(n)" space="O(n)">

Because the text is ASCII, you can shift the bytes directly and decode them at the end. This is the fastest version.

```swift
public static func shift(_ text: String, by k: Int) -> String {
    let step = ((k % 26) + 26) % 26
    var bytes = Array(text.utf8)
    for i in bytes.indices where bytes[i] >= 97 && bytes[i] <= 122 {
        bytes[i] = UInt8(97 + (Int(bytes[i]) - 97 + step) % 26)
    }
    return String(decoding: bytes, as: UTF8.self)
}
```

</Approach>
