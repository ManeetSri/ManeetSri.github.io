How many ways can you pick positions in `text`, from left to right, whose characters spell `word`? Two ways are different if they use different positions. The count can be enormous, so return it modulo 1,000,000,007.

`HiddenWordCount.ways(text: String, word: String) -> Int`

## Examples

| `text` | `word` | Output |
| --- | --- | --- |
| `"banana"` | `"ban"` | `3` |
| `"banana"` | `"ana"` | `4` |
| `"banana"` | `"nab"` | `0` |
| `"aaaa"` | `"aa"` | `6` |
| `"swift"` | `""` | `1` |
| `""` | `"a"` | `0` |

`"ban"` uses positions (0, 1, 2), (0, 1, 4) or (0, 3, 4). Any two of the four a's spell `"aa"`, so that's C(4, 2) = 6. The empty word can be picked in exactly one way: pick nothing.

## Constraints

- `text` has 0 to 3,000 characters and `word` has 0 to 1,000. Compare `Character`s.
- Picking 1,000 a's out of 3,000 can be done in a number of ways with 828 digits, so reduce modulo 1,000,000,007 as you go: the tests include it.

<Hints>
<Hint>
Let `W(i, j)` be the number of ways to pick the first j characters of `word` from the first i of `text`. The last text character is either skipped or used as the word's last character (only if they're equal). Those two groups don't overlap, so add them.
</Hint>
<Hint>
`W(i, 0) = 1` for every i (the empty word), and `W(0, j) = 0` for j > 0. One row is enough if you sweep j from right to left, so `ways[j - 1]` is still the previous text character's value.
</Hint>
<Hint>
Take `% 1_000_000_007` after every addition. Both terms are below the modulus, so their sum always fits in an `Int`.
</Hint>
</Hints>

## Solutions

<Approach title="Plain recursion" time="O(2ⁿ)" space="O(n)">

At each text position, skip it or (if it matches) use it, and count the ways that complete the word. It's correct, and the tests use it on short strings, where every count is below the modulus.

</Approach>

<Approach title="One-row counting DP" time="O(n · m)" space="O(m)">

```swift
public enum HiddenWordCount {
    public static func ways(text: String, word: String) -> Int {
        let modulus = 1_000_000_007
        let w = Array(word)
        var ways = Array(repeating: 0, count: w.count + 1)
        ways[0] = 1
        for letter in text {
            for j in stride(from: w.count, through: 1, by: -1) where w[j - 1] == letter {
                ways[j] = (ways[j] + ways[j - 1]) % modulus
            }
        }
        return ways[w.count]
    }
}
```

Sweeping j upwards instead would let one text character play two roles in the same pick: for `"aa"` in `"a"`, it would count 1 instead of 0.

</Approach>
