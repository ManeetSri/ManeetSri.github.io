Write a generic graph type, `AdjacencyGraphDesign.Graph<Vertex: Hashable>`, stored as adjacency lists. It's a struct, so copies are independent, and the caller chooses directed or undirected when creating it. Edges have `Int` weights, 1 unless given.

```swift
var graph = AdjacencyGraphDesign.Graph<String>(directed: false)
graph.addEdge(from: "Leeds", to: "York", weight: 40)
graph.vertices                    // ["Leeds", "York"]
graph.neighbors(of: "York")       // [(vertex: "Leeds", weight: 40)]
```

| Member | What it does |
| --- | --- |
| `init(directed:)`, `isDirected` | an empty graph, and which kind it is |
| `vertices` | every vertex, in the order each was first added |
| `edgeCount` | the number of edges; an undirected edge counts once |
| `contains(_:)` | whether a vertex is in the graph |
| `addVertex(_:)` | adds a vertex with no edges, unless it's already there |
| `addEdge(from:to:weight:)` | adds the edge (both ways when undirected), adding missing vertices first, `from` before `to` |
| `removeEdge(from:to:) -> Bool` | removes the edge (both ways when undirected); false if it wasn't there |
| `neighbors(of:)` | the edges leaving a vertex as `(vertex:, weight:)` pairs, in the order they were first added |
| `outDegree(of:)`, `inDegree(of:)` | how many edges leave and arrive at a vertex |

The rules, which match DSAKit's `Graph`:

- **At most one edge** from a vertex to another. Adding an edge that's already there replaces its weight and keeps its place in the neighbour list. In an undirected graph, `addEdge(from: "b", to: "a")` finds the edge added as `from: "a", to: "b"`.
- **A self-loop** (an edge from a vertex to itself) is stored once, and counts once in the vertex's out-degree and in-degree.
- **Unknown vertices** are fine to ask about: they have no neighbours and degree 0.
- **Removing** an edge keeps both vertices and the order of the other neighbours.

## Examples

| Calls on a directed graph | Then |
| --- | --- |
| `addEdge(from: "a", to: "b", weight: 5)`, `addEdge(from: "a", to: "c")` | `neighbors(of: "a")` is `[("b", 5), ("c", 1)]`, `inDegree(of: "b")` is 1 |
| then `addEdge(from: "a", to: "b", weight: 9)` | `neighbors(of: "a")` is `[("b", 9), ("c", 1)]`, `edgeCount` is still 2 |
| then `removeEdge(from: "b", to: "a")` | returns false: edges have a direction |
| then `removeEdge(from: "a", to: "b")` | returns true; `neighbors(of: "a")` is `[("c", 1)]` and `vertices` is still `["a", "b", "c"]` |

## Constraints

- Up to 200,000 operations per test, with any `Hashable` vertex type.
- `addEdge`, `addVertex`, `contains` and both degrees should be O(1) on average. The tests add 100,000 edges to one vertex and then add them all again, so finding an existing edge by walking a 100,000-entry list each time is far too slow.
- `removeEdge` may be O(degree), and `neighbors(of:)` is O(degree).

<Hints>
<Hint>
Keep `vertices` in an array (for order) and the adjacency lists in a dictionary keyed by vertex (for speed). A dictionary on its own would hand back the vertices in a different order on every run.
</Hint>
<Hint>
To spot a duplicate edge in O(1), keep a second dictionary beside each list: `weights[from][to]`. If it's already set, only replace the weight. `updateValue(_:forKey:)` returns the old value, or `nil` when the key is new, so one call does both jobs.
</Hint>
<Hint>
Write a private helper for one direction, say `link(from, to, weight) -> Bool` returning whether the edge is new, and call it twice for an undirected edge, unless `from == to`. Keep a dictionary of in-degrees and update it in the helper. Count `edgeCount` once per call to `addEdge`.
</Hint>
</Hints>

## Solutions

<Approach title="An adjacency list and a weight dictionary per vertex" time="O(1) average per add, O(degree) per removal" space="O(V + E)">

Every vertex has an array of targets in insertion order and a dictionary of weights for O(1) lookups. One-direction helpers keep the undirected case short.

```swift
public enum AdjacencyGraphDesign {
    public struct Graph<Vertex: Hashable> {
        public let isDirected: Bool
        public private(set) var vertices: [Vertex] = []
        public private(set) var edgeCount = 0
        private var targets: [Vertex: [Vertex]] = [:]          // the adjacency lists
        private var weights: [Vertex: [Vertex: Int]] = [:]     // weights[u][v] is the edge u → v
        private var incoming: [Vertex: Int] = [:]              // in-degrees

        public init(directed: Bool) {
            isDirected = directed
        }

        public func contains(_ vertex: Vertex) -> Bool {
            targets[vertex] != nil
        }

        public mutating func addVertex(_ vertex: Vertex) {
            guard targets[vertex] == nil else { return }
            targets[vertex] = []
            weights[vertex] = [:]
            incoming[vertex] = 0
            vertices.append(vertex)
        }

        public mutating func addEdge(from: Vertex, to: Vertex, weight: Int = 1) {
            addVertex(from)
            addVertex(to)
            let isNew = link(from, to, weight)
            if !isDirected && from != to {
                link(to, from, weight)
            }
            if isNew {
                edgeCount += 1
            }
        }

        @discardableResult
        public mutating func removeEdge(from: Vertex, to: Vertex) -> Bool {
            guard unlink(from, to) else { return false }
            if !isDirected && from != to {
                unlink(to, from)
            }
            edgeCount -= 1
            return true
        }

        public func neighbors(of vertex: Vertex) -> [(vertex: Vertex, weight: Int)] {
            guard let list = targets[vertex], let weight = weights[vertex] else { return [] }
            return list.map { (vertex: $0, weight: weight[$0]!) }
        }

        public func outDegree(of vertex: Vertex) -> Int {
            targets[vertex]?.count ?? 0
        }

        public func inDegree(of vertex: Vertex) -> Int {
            incoming[vertex] ?? 0
        }

        @discardableResult
        private mutating func link(_ from: Vertex, _ to: Vertex, _ weight: Int) -> Bool {
            let isNew = weights[from]!.updateValue(weight, forKey: to) == nil
            if isNew {
                targets[from]!.append(to)
                incoming[to]! += 1
            }
            return isNew
        }

        @discardableResult
        private mutating func unlink(_ from: Vertex, _ to: Vertex) -> Bool {
            guard weights[from]?.removeValue(forKey: to) != nil else { return false }
            targets[from]!.remove(at: targets[from]!.firstIndex(of: to)!)
            incoming[to]! -= 1
            return true
        }
    }
}
```

`weights[from]!.updateValue(...)` changes the inner dictionary in place: the `!` here unwraps a stored value for mutation rather than making a copy. `from != to` stops an undirected self-loop being linked twice.

</Approach>

<Approach title="Only a dictionary of dictionaries" time="O(1) average per operation" space="O(V + E)">

`[Vertex: [Vertex: Int]]` alone makes removal O(1) too, but a dictionary's order changes from run to run, so `neighbors(of:)` would list edges in a different order each time and fail the order tests. It's a fine choice when order doesn't matter; DSAKit and this problem promise insertion order because it makes output reproducible.

</Approach>
