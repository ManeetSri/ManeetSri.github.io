Two security cameras watch the same door. Each camera's log lists the windows when it was recording, sorted by start. Return every window when **both** cameras were recording, sorted by start.

`SharedRecordingWindows.sharedWindows(_ first: [[Int]], _ second: [[Int]]) -> [[Int]]`

A window `[start, end]` is closed: it covers every whole second from `start` to `end`, inclusive. Within one camera's log, no two windows share a second. When the cameras share just one second, that's a window too, such as `[5, 5]`.

## Examples

| `first` | `second` | Output |
| --- | --- | --- |
| `[[0, 4], [7, 10]]` | `[[2, 8]]` | `[[2, 4], [7, 8]]` |
| `[[1, 5]]` | `[[5, 9]]` | `[[5, 5]]` |
| `[[1, 3], [6, 9]]` | `[[4, 5]]` | `[]` |
| `[[0, 10]]` | `[[1, 2], [4, 6], [9, 12]]` | `[[1, 2], [4, 6], [9, 10]]` |
| `[]` | `[[1, 2]]` | `[]` |

## Constraints

- `0 ≤ first.count, second.count ≤ 100,000`
- Each list is sorted by start, and each of its windows starts at least 1 after the previous one ends.
- Every window has `start ≤ end`, with values between 0 and 10⁹.
- Aim for O(m + n) time. Checking every pair of windows could take 10¹⁰ steps.

<Hints>
<Hint>
Two windows share the stretch from the later start to the earlier end, `[max of starts, min of ends]`, as long as that start is at most that end.
</Hint>
<Hint>
Keep one index into each list. After you've compared the two current windows, one of them can't meet anything else in the other list. Which one?
</Hint>
<Hint>
Move on from whichever window **ends first**. Every later window in the other list starts after the other current window ends, so after this one ends too. When both end together, moving either is fine.
</Hint>
</Hints>

## Solutions

<Approach title="Every pair" time="O(m × n + k log k)" space="O(k)">

Here k is the number of shared windows. Intersect every window of one list with every window of the other, then sort what's found. Too slow for big logs, but a reliable checker.

```swift
public static func sharedWindows(_ first: [[Int]], _ second: [[Int]]) -> [[Int]] {
    var result: [[Int]] = []
    for a in first {
        for b in second {
            let start = max(a[0], b[0])
            let end = min(a[1], b[1])
            if start <= end {
                result.append([start, end])
            }
        }
    }
    return result.sorted { $0[0] < $1[0] }
}
```

</Approach>

<Approach title="Two pointers" time="O(m + n)" space="O(1) besides the result">

Each step records at most one shared window and moves one pointer forwards, so there are at most m + n steps, and the windows come out already sorted.

```swift
public enum SharedRecordingWindows {
    public static func sharedWindows(_ first: [[Int]], _ second: [[Int]]) -> [[Int]] {
        var result: [[Int]] = []
        var i = 0
        var j = 0
        while i < first.count && j < second.count {
            let start = max(first[i][0], second[j][0])
            let end = min(first[i][1], second[j][1])
            if start <= end {
                result.append([start, end])
            }
            if first[i][1] < second[j][1] {
                i += 1                      // first[i] can't meet any later window of second
            } else {
                j += 1
            }
        }
        return result
    }
}
```

The `<=` keeps single-second windows like `[5, 5]`, because the windows are closed. For half-open intervals, the test would be `start < end`.

</Approach>
