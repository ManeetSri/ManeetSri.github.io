A festival runs from day 1 to day `days`. Each pledge promises `people` volunteers on **every** day from day `first` through day `last`, inclusive. Return how many volunteers there are on each day, as an array whose element 0 is day 1.

`VolunteerRoster.volunteersPerDay(days: Int, pledges: [(first: Int, last: Int, people: Int)]) -> [Int]`

## Examples

| `days` | `pledges` | Output |
| --- | --- | --- |
| `5` | `[(1, 3, 4), (2, 5, 1), (4, 4, 10)]` | `[4, 5, 5, 11, 1]` |
| `3` | `[(1, 3, 7)]` | `[7, 7, 7]` |
| `4` | `[(4, 4, 3)]` | `[0, 0, 0, 3]` |
| `3` | `[]` | `[0, 0, 0]` |

In the first example, day 4 gets 1 volunteer from the second pledge and 10 from the third.

## Constraints

- `1 ≤ days ≤ 100,000` and `0 ≤ pledges.count ≤ 100,000`
- `1 ≤ first ≤ last ≤ days` and `1 ≤ people ≤ 10,000`
- Aim for O(days + pledges) time. Adding each pledge to every day it covers could take 10¹⁰ steps.

<Hints>
<Hint>
The days are numbered from 1, but arrays start at 0. Decide once where you translate, for example "day `d` lives at index `d - 1`", and stick to it.
</Hint>
<Hint>
A pledge only changes the day-to-day **difference** in two places: the count goes up by `people` on day `first`, and back down by `people` on the day after `last`.
</Hint>
<Hint>
Record those two changes in an array with one spare slot, so the day after the final day still has somewhere to go. Then one running sum over the changes gives each day's total.
</Hint>
</Hints>

## Solutions

<Approach title="Add each pledge to every day" time="O(days × pledges)" space="O(days)">

The direct simulation. It's correct and makes a good test oracle, but a long pledge costs as much as the days it covers.

```swift
public static func volunteersPerDay(days: Int, pledges: [(first: Int, last: Int, people: Int)]) -> [Int] {
    var totals = Array(repeating: 0, count: days)
    for pledge in pledges {
        for day in pledge.first...pledge.last {
            totals[day - 1] += pledge.people
        }
    }
    return totals
}
```

</Approach>

<Approach title="A difference array" time="O(days + pledges)" space="O(days)">

Each pledge becomes two O(1) writes: `+people` at day `first`'s index, `first - 1`, and `-people` at the index of the day after `last`. With day `d` at index `d - 1`, the day after `last` is at index `last`. The array has `days + 1` slots so that a pledge ending on the final day can still write its `-people`. A running sum then turns the changes back into totals.

```swift
public enum VolunteerRoster {
    public static func volunteersPerDay(days: Int, pledges: [(first: Int, last: Int, people: Int)]) -> [Int] {
        var change = Array(repeating: 0, count: days + 1)
        for pledge in pledges {
            change[pledge.first - 1] += pledge.people
            change[pledge.last] -= pledge.people
        }
        var totals: [Int] = []
        totals.reserveCapacity(days)
        var running = 0
        for index in 0..<days {
            running += change[index]
            totals.append(running)
        }
        return totals
    }
}
```

The spare slot at index `days` is written to but never read: it only exists so no pledge needs a bounds check.

</Approach>
