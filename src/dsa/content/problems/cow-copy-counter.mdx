Copy-on-write makes copying an array free, and charges for it later, on the first write to shared storage. Simulate a program's array variables and work out how many elements copy-on-write copies in total.

`CowCopyCounter.elementsCopied(by commands: [String]) -> Int`

Each command is words separated by single spaces:

| Command | Means |
| --- | --- |
| `new a 3` | `a` becomes a new array of 3 elements, with storage of its own |
| `copy b a` | `b = a`: `b` now shares `a`'s storage |
| `append a` | a write that adds one element |
| `write a` | a write that changes one element in place |
| `remove a` | a write that removes the last element |
| `read a` | reads one element |

Before any write, if the variable's storage is shared with another variable, the variable first gets its own copy, which copies **every element the storage holds at that moment**. Storage that no variable uses any more is gone, so a variable that's left alone with its storage owns it again.

## Examples

| Commands | Copied | Why |
| --- | --- | --- |
| `new a 3`, `copy b a`, `append b`, `append b` | 3 | the first append copies 3 elements; then `b` owns its storage |
| `new board 4`, then three times: `copy hN board`, `write board` | 12 | every snapshot shares the board, so every write copies all 4 |
| `new a 5`, `copy b a`, `new b 2`, `append a` | 0 | `b` moved to new storage, so `a` owns its storage again |
| `new a 2`, `copy b a`, `copy c a`, `write a`, `write b`, `write c` | 4 | `a` copies 2, then `b` (still sharing with `c`) copies 2, then `c` is alone |
| `new a 1000`, `copy b a`, `read a`, `read b` | 0 | reading never copies |

## Constraints

- Up to 100,000 commands.
- Every variable is given an array by `new` or `copy` before any other command uses it.
- `remove` is never used on an empty array, and arrays hold at most 1,000,000 elements.

<Hints>
<Hint>
Think of each block of storage as having two numbers: how many elements it holds, and how many variables share it. Give every block a number of its own, and keep a dictionary from variable name to block number.
</Hint>
<Hint>
Whenever a variable stops using a block (because of `new`, `copy`, or a copy-on-write), lower that block's sharer count. When a variable starts using one, raise it. `copy a a`, or copying from a variable that already shares your block, changes nothing.
</Hint>
<Hint>
For a write: if the variable's block has more than one sharer, add its element count to the total, take the variable off that block, and give it a new block with the same count. Then apply the write's effect on the count: plus one for `append`, minus one for `remove`.
</Hint>
</Hints>

## Solutions

<Approach title="Count sharers for each block of storage" time="O(n)" space="O(n)">

This is the check Swift really makes: before writing, is my storage shared? Here the "reference count" is the number of variables using each block. Every command touches at most two blocks, so each takes constant time.

```swift
public enum CowCopyCounter {
    public static func elementsCopied(by commands: [String]) -> Int {
        var storageOf: [String: Int] = [:]
        var elementCount: [Int: Int] = [:]
        var sharers: [Int: Int] = [:]
        var nextBlock = 0
        var copied = 0

        func makeBlock(holding count: Int) -> Int {
            nextBlock += 1
            elementCount[nextBlock] = count
            sharers[nextBlock] = 1
            return nextBlock
        }

        func release(_ name: String) {
            guard let block = storageOf[name] else {
                return
            }
            sharers[block]! -= 1
            if sharers[block]! == 0 {
                sharers[block] = nil
                elementCount[block] = nil
            }
        }

        for command in commands {
            let words = command.split(separator: " ").map(String.init)
            let name = words[1]
            switch words[0] {
            case "new":
                release(name)
                storageOf[name] = makeBlock(holding: Int(words[2])!)
            case "copy":
                let block = storageOf[words[2]]!
                if storageOf[name] != block {
                    release(name)
                    storageOf[name] = block
                    sharers[block]! += 1
                }
            case "append", "write", "remove":
                var block = storageOf[name]!
                if sharers[block]! > 1 {
                    let count = elementCount[block]!
                    copied += count
                    release(name)
                    block = makeBlock(holding: count)
                    storageOf[name] = block
                }
                if words[0] == "append" {
                    elementCount[block]! += 1
                } else if words[0] == "remove" {
                    elementCount[block]! -= 1
                }
            default:
                break
            }
        }
        return copied
    }
}
```

The snapshot example shows the lesson's performance trap in numbers: keep a copy alive before every write and each write costs the whole array. With 1,000 snapshots of a 1,000-element board, that's a million elements copied, where writing without snapshots would copy none.

</Approach>
