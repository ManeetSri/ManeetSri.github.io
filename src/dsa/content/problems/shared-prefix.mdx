Return the longest string that every word in `words` starts with. If the words share no first character, or the list is empty, return `""`.

`SharedPrefix.longestCommonPrefix(_ words: [String]) -> String`

## Examples

| `words` | Output |
| --- | --- |
| `["interview", "internet", "interval", "internal"]` | `"inter"` |
| `["swift", "swiftui", "swiftly"]` | `"swift"` |
| `["abc", "ab", "abcd"]` | `"ab"` |
| `["apple", "banana"]` | `""` |
| `["solo"]` | `"solo"` |
| `[]` | `""` |

The prefix can never be longer than the shortest word, as the third example shows. A single word is its own longest prefix.

## Constraints

- `0 ≤ words.count ≤ 2,000`
- `0 ≤ words[i].count ≤ 1,000`
- Words can contain any characters. Compare whole characters, and treat upper and lower case as different.

<Hints>
<Hint>
Use the first word as the reference. The answer is some prefix of it.
</Hint>
<Hint>
Scan **vertically**: look at column 0 of every word, then column 1, and so on. Stop at the first column where some word has ended or has a different character.
</Hint>
<Hint>
Convert each word with `Array(word)` first, so `chars[column]` is O(1). When you stop at column `c`, the answer is the first `c` characters of the reference.
</Hint>
</Hints>

## Solutions

<Approach title="Shrink a candidate" time="O(S)" space="O(L)">

Start with the whole first word as the candidate, and cut it down against each other word until that word starts with it. S is the total number of characters.

```swift
public static func longestCommonPrefix(_ words: [String]) -> String {
    guard let first = words.first else { return "" }
    var prefix = Array(first)
    for word in words.dropFirst() {
        let chars = Array(word)
        var length = 0
        while length < min(prefix.count, chars.count) && prefix[length] == chars[length] {
            length += 1
        }
        prefix.removeLast(prefix.count - length)
    }
    return String(prefix)
}
```

</Approach>

<Approach title="Vertical scan" time="O(S)" space="O(S)">

Compare column by column and stop at the first mismatch. Its advantage shows when the prefix is short: it stops after a few columns, even if every word is long.

```swift
public enum SharedPrefix {
    public static func longestCommonPrefix(_ words: [String]) -> String {
        guard let first = words.first else { return "" }
        let reference = Array(first)
        let others = words.dropFirst().map { Array($0) }
        for column in 0..<reference.count {
            for chars in others where column == chars.count || chars[column] != reference[column] {
                return String(reference[0..<column])
            }
        }
        return first
    }
}
```

`column == chars.count` is checked first, so `chars[column]` is never read past the end of a shorter word: `||` stops as soon as its left side is true.

</Approach>
