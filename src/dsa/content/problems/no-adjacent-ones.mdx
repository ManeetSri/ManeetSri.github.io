Return every string of `"0"`s and `"1"`s that has exactly `length` characters and never has two `"1"`s side by side. Return them sorted in ascending order. For `length` 0 there's exactly one such string, the empty one.

`NoAdjacentOnes.strings(length: Int) -> [String]`

## Examples

| `length` | Output |
| --- | --- |
| `0` | `[""]` |
| `1` | `["0", "1"]` |
| `2` | `["00", "01", "10"]` |
| `3` | `["000", "001", "010", "100", "101"]` |

For length 2, `"11"` is left out. For length 3, the three strings containing `"11"` are left out: `"011"`, `"110"` and `"111"`.

## Constraints

- `0 ≤ length ≤ 20`. There are 17,711 valid strings of length 20.

<Hint>
`"0"` is always allowed. `"1"` is allowed only at the very start or right after a `"0"`. Skip the `"1"` branch otherwise, so invalid strings are never even started.
</Hint>
<Hint>
If every call tries `"0"` before `"1"`, the strings come out already sorted, because all strings with a `"0"` in some position finish before any with a `"1"` there. The base case is a string that has reached `length` characters: add it to the result.
</Hint>
</Hints>

## Solutions

<Approach title="Brute force: test every bit pattern" time="O(n × 2ⁿ)" space="O(n × answer)">

Every string of length n corresponds to a number from 0 to 2ⁿ − 1, written in binary. A number has two adjacent 1 bits exactly when `x & (x >> 1)` isn't zero: shifting right lines each bit up with its neighbour (M16). Counting up through the numbers gives the strings in sorted order. It checks all 2ⁿ patterns, even though most of them fail.

```swift
public static func strings(length: Int) -> [String] {
    if length == 0 {
        return [""]
    }
    var result: [String] = []
    for x in 0..<(1 << length) where x & (x >> 1) == 0 {
        let bits = String(x, radix: 2)
        result.append(String(repeating: "0", count: length - bits.count) + bits)
    }
    return result
}
```

`String(x, radix: 2)` drops leading zeros, so each string is padded back to full length. `String(0, radix: 2)` is `"0"`, one character too long for length 0, so that case gets its own line.

</Approach>

<Approach title="Recursion that never builds an invalid string" time="O(n × answer)" space="O(n)">

Build each string one character at a time. Try `"0"` first, always allowed, then `"1"`, but only when the last character isn't already a `"1"`. Because invalid strings are cut off as soon as they'd break the rule, every call leads to at least one valid string, so the work is proportional to the size of the answer.

```swift
public static func strings(length: Int) -> [String] {
    var result: [String] = []
    func build(_ prefix: String) {
        if prefix.count == length {
            result.append(prefix)
            return
        }
        build(prefix + "0")
        if !prefix.hasSuffix("1") {
            build(prefix + "1")
        }
    }
    build("")
    return result
}
```

A tidier variant keeps one shared `[Character]` buffer, appending a character before each recursive call and removing it afterwards, instead of building a new prefix string for every call. That "choose, explore, un-choose" rhythm is the heart of backtracking, coming in M48.

The counts, 1, 2, 3, 5, 8, 13, …, are the Fibonacci numbers. A valid string of length n either ends in `"0"`, after any valid string of length n − 1, or ends in `"01"`, after any valid string of length n − 2.

</Approach>
