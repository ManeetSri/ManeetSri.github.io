A degree has `courseCount` courses, labelled 0 to `courseCount - 1`. Each pair `[before, after]` in `prerequisites` means course `before` must be completed before course `after` can start. Return true if some order lets you complete every course, and false if some courses can never be started.

`CourseCompletionCheck.canFinish(courseCount: Int, prerequisites: [[Int]]) -> Bool`

Note the direction: the first number is the course you take **first**, so each pair is an edge `before → after`.

## Examples

| `courseCount` | `prerequisites` | Returns | Why |
| --- | --- | --- | --- |
| 2 | `[[0, 1]]` | true | take 0, then 1 |
| 2 | `[[0, 1], [1, 0]]` | false | each waits for the other |
| 4 | `[[0, 1], [1, 2], [2, 3], [3, 1]]` | false | 1, 2 and 3 wait for each other in a ring |
| 5 | `[[4, 0], [4, 1], [0, 2], [1, 2], [2, 3]]` | true | for example 4, 0, 1, 2, 3 |
| 1 | `[[0, 0]]` | false | a course that requires itself |
| 3 | `[]` | true | no prerequisites at all |

## Constraints

- `0 ≤ courseCount ≤ 100,000` and `0 ≤ prerequisites.count ≤ 200,000`.
- Labels are in range. A pair may appear more than once, and `[a, a]` is possible.
- The tests use 100,000 courses, so the answer must be O(n + p).
- Every chain of prerequisites in the tests is shorter than 1,000 courses, so a recursive depth-first search won't overflow the test thread's stack.

<Hints>
<Hint>
Every course can be completed exactly when the graph of `before → after` edges has **no cycle**. So this is cycle detection in a directed graph.
</Hint>
<Hint>
Kahn's algorithm: count each course's prerequisites (its in-degree), start with the courses that have none, and each time you take a course, subtract 1 from the courses it unlocks. If fewer than `courseCount` courses ever come out, some are stuck in a cycle.
</Hint>
<Hint>
Or three colours: depth-first search, marking a course "in progress" when you enter it and "done" when you leave. Reaching a course that's still in progress means you've gone round a cycle. A course that's done is safe to skip.
</Hint>
</Hints>

## Solutions

<Approach title="Kahn's algorithm" time="O(n + p)" space="O(n + p)">

Courses that become free join a queue; a cycle's courses never do, so the count comes up short. No recursion, so any depth is safe.

```swift
public enum CourseCompletionCheck {
    public static func canFinish(courseCount: Int, prerequisites: [[Int]]) -> Bool {
        var unlocks = Array(repeating: [Int](), count: courseCount)
        var waitingOn = Array(repeating: 0, count: courseCount)      // in-degrees
        for pair in prerequisites {
            unlocks[pair[0]].append(pair[1])
            waitingOn[pair[1]] += 1
        }
        var ready = (0..<courseCount).filter { waitingOn[$0] == 0 }
        var head = 0                                                 // ready doubles as a queue
        while head < ready.count {
            let course = ready[head]
            head += 1
            for next in unlocks[course] {
                waitingOn[next] -= 1
                if waitingOn[next] == 0 {
                    ready.append(next)
                }
            }
        }
        return ready.count == courseCount
    }
}
```

A repeated pair adds 1 to the in-degree twice and is subtracted twice, so repeats need no special handling.

</Approach>

<Approach title="Depth-first search with three colours" time="O(n + p)" space="O(n + p)">

White means unvisited, grey means on the current path, black means finished. An edge into a grey course closes a cycle.

```swift
public enum CourseCompletionCheck {
    public static func canFinish(courseCount: Int, prerequisites: [[Int]]) -> Bool {
        var unlocks = Array(repeating: [Int](), count: courseCount)
        for pair in prerequisites {
            unlocks[pair[0]].append(pair[1])
        }
        var colour = Array(repeating: 0, count: courseCount)        // 0 white, 1 grey, 2 black
        func hasCycle(from course: Int) -> Bool {
            colour[course] = 1
            for next in unlocks[course] {
                if colour[next] == 1 { return true }
                if colour[next] == 0 && hasCycle(from: next) { return true }
            }
            colour[course] = 2
            return false
        }
        for course in 0..<courseCount where colour[course] == 0 {
            if hasCycle(from: course) { return false }
        }
        return true
    }
}
```

The recursion is as deep as the longest path it follows, which the tests keep under 1,000. For a chain of 100,000 courses, use Kahn's algorithm or an explicit stack instead.

</Approach>
