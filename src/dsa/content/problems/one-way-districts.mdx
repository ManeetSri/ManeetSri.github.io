A city has `n` junctions, numbered 0 to n − 1, joined by one-way roads. A **district** is a group of junctions where you can drive from any one of them to any other and back again, and which can't be made any bigger. Every junction is in exactly one district: a junction you can leave but never get back to is a district on its own. Return the number of districts.

`OneWayDistricts.count(_ n: Int, _ roads: [[Int]]) -> Int`

Each road is `[from, to]`. Roads may repeat, and a road may start and end at the same junction.

## Examples

| `n` | `roads` | Returns |
| --- | --- | --- |
| `8` | `[[0, 1], [1, 2], [2, 0], [1, 3], [2, 4], [3, 4], [4, 5], [5, 3], [5, 6], [6, 7], [7, 6], [0, 7]]` | `3`: junctions 0–2, 3–5 and 6–7 |
| `5` | `[[0, 1], [1, 2], [2, 3], [3, 4]]` | `5`: you can never drive back along a chain |
| `5` | `[[0, 1], [1, 2], [2, 3], [3, 4], [4, 0]]` | `1`: one big loop |
| `4` | `[]` | `4` |

## Constraints

- `1 ≤ n ≤ 100,000`, with up to 200,000 roads.
- Every junction number is between 0 and n − 1.
- Driving from every junction to see what it reaches is O(V · (V + E)), around ten billion steps for the largest tests.
- **One test is a chain of 100,000 junctions**, and a recursive DFS on it goes 100,000 calls deep. That overflows the test thread's stack, as [Stack depth limits in Swift](/dsa/learn/rec-stack-limits) explains, and the test process crashes. Write the DFS with an explicit stack, as the lesson shows. Every other test keeps the depth small, so you can check a recursive version first with `swift test --filter OneWayDistrictsTests --skip deepChainAndRing`.

<Hints>
<Hint>
A district is a strongly connected component. Counting districts is counting components.
</Hint>
<Hint>
Kosaraju's algorithm: run a DFS over the whole city and note the order in which junctions finish. Then search the city with every road reversed, starting from the junctions that finished last. Each search from an unclaimed junction claims exactly one district.
</Hint>
<Hint>
To make the DFS iterative, keep a stack of `(junction, next)` pairs, where `next` is the index of the next road to try. Look at the top pair: if it has a road left, advance `next` and push the far end if it's new; otherwise pop it, and that's the moment the junction finishes.
</Hint>
</Hints>

## Solutions

<Approach title="Mutual reachability from every junction" time="O(V · (V + E))" space="O(V + E)">

For each junction not yet in a district, find everything it reaches with a BFS along the roads, and everything that reaches it with a BFS along the reversed roads. The junctions in both sets form its district. It's correct and simple, but one or two searches per district over the whole city is far too slow for 100,000 junctions.

</Approach>

<Approach title="Kosaraju's algorithm, iterative" time="O(V + E)" space="O(V + E)">

Pass 1 records finishing order with an explicit stack of frames. Pass 2 only needs to know which junctions each search reaches, not the order it reaches them in, so a plain stack does the job.

```swift
public enum OneWayDistricts {
    public static func count(_ n: Int, _ roads: [[Int]]) -> Int {
        var forward = [[Int]](repeating: [], count: n)
        var backward = [[Int]](repeating: [], count: n)
        for road in roads {
            forward[road[0]].append(road[1])
            backward[road[1]].append(road[0])
        }

        // Pass 1: an iterative DFS that records each junction when it finishes
        var visited = [Bool](repeating: false, count: n)
        var finished: [Int] = []
        var frames: [(junction: Int, next: Int)] = []
        for start in 0..<n where !visited[start] {
            visited[start] = true
            frames.append((start, 0))
            while let frame = frames.last {
                let v = frame.junction
                if frame.next < forward[v].count {
                    frames[frames.count - 1].next += 1
                    let w = forward[v][frame.next]
                    if !visited[w] {
                        visited[w] = true
                        frames.append((w, 0))
                    }
                } else {
                    frames.removeLast()
                    finished.append(v)
                }
            }
        }

        // Pass 2: on the reversed roads, latest finisher first. Each search claims one district.
        var claimed = [Bool](repeating: false, count: n)
        var districts = 0
        for start in finished.reversed() where !claimed[start] {
            districts += 1
            claimed[start] = true
            var stack = [start]
            while let v = stack.popLast() {
                for w in backward[v] where !claimed[w] {
                    claimed[w] = true
                    stack.append(w)
                }
            }
        }
        return districts
    }
}
```

</Approach>

<Approach title="Tarjan's algorithm, iterative" time="O(V + E)" space="O(V + E)">

One DFS instead of two, and no reversed copy of the roads. Each junction gets a discovery index and a low-link; a junction whose low-link equals its own index starts a district, and the district is everything above it on the stack.

```swift
public enum OneWayDistricts {
    public static func count(_ n: Int, _ roads: [[Int]]) -> Int {
        var adjacency = [[Int]](repeating: [], count: n)
        for road in roads {
            adjacency[road[0]].append(road[1])
        }

        var index = [Int](repeating: -1, count: n)     // discovery order; -1 means not visited yet
        var low = [Int](repeating: 0, count: n)
        var onStack = [Bool](repeating: false, count: n)
        var stack: [Int] = []
        var nextIndex = 0
        var districts = 0
        var frames: [(junction: Int, next: Int)] = []  // the DFS "call stack"

        for start in 0..<n where index[start] == -1 {
            index[start] = nextIndex
            low[start] = nextIndex
            nextIndex += 1
            stack.append(start)
            onStack[start] = true
            frames.append((start, 0))

            while let frame = frames.last {
                let v = frame.junction
                if frame.next < adjacency[v].count {
                    frames[frames.count - 1].next += 1
                    let w = adjacency[v][frame.next]
                    if index[w] == -1 {
                        // A tree edge: "call" the DFS on w
                        index[w] = nextIndex
                        low[w] = nextIndex
                        nextIndex += 1
                        stack.append(w)
                        onStack[w] = true
                        frames.append((w, 0))
                    } else if onStack[w] {
                        low[v] = min(low[v], index[w])
                    }
                } else {
                    // Every road out of v is done: "return" to its parent
                    frames.removeLast()
                    if let parent = frames.last?.junction {
                        low[parent] = min(low[parent], low[v])
                    }
                    if low[v] == index[v] {
                        districts += 1
                        while true {
                            let w = stack.removeLast()
                            onStack[w] = false
                            if w == v { break }
                        }
                    }
                }
            }
        }
        return districts
    }
}
```

The `onStack` check matters: a road into a junction whose district is already finished must not lower the low-link, or two districts would merge.

</Approach>
