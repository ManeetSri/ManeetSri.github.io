Delivery companies plan routes that avoid left turns: waiting to cross oncoming traffic wastes time and causes accidents. Extend the route planner so that every left turn adds a penalty to the trip's cost, and U-turns aren't allowed at all. Return the cheapest trip.

`TurnPenaltyRoutes.cheapest(places: [[Int]], roads: [[Int]], from start: Int, to goal: Int, leftTurnPenalty: Int) -> Int?`

`places[i]` is `[x, y]`, with x pointing east and y pointing north. Each road is `[a, b, length]` and can be driven both ways. A trip leaves `start` along any road, and its cost is the total length driven plus `leftTurnPenalty` for each left turn. At a place `v` reached from `u`, driving on to `w`:

- is a **U-turn** if `w` is `u`, which isn't allowed;
- is a **left turn** if the cross product of the direction in, `v − u`, and the direction out, `w − v`, is positive: `(vx − ux) × (wy − vy) − (vy − uy) × (wx − vx) > 0`;
- otherwise (straight on, or a right turn) costs nothing extra.

A trip may pass through a place more than once. Return `nil` if `goal` can't be reached, and 0 if `start` is `goal`.

## Examples

A grid of junctions 100 m apart, numbered from the south-west corner, and place 9, 50 m south of place 1, whose only road leads north into town:

```text
6 ─── 7 ─── 8        north
│     │     │          ↑
3 ─── 4 ─── 5
│     │     │
0 ─── 1 ─── 2
      │
      9
```

| Trip | `leftTurnPenalty` | Output | Route |
| --- | --- | --- | --- |
| 9 to 0 | `0` | `150` | north to 1, left to 0 |
| 9 to 0 | `30` | `180` | the same, with one left turn |
| 9 to 0 | `500` | `550` | north to 4, then right, right, right round the block to 1, and on to 0 |
| 9 to 2 | `500` | `150` | north to 1, then right |
| 0 to 8 | `500` | `400` | north to 6, then right along the top |
| 9 to 9 | `500` | `0` | already there |

With U-turns allowed, 9 → 1 → 4, back to 1 and right to 0 would cost only 350 at any penalty. A U-turn crosses the oncoming traffic too, so the rules forbid it outright.

## Constraints

- Up to 5,000 places and 10,000 roads. Places have distinct coordinates from `-10⁶` to `10⁶`.
- Lengths from 1 to 10⁶, and `0 ≤ leftTurnPenalty ≤ 10⁶`.
- No two roads join the same pair of places, no road joins a place to itself, and no two roads leave a place in exactly the same direction.
- A place has at most 8 roads.

<Hints>
<Hint>
Dijkstra over places doesn't work: whether the next move is a left turn depends on which road you arrived by, so two arrivals at the same place with different costs can both matter. What state captures "where I am and which way I'm facing"?
</Hint>
<Hint>
Make the state a **directed road**: "I just drove from `u` to `v`". The start states are the roads out of `start`, each costing its length. From state `u → v`, you can move to `v → w` for every road out of `v` except back to `u`, paying its length plus the penalty if the turn is a left.
</Hint>
<Hint>
Run Dijkstra with a heap over these states. The first time you pop a state whose road ends at `goal`, its cost is the answer. There are twice as many states as roads, and each has at most 7 moves.
</Hint>
</Hints>

## Solutions

<Approach title="Dijkstra over directed roads" time="O(T log T)" space="O(T)">

Here T is the number of moves between states, the sum over places of (roads at the place)², at most 7 times the number of directed roads. Every cost is non-negative, so Dijkstra's greedy rule holds: a state popped with its best cost is final. `Heap` is DSAKit's.

```swift
import DSAKit

public enum TurnPenaltyRoutes {
    public static func cheapest(places: [[Int]], roads: [[Int]], from start: Int, to goal: Int,
                                leftTurnPenalty: Int) -> Int? {
        if start == goal { return 0 }
        // Directed road i goes from tail[i] to head[i]; leaving[p] lists the directed roads out of p
        var tail: [Int] = [], head: [Int] = [], length: [Int] = []
        var leaving = [[Int]](repeating: [], count: places.count)
        for road in roads {
            for (from, to) in [(road[0], road[1]), (road[1], road[0])] {
                leaving[from].append(tail.count)
                tail.append(from)
                head.append(to)
                length.append(road[2])
            }
        }

        func isLeftTurn(_ u: Int, _ v: Int, _ w: Int) -> Bool {
            let (inX, inY) = (places[v][0] - places[u][0], places[v][1] - places[u][1])
            let (outX, outY) = (places[w][0] - places[v][0], places[w][1] - places[v][1])
            return inX * outY - inY * outX > 0                  // counterclockwise, with y pointing north
        }

        var best = [Int](repeating: Int.max, count: tail.count)
        var queue = Heap<(cost: Int, road: Int)>(areInIncreasingOrder: { $0.cost < $1.cost })
        for road in leaving[start] {
            best[road] = length[road]
            queue.insert((length[road], road))
        }
        while let (cost, road) = queue.pop() {
            guard cost == best[road] else { continue }           // a stale entry
            let (u, v) = (tail[road], head[road])
            if v == goal { return cost }
            for next in leaving[v] where head[next] != u {       // no U-turns
                let total = cost + length[next] + (isLeftTurn(u, v, head[next]) ? leftTurnPenalty : 0)
                if total < best[next] {
                    best[next] = total
                    queue.insert((total, next))
                }
            }
        }
        return nil
    }
}
```

This is the lesson's stretch goal, "search over (place, arriving road) pairs", and the same idea works for any cost that depends on how you arrive: banned turns, a penalty for changing bus lines, or a ship that needs time to change heading. A\* still applies on top when every road is at least as long as the straight line between its ends: the straight-line distance to the goal then never overestimates, since penalties only add cost. The cross products fit in an `Int` easily, because coordinates up to 10⁶ make each term at most about 4 × 10¹².

</Approach>
