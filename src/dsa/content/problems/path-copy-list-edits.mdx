An immutable list never changes: every property of its nodes is a `let`. To "edit" one, you build a new version that copies only the nodes in front of the change and **shares** everything after it with the old version. Write insert and remove that work this way, so that every old version stays valid and cheap to keep.

`PathCopyingList.inserting(_ value: Int, at index: Int, into head: PathCopyingList.Node?) -> PathCopyingList.Node?`

`PathCopyingList.removing(at index: Int, from head: PathCopyingList.Node?) -> PathCopyingList.Node?`

The node type is given:

```swift
public final class Node {
    public let value: Int
    public let next: Node?
    public init(_ value: Int, next: Node? = nil)
}
```

`inserting` returns a version with `value` at position `index`, and the node that was at `index` in the old version, if there was one, must be the very same node at `index + 1` in the new one. `removing` returns a version without the node at `index`, and the node that came after it, if any, must be the very same node at `index` in the new one. Copy only the nodes before `index`.

## Examples

| Old version | Call | New version | Nodes shared with the old version |
| --- | --- | --- | --- |
| `1 -> 2 -> 3 -> 4` | `inserting(9, at: 2, ...)` | `1 -> 2 -> 9 -> 3 -> 4` | `3` and `4` |
| `1 -> 2 -> 3 -> 4` | `inserting(0, at: 0, ...)` | `0 -> 1 -> 2 -> 3 -> 4` | all four |
| `1 -> 2 -> 3 -> 4` | `inserting(5, at: 4, ...)` | `1 -> 2 -> 3 -> 4 -> 5` | none |
| `1 -> 2 -> 3 -> 4` | `removing(at: 1, ...)` | `1 -> 3 -> 4` | `3` and `4` |
| `1 -> 2 -> 3 -> 4` | `removing(at: 0, ...)` | `2 -> 3 -> 4` | all three |
| empty (`nil`) | `inserting(7, at: 0, ...)` | `7` | none |
| `7` | `removing(at: 0, ...)` | empty | none |

In every row, the old version still reads `1 -> 2 -> 3 -> 4` (or whatever it was) afterwards. Removing at 0 copies nothing at all: the new version is just the old second node.

## Constraints

- Lists have up to 5,000 nodes. `0 ≤ index ≤` the length for `inserting`, and `0 ≤ index <` the length for `removing`.
- O(index) time and extra space per edit. The tests keep hundreds of versions alive at once and edit near the front of a long list.

<Hints>
<Hint>
A node can't change, so the nodes before `index` in the new version must be new: they hold the same values as the old ones, but a different `next`. Everything from the old node at `index` on (for an insert) or after it (for a removal) can be reused as it is.
</Hint>
<Hint>
Recursion says it neatly. Inserting at 0 is `Node(value, next: head)`, and removing at 0 is `head?.next`. Any other index copies the head and recurses: `Node(head.value, next: inserting(value, at: index - 1, into: head.next))`.
</Hint>
<Hint>
Without recursion: walk `index` steps, saving the values you pass in an array. The node you stop at is where sharing starts. Build the new front by prepending the saved values in reverse order, starting from the new node (insert) or the node after the stopping point (remove).
</Hint>
</Hints>

## Solutions

<Approach title="Copy the whole list" time="O(n)" space="O(n)">

Turn the list into an array of values, edit the array, and build a brand-new list. The values come out right, but nothing is shared: every edit copies every node, and the tests check that the tail is reused.

```swift
public static func inserting(_ value: Int, at index: Int, into head: Node?) -> Node? {
    var values: [Int] = []
    var current = head
    while let node = current {
        values.append(node.value)
        current = node.next
    }
    values.insert(value, at: index)
    var result: Node? = nil
    for value in values.reversed() {
        result = Node(value, next: result)
    }
    return result
}
```

</Approach>

<Approach title="Path copying, recursively" time="O(index)" space="O(index) stack">

Copy the path from the head to the change, one call per node, and hand back the old nodes from the change onwards untouched. Each call is one stack frame, which is fine for a few thousand nodes.

```swift
public static func inserting(_ value: Int, at index: Int, into head: Node?) -> Node? {
    guard index > 0, let head else {
        return Node(value, next: head)                 // share the whole rest
    }
    return Node(head.value, next: inserting(value, at: index - 1, into: head.next))
}

public static func removing(at index: Int, from head: Node?) -> Node? {
    guard let head else { return nil }
    if index == 0 {
        return head.next                               // copy nothing
    }
    return Node(head.value, next: removing(at: index - 1, from: head.next))
}
```

</Approach>

<Approach title="Path copying with a loop" time="O(index)" space="O(index)">

The same copying without the recursion: save the values on the path, then rebuild that short front section from the back, onto the shared tail.

```swift
public enum PathCopyingList {
    public final class Node {
        public let value: Int
        public let next: Node?

        public init(_ value: Int, next: Node? = nil) {
            self.value = value
            self.next = next
        }
    }

    public static func inserting(_ value: Int, at index: Int, into head: Node?) -> Node? {
        let (path, rest) = split(head, at: index)
        return rebuild(path, onto: Node(value, next: rest))
    }

    public static func removing(at index: Int, from head: Node?) -> Node? {
        let (path, rest) = split(head, at: index)
        return rebuild(path, onto: rest?.next)         // skip the removed node
    }

    /// The values of the first `index` nodes, and the node at `index`, where sharing starts.
    private static func split(_ head: Node?, at index: Int) -> ([Int], Node?) {
        var path: [Int] = []
        var current = head
        while path.count < index, let node = current {
            path.append(node.value)
            current = node.next
        }
        return (path, current)
    }

    /// New nodes holding `path`, in order, in front of `tail`.
    private static func rebuild(_ path: [Int], onto tail: Node?) -> Node? {
        var result = tail
        for value in path.reversed() {
            result = Node(value, next: result)
        }
        return result
    }
}
```

</Approach>
