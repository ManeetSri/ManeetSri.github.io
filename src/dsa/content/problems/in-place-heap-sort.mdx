Sort an array of integers into increasing order **in place**, with heap sort: O(n log n) time in every case, and O(1) extra memory. Don't call the standard library's `sort()` or `sorted()`.

`InPlaceHeapSort.sort(_ items: inout [Int])`

## Examples

| `items` before | `items` after |
| --- | --- |
| `[5, 2, 9, 1, 6, 3]` | `[1, 2, 3, 5, 6, 9]` |
| `[3, 3, 1, 3, 1]` | `[1, 1, 3, 3, 3]` |
| `[-4, 10, 0, -4, 7]` | `[-4, -4, 0, 7, 10]` |
| `[2, 1]` | `[1, 2]` |
| `[]` | `[]` |

## Constraints

- `0 ≤ items.count ≤ 100,000`, any `Int` values.
- The tests include 100,000 values already sorted, reversed, all equal and in an "organ pipe" (up, then down). Insertion sort and a quick sort with a fixed pivot are O(n²) on some of those.

<Hints>
<Hint>
Use a **max**-heap, built inside the array itself. Once the largest value is at index 0, where does it belong in the sorted result?
</Hint>
<Hint>
At the end. Swap index 0 with the last index of the heap, and treat that last slot as finished: the heap now occupies one fewer slot. The new root is probably too small, so sift it down, but only within the shrunken heap.
</Hint>
<Hint>
Build the max-heap bottom-up first: sift down every index from `count / 2 - 1` back to 0. Your sift-down function needs an `end` parameter, so it ignores the sorted part at the back.
</Hint>
</Hints>

## Solutions

<Approach title="Heapify, then swap the root to the back" time="O(n log n)" space="O(1)">

After heapifying, the array is one max-heap. Each round moves the largest remaining value to the front of the sorted suffix and repairs the heap with one sift down, O(log n). There are n − 1 rounds.

```swift
public enum InPlaceHeapSort {
    public static func sort(_ items: inout [Int]) {
        let count = items.count
        for index in stride(from: count / 2 - 1, through: 0, by: -1) {
            siftDown(&items, from: index, end: count)
        }
        var end = count - 1
        while end > 0 {
            items.swapAt(0, end)
            siftDown(&items, from: 0, end: end)
            end -= 1
        }
    }

    /// Sifts items[index] down a max-heap that occupies items[0..<end].
    private static func siftDown(_ items: inout [Int], from index: Int, end: Int) {
        var parent = index
        while true {
            let left = 2 * parent + 1
            let right = left + 1
            var largest = parent
            if left < end && items[left] > items[largest] { largest = left }
            if right < end && items[right] > items[largest] { largest = right }
            if largest == parent { return }
            items.swapAt(parent, largest)
            parent = largest
        }
    }
}
```

The only extra memory is a few `Int` variables, and the loops never recurse. Heap sort isn't stable, which doesn't matter for plain integers.

</Approach>
