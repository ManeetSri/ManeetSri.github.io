Write a function that makes counters. Each counter is a closure: its first call returns `start`, and every later call returns `step` more than the call before. Counters made by separate calls must count independently.

`CounterMaker.makeCounter(start: Int = 0, step: Int = 1) -> () -> Int`

## Examples

| Counter | Calls | Returns |
| --- | --- | --- |
| `let c = makeCounter()` | `c()`, `c()`, `c()` | `0`, `1`, `2` |
| `let c = makeCounter(start: 5, step: 2)` | `c()`, `c()`, `c()` | `5`, `7`, `9` |
| `let c = makeCounter(start: 10, step: -3)` | `c()`, `c()`, `c()` | `10`, `7`, `4` |
| `let a = makeCounter()` and `let b = makeCounter()` | `a()`, `a()`, `b()`, `a()` | `0`, `1`, `0`, `2` |

## Constraints

- `-1,000 ≤ start ≤ 1,000` and `-1,000 ≤ step ≤ 1,000`
- A counter is called at most 10,000 times.
- If one counter is stored under two names (`let d = c`), calling either one advances the same count.

<Hints>
<Hint>
The return type `() -> Int` means you return a closure that takes nothing and returns an `Int`. Where can that closure keep its count between calls?
</Hint>
<Hint>
Declare a `var` inside `makeCounter`, before the closure. The closure captures it, so it survives after `makeCounter` returns, and each call to `makeCounter` creates a fresh one.
</Hint>
<Hint>
The first call must return `start` itself. So save the current value in a `let`, add `step` to the variable, then return the saved value.
</Hint>
</Hints>

## Solutions

<Approach title="Capture the next value" time="O(1) per call" space="O(1) per counter">

The closure captures `next`, the value it will hand out on its next call. Each call remembers the current value, moves `next` on by `step`, and returns what it remembered. Because every call to `makeCounter` runs its body again, each counter gets its own `next`.

```swift
public enum CounterMaker {
    public static func makeCounter(start: Int = 0, step: Int = 1) -> () -> Int {
        var next = start
        return {
            let current = next
            next += step
            return current
        }
    }
}
```

</Approach>

<Approach title="Capture how many calls so far" time="O(1) per call" space="O(1) per counter">

Another way: count the calls, and work out the value from the count. The nth call (counting from 0) returns `start + n * step`. It needs the same capturing idea, and shows that the captured state can be anything you like.

```swift
public static func makeCounter(start: Int = 0, step: Int = 1) -> () -> Int {
    var calls = 0
    return {
        let value = start + calls * step
        calls += 1
        return value
    }
}
```

The closure captures `start` and `step` as well. Those never change, so capturing them is safe and simple.

</Approach>
