A map of an island gives the height of every square. The **north-west sea** lies beyond the top and left edges, and the **south-east sea** beyond the bottom and right edges. Rain that falls on a square can flow to any neighbouring square (up, down, left or right) that is **no higher** than the one it's on, and from a square on an edge it can flow straight into the sea on that side.

Return every square from which rain can reach **both** seas, as `[row, column]` pairs in row-major order: row by row, left to right within a row.

`TwoSeaDrainage.cells(_ heights: [[Int]]) -> [[Int]]`

## Examples

| `heights` | Returns |
| --- | --- |
| `[[1, 2, 3], [8, 9, 4], [7, 6, 5]]` | `[[0, 2], [1, 0], [1, 1], [1, 2], [2, 0], [2, 1], [2, 2]]` |
| `[[5, 5, 5], [5, 1, 5], [5, 5, 5]]` | every square except `[1, 1]` |
| `[[3, 1, 2]]` | `[[0, 0], [0, 1], [0, 2]]` |
| `[[7]]` | `[[0, 0]]` |
| `[]` | `[]` |

In the first example, the squares of height 1 and 2 are on the north-west sea's edges, but every route away from them goes uphill, so they never reach the south-east sea. The square of height 6 is on the bottom edge, and it also reaches the north-west sea downhill through 5, 4 and 3. In the second, rain on the low middle square is trapped: every neighbour is higher. In the third, every square touches both the top and bottom edges.

## Constraints

- `0 ≤ rows, columns ≤ 1,000`, and every row has the same length.
- Heights are non-negative `Int`s, and neighbours may have equal heights.
- The tests include a 1000 × 1000 slope and a flat 600 × 600 plain where every square qualifies. On the plain, a recursive search could go hundreds of thousands of calls deep: use an explicit stack or BFS.

<Hints>
<Hint>
Following the rain downhill from every square works, but each search can cover the whole map: O((rows × columns)²) for a large one.
</Hint>
<Hint>
Reverse the flow. Rain from square A reaches the north-west sea exactly when you can walk from some top-edge or left-edge square to A, only ever stepping to a neighbour that is **at least as high**. Start from all those edge squares at once.
</Hint>
<Hint>
Do that climb once for each sea, filling two `[[Bool]]` grids. The answer is the squares that are `true` in both, collected row by row.
</Hint>
</Hints>

## Solutions

<Approach title="Follow the rain from every square" time="O((rows × columns)²)" space="O(rows × columns)">

For each square, run a DFS that only moves to neighbours no higher than the current square, and note whether it ever reaches a top or left edge and a bottom or right edge. It's the most direct translation of the statement, and fine for small maps, but every search can revisit most of the map.

</Approach>

<Approach title="Climb from each sea" time="O(rows × columns)" space="O(rows × columns)">

Two multi-source searches, each starting from one sea's edge squares and moving uphill or level. Each square is pushed at most once per search.

```swift
public enum TwoSeaDrainage {
    private static let directions = [(-1, 0), (1, 0), (0, -1), (0, 1)]

    public static func cells(_ heights: [[Int]]) -> [[Int]] {
        guard let columns = heights.first?.count, columns > 0 else { return [] }
        let rows = heights.count

        func drainsInto(from edge: [(Int, Int)]) -> [[Bool]] {
            var reached = Array(repeating: Array(repeating: false, count: columns), count: rows)
            var stack: [(Int, Int)] = []
            for (row, column) in edge where !reached[row][column] {
                reached[row][column] = true
                stack.append((row, column))
            }
            while let cell = stack.popLast() {
                for (dr, dc) in directions {
                    let r = cell.0 + dr
                    let c = cell.1 + dc
                    guard r >= 0, r < rows, c >= 0, c < columns, !reached[r][c] else { continue }
                    guard heights[r][c] >= heights[cell.0][cell.1] else { continue }   // uphill or level
                    reached[r][c] = true
                    stack.append((r, c))
                }
            }
            return reached
        }

        let northWest = drainsInto(from: (0..<rows).map { ($0, 0) } + (0..<columns).map { (0, $0) })
        let southEast = drainsInto(from: (0..<rows).map { ($0, columns - 1) } + (0..<columns).map { (rows - 1, $0) })
        var result: [[Int]] = []
        for row in 0..<rows {
            for column in 0..<columns where northWest[row][column] && southEast[row][column] {
                result.append([row, column])
            }
        }
        return result
    }
}
```

The comparison is the step people get backwards. Rain flows from high to low, so climbing **against** the flow means moving to a neighbour that is `>=` the current square, including equal heights.

</Approach>
