A sign-up screen wants to say "that username is taken" instantly, without asking the server about every keystroke. Build the Bloom filter it downloads: a fixed recipe of hashes over a bit array, so a filter built on the server and one built in the app agree bit for bit.

`UsernameBloomFilter.Filter`, a struct with `init(bitCount:hashCount:)`, `words`, `positions(of:bitCount:hashCount:)` (static), `insert(_:)`, `mightContain(_:)`, `setBitCount`, `estimatedFalsePositiveRate` and `formUnion(_:)`; plus `UsernameBloomFilter.bestHashCount(bitCount:expectedCount:)`

- **Storage.** `words` holds `(bitCount + 63) / 64` values of `UInt64`, all 0 at first. Bit b is bit `b % 64` of `words[b / 64]`.
- **The recipe.** The stub gives you `fnv1a(_:)` and `mix(_:)`. For a name, let `h1 = mix(fnv1a(name))` and `h2 = mix(h1 ^ 0x9E37_79B9_7F4A_7C15) | 1`. Its positions, in order, are `(h1 &+ i &* h2) % bitCount` for `i = 0, 1, …, hashCount − 1`, computed in `UInt64`.
- `insert(_:)` sets the bit at every position. `mightContain(_:)` returns `true` exactly when every position's bit is set.
- `setBitCount` is the number of bits set, and `estimatedFalsePositiveRate` is (`setBitCount` / `bitCount`) raised to the power `hashCount`.
- `formUnion(_:)` adds every name of another filter with the same `bitCount` and `hashCount`: a bitwise OR, word by word.
- `bestHashCount(bitCount:expectedCount:)` returns (`bitCount` / `expectedCount`) · ln 2, rounded to the nearest whole number, and at least 1.

## Examples

| Code | Result |
| --- | --- |
| `Filter(bitCount: 130, hashCount: 4).words` | `[0, 0, 0]` |
| `bestHashCount(bitCount: 10_000, expectedCount: 1_000)` | `7` (6.93 rounded) |
| `bestHashCount(bitCount: 8_000, expectedCount: 1_000)` | `6` (5.55 rounded) |
| `bestHashCount(bitCount: 100, expectedCount: 1_000)` | `1` (0.07 rounds to 0, but at least 1) |
| a 10,000-bit, 7-hash filter after inserting 1,000 names | about 5,030 bits set; every inserted name gives `true` |
| asking that filter about 10,000 names never inserted | about 0.8% give `true` |

## Constraints

- `1 ≤ bitCount ≤ 10,000,000`, `1 ≤ hashCount ≤ 20`, and `expectedCount ≥ 1`.
- Names are any strings, including empty ones and emoji. Hash their UTF-8 bytes, as `fnv1a(_:)` does.
- The tests compare `words` with the recipe exactly, so use the formula as given, with wrapping arithmetic (`&+`, `&*`) and `UInt64` throughout.
- One test inserts 100,000 names into a million bits and checks the false positive rate.

## Solutions

<Approach title="Bits in UInt64 words" time="O(hashCount) per insert or query" space="O(bitCount / 64)">

Every operation is a handful of hash computations and word operations. The filter never stores the names, so its size depends only on `bitCount`.

```swift
public enum UsernameBloomFilter {
    public static func fnv1a(_ text: String) -> UInt64 {
        var hash: UInt64 = 0xcbf2_9ce4_8422_2325
        for byte in text.utf8 {
            hash ^= UInt64(byte)
            hash = hash &* 0x0000_0100_0000_01B3
        }
        return hash
    }

    public static func mix(_ x: UInt64) -> UInt64 {
        var z = x
        z = (z ^ (z >> 30)) &* 0xBF58_476D_1CE4_E5B9
        z = (z ^ (z >> 27)) &* 0x94D0_49BB_1331_11EB
        return z ^ (z >> 31)
    }

    public static func bestHashCount(bitCount: Int, expectedCount: Int) -> Int {
        let ln2 = 0.693_147_180_559_945_3
        return max(1, Int((Double(bitCount) / Double(expectedCount) * ln2).rounded()))
    }

    public struct Filter {
        public let bitCount: Int
        public let hashCount: Int
        public private(set) var words: [UInt64]

        public init(bitCount: Int, hashCount: Int) {
            self.bitCount = bitCount
            self.hashCount = hashCount
            words = Array(repeating: 0, count: (bitCount + 63) / 64)
        }

        public static func positions(of name: String, bitCount: Int, hashCount: Int) -> [Int] {
            let h1 = mix(fnv1a(name))
            let h2 = mix(h1 ^ 0x9E37_79B9_7F4A_7C15) | 1
            let m = UInt64(bitCount)
            return (0..<hashCount).map { Int((h1 &+ UInt64($0) &* h2) % m) }
        }

        public mutating func insert(_ name: String) {
            for bit in Self.positions(of: name, bitCount: bitCount, hashCount: hashCount) {
                words[bit >> 6] |= 1 << UInt64(bit & 63)
            }
        }

        public func mightContain(_ name: String) -> Bool {
            Self.positions(of: name, bitCount: bitCount, hashCount: hashCount).allSatisfy {
                words[$0 >> 6] & (1 << UInt64($0 & 63)) != 0
            }
        }

        public var setBitCount: Int {
            words.reduce(0) { $0 + $1.nonzeroBitCount }
        }

        public var estimatedFalsePositiveRate: Double {
            let fraction = Double(setBitCount) / Double(bitCount)
            var rate = 1.0
            for _ in 0..<hashCount {
                rate *= fraction
            }
            return rate
        }

        public mutating func formUnion(_ other: Filter) {
            precondition(bitCount == other.bitCount && hashCount == other.hashCount, "Filters must match")
            for i in words.indices {
                words[i] |= other.words[i]
            }
        }
    }
}
```

Why `| 1`? If h2 were 0, every position would equal h1 and the filter would effectively use one hash. Forcing h2 odd rules that out (and, when `bitCount` is a power of two, guarantees the positions don't repeat early).

</Approach>
