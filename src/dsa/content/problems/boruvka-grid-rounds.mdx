A power company is linking `towns` towns, numbered `0` to `towns - 1`, using some of the possible power lines in `lines`. Each line `[a, b, cost]` would join towns a and b. Every town starts as its own little **grid**, and the work happens in rounds, the way Borůvka planned it:

1. Every grid that has at least one line to a different grid picks its **cheapest** such line. Compare lines by cost, and break ties by position in `lines`: the earlier line counts as cheaper.
2. All the picked lines are built at once, merging the grids they join. A line picked by both its grids is built once.

Rounds continue until no line joins two different grids. Return the total cost of every line built, and the number of separate grids left after each round.

`BoruvkaGridRounds.plan(towns: Int, lines: [[Int]]) -> (cost: Int, gridsAfterRound: [Int])`

## Examples

| `towns` | `lines` | `cost` | `gridsAfterRound` |
| --- | --- | --- | --- |
| `6` | `[[0, 1, 4], [0, 2, 2], [1, 2, 1], [1, 3, 5], [2, 4, 10], [3, 4, 2], [3, 5, 6], [4, 5, 3]]` | `13` | `[2, 1]` |
| `3` | `[[0, 1, 1], [1, 2, 1], [2, 0, 1]]` | `2` | `[1]` |
| `5` | `[[0, 1, 3], [2, 3, 1]]` | `4` | `[3]` |
| `4` | `[[0, 1, 1], [2, 3, 1], [1, 2, 9], [0, 3, 8]]` | `10` | `[2, 1]` |
| `1` | `[]` | `0` | `[]` |

The first is the lesson's graph: round 1 builds lines 1, 2, 5 and 7, leaving grids \{0, 1, 2\} and \{3, 4, 5\}, and both pick line 3 in round 2. In the second, all three lines cost 1, so the tie-break decides: towns 0 and 1 both pick line 0 and town 2 picks line 1, and no cycle forms. In the third, town 4 has no lines at all, so after one round nothing more can be done and three grids remain.

## Constraints

- `1 ≤ towns ≤ 100,000` and `0 ≤ lines.count ≤ 300,000`, with `0 ≤ a, b < towns` and `0 ≤ cost ≤ 1,000,000`.
- A line can join a town to itself, and two towns can have several lines between them.
- The tests use 50,000 towns and 150,000 lines, check every round's count against a slower Borůvka, and check the cost against Kruskal.

<Hints>
<Hint>
Keep the grids in a union-find. A line is "between two grids" exactly when its two towns have different roots, and you must call `find` fresh in every round, because the roots change as grids merge.
</Hint>
<Hint>
Each round, make one pass over the lines with an array `cheapest`, indexed by root, holding the index of the best line found so far for that grid. A line between roots r and s is a candidate for both. Compare `(cost, index)` pairs so there are never two equally cheap lines.
</Hint>
<Hint>
Then union the endpoints of every chosen line, adding its cost only when `union` actually joins two grids: that skips a line picked by both sides. If no grid had a candidate, stop; otherwise record the number of grids and go again.
</Hint>
</Hints>

## Solutions

<Approach title="Borůvka with union-find" time="O(lines log towns)" space="O(towns)">

Every chosen line is the cheapest one leaving its grid, so the cut property makes it safe. With the strict order, every chosen line belongs to the one minimum spanning forest under that order, so the lines built in a round never form a cycle. And every grid with a way out merges with at least one other each round, so for a connected network the number of grids at least halves: at most about log₂ towns rounds, each one pass over the lines.

```swift
import DSAKit

public enum BoruvkaGridRounds {
    public static func plan(towns: Int, lines: [[Int]]) -> (cost: Int, gridsAfterRound: [Int]) {
        /// Line a comes before line b: by cost, then by position in the list
        func cheaper(_ a: Int, _ b: Int) -> Bool {
            lines[a][2] != lines[b][2] ? lines[a][2] < lines[b][2] : a < b
        }
        var grids = UnionFind(count: towns)
        var cost = 0
        var history: [Int] = []
        while true {
            // cheapest[root]: the index of the cheapest line leaving that root's grid, or -1
            var cheapest = Array(repeating: -1, count: towns)
            for index in lines.indices {
                let rootA = grids.find(lines[index][0])
                let rootB = grids.find(lines[index][1])
                if rootA == rootB { continue }                      // inside one grid
                if cheapest[rootA] == -1 || cheaper(index, cheapest[rootA]) { cheapest[rootA] = index }
                if cheapest[rootB] == -1 || cheaper(index, cheapest[rootB]) { cheapest[rootB] = index }
            }
            var built = false
            for index in cheapest where index != -1 && grids.union(lines[index][0], lines[index][1]) {
                cost += lines[index][2]
                built = true
            }
            if !built { break }                                     // no line joins two grids
            history.append(grids.componentCount)
        }
        return (cost, history)
    }
}
```

The `where` clause calls `union`, which changes the union-find while the loop runs. That's on purpose: the second time a shared line comes up, its towns are already joined, `union` returns `false`, and the line isn't paid for twice. The `cheapest` array is sized by town rather than by grid, so its stale entries for non-roots simply stay `-1`.

</Approach>
