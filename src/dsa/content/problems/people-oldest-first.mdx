Sort a list of people from **oldest to youngest**. When two people are the same age, put them in alphabetical order of name. Return a new array and leave the input alone.

`PeopleSortedByAge.sorted(_ people: [Person]) -> [Person]`

A `Person` is a small struct with a `name` and an `age`, which you read as `person.name` and `person.age`. You'll write structs of your own in M09.

## Examples

| Input (name, age) | Output (name, age) |
| --- | --- |
| Ben 29, Ada 36, Cleo 41 | Cleo 41, Ada 36, Ben 29 |
| Dev 30, Ada 30, Zoe 52, Cleo 30 | Zoe 52, Ada 30, Cleo 30, Dev 30 |
| Mia 25, Ari 25 | Ari 25, Mia 25 |
| empty | empty |

## Constraints

- `0 ≤ people.count ≤ 10,000`
- `0 ≤ age ≤ 150`
- Names are compared with `<`, exactly as Swift compares strings. So, for example, `"Zed"` comes before `"amy"`, because capital letters sort first.

## Solutions

<Approach title="A closure with two rules" time="O(n log n)" space="O(n)">

The `if` handles the main rule, and the line after it only runs for ties. The two rules point in different directions, ages down and names up, and the `if` keeps each direction obvious.

```swift
public enum PeopleSortedByAge {
    public struct Person: Equatable {
        public let name: String
        public let age: Int

        public init(name: String, age: Int) {
            self.name = name
            self.age = age
        }
    }

    public static func sorted(_ people: [Person]) -> [Person] {
        people.sorted { first, second in
            if first.age != second.age {
                return first.age > second.age     // older first
            }
            return first.name < second.name       // then A to Z
        }
    }
}
```

Both comparisons are strict, `>` and `<`, so two people with the same age and name count as a tie, which is what sorting needs.

</Approach>

<Approach title="Tuple comparison, with a twist" time="O(n log n)" space="O(n)">

Tuples compare element by element, which handles "first rule, then tie-break" in one expression. To make ages go *down* while names go *up*, swap which person's age goes on which side:

```swift
public static func sorted(_ people: [Person]) -> [Person] {
    people.sorted { first, second in
        (second.age, first.name) < (first.age, second.name)
    }
}
```

If `second.age < first.age`, the first person is older, so they come first. If the ages are equal, the names decide in the usual direction. It's short and correct, but you have to think hard to check it, which is why the version with an `if` is often the better choice in real code.

</Approach>
