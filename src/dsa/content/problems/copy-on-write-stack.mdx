Finish a stack of `Int` values that keeps its elements in a shared class, and make it a true value type with copy-on-write: copies share storage until one of them changes, and changing one copy never affects another.

`CopyOnWriteStack.Stack`, with `count`, `isEmpty`, `top`, `elements`, `push(_:)`, `pop()`, `removeAll()` and `isSharingStorage(with:)`

The starter code gives you the `Storage` class, the initialisers and `storageID`. Implement the rest:

- `push`, `pop` and `removeAll` work like a normal stack (`pop` returns `nil` when empty), and must never change another copy.
- When a stack's storage is **not** shared, those methods change it in place: `storageID` stays the same.
- When it **is** shared, the first change gives this stack its own storage, once.
- Reading (`count`, `isEmpty`, `top`, `elements`) never copies.
- `isSharingStorage(with:)` is `true` exactly when both stacks use the same storage object.

## Examples

| Code | Result |
| --- | --- |
| `var a = Stack([1, 2])`, `var b = a` | `a.isSharingStorage(with: b)` is `true` |
| then `b.push(3)` | sharing is `false`; `a.elements` is `[1, 2]`, `b.elements` is `[1, 2, 3]` |
| then `b.push(4)` | `b.storageID` doesn't change |
| `var c = Stack([5])`, `c.pop()` | returns `5`, and `c.storageID` doesn't change |
| `Stack().pop()` | `nil` |

## Constraints

- Up to 100,000 operations.
- Use the `Storage` class for the elements; don't replace it with a plain array property.

<Hints>
<Hint>
Write a `private mutating func makeUnique()` and call it as the first line of every mutating method. That's the whole trick; the rest is an ordinary stack built on `storage.items`.
</Hint>
<Hint>
Inside `makeUnique()`, `isKnownUniquelyReferenced(&storage)` tells you whether this stack is the only one using the storage. If it isn't, replace `storage` with a new `Storage` holding a copy of the items.
</Hint>
<Hint>
For `isSharingStorage(with:)`, compare the two stacks' `storageID` values. Two `ObjectIdentifier`s are equal exactly when they identify the same object.
</Hint>
</Hints>

## Solutions

<Approach title="Brute force: copy on every change" time="O(n) per change" space="O(n)">

Always giving the stack fresh storage before a change keeps copies independent, so it's *correct* about values. But it copies all n elements on every push and pop, even when nobody shares the storage. The tests that check `storageID` stays the same catch this, and a loop of pushes becomes O(n²).

```swift
public mutating func push(_ value: Int) {
    storage = Storage(items: storage.items)   // copies even when not shared
    storage.items.append(value)
}
```

</Approach>

<Approach title="Copy only when shared" time="O(1) per change" space="O(n)">

`makeUnique()` copies only when another stack shares the storage. After that one copy, both stacks own their storage and every later change is in place. Push is O(1) amortised (the array occasionally grows its buffer) and pop is O(1). The first change after sharing costs O(n), once.

```swift
public enum CopyOnWriteStack {
    final class Storage {
        var items: [Int]

        init(items: [Int]) {
            self.items = items
        }
    }

    public struct Stack {
        private var storage: Storage

        public init() {
            storage = Storage(items: [])
        }

        public init(_ elements: [Int]) {
            storage = Storage(items: elements)
        }

        public var storageID: ObjectIdentifier {
            ObjectIdentifier(storage)
        }

        public var count: Int { storage.items.count }
        public var isEmpty: Bool { storage.items.isEmpty }
        public var top: Int? { storage.items.last }
        public var elements: [Int] { storage.items }

        private mutating func makeUnique() {
            if !isKnownUniquelyReferenced(&storage) {
                storage = Storage(items: storage.items)
            }
        }

        public mutating func push(_ value: Int) {
            makeUnique()
            storage.items.append(value)
        }

        public mutating func pop() -> Int? {
            makeUnique()
            return storage.items.popLast()
        }

        public mutating func removeAll() {
            makeUnique()
            storage.items.removeAll()
        }

        public func isSharingStorage(with other: Stack) -> Bool {
            storageID == other.storageID
        }
    }
}
```

`storageID` is safe to read in tests because an `ObjectIdentifier` doesn't hold a strong reference: taking one doesn't make the storage look shared.

</Approach>
