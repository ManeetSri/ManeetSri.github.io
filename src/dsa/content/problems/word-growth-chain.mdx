A word **grows** into another word by inserting exactly one letter anywhere in it: "cat" grows into "chat" (an h after the c) and into "cart". Given a list of words, return the length of the longest chain of words from the list in which each word grows into the next. A single word is a chain of length 1.

`WordGrowthChain.longestChain(_ words: [String]) -> Int`

## Examples

| `words` | Output | One longest chain |
| --- | --- | --- |
| `["chart", "a", "cat", "dog", "at", "cart", "do", "chat", "art"]` | `5` | a → at → cat → cart → chart |
| `["boned", "on", "one", "o", "bone", "bond"]` | `5` | o → on → one → bone → boned |
| `["x", "xx", "xxx", "xx"]` | `3` | x → xx → xxx |
| `["a", "abc"]` | `1` | "abc" is two letters longer |
| `["dog", "god"]` | `1` | same length, so neither grows into the other |
| `[]` | `0` | |

## Constraints

- `0 ≤ words.count ≤ 20,000`
- Each word has 1 to 16 lowercase letters `a` to `z`.
- The list may contain the same word more than once.
- The tests use 20,000 words, so comparing every pair of words is too slow.

<Hints>
<Hint>
A word can only grow from a word exactly one letter shorter. If you handle words in order of length, everything a word could grow from has already been handled.
</Hint>
<Hint>
Keep a dictionary from each word to the longest chain that ends with it. For a new word, which words could come just before it? Only the ones you get by deleting one of its letters.
</Hint>
<Hint>
For each position, delete that letter, and look the shorter word up in the dictionary. The new word's chain is one more than the best lookup, or 1 if none succeed. Converting the word to `Array(word)` once makes deleting by position easy.
</Hint>
</Hints>

## Solutions

<Approach title="Compare every pair" time="O(n² · L)" space="O(n)">

Sort by length, then run the LIS-style DP where word j can come before word i if inserting one letter into j gives i. Checking a pair walks both words together, allowing one skip. Correct, but 20,000 words means 200 million pair checks.

</Approach>

<Approach title="Delete each letter and look it up" time="O(n log n + n · L²)" space="O(n · L)">

With at most 16 letters per word, each word has at most 16 possible predecessors, and a dictionary finds each in O(L).

```swift
public enum WordGrowthChain {
    public static func longestChain(_ words: [String]) -> Int {
        var chainEndingAt: [String: Int] = [:]
        var best = 0
        for word in words.sorted(by: { $0.count < $1.count }) {
            let letters = Array(word)
            var chain = 1
            for skip in letters.indices {
                var shorter = letters
                shorter.remove(at: skip)
                if let before = chainEndingAt[String(shorter)] {
                    chain = max(chain, before + 1)
                }
            }
            chainEndingAt[word] = chain
            best = max(best, chain)
        }
        return best
    }
}
```

A repeated word gets the same chain length both times, so overwriting its entry is harmless. Words that skip a length find nothing and start at 1.

</Approach>
