Given a list of positive whole numbers, decide whether they can be divided into two groups with **equal sums**. Every number goes into exactly one of the groups.

`EqualSumHalves.canSplit(_ numbers: [Int]) -> Bool`

## Examples

| `numbers` | Output |
| --- | --- |
| `[3, 1, 1, 2, 2, 1]` | `true` |
| `[100, 99, 1]` | `true` |
| `[2, 2, 3, 5]` | `false` |
| `[2, 3, 4]` | `false` |
| `[7]` | `false` |

In the first example, 3 + 2 = 5 and 1 + 1 + 2 + 1 = 5. In the third, the total is 12, but no group of the numbers adds up to 6. In the fourth, the total is odd.

## Constraints

- `1 ≤ numbers.count ≤ 200`
- `1 ≤ numbers[i] ≤ 500`
- The tests use 200 numbers, so trying all 2²⁰⁰ ways to split them won't finish.

<Hints>
<Hint>
If one group adds up to half of the total, what do the other numbers add up to?
</Hint>
<Hint>
So the question is: does some subset add up to exactly `total / 2`? Rule out an odd total first.
</Hint>
<Hint>
Keep a `[Bool]` of reachable sums from 0 to `total / 2`, with `reachable[0] = true`. For each number `x`, mark `s` reachable when `s - x` is, going from high `s` to low so that each number is used once.
</Hint>
</Hints>

## Solutions

<Approach title="Try every split" time="O(2ⁿ · n)" space="O(n)">

A bitmask chooses the first group, and the rest is the second. Check whether the first adds up to half the total. Fine for 15 numbers, hopeless for 200.

</Approach>

<Approach title="Subset sum to half the total" time="O(n · S)" space="O(S)">

With total `S`, the split exists exactly when some subset adds up to `S / 2`, because the numbers left out then add up to `S / 2` too. That's subset sum: a Boolean row updated right to left. An odd total, or a number bigger than half, rules a split out before any DP.

```swift
public enum EqualSumHalves {
    public static func canSplit(_ numbers: [Int]) -> Bool {
        let total = numbers.reduce(0, +)
        if total % 2 != 0 { return false }
        let half = total / 2
        if numbers.contains(where: { $0 > half }) { return false }
        var reachable = Array(repeating: false, count: half + 1)
        reachable[0] = true
        for x in numbers {
            for s in stride(from: half, through: x, by: -1) where reachable[s - x] {
                reachable[s] = true
            }
            if reachable[half] { return true }
        }
        return reachable[half]
    }
}
```

With 200 numbers up to 500, half the total is at most 50,000, so the work is at most 10⁷ cheap steps. Stopping as soon as `reachable[half]` turns true saves time on easy inputs. A bitset version (`bits |= bits << x`) would be about 64 times faster still.

</Approach>
