Build a trie that can hold several copies of the same word. It counts copies of a word, counts the words that start with a prefix, and removes one copy at a time. When a removal leaves part of the trie leading to no stored word, those nodes must go.

`CountingTrieDesign.CountingTrie`, a `final class` with `init()`, `insert(_ word: String)`, `count(of word: String) -> Int`, `count(withPrefix prefix: String) -> Int`, `remove(_ word: String) -> Bool` and `nodeCount: Int`

- `insert` adds one copy, even if the word is already there.
- `count(withPrefix:)` counts every stored copy that starts with `prefix`, including copies of `prefix` itself. The empty prefix counts every copy.
- `remove` takes away one copy and returns `true`, or returns `false` and changes nothing if no copy is stored.
- `nodeCount` is the number of nodes, not counting the root. It must always equal the number of distinct non-empty prefixes of the words currently stored, so removing the last word that uses a branch must remove the branch.

Every operation should take O(length of the word or prefix).

## Examples

| Code | Result |
| --- | --- |
| `insert("apple")` twice and `insert("app")`, then `count(of: "apple")` | `2` |
| then `count(withPrefix: "app")` | `3` |
| then `remove("apple")`, and `count(withPrefix: "app")` | `true`, and `2` |
| then `remove("apple")` twice | `true`, then `false` |
| then `nodeCount` | `3`: only a, p, p are left |
| holding "cart", "car", "cat" and "dog": `nodeCount` | `8` |
| then `remove("cart")` and `nodeCount` | `true`, and `7`: the final t goes |
| then `remove("dog")` and `nodeCount` | `true`, and `4` |

## Constraints

- Words hold 1 to 50 lowercase letters, a to z. Prefixes hold 0 to 50.
- Up to 100,000 operations. The tests compare 30,000 random operations against a dictionary of counts.

<Hints>
<Hint>
Give each node two numbers: `endCount`, how many copies of its word are stored, and `passCount`, how many stored copies end at this node or somewhere below it. `count(of:)` reads the first at the word's node, and `count(withPrefix:)` reads the second at the prefix's node.
</Hint>
<Hint>
On insert, add 1 to `passCount` on every node along the path, the root included, and 1 to `endCount` at the end. On remove, check first that `count(of:)` is above 0. Only then walk down again, subtracting 1 from each `passCount`.
</Hint>
<Hint>
If a node's `passCount` drops to 0, no stored copy goes through it any more, and none goes through anything below it either. Remove it from its parent's children right there and stop: the whole branch goes at once. The number of nodes removed is the number of letters from that node to the end of the word.
</Hint>
</Hints>

## Solutions

<Approach title="Pass counts and pruning" time="O(L) per operation" space="O(total letters stored)">

The pass count does both jobs: it answers prefix questions in one walk, and it says exactly where a removed word's private branch begins.

```swift
public enum CountingTrieDesign {
    public final class CountingTrie {
        final class Node {
            var children: [Character: Node] = [:]
            var endCount = 0
            var passCount = 0
        }

        private let root = Node()
        public private(set) var nodeCount = 0

        public init() {}

        public func insert(_ word: String) {
            var node = root
            node.passCount += 1
            for character in word {
                if let next = node.children[character] {
                    node = next
                } else {
                    let next = Node()
                    node.children[character] = next
                    nodeCount += 1
                    node = next
                }
                node.passCount += 1
            }
            node.endCount += 1
        }

        public func count(of word: String) -> Int {
            node(for: word)?.endCount ?? 0
        }

        public func count(withPrefix prefix: String) -> Int {
            node(for: prefix)?.passCount ?? 0
        }

        public func remove(_ word: String) -> Bool {
            guard count(of: word) > 0 else { return false }
            let characters = Array(word)
            var node = root
            node.passCount -= 1
            for (depth, character) in characters.enumerated() {
                let child = node.children[character]!
                child.passCount -= 1
                if child.passCount == 0 {
                    node.children[character] = nil              // the rest of the path goes with it
                    nodeCount -= characters.count - depth
                    return true
                }
                node = child
            }
            node.endCount -= 1
            return true
        }

        private func node(for text: String) -> Node? {
            var node = root
            for character in text {
                guard let next = node.children[character] else { return nil }
                node = next
            }
            return node
        }
    }
}
```

The force unwrap in `remove` is safe because the guard has already checked that the whole path exists. Checking first matters: subtracting along a path that turns out not to be a stored word would leave every count on the way wrong.

</Approach>

<Approach title="Recursive removal without pass counts" time="O(L) to remove, O(size of subtree) to count a prefix" space="O(total letters stored)">

Without pass counts, a recursive removal can still prune: after the same check that a copy exists, remove the copy at the bottom, then on the way back up, delete any child that has no children and no copies left. But counting by prefix then means visiting every node under the prefix, which is far slower when many words share it. That's why the pass count is worth its one extra integer per node.

```swift
/// Returns true when the caller should delete `node`: it ends no word and leads nowhere.
private func remove(_ letters: [Character], at depth: Int, from node: Node) -> Bool {
    if depth == letters.count {
        node.endCount -= 1
    } else if let child = node.children[letters[depth]], remove(letters, at: depth + 1, from: child) {
        node.children[letters[depth]] = nil
        nodeCount -= 1
    }
    return node.endCount == 0 && node.children.isEmpty
}
```

</Approach>
