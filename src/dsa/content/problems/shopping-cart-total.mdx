Work out what a shopping cart costs. Each item has a price in pence and a quantity. The total is every item's price times its quantity, all added up.

`ShoppingCartTotal.total(of items: [Item]) -> Int`

An `Item` is a small struct with three properties, which you read with a dot: `item.name`, `item.pricePence` and `item.quantity`. You'll write structs of your own in M09.

## Examples

| Cart | Returns | Why |
| --- | --- | --- |
| Bread 145p × 2, Milk 95p × 1, Apples 30p × 6 | `565` | 290 + 95 + 180 |
| Eggs 25p × 12 | `300` | |
| Cake 1200p × 0, Juice 180p × 2 | `360` | a quantity of 0 adds nothing |
| empty cart | `0` | |

## Constraints

- `0 ≤ items.count ≤ 1,000`
- `0 ≤ pricePence ≤ 100,000` and `0 ≤ quantity ≤ 1,000`
- Prices are whole pence, not `Double` pounds, so there's no floating-point rounding to worry about.

<Hints>
<Hint>
Two steps: turn each item into its line cost, `item.pricePence * item.quantity`, then add those up. Which tool does each step?
</Hint>
<Hint>
`map` gives you an array of line costs, and `reduce(0, +)` adds them. Or do both at once with one `reduce` whose closure adds each line cost to the running total.
</Hint>
</Hints>

## Solutions

<Approach title="map, then reduce" time="O(n)" space="O(n)">

Turn the items into line costs, then sum them. It reads exactly like the task, at the cost of a temporary array of line costs.

```swift
public static func total(of items: [Item]) -> Int {
    items
        .map { $0.pricePence * $0.quantity }
        .reduce(0, +)
}
```

</Approach>

<Approach title="One reduce" time="O(n)" space="O(1)">

A single `reduce` adds each line cost straight into the running total, so no temporary array is needed. The initial value `0` makes the result an `Int`, even though the elements are `Item`s.

```swift
public enum ShoppingCartTotal {
    public struct Item: Equatable {
        public let name: String
        public let pricePence: Int
        public let quantity: Int

        public init(name: String, pricePence: Int, quantity: Int) {
            self.name = name
            self.pricePence = pricePence
            self.quantity = quantity
        }
    }

    public static func total(of items: [Item]) -> Int {
        items.reduce(0) { total, item in total + item.pricePence * item.quantity }
    }
}
```

A `for-in` loop with a running `total` is just as good. All three versions visit each item once.

</Approach>
