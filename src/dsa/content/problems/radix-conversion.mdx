You're given a non-negative whole number written as text in one base. Return the same number written in another base, or `nil` if the text isn't a valid number in the base it claims to be in.

`RadixConverter.convert(_ digits: String, from source: Int, to target: Int) -> String?`

Digits run from `0` to `9`, then letters for 10 upwards: `a` is 10, `b` is 11, up to `z`, which is 35. The input may use upper- or lower-case letters. The output uses lower-case letters, has no leading zeros, and is `"0"` for zero.

Do it **without** `Int(_:radix:)` and `String(_:radix:)`. Writing both conversion loops yourself is the point.

## Examples

| Call | Returns | Why |
| --- | --- | --- |
| `convert("101101", from: 2, to: 10)` | `"45"` | 32 + 8 + 4 + 1 |
| `convert("2D", from: 16, to: 2)` | `"101101"` | 2 × 16 + 13 = 45 |
| `convert("zz", from: 36, to: 10)` | `"1295"` | 35 × 36 + 35 |
| `convert("0007", from: 8, to: 16)` | `"7"` | leading zeros disappear |
| `convert("0", from: 10, to: 2)` | `"0"` | zero is written as one digit |
| `convert("19", from: 8, to: 10)` | `nil` | 9 isn't an octal digit |
| `convert("", from: 10, to: 2)` | `nil` | no digits at all |

## Constraints

- `2 ≤ source ≤ 36` and `2 ≤ target ≤ 36`
- `digits` has at most 100 characters, and may contain anything.
- When `digits` is valid, its value is at most 10¹⁸, so it fits in an `Int`.

<Hints>
<Hint>
Split the job in two: text in base `source` to an `Int`, then that `Int` to text in base `target`. Each half is one loop from the number systems lesson.
</Hint>
<Hint>
To read a character's value, use its `asciiValue`. `"0"` to `"9"` are 48 to 57, `"a"` to `"z"` are 97 to 122, and `"A"` to `"Z"` are 65 to 90. Anything else, or any value that isn't less than `source`, makes the input invalid.
</Hint>
<Hint>
For the output, peel digits off with `% target` and `/ target`, then reverse. Use `repeat-while` so that 0 still produces `"0"`.
</Hint>
</Hints>

## Solutions

<Approach title="Read with Horner's rule, write by repeated division" time="O(d)" space="O(d)">

Reading: for each character, shift the value so far one place left (multiply by `source`) and add the digit. Writing: `value % target` is the last digit in the new base and `value / target` removes it. Both loops do one step per digit, so the time is proportional to d, the number of digits, which is O(log n) in terms of the value n.

```swift
public enum RadixConverter {
    private static let symbols = Array("0123456789abcdefghijklmnopqrstuvwxyz")

    public static func convert(_ digits: String, from source: Int, to target: Int) -> String? {
        guard !digits.isEmpty else { return nil }

        var value = 0
        for character in digits {
            guard let digit = digitValue(of: character), digit < source else { return nil }
            value = value * source + digit
        }

        var output: [Character] = []
        repeat {
            output.append(symbols[value % target])
            value /= target
        } while value > 0
        return String(output.reversed())
    }

    private static func digitValue(of character: Character) -> Int? {
        guard let code = character.asciiValue else { return nil }
        switch code {
        case 48...57: return Int(code) - 48        // "0" to "9"
        case 97...122: return Int(code) - 97 + 10  // "a" to "z"
        case 65...90: return Int(code) - 65 + 10   // "A" to "Z"
        default: return nil
        }
    }
}
```

`asciiValue` is `nil` for characters outside ASCII, such as emoji, so `guard let` rejects those as well. The `symbols` array turns a digit value back into its character in one lookup.

</Approach>
