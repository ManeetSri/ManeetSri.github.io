In a word-hunt puzzle, you trace words on a grid of letters by moving from cell to cell. Return every word from `words` that can be traced on `board`, each once, sorted alphabetically.

`GridWordHunt.findWords(in board: [[Character]], words: [String]) -> [String]`

A word is traced by starting on any cell holding its first letter, then stepping to a cell above, below, left or right (not diagonally) for each following letter. A cell can be used at most once within one word, but different words may share cells.

## Examples

With this board:

```text
s t a r
p e n t
o a t s
n d e w
```

and `words = ["star", "tent", "pest", "neat", "seat", "spoon", "stew", "sand", "pond", "oat", "tea"]`, the output is `["neat", "oat", "pond", "star", "stew", "tea", "tent"]`.

"stew" starts at the s on the right-hand edge, goes left to t, down to e and right to w. "pest" fails because no s touches the e, and "spoon" would need a second o.

| `board` | `words` | Output |
| --- | --- | --- |
| `[["a", "b"]]` | `["aba", "ab", "ba"]` | `["ab", "ba"]` |
| `[["a", "x"], ["x", "b"]]` | `["ab", "axb"]` | `["axb"]` |
| `[["c", "a", "t"], ["z", "z", "z"]]` | `["cat", "cat", "at"]` | `["at", "cat"]` |

"aba" would need the a twice, and "ab" on the second board would need a diagonal step.

## Constraints

- The board has 1 to 12 rows and 1 to 12 columns, all the same length, of lowercase letters.
- `0 ≤ words.count ≤ 30,000`, and each word holds 1 to 14 lowercase letters. Words may repeat.
- The tests include a 12 × 12 board with 20,000 words, and a board of a's with words up to 14 letters long, where a search that keeps exploring branches whose words it has already found is hundreds of times slower.

<Hints>
<Hint>
Searching for each word separately repeats the same work: "stew", "stem" and "step" all explore the same s-t-e paths. Put the words in a trie instead, and search the grid once from every cell, walking the trie alongside the grid.
</Hint>
<Hint>
From a cell, step to the trie child for that cell's letter. If there's no such child, stop: no word continues this way. Store each word at the node where it ends, so reaching a node with a word means you've found it. Mark a cell as used by overwriting its letter (say with "#") and put the letter back when you return.
</Hint>
<Hint>
To report each word once, clear it from its node when you find it. Then prune: after exploring from a node, if it has no word left and no children, remove it from its parent. Branches whose words have all been found disappear, and the search stops visiting them.
</Hint>
</Hints>

## Solutions

<Approach title="Search for each word on its own" time="O(words × cells × 3^L)" space="O(L)">

The search from [Direction arrays for grid moves](/dsa/learn/matrix-directions), run once per word: try every starting cell, and step to matching neighbours, backtracking when a path fails. It's correct and a good way to check a faster version on small boards, but words with a shared prefix each redo the same exploration.

```swift
public enum GridWordHunt {
    public static func findWords(in board: [[Character]], words: [String]) -> [String] {
        let rows = board.count
        let columns = board[0].count
        var used = Array(repeating: Array(repeating: false, count: columns), count: rows)

        func walk(_ letters: [Character], _ row: Int, _ column: Int, _ index: Int) -> Bool {
            guard row >= 0, row < rows, column >= 0, column < columns,
                  !used[row][column], board[row][column] == letters[index] else { return false }
            if index == letters.count - 1 { return true }
            used[row][column] = true
            defer { used[row][column] = false }
            return walk(letters, row - 1, column, index + 1) || walk(letters, row, column + 1, index + 1)
                || walk(letters, row + 1, column, index + 1) || walk(letters, row, column - 1, index + 1)
        }

        var found = Set<String>()
        for word in words where !found.contains(word) {
            let letters = Array(word)
            search: for row in 0..<rows {
                for column in 0..<columns where walk(letters, row, column, 0) {
                    found.insert(word)
                    break search
                }
            }
        }
        return found.sorted()
    }
}
```

`defer` runs when the function returns, so the cell is unmarked whichever `return` is taken. `break search` leaves both loops at once.

</Approach>

<Approach title="Trie-guided search with pruning" time="O(cells × 4 × 3^(L − 1)) worst case" space="O(total letters in words)">

One search from each cell explores every word at once. The trie stops a path the moment no word continues it, and pruning removes finished branches, so the search shrinks as words are found.

```swift
public enum GridWordHunt {
    final class Node {
        var children = [Node?](repeating: nil, count: 26)
        var childCount = 0
        var word: String?
    }

    public static func findWords(in board: [[Character]], words: [String]) -> [String] {
        let root = Node()
        for word in words {
            var node = root
            for byte in word.utf8 {
                let slot = Int(byte - 97)
                if node.children[slot] == nil {
                    node.children[slot] = Node()
                    node.childCount += 1
                }
                node = node.children[slot]!
            }
            node.word = word
        }

        let visited: UInt8 = 35                          // "#", never a letter
        var grid = board.map { row in row.map { $0.asciiValue! } }
        let rows = grid.count
        let columns = grid.first?.count ?? 0
        let moves = [(-1, 0), (0, 1), (1, 0), (0, -1)]
        var found: [String] = []

        func search(_ row: Int, _ column: Int, from parent: Node) {
            let letter = grid[row][column]
            guard letter != visited, let node = parent.children[Int(letter - 97)] else { return }
            if let word = node.word {
                found.append(word)
                node.word = nil                          // each word is reported once
            }
            if node.childCount > 0 {
                grid[row][column] = visited
                for (dr, dc) in moves {
                    let r = row + dr
                    let c = column + dc
                    if r >= 0 && r < rows && c >= 0 && c < columns {
                        search(r, c, from: node)
                    }
                }
                grid[row][column] = letter
            }
            if node.word == nil && node.childCount == 0 {
                parent.children[Int(letter - 97)] = nil  // nothing left to find down here
                parent.childCount -= 1
            }
        }

        for row in 0..<rows {
            for column in 0..<columns {
                search(row, column, from: root)
            }
        }
        return found.sorted()
    }
}
```

The worst case counts paths: the first step can go 4 ways, and each later step at most 3, since going back to the previous cell is ruled out. The grid is converted to bytes once, so marking a cell is a cheap write, and `childCount` makes "has no children" an O(1) check.

</Approach>
