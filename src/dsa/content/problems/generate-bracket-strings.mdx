Return every **balanced** string made of `n` opening brackets `(` and `n` closing brackets `)`. A string is balanced when every `)` closes an earlier `(` that hasn't been closed yet, and no `(` is left open at the end.

`BracketStringGenerator.balanced(pairs n: Int) -> [String]`

The strings may come in any order: the tests sort them before comparing.

## Examples

| `n` | Output |
| --- | --- |
| `1` | `["()"]` |
| `2` | `["(())", "()()"]` |
| `3` | `["((()))", "(()())", "(())()", "()(())", "()()()"]` |
| `0` | `[""]` |

With no pairs at all, the empty string is the one balanced string.

## Constraints

- `0 ≤ n ≤ 12`.
- For n = 12 there are 208,012 balanced strings among 2²⁴ ≈ 16.8 million strings of brackets. Building every string and filtering is too slow; build only valid prefixes.

<Hints>
<Hint>
Build the string one character at a time, and keep two counts: how many `(` and how many `)` you've placed.
</Hint>
<Hint>
You may add `(` while fewer than `n` have been placed. You may add `)` only while it has something to close: while the `)` count is less than the `(` count.
</Hint>
<Hint>
With those two rules, every prefix you build can still be completed, so every string that reaches length 2n is balanced. Nothing needs checking at the end.
</Hint>
</Hints>

## Solutions

<Approach title="Generate everything, then filter" time="O(n · 4ⁿ)" space="O(n)">

Try all 2²ⁿ strings of brackets and keep the balanced ones, checking each with a running count. Correct, but it looks at 16.8 million strings for n = 12.

</Approach>

<Approach title="Backtracking with open and close counts" time="O(n · Cₙ)" space="O(n) besides the output">

The counts decide what may come next, so the search never builds an invalid prefix. The number of answers is the nth Catalan number, Cₙ = C(2n, n) ÷ (n + 1), and the tree is only a few times larger than that.

```swift
public enum BracketStringGenerator {
    public static func balanced(pairs n: Int) -> [String] {
        var result: [String] = []
        var current: [Character] = []

        func explore(open: Int, close: Int) {
            if current.count == 2 * n {
                result.append(String(current))
                return
            }
            if open < n {
                current.append("(")
                explore(open: open + 1, close: close)
                current.removeLast()
            }
            if close < open {
                current.append(")")
                explore(open: open, close: close + 1)
                current.removeLast()
            }
        }

        explore(open: 0, close: 0)
        return result
    }
}
```

</Approach>
