Expand a string written with repeat counts: `k[text]` stands for `text` repeated `k` times, and repeats can nest.

`RepeatDecoder.decode(_ encoded: String) -> String`

## Examples

| `encoded` | Result |
| --- | --- |
| `"3[ab]"` | `"ababab"` |
| `"2[a3[b]]c"` | `"abbbabbbc"` |
| `"x2[yz]w"` | `"xyzyzw"` |
| `"12[z]"` | `"zzzzzzzzzzzz"` |
| `"2[]x"` | `"x"` |
| `"plain"` | `"plain"` |

## Constraints

- The input is valid: every `[` follows a count and has a matching `]`. Letters are lowercase; digits only appear in counts.
- `1 ≤ k ≤ 50,000`, and the decoded string has at most 100,000 characters.
- Brackets can nest up to 2,000 levels deep, so a recursive solution may be at risk; an explicit stack is safe.

<Hints>
<Hint>
Build the current piece of text as you read letters. A count can have several digits: `count = count * 10 + digit`.
</Hint>
<Hint>
At `[`, the text so far and the count must wait while the inside is decoded. Push them as a pair on a stack, then start a fresh piece and a fresh count.
</Hint>
<Hint>
At `]`, pop the saved text and count, and set the current piece to the saved text followed by the current piece repeated `count` times.
</Hint>
</Hints>

## Solutions

<Approach title="A stack of unfinished pieces" time="about the length of the output" space="O(output length + depth)">

The stack holds one entry per open bracket: the text built before it and the count in front of it. `String(repeating:count:)` does the repeating.

```swift
public enum RepeatDecoder {
    public static func decode(_ encoded: String) -> String {
        var saved: [(prefix: String, count: Int)] = []
        var current = ""
        var count = 0
        for character in encoded {
            if let digit = character.wholeNumberValue {
                count = count * 10 + digit
            } else if character == "[" {
                saved.append((current, count))
                current = ""
                count = 0
            } else if character == "]" {
                let (prefix, repeats) = saved.removeLast()
                current = prefix + String(repeating: current, count: repeats)
            } else {
                current.append(character)
            }
        }
        return current
    }
}
```

Each `]` copies the saved prefix as well as the repeated piece, so heavily nested input with long text before each bracket can copy characters once per level. For the inputs allowed here, the work stays close to the size of the output.

</Approach>
