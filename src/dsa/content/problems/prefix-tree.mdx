Build a prefix tree (a trie) for lowercase words. It needs three operations: add a word, ask whether a whole word was added, and ask whether any added word starts with a given prefix.

`PrefixTreeDesign.PrefixTree`, a `final class` with `init()`, `insert(_ word: String)`, `search(_ word: String) -> Bool` and `startsWith(_ prefix: String) -> Bool`

`search` is true only for words that were inserted, not for the beginnings of longer words. `startsWith` is true when at least one inserted word begins with `prefix`, and a word begins with itself. Every operation should take O(length of the word or prefix), however many words are stored.

## Examples

| Code | Result |
| --- | --- |
| `insert("seat")`, then `search("seat")` | `true` |
| then `search("sea")` | `false`: "sea" is only the start of "seat" |
| then `startsWith("sea")` | `true` |
| then `insert("sea")` and `search("sea")` | `true` |
| then `startsWith("seats")` | `false` |
| A new tree: `startsWith("a")` | `false` |

## Constraints

- Words and prefixes hold 1 to 50 lowercase letters, a to z.
- Up to 100,000 calls in total. The tests insert 50,000 random words, then make 50,000 queries.
- Two trees made with `PrefixTree()` are independent: words added to one never appear in the other.

<Hints>
<Hint>
Nest a node class inside `PrefixTree`. Each node needs a way to find its child for a letter, and a flag saying whether a word ends there. The tree itself holds the root, which stands for the empty prefix.
</Hint>
<Hint>
`insert` walks down from the root one letter at a time, creating a child whenever it's missing, then sets the flag on the last node. `search` and `startsWith` make the same walk without creating anything: if a child is missing, the answer is `false`.
</Hint>
<Hint>
The only difference between `search` and `startsWith` is the last step. Write one private helper that returns the node a string leads to, or `nil`, and both become one line.
</Hint>
</Hints>

## Solutions

<Approach title="Dictionary children" time="O(L) per operation" space="O(total letters inserted)">

Each node keeps a `[Character: Node]` dictionary, so it stores only the children it really has. One helper does the walking for both queries.

```swift
public enum PrefixTreeDesign {
    public final class PrefixTree {
        final class Node {
            var children: [Character: Node] = [:]
            var isWord = false
        }

        private let root = Node()

        public init() {}

        public func insert(_ word: String) {
            var node = root
            for character in word {
                if let next = node.children[character] {
                    node = next
                } else {
                    let next = Node()
                    node.children[character] = next
                    node = next
                }
            }
            node.isWord = true
        }

        public func search(_ word: String) -> Bool {
            node(for: word)?.isWord ?? false
        }

        public func startsWith(_ prefix: String) -> Bool {
            node(for: prefix) != nil
        }

        private func node(for text: String) -> Node? {
            var node = root
            for character in text {
                guard let next = node.children[character] else { return nil }
                node = next
            }
            return node
        }
    }
}
```

`root` is a `let`: the tree always has the same root object, even though that object's children change. That works because `Node` is a class, so changing `node.children` changes the node itself, not a copy.

</Approach>

<Approach title="An array of 26 children" time="O(L) per operation" space="O(26 × nodes)">

With only lowercase letters, a node can keep 26 optional child slots, one per letter, and index them with the letter's byte value minus 97 (the code for "a"). There's no hashing, so each step is a little faster, but every node pays for 26 slots, even a leaf that uses none.

```swift
public final class PrefixTree {
    final class Node {
        var children = [Node?](repeating: nil, count: 26)
        var isWord = false
    }

    private let root = Node()

    public init() {}

    public func insert(_ word: String) {
        var node = root
        for byte in word.utf8 {
            let slot = Int(byte - 97)
            if node.children[slot] == nil {
                node.children[slot] = Node()
            }
            node = node.children[slot]!
        }
        node.isWord = true
    }

    public func search(_ word: String) -> Bool {
        node(for: word)?.isWord ?? false
    }

    public func startsWith(_ prefix: String) -> Bool {
        node(for: prefix) != nil
    }

    private func node(for text: String) -> Node? {
        var node = root
        for byte in text.utf8 {
            guard let next = node.children[Int(byte - 97)] else { return nil }
            node = next
        }
        return node
    }
}
```

`word.utf8` walks the bytes directly, which is safe here because the constraints promise lowercase a to z. Any other character would crash: a byte below 97 makes the `UInt8` subtraction overflow, and one above 122 gives a slot past 25.

</Approach>
