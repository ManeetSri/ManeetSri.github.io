A field agent encodes each letter as its position in the alphabet, A = 1, B = 2, and so on up to Z = 26, then writes the numbers down with no gaps between them. Given the resulting string of digits, return how many different messages it could have come from, modulo 1,000,000,007.

`DigitMessageDecoder.countDecodings(_ message: String) -> Int`

## Examples

| `message` | Output | Why |
| --- | --- | --- |
| `"2611"` | `4` | 2 6 1 1, 26 1 1, 2 6 11, 26 11 |
| `"1201"` | `1` | only 1 20 1: reading 12 leaves a 0 with nothing to pair with |
| `"27"` | `1` | 27 is too big for one letter |
| `"06"` | `0` | no letter starts with 0, and 06 isn't 6 |
| `"100"` | `0` | the last 0 is stranded |
| `"1111"` | `5` | |

## Constraints

- `1 ≤ message.count ≤ 100,000`
- `message` contains only the digits `0` to `9`.
- The tests use messages of 100,000 digits, so a string of ones has far more readings than an `Int` can hold. Reduce modulo 1,000,000,007 as you go.

<Hints>
<Hint>
Look at the last letter of a reading of the first i digits. It used either the last digit on its own, or the last two digits together. When is each one allowed?
</Hint>
<Hint>
One digit works if it's 1 to 9. Two digits work if together they make 10 to 26, which also rules out pairs starting with 0, like 06. So `ways[i]` = (`ways[i − 1]` if the one-digit option works) + (`ways[i − 2]` if the two-digit option works), with `ways[0] = 1`.
</Hint>
<Hint>
Convert the string to an array of digits once, with `message.utf8.map { Int($0) - 48 }` or `compactMap { $0.wholeNumberValue }`, so every access is O(1). Only the last two entries are needed, so two variables are enough.
</Hint>
</Hints>

## Solutions

<Approach title="Try every reading" time="exponential" space="O(n)">

Recursion from the front: read one digit, or two, whenever that's allowed. It's clearly correct, and useful for checking small cases, but a string of n ones has about 1.6ⁿ readings, and the recursion is as deep as the message.

```swift
public static func countDecodings(_ message: String) -> Int {
    let digits = message.compactMap { $0.wholeNumberValue }
    func read(from i: Int) -> Int {
        if i == digits.count {
            return 1
        }
        var total = 0
        if digits[i] != 0 {
            total += read(from: i + 1)
        }
        if i + 1 < digits.count, (10...26).contains(digits[i] * 10 + digits[i + 1]) {
            total += read(from: i + 2)
        }
        return total % 1_000_000_007
    }
    return read(from: 0)
}
```

</Approach>

<Approach title="Bottom-up with two variables" time="O(n)" space="O(n)">

From [Decode ways and perfect squares](/dsa/learn/dp-decode-squares). **State:** `ways[i]`, the readings of the first i digits. **Transition:** add `ways[i − 1]` if digit i is 1 to 9, and `ways[i − 2]` if digits i − 1 and i make 10 to 26. **Base case:** `ways[0] = 1`. **Order:** left to right. **Answer:** `ways[n]`. Rolled down to two variables, with the digit array the only O(n) memory.

```swift
public enum DigitMessageDecoder {
    public static func countDecodings(_ message: String) -> Int {
        let modulus = 1_000_000_007
        let digits = message.utf8.map { Int($0) - 48 }       // 48 is the byte for "0"
        var (twoBack, oneBack) = (0, 1)                      // ways[i - 2] and ways[i - 1], starting at i = 1
        for i in digits.indices {
            var current = 0
            if digits[i] != 0 {
                current = oneBack                             // one digit, 1-9
            }
            if i >= 1 {
                let pair = digits[i - 1] * 10 + digits[i]
                if pair >= 10 && pair <= 26 {
                    current = (current + twoBack) % modulus   // two digits, 10-26
                }
            }
            (twoBack, oneBack) = (oneBack, current)
        }
        return oneBack
    }
}
```

A 0 makes `current` 0 unless it's the second half of 10 or 20, and a 0 entry stays 0 for good: once a prefix can't be read, nothing built on it can.

</Approach>
