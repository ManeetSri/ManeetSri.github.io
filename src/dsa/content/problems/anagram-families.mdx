Group the words that are **anagrams** of each other: words that use exactly the same letters, the same number of times. Return the groups in the order their first word appears in `words`, with words inside each group in their original order.

`AnagramFamilies.groups(_ words: [String]) -> [[String]]`

## Examples

| `words` | Output |
| --- | --- |
| `["stone", "night", "notes", "thing", "onset", "tab", "bat", "tones"]` | `[["stone", "notes", "onset", "tones"], ["night", "thing"], ["tab", "bat"]]` |
| `["aab", "abb", "bab", "aba"]` | `[["aab", "aba"], ["abb", "bab"]]` |
| `["a", "a", "b"]` | `[["a", "a"], ["b"]]` |
| `[]` | `[]` |

In the second example, `"aab"` and `"abb"` use the same *set* of letters but not the same counts, so they're in different groups. Repeated words stay, as in the third example.

## Constraints

- `0 ≤ words.count ≤ 30,000`
- `0 ≤ words[i].count ≤ 100`
- Words use only lowercase letters `a` to `z`. A word may be empty.

<Hints>
<Hint>
You need a **key**: something every anagram of a word shares, and no non-anagram does. Then a dictionary from key to group does the grouping.
</Hint>
<Hint>
Sorting the letters gives such a key: `"notes"` and `"stone"` both become `"enost"`. So does a 26-slot count array, and `[Int]` is `Hashable`, so it can be a dictionary key directly.
</Hint>
<Hint>
A `Dictionary` doesn't keep insertion order, so don't build the answer from its values. Map each key to the **index** of its group in a result array, and append new groups to the end.
</Hint>
</Hints>

## Solutions

<Approach title="Compare with every group" time="O(n · g · L log L)" space="O(n · L)">

For each word, compare it with the first word of every group so far, and start a new group if none match. With g groups that's a lot of comparisons; with 30,000 different words it's hundreds of millions.

```swift
public static func groups(_ words: [String]) -> [[String]] {
    var result: [[String]] = []
    for word in words {
        let sorted = word.sorted()
        if let index = result.firstIndex(where: { $0[0].sorted() == sorted }) {
            result[index].append(word)
        } else {
            result.append([word])
        }
    }
    return result
}
```

</Approach>

<Approach title="Sorted letters as the key" time="O(n · L log L)" space="O(n · L)">

`word.sorted()` gives the letters as a sorted `[Character]`, and `String(...)` turns that into the key.

```swift
public static func groups(_ words: [String]) -> [[String]] {
    var groupIndex: [String: Int] = [:]
    var result: [[String]] = []
    for word in words {
        let key = String(word.sorted())
        if let index = groupIndex[key] {
            result[index].append(word)
        } else {
            groupIndex[key] = result.count
            result.append([word])
        }
    }
    return result
}
```

</Approach>

<Approach title="Letter counts as the key" time="O(n · (L + 26))" space="O(n · L)">

Counting is linear in the word's length, and with lowercase letters guaranteed, a 26-slot array is the cheapest count there is.

```swift
public enum AnagramFamilies {
    public static func groups(_ words: [String]) -> [[String]] {
        var groupIndex: [[Int]: Int] = [:]
        var result: [[String]] = []
        for word in words {
            var key = [Int](repeating: 0, count: 26)
            for byte in word.utf8 {
                key[Int(byte - UInt8(ascii: "a"))] += 1
            }
            if let index = groupIndex[key] {
                result[index].append(word)
            } else {
                groupIndex[key] = result.count
                result.append([word])
            }
        }
        return result
    }
}
```

For short words both keys are fast; the count key wins as words get longer, and it hashes a fixed 26 numbers whatever the word's length.

</Approach>
