A queue is kept in an array: `append` to enqueue and `removeFirst()` to dequeue. Every dequeue slides each item still waiting one place to the left, so dequeuing from a queue of `c` items makes `c - 1` moves. Given a log of operations, work out how many moves the whole log costs, without doing the moves.

`ArrayQueueShiftCount.moves(for operations: String) -> Int`

Each character of `operations` is one operation: `"E"` enqueues an item and `"D"` dequeues one. A dequeue on an empty queue does nothing and costs nothing.

## Examples

| `operations` | Output |
| --- | --- |
| `"EEED"` | `2` |
| `"EEEDDD"` | `3` |
| `"EDEDED"` | `0` |
| `"EEEEEDEDED"` | `12` |
| `"DDE"` | `0` |
| `""` | `0` |

In the second example the three dequeues find 3, 2 and 1 items waiting, so they cost 2 + 1 + 0. In the fourth, the queue holds 5 items at each of its three dequeues, and every enqueue in between tops it back up to 5, so each dequeue costs 4.

## Constraints

- `0 ≤ operations.count ≤ 1,000,000`, and every character is `"E"` or `"D"`.
- The answer fits in an `Int`. The tests include 100,000 enqueues followed by 100,000 dequeues, which cost about 5 billion moves: actually moving them would take far too long.

<Hints>
<Hint>
The cost of a dequeue depends on only one thing: how many items are waiting when it happens.
</Hint>
<Hint>
You don't need the items themselves, just their number. Keep a count: `"E"` adds 1; `"D"` on a non-empty queue adds `count - 1` to the total and then takes 1 off the count.
</Hint>
</Hints>

## Solutions

<Approach title="Simulate the array" time="O(n²)" space="O(n)">

Keep a real array, and for each dequeue, count the elements that `removeFirst()` would slide. It gives the right answer and shows where the cost comes from, but it does all the work it's counting.

```swift
public static func moves(for operations: String) -> Int {
    var queue: [Int] = []
    var total = 0
    for operation in operations {
        if operation == "E" {
            queue.append(0)
        } else if !queue.isEmpty {
            total += queue.count - 1
            queue.removeFirst()
        }
    }
    return total
}
```

</Approach>

<Approach title="Count, don't move" time="O(n)" space="O(1)">

Only the queue's size matters, so a single integer replaces the whole array.

```swift
public enum ArrayQueueShiftCount {
    public static func moves(for operations: String) -> Int {
        var waiting = 0
        var total = 0
        for operation in operations.utf8 {
            if operation == UInt8(ascii: "E") {
                waiting += 1
            } else if waiting > 0 {
                total += waiting - 1             // everyone behind the front slides along
                waiting -= 1
            }
        }
        return total
    }
}
```

Every character is ASCII, so scanning `utf8` bytes is safe here and quicker than walking `Character`s. A steady queue of `w` items costs `w - 1` moves per dequeue, which is why a busy queue that never grows past 1,000 items can still make a billion moves.

</Approach>
