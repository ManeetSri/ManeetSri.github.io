After a flood, people wait on a roof to be ferried to safety. Each boat makes one trip, carries **at most two people**, and can hold at most `limit` kilograms. Nobody weighs more than `limit`. Return the fewest boats needed to carry everyone.

`RescueBoatPairs.boatsNeeded(_ weights: [Int], limit: Int) -> Int`

## Examples

| `weights` | `limit` | Output | Why |
| --- | --- | --- | --- |
| `[3, 5, 3, 4, 2, 1]` | `5` | `4` | 5 alone, 4 + 1, 3 + 2, 3 alone |
| `[2, 2, 2, 2]` | `3` | `4` | no two fit together |
| `[1, 1, 1, 1, 1]` | `100` | `3` | weight isn't the problem: two per boat |
| `[7, 3, 6, 4]` | `10` | `2` | 7 + 3 and 6 + 4 |
| `[]` | `10` | `0` | |

## Constraints

- `0 ≤ weights.count ≤ 100,000`
- `1 ≤ weights[i] ≤ limit ≤ 30,000`
- The tests compare your answer with an exhaustive search over every way to pair people up, on small groups.

<Hints>
<Hint>
Look at the heaviest person. They need a boat no matter what. Who is the best person to send with them?
</Hint>
<Hint>
If the lightest person can't share with the heaviest, nobody can. If they can, is pairing them ever a mistake? Try swapping partners in some best plan.
</Hint>
<Hint>
Sort the weights and use two pointers, `light` at the start and `heavy` at the end. Each step uses one boat for the heavy person, and also takes the light person if they fit. Watch the case where one person is left.
</Hint>
</Hints>

## Solutions

<Approach title="Exhaustive search over sets of people" time="O(2ⁿ · n)" space="O(2ⁿ)">

For every set of people (as a bitmask), the person with the lowest index goes alone or with any one other person who fits. The fewest boats for the whole set is the best of those choices plus the fewest for what's left. Only for small groups, but it settles any doubt about the greedy.

```swift
public static func boatsNeeded(_ weights: [Int], limit: Int) -> Int {
    let n = weights.count
    var fewest = Array(repeating: Int.max, count: 1 << n)
    fewest[0] = 0
    for mask in 1..<(1 << n) {
        let first = mask.trailingZeroBitCount
        let rest = mask & ~(1 << first)
        fewest[mask] = fewest[rest] + 1                       // alone
        for other in 0..<n where rest & (1 << other) != 0 && weights[first] + weights[other] <= limit {
            fewest[mask] = min(fewest[mask], fewest[rest & ~(1 << other)] + 1)
        }
    }
    return fewest[(1 << n) - 1]
}
```

</Approach>

<Approach title="Heaviest with lightest" time="O(n log n)" space="O(n)">

Sort, then pair the heaviest with the lightest whenever they fit. If the lightest doesn't fit with the heaviest, nobody does, so the heaviest goes alone in every plan. If they fit, take a best plan where the heaviest h rides with x and the lightest l with y, and swap partners: h with l fits by assumption, and x with y fits because y weighs no more than h, so `x + y ≤ x + h ≤ limit`. The count never goes up.

```swift
public enum RescueBoatPairs {
    public static func boatsNeeded(_ weights: [Int], limit: Int) -> Int {
        let people = weights.sorted()
        var light = 0
        var heavy = people.count - 1
        var boats = 0
        while light <= heavy {
            if light < heavy && people[light] + people[heavy] <= limit {
                light += 1
            }
            heavy -= 1
            boats += 1
        }
        return boats
    }
}
```

</Approach>
