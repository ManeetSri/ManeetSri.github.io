Decide whether any value repeats within a short distance: two different positions holding the same value, at most `distance` apart.

`NearbyRepeat.hasRepeat(in values: [Int], within distance: Int) -> Bool`

Return `true` if there are positions `i != j` with `values[i] == values[j]` and `abs(i - j) <= distance`.

## Examples

| `values` | `distance` | Result |
| --- | --- | --- |
| `[4, 1, 7, 4]` | `3` | `true` |
| `[4, 1, 7, 4]` | `2` | `false` |
| `[7, 1, 2, 3, 4, 7, 9, 7]` | `2` | `true` |
| `[5, 5]` | `0` | `false` |
| `[1, 2, 3, 4]` | `100` | `false` |

In the third example, the 7s at positions 0 and 5 are too far apart, but the 7s at 5 and 7 are close enough.

## Constraints

- `0 ≤ values.count ≤ 100,000`
- `0 ≤ distance ≤ 100,000`
- `-10⁹ ≤ values[i] ≤ 10⁹`
- Aim for O(n). Comparing every pair within the distance is O(n × distance), too slow when the distance is large.

<Hints>
<Hint>
When you reach a value, which earlier copy of it is the closest?
</Hint>
<Hint>
The most recent one. Keep a dictionary from each value to the last position you saw it at.
</Hint>
<Hint>
At each position, check the stored position (if any) against the distance, then overwrite it with the current position.
</Hint>
</Hints>

## Solutions

<Approach title="Remember the last position of each value" time="O(n)" space="O(n)">

An older copy of a value is always further away than a newer one, so the last position is the only one worth keeping. Overwriting it each time is exactly right.

```swift
public enum NearbyRepeat {
    public static func hasRepeat(in values: [Int], within distance: Int) -> Bool {
        var lastSeen: [Int: Int] = [:]
        for (index, value) in values.enumerated() {
            if let previous = lastSeen[value], index - previous <= distance {
                return true
            }
            lastSeen[value] = index
        }
        return false
    }
}
```

</Approach>

<Approach title="A sliding window set" time="O(n)" space="O(min(n, distance))">

Keep a `Set` of the last `distance` values only. Before adding each value, check whether it's already in the window; after adding it, remove the value that has fallen out of range. This is the sliding-window pattern from M22, and it bounds the memory by the distance instead of by the number of distinct values.

```swift
public static func hasRepeat(in values: [Int], within distance: Int) -> Bool {
    var window = Set<Int>()
    for (index, value) in values.enumerated() {
        if window.contains(value) {
            return true
        }
        window.insert(value)
        if index >= distance {
            window.remove(values[index - distance])
        }
    }
    return false
}
```

When `distance` is 0, each value is removed straight after it's added, so nothing can ever repeat, which matches the definition.

</Approach>
