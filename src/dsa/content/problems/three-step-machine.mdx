A number machine follows three instructions, in order, exactly like a program. Return the number that comes out for a given input.

1. Add 4.
2. Multiply by 3.
3. Subtract 2.

`ThreeStepMachine.run(_ input: Int) -> Int`

You haven't written functions yet, and you don't need to: the exercise file already has the function. Inside it, `input` works like a constant that already holds the starting number. Replace `return 0` with `return` followed by your answer. That's the whole program: input, processing, output.

## Examples

| Call | Returns | Why |
| --- | --- | --- |
| `run(1)` | `13` | 1 + 4 = 5, then 5 × 3 = 15, then 15 − 2 = 13 |
| `run(0)` | `10` | 4, then 12, then 10 |
| `run(10)` | `40` | 14, then 42, then 40 |
| `run(-4)` | `-2` | 0, then 0, then −2 |

## Constraints

- `-1,000 ≤ input ≤ 1,000`
- The steps happen in the order listed. Doing them in a different order gives different answers.

<Hints>
<Hint>
Trace the machine the way the computer would: one step at a time, keeping track of the number so far. Check that you get 13 for an input of 1 before you write any code.
</Hint>
<Hint>
Careful with `input + 4 * 3 - 2`. Swift does `*` before `+` and `-`, just like school maths, so that multiplies 4 by 3 first and gives 11 for an input of 1. Parentheses make the addition happen first.
</Hint>
<Hint>
Either write one expression, `(input + 4) * 3 - 2`, or give each step its own `let`: `let added = input + 4`, then `let tripled = added * 3`, then `return tripled - 2`.
</Hint>
</Hints>

## Solutions

<Approach title="One constant per step" time="O(1)" space="O(1)">

Each line is one instruction, run from top to bottom, and each name records what has happened so far. This is the program written exactly as the machine works, and it's easy to trace by hand.

```swift
public enum ThreeStepMachine {
    public static func run(_ input: Int) -> Int {
        let added = input + 4
        let tripled = added * 3
        return tripled - 2
    }
}
```

</Approach>

<Approach title="One expression with parentheses" time="O(1)" space="O(1)">

The same three steps fit in one expression. The parentheses force the addition to happen before the multiplication. Without them, Swift would multiply first, and the machine's steps would run in the wrong order.

```swift
public enum ThreeStepMachine {
    public static func run(_ input: Int) -> Int {
        return (input + 4) * 3 - 2
    }
}
```

Both versions do the same work. The first is easier to follow while you're learning; the second is what you'll often see once the steps are obvious.

</Approach>
