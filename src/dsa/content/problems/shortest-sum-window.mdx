You're saving towards a goal, and `values` holds what you put away each day: always a positive amount. Return the length of the shortest run of consecutive days whose total is **at least** `target`, or `0` if no run gets there.

`ShortestSumWindow.minLength(_ values: [Int], atLeast target: Int) -> Int`

## Examples

| `values` | `target` | Output |
| --- | --- | --- |
| `[5, 1, 3, 5, 10, 7, 4, 9, 2, 8]` | `15` | `2` |
| `[3, 1, 4, 1, 5]` | `9` | `3` |
| `[4, 2, 6, 1]` | `6` | `1` |
| `[1, 1, 1, 1]` | `5` | `0` |

In the first example, `10 + 7 = 17` reaches 15 in two days, and no single day does. In the second, `4 + 1 + 5 = 10` takes three days; `3 + 1 + 4 + 1 = 9` also reaches the target, but takes four.

## Constraints

- `0 ≤ values.count ≤ 100,000`
- `1 ≤ values[i] ≤ 10,000`: every value is positive.
- `1 ≤ target ≤ 10⁹`

<Hints>
<Hint>
Because every value is positive, adding a day to a run can only raise its total, and dropping a day can only lower it. That's what makes a sliding window work here.
</Hint>
<Hint>
Grow the window on the right, one day at a time. As soon as its sum reaches the target, it's a candidate. Then try to make it shorter.
</Hint>
<Hint>
While the sum is still at least `target`, record the length and drop `values[left]` from the left. When the sum falls below `target`, go back to growing.
</Hint>
</Hints>

## Solutions

<Approach title="Every start" time="O(n²)" space="O(1)">

From each start, add days until the total reaches the target, and keep the shortest. With 100,000 ones and a target of 50,000, that's billions of additions.

```swift
public static func minLength(_ values: [Int], atLeast target: Int) -> Int {
    var best = 0
    for start in values.indices {
        var sum = 0
        for end in start..<values.count {
            sum += values[end]
            if sum >= target {
                if best == 0 || end - start + 1 < best { best = end - start + 1 }
                break
            }
        }
    }
    return best
}
```

</Approach>

<Approach title="Grow, then shrink" time="O(n)" space="O(1)">

`right` adds one day per pass. Whenever the window reaches the target, shrink it from the left for as long as it still does, recording each length on the way. Both pointers only move forward, so the work is at most 2n steps.

```swift
public enum ShortestSumWindow {
    public static func minLength(_ values: [Int], atLeast target: Int) -> Int {
        var left = 0
        var sum = 0
        var best = Int.max
        for right in 0..<values.count {
            sum += values[right]
            while sum >= target {
                best = min(best, right - left + 1)
                sum -= values[left]
                left += 1
            }
        }
        return best == Int.max ? 0 : best
    }
}
```

`Int.max` stands for "no window found yet". It can never be a real length, so the last line can tell the two cases apart.

</Approach>
