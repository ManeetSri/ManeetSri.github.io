Build a trie of lowercase words with no node objects at all: every node is an `Int`, and all the nodes' data lives in a few flat arrays. The root is node `0`, and new nodes are numbered `1`, `2`, `3`, … in the order they're created, which the tests check through `child(of:letter:)`. Because the trie is a struct of arrays, copies must be independent values without any extra work.

`FlatArrayTrie.Trie`, with `nodeCount`, `wordCount`, `insert(_:)`, `contains(_:)`, `countWords(withPrefix:)` and `child(of:letter:)`

- `insert(_:)` stores a word of one or more letters `a`–`z`. Inserting a word that's already stored changes nothing.
- `contains(_:)` is `true` for stored words only, not for prefixes of them.
- `countWords(withPrefix:)` counts stored words that start with the prefix. The empty prefix matches every word.
- `child(of:letter:)` returns the number of the node reached from `node` by `letter`, or `nil` if there's none, including for any character outside `a`–`z`.
- `nodeCount` includes the root, so an empty trie has 1 node. `wordCount` is the number of different words stored.

## Examples

After inserting `"car"`, `"cat"`, `"cart"` and `"dog"`, in that order:

| Call | Result | Why |
| --- | --- | --- |
| `nodeCount` | `9` | root, c, a, r, t (in cat), t (in cart), d, o, g |
| `child(of: 0, letter: "c")` | `1` | the first node created |
| `child(of: 2, letter: "t")` | `4` | the `t` of "cat", created fourth |
| `child(of: 3, letter: "t")` | `5` | the `t` of "cart", under the `r` |
| `child(of: 0, letter: "d")` | `6` | |
| `contains("ca")` | `false` | a prefix, not a stored word |
| `countWords(withPrefix: "ca")` | `3` | car, cat, cart |
| `countWords(withPrefix: "car")` | `2` | car, cart |
| `countWords(withPrefix: "")` | `4` | every word |

## Constraints

- Up to 50,000 insertions, words of 1 to 20 letters; up to 50,000 queries.
- `insert`, `contains` and `countWords(withPrefix:)` should be O(length of the word or prefix).
- Prefixes passed to `countWords(withPrefix:)` and words passed to `contains(_:)` may include characters outside `a`–`z`; they simply match nothing.
- `child(of:letter:)` is only asked about nodes that exist.

<Hints>
<Hint>
Keep `children: [Int32]` with 26 entries per node: node `n`'s child for letter `l` is at `children[n * 26 + l]`. Creating a node appends 26 zeros, and its number is the old node count. The root, node 0, is never anyone's child, so `0` can mean "no child".
</Hint>
<Hint>
Add parallel arrays, one entry per node: `isWord: [Bool]`, and a pass count saying how many stored words run through or end at that node. Then `countWords(withPrefix:)` walks to the prefix's node and reads its pass count, in O(prefix length).
</Hint>
<Hint>
Duplicates would break the pass counts, so `insert` should do nothing if `contains(word)` is already true. Otherwise add one to the root's count (that's `wordCount`) and to the count of every node on the word's path, creating nodes as needed. Work on `word.utf8` bytes: `"a"` is 97.
</Hint>
</Hints>

## Solutions

<Approach title="Class nodes with a counter" time="O(L) per operation" space="O(nodes × 26)">

The trie from [Build a Trie: insert, search, startsWith](/dsa/learn/trie-build), with a pass count per node and an id given to each node when it's created, meets the complexity. But `child(of:letter:)` then needs a way back from a number to a node object, such as an array of nodes, and copying the trie needs a deep copy of every node to keep copies independent. Each node is also two heap allocations.

</Approach>

<Approach title="Flat arrays, nodes as indices" time="O(L) per operation" space="O(nodes × 26)">

Three arrays hold everything: children as `Int32`s, 26 per node, plus a word flag and a pass count per node. A node's number is its index, so `child(of:letter:)` is one array read, nodes are numbered in creation order automatically, and copying a `Trie` is a lazy copy of three arrays.

```swift
public enum FlatArrayTrie {
    public struct Trie {
        private var children: [Int32] = Array(repeating: 0, count: 26)
        private var isWord: [Bool] = [false]
        private var passCount: [Int32] = [0]

        public init() {}

        public var nodeCount: Int {
            isWord.count
        }

        public var wordCount: Int {
            Int(passCount[0])
        }

        private static func slot(_ byte: UInt8) -> Int? {
            byte >= 97 && byte <= 122 ? Int(byte) - 97 : nil
        }

        /// The node reached by following `text` from the root, or nil
        private func find(_ text: String) -> Int? {
            var node = 0
            for byte in text.utf8 {
                guard let slot = Self.slot(byte) else { return nil }
                let next = Int(children[node * 26 + slot])
                if next == 0 { return nil }
                node = next
            }
            return node
        }

        public mutating func insert(_ word: String) {
            guard !word.isEmpty, !contains(word) else { return }
            var node = 0
            passCount[0] += 1
            for byte in word.utf8 {
                let slot = Int(byte) - 97
                var next = Int(children[node * 26 + slot])
                if next == 0 {
                    next = isWord.count
                    children[node * 26 + slot] = Int32(next)
                    children.append(contentsOf: repeatElement(0, count: 26))
                    isWord.append(false)
                    passCount.append(0)
                }
                node = next
                passCount[node] += 1
            }
            isWord[node] = true
        }

        public func contains(_ word: String) -> Bool {
            guard let node = find(word) else { return false }
            return isWord[node]
        }

        public func countWords(withPrefix prefix: String) -> Int {
            guard let node = find(prefix) else { return 0 }
            return Int(passCount[node])
        }

        public func child(of node: Int, letter: Character) -> Int? {
            guard let byte = letter.asciiValue, let slot = Self.slot(byte) else { return nil }
            let next = Int(children[node * 26 + slot])
            return next == 0 ? nil : next
        }
    }
}
```

`Int32` children halve the memory of `Int`, and 2 billion nodes is far more than any trie here needs. Each node costs 26 × 4 = 104 bytes of children, against roughly 270 bytes and two allocations for a class node with a `[Node?]` of 26. `find` returns the empty string's node as the root, which is why `countWords(withPrefix: "")` gives `wordCount` with no special case.

</Approach>
