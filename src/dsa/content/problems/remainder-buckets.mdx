Given an array of whole numbers and a positive whole number `k`, sort the numbers into buckets by their **remainder** after dividing by `k`. The remainder must always be between `0` and `k - 1`, even for negative numbers: `-1` with `k = 3` goes in bucket `2`, because `-1 = 3 × (-1) + 2`.

Return a dictionary from each remainder to the numbers in its bucket. Each bucket keeps the numbers in their input order, and remainders with no numbers don't appear as keys.

`RemainderBuckets.buckets(_ numbers: [Int], k: Int) -> [Int: [Int]]`

## Examples

| `numbers` | `k` | Output |
| --- | --- | --- |
| `[7, 3, 10, 4, 6, 1]` | `3` | `[0: [3, 6], 1: [7, 10, 4, 1]]` |
| `[-1, -3, -7, 2, 5]` | `3` | `[0: [-3], 2: [-1, -7, 2, 5]]` |
| `[4, 8, 12]` | `4` | `[0: [4, 8, 12]]` |
| `[]` | `5` | `[:]` |

In the second example, `-7 = 3 × (-3) + 2`, so `-7` belongs in bucket 2.

## Constraints

- `0 ≤ numbers.count ≤ 100,000`
- `-10⁹ ≤ numbers[i] ≤ 10⁹`
- `1 ≤ k ≤ 1,000`

<Hints>
<Hint>
This is grouping: every number needs a key, its remainder, and each key collects an array of numbers. Either `groups[key, default: []].append(number)` or `Dictionary(grouping:by:)` will do it.
</Hint>
<Hint>
Try `print(-7 % 3)` in Swift. It prints `-1`, not `2`: Swift's `%` gives a result with the same sign as the left-hand number. So `number % k` alone puts negative numbers in negative buckets.
</Hint>
<Hint>
If `number % k` is negative, adding `k` brings it into range. `((number % k) + k) % k` works for every number: the final `% k` turns a result of exactly `k` back into `0`.
</Hint>
</Hints>

## Solutions

<Approach title="Group with default: and a fixed-up remainder" time="O(n)" space="O(n)">

Compute each number's remainder, correct it for negative numbers, then append the number to that bucket. Appending in input order keeps each bucket in input order.

```swift
public static func buckets(_ numbers: [Int], k: Int) -> [Int: [Int]] {
    var groups: [Int: [Int]] = [:]
    for number in numbers {
        var remainder = number % k
        if remainder < 0 {
            remainder += k
        }
        groups[remainder, default: []].append(number)
    }
    return groups
}
```

</Approach>

<Approach title="Dictionary(grouping:by:)" time="O(n)" space="O(n)">

The same idea in one line. `((n % k) + k) % k` handles negative numbers without an `if`.

```swift
public enum RemainderBuckets {
    public static func buckets(_ numbers: [Int], k: Int) -> [Int: [Int]] {
        Dictionary(grouping: numbers) { (($0 % k) + k) % k }
    }
}
```

`Dictionary(grouping:by:)` keeps each group in the order the elements appeared, which is exactly what the problem asks for.

</Approach>
