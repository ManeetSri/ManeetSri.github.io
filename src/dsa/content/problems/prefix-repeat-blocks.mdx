A text is being typed one letter at a time, and after every letter you want to know whether everything typed so far is one short block repeated. For each prefix of `text`, return the length of the shortest block that, repeated a whole number of times, builds exactly that prefix. If no shorter block works, the answer is the prefix's own length (the block is the whole prefix, used once).

`PrefixRepeatBlocks.blockLengths(of text: String) -> [Int]`

Entry i of the result is for the prefix of length i + 1.

## Examples

| `text` | Output |
| --- | --- |
| `"abababab"` | `[1, 2, 3, 2, 5, 2, 7, 2]` |
| `"aaaa"` | `[1, 1, 1, 1]` |
| `"abcabcab"` | `[1, 2, 3, 4, 5, 3, 7, 8]` |
| `"aabaab"` | `[1, 1, 3, 4, 5, 3]` |
| `""` | `[]` |

In the first example, `"abab"` is `"ab"` twice, so its entry is 2, but `"ababa"` can't be built from whole copies of anything shorter, so its entry is 5. In the third, `"abcabcab"` repeats `abc` but stops partway through a block, so it counts as no repeat at all.

## Constraints

- `text` holds 0 to 100,000 lowercase letters, a to z.
- The tests use 100,000-letter texts, including repeated blocks, a Fibonacci word (full of near-repeats) and random letters. Checking every divisor of every prefix letter by letter is far too slow.

<Hints>
<Hint>
If a prefix of length L is a block of length d repeated, then every letter equals the one d places earlier: d is a **period** of the prefix. So you want the smallest period that divides L.
</Hint>
<Hint>
The smallest period of a string is its length minus its longest border (proper prefix that is also a suffix). The prefix function gives the longest border of *every* prefix in one O(n) pass.
</Hint>
<Hint>
For the prefix of length L, let p = L − π[L − 1]. If p divides L, the answer is p. If it doesn't, no block works and the answer is L: any period that divides L would be a multiple of p (by a classic result about periods, since both fit in the string), so p would divide L too.
</Hint>
</Hints>

## Solutions

<Approach title="Try every divisor of every prefix" time="O(n² log n)" space="O(1)">

For each prefix, try each block length d that divides L, smallest first, and check that every letter equals the one d places back. Correct, and fine for short texts, but a prefix of length L can take O(L) per divisor: hopeless at 100,000 letters.

</Approach>

<Approach title="The prefix function" time="O(n)" space="O(n)">

One prefix function gives every prefix's longest border, so every prefix's smallest period, and the divisibility check finishes the job.

```swift
public enum PrefixRepeatBlocks {
    public static func blockLengths(of text: String) -> [Int] {
        let s = Array(text.utf8)
        var pi = [Int](repeating: 0, count: s.count)
        var k = 0
        for i in s.indices.dropFirst() {
            while k > 0 && s[i] != s[k] { k = pi[k - 1] }
            if s[i] == s[k] { k += 1 }
            pi[i] = k
        }
        return s.indices.map { i in
            let length = i + 1
            let period = length - pi[i]
            return length % period == 0 ? period : length
        }
    }
}
```

Why is "not divisible" the same as "no block at all"? If a block of length d < L works, d divides L, so d ≤ L/2, and the smallest period p ≤ d. Two periods p and d with p + d ≤ L force gcd(p, d) to be a period too (the Fine–Wilf theorem), and since p is the smallest, gcd(p, d) = p: p divides d, so p divides L.

</Approach>

<Approach title="The Z-array" time="O(n log n)" space="O(n)">

The prefix of length L is built from blocks of length d exactly when d divides L and the text from position d agrees with the start for L − d letters: z[d] ≥ L − d. For each d, visit its multiples L = 2d, 3d, … and set the answer for any L that doesn't have one yet. Visiting d in increasing order means the first block found is the shortest. The multiples add up to about n ln n visits.

```swift
public enum PrefixRepeatBlocks {
    public static func blockLengths(of text: String) -> [Int] {
        let s = Array(text.utf8)
        let n = s.count
        var z = [Int](repeating: 0, count: n)
        var l = 0, r = 0
        for i in s.indices.dropFirst() {
            if i < r { z[i] = min(r - i, z[i - l]) }
            while i + z[i] < n && s[z[i]] == s[i + z[i]] { z[i] += 1 }
            if i + z[i] > r { l = i; r = i + z[i] }
        }
        var answer = (0..<n).map { $0 + 1 }
        for block in stride(from: 1, through: n / 2, by: 1) {
            for length in stride(from: 2 * block, through: n, by: block)
            where answer[length - 1] == length && z[block] >= length - block {
                answer[length - 1] = block
            }
        }
        return answer
    }
}
```

This works, but it's a little slower and longer than the prefix function, which answers "every prefix" questions directly.

</Approach>
