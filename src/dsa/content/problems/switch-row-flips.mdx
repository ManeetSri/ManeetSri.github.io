A row of switches is written as a string of `"0"` (off) and `"1"` (on). Flipping a switch turns it on if it was off and off if it was on. Return the fewest flips needed so that every off switch comes before every on switch. A row that is all off or all on already counts as sorted.

`SwitchRowFlips.minimumFlips(_ switches: String) -> Int`

## Examples

| `switches` | Output |
| --- | --- |
| `"00110"` | `1` |
| `"010110"` | `2` |
| `"11100"` | `2` |
| `"0111111110"` | `1` |
| `""` | `0` |

In the first example, flip the last switch on. In the second, `000111` and `011111` both take two flips. In the third, turning the two off switches on (`11111`) beats turning the three on switches off.

## Constraints

- `0 ≤ switches.count ≤ 200,000`
- Every character is `"0"` or `"1"`.

<Hints>
<Hint>
A sorted row is some off switches, then some on switches. Reading left to right, you're either still in the off part or already in the on part.
</Hint>
<Hint>
Two states: `zeros` (everything so far is off) and `ones` (switched to the on part). There's no way back from `ones` to `zeros`. A `"1"` costs a flip in `zeros`; a `"0"` costs a flip in `ones`.
</Hint>
<Hint>
`zeros += 1` on a `"1"`, and `ones = min(zeros, ones) + 1` on a `"0"` (or without the + 1 on a `"1"`). Use the old `zeros` for `ones`. The answer is `min(zeros, ones)`.
</Hint>
</Hints>

## Solutions

<Approach title="Try every split" time="O(n)" space="O(n)">

A sorted row is decided by where the on part starts. For a split at position s, the flips are the on switches before s plus the off switches from s on. Start with every off switch counted (split at 0) and move the split one place at a time, updating both counts. Converting the string to an array takes O(n) memory.

</Approach>

<Approach title="Two-state machine" time="O(n)" space="O(1)">

Read the switches once, keeping the fewest flips for each state. Iterating `utf8` avoids building `Character` values.

```swift
public enum SwitchRowFlips {
    public static func minimumFlips(_ switches: String) -> Int {
        var zeros = 0
        var ones = 0
        for switchState in switches.utf8 {
            let isOn = switchState == UInt8(ascii: "1")
            (zeros, ones) = (zeros + (isOn ? 1 : 0), min(zeros, ones) + (isOn ? 0 : 1))
        }
        return min(zeros, ones)
    }
}
```

The two views are the same computation: `zeros` is the count of on switches so far, and `ones` is the best split seen so far.

</Approach>
