Two playlists were merged into one queue without reordering either: the queue takes songs from one or the other, keeping each playlist's own order. Given the two lists as strings, return whether `merged` could have been made this way, using every character of each exactly once.

`InterleavedStringsCheck.canInterleave(_ first: String, _ second: String, into merged: String) -> Bool`

## Examples

| `first` | `second` | `merged` | Output |
| --- | --- | --- | --- |
| `"ab"` | `"ac"` | `"acab"` | `true` |
| `"ab"` | `"ac"` | `"aabc"` | `true` |
| `"ab"` | `"ac"` | `"abca"` | `false` |
| `"abc"` | `"def"` | `"adbecf"` | `true` |
| `"abc"` | `"def"` | `"abdfce"` | `false` |
| `"a"` | `"b"` | `"abc"` | `false` |
| `""` | `""` | `""` | `true` |

In the first example, `merged` is all of `second`, then all of `first`. Taking the first a from `first`, the obvious choice, leads nowhere. In the fifth, f arrives before e, but both come from `second`. In the sixth, `merged` is too long.

## Constraints

- `first` and `second` have 0 to 500 characters each, and `merged` has 0 to 1,000.
- The tests include strings of 500 a's with one different letter at the end, where every guess looks right until the last character.

<Hints>
<Hint>
If `merged.count` isn't `first.count + second.count`, the answer is false. Otherwise, a greedy rule ("take from `first` whenever it fits") fails when both strings offer the same character. You need to keep both options open.
</Hint>
<Hint>
Let `I(i, j)` say whether the first i characters of `first` and the first j of `second` can form the first `i + j` characters of `merged`. The last of those, `merged[i + j - 1]`, came from one string or the other.
</Hint>
<Hint>
`I(i, j)` is true if (`I(i - 1, j)` and `first[i - 1]` equals it) or (`I(i, j - 1)` and `second[j - 1]` equals it). `I(0, 0)` is true. Each row reads only itself and the row above, so one row of Booleans is enough.
</Hint>
</Hints>

## Solutions

<Approach title="Plain recursion" time="O(2ⁿ⁺ᵐ)" space="O(n + m)">

Take `merged`'s next character from whichever strings offer it, and recurse. The tests use it on short strings; on 500 a's it explores an enormous number of equivalent orders.

</Approach>

<Approach title="DP on the two prefixes, one row" time="O(n · m)" space="O(m)">

```swift
public enum InterleavedStringsCheck {
    public static func canInterleave(_ first: String, _ second: String, into merged: String) -> Bool {
        let a = Array(first), b = Array(second), c = Array(merged)
        guard a.count + b.count == c.count else { return false }
        var can = Array(repeating: false, count: b.count + 1)
        for i in 0...a.count {
            for j in 0...b.count {
                if i == 0 && j == 0 {
                    can[j] = true
                } else {
                    let fromFirst = i > 0 && can[j] && a[i - 1] == c[i + j - 1]       // can[j] still holds row i - 1
                    let fromSecond = j > 0 && can[j - 1] && b[j - 1] == c[i + j - 1]
                    can[j] = fromFirst || fromSecond
                }
            }
        }
        return can[b.count]
    }
}
```

A memoised recursion on `(i, j)` works too, at most 1,000 calls deep for these limits.

</Approach>
