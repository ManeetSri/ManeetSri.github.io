Walls stand in a row at positions 0, 1, 2, …, with the given heights. Choose two walls: together with the ground, they hold water up to the height of the **shorter** wall, across the distance between them. The walls in between don't get in the way. Return the most water any two walls can hold.

`MostWaterContainer.maxWater(heights: [Int]) -> Int`

For walls at positions `i < j`, the water is `min(heights[i], heights[j]) × (j − i)`.

## Examples

| `heights` | Output | Best pair |
| --- | --- | --- |
| `[3, 7, 2, 5, 4, 8, 3, 6]` | `36` | positions 1 and 7: `min(7, 6) × 6` |
| `[2, 9, 9, 3]` | `9` | positions 1 and 2: `min(9, 9) × 1` |
| `[1, 2, 3, 4, 5]` | `6` | positions 1 and 4, or 2 and 4 |
| `[1, 1]` | `1` | |
| `[5]` | `0` | there's no second wall |

## Constraints

- `0 ≤ heights.count ≤ 100,000`
- `0 ≤ heights[i] ≤ 10⁴`
- Aim for O(n) time and O(1) space. There are about 5 × 10⁹ pairs of walls.

<Hints>
<Hint>
Write the O(n²) version that tries every pair, and keep it for testing. Then start from the widest container, the first and last walls: every other container is narrower.
</Hint>
<Hint>
To beat a container with a narrower one, the new one must be taller. Which wall limits the height of the current container?
</Hint>
<Hint>
Always move the pointer at the **shorter** wall inwards. Every other container that uses the shorter wall is narrower and no taller, so it can't win. When the heights are equal, moving either one is fine.
</Hint>
</Hints>

## Solutions

<Approach title="Every pair" time="O(n²)" space="O(1)">

```swift
public static func maxWater(heights: [Int]) -> Int {
    var best = 0
    for i in heights.indices {
        for j in (i + 1)..<heights.count {
            best = max(best, min(heights[i], heights[j]) * (j - i))
        }
    }
    return best
}
```

</Approach>

<Approach title="Two pointers, moving the shorter wall" time="O(n)" space="O(1)">

Suppose `heights[left] ≤ heights[right]`. Every container that uses wall `left` with a partner still in play is no wider than the current one, because the partner is at or inside `right`, and no taller, because wall `left` caps the height. So wall `left` has already been measured with its best partner, and it can go. Each step discards one wall that way, so the best container is measured along the way.

```swift
public enum MostWaterContainer {
    public static func maxWater(heights: [Int]) -> Int {
        var left = 0
        var right = heights.count - 1
        var best = 0
        while left < right {
            best = max(best, min(heights[left], heights[right]) * (right - left))
            if heights[left] < heights[right] {
                left += 1
            } else {
                right -= 1
            }
        }
        return best
    }
}
```

Moving the taller wall instead looks harmless, but on `[2, 9, 9, 3]` it keeps the height-2 wall in every container and returns 6.

</Approach>
