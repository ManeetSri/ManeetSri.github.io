A data centre has `n` servers, numbered 0 to n − 1, joined by two-way cables. A cable is **critical** if cutting it alone would split the servers into more separate groups than before: some pair of servers that could reach each other no longer can. Return every critical cable as `[smaller, larger]`, with the list sorted in ascending order.

`CriticalCables.find(_ n: Int, _ cables: [[Int]]) -> [[Int]]`

Each cable is `[a, b]` with `a ≠ b`, in either order. Two servers may be joined by more than one cable, and the network doesn't have to be connected to begin with.

## Examples

| `n` | `cables` | Returns |
| --- | --- | --- |
| `8` | `[[0, 1], [0, 2], [1, 2], [1, 3], [3, 4], [3, 5], [4, 5], [5, 6], [6, 7]]` | `[[1, 3], [5, 6], [6, 7]]` |
| `4` | `[[0, 1], [1, 2], [2, 3], [3, 0]]` | `[]`: every cable is on a loop |
| `3` | `[[0, 1], [0, 1], [1, 2]]` | `[[1, 2]]`: the two 0–1 cables back each other up |
| `6` | `[[0, 1], [1, 2], [2, 0], [3, 4]]` | `[[3, 4]]` |

## Constraints

- `1 ≤ n ≤ 100,000`, with up to 120,000 cables.
- Cutting each cable in turn and counting groups is O(E · (V + E)): over ten billion steps for the largest tests.
- **One test is a line of 100,000 servers**, and a recursive DFS on it goes 100,000 calls deep, which overflows the test thread's stack (see [Stack depth limits in Swift](/dsa/learn/rec-stack-limits)) and crashes the test process. The lesson shows the iterative version. Every other test keeps the depth small, so you can check a recursive version first with `swift test --filter CriticalCablesTests --skip deepLineAndRing`.

<Hints>
<Hint>
A critical cable is a bridge. Run one DFS, giving each server a discovery time `disc` and a low-link `low`: the earliest discovery time its DFS subtree can reach using one cable that isn't part of the DFS tree.
</Hint>
<Hint>
A tree cable from `parent` to `child` is critical exactly when `low[child] > disc[parent]`: nothing below the child has another way up to the parent or above.
</Hint>
<Hint>
Don't skip "the cable back to the parent" by checking the neighbour's number: a second cable to the same parent is a genuine way back. Give every cable an id, and skip only the id you arrived by.
</Hint>
</Hints>

## Solutions

<Approach title="Cut each cable and count groups" time="O(E · (V + E))" space="O(V + E)">

For each cable, count the connected groups without it (with a BFS or union-find) and compare with the count with it. Easy to get right, which makes it a good checker for small networks, and far too slow for 100,000 cables.

</Approach>

<Approach title="Low-links, recursive" time="O(V + E)" space="O(V + E)">

The algorithm from the lesson, written the natural way. It passes every test except the 100,000-server line.

```swift
public enum CriticalCables {
    public static func find(_ n: Int, _ cables: [[Int]]) -> [[Int]] {
        var adjacency = [[(to: Int, id: Int)]](repeating: [], count: n)
        for (id, cable) in cables.enumerated() {
            adjacency[cable[0]].append((cable[1], id))
            adjacency[cable[1]].append((cable[0], id))
        }
        var disc = [Int](repeating: -1, count: n)
        var low = [Int](repeating: 0, count: n)
        var timer = 0
        var critical: [[Int]] = []

        func visit(_ u: Int, arrivedBy cable: Int) {
            disc[u] = timer
            low[u] = timer
            timer += 1
            for (v, id) in adjacency[u] where id != cable {
                if disc[v] == -1 {
                    visit(v, arrivedBy: id)
                    low[u] = min(low[u], low[v])
                    if low[v] > disc[u] { critical.append([min(u, v), max(u, v)]) }
                } else {
                    low[u] = min(low[u], disc[v])
                }
            }
        }

        for server in 0..<n where disc[server] == -1 {
            visit(server, arrivedBy: -1)
        }
        return critical.sorted { $0.lexicographicallyPrecedes($1) }
    }
}
```

`[[Int]]` isn't `Comparable` (arrays aren't), so `sorted()` alone doesn't compile: `lexicographicallyPrecedes` compares two arrays element by element.

</Approach>

<Approach title="Low-links, iterative" time="O(V + E)" space="O(V + E)">

The same algorithm with the call stack made explicit. Each frame remembers the server, the cable it arrived by and the next neighbour to try. The work done after a recursive call returns (updating the parent's low-link and testing the cable) moves to the moment a frame is popped.

```swift
public enum CriticalCables {
    public static func find(_ n: Int, _ cables: [[Int]]) -> [[Int]] {
        var adjacency = [[(to: Int, id: Int)]](repeating: [], count: n)
        for (id, cable) in cables.enumerated() {
            adjacency[cable[0]].append((cable[1], id))
            adjacency[cable[1]].append((cable[0], id))
        }

        var disc = [Int](repeating: -1, count: n)      // -1 means not discovered yet
        var low = [Int](repeating: 0, count: n)
        var timer = 0
        var critical: [[Int]] = []
        // Each frame: a server, the cable it was reached by (-1 for a root), and the next neighbour to try
        var frames: [(server: Int, viaCable: Int, next: Int)] = []

        for root in 0..<n where disc[root] == -1 {
            disc[root] = timer
            low[root] = timer
            timer += 1
            frames.append((root, -1, 0))

            while let frame = frames.last {
                let u = frame.server
                if frame.next < adjacency[u].count {
                    frames[frames.count - 1].next += 1
                    let (v, id) = adjacency[u][frame.next]
                    if id == frame.viaCable { continue }   // not back along the same cable
                    if disc[v] == -1 {
                        disc[v] = timer
                        low[v] = timer
                        timer += 1
                        frames.append((v, id, 0))
                    } else {
                        low[u] = min(low[u], disc[v])      // a back edge to an ancestor
                    }
                } else {
                    frames.removeLast()
                    if let parent = frames.last?.server {
                        low[parent] = min(low[parent], low[u])
                        if low[u] > disc[parent] {
                            critical.append([min(parent, u), max(parent, u)])
                        }
                    }
                }
            }
        }
        return critical.sorted { $0.lexicographicallyPrecedes($1) }
    }
}
```

</Approach>
