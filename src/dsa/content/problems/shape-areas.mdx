A `Shape` enum has three cases, each carrying its own measurements. Give it an `area` property, then write two functions that work on a list of shapes.

`ShapeAreas.Shape.area: Double`, `ShapeAreas.totalArea(of shapes: [Shape]) -> Double` and `ShapeAreas.largest(in shapes: [Shape]) -> Shape?`

```swift
public enum Shape: Equatable {
    case circle(radius: Double)
    case rectangle(width: Double, height: Double)
    case triangle(base: Double, height: Double)
}
```

- A circle's area is π × radius². Use `Double.pi`.
- A rectangle's area is width × height.
- A triangle's area is base × height ÷ 2.
- `totalArea` adds up every shape's area, giving `0` for an empty list.
- `largest` returns the shape with the biggest area. If several tie, return the **first** of them. Return `nil` for an empty list.

## Examples

| Input | Result |
| --- | --- |
| `Shape.rectangle(width: 3, height: 4).area` | `12.0` |
| `Shape.triangle(base: 6, height: 4).area` | `12.0` |
| `Shape.circle(radius: 1).area` | `3.141592653589793` |
| `totalArea(of: [.rectangle(width: 2, height: 3), .triangle(base: 4, height: 5)])` | `16.0` |
| `largest(in: [.circle(radius: 1), .rectangle(width: 2, height: 3)])` | `.rectangle(width: 2, height: 3)` |
| `largest(in: [])` | `nil` |

## Constraints

- `0 ≤ shapes.count ≤ 1,000`
- Every measurement is between `0` and `10,000`.
- Areas are checked to within `0.000000001`.

<Hints>
<Hint>
Inside `area`, `switch self` and write one case per shape. Bind the measurements with `case .circle(let radius):` or `case let .rectangle(width, height):`.
</Hint>
<Hint>
`totalArea` is a running sum: a loop, or `reduce(0) { $0 + $1.area }`.
</Hint>
<Hint>
`largest` is the "best so far" pattern from the largest-number problem. Start from the first shape and replace it only when a later shape is **strictly** bigger, so the first of several ties survives.
</Hint>
</Hints>

## Solutions

<Approach title="Switch with binding, then one pass" time="O(n)" space="O(1)">

`area` matches each case and binds its associated values. The two list functions then never need to know which kind of shape they're looking at: they just ask for `.area`.

```swift
public enum ShapeAreas {
    public enum Shape: Equatable {
        case circle(radius: Double)
        case rectangle(width: Double, height: Double)
        case triangle(base: Double, height: Double)

        public var area: Double {
            switch self {
            case .circle(let radius):
                return Double.pi * radius * radius
            case let .rectangle(width, height):
                return width * height
            case let .triangle(base, height):
                return base * height / 2
            }
        }
    }

    public static func totalArea(of shapes: [Shape]) -> Double {
        shapes.reduce(0) { $0 + $1.area }
    }

    public static func largest(in shapes: [Shape]) -> Shape? {
        guard var best = shapes.first else { return nil }
        for shape in shapes.dropFirst() where shape.area > best.area {
            best = shape
        }
        return best
    }
}
```

Using `>` rather than `>=` is what keeps the first of several equal shapes: with `>=`, each tie would replace the best, leaving the last one. The built-in `shapes.max { $0.area < $1.area }` gives the same answer as the loop, including the tie rule, once you're comfortable with it.

</Approach>
