Build a sorted set of distinct integers as a skip list. Node heights come from a coin-flip closure that the tests supply, so they can check the structure as well as the answers. `insert`, `remove`, `contains` and `ceiling` should be O(log n) expected, whatever order values arrive in.

`SkipListFromScratch.SkipSet`, a class with `init(maxLevel:coinFlip:)`, `count`, `contains(_:)`, `ceiling(_:)`, `insert(_:)`, `remove(_:)`, `elements` and `levelSizes`

- `init(maxLevel: Int = 16, coinFlip: @escaping () -> Bool)`. `maxLevel` is at least 1.
- **Heights.** When `insert` adds a new value, it gives the node a height by calling `coinFlip()`: start at 1 and add a level for every `true`, stopping at the first `false` or when the height reaches `maxLevel`. It calls `coinFlip()` only when the value isn't already present, and only in this way.
- `insert(_:)` returns `true` if the value was added, `false` if it was already there (changing nothing). `remove(_:)` returns whether the value was there.
- `ceiling(_:)` returns the smallest value ≥ its argument, or `nil`.
- `elements` lists every value in increasing order.
- `levelSizes` lists how many nodes are on each level, from level 1 up to the highest level that has any node. It's `[]` for an empty set.

## Examples

With a coin that returns `false, true, true, false, true, false, false, true, true, true, false` and then `false` forever:

| Code | Result | Notes |
| --- | --- | --- |
| `insert(5)` | `true` | one flip, `false`: height 1 |
| `insert(1)` | `true` | `true, true, false`: height 3 |
| `insert(4)`, `insert(2)`, `insert(3)` | `true` each | heights 2, 1 and 4 |
| `levelSizes` | `[5, 3, 2, 1]` | 3 nodes have height ≥ 2: 1, 3 and 4 |
| `insert(4)` | `false` | already present: no flips |
| `ceiling(3)`, `ceiling(6)` | `3`, `nil` | |
| `remove(3)` | `true` | the only node on level 4 |
| `levelSizes`, `elements` | `[4, 2, 1]`, `[1, 2, 4, 5]` | |

## Constraints

- Values are any `Int`, including `Int.min` and `Int.max`.
- The tests insert 100,000 values **in increasing order**, then look up and remove many of them. A plain sorted linked list would make that billions of steps.
- **Freeing a long skip list.** If every node owns an array of links to the nodes after it, freeing the first node frees the second from inside its own `deinit`, and so on: one nested call per node. On a test thread, that overflows the stack after a few tens of thousands of nodes and crashes the tests. Give `SkipSet` a `deinit` that unlinks level 1 with a loop, holding the next node before emptying the current node's links. With nodes like the ones in the hints, it's:

```swift
deinit {
    var current = head.next[0]
    for level in head.next.indices { head.next[level] = nil }
    while let node = current {
        current = node.next[0]
        node.next.removeAll()
    }
}
```

<Hint>
Each node holds its value and an array `next` with one link per level it's on. A head sentinel with `maxLevel` links starts every level. Keep track of `height`, the number of levels in use, so searches start at the top level that has nodes.
</Hint>
<Hint>
Write one helper that walks from the head's top level down: on each level, move right while the next value is less than the target, then record the node you're on before dropping a level. That gives the predecessor on every level. `contains` and `ceiling` look at the predecessor's next node on level 1; `insert` splices the new node in after each predecessor up to its height (new levels above the old height start from the head); `remove` makes each predecessor skip the node, then lowers `height` while the top level is empty.
</Hint>
<Hint>
Heights first: count flips only after the search has shown the value is new, or the scripted coin in the tests gets out of step. Then check `levelSizes` by walking each level from the head, and stop at the first empty level.
</Hint>

## Solutions

<Approach title="Sorted array" time="O(n) per insert or remove" space="O(n)">

A sorted array with binary search answers `contains` and `ceiling` in O(log n), but each insert or remove shifts up to n elements, and it has no levels to report. It's useful as a model to test against, not as an answer.

</Approach>

<Approach title="Skip list with injected coin flips" time="O(log n) expected" space="O(n) expected">

The predecessor walk is the whole algorithm; everything else is splicing.

```swift
public enum SkipListFromScratch {
    public final class SkipSet {
        final class Node {
            let value: Int
            var next: [Node?]

            init(value: Int, height: Int) {
                self.value = value
                next = Array(repeating: nil, count: height)
            }
        }

        public let maxLevel: Int
        private let coinFlip: () -> Bool
        private let head: Node
        private var height = 1                  // levels in use, at least 1
        public private(set) var count = 0

        public init(maxLevel: Int = 16, coinFlip: @escaping () -> Bool) {
            self.maxLevel = max(1, maxLevel)
            self.coinFlip = coinFlip
            head = Node(value: Int.min, height: self.maxLevel)
        }

        deinit {
            var current = head.next[0]
            for level in head.next.indices {
                head.next[level] = nil
            }
            while let node = current {
                current = node.next[0]
                node.next.removeAll()
            }
        }

        /// The last node before `value` on every level in use.
        private func predecessors(of value: Int) -> [Node] {
            var result = Array(repeating: head, count: height)
            var current = head
            for level in stride(from: height - 1, through: 0, by: -1) {
                while let next = current.next[level], next.value < value {
                    current = next
                }
                result[level] = current
            }
            return result
        }

        public func contains(_ value: Int) -> Bool {
            predecessors(of: value)[0].next[0]?.value == value
        }

        public func ceiling(_ value: Int) -> Int? {
            predecessors(of: value)[0].next[0]?.value
        }

        @discardableResult
        public func insert(_ value: Int) -> Bool {
            var before = predecessors(of: value)
            if before[0].next[0]?.value == value { return false }
            var nodeHeight = 1
            while nodeHeight < maxLevel && coinFlip() {
                nodeHeight += 1
            }
            while before.count < nodeHeight {
                before.append(head)                 // new levels start from the head
            }
            height = max(height, nodeHeight)
            let node = Node(value: value, height: nodeHeight)
            for level in 0..<nodeHeight {
                node.next[level] = before[level].next[level]
                before[level].next[level] = node
            }
            count += 1
            return true
        }

        @discardableResult
        public func remove(_ value: Int) -> Bool {
            let before = predecessors(of: value)
            guard let node = before[0].next[0], node.value == value else { return false }
            for level in 0..<node.next.count {
                before[level].next[level] = node.next[level]
            }
            while height > 1 && head.next[height - 1] == nil {
                height -= 1
            }
            count -= 1
            return true
        }

        public var elements: [Int] {
            var result: [Int] = []
            var current = head.next[0]
            while let node = current {
                result.append(node.value)
                current = node.next[0]
            }
            return result
        }

        public var levelSizes: [Int] {
            var sizes: [Int] = []
            for level in 0..<height {
                var size = 0
                var current = head.next[level]
                while let node = current {
                    size += 1
                    current = node.next[level]
                }
                if size == 0 { break }
                sizes.append(size)
            }
            return sizes
        }
    }
}
```

The head's value, `Int.min`, is never compared: the walk only compares the values of nodes after the head, so `Int.min` itself can be stored as an ordinary value.

</Approach>
