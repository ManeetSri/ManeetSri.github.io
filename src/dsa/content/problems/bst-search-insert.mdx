Two warm-ups on a binary search tree, where every value in a node's left subtree is smaller than the node's value and every value in its right subtree is bigger. Find the node holding a value, and add a new value as a leaf.

`BSTSearchInsert.search(_ target: Int, in root: TreeNode?) -> TreeNode?`

`BSTSearchInsert.insert(_ value: Int, into root: TreeNode?) -> TreeNode`

`search` returns the node itself, or `nil` if no node holds `target`. `insert` adds a new leaf in the one place the value can go and returns the root: the same root as before, or the new node if the tree was empty. A BST holds each value once, so inserting a value that's already there changes nothing. Don't rearrange existing nodes.

## Examples

The tree `[40, 20, 60, 10, 30, 50, 70, nil, 15, nil, nil, 45]` has 40 at the root, 15 as the right child of 10, and 45 as the left child of 50.

| Call | Result |
| --- | --- |
| `search(30, …)` | the node holding 30 |
| `search(35, …)` | `nil` |
| `insert(35, …)` | `[40, 20, 60, 10, 30, 50, 70, nil, 15, nil, 35, 45]` |
| `insert(12, …)` | `[40, 20, 60, 10, 30, 50, 70, nil, 15, nil, nil, 45, nil, nil, nil, 12]` |
| `insert(45, …)` | unchanged: 45 is already there |
| `insert(9, into: nil)` | `[9]` |

35 goes right of 30 (bigger than 20, smaller than 40, bigger than 30). 12 goes left of 15.

## Constraints

- `0 ≤` number of nodes `≤ 200,000`
- `root` is a valid binary search tree with no repeated values.
- Trees in the tests are at most 1,000 levels deep, so recursion is fine.

<Hints>
<Hint>
At each node, compare. Equal means found. Smaller means the value can only be in the left subtree, so the right subtree never needs a look. Bigger means right.
</Hint>
<Hint>
For `insert`, walk exactly as `search` does. The walk ends when the side you want to go to is `nil`: that empty spot is where the new leaf belongs.
</Hint>
<Hint>
A loop needs no extra space: keep a `current` node and move it to `node.left` or `node.right`. For `insert`, stop one step early, while you still hold the parent, so you can set `parent.left` or `parent.right`.
</Hint>
</Hints>

## Solutions

<Approach title="Recursion" time="O(h)" space="O(h)">

Each call handles one node and hands the rest to the subtree that can hold the value. `insert` returns the root of the subtree it was given, so the parent re-links whatever comes back; only an empty subtree becomes a new node. h is the height of the tree.

```swift
public static func search(_ target: Int, in root: TreeNode?) -> TreeNode? {
    guard let node = root else { return nil }
    if target == node.value { return node }
    return target < node.value ? search(target, in: node.left) : search(target, in: node.right)
}

public static func insert(_ value: Int, into root: TreeNode?) -> TreeNode {
    guard let node = root else { return TreeNode(value) }
    if value < node.value {
        node.left = insert(value, into: node.left)
    } else if value > node.value {
        node.right = insert(value, into: node.right)
    }
    return node
}
```

</Approach>

<Approach title="Loops" time="O(h)" space="O(1)">

The same walk without the call stack. `insert` checks the child before moving to it, so it still holds the parent when it finds the empty spot.

```swift
public enum BSTSearchInsert {
    public static func search(_ target: Int, in root: TreeNode?) -> TreeNode? {
        var current = root
        while let node = current {
            if target == node.value {
                return node
            }
            current = target < node.value ? node.left : node.right
        }
        return nil
    }

    public static func insert(_ value: Int, into root: TreeNode?) -> TreeNode {
        guard let root else { return TreeNode(value) }
        var node = root
        while true {
            if value < node.value {
                guard let left = node.left else {
                    node.left = TreeNode(value)
                    return root
                }
                node = left
            } else if value > node.value {
                guard let right = node.right else {
                    node.right = TreeNode(value)
                    return root
                }
                node = right
            } else {
                return root                       // already there
            }
        }
    }
}
```

</Approach>
