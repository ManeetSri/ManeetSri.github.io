Reverse each run of `k` consecutive nodes, starting from the front, and return the new head. If fewer than `k` nodes remain at the end, leave them in their original order. Move the nodes themselves; don't change their values.

`ReverseInGroups.reversed(_ head: ListNode?, groupSize k: Int) -> ListNode?`

## Examples

| List | k | Result |
| --- | --- | --- |
| `1 2 3 4 5 6 7 8` | 3 | `3 2 1 6 5 4 7 8` |
| `1 2 3 4 5` | 2 | `2 1 4 3 5` |
| `1 2 3 4` | 4 | `4 3 2 1` |
| `1 2 3` | 4 | `1 2 3` |
| `1 2 3` | 1 | `1 2 3` |

In the first example, 7 and 8 are a group of only two, so they stay as they are.

## Constraints

- 0 to 100,000 nodes.
- `k ≥ 1`, and `k` may be larger than the list.
- O(1) extra space is possible. A recursive solution with one call per group can overflow the stack when `k` is small and the list is long.

<Hints>
<Hint>
Use a dummy node in front of the head, because reversing the first group changes the head. Keep `groupBefore`, the node just before the next group; at first it's the dummy.
</Hint>
<Hint>
Before reversing, walk k steps from `groupBefore` to find the group's last node. If the list ends first, you're done. Otherwise note the node after the group: the group's old first node must end up pointing at it.
</Hint>
<Hint>
Reverse exactly k nodes with the three-pointer loop, starting `previous` at the node after the group instead of `nil`. Then point `groupBefore.next` at the group's old last node, and make the group's old first node the new `groupBefore`.
</Hint>
</Hints>

## Solutions

<Approach title="Swap values through an array" time="O(n)" space="O(n)">

Copying the values out, reversing each whole group in the array, and writing the values back produces the right sequence. But the task asks you to move nodes, and the tests check node identity, so this doesn't pass. It's useful as a reference to compare against while you debug the real thing.

```swift
public static func reversed(_ head: ListNode?, groupSize k: Int) -> ListNode? {
    var values = head?.values ?? []
    var start = 0
    while start + k <= values.count {
        values[start..<(start + k)].reverse()
        start += k
    }
    var current = head
    for value in values {
        current?.value = value        // overwrites values: not allowed
        current = current?.next
    }
    return head
}
```

</Approach>

<Approach title="Look ahead, reverse, reconnect" time="O(n)" space="O(1)">

Everything up to `groupBefore` is finished, and `groupBefore.next` is the first unprocessed node. Each pass checks that a whole group exists, reverses it straight onto the rest of the list, and links it in after `groupBefore`. Every node is visited twice: once by a look-ahead and once by a reversal.

```swift
import DSAKit

public enum ReverseInGroups {
    public static func reversed(_ head: ListNode?, groupSize k: Int) -> ListNode? {
        guard k > 1 else { return head }
        let dummy = ListNode(0, next: head)
        var groupBefore = dummy

        while true {
            // Is there a whole group left? Find its last node.
            var groupLast: ListNode? = groupBefore
            for _ in 0..<k {
                groupLast = groupLast?.next
            }
            guard let last = groupLast else { break }

            let groupFirst = groupBefore.next!
            let after = last.next

            // Reverse the k nodes, starting the reversed chain off pointing at `after`.
            var previous = after
            var current: ListNode? = groupFirst
            while let node = current, node !== after {
                let next = node.next
                node.next = previous
                previous = node
                current = next
            }

            groupBefore.next = last       // the old last node starts the group now
            groupBefore = groupFirst      // and the old first node ends it
        }
        return dummy.next
    }
}
```

</Approach>
