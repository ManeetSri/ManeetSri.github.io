An airline flies one-way routes between cities numbered `0` to `cityCount - 1`. Each flight is `[from, to, price]`. Return the cheapest total price to get from `source` to `target` changing planes at most `maxStops` times, which means using at most `maxStops + 1` flights. Return `-1` if no such trip exists.

`CheapestTripWithinStops.cheapestPrice(cityCount: Int, flights: [[Int]], from source: Int, to target: Int, maxStops: Int) -> Int`

## Examples

With `flights = [[0, 1, 10], [1, 3, 10], [0, 2, 5], [2, 1, 2], [0, 3, 40]]` and 4 cities, from 0 to 3:

| `maxStops` | Output | The trip |
| --- | --- | --- |
| `0` | `40` | 0 → 3 |
| `1` | `20` | 0 → 1 → 3 |
| `2` | `17` | 0 → 2 → 1 → 3 |
| `5` | `17` | more stops don't help |

And some others:

| `cityCount` | `flights` | `source`, `target` | `maxStops` | Output |
| --- | --- | --- | --- | --- |
| `4` | `[[0, 1, 1], [1, 2, 1], [0, 2, 5], [2, 3, 1]]` | 0, 3 | `1` | `6` |
| `2` | `[[0, 1, 5]]` | 1, 0 | `3` | `-1` |
| `3` | `[[0, 1, 5]]` | 2, 2 | `0` | `0` |

In the first of these, the cheap way into city 2 (through city 1) already uses the one stop allowed, so the only legal trip is 0 → 2 → 3. If `source` and `target` are the same city, the trip costs nothing.

## Constraints

- `1 ≤ cityCount ≤ 2,000` and `0 ≤ flights.count ≤ 20,000`
- `0 ≤ from, to < cityCount`, `from ≠ to`, and `1 ≤ price ≤ 10,000,000`
- There may be several flights between the same two cities.
- `0 ≤ maxStops < cityCount`
- The tests use 2,000 cities and 20,000 flights, with `maxStops` up to 1,998.

<Hint>
Plain Dijkstra on price isn't enough: the cheapest way into a city might use up all your stops, while a dearer one with stops to spare is the only way to finish. Look at the second table's first example.
</Hint>
<Hint>
Bellman–Ford's round i finds every cheapest trip that uses at most i flights. How many rounds do you need?
</Hint>
<Hint>
Run `maxStops + 1` rounds, and in each round read prices from a copy of the array taken at the start of the round. Updating in place lets one round chain several flights together.
</Hint>
</Hints>

## Solutions

<Approach title="Try every trip" time="exponential" space="O(maxStops)">

A depth-first search over every sequence of at most `maxStops + 1` flights finds the answer, and it's a good way to check a faster solution on tiny inputs. With dozens of flights per city and many stops it never finishes.

</Approach>

<Approach title="Bellman–Ford with a copy per round" time="O((maxStops + 1) · (n + m))" space="O(n)">

After round i, `price[c]` is the cheapest way to reach c with at most i flights, because each round reads only last round's prices and so adds exactly one flight. If a round changes nothing, later rounds can't either, so stop early.

```swift
public enum CheapestTripWithinStops {
    public static func cheapestPrice(cityCount: Int, flights: [[Int]], from source: Int, to target: Int, maxStops: Int) -> Int {
        let unreached = Int.max
        var price = Array(repeating: unreached, count: cityCount)
        price[source] = 0
        for _ in 0...maxStops {
            let before = price                          // prices using one flight fewer
            var changed = false
            for flight in flights where before[flight[0]] != unreached {
                let candidate = before[flight[0]] + flight[2]
                if candidate < price[flight[1]] {
                    price[flight[1]] = candidate
                    changed = true
                }
            }
            if !changed { break }                       // more flights can't help any further
        }
        return price[target] == unreached ? -1 : price[target]
    }
}
```

</Approach>

<Approach title="Dijkstra on (city, flights used)" time="O(k · m · log(k · m))" space="O(k · n)">

Make each state a pair: a city and the number of flights used to get there. Two ways into the same city with different numbers of flights are now different vertices, so neither blocks the other. Run Dijkstra over states, never using more than `maxStops + 1` flights, and return the price the first time any state of `target` is popped. Here k is `maxStops + 2`, the number of possible flight counts.

</Approach>
