Build a stack of integers that can also report its smallest element, with every operation in O(1).

`MinStackDesign.MinStack`, with `init()`, `push(_ value: Int)`, `pop() -> Int?`, `top: Int?`, `minimum: Int?` and `count: Int`

- `push` puts a value on top.
- `pop` removes and returns the top value, or returns `nil` if the stack is empty. It's marked `@discardableResult`.
- `top` is the top value and `minimum` the smallest value in the stack, or `nil` when it's empty.

## Examples

| Operations | Result |
| --- | --- |
| push 5, push 8, then `minimum` | `5` |
| then push 3, then `minimum` and `top` | `3` and `3` |
| then `pop()`, then `minimum` and `top` | `3` (popped), then `5` and `8` |
| push 2, push 1, push 1, `pop()`, then `minimum` | `1` |
| `MinStack().minimum` | `nil` |

The fourth example has two 1s. Popping one of them leaves the other, so the minimum is still 1.

## Constraints

- Up to 200,000 operations, each O(1).
- Values can be anything from `Int.min` to `Int.max`.

<Hints>
<Hint>
A single variable holding the minimum breaks when the minimum is popped: what was the minimum before it arrived?
</Hint>
<Hint>
Store that answer at push time. Make each entry a pair: the value, and the minimum of everything at or below it.
</Hint>
<Hint>
The new entry's minimum is `Swift.min(value, entries.last?.minimum ?? value)`. Writing `Swift.min` avoids confusion with your own `minimum` property.
</Hint>
</Hints>

## Solutions

<Approach title="Pairs of value and minimum so far" time="O(1) per operation" space="O(n)">

The top entry's stored minimum is the minimum of the whole stack. Popping exposes the entry below, which remembers the minimum from before. Because a stack only changes at the top, a stored minimum can never go out of date.

```swift
public enum MinStackDesign {
    public struct MinStack {
        private var entries: [(value: Int, minimum: Int)] = []

        public init() {}

        public mutating func push(_ value: Int) {
            let minimum = Swift.min(value, entries.last?.minimum ?? value)
            entries.append((value, minimum))
        }

        @discardableResult
        public mutating func pop() -> Int? {
            entries.popLast()?.value
        }

        public var top: Int? { entries.last?.value }
        public var minimum: Int? { entries.last?.minimum }
        public var count: Int { entries.count }
    }
}
```

</Approach>

<Approach title="A second stack of minimums only" time="O(1) per operation" space="O(n), often less">

Keep the values in one array and push onto a second array only when a value is less than **or equal to** the current minimum. When a popped value equals the top of the minimums, pop that too. Ties must be saved, or popping one copy of the minimum would lose it while another copy remains.

```swift
public struct MinStack {
    private var values: [Int] = []
    private var minimums: [Int] = []

    public init() {}

    public mutating func push(_ value: Int) {
        values.append(value)
        if value <= (minimums.last ?? value) {
            minimums.append(value)
        }
    }

    @discardableResult
    public mutating func pop() -> Int? {
        guard let value = values.popLast() else {
            return nil
        }
        if value == minimums.last {
            minimums.removeLast()
        }
        return value
    }

    public var top: Int? { values.last }
    public var minimum: Int? { minimums.last }
    public var count: Int { values.count }
}
```

When values mostly rise, the second array stays short. In the worst case, falling values, it's as long as the first.

</Approach>
