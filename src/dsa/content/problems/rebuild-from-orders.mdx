Rebuild a binary tree from two of its traversals, twice: once from its preorder and inorder, and once from its postorder and inorder. Return the root of a new tree.

`RebuildFromOrders.fromPreorder(_ preorder: [Int], inorder: [Int]) -> TreeNode?` and `RebuildFromOrders.fromPostorder(_ postorder: [Int], inorder: [Int]) -> TreeNode?`

All values are distinct, and both arrays always come from the same tree. `TreeNode` comes from DSAKit; outputs are written in level order, the way `TreeNode.make` takes them.

## Examples

| Call | Output |
| --- | --- |
| `fromPreorder([1, 2, 4, 5, 3, 6], inorder: [4, 2, 5, 1, 3, 6])` | `[1, 2, 3, 4, 5, nil, 6]` |
| `fromPostorder([4, 5, 2, 6, 3, 1], inorder: [4, 2, 5, 1, 3, 6])` | `[1, 2, 3, 4, 5, nil, 6]` |
| `fromPreorder([1, 2], inorder: [2, 1])` | `[1, 2]` |
| `fromPreorder([1, 2], inorder: [1, 2])` | `[1, nil, 2]` |
| `fromPreorder([], inorder: [])` | `nil` |

The last two show why the inorder is needed: the same preorder makes 2 a left child or a right child depending on whether it comes before or after 1 in the inorder.

## Constraints

- At most 150,000 values, all distinct.
- The trees are at most 500 levels deep.
- Aim for O(n).

<Hints>
<Hint>
The first preorder value (or the last postorder value) is the root. Everything before the root in the inorder is its left subtree, and everything after it is its right subtree.
</Hint>
<Hint>
Searching the inorder for each root costs O(n) per node. Build a dictionary from each value to its inorder index first, then recurse on inorder index ranges such as `low..<high`.
</Hint>
<Hint>
Nodes get created in preorder (root, whole left subtree, whole right subtree), so one index can walk the preorder from the front. For postorder, walk from the back: root, then right subtree, then left, so build the right side first.
</Hint>
</Hints>

## Solutions

<Approach title="Slices and a search for each root" time="O(n²) worst case, O(n log n) when balanced" space="O(h)">

Slices describe each piece without copying. Remember that a slice keeps its original indices, so the left subtree's size is `middle - inorder.startIndex`.

```swift
public static func fromPreorder(_ preorder: [Int], inorder: [Int]) -> TreeNode? {
    func build(_ preorder: ArraySlice<Int>, _ inorder: ArraySlice<Int>) -> TreeNode? {
        guard let rootValue = preorder.first else { return nil }
        let middle = inorder.firstIndex(of: rootValue)!
        let leftCount = middle - inorder.startIndex
        let node = TreeNode(rootValue)
        node.left = build(preorder.dropFirst().prefix(leftCount), inorder[inorder.startIndex..<middle])
        node.right = build(preorder.dropFirst(1 + leftCount), inorder[(middle + 1)...])
        return node
    }
    return build(preorder[...], inorder[...])
}
```

</Approach>

<Approach title="An index dictionary and a moving pointer" time="O(n)" space="O(n)">

Each root is found in O(1), and each node is created once.

```swift
import DSAKit

public enum RebuildFromOrders {
    public static func fromPreorder(_ preorder: [Int], inorder: [Int]) -> TreeNode? {
        var position: [Int: Int] = [:]
        for (index, value) in inorder.enumerated() {
            position[value] = index
        }
        var next = 0                                 // preorder[next] is the next root to place
        func build(_ low: Int, _ high: Int) -> TreeNode? {     // inorder[low..<high]
            guard low < high else { return nil }
            let node = TreeNode(preorder[next])
            next += 1
            let middle = position[node.value]!
            node.left = build(low, middle)
            node.right = build(middle + 1, high)
            return node
        }
        return build(0, inorder.count)
    }

    public static func fromPostorder(_ postorder: [Int], inorder: [Int]) -> TreeNode? {
        var position: [Int: Int] = [:]
        for (index, value) in inorder.enumerated() {
            position[value] = index
        }
        var next = postorder.count - 1               // backwards: root, right subtree, left subtree
        func build(_ low: Int, _ high: Int) -> TreeNode? {
            guard low < high else { return nil }
            let node = TreeNode(postorder[next])
            next -= 1
            let middle = position[node.value]!
            node.right = build(middle + 1, high)
            node.left = build(low, middle)
            return node
        }
        return build(0, inorder.count)
    }
}
```

</Approach>
