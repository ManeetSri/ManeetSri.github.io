You'll meet plenty of old tests written with XCTest. Write a translator that converts one line of XCTest into its Swift Testing equivalent, following the lesson's table, so reading old code becomes second nature.

`XCTestTranslator.translate(_ line: String) -> String?`

| XCTest | Swift Testing |
| --- | --- |
| `XCTAssertEqual(a, b)` | `#expect(a == b)` |
| `XCTAssertNotEqual(a, b)` | `#expect(a != b)` |
| `XCTAssert(x)` or `XCTAssertTrue(x)` | `#expect(x)` |
| `XCTAssertFalse(x)` | `#expect(!x)`, or `#expect(!(x))` when `x` contains a space |
| `XCTAssertNil(x)` | `#expect(x == nil)` |
| `XCTAssertNotNil(x)` | `#expect(x != nil)` |
| `XCTAssertThrowsError(e)` | `#expect(throws: (any Error).self) { e }` |

The rules:

- A line containing `try XCTUnwrap(` gets every occurrence replaced by `try #require(`, and is otherwise unchanged. Check this first.
- Otherwise, the line (ignoring spaces at either end) must be one of the assertions above: a name, `(`, the arguments, and a closing `)` as the last character.
- Arguments are separated by commas that aren't inside `( )`, `[ ]` or a string literal, and each is trimmed of spaces.
- Each assertion may have one extra argument, a message, which goes after the first part: `XCTAssertEqual(a, b, "oops")` becomes `#expect(a == b, "oops")`, and the throwing form becomes `#expect(throws: (any Error).self, "oops") { e }`.
- Keep the line's leading spaces, and drop trailing ones.
- Return `nil` for anything else, including the wrong number of arguments.

## Examples

| Line | Result |
| --- | --- |
| `XCTAssertEqual(max(a, b), 9)` | `#expect(max(a, b) == 9)` |
| `XCTAssertFalse(list.isEmpty)` | `#expect(!list.isEmpty)` |
| `XCTAssertFalse(a < b)` | `#expect(!(a < b))` |
| `XCTAssertEqual(name, "Smith, Jo")` | `#expect(name == "Smith, Jo")` |
| `XCTAssertNil(error, "no error")` | `#expect(error == nil, "no error")` |
| `    let first = try XCTUnwrap(sample.first)` | `    let first = try #require(sample.first)` |
| `XCTFail("not done")` | `nil` |
| `XCTAssertEqual(a)` | `nil` |

## Constraints

- Lines are at most 200 characters.
- String literals never contain an escaped quote, and brackets outside strings are balanced.

<Hints>
<Hint>
Separate the indentation first: `line.prefix { $0 == " " }` is the leading spaces. For the `XCTUnwrap` rule, `contains("try XCTUnwrap(")` and `replacing("try XCTUnwrap(", with: "try #require(")` from the standard library do the work.
</Hint>
<Hint>
For an assertion, the name is everything before the first `(`, and the arguments are everything between it and the final `)`. Split the arguments by walking their characters with a `depth` counter (up on `(` or `[`, down on `)` or `]`) and an `inString` flag that flips on every `"`. Split only at a comma when `depth` is 0 and you're not in a string.
</Hint>
<Hint>
Decide how many arguments each name needs (2 for the equality pair, 1 for the rest), accept that many or one more, and build the condition with a `switch` on the name. Add `", " + message` when there's an extra argument.
</Hint>
</Hints>

## Solutions

<Approach title="Split at top-level commas, rebuild as #expect" time="O(L) for a line of length L" space="O(L)">

The only tricky part is splitting the arguments: a comma inside `max(a, b)`, `[1, 2]` or `"Smith, Jo"` belongs to an argument, not between two. Tracking bracket depth and whether you're inside a string handles all three. After that, each assertion is a template.

```swift
public enum XCTestTranslator {
    public static func translate(_ line: String) -> String? {
        let indent = String(line.prefix { $0 == " " })
        var body = Substring(line.dropFirst(indent.count))
        while body.last == " " {
            body.removeLast()
        }

        if body.contains("try XCTUnwrap(") {
            return indent + String(body.replacing("try XCTUnwrap(", with: "try #require("))
        }

        guard let open = body.firstIndex(of: "("), body.last == ")" else {
            return nil
        }
        let name = body[..<open]
        let inside = body[body.index(after: open)..<body.index(before: body.endIndex)]
        let arguments = splitArguments(inside)

        let needed: Int
        switch name {
        case "XCTAssertEqual", "XCTAssertNotEqual":
            needed = 2
        case "XCTAssert", "XCTAssertTrue", "XCTAssertFalse", "XCTAssertNil", "XCTAssertNotNil", "XCTAssertThrowsError":
            needed = 1
        default:
            return nil
        }
        guard arguments.count == needed || arguments.count == needed + 1 else {
            return nil
        }
        let first = arguments[0]
        let message = arguments.count > needed ? ", " + arguments[needed] : ""

        let condition: String
        switch name {
        case "XCTAssertEqual":
            condition = "\(first) == \(arguments[1])"
        case "XCTAssertNotEqual":
            condition = "\(first) != \(arguments[1])"
        case "XCTAssertFalse":
            condition = first.contains(" ") ? "!(\(first))" : "!\(first)"
        case "XCTAssertNil":
            condition = "\(first) == nil"
        case "XCTAssertNotNil":
            condition = "\(first) != nil"
        case "XCTAssertThrowsError":
            return indent + "#expect(throws: (any Error).self\(message)) { \(first) }"
        default:
            condition = first
        }
        return indent + "#expect(\(condition)\(message))"
    }

    private static func splitArguments(_ text: Substring) -> [String] {
        var arguments: [String] = []
        var current = ""
        var depth = 0
        var inString = false
        for character in text {
            if character == "\"" {
                inString.toggle()
            } else if !inString {
                if character == "(" || character == "[" {
                    depth += 1
                } else if character == ")" || character == "]" {
                    depth -= 1
                } else if character == "," && depth == 0 {
                    arguments.append(trimmed(current))
                    current = ""
                    continue
                }
            }
            current.append(character)
        }
        arguments.append(trimmed(current))
        return arguments
    }

    private static func trimmed(_ text: String) -> String {
        var result = Substring(text)
        while result.first == " " { result.removeFirst() }
        while result.last == " " { result.removeLast() }
        return String(result)
    }
}
```

Why the extra brackets for `XCTAssertFalse(a < b)`? Without them you'd get `#expect(!a < b)`, which negates `a` alone: a different test, or one that doesn't compile.

</Approach>
