Given a struct's stored properties in declaration order, each described by its size and alignment, work out where each one goes and what `MemoryLayout` would report for the whole struct.

`StructLayoutCalculator.offsets(of fields: [Field]) -> [Int]` and `StructLayoutCalculator.layout(of fields: [Field]) -> Layout`

Lay the fields out the way Swift does:

1. Each field starts at the smallest offset that is at or after the end of the previous field **and** a multiple of the field's alignment. The first field starts at 0.
2. The struct's **size** is where the last field ends (0 for no fields).
3. Its **alignment** is the largest field alignment (1 for no fields).
4. Its **stride** is the size rounded up to a multiple of the alignment, but never less than 1.

## Examples

| Fields as (size, alignment) | Offsets | Size, stride, alignment |
| --- | --- | --- |
| `(1, 1), (8, 8), (1, 1)`: `Bool, Int, Bool` | `[0, 8, 16]` | `17, 24, 8` |
| `(8, 8), (1, 1), (1, 1)`: `Int, Bool, Bool` | `[0, 8, 9]` | `10, 16, 8` |
| `(1, 1), (2, 2), (1, 1), (8, 8)` | `[0, 2, 4, 8]` | `16, 16, 8` |
| `(9, 8), (1, 1)`: a nested struct, then `Bool` | `[0, 9]` | `10, 16, 8` |
| no fields | `[]` | `0, 1, 1` |

The fourth example is a nested struct of size 9 (an `Int` then a `Bool`) followed by a `Bool`. The `Bool` goes at offset 9, inside the nested struct's unused tail. Swift really does this.

## Constraints

- `0 ≤ fields.count ≤ 100`
- `0 ≤ size ≤ 1,000`
- `alignment` is 1, 2, 4, 8 or 16.

<Hints>
<Hint>
Keep one running number: where the previous field ended. For each field, move it forward to the next multiple of the field's alignment, record that as the field's offset, then add the field's size.
</Hint>
<Hint>
To round `n` up to a multiple of `a`, compute `(n + a - 1) / a * a`. Integer division drops the remainder, which is exactly what makes this work. Try it with `n = 9, a = 8` and `n = 16, a = 8`.
</Hint>
<Hint>
The stride is the final size rounded up to the struct's alignment. An empty struct still needs a stride of 1, so use `max(1, …)`.
</Hint>
</Hints>

## Solutions

<Approach title="One pass with a rounding helper" time="O(n)" space="O(1)">

A single pass places every field and tracks the largest alignment. `layout(of:)` needs only two running numbers; `offsets(of:)` also stores one offset per field for its result.

```swift
public enum StructLayoutCalculator {
    // Field and Layout as in the starter code

    private static func roundUp(_ offset: Int, toMultipleOf alignment: Int) -> Int {
        (offset + alignment - 1) / alignment * alignment
    }

    public static func offsets(of fields: [Field]) -> [Int] {
        var offsets: [Int] = []
        var end = 0
        for field in fields {
            let start = roundUp(end, toMultipleOf: field.alignment)
            offsets.append(start)
            end = start + field.size
        }
        return offsets
    }

    public static func layout(of fields: [Field]) -> Layout {
        var end = 0
        var alignment = 1
        for field in fields {
            end = roundUp(end, toMultipleOf: field.alignment) + field.size
            alignment = max(alignment, field.alignment)
        }
        let stride = max(1, roundUp(end, toMultipleOf: alignment))
        return Layout(size: end, stride: stride, alignment: alignment)
    }
}
```

</Approach>
