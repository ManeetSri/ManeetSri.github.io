People are numbered 0 to n − 1, and you're given a list of friendships, each a pair `[a, b]`. Friends of friends belong to the same friend group, however long the chain. Return the number of friend groups. Someone with no friends at all is a group of one.

`FriendGroupCount.count(_ n: Int, _ friendships: [[Int]]) -> Int`

## Examples

| `n` | `friendships` | Returns | Why |
| --- | --- | --- | --- |
| 5 | `[[0, 1], [1, 2], [3, 4]]` | 2 | \{0, 1, 2\} and \{3, 4\} |
| 6 | `[[0, 1], [2, 3], [4, 5], [1, 3]]` | 2 | \{0, 1, 2, 3\} and \{4, 5\} |
| 7 | `[[5, 6]]` | 6 | \{5, 6\} and five people on their own |
| 3 | `[[0, 1], [1, 0], [0, 1]]` | 2 | the same friendship three times |
| 4 | `[]` | 4 | nobody knows anybody |

## Constraints

- `1 ≤ n ≤ 200,000` and `0 ≤ friendships.count ≤ 200,000`.
- Each pair holds two different people in `0..<n`. A pair can appear more than once, in either order.
- The tests include 200,000 people in 1,000 groups, with the friendships shuffled.

<Hints>
<Hint>
Start by assuming everyone is in a group of their own: n groups. What does one friendship do to that number?
</Hint>
<Hint>
A friendship between two people in different groups merges them, so the count drops by one. A friendship inside one group changes nothing. Union-find's `union` tells you which case you're in.
</Hint>
<Hint>
DSAKit's `UnionFind(count: n)` is available and keeps `componentCount` for you, but writing your own parent array first is the best practice for this module.
</Hint>
</Hints>

## Solutions

<Approach title="Breadth-first search from every unvisited person" time="O(n + f)" space="O(n + f)">

Build an adjacency list from the f friendships, then start a BFS from every person not yet visited, as in [Connected components and flood fill](/dsa/learn/gt-components). Each search that starts is a new group. It's just as fast, but it has to build the adjacency list first.

</Approach>

<Approach title="Union-find" time="O(n + f α(n))" space="O(n)">

Each friendship is a union. The answer is n minus the number of unions that joined two different groups, which is exactly `componentCount`.

```swift
import DSAKit

public enum FriendGroupCount {
    public static func count(_ n: Int, _ friendships: [[Int]]) -> Int {
        var groups = UnionFind(count: n)
        for pair in friendships {
            groups.union(pair[0], pair[1])
        }
        return groups.componentCount
    }
}
```

With your own union-find, keep a counter that starts at n and goes down by one whenever `union` returns true. α(n) is the inverse Ackermann function, so each friendship costs effectively O(1).

</Approach>
