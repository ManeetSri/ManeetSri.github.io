Write a function that greets someone by name.

`HelloSwift.greet(_ name: String) -> String` returns `"Hello, <name>!"`. When the name is empty, it greets the whole world instead: `"Hello, world!"`.

## Examples

| Call | Returns |
| --- | --- |
| `greet("Maneet")` | `"Hello, Maneet!"` |
| `greet("Ada Lovelace")` | `"Hello, Ada Lovelace!"` |
| `greet("")` | `"Hello, world!"` |

## Constraints

- `name` has at most 100 characters.
- Spaces inside the name are kept as they are.

This problem is about the workflow, not the algorithm: edit the exercise, run the tests, read the output, and repeat until it passes.

<Hints>
<Hint>
A `String` has an `isEmpty` property that's `true` when it has no characters.
</Hint>
<Hint>
Put a value inside a string with interpolation: `"Hello, \(name)!"`. Check for the empty case first and return early.
</Hint>
</Hints>

## Solutions

<Approach title="Check, then interpolate" time="O(n)" space="O(n)">

Handle the special case first with `guard`, then build the greeting with string interpolation:

```swift
public enum HelloSwift {
    public static func greet(_ name: String) -> String {
        guard !name.isEmpty else { return "Hello, world!" }
        return "Hello, \(name)!"
    }
}
```

Building the result copies the name's characters into a new string, so time and space grow with the name's length, *n*.

</Approach>
