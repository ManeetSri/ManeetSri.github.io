A weather station logs each day as rainy or dry, and old entries are sometimes corrected. Build a log that answers "what's the longest run of consecutive dry days between these two days?", with every correction so far taken into account.

`LongestDrySpell.Log`, with `init(_ rainy: [Bool])`, `setRainy(_ rainy: Bool, on day: Int)` and `longestDryRun(from start: Int, through end: Int) -> Int`

`rainy[d]` is `true` when day d was rainy. A question covers days `start...end`, inclusive, and only counts dry days inside that range. If every day in it was rainy, the answer is 0.

## Examples

Days 0 to 7 start as rainy, dry, dry, rainy, dry, dry, dry, rainy, which is `[true, false, false, true, false, false, false, true]`. One call after another:

| Call | Output | Why |
| --- | --- | --- |
| `longestDryRun(from: 0, through: 7)` | `3` | days 4–6 |
| `longestDryRun(from: 0, through: 3)` | `2` | days 1–2 |
| `longestDryRun(from: 5, through: 7)` | `2` | days 5–6: day 4 is outside the range |
| `setRainy(false, on: 3)` | | day 3 was dry after all |
| `longestDryRun(from: 0, through: 7)` | `6` | days 1–6 |
| `longestDryRun(from: 2, through: 4)` | `3` | days 2–4 |
| `setRainy(true, on: 5)` | | |
| `longestDryRun(from: 0, through: 7)` | `4` | days 1–4 |

## Constraints

- `1 ≤ rainy.count ≤ 100,000`
- Every call has `0 ≤ start ≤ end < rainy.count` and `0 ≤ day < rainy.count`.
- Up to 100,000 calls, corrections and questions mixed in any order. The tests use 100,000 days and wide ranges, so walking the range for each question is too slow.

<Hints>
<Hint>
A segment tree needs a summary of a block of days such that the summaries of two neighbouring blocks can be joined into the summary of both. The longest dry run alone isn't enough: two blocks with best runs of 2 and 3 might join into a run of 5, or not.
</Hint>
<Hint>
The joined block's best run is inside the left block, inside the right block, or crosses the middle. A crossing run is the dry run at the **end** of the left block plus the dry run at the **start** of the right block. So each block should also remember those two runs.
</Hint>
<Hint>
Store four numbers per block: its length, the dry run from its first day, the dry run up to its last day, and its best run. When the left block is dry all the way through (its starting run equals its length), the joined block's starting run continues into the right block; the ending run works the same way in mirror image. The block of zero days, all four numbers 0, is the identity.
</Hint>
</Hints>

## Solutions

<Approach title="Walk the range" time="O(1) per correction, O(n) per question" space="O(n)">

Keep the array and walk each range, counting the current dry run. Correct and simple, and the obvious check for a faster version, but 100,000 wide questions is billions of steps.

```swift
public struct Log {
    private var rainy: [Bool]

    public init(_ rainy: [Bool]) {
        self.rainy = rainy
    }

    public mutating func setRainy(_ rainy: Bool, on day: Int) {
        self.rainy[day] = rainy
    }

    public func longestDryRun(from start: Int, through end: Int) -> Int {
        var best = 0, current = 0
        for day in start...end {
            current = rainy[day] ? 0 : current + 1
            best = max(best, current)
        }
        return best
    }
}
```

</Approach>

<Approach title="Segment tree of block summaries" time="O(n) to build, O(log n) per call" space="O(n)">

The generic tree from [A generic `SegmentTree<T>`](/dsa/learn/seg-generic), with a four-number summary as the element. Joining isn't commutative (which block is on the left matters), so the query keeps its left and right pieces separate and joins them in the middle.

```swift
public enum LongestDrySpell {
    private struct Block {
        var length: Int
        var prefix: Int                         // dry days running from the block's first day
        var suffix: Int                         // dry days running up to its last day
        var best: Int                           // the longest dry run inside it

        static let empty = Block(length: 0, prefix: 0, suffix: 0, best: 0)

        static func day(rainy: Bool) -> Block {
            rainy ? Block(length: 1, prefix: 0, suffix: 0, best: 0) : Block(length: 1, prefix: 1, suffix: 1, best: 1)
        }

        static func join(_ a: Block, _ b: Block) -> Block {
            Block(length: a.length + b.length,
                  prefix: a.prefix == a.length ? a.length + b.prefix : a.prefix,
                  suffix: b.suffix == b.length ? b.length + a.suffix : b.suffix,
                  best: max(a.best, b.best, a.suffix + b.prefix))
        }
    }

    public struct Log {
        private var tree: [Block]               // bottom-up layout: days are the leaves tree[n..<2n]
        private let count: Int

        public init(_ rainy: [Bool]) {
            count = rainy.count
            tree = Array(repeating: .empty, count: rainy.count) + rainy.map { Block.day(rainy: $0) }
            for node in stride(from: count - 1, through: 1, by: -1) {
                tree[node] = Block.join(tree[2 * node], tree[2 * node + 1])
            }
        }

        public mutating func setRainy(_ rainy: Bool, on day: Int) {
            var node = day + count
            tree[node] = Block.day(rainy: rainy)
            while node > 1 {
                node /= 2
                tree[node] = Block.join(tree[2 * node], tree[2 * node + 1])
            }
        }

        public func longestDryRun(from start: Int, through end: Int) -> Int {
            var left = start + count, right = end + count + 1
            var fromLeft = Block.empty, fromRight = Block.empty
            while left < right {
                if left % 2 == 1 {
                    fromLeft = Block.join(fromLeft, tree[left])
                    left += 1
                }
                if right % 2 == 1 {
                    right -= 1
                    fromRight = Block.join(tree[right], fromRight)
                }
                left /= 2
                right /= 2
            }
            return Block.join(fromLeft, fromRight).best
        }
    }
}
```

With DSAKit, the tree is one line: `SegmentTree(days.map { Block.day(rainy: $0) }, identity: .empty, merge: Block.join)`, and a question is `tree.query(start...end).best`.

</Approach>
