Given a string, decide whether its **letters** read the same forwards and backwards. Ignore case, so `"R"` matches `"r"`, and ignore every character that isn't a letter: spaces, punctuation and digits all get skipped. Text with no letters at all counts as a palindrome.

`LetterPalindrome.isPalindrome(_ text: String) -> Bool`

## Examples

| Input | Output | Letters compared |
| --- | --- | --- |
| `"Never odd or even"` | `true` | `neveroddoreven` |
| `"Was it a car or a cat I saw?"` | `true` | `wasitacaroracatisaw` |
| `"a1b2b3a"` | `true` | `abba` |
| `"Palindrome"` | `false` | `palindrome` |
| `"!!! 42"` | `true` | (none) |

## Constraints

- `0 ≤ text.count ≤ 100,000`
- `text` may contain letters, digits, spaces and punctuation.

<Hints>
<Hint>
Split the problem in two: first get only the letters, all lowercased; then check whether that sequence is a palindrome.
</Hint>
<Hint>
`text.filter { $0.isLetter }` keeps only the letters, and `.lowercased()` lowercases a whole string. Then convert to an array with `Array(...)` for O(1) access by index.
</Hint>
<Hint>
Use two integer indexes, `left = 0` and `right = letters.count - 1`. While `left < right`, compare `letters[left]` and `letters[right]`, then move both towards the middle. Any mismatch means `false`.
</Hint>
</Hints>

## Solutions

<Approach title="Brute force: clean, reverse, compare" time="O(n)" space="O(n)">

Build the cleaned-up letters, then compare them with their reverse. Short and correct, though it builds two arrays and compares every letter twice.

```swift
public static func isPalindrome(_ text: String) -> Bool {
    let letters = Array(text.filter { $0.isLetter }.lowercased())
    return letters == letters.reversed()
}
```

</Approach>

<Approach title="Clean once, then two pointers" time="O(n)" space="O(n)">

Keep only the lowercased letters, in an array for fast indexing. Then walk inwards from both ends, stopping at the first mismatch.

```swift
public enum LetterPalindrome {
    public static func isPalindrome(_ text: String) -> Bool {
        let letters = Array(text.filter { $0.isLetter }.lowercased())
        var left = 0
        var right = letters.count - 1
        while left < right {
            if letters[left] != letters[right] {
                return false
            }
            left += 1
            right -= 1
        }
        return true
    }
}
```

When there are no letters, `right` is `-1`, so the loop never runs and the answer is `true`. In M21 you'll learn to skip non-letters with the two pointers directly on the original text, which avoids building the array at all.

</Approach>
