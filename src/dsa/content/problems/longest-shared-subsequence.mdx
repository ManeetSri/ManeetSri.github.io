A diff tool compares two versions of a text by finding the longest sequence of characters they share in the same order, not necessarily side by side. Return its length, and one such sequence.

`LongestSharedSubsequence.length(_ first: String, _ second: String) -> Int`

`LongestSharedSubsequence.oneLongest(_ first: String, _ second: String) -> String`

## Examples

| `first` | `second` | `length` | One answer for `oneLongest` |
| --- | --- | --- | --- |
| `"ABCBDAB"` | `"BDCABA"` | `4` | `"BCBA"` (or `"BDAB"`, or `"BCAB"`) |
| `"SWIFTLY"` | `"SHIFTILY"` | `6` | `"SIFTLY"` |
| `"abcde"` | `"ace"` | `3` | `"ace"` |
| `"abc"` | `"def"` | `0` | `""` |
| `""` | `"abc"` | `0` | `""` |

When several longest sequences exist, `oneLongest` may return any of them: the tests check that your answer is a subsequence of both strings and has the right length.

## Constraints

- Each string has 0 to 2,000 characters. Compare `Character`s, so accented letters count as one character.
- The tests include two random 2,000-character strings. A memoised recursion would go about 4,000 calls deep, more than a test thread's stack allows, so build the table bottom-up.

<Hints>
<Hint>
Let `L(i, j)` be the answer for the first i characters of `first` and the first j of `second`. Look at the last character of each prefix: what happens when they're equal, and when they're not?
</Hint>
<Hint>
Equal: `L(i - 1, j - 1) + 1`. Different: at least one of them isn't used, so `max(L(i - 1, j), L(i, j - 1))`. An empty prefix gives 0. Fill a table of (n + 1) × (m + 1) cells row by row.
</Hint>
<Hint>
For the sequence itself, start at the bottom-right cell. On equal characters, record the character and move diagonally; otherwise move towards the larger of the cells above and to the left. Reverse what you recorded.
</Hint>
</Hints>

## Solutions

<Approach title="Plain recursion" time="O(2ⁿ⁺ᵐ)" space="O(n + m)">

Write the recurrence as a recursive function on `(i, j)`. It's correct, and worth keeping to test against, but every mismatch branches in two: two 10-character strings with nothing in common already take hundreds of thousands of calls.

</Approach>

<Approach title="The LCS table and its traceback" time="O(n · m)" space="O(n · m)">

Fill the table on prefixes. Looping over `0...n` with the base case as the first branch keeps empty strings safe. The length only needs two rows; the traceback needs the whole table.

```swift
public enum LongestSharedSubsequence {
    public static func length(_ first: String, _ second: String) -> Int {
        let a = Array(first), b = Array(second)
        var previous = Array(repeating: 0, count: b.count + 1)
        var current = previous
        for i in 0..<a.count {
            for j in 1..<(b.count + 1) {
                current[j] = a[i] == b[j - 1] ? previous[j - 1] + 1 : max(previous[j], current[j - 1])
            }
            swap(&previous, &current)
        }
        return previous[b.count]
    }

    public static func oneLongest(_ first: String, _ second: String) -> String {
        let a = Array(first), b = Array(second)
        let n = a.count, m = b.count
        var table = Array(repeating: Array(repeating: 0, count: m + 1), count: n + 1)
        for i in 0...n {
            for j in 0...m {
                if i == 0 || j == 0 {
                    table[i][j] = 0
                } else if a[i - 1] == b[j - 1] {
                    table[i][j] = table[i - 1][j - 1] + 1
                } else {
                    table[i][j] = max(table[i - 1][j], table[i][j - 1])
                }
            }
        }
        var letters: [Character] = []
        var i = n, j = m
        while i > 0 && j > 0 {
            if a[i - 1] == b[j - 1] {
                letters.append(a[i - 1])
                i -= 1
                j -= 1
            } else if table[i - 1][j] >= table[i][j - 1] {
                i -= 1
            } else {
                j -= 1
            }
        }
        return String(letters.reversed())
    }
}
```

In the two-row version, `current[0]` is never written, so it stays 0: the empty prefix of `second`.

</Approach>
