Return the shortest substring of `text` that **covers** `pattern`: it contains every character of `pattern`, at least as many times as `pattern` does. If several windows are equally short, return the one that starts first. If no window covers the pattern, return `""`.

`SmallestCoveringWindow.window(in text: String, covering pattern: String) -> String`

## Examples

| `text` | `pattern` | Output |
| --- | --- | --- |
| `"BANANABREAD"` | `"ABD"` | `"BREAD"` |
| `"xaybzaxb"` | `"aab"` | `"aybza"` |
| `"SWIFTLYSWIFT"` | `"WIT"` | `"WIFT"` |
| `"helloworld"` | `"lol"` | `"llo"` |
| `"a"` | `"A"` | `""` |

In the second example, the window needs two `a`s and a `b`. In the third, `"WIFT"` appears twice; the first one wins. Upper and lower case are different characters, so `"A"` doesn't cover `"a"`.

## Constraints

- `1 ≤ text.count ≤ 100,000` and `1 ≤ pattern.count ≤ 100,000`
- Both strings use only the English letters `a` to `z` and `A` to `Z`.

<Hints>
<Hint>
Count what the pattern needs, character by character. A window covers the pattern when, for every character, the window has at least the needed count.
</Hint>
<Hint>
Grow the window on the right until it covers the pattern. Then shrink it from the left for as long as it still covers, recording the window each time. Then grow again.
</Hint>
<Hint>
Checking every count after each step is slow. Keep `missing`: how many pattern characters the window still lacks, counting repeats. Adding a character that was still needed decreases it; removing a character the window can't spare increases it. The window covers the pattern exactly when `missing == 0`.
</Hint>
</Hints>

## Solutions

<Approach title="Every window" time="O(n² · m)" space="O(1)">

Try every length from shortest to longest, and every start for that length, counting the window's characters each time. The first window that covers the pattern is the answer. It's a useful brute force for testing, and hopeless for 100,000 characters.

```swift
public static func window(in text: String, covering pattern: String) -> String {
    let t = Array(text)
    var need: [Character: Int] = [:]
    for ch in pattern { need[ch, default: 0] += 1 }
    guard pattern.count <= t.count else { return "" }
    for length in pattern.count...t.count {
        for start in 0...(t.count - length) {
            var have: [Character: Int] = [:]
            for ch in t[start..<start + length] { have[ch, default: 0] += 1 }
            if need.allSatisfy({ have[$0.key, default: 0] >= $0.value }) {
                return String(t[start..<start + length])
            }
        }
    }
    return ""
}
```

</Approach>

<Approach title="Grow, shrink and a missing counter" time="O(n + m)" space="O(1)">

`need[c]` starts as the pattern's count of `c` and goes down as the window takes copies of `c`. It can go negative, which means the window has spare copies. `missing` only changes when a needed copy enters or leaves.

```swift
public enum SmallestCoveringWindow {
    public static func window(in text: String, covering pattern: String) -> String {
        let t = Array(text.utf8)
        let p = Array(pattern.utf8)
        guard !p.isEmpty, p.count <= t.count else { return "" }
        var need = [Int](repeating: 0, count: 128)
        for byte in p {
            need[Int(byte)] += 1
        }
        var missing = p.count
        var left = 0
        var bestStart = 0
        var bestLength = Int.max
        for right in 0..<t.count {
            let entering = Int(t[right])
            if need[entering] > 0 {
                missing -= 1
            }
            need[entering] -= 1
            while missing == 0 {
                if right - left + 1 < bestLength {
                    bestLength = right - left + 1
                    bestStart = left
                }
                let leaving = Int(t[left])
                need[leaving] += 1
                if need[leaving] > 0 {
                    missing += 1
                }
                left += 1
            }
        }
        guard bestLength != Int.max else { return "" }
        return String(decoding: t[bestStart..<bestStart + bestLength], as: UTF8.self)
    }
}
```

Two details make it fast. The window is remembered as a start and a length, and the substring is built once at the very end; building a `String` for every candidate would copy up to n characters each time. And because only a strictly shorter window replaces the best, the first of several equal windows is the one returned.

</Approach>
