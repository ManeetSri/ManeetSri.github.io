Draw a name badge: the name inside a box made of `+`, `-` and `|` characters, returned as one three-line string.

`NameBadge.badge(for name: String) -> String`

For `badge(for: "Ada")`, the result prints as:

```text
+-----+
| Ada |
+-----+
```

The middle line is `| `, the name, then ` |`. The top and bottom borders are `+`, then enough `-` to match, then `+`, so all three lines are the same width. Lines are separated by a newline, with no newline at the end.

Two tools you haven't met yet will help:

- `name.count` is the number of characters in `name`. `"Ada".count` is `3`.
- `String(repeating: "-", count: 4)` makes a string of four dashes: `"----"`.

You'll study both properly in M02 and M08. Here you only need to use them.

## Examples

| Call | Returns (as written in Swift) |
| --- | --- |
| `badge(for: "Ada")` | `"+-----+\n\| Ada \|\n+-----+"` |
| `badge(for: "X")` | `"+---+\n\| X \|\n+---+"` |
| `badge(for: "Maneet")` | `"+--------+\n\| Maneet \|\n+--------+"` |
| `badge(for: "")` | `"+--+\n\|  \|\n+--+"` |

## Constraints

- `name` has at most 50 characters: letters and spaces only.
- An empty name still gets a box, with two spaces inside.

<Hints>
<Hint>
Work out the border first. For `"Ada"` there are 5 dashes. How does 5 relate to the 3 letters of the name?
</Hint>
<Hint>
The dashes cover the name **plus** the space on each side, so you need `name.count + 2` of them.
</Hint>
<Hint>
Store the border in a constant with `let`, then use it twice: `"\(border)\n| \(name) |\n\(border)"`.
</Hint>
</Hints>

## Solutions

<Approach title="Build the border once, use it twice" time="O(n)" space="O(n)">

The top and bottom lines are identical, so build that line once and give it a name. Then interpolate it above and below the name.

```swift
public enum NameBadge {
    public static func badge(for name: String) -> String {
        let border = "+" + String(repeating: "-", count: name.count + 2) + "+"
        return "\(border)\n| \(name) |\n\(border)"
    }
}
```

`+` joins the corner characters to the dashes, which is fine here because all three pieces are strings. Counting the name's characters and building the border both take time in proportion to the name's length, *n*, so the whole function is O(n) time and space.

</Approach>

<Approach title="A multi-line string" time="O(n)" space="O(n)">

The same idea, written so the code looks like the badge.

```swift
public enum NameBadge {
    public static func badge(for name: String) -> String {
        let dashes = String(repeating: "-", count: name.count + 2)
        return """
        +\(dashes)+
        | \(name) |
        +\(dashes)+
        """
    }
}
```

</Approach>
