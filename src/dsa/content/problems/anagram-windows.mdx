Return every index where an **anagram** of `pattern` starts in `text`: a stretch of `pattern.count` consecutive characters that uses exactly the same letters, the same number of times, in any order. Return the indexes in increasing order.

`AnagramWindows.starts(of pattern: String, in text: String) -> [Int]`

## Examples

| `pattern` | `text` | Output |
| --- | --- | --- |
| `"listen"` | `"enlistsilent"` | `[0, 5, 6]` |
| `"tea"` | `"eatate"` | `[0, 3]` |
| `"ab"` | `"abab"` | `[0, 1, 2]` |
| `"aab"` | `"baaab"` | `[0, 2]` |
| `"abc"` | `"xyz"` | `[]` |

In the first example, the windows at 0, 5 and 6 are `"enlist"`, `"tsilen"` and `"silent"`. Windows may overlap, as in the third example.

## Constraints

- `1 ≤ pattern.count ≤ 100,000` and `1 ≤ text.count ≤ 100,000`
- Both strings use only the lowercase letters `a` to `z`.
- `pattern` may be longer than `text`; then the answer is `[]`.

<Hints>
<Hint>
Every candidate window has the same length as `pattern`, so this is a fixed-size window. Two windows are anagrams exactly when their letter counts match.
</Hint>
<Hint>
Keep a 26-slot count array for the pattern and another for the current window. Sliding the window changes only two slots: one count goes up, one goes down.
</Hint>
<Hint>
Comparing all 26 slots each step is fine. For an O(1) check, keep `matches`: how many of the 26 slots agree. Before changing a slot, subtract 1 if it agreed; after, add 1 if it agrees now. The window is an anagram when `matches == 26`.
</Hint>
</Hints>

## Solutions

<Approach title="Sort every window" time="O(n · m log m)" space="O(m)">

Sort the pattern once, then sort each window and compare. With a 50,000-letter pattern and 50,000 windows, that's far too slow.

```swift
public static func starts(of pattern: String, in text: String) -> [Int] {
    let p = Array(pattern).sorted()
    let t = Array(text)
    guard p.count <= t.count else { return [] }
    var result: [Int] = []
    for start in 0...(t.count - p.count) where t[start..<start + p.count].sorted() == p {
        result.append(start)
    }
    return result
}
```

</Approach>

<Approach title="Slide and compare counts" time="O(26 · n)" space="O(1)">

Keep both count arrays and compare them with `==` after each slide. Each comparison looks at 26 slots, a constant.

```swift
public static func starts(of pattern: String, in text: String) -> [Int] {
    let p = Array(pattern.utf8)
    let t = Array(text.utf8)
    let m = p.count
    guard m <= t.count else { return [] }
    let a = UInt8(ascii: "a")
    var need = [Int](repeating: 0, count: 26)
    var have = [Int](repeating: 0, count: 26)
    for byte in p { need[Int(byte - a)] += 1 }
    var result: [Int] = []
    for right in 0..<t.count {
        have[Int(t[right] - a)] += 1
        if right >= m { have[Int(t[right - m] - a)] -= 1 }
        if right >= m - 1 && have == need { result.append(right - m + 1) }
    }
    return result
}
```

</Approach>

<Approach title="Slide with a matches counter" time="O(n + m)" space="O(1)">

`matches` counts the slots where the window and the pattern agree. A slide changes two slots, and a small helper updates `matches` around each change.

```swift
public enum AnagramWindows {
    public static func starts(of pattern: String, in text: String) -> [Int] {
        let p = Array(pattern.utf8)
        let t = Array(text.utf8)
        let m = p.count
        guard m > 0, m <= t.count else { return [] }
        let a = UInt8(ascii: "a")
        var need = [Int](repeating: 0, count: 26)
        var have = [Int](repeating: 0, count: 26)
        for byte in p { need[Int(byte - a)] += 1 }
        var matches = 0
        for slot in 0..<26 where need[slot] == 0 { matches += 1 }

        func change(_ slot: Int, by delta: Int) {
            if have[slot] == need[slot] { matches -= 1 }
            have[slot] += delta
            if have[slot] == need[slot] { matches += 1 }
        }

        var result: [Int] = []
        for right in 0..<t.count {
            change(Int(t[right] - a), by: 1)
            if right >= m { change(Int(t[right - m] - a), by: -1) }
            if right >= m - 1 && matches == 26 { result.append(right - m + 1) }
        }
        return result
    }
}
```

At the start, the window is empty, so every letter the pattern doesn't use already agrees (both counts are 0). That's why `matches` starts at the number of zero slots in `need`, not at 0.

</Approach>
