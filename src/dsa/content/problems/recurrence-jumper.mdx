A sequence starts with k given terms a(0), …, a(k − 1), and every later term is a fixed combination of the k before it:

a(i) = c₁ × a(i − 1) + c₂ × a(i − 2) + … + c_k × a(i − k)

Return a(n) modulo 1,000,000,007, as a number from 0 to 1,000,000,006. n can be as large as 10¹⁸.

`RecurrenceJumper.term(_ n: Int, coefficients: [Int], initial: [Int]) -> Int`

`coefficients` is [c₁, …, c_k] and `initial` is [a(0), …, a(k − 1)]. Both can contain negative numbers.

## Examples

| `n` | `coefficients` | `initial` | Output | Why |
| --- | --- | --- | --- | --- |
| `10` | `[1, 1]` | `[0, 1]` | `55` | the Fibonacci numbers |
| `6` | `[1, 1, 1]` | `[0, 1, 1]` | `13` | tribonacci: 0, 1, 1, 2, 4, 7, 13 |
| `2` | `[5, 7]` | `[3, 4]` | `41` | 5 × 4 + 7 × 3 |
| `0` | `[5, 7]` | `[3, 4]` | `3` | a given term |
| `7` | `[1]` | `[-4]` | `1000000003` | every term is −4, which is 1,000,000,003 modulo the prime |
| `1_000_000_000_000_000_000` | `[1, 1]` | `[0, 1]` | `209783453` | |

## Constraints

- `0 ≤ n ≤ 10¹⁸`
- `1 ≤ k ≤ 10`, and `coefficients.count == initial.count == k`
- Every coefficient and initial term is between −10⁹ and 10⁹.
- The tests compare with stepping the recurrence term by term for n up to 1,500, and with a different fast method for n up to 10¹⁸.

<Hints>
<Hint>
Keep the last k terms as a state vector, newest first: [a(i), a(i − 1), …, a(i − k + 1)]. One step of the recurrence turns it into [a(i + 1), a(i), …, a(i − k + 2)]. Every entry of the new state is a fixed combination of the old ones, so a step is a k × k matrix.
</Hint>
<Hint>
That's the companion matrix: its first row is the coefficients, and each row below has a single 1 just left of the diagonal. Start from [a(k − 1), …, a(0)]. After n − k + 1 steps, the first entry is a(n). If n is less than k, return the given term directly.
</Hint>
<Hint>
Raise the matrix to the power n − k + 1 with fast exponentiation, starting from the identity. Reduce every input into 0 to p − 1 first, so negatives work, and reduce after every single product inside the matrix multiplication: ten products near 10¹⁸ added together overflow `Int`.
</Hint>
</Hints>

## Solutions

<Approach title="Step term by term" time="O(n · k)" space="O(k)">

Keep the last k terms and compute the next one from them, n − k + 1 times. It's the right reference for small n, and the tests use it, but 10¹⁸ steps never finish.

</Approach>

<Approach title="Companion matrix power" time="O(k³ log n)" space="O(k²)">

Build the companion matrix, raise it to the power n − k + 1, and combine its first row with the starting terms.

```swift
public enum RecurrenceJumper {
    private static let mod = 1_000_000_007

    public static func term(_ n: Int, coefficients: [Int], initial: [Int]) -> Int {
        let k = coefficients.count
        let start = initial.map { reduce($0) }
        if n < k { return start[n] }
        var step = Array(repeating: Array(repeating: 0, count: k), count: k)
        step[0] = coefficients.map { reduce($0) }
        for row in stride(from: 1, to: k, by: 1) {
            step[row][row - 1] = 1                      // a(i − row) moves down to the next slot
        }
        let jump = power(step, n - k + 1)
        var answer = 0
        for j in 0..<k {                                // first row of the power times [a(k − 1), …, a(0)]
            answer = (answer + jump[0][j] * start[k - 1 - j]) % mod
        }
        return answer
    }

    private static func reduce(_ value: Int) -> Int {
        ((value % mod) + mod) % mod
    }

    private static func multiply(_ a: [[Int]], _ b: [[Int]]) -> [[Int]] {
        let size = a.count
        var c = Array(repeating: Array(repeating: 0, count: size), count: size)
        for i in 0..<size {
            for t in 0..<size where a[i][t] != 0 {
                for j in 0..<size {
                    c[i][j] = (c[i][j] + a[i][t] * b[t][j]) % mod
                }
            }
        }
        return c
    }

    private static func power(_ base: [[Int]], _ exponent: Int) -> [[Int]] {
        let size = base.count
        var result = (0..<size).map { i in (0..<size).map { j in i == j ? 1 : 0 } }
        var square = base
        var e = exponent
        while e > 0 {
            if e & 1 == 1 { result = multiply(result, square) }
            e >>= 1
            if e > 0 { square = multiply(square, square) }
        }
        return result
    }
}
```

The `if e > 0` before squaring skips one unneeded matrix product at the end, a small saving that matters more for a 10 × 10 matrix than for a number.

</Approach>
