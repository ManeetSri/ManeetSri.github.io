A text editor keeps a line as an array of characters. Reverse the order of the words in that array **in place**: afterwards it must hold the same words in reverse order, separated by single spaces, with no spaces at either end. Each word keeps its own spelling.

`WordBufferReversal.reverseWords(_ chars: inout [Character])`

The point is the O(1) extra space: no second array, no `split`, no new `String`. Shortening the array at the end with `removeLast(_:)` is fine, since that keeps the same storage.

## Examples

| `chars` before, as text | `chars` after, as text |
| --- | --- |
| `"the sky is blue"` | `"blue is sky the"` |
| `"  fast   and  safe "` | `"safe and fast"` |
| `"a b"` | `"b a"` |
| `"Swift"` | `"Swift"` |
| `"   "` | `""` |
| `""` | `""` |

## Constraints

- `0 ≤ chars.count ≤ 100,000`
- Only the space character `" "` separates words. Words can hold any other characters, including punctuation.
- O(n) time and O(1) extra space.

<Hint>
Reverse the whole array first. The words come out in the right order, but each one is spelled backwards. What second pass fixes the spelling?
</Hint>
<Hint>
Write one helper that reverses `chars` between two indexes with `swapAt`. Then walk the array: each time you reach a space, or the end, the word since the last space runs from `start` to the index before. Reverse it and set `start` past the space.
</Hint>
<Hint>
Messy spacing needs one more pass before the reversals: squeeze the array with read/write pointers so there's exactly one space between words and none at the ends. Write a space before every word except the first, copy the word, then trim with `removeLast(chars.count - write)`.
</Hint>
</Hints>

## Solutions

<Approach title="Split, reverse, join" time="O(n)" space="O(n)">

This is what you'd write in app code, and it's a handy check for the in-place version. `split` drops the empty pieces that extra spaces would make, but it builds a new array of words and a new string, so it isn't in place.

```swift
public static func reverseWords(_ chars: inout [Character]) {
    let words = String(chars).split(separator: " ")
    chars = Array(words.reversed().joined(separator: " "))
}
```

</Approach>

<Approach title="Squeeze, reverse everything, reverse each word" time="O(n)" space="O(1)">

Reading never falls behind writing during the squeeze: a separator is only written after `read` has skipped at least one space, so nothing unread is overwritten. Then the two rounds of reversal swap each character at most twice.

```swift
public enum WordBufferReversal {
    public static func reverseWords(_ chars: inout [Character]) {
        // 1. Squeeze: one space between words, none at the ends
        var write = 0
        var read = 0
        while read < chars.count {
            if chars[read] == " " {
                read += 1
                continue
            }
            if write > 0 {
                chars[write] = " "
                write += 1
            }
            while read < chars.count && chars[read] != " " {
                chars[write] = chars[read]
                write += 1
                read += 1
            }
        }
        chars.removeLast(chars.count - write)

        // 2. Reverse everything, then 3. reverse each word back
        reverse(&chars, from: 0, to: chars.count - 1)
        var start = 0
        for index in 0...chars.count where index == chars.count || chars[index] == " " {
            reverse(&chars, from: start, to: index - 1)
            start = index + 1
        }
    }

    private static func reverse(_ chars: inout [Character], from start: Int, to end: Int) {
        var left = start
        var right = end
        while left < right {
            chars.swapAt(left, right)
            left += 1
            right -= 1
        }
    }
}
```

`index == chars.count ||` comes first, so `chars[index]` is never read past the end. For an empty array, `reverse(from: 0, to: -1)` does nothing, because `left < right` is false straight away.

</Approach>
