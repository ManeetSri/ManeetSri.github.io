Split a string of lowercase letters into as many consecutive zones as possible, so that every letter appears in only one zone. Return the lengths of the zones, from left to right.

`LetterZoneSplit.zoneLengths(_ text: String) -> [Int]`

## Examples

| `text` | Output | Zones |
| --- | --- | --- |
| `"abacbdedfghgih"` | `[5, 3, 1, 5]` | `abacb`, `ded`, `f`, `ghgih` |
| `"abcabc"` | `[6]` | the whole string |
| `"xyz"` | `[1, 1, 1]` | every letter on its own |
| `"abccbaddeffe"` | `[6, 2, 4]` | `abccba`, `dd`, `effe` |
| `"a"` | `[1]` | |

## Constraints

- `1 ≤ text.count ≤ 100,000`
- `text` contains only the letters `a` to `z`.
- The tests compare your answer with trying every possible set of cuts on short strings.

<Hints>
<Hint>
The zone that contains a letter's first occurrence must also contain its last occurrence. So where does each letter appear for the last time?
</Hint>
<Hint>
Walk the string. The current zone can't end before the last occurrence of any letter in it so far. When can you be sure it may end here?
</Hint>
<Hint>
Record each letter's last index first. Then walk the string, setting `end = max(end, last[letter])`. When `i == end`, close the zone: its length is `i - start + 1`, and the next zone starts at `i + 1`.
</Hint>
</Hints>

## Solutions

<Approach title="Try every set of cuts" time="O(2ⁿ · n)" space="O(n)">

Each of the n − 1 gaps between letters is cut or not. Build the zones for every choice, keep those where no letter shows up in two zones, and return the split with the most zones. Exponential, so only for short strings.

```swift
public static func zoneLengths(_ text: String) -> [Int] {
    let letters = Array(text)
    let n = letters.count
    var best: [Int] = []
    for mask in 0..<(1 << max(n - 1, 0)) {
        var zones: [[Character]] = [[]]
        for i in 0..<n {
            zones[zones.count - 1].append(letters[i])
            if i < n - 1 && mask & (1 << i) != 0 { zones.append([]) }
        }
        var seen = Set<Character>()
        var valid = true
        for zone in zones {
            let zoneLetters = Set(zone)
            if !seen.isDisjoint(with: zoneLetters) { valid = false }
            seen.formUnion(zoneLetters)
        }
        if valid && zones.count > best.count {
            best = zones.map(\.count)
        }
    }
    return best
}
```

<Approach title="Last occurrences" time="O(n)" space="O(1)">

Whether a cut after index i is allowed doesn't depend on any other cut: it's allowed exactly when every letter up to i has its last occurrence at or before i. The greedy cuts at exactly those places. When `i == end`, every letter in the zone has finished. And if a cut after i is allowed, `end` can't be past i, while it's always at least i, so the greedy cuts there. Making every allowed cut gives the most zones. Working with the string's UTF-8 bytes keeps it fast; the 26 counters are O(1) memory.

```swift
public enum LetterZoneSplit {
    public static func zoneLengths(_ text: String) -> [Int] {
        let letters = Array(text.utf8).map { Int($0) - 97 }      // a...z as 0...25
        var last = Array(repeating: -1, count: 26)
        for (i, letter) in letters.enumerated() {
            last[letter] = i
        }
        var lengths: [Int] = []
        var start = 0
        var end = 0
        for (i, letter) in letters.enumerated() {
            end = max(end, last[letter])
            if i == end {
                lengths.append(i - start + 1)
                start = i + 1
            }
        }
        return lengths
    }
}
```

</Approach>
