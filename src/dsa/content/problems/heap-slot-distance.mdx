A binary heap stores a complete tree in an array, with the children of index `i` at `2i + 1` and `2i + 2`. Given two array positions, return how many **edges** separate them in that tree: the number of steps on the path from one to the other, going up to their lowest common ancestor and back down.

`HeapSlotDistance.steps(from first: Int, to second: Int) -> Int`

You don't need the heap itself, only the index maths, so the positions can be enormous. Aim for O(log n) time and O(1) space.

## Examples

| `first` | `second` | Output | Why |
| --- | --- | --- | --- |
| `3` | `4` | `2` | siblings: both children of 1 |
| `0` | `6` | `2` | 6's parent is 2, whose parent is the root |
| `7` | `2` | `4` | 7 → 3 → 1 → 0 → 2 |
| `5` | `5` | `0` | the same slot |
| `1` | `10` | `2` | 10's parent is 4, and 4's parent is 1 |
| `1_000_000_000_000_000_000` | `0` | `59` | the depth of slot 10¹⁸ |

## Constraints

- `0 ≤ first, second ≤ 1,000,000,000,000,000,000` (10¹⁸)
- The parent of `i > 0` is `(i - 1) / 2`.

<Hints>
<Hint>
Walk both positions up towards the root until they meet, counting the steps. The meeting point is their lowest common ancestor. The question is which one to move at each step.
</Hint>
<Hint>
In a complete tree stored level by level, a larger index is never on a shallower level than a smaller one. So while the two positions differ, move the **larger** one to its parent. If they're on the same level, that's fine: both will have to move up anyway.
</Hint>
<Hint>
Each step at least halves the larger index, so there are at most about 2 log₂ n steps. With positions up to 10¹⁸, that's about 120 loop iterations at most.
</Hint>
</Hints>

## Solutions

<Approach title="Depths first, then climb together" time="O(log n)" space="O(1)">

Work out each position's depth by counting steps to the root. Lift the deeper one until they're level, then lift both together until they meet. The answer is the total number of steps taken.

```swift
public static func steps(from first: Int, to second: Int) -> Int {
    func depth(_ index: Int) -> Int {
        var index = index
        var levels = 0
        while index > 0 { index = (index - 1) / 2; levels += 1 }
        return levels
    }
    var (a, b) = (first, second)
    var (depthA, depthB) = (depth(a), depth(b))
    var steps = 0
    while depthA > depthB { a = (a - 1) / 2; depthA -= 1; steps += 1 }
    while depthB > depthA { b = (b - 1) / 2; depthB -= 1; steps += 1 }
    while a != b {
        a = (a - 1) / 2
        b = (b - 1) / 2
        steps += 2
    }
    return steps
}
```

</Approach>

<Approach title="Always lift the larger index" time="O(log n)" space="O(1)">

The larger index is at least as deep, so moving it up never overshoots the common ancestor. No depths are needed.

```swift
public enum HeapSlotDistance {
    public static func steps(from first: Int, to second: Int) -> Int {
        var a = first
        var b = second
        var steps = 0
        while a != b {
            if a > b {
                a = (a - 1) / 2                      // the larger index is never shallower
            } else {
                b = (b - 1) / 2
            }
            steps += 1
        }
        return steps
    }
}
```

The loop stops at the root at the latest, where both positions become 0, so the `(0 - 1) / 2` trap from the lesson never comes up: a position is only lifted while it's bigger than the other, so it's never 0.

</Approach>
