Find the smallest and the largest number in an array, both in a **single pass**, and return them together as a named tuple. If the array is empty, there's no answer, so return `nil`.

`MinAndMaxTogether.minAndMax(of numbers: [Int]) -> (min: Int, max: Int)?`

Don't use the built-in `min()` or `max()`: use one loop that tracks both.

## Examples

| Input | Output |
| --- | --- |
| `[3, 9, 4]` | `(min: 3, max: 9)` |
| `[-5, -2, -8]` | `(min: -8, max: -2)` |
| `[7]` | `(min: 7, max: 7)` |
| `[]` | `nil` |

## Constraints

- `0 ≤ numbers.count ≤ 100,000`
- `-10⁹ ≤ numbers[i] ≤ 10⁹`

<Hints>
<Hint>
Keep two variables, the smallest so far and the largest so far, and update both as you walk through the array once.
</Hint>
<Hint>
Don't start them at `0`: think about `[-5, -2, -8]` or `[3, 9, 4]`. The first element is a safe starting value for both.
</Hint>
<Hint>
`guard let first = numbers.first else { return nil }` handles the empty array and gives you that starting value. Return the answer as `(min: smallest, max: largest)`.
</Hint>
</Hints>

## Solutions

<Approach title="Two separate passes" time="O(n)" space="O(1)">

Find the smallest in one loop and the largest in another. It's correct, and still O(n), but it reads the whole array twice. The single-pass version below does the same job with one loop.

```swift
public static func minAndMax(of numbers: [Int]) -> (min: Int, max: Int)? {
    guard let first = numbers.first else { return nil }
    var smallest = first
    for number in numbers where number < smallest {
        smallest = number
    }
    var largest = first
    for number in numbers where number > largest {
        largest = number
    }
    return (min: smallest, max: largest)
}
```

</Approach>

<Approach title="One pass, tracking both" time="O(n)" space="O(1)">

Start both trackers at the first element, then look at each remaining number once. A number can't be both a new smallest and a new largest, so `else if` saves a comparison whenever the first test succeeds.

```swift
public enum MinAndMaxTogether {
    public static func minAndMax(of numbers: [Int]) -> (min: Int, max: Int)? {
        guard let first = numbers.first else { return nil }
        var smallest = first
        var largest = first
        for number in numbers.dropFirst() {
            if number < smallest {
                smallest = number
            } else if number > largest {
                largest = number
            }
        }
        return (min: smallest, max: largest)
    }
}
```

The caller reads the answer by name, `result.min` and `result.max`, after unwrapping it with `if let` or `guard let`.

</Approach>
