Build the text storage for a code editor: insert and delete anywhere, read any character or slice, and undo. Edits in the middle of a long document must stay fast, and undo must be instant.

`RopeTextBuffer.Buffer`, a struct with `init(_:)`, `count`, `text`, `character(at:)`, `slice(from:count:)`, `insert(_:at:)`, `delete(from:count:)` and `undo()`

- Positions count `Character`s, starting at 0. `init(_ text: String = "")` starts the buffer with that text.
- `insert(_ text:at:)` inserts so that the new text starts at the given position, which is in `0...count`.
- `delete(from:count:)` deletes that many characters starting at `from`. The range lies within the text.
- `character(at:)` returns one character (the position is in `0..<count`), and `slice(from:count:)` returns that many characters as a `String`. `text` returns everything.
- **Undo.** Every call to `insert` or `delete` is one edit, even if it changes nothing. `undo()` restores the text as it was before the most recent edit that hasn't been undone, and returns `true`; with nothing to undo, it returns `false` and changes nothing.
- **Value semantics.** `Buffer` is a struct: after `var copy = buffer`, editing or undoing either one doesn't affect the other.

## Examples

| Code | `text` afterwards | Result |
| --- | --- | --- |
| `var b = Buffer("Hello, world!")` | `Hello, world!` | |
| `b.character(at: 7)` | | `"w"` |
| `b.insert("brave new ", at: 7)` | `Hello, brave new world!` | |
| `b.delete(from: 5, count: 1)` | `Hello brave new world!` | |
| `b.slice(from: 6, count: 5)` | | `"brave"` |
| `b.undo()` | `Hello, brave new world!` | `true` |
| `b.undo()` | `Hello, world!` | `true` |
| `b.undo()` | `Hello, world!` | `false` |

## Constraints

- Documents of up to a few hundred thousand characters, and up to 100,000 edits.
- The tests start from a 50,000-character document, make 10,000 edits at random places, check characters along the way, and then undo every edit. Copying the whole text for each edit, to undo it later, would copy 500 million characters.
- The tests use ASCII letters, spaces and some emoji and accented letters, but never a combining mark on its own, so Swift never merges two of your characters into one.

<Hints>
<Hint>
A rope stores text as a balanced tree, with each node knowing the size of its subtree. To find position i, compare i with the size of the left subtree: go left, stop here, or go right with i reduced. Insert and delete become "split at a position" and "join two pieces", which only walk one path each.
</Hint>
<Hint>
A treap of characters, one per node, ordered by position rather than by key (an implicit treap), is the shortest balanced rope to write: split(t, k) returns (the first k characters, the rest), and merge(a, b) joins them, choosing the root by random priority. Insert is split, merge, merge; delete is split, split, merge.
</Hint>
<Hint>
Make the nodes immutable: every property `let`, and split and merge build new nodes along their path instead of changing old ones. Then every old root is still a complete, valid version of the text, so undo is a stack of earlier roots, and copies of the struct are independent for free. A random priority per new node, from a seeded generator stored in the buffer, keeps the treap balanced.
</Hint>
</Hints>

## Solutions

<Approach title="Array of characters with an undo log" time="O(n) per edit and per undo" space="O(n + total edit sizes)">

Store the text as `[Character]`, and record each edit's inverse: for an insert, its position and length; for a delete, its position and the deleted characters. Undo applies the inverse. It's a legitimate design and passes for moderate sizes, but every edit in the middle shifts everything after it, so edits cost O(n), and getting every inverse exactly right is fiddly.

</Approach>

<Approach title="Persistent implicit treap" time="O(log n) expected per edit and lookup; O(1) undo" space="O(n + edits · log n)">

Split and merge copy only the nodes on their path, so each edit creates O(log n) new nodes and shares everything else with the previous version. Undo restores the previous root.

```swift
public enum RopeTextBuffer {
    final class Node {
        let character: Character
        let priority: UInt64
        let left: Node?
        let right: Node?
        let size: Int

        init(_ character: Character, _ priority: UInt64, left: Node?, right: Node?) {
            self.character = character
            self.priority = priority
            self.left = left
            self.right = right
            size = 1 + (left?.size ?? 0) + (right?.size ?? 0)
        }

        /// A copy with new children: the only way a "change" happens.
        func with(left: Node?, right: Node?) -> Node {
            Node(character, priority, left: left, right: right)
        }
    }

    public struct Buffer {
        private var root: Node?
        private var history: [Node?] = []
        private var state: UInt64 = 0x0123_4567_89AB_CDEF

        public init(_ text: String = "") {
            root = makeTreap(Array(text))
        }

        public var count: Int { root?.size ?? 0 }

        public var text: String {
            var result = ""
            result.reserveCapacity(count)
            func visit(_ node: Node?) {
                guard let node else { return }
                visit(node.left)
                result.append(node.character)
                visit(node.right)
            }
            visit(root)
            return result
        }

        public func character(at index: Int) -> Character {
            precondition(index >= 0 && index < count, "Index \(index) is out of range")
            var node = root!
            var index = index
            while true {
                let leftSize = node.left?.size ?? 0
                if index < leftSize {
                    node = node.left!
                } else if index == leftSize {
                    return node.character
                } else {
                    index -= leftSize + 1
                    node = node.right!
                }
            }
        }

        public func slice(from start: Int, count length: Int) -> String {
            precondition(start >= 0 && length >= 0 && start + length <= count, "Range is out of bounds")
            var result = ""
            // Visit only subtrees that overlap start..<start + length; offset is the position of the
            // first character in `node`'s subtree.
            func visit(_ node: Node?, _ offset: Int) {
                guard let node, offset < start + length, offset + node.size > start else { return }
                let leftSize = node.left?.size ?? 0
                visit(node.left, offset)
                let position = offset + leftSize
                if position >= start && position < start + length {
                    result.append(node.character)
                }
                visit(node.right, position + 1)
            }
            visit(root, 0)
            return result
        }

        public mutating func insert(_ text: String, at index: Int) {
            precondition(index >= 0 && index <= count, "Index \(index) is out of range")
            history.append(root)
            let (before, after) = Self.split(root, index)
            root = Self.merge(Self.merge(before, makeTreap(Array(text))), after)
        }

        public mutating func delete(from start: Int, count length: Int) {
            precondition(start >= 0 && length >= 0 && start + length <= count, "Range is out of bounds")
            history.append(root)
            let (before, rest) = Self.split(root, start)
            let (_, after) = Self.split(rest, length)
            root = Self.merge(before, after)
        }

        @discardableResult
        public mutating func undo() -> Bool {
            guard let previous = history.popLast() else { return false }
            root = previous
            return true
        }

        private mutating func nextPriority() -> UInt64 {
            state &+= 0x9E37_79B9_7F4A_7C15
            var z = state
            z = (z ^ (z >> 30)) &* 0xBF58_476D_1CE4_E5B9
            z = (z ^ (z >> 27)) &* 0x94D0_49BB_1331_11EB
            return z ^ (z >> 31)
        }

        /// A treap of `characters` in O(n): the Cartesian tree of random priorities, built with a stack.
        private mutating func makeTreap(_ characters: [Character]) -> Node? {
            let n = characters.count
            guard n > 0 else { return nil }
            let priorities = (0..<n).map { _ in nextPriority() }
            var left = Array(repeating: -1, count: n)
            var right = Array(repeating: -1, count: n)
            var stack: [Int] = []
            for i in 0..<n {
                var last = -1
                while let top = stack.last, priorities[top] < priorities[i] {
                    last = stack.removeLast()
                }
                left[i] = last
                if let top = stack.last { right[top] = i }
                stack.append(i)
            }
            func make(_ i: Int) -> Node? {
                i < 0 ? nil : Node(characters[i], priorities[i], left: make(left[i]), right: make(right[i]))
            }
            return make(stack[0])
        }

        /// (the first k characters, the rest), copying only the nodes on one path.
        private static func split(_ node: Node?, _ k: Int) -> (Node?, Node?) {
            guard let node else { return (nil, nil) }
            let leftSize = node.left?.size ?? 0
            if k <= leftSize {
                let (a, b) = split(node.left, k)
                return (a, node.with(left: b, right: node.right))
            }
            let (a, b) = split(node.right, k - leftSize - 1)
            return (node.with(left: node.left, right: a), b)
        }

        /// The characters of `a` followed by those of `b`.
        private static func merge(_ a: Node?, _ b: Node?) -> Node? {
            guard let a else { return b }
            guard let b else { return a }
            if a.priority > b.priority {
                return a.with(left: a.left, right: merge(a.right, b))
            }
            return b.with(left: merge(a, b.left), right: b.right)
        }
    }
}
```

`makeTreap` builds the treap for new text in O(n) instead of merging one character at a time: it's the classic stack algorithm for a Cartesian tree. Each character keeps its priority for life, so the treap stays a valid treap through every split and merge.

</Approach>
