Build a grid of whole numbers stored in **one flat array**, row by row. Give it a two-number subscript, methods to read a whole row or column, and conformance to `Collection`, so that looping over it visits every cell in row order.

`GridSubscripts.Grid(rows:columns:repeating:)`, with `subscript(row: Int, column: Int) -> Int` (get and set), `row(_:) -> [Int]`, `column(_:) -> [Int]`, and the `Collection` requirements `startIndex`, `endIndex`, `index(after:)` and `subscript(position: Int) -> Int`

- `Grid(rows: 2, columns: 3, repeating: 0)` has 6 cells, all 0.
- `grid[1, 2]` reads or writes the cell in row 1, column 2. Rows and columns are numbered from 0.
- As a collection, the grid holds all of row 0, then all of row 1, and so on. Position `p` is the `p`th cell in that order.
- `rows` and `columns` are already declared. Add private storage and fill it in the initialiser.

## Examples

For a grid with 2 rows and 3 columns, filled so that the cells read 1 to 6 row by row:

```text
1 2 3
4 5 6
```

| Code | Result |
| --- | --- |
| `grid[1, 0]` | `4` |
| `grid.row(1)` | `[4, 5, 6]` |
| `grid.column(2)` | `[3, 6]` |
| `Array(grid)` | `[1, 2, 3, 4, 5, 6]` |
| `grid[4]` (the `Collection` subscript) | `5` |
| `grid.count`, `grid.max()` | `6`, `6` |

## Constraints

- `0 ≤ rows, columns ≤ 1,000`
- Subscripts, `row(_:)` and `column(_:)` are only called with valid positions.
- Both subscripts must be O(1). Copying a grid gives an independent grid.

<Hints>
<Hint>
Store `private var cells: [Int]` and create it with `Array(repeating: value, count: rows * columns)`.
</Hint>
<Hint>
Row `r`, column `c` lives at index `r * columns + c`. Use that in both the getter and the setter of the two-number subscript. The `Collection` subscript is then just `cells[position]`.
</Hint>
<Hint>
`startIndex` is `0` and `endIndex` is `cells.count`, one past the last cell. For `row(_:)`, slice the flat array from `index * columns` for `columns` cells; for `column(_:)`, map over `0..<rows`.
</Hint>
</Hints>

## Solutions

<Approach title="Row-major flat storage" time="O(1) per cell, O(columns) per row, O(rows) per column" space="O(rows × columns)">

All the cells live in one array, row after row, so a cell's position is a little arithmetic away. The `Collection` conformance simply exposes that array's indices, and everything else (`count`, `max()`, `contains`, `for-in`) comes free.

```swift
public enum GridSubscripts {
    public struct Grid: Collection {
        public let rows: Int
        public let columns: Int
        private var cells: [Int]

        public init(rows: Int, columns: Int, repeating value: Int) {
            self.rows = rows
            self.columns = columns
            cells = Array(repeating: value, count: rows * columns)
        }

        public subscript(row: Int, column: Int) -> Int {
            get { cells[row * columns + column] }
            set { cells[row * columns + column] = newValue }
        }

        public func row(_ index: Int) -> [Int] {
            let start = index * columns
            return Array(cells[start..<start + columns])
        }

        public func column(_ index: Int) -> [Int] {
            (0..<rows).map { self[$0, index] }
        }

        public var startIndex: Int { 0 }
        public var endIndex: Int { cells.count }

        public func index(after i: Int) -> Int {
            i + 1
        }

        public subscript(position: Int) -> Int {
            cells[position]
        }
    }
}
```

`row(_:)` wraps its slice in `Array(...)`: a slice keeps the original array's indices, as you saw in M07, so returning a fresh array avoids surprises. An array of arrays (`[[Int]]`) would also work, but a flat array keeps every cell in one block of memory and makes the `Collection` conformance trivial.

</Approach>
