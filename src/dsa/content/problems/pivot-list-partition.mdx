Rearrange a list around a `pivot`: every node whose value is less than `pivot` comes first, then every node whose value is `pivot` or more. Inside each group, keep the nodes in their original order. Rewire the existing nodes rather than creating new ones, and return the new head.

`PivotListPartition.partitioned(_ head: ListNode?, around pivot: Int) -> ListNode?`

## Examples

| List | `pivot` | Result |
| --- | --- | --- |
| `4 -> 1 -> 7 -> 3 -> 5 -> 2` | `4` | `1 -> 3 -> 2 -> 4 -> 7 -> 5` |
| `3 -> 1 -> 2` | `5` | `3 -> 1 -> 2` |
| `3 -> 1 -> 2` | `0` | `3 -> 1 -> 2` |
| `9 -> 2 -> 9 -> 2` | `9` | `2 -> 2 -> 9 -> 9` |
| empty (`nil`) | `1` | empty |

The pivot doesn't have to appear in the list, and a node equal to the pivot belongs to the second group, as the first example shows.

## Constraints

- 0 to 20,000 nodes. Values and `pivot` are any `Int`.
- O(n) time and O(1) extra space.

<Hints>
<Hint>
Split the list into two pieces as you walk it: one chain for the small values and one for the rest. Each chain needs a head and a tail to append to.
</Hint>
<Hint>
A dummy node at the start of each chain means appending never needs a special case for an empty chain: `smallTail.next = node; smallTail = node`.
</Hint>
<Hint>
When the walk ends, splice: the small chain's tail points at the first real node of the other chain. Then set the other chain's tail's `next` to `nil`. That last node may still point at a small node from the original order, which would make a cycle.
</Hint>
</Hints>

## Solutions

<Approach title="Copy the values, then write them back" time="O(n)" space="O(n)">

Collect the small values and the rest in two arrays, and write them back into the nodes in their new order. It produces the right sequence of values, but it rearranges the values rather than the nodes, and uses O(n) extra space, so it doesn't meet the rules.

```swift
public static func partitioned(_ head: ListNode?, around pivot: Int) -> ListNode? {
    let values = head?.values ?? []
    let ordered = values.filter { $0 < pivot } + values.filter { $0 >= pivot }
    var current = head
    for value in ordered {
        current!.value = value
        current = current!.next
    }
    return head
}
```

</Approach>

<Approach title="Two chains with dummy heads" time="O(n)" space="O(1)">

Unzip the list into two chains in one walk, then join them. Each node is appended to exactly one chain, in the order it was met, which keeps both groups stable.

```swift
import DSAKit

public enum PivotListPartition {
    public static func partitioned(_ head: ListNode?, around pivot: Int) -> ListNode? {
        let smallDummy = ListNode(0)
        let restDummy = ListNode(0)
        var smallTail = smallDummy
        var restTail = restDummy
        var current = head
        while let node = current {
            current = node.next
            if node.value < pivot {
                smallTail.next = node
                smallTail = node
            } else {
                restTail.next = node
                restTail = node
            }
        }
        restTail.next = nil                  // the last node may still point into the small chain
        smallTail.next = restDummy.next      // small chain, then the rest
        return smallDummy.next
    }
}
```

`current` moves on before the node is appended. Appending doesn't change `node.next` here, but saving it first is a good habit whenever you rewire as you walk.

</Approach>
