A chess club is splitting its members into two teams for a tournament, and wants no pair of rivals on the same team. There are `people` members, numbered from 0, and each pair `[a, b]` in `rivalries` means a and b must be on different teams.

Return an array `teams` where `teams[i]` is `0` or `1`, the team of member i, that keeps every pair of rivals apart, or `nil` if no split can. Any valid split is accepted. Members with no rivals can go on either team.

`RivalTeamSplit.teams(_ people: Int, rivalries: [[Int]]) -> [Int]?`

## Examples

| `people` | `rivalries` | Returns |
| --- | --- | --- |
| `4` | `[[0, 1], [1, 2], [2, 3], [3, 0]]` | `[0, 1, 0, 1]` or `[1, 0, 1, 0]` |
| `5` | `[[0, 1], [0, 2], [0, 3], [0, 4]]` | `[0, 1, 1, 1, 1]` or `[1, 0, 0, 0, 0]` |
| `3` | `[[0, 1], [1, 2], [2, 0]]` | `nil` |
| `6` | `[[0, 1], [1, 2], [3, 4], [4, 5], [5, 3]]` | `nil` |
| `3` | `[]` | any split, such as `[0, 0, 0]` |

In the third example, 0 and 1 must differ, and so must 1 and 2, which puts 0 and 2 together, but they're rivals too. In the fourth, members 0 to 2 can be split, but 3, 4 and 5 form the same impossible triangle.

## Constraints

- `1 ≤ people ≤ 100,000`, with up to 200,000 rivalries.
- A pair may appear more than once. A pair `[a, a]` means someone is their own rival, which no split can satisfy.
- The tests include loops of 100,000 and 99,999 rivals, and 50,000 separate pairs. Use BFS or an explicit stack.

<Hints>
<Hint>
Put member 0 on team 0. Each of their rivals must then be on team 1, each of **their** rivals on team 0, and so on. Spread the teams outwards with BFS, giving each newly reached member the opposite team to the one who reached them.
</Hint>
<Hint>
If a rival has already been placed on the **same** team as the current member, no split exists: you've found a loop of rivals with an odd number of people in it.
</Hint>
<Hint>
The club may fall into separate groups with no rivalries between them. Loop over every member, and start a new BFS from anyone who doesn't have a team yet.
</Hint>
</Hints>

## Solutions

<Approach title="Two-colouring with BFS" time="O(people + rivalries)" space="O(people + rivalries)">

`-1` means "no team yet", so the team array is also the visited mark. One head-index queue serves every group, because each BFS starts after the previous one has emptied it.

```swift
public enum RivalTeamSplit {
    public static func teams(_ people: Int, rivalries: [[Int]]) -> [Int]? {
        var rivals = Array(repeating: [Int](), count: people)
        for pair in rivalries {
            rivals[pair[0]].append(pair[1])
            rivals[pair[1]].append(pair[0])
        }

        var team = Array(repeating: -1, count: people)
        var queue: [Int] = []
        var head = 0
        for first in 0..<people where team[first] == -1 {
            team[first] = 0
            queue.append(first)
            while head < queue.count {
                let person = queue[head]
                head += 1
                for rival in rivals[person] {
                    if team[rival] == -1 {
                        team[rival] = 1 - team[person]
                        queue.append(rival)
                    } else if team[rival] == team[person] {
                        return nil                       // an odd cycle: two rivals on one team
                    }
                }
            }
        }
        return team
    }
}
```

A self-rivalry needs no special case: member a is already on a team when a appears in their own list, and that team is the same.

</Approach>

<Approach title="Union-find" time="O((people + rivalries) · α(people))" space="O(people)">

All of one member's rivals must end up on the same team as each other. Union them together, then check that no member is in the same set as any of their rivals. You'll build union-find in M45; it's handy when rivalries arrive one at a time.

</Approach>
