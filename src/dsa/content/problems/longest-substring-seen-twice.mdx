Return the length of the longest substring that occurs at least twice in `text`. The two occurrences may overlap. If no letter appears twice, return 0.

`SeenTwiceSubstring.longestLength(in text: String) -> Int`

## Examples

| `text` | Output |
| --- | --- |
| `"banana"` | `3`: `ana`, at 1 and 3 |
| `"mississippi"` | `4`: `issi`, at 1 and 4 |
| `"aaaa"` | `3`: `aaa`, at 0 and 1 |
| `"abcabcabc"` | `6`: `abcabc`, at 0 and 3 |
| `"abcd"` | `0` |
| `""` | `0` |

In `"banana"` and `"aaaa"`, the two occurrences overlap, and that's allowed.

## Constraints

- `text` holds 0 to 100,000 lowercase letters, a to z.
- The tests include 100,000 copies of one letter, where the answer is 99,999. Comparing every pair of starting positions, or checking every length one by one, is far too slow.

<Hints>
<Hint>
A substring occurs twice exactly when two different suffixes start with it. So the answer is the longest common prefix of any two suffixes.
</Hint>
<Hint>
Sort the suffixes. The pair of suffixes that share the longest start are always neighbours in sorted order. That's the suffix array, and the LCP array of neighbouring common prefixes; the answer is the largest LCP.
</Hint>
<Hint>
Another route: if some substring of length L repeats, so does one of length L − 1. Binary search on L, and test a length by hashing every window of that length into a set and looking for a repeat.
</Hint>
</Hints>

## Solutions

<Approach title="Every pair of starting positions" time="O(n³)" space="O(1)">

For every pair of positions, count how far they agree, and keep the best. Correct, and even O(n²) with care on random text, but on 100,000 copies of one letter every pair agrees for tens of thousands of letters.

</Approach>

<Approach title="Suffix array and Kasai's LCP" time="O(n log n)" space="O(n)">

Build the suffix array by prefix doubling with a counting sort each round, then the LCP array with Kasai's algorithm, and return its largest value.

```swift
public enum SeenTwiceSubstring {
    public static func longestLength(in text: String) -> Int {
        let s = Array(text.utf8)
        guard s.count > 1 else { return 0 }
        let sa = suffixArray(s)
        return lcpArray(s, sa).max() ?? 0
    }

    static func suffixArray(_ text: [UInt8]) -> [Int] {
        let n = text.count + 1                          // one extra position for the sentinel
        var rank = [Int](repeating: 0, count: n)        // the sentinel keeps rank 0, below every byte
        for i in text.indices { rank[i] = Int(text[i]) + 1 }
        var sa = [Int](repeating: 0, count: n)
        var count = [Int](repeating: 0, count: max(257, n))
        for i in 0..<n { count[rank[i]] += 1 }
        for c in 1..<count.count { count[c] += count[c - 1] }
        for i in stride(from: n - 1, through: 0, by: -1) {
            count[rank[i]] -= 1
            sa[count[rank[i]]] = i
        }
        var newRank = [Int](repeating: 0, count: n)
        var classes = 1
        for p in 1..<n {
            if rank[sa[p]] != rank[sa[p - 1]] { classes += 1 }
            newRank[sa[p]] = classes - 1
        }
        swap(&rank, &newRank)

        var shifted = [Int](repeating: 0, count: n)
        var k = 1
        while classes < n {
            // Sorted by the second half already: start each suffix k places earlier, wrapping round
            for p in 0..<n {
                let start = sa[p] - k
                shifted[p] = start < 0 ? start + n : start
            }
            // A stable counting sort by the first half's rank
            for c in 0..<classes { count[c] = 0 }
            for start in shifted { count[rank[start]] += 1 }
            for c in 1..<classes { count[c] += count[c - 1] }
            for start in shifted.reversed() {
                count[rank[start]] -= 1
                sa[count[rank[start]]] = start
            }
            // Equal (first half, second half) rank pairs share a new rank
            newRank[sa[0]] = 0
            classes = 1
            for p in 1..<n {
                let a = sa[p], b = sa[p - 1]
                let aSecond = a + k < n ? a + k : a + k - n
                let bSecond = b + k < n ? b + k : b + k - n
                if rank[a] != rank[b] || rank[aSecond] != rank[bSecond] { classes += 1 }
                newRank[a] = classes - 1
            }
            swap(&rank, &newRank)
            k *= 2
        }
        return Array(sa.dropFirst())                    // the sentinel's suffix sorts first
    }

    static func lcpArray(_ s: [UInt8], _ sa: [Int]) -> [Int] {
        let n = s.count
        var rank = [Int](repeating: 0, count: n)
        for (p, start) in sa.enumerated() { rank[start] = p }
        var lcp = [Int](repeating: 0, count: n)
        var h = 0
        for i in 0..<n {
            if rank[i] == 0 {
                h = 0
                continue
            }
            let j = sa[rank[i] - 1]
            while i + h < n && j + h < n && s[i + h] == s[j + h] { h += 1 }
            lcp[rank[i]] = h
            if h > 0 { h -= 1 }
        }
        return lcp
    }
}
```

The prefix-doubling version with a plain `sort` from [Suffix arrays and LCP](/dsa/learn/sa-suffix-array) is O(n log² n) and also passes; it's shorter, and a good first version.

</Approach>

<Approach title="Binary search on the length, with hashes" time="O(n log n)" space="O(n)">

"Some substring of length L repeats" is monotonic in L, so binary search for the largest L where it holds. To test L, put the hash of every window of length L in a `Set` and stop at the first hash seen before. With prefix hashes modulo 2⁶¹ − 1, each window's hash is O(1).

```swift
public enum SeenTwiceSubstring {
    public static func longestLength(in text: String) -> Int {
        let s = Array(text.utf8)
        let modulus: UInt64 = (1 << 61) - 1
        func mulMod(_ x: UInt64, _ y: UInt64) -> UInt64 {
            let (high, low) = x.multipliedFullWidth(by: y)
            let sum = ((high << 3) | (low >> 61)) + (low & modulus)
            return sum >= modulus ? sum - modulus : sum
        }
        let base = UInt64.random(in: 256..<modulus)
        var prefix = [UInt64](repeating: 0, count: s.count + 1)
        var power = [UInt64](repeating: 1, count: s.count + 1)
        for i in s.indices {
            prefix[i + 1] = (mulMod(prefix[i], base) + UInt64(s[i])) % modulus
            power[i + 1] = mulMod(power[i], base)
        }
        func repeats(_ length: Int) -> Bool {
            var seen = Set<UInt64>()
            for start in 0...(s.count - length) {
                let shifted = mulMod(prefix[start], power[length])
                let end = prefix[start + length]
                let hash = end >= shifted ? end - shifted : end + modulus - shifted
                if !seen.insert(hash).inserted { return true }
            }
            return false
        }
        var low = 0, high = max(s.count - 1, 0)
        while low < high {
            let mid = (low + high + 1) / 2
            if repeats(mid) { low = mid } else { high = mid - 1 }
        }
        return low
    }
}
```

Shorter than the suffix array, and just as fast in practice. Many hashes go into one set, so the birthday problem applies: with a 30-bit modulus you'd expect a few false repeats among 100,000 windows, but with 2⁶¹ − 1 the chance is around one in a billion.

</Approach>

<Approach title="Suffix automaton" time="O(n)" space="O(n)">

In a suffix automaton, a state's strings occur as many times as its endpos set has positions. Count endpos sizes by giving each non-clone state 1 and adding counts up the suffix-link tree, longest states first; the answer is the largest `len` among states with a count of at least 2. It's linear, but the clone bookkeeping makes it the longest to write of the three.

</Approach>
