Return whether `n` is a power of two: 1, 2, 4, 8, 16 and so on. The input can be any `Int` at all, including 0, negative numbers, `Int.min` and `Int.max`, and your function must never crash. Try to solve it without a loop.

`PowerOfTwoCheck.isPowerOfTwo(_ n: Int) -> Bool`

## Examples

| Input | Output |
| --- | --- |
| `1` | `true` |
| `64` | `true` |
| `96` | `false` |
| `0` | `false` |
| `-8` | `false` |

1 is 2⁰, so it counts. No negative number is a power of two.

## Constraints

- `Int.min ≤ n ≤ Int.max`

<Hints>
<Hint>
Write the first few powers of two in binary. What do they all have in common?
</Hint>
<Hint>
`n & (n - 1)` is `n` with its lowest set bit cleared. What does that leave when `n` has only one set bit?
</Hint>
<Hint>
Test `n > 0` first and join the tests with `&&`. Besides ruling out 0 and negatives, that stops `n - 1` from ever being worked out for `Int.min`, where it would overflow.
</Hint>
</Hints>

## Solutions

<Approach title="Keep halving" time="O(log n)" space="O(1)">

A power of two can be halved exactly until it reaches 1. Any odd factor shows up as a remainder along the way.

```swift
public static func isPowerOfTwo(_ n: Int) -> Bool {
    guard n > 0 else { return false }
    var value = n
    while value % 2 == 0 {
        value /= 2
    }
    return value == 1
}
```

It runs at most 63 times, so it's fast, but the bit test does the same in one step.

</Approach>

<Approach title="One bit set" time="O(1)" space="O(1)">

A power of two has exactly one set bit, so clearing its lowest set bit leaves 0. The `n > 0` check rules out 0, which would otherwise pass, and every negative number. Because `&&` stops at the first `false`, `n - 1` is never computed for `Int.min`.

```swift
public enum PowerOfTwoCheck {
    public static func isPowerOfTwo(_ n: Int) -> Bool {
        n > 0 && n & (n - 1) == 0
    }
}
```

`n > 0 && n.nonzeroBitCount == 1` is an equally good answer, and arguably clearer. Without the `n > 0`, it would wrongly accept `Int.min`, whose only set bit is the sign bit.

</Approach>
