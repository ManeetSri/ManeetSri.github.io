Return an array whose entry `i` is the number of 1 bits in `i`, for every `i` from 0 to `n`. Work the counts out yourself, without `nonzeroBitCount`.

`BitTallies.tallies(upTo n: Int) -> [Int]`

## Examples

| Input | Output |
| --- | --- |
| `0` | `[0]` |
| `5` | `[0, 1, 1, 2, 1, 2]` |
| `8` | `[0, 1, 1, 2, 1, 2, 2, 3, 1]` |

For `5`: 0 is `0`, 1 is `1`, 2 is `10`, 3 is `11`, 4 is `100` and 5 is `101`, which have 0, 1, 1, 2, 1 and 2 set bits.

## Constraints

- `0 ≤ n ≤ 100,000`
- Aim for O(n) time once you have a working version.

<Hints>
<Hint>
Kernighan's loop, `while x != 0 { x &= x - 1; count += 1 }`, counts the bits of one number. Running it for every `i` works, and no number up to 100,000 has more than 17 bits set.
</Hint>
<Hint>
To go faster, reuse answers you've already worked out. `i >> 1` is `i` without its lowest bit, and it's smaller than `i`, so its count is already in your array. What do you need to add back?
</Hint>
<Hint>
`counts[i] = counts[i >> 1] + (i & 1)`. Or use Kernighan's idea: `i & (i - 1)` has exactly one fewer set bit than `i`, so `counts[i] = counts[i & (i - 1)] + 1`.
</Hint>
</Hints>

## Solutions

<Approach title="Kernighan's loop for every number" time="O(n log n)" space="O(1)">

Count each number separately. The inner loop runs once per set bit, and a number up to `n` has at most about log₂ n of them. The space is O(1) apart from the answer itself.

```swift
public static func tallies(upTo n: Int) -> [Int] {
    var counts: [Int] = []
    for i in 0...n {
        var x = i
        var count = 0
        while x != 0 {
            x &= x - 1
            count += 1
        }
        counts.append(count)
    }
    return counts
}
```

</Approach>

<Approach title="Reuse a smaller number's count" time="O(n)" space="O(1)">

Shifting `i` right by one drops its lowest bit and keeps all the others. So `i` has the same count as `i >> 1`, plus one if its lowest bit is set. Since `i >> 1` is smaller than `i`, its count is always ready when you need it.

```swift
public enum BitTallies {
    public static func tallies(upTo n: Int) -> [Int] {
        var counts = Array(repeating: 0, count: n + 1)
        for i in stride(from: 1, through: n, by: 1) {
            counts[i] = counts[i >> 1] + (i & 1)
        }
        return counts
    }
}
```

`stride(from: 1, through: n, by: 1)` is empty when `n` is 0, where `1...0` would crash. Each entry takes one step, so the whole table is O(n). Building each answer from smaller answers you've already stored is the heart of dynamic programming, which you'll study in Part VII.

</Approach>
