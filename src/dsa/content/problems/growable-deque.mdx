Build a double-ended queue that adds and removes at both ends, on a ring buffer that doubles its slots whenever it runs out of room.

`GrowableDeque.RingDeque<Element>`, with `init()`, `append(_:)`, `prepend(_:)`, `popFirst() -> Element?`, `popLast() -> Element?`, `first: Element?`, `last: Element?`, `count: Int`, `isEmpty: Bool` and `subscript(position: Int) -> Element?`

`append` adds at the back and `prepend` at the front. The pops remove and return an end element, or `nil` if the deque is empty. The subscript returns the element at a position counted from 0 at the front, or `nil` if the position is outside `0..<count`. Adding must be O(1) amortised, and everything else O(1).

## Examples

| Code | Result |
| --- | --- |
| append `"b"`, prepend `"a"`, append `"c"`, then `first`, `last` and `count` | `"a"`, `"c"` and `3` |
| prepend 1, 2, 3, then `popFirst()` and `popLast()` | `3` and `1` |
| append 10, 20, then `deque[0]`, `deque[1]` and `deque[2]` | `10`, `20` and `nil` |
| `RingDeque<Int>().popLast()` | `nil` |
| append 0 to 999, then `deque[500]` and `count` | `500` and `1000` |

## Constraints

- Up to 200,000 operations in any mix, at either end.
- Copying a deque gives an independent deque, as with any struct.
- Don't use `insert(_:at: 0)` or `removeFirst()` on an array: both are O(n).

<Hints>
<Hint>
Use the ring buffer pieces: `private var slots: [Element?]`, `head` (the slot of the front element) and `count`. The element at position i lives in slot `(head + i) % slots.count`. Appending writes the slot right after the back; prepending moves `head` one step back first.
</Hint>
<Hint>
Stepping back must wrap from slot 0 to the last slot, and Swift's `%` keeps the sign: `(0 - 1) % 8` is `-1`. Write `(head - 1 + slots.count) % slots.count`.
</Hint>
<Hint>
When `count == slots.count`, grow before computing any slot (a new deque has 0 slots, and `% 0` crashes). Make an array twice as big (at least a few slots), copy the elements across **in queue order** so the front lands in slot 0, and set `head` to 0. Inside the struct, write `Swift.max(…)` if you need the global `max`.
</Hint>
</Hints>

## Solutions

<Approach title="Arrays with insert and remove at the front" time="O(n) per front operation" space="O(n)">

An array can do everything a deque does: `insert(element, at: 0)` to prepend and `removeFirst()` to pop the front. It's a fine model to test against, which is exactly what the tests do. But every front operation shifts all the other elements, so a deque used mostly at the front costs O(n) per operation.

</Approach>

<Approach title="A growable ring buffer" time="O(1) amortised per operation" space="O(n)">

Both ends move round a ring of slots, so neither end ever shifts the other elements. When the ring is full, doubling it copies everything once, which, as with `Array.append`, averages out to O(1) per insertion.

```swift
public enum GrowableDeque {
    public struct RingDeque<Element> {
        private var slots: [Element?] = []
        private var head = 0
        public private(set) var count = 0

        public init() {}

        private func slot(_ offset: Int) -> Int {
            (head + offset) % slots.count
        }

        // Doubles the slots, copying the elements in order so the front lands in slot 0
        private mutating func grow() {
            var bigger = [Element?](repeating: nil, count: Swift.max(8, slots.count * 2))
            for offset in 0..<count {
                bigger[offset] = slots[slot(offset)]
            }
            slots = bigger
            head = 0
        }

        public mutating func append(_ element: Element) {
            if count == slots.count { grow() }
            slots[slot(count)] = element
            count += 1
        }

        public mutating func prepend(_ element: Element) {
            if count == slots.count { grow() }
            head = (head - 1 + slots.count) % slots.count
            slots[head] = element
            count += 1
        }

        public mutating func popFirst() -> Element? {
            guard count > 0 else { return nil }
            let element = slots[head]
            slots[head] = nil
            head = slot(1)
            count -= 1
            return element
        }

        public mutating func popLast() -> Element? {
            guard count > 0 else { return nil }
            let index = slot(count - 1)
            let element = slots[index]
            slots[index] = nil
            count -= 1
            return element
        }

        public var first: Element? {
            count > 0 ? slots[head] : nil
        }

        public var last: Element? {
            count > 0 ? slots[slot(count - 1)] : nil
        }

        public var isEmpty: Bool {
            count == 0
        }

        public subscript(position: Int) -> Element? {
            guard position >= 0 && position < count else { return nil }
            return slots[slot(position)]
        }
    }
}
```

Both pops set their slot back to `nil`, so removed elements are released straight away. DSAKit's `Deque` is the same design, with collection conformances added.

</Approach>
