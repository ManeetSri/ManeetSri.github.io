Settings files are often lines like `level = 3`. Write a parser that splits a line into a key and a value, and throws a descriptive error when the line is malformed. Then use it two ways: stopping at the first bad line, and skipping bad lines.

`ConfigLineParser.parse(_ line: String) throws -> Entry`, `ConfigLineParser.parseAll(_ lines: [String]) throws -> [Entry]` and `ConfigLineParser.validEntries(in lines: [String]) -> [Entry]`

**`parse`** splits the line at its **first** `=`. The key is the text before it and the value is the text after it, each with spaces removed from both ends. The value may be empty and may contain more `=` signs. Check for problems in this order, throwing the first one found:

1. No `=` anywhere: `ParseError.missingEquals`.
2. The key is empty (nothing but spaces before the `=`): `ParseError.emptyKey`.
3. The key contains a character that isn't an ASCII letter, an ASCII digit or `_`: `ParseError.invalidKeyCharacter(c)`, where `c` is the **first** such character.

**`parseAll`** parses every line in order and throws the first error any line causes. **`validEntries`** parses every line in order and leaves out the lines that cause errors.

## Examples

| Input | Result |
| --- | --- |
| `"name=Maneet"` | key `"name"`, value `"Maneet"` |
| `"  level = 3  "` | key `"level"`, value `"3"` |
| `"formula=a=b+c"` | key `"formula"`, value `"a=b+c"` |
| `"nickname="` | key `"nickname"`, value `""` |
| `"hello"` | throws `.missingEquals` |
| `"   = 5"` | throws `.emptyKey` |
| `"my key=1"` | throws `.invalidKeyCharacter(" ")` |
| `validEntries(in: ["a=1", "=2", "d = 4"])` | entries for `a` and `d` |

## Constraints

- Lines have at most 1,000 characters.
- Up to 1,000 lines.

<Hints>
<Hint>
`line.firstIndex(of: "=")` gives the position of the first `=`, or `nil` if there isn't one, which is exactly the first error. `line[..<index]` and `line[line.index(after: index)...]` are the parts before and after it.
</Hint>
<Hint>
To trim spaces from a `Substring`, remove characters while `first == " "`, then while `last == " "`. For the key check, a character is allowed if it's `"_"`, or if `isASCII` is true and it's a letter or a number. `key.first(where:)` finds the first one that isn't allowed.
</Hint>
<Hint>
`parseAll` is a loop that calls `try parse(line)` without catching: the first error leaves the function by itself. `validEntries` is one line with `compactMap` and `try?`.
</Hint>
</Hints>

## Solutions

<Approach title="Split at the first =, trim, validate in order" time="O(L)" space="O(L)">

Each line is scanned a constant number of times, so parsing takes time in proportion to its length, L. The two list functions show the two ways of handling errors from the lesson: `try` lets them propagate, and `try?` turns them into `nil`s for `compactMap` to drop.

```swift
public enum ConfigLineParser {
    // ParseError and Entry as in the starter code

    private static func trimmingSpaces(_ text: Substring) -> String {
        var result = text
        while result.first == " " { result.removeFirst() }
        while result.last == " " { result.removeLast() }
        return String(result)
    }

    private static func isAllowedInKey(_ character: Character) -> Bool {
        character == "_" || (character.isASCII && (character.isLetter || character.isNumber))
    }

    public static func parse(_ line: String) throws -> Entry {
        guard let equals = line.firstIndex(of: "=") else {
            throw ParseError.missingEquals
        }
        let key = trimmingSpaces(line[..<equals])
        let value = trimmingSpaces(line[line.index(after: equals)...])
        if key.isEmpty {
            throw ParseError.emptyKey
        }
        if let bad = key.first(where: { !isAllowedInKey($0) }) {
            throw ParseError.invalidKeyCharacter(bad)
        }
        return Entry(key: key, value: value)
    }

    public static func parseAll(_ lines: [String]) throws -> [Entry] {
        var entries: [Entry] = []
        for line in lines {
            entries.append(try parse(line))
        }
        return entries
    }

    public static func validEntries(in lines: [String]) -> [Entry] {
        lines.compactMap { try? parse($0) }
    }
}
```
