You're given a list of strings typed into a form. Some are whole numbers and some are junk. Add up the whole numbers and ignore everything else. If **none** of the strings is a whole number, return `nil`, so the caller can tell "no numbers at all" apart from "numbers that add up to 0".

`ValidNumberSum.sum(of texts: [String]) -> Int?`

A string counts as a whole number exactly when Swift's `Int(text)` accepts it.

## Examples

| Input | Output | Why |
| --- | --- | --- |
| `["4", "x", "10"]` | `14` | "x" is ignored |
| `["-5", "20", "oops"]` | `15` | negatives count |
| `["2.5", " 4", "1"]` | `1` | decimals and spaces aren't whole numbers |
| `["-5", "5"]` | `0` | real numbers that add up to 0 |
| `["a", ""]` | `nil` | no numbers at all |
| `[]` | `nil` | no numbers at all |

## Constraints

- `0 ≤ texts.count ≤ 10,000`
- Every valid number is between `-10⁹` and `10⁹`. Strings too big for an `Int` give nil from `Int(text)`, so they're ignored like any other junk.

<Hints>
<Hint>
`if let number = Int(text)` runs its block only for strings that really are whole numbers.
</Hint>
<Hint>
You need to remember whether you've seen *any* valid number. A `Bool` flag works, or keep the total itself as an `Int?` that starts as `nil`.
</Hint>
<Hint>
With an optional total, `total = (total ?? 0) + number` adds to it, treating "nothing yet" as 0. If no valid number ever arrives, it's still `nil` at the end.
</Hint>
</Hints>

## Solutions

<Approach title="A flag and a running total" time="O(n)" space="O(1)">

Keep an ordinary total, plus a `Bool` that records whether any valid number was seen. At the end, the flag decides between the total and `nil`.

```swift
public static func sum(of texts: [String]) -> Int? {
    var total = 0
    var foundAny = false
    for text in texts {
        if let number = Int(text) {
            total += number
            foundAny = true
        }
    }
    return foundAny ? total : nil
}
```

</Approach>

<Approach title="An optional running total" time="O(n)" space="O(1)">

The total can carry the "seen anything?" information itself. It starts as `nil`, and the first valid number turns it into a real value.

```swift
public enum ValidNumberSum {
    public static func sum(of texts: [String]) -> Int? {
        var total: Int? = nil
        for text in texts {
            if let number = Int(text) {
                total = (total ?? 0) + number
            }
        }
        return total
    }
}
```

The parentheses around `total ?? 0` matter: without them, `??` would bind more loosely than `+`, and `total ?? 0 + number` would mean `total ?? (0 + number)`. The type now says exactly what the function means: an `Int?` is either a sum or nothing.

</Approach>
