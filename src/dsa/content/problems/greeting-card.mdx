Write a short greeting card as a single string with three lines: who it's to, the message in double quotes, and who it's from.

`GreetingCard.card(to recipient: String, from sender: String, message: String) -> String`

For example, `card(to: "Ada", from: "Maneet", message: "Happy birthday!")` returns a string that prints as:

```text
To: Ada
"Happy birthday!"
From: Maneet
```

Inside the function, `recipient`, `sender` and `message` hold the values. The lines are separated by a newline, and there's **no** newline after the last line.

## Examples

| Call | Returns (as written in Swift) |
| --- | --- |
| `card(to: "Ada", from: "Maneet", message: "Happy birthday!")` | `"To: Ada\n\"Happy birthday!\"\nFrom: Maneet"` |
| `card(to: "Grace Hopper", from: "The Team", message: "Thanks!")` | `"To: Grace Hopper\n\"Thanks!\"\nFrom: The Team"` |
| `card(to: "Ada", from: "Maneet", message: "")` | `"To: Ada\n\"\"\nFrom: Maneet"` |

## Constraints

- Each part has at most 100 characters and contains no newlines.
- An empty message still appears as a pair of quotes, `""`.

<Hints>
<Hint>
Two escape sequences do all the work: `\n` starts a new line and `\"` puts a double quote inside a string.
</Hint>
<Hint>
The middle line is a quote, then the message, then another quote: `\"\(message)\"`.
</Hint>
<Hint>
A multi-line string, between `"""` lines, avoids escapes altogether. Quotes need no backslash inside it, and it doesn't add a newline after the last line of text.
</Hint>
</Hints>

## Solutions

<Approach title="Escape sequences" time="O(n)" space="O(n)">

One ordinary string, with `\n` between the lines and `\"` around the message.

```swift
public enum GreetingCard {
    public static func card(to recipient: String, from sender: String, message: String) -> String {
        return "To: \(recipient)\n\"\(message)\"\nFrom: \(sender)"
    }
}
```

It works, but it's hard to read: the quotes and backslashes blur together.

</Approach>

<Approach title="A multi-line string" time="O(n)" space="O(n)">

A multi-line string looks just like the card it produces. Quotes don't need escaping inside `"""`, and interpolation still works. The closing `"""` sets the indentation, so the eight spaces in front of each line are removed.

```swift
public enum GreetingCard {
    public static func card(to recipient: String, from sender: String, message: String) -> String {
        return """
        To: \(recipient)
        "\(message)"
        From: \(sender)
        """
    }
}
```

The newline just before the closing `"""` isn't part of the string, which is exactly why there's no newline at the end. Both versions copy each character once: O(n) time and space for a card of *n* characters.

</Approach>
