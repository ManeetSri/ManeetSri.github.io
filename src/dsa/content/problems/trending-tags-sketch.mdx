A social app wants to spot trending hashtags in a stream far too large to count exactly. Build a count-min sketch with fixed row hashes, and use it to report each tag the moment its estimated count reaches a threshold.

`TrendingTagsSketch.Sketch`, a struct with `init(width:depth:)`, `total`, `add(_:count:)`, `estimate(_:)`, `counter(row:column:)` and `merge(_:)`; plus `TrendingTagsSketch.heavyHitters(in:width:depth:threshold:)`

- The sketch has `depth` rows of `width` counters, all 0 at first.
- **Row hashes.** The stub gives you `column(of:row:width:)`: the column a tag uses in each row. Don't change it; the tests compare your counters with it.
- `add(_ tag:count:)` (count defaults to 1) adds `count` to the tag's counter in **every** row, and to `total`.
- `estimate(_:)` returns the **smallest** of the tag's counters across the rows. It's never below the tag's true count.
- `counter(row:column:)` returns one counter, so the tests can inspect the grid.
- `merge(_:)` adds every counter of another sketch with the same width and depth, so the result is the sketch of both streams. `total` adds up too.
- `heavyHitters(in:width:depth:threshold:)` feeds the stream into a new sketch one tag at a time. Right after adding a tag, if its estimate is at least `threshold` and the tag hasn't been reported, it's reported. It returns the reported tags in the order they were reported.

## Examples

| Code | Result |
| --- | --- |
| `heavyHitters(in: ["x", "y", "x", "z", "y", "x"], width: 1_000, depth: 4, threshold: 2)` | `["x", "y"]` |
| `heavyHitters(in: ["a", "b", "c", "a", "d"], width: 1, depth: 2, threshold: 3)` | `["c", "a", "d"]` |
| `heavyHitters(in: [], width: 10, depth: 2, threshold: 1)` | `[]` |

In the second example the sketch is one counter wide, so every tag shares a single counter per row and each estimate is how many tags have arrived so far: "c" is the third, and reaches 3. It's a deliberately terrible sketch that shows the rule exactly. In the first, the sketch is wide enough to count these few tags exactly, so "x" and "y" are reported when they arrive for the second time, and "z" never is.

## Constraints

- `1 ≤ width ≤ 100,000`, `1 ≤ depth ≤ 10`, and counts are positive.
- The tests feed streams of up to 200,000 tags. Each `add` and `estimate` should cost O(depth).
- Don't keep an exact count per tag: `heavyHitters` must use the sketch's estimates, overcounts and all, because the tests expect exactly what the sketch reports.

<Hints>
<Hint>
Store the counters in one array of `width · depth` integers, row by row, so row r, column c is at index `r * width + c`. Or use `[[Int]]`: either is fine.
</Hint>
<Hint>
`add` loops over the rows and increments `counter(row, column(of: tag, row: row, width: width))`. `estimate` loops over the same counters and keeps the minimum. Compute `fnv1a(tag)` once if you want to save time; `column(of:row:width:)` is `mix(fnv1a(tag) &+ row) % width`.
</Hint>
<Hint>
For `heavyHitters`, keep a `Set<String>` of reported tags next to the result array: `reported.insert(tag).inserted` tells you whether this is the first time.
</Hint>
</Hints>

## Solutions

<Approach title="Exact counts in a dictionary" time="O(1) per tag" space="O(distinct tags)">

A `[String: Int]` gives exact counts, and exact heavy hitters, at the cost of memory for every distinct tag ever seen, which is what a sketch exists to avoid. It also reports different tags from the sketch whenever collisions push an estimate over the threshold early, so it doesn't pass the tests. It's still the right tool for checking a sketch's accuracy on test data.

</Approach>

<Approach title="Count-min sketch" time="O(depth) per tag" space="O(width · depth)">

Each row overcounts by whatever collides with the tag there, so the minimum over the rows is the best estimate, and it never undercounts.

```swift
public enum TrendingTagsSketch {
    public static func fnv1a(_ text: String) -> UInt64 {
        var hash: UInt64 = 0xcbf2_9ce4_8422_2325
        for byte in text.utf8 {
            hash ^= UInt64(byte)
            hash = hash &* 0x0000_0100_0000_01B3
        }
        return hash
    }

    public static func mix(_ x: UInt64) -> UInt64 {
        var z = x
        z = (z ^ (z >> 30)) &* 0xBF58_476D_1CE4_E5B9
        z = (z ^ (z >> 27)) &* 0x94D0_49BB_1331_11EB
        return z ^ (z >> 31)
    }

    public static func column(of tag: String, row: Int, width: Int) -> Int {
        Int(mix(fnv1a(tag) &+ UInt64(row)) % UInt64(width))
    }

    public struct Sketch {
        public let width: Int
        public let depth: Int
        public private(set) var total = 0
        private var counters: [Int]                 // row-major: row r, column c is r * width + c

        public init(width: Int, depth: Int) {
            self.width = width
            self.depth = depth
            counters = Array(repeating: 0, count: width * depth)
        }

        public mutating func add(_ tag: String, count: Int = 1) {
            let h = fnv1a(tag)
            for row in 0..<depth {
                counters[row * width + Int(mix(h &+ UInt64(row)) % UInt64(width))] += count
            }
            total += count
        }

        public func estimate(_ tag: String) -> Int {
            let h = fnv1a(tag)
            var smallest = Int.max
            for row in 0..<depth {
                smallest = min(smallest, counters[row * width + Int(mix(h &+ UInt64(row)) % UInt64(width))])
            }
            return smallest
        }

        public func counter(row: Int, column: Int) -> Int {
            counters[row * width + column]
        }

        public mutating func merge(_ other: Sketch) {
            precondition(width == other.width && depth == other.depth, "Sketches must have the same shape")
            for i in counters.indices {
                counters[i] += other.counters[i]
            }
            total += other.total
        }
    }

    public static func heavyHitters(in stream: [String], width: Int, depth: Int, threshold: Int) -> [String] {
        var sketch = Sketch(width: width, depth: depth)
        var reported: Set<String> = []
        var result: [String] = []
        for tag in stream {
            sketch.add(tag)
            if sketch.estimate(tag) >= threshold && reported.insert(tag).inserted {
                result.append(tag)
            }
        }
        return result
    }
}
```

Every tag whose true count reaches the threshold is guaranteed to be reported, because its estimate is at least its true count. A few rarer tags may be reported too, if collisions lift them over; a wider sketch makes that less likely.

</Approach>
