Compute base^e modulo `modulus`, where the exponent e is far too big for any `Int`: it arrives as an array of its decimal digits, most significant first. Return the remainder as a value from 0 to modulus − 1. Treat anything to the power 0 as 1, even 0.

`DigitExponentPower.remainder(base: Int, exponentDigits: [Int], modulus: Int) -> Int`

## Examples

| `base` | `exponentDigits` | `modulus` | Output |
| --- | --- | --- | --- |
| `3` | `[1, 3]` | `1000` | `323` |
| `-2` | `[3]` | `5` | `2` |
| `7` | `[0]` | `13` | `1` |
| `10` | `[1, 0, 0]` | `7` | `4` |
| `5` | `[2, 0]` | `1` | `0` |

3¹³ is 1,594,323, which leaves 323. (−2)³ is −8, and the remainder of −8 modulo 5 is 2, not −3. 10¹⁰⁰ is a 1 followed by a hundred zeros, and it leaves 4 when divided by 7. Modulo 1, every remainder is 0.

## Constraints

- `-10¹⁸ ≤ base ≤ 10¹⁸`
- `1 ≤ exponentDigits.count ≤ 10,000`, each digit is 0 to 9, and there are no leading zeros unless the exponent is exactly `[0]`.
- `1 ≤ modulus ≤ 2,000,000,000`, so the product of two remainders is below 4 × 10¹⁸ and fits in an `Int`.

<Hints>
<Hint>
Read the digits from the left. If the digits so far make the number e, then adding one more digit d makes 10e + d. How does x^(10e + d) relate to x^e?
</Hint>
<Hint>
x^(10e + d) = (x^e)¹⁰ · x^d. So keep `result` = x^(digits so far) modulo m, and for each digit replace it with result¹⁰ · x^d, reducing after every multiplication. Each step needs only a small fast power.
</Hint>
<Hint>
Reduce the base first with `((base % m) + m) % m`, which also turns negative bases into proper remainders, and start from `1 % m` so that m = 1 gives 0.
</Hint>
</Hints>

## Solutions

<Approach title="Digit by digit from the top" time="O(L)" space="O(1)">

L is the number of digits. This is the lesson's top-down fast power in base 10: each digit raises the running result to the 10th power and multiplies in x^d, a constant number of multiplications per digit.

```swift
public enum DigitExponentPower {
    public static func remainder(base: Int, exponentDigits: [Int], modulus: Int) -> Int {
        let x = ((base % modulus) + modulus) % modulus       // reduce first, and fix negative bases
        var result = 1 % modulus                             // 1 % m handles m = 1
        for digit in exponentDigits {
            result = power(result, 10, modulus) * power(x, digit, modulus) % modulus
        }
        return result
    }

    /// value^exponent mod m for a small exponent, by repeated squaring
    private static func power(_ value: Int, _ exponent: Int, _ modulus: Int) -> Int {
        var result = 1 % modulus
        var square = value
        var remaining = exponent
        while remaining > 0 {
            if remaining % 2 == 1 {
                result = result * square % modulus
            }
            square = square * square % modulus
            remaining /= 2
        }
        return result
    }
}
```

</Approach>

<Approach title="Digit by digit from the bottom" time="O(L)" space="O(1)">

M15's loop worked from the lowest bit up, keeping x¹, x², x⁴, x⁸… The base-10 version keeps x^(10^i) for each decimal place instead. Read the digits from the right: multiply the result by (x^(10^i))^d for the digit d in place i, then raise the place value to the 10th power for the next place. Same cost, same answer, opposite direction.

```swift
var result = 1 % modulus
var place = ((base % modulus) + modulus) % modulus        // x^(10^i), starting with x^1
for digit in exponentDigits.reversed() {
    result = result * power(place, digit, modulus) % modulus
    place = power(place, 10, modulus)
}
```

</Approach>
