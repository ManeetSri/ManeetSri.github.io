A region has cities numbered `0` to `cityCount - 1` joined by two-way roads `[a, b, length]`. A city's **neighbourhood** is the set of other cities whose shortest road distance from it is at most `maxDistance`. Return the city with the smallest neighbourhood. If several cities tie, return the smallest-numbered one.

`QuietestCityWithinReach.city(cityCount: Int, roads: [[Int]], maxDistance: Int) -> Int`

## Examples

| `cityCount` | `roads` | `maxDistance` | Output |
| --- | --- | --- | --- |
| `4` | `[[0, 1, 3], [1, 2, 1], [2, 3, 4], [0, 3, 9]]` | `4` | `3` |
| `4` | `[[0, 1, 3], [1, 2, 1], [2, 3, 4], [0, 3, 9]]` | `5` | `0` |
| `5` | `[[0, 1, 2], [1, 2, 2], [2, 3, 2], [3, 4, 2]]` | `3` | `0` |
| `4` | `[[0, 1, 1], [0, 2, 1], [0, 3, 1]]` | `1` | `1` |

In the first example the shortest distances are 0–1: 3, 0–2: 4, 0–3: 8, 1–2: 1, 1–3: 5 and 2–3: 4. Within 4, city 0 reaches 1 and 2, city 1 reaches 0 and 2, city 2 reaches all three, and city 3 reaches only 2, so city 3 is the quietest. With a limit of 5, cities 0 and 3 both reach two others, and the tie goes to 0.

## Constraints

- `1 ≤ cityCount ≤ 200`, and `0 ≤ roads.count ≤ 20,000`
- `a ≠ b`, `1 ≤ length ≤ 10,000`, and there may be several roads between the same two cities.
- `0 ≤ maxDistance ≤ 1,000,000`
- The tests include 150 cities with a road between every pair.

<Hints>
<Hint>
Each city's neighbourhood depends on its shortest distance to every other city, through any number of roads. So you need all-pairs shortest distances.
</Hint>
<Hint>
With at most 200 cities, Floyd–Warshall's O(n³) is about eight million steps. Start the matrix at 0 on the diagonal, the road lengths (the shortest, for parallel roads, in both directions), and infinity elsewhere.
</Hint>
<Hint>
Then, for each city in order, count the others within `maxDistance`, and replace the best only when a count is strictly smaller. That keeps the smallest number on ties.
</Hint>
</Hints>

## Solutions

<Approach title="Dijkstra from every city" time="O(n · m log n)" space="O(n + m)">

Run Dijkstra from each city and count the distances within the limit. It's the better choice for big, sparse maps, and it works here too.

</Approach>

<Approach title="Floyd–Warshall" time="O(n³)" space="O(n²)">

Three loops fill in every distance, with k, the city allowed in the middle, outermost.

```swift
public enum QuietestCityWithinReach {
    public static func city(cityCount n: Int, roads: [[Int]], maxDistance: Int) -> Int {
        let infinity = Int.max / 2
        var dist = Array(repeating: Array(repeating: infinity, count: n), count: n)
        for i in 0..<n {
            dist[i][i] = 0
        }
        for road in roads {
            let length = min(dist[road[0]][road[1]], road[2])   // keep the shorter of parallel roads
            dist[road[0]][road[1]] = length
            dist[road[1]][road[0]] = length
        }
        for k in 0..<n {
            for i in 0..<n where dist[i][k] < infinity {
                for j in 0..<n where dist[i][k] + dist[k][j] < dist[i][j] {
                    dist[i][j] = dist[i][k] + dist[k][j]
                }
            }
        }
        var best = 0
        var fewest = Int.max
        for city in 0..<n {
            let neighbours = (0..<n).filter { $0 != city && dist[city][$0] <= maxDistance }.count
            if neighbours < fewest {                    // strict: ties keep the smaller number
                fewest = neighbours
                best = city
            }
        }
        return best
    }
}
```

`Int.max / 2` leaves room for `dist[i][k] + dist[k][j]` even when the second term is still infinity, so the sum never overflows.

</Approach>
