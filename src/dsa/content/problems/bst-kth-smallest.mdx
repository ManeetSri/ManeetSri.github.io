Return the kth smallest value in a binary search tree, counting from 1: k = 1 is the minimum, and k = the number of nodes is the maximum.

`BSTKthSmallest.value(_ k: Int, in root: TreeNode?) -> Int`

Aim for O(h + k), where h is the height: stop as soon as you know the answer.

## Examples

The tree `[40, 20, 60, 10, 30, 50, 70, nil, 15, nil, nil, 45]` holds 10, 15, 20, 30, 40, 45, 50, 60 and 70.

| `k` | Output |
| --- | --- |
| `1` | `10` |
| `2` | `15` |
| `5` | `40` |
| `6` | `45` |
| `9` | `70` |

With `[3, 1, 4, nil, 2]` and k = 3, the answer is 3.

## Constraints

- `1 ≤ k ≤` number of nodes `≤ 200,000`
- `root` is a valid binary search tree with no repeated values.
- Trees in the tests are at most 1,000 levels deep, so recursion is fine.

<Hints>
<Hint>
Which traversal visits a BST's values in increasing order?
</Hint>
<Hint>
Inorder: left subtree, node, right subtree. Count the nodes as you visit them, and the kth one visited is the answer. Collecting every value into an array first works, but does O(n) work even when k is 1.
</Hint>
<Hint>
To stop early, use the iterative inorder walk with a stack: push the left spine, pop a node, count it, then move to its right child. Return as soon as the count reaches k.
</Hint>
</Hints>

## Solutions

<Approach title="Collect the inorder walk" time="O(n)" space="O(n)">

Simple and correct, but it always visits every node and stores every value.

```swift
public static func value(_ k: Int, in root: TreeNode?) -> Int {
    var values: [Int] = []
    func walk(_ node: TreeNode?) {
        guard let node else { return }
        walk(node.left)
        values.append(node.value)
        walk(node.right)
    }
    walk(root)
    return values[k - 1]
}
```

</Approach>

<Approach title="Iterative inorder with an early exit" time="O(h + k)" space="O(h)">

Reaching the minimum costs O(h) (down the left spine), and each of the k values after that costs amortised O(1). The stack never holds more than one node per level.

```swift
public enum BSTKthSmallest {
    public static func value(_ k: Int, in root: TreeNode?) -> Int {
        var stack: [TreeNode] = []
        var current = root
        var visited = 0
        while current != nil || !stack.isEmpty {
            while let node = current {
                stack.append(node)
                current = node.left
            }
            let node = stack.removeLast()
            visited += 1
            if visited == k {
                return node.value
            }
            current = node.right
        }
        preconditionFailure("k is larger than the number of nodes")
    }
}
```

If the kth smallest is asked for often while the tree changes, store each node's subtree size in the node. Then compare k with the size of the left subtree and go left, stop, or go right with a smaller k: O(h) per query.

</Approach>
