Group words that are shifts of each other. Shifting a word moves every letter forward by the same number of places in the alphabet, wrapping from z back to a: shifting `"ace"` by 1 gives `"bdf"`, and shifting `"xzb"` by 3 gives `"ace"`.

`ShiftGroups.groups(of words: [String]) -> [[String]]`

Each group lists its words in the order they appear in the input, duplicates included. The groups are ordered by where their first word appears.

## Examples

| `words` | Result |
| --- | --- |
| `["ace", "bdf", "az", "yz", "ba", "xzb", "q", "c"]` | `[["ace", "bdf", "xzb"], ["az", "ba"], ["yz"], ["q", "c"]]` |
| `["xyz", "abc", "zab"]` | `[["xyz", "abc", "zab"]]` |
| `["ab", "abc", "bc"]` | `[["ab", "bc"], ["abc"]]` |
| `["ab", "ba"]` | `[["ab"], ["ba"]]` |
| `[]` | `[]` |

`"az"` shifted by 1 is `"ba"`, because z wraps round to a. `"ab"` and `"ba"` aren't shifts of each other: in `"ab"` the second letter is one place after the first, but in `"ba"` it's 25 places after. Any two one-letter words are shifts of each other.

## Constraints

- `0 ≤ words.count ≤ 50,000`
- Each word has 1 to 50 letters, all lowercase `a` to `z`.
- Aim for O(total letters).

<Hints>
<Hint>
What stays the same when every letter of a word shifts by the same amount? Think about the gap between each letter and the next.
</Hint>
<Hint>
Use the list of gaps, each wrapped into 0 to 25 with `(next - current + 26) % 26`, as the key. `"ace"` and `"xzb"` both give `[2, 2]`. An `[Int]` is `Hashable`, so it can be a dictionary key directly.
</Hint>
<Hint>
For the order, keep the groups in an array, and a dictionary from key to the position of that key's group. A new key appends a new group.
</Hint>
</Hints>

## Solutions

<Approach title="Gap lists as keys, groups in first-seen order" time="O(total letters)" space="O(total letters)">

Two words are shifts of each other exactly when their gap lists match. Equal gap lists also mean equal lengths, since a word of n letters has n − 1 gaps, so `"ab"` and `"abc"` can never share a key. Every one-letter word has the empty gap list, so they all group together.

```swift
public enum ShiftGroups {
    public static func groups(of words: [String]) -> [[String]] {
        var groupIndex: [[Int]: Int] = [:]
        var result: [[String]] = []
        for word in words {
            let key = shiftKey(word)
            if let index = groupIndex[key] {
                result[index].append(word)
            } else {
                groupIndex[key] = result.count
                result.append([word])
            }
        }
        return result
    }

    private static func shiftKey(_ word: String) -> [Int] {
        let values = word.unicodeScalars.map { Int($0.value) }
        var key: [Int] = []
        for index in values.indices.dropFirst() {
            key.append((values[index] - values[index - 1] + 26) % 26)
        }
        return key
    }
}
```

Adding 26 before taking the remainder keeps the gap non-negative, since Swift's `%` keeps the sign of a negative left side.

</Approach>

<Approach title="Shift every word to start with a" time="O(total letters)" space="O(total letters)">

Another canonical form: shift each word backwards until it starts with `a`. Every word in a group becomes the same string, so that string is the key. `"bdf"` and `"xzb"` both become `"ace"`.

```swift
private static func shiftKey(_ word: String) -> String {
    let values = word.unicodeScalars.map { Int($0.value) - 97 }   // a = 0, ..., z = 25
    let shift = values.first ?? 0
    let letters = values.map { Character(UnicodeScalar(UInt8((($0 - shift + 26) % 26) + 97))) }
    return String(letters)
}
```

Both keys work. The gap list avoids building a new string; the shifted word is easier to read when debugging.

</Approach>
