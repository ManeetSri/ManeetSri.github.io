Build a pyramid of digits, one string per row, padded with dots so every row has the same width.

`NumberPyramid.rows(_ height: Int) -> [String]`

Row `r` (counting from 1 at the top) is made of:

1. `height - r` dots,
2. the digits from 1 up to `r`, then back down to 1,
3. `height - r` dots again.

So every row is `2 × height - 1` characters wide. A height of 0 gives no rows.

## Examples

`rows(3)` returns `["..1..", ".121.", "12321"]`, which looks like this when printed one row per line:

```text
..1..
.121.
12321
```

| Input | Output |
| --- | --- |
| `1` | `["1"]` |
| `2` | `[".1.", "121"]` |
| `3` | `["..1..", ".121.", "12321"]` |
| `0` | `[]` |

## Constraints

- `0 ≤ height ≤ 9` (so every number in the pyramid is a single digit)

<Hints>
<Hint>
Start with an empty array, `var result: [String] = []`, add each finished row with `result.append(line)`, and return `result` at the end.
</Hint>
<Hint>
Use an outer loop over the rows. For each row, build `line` in three parts: padding, the climb up, the climb down. Trace height 3 by hand first, and write down what each part should be for every row.
</Hint>
<Hint>
The climb up is `1...r`. The climb down is `r - 1` to 1, which is `stride(from: r - 1, through: 1, by: -1)`: empty on the first row, which is exactly right. The padding is `String(repeating: ".", count: height - r)`, or a loop that adds one dot at a time.
</Hint>
</Hints>

## Solutions

<Approach title="Three inner pieces per row" time="O(height²)" space="O(height²)">

The outer loop makes one row at a time. Each row is padding, digits going up, digits coming down, and the same padding again. Looping with `stride(from: 1, through: height, by: 1)` means a height of 0 produces no rows instead of crashing on `1...0`.

```swift
public enum NumberPyramid {
    public static func rows(_ height: Int) -> [String] {
        var result: [String] = []
        for row in stride(from: 1, through: height, by: 1) {
            let padding = String(repeating: ".", count: height - row)
            var line = padding
            for digit in 1...row {
                line += "\(digit)"
            }
            for digit in stride(from: row - 1, through: 1, by: -1) {
                line += "\(digit)"
            }
            line += padding
            result.append(line)
        }
        return result
    }
}
```

The output itself has `height` rows of about `2 × height` characters, so no solution can do better than O(height²).

</Approach>

<Approach title="One loop over every column" time="O(height²)" space="O(height²)">

Another way to see it: number the columns from 1 to `2 × height - 1`. A column's distance from the centre column, `height`, decides what goes there. In row `r`, a column at distance `d` shows the digit `r - d` if that's at least 1, and a dot otherwise.

```swift
public static func rows(_ height: Int) -> [String] {
    var result: [String] = []
    for row in stride(from: 1, through: height, by: 1) {
        var line = ""
        for column in stride(from: 1, through: 2 * height - 1, by: 1) {
            let distance = column > height ? column - height : height - column
            let value = row - distance
            line += value >= 1 ? "\(value)" : "."
        }
        result.append(line)
    }
    return result
}
```

One rule for every cell instead of three pieces. Patterns like this are easier to find once you've written out a trace table of row, column and value.

</Approach>
