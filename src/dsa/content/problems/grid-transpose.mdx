Given a rectangular grid of numbers, return its **transpose**: the grid flipped over its top-left to bottom-right diagonal, so that row `r` of the input becomes column `r` of the output. In other words, the value at row `r`, column `c` of the result is `grid[c][r]`.

`GridTranspose.transpose(_ grid: [[Int]]) -> [[Int]]`

If the grid has no rows, or its rows are empty, return `[]`.

## Examples

| Input | Output |
| --- | --- |
| `[[1, 2], [3, 4]]` | `[[1, 3], [2, 4]]` |
| `[[1, 2, 3], [4, 5, 6]]` | `[[1, 4], [2, 5], [3, 6]]` |
| `[[7, 8, 9]]` | `[[7], [8], [9]]` |
| `[]` | `[]` |

A grid with 2 rows and 3 columns becomes a grid with 3 rows and 2 columns.

## Constraints

- `0 ≤ rows, cols ≤ 100`
- Every row has the same length.
- `-10⁹ ≤ grid[r][c] ≤ 10⁹`

<Hints>
<Hint>
Work out the size of the result first. If the input has `rows` rows and `cols` columns, how many rows and columns does the transpose have?
</Hint>
<Hint>
Create the result full of zeros with `Array(repeating: Array(repeating: 0, count: rows), count: cols)`, then fill it in.
</Hint>
<Hint>
Loop over every cell of the input with two nested loops, and copy each value with `result[c][r] = grid[r][c]`. Use `guard let cols = grid.first?.count, cols > 0` to handle empty grids.
</Hint>
</Hints>

## Solutions

<Approach title="Fill a new grid cell by cell" time="O(rows × cols)" space="O(rows × cols)">

The result has `cols` rows and `rows` columns. Create it full of zeros, then copy each value across with the indexes swapped.

```swift
public enum GridTranspose {
    public static func transpose(_ grid: [[Int]]) -> [[Int]] {
        guard let cols = grid.first?.count, cols > 0 else { return [] }
        let rows = grid.count
        var result = Array(repeating: Array(repeating: 0, count: rows), count: cols)
        for r in 0..<rows {
            for c in 0..<cols {
                result[c][r] = grid[r][c]
            }
        }
        return result
    }
}
```

</Approach>

<Approach title="Build each new row with map" time="O(rows × cols)" space="O(rows × cols)">

Row `c` of the result is column `c` of the input: one value from each input row. `map` builds that directly, with no zero-filled grid.

```swift
public static func transpose(_ grid: [[Int]]) -> [[Int]] {
    guard let cols = grid.first?.count, cols > 0 else { return [] }
    return (0..<cols).map { c in
        grid.map { row in row[c] }
    }
}
```

Both versions do the same work. The first is easier to get right while you're learning; the second is a nice use of M06's `map`.

</Approach>
