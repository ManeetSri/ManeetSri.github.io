An array holds each of the numbers 1 to n exactly once, in some order. A **swap** exchanges any two elements, not necessarily neighbours. Return the fewest swaps that sort the array into increasing order.

`FewestSwapsToSort.fewestSwaps(_ numbers: [Int]) -> Int`

## Examples

| `numbers` | Returns |
| --- | --- |
| `[3, 5, 2, 1, 4]` | `4` |
| `[2, 1, 4, 3]` | `2` |
| `[4, 3, 2, 1]` | `2` |
| `[2, 3, 1]` | `2` |
| `[1, 2, 3]` | `0` |
| `[]` | `0` |

`[4, 3, 2, 1]` needs only two swaps: 4 with 1, then 3 with 2.

## Constraints

- `0 ≤ numbers.count ≤ 200,000`
- `numbers` holds each of 1 to n exactly once.
- Aim for O(n) time. Don't change the caller's array (it's passed by value, so you can't anyway).

<Hints>
<Hint>
Cyclic sort sends each value straight to its home, index v − 1, and a value that's home never moves again. Count its swaps.
</Hint>
<Hint>
Why is that the minimum? Follow where each value wants to go: index 0's value wants some index, whose value wants another, and so on until you come back. Those are **cycles**. A cycle of length L needs L − 1 swaps, and one swap can split a cycle into at most two pieces.
</Hint>
<Hint>
So the answer is n minus the number of cycles. You can count cycles directly by following each one once, marking indexes as visited, without moving anything.
</Hint>
</Hints>

## Solutions

<Approach title="Cyclic sort, counting swaps" time="O(n)" space="O(n)">

Sort a copy with cyclic sort and count the swaps. Each swap puts one value home for good, so there are fewer than n swaps, plus n moves of i.

```swift
public enum FewestSwapsToSort {
    public static func fewestSwaps(_ numbers: [Int]) -> Int {
        var items = numbers
        var swaps = 0
        var i = 0
        while i < items.count {
            let home = items[i] - 1
            if home != i {
                items.swapAt(i, home)
                swaps += 1
            } else {
                i += 1
            }
        }
        return swaps
    }
}
```

Comparing `home != i` is safe here because the values are all different: a value whose home isn't i can't find an equal value waiting there. With repeats it would loop forever, as the cyclic sort lesson warns.

</Approach>

<Approach title="Count the cycles" time="O(n)" space="O(n)">

Nothing needs to move. Walk each cycle once, marking indexes as you go; every unvisited index starts a new cycle.

```swift
public static func fewestSwaps(_ numbers: [Int]) -> Int {
    var visited = [Bool](repeating: false, count: numbers.count)
    var cycles = 0
    for start in numbers.indices where !visited[start] {
        cycles += 1
        var index = start
        while !visited[index] {
            visited[index] = true
            index = numbers[index] - 1
        }
    }
    return numbers.count - cycles
}
```

A value already at home is a cycle of length 1, needing no swaps. If the values were any distinct numbers rather than 1 to n, you'd first sort a copy to learn where each value belongs (O(n log n)), then count cycles the same way.

</Approach>
