On a phone keypad, each digit from 2 to 9 carries some letters: 2 is `abc`, 3 is `def`, 4 is `ghi`, 5 is `jkl`, 6 is `mno`, 7 is `pqrs`, 8 is `tuv` and 9 is `wxyz`. Given a string of such digits, return every string you could type by choosing one letter for each digit, in order.

`KeypadLetterWords.words(for digits: String) -> [String]`

The words may come in any order: the tests sort them before comparing. An empty string of digits gives an empty list.

## Examples

| `digits` | Output |
| --- | --- |
| `"47"` | `["gp", "gq", "gr", "gs", "hp", "hq", "hr", "hs", "ip", "iq", "ir", "is"]` |
| `"9"` | `["w", "x", "y", "z"]` |
| `"22"` | `["aa", "ab", "ac", "ba", "bb", "bc", "ca", "cb", "cc"]` |
| `""` | `[]` |

## Constraints

- `0 ≤ digits.count ≤ 8`, and every character is a digit from `2` to `9`.
- The longest test, `"79797979"`, has 4⁸ = 65,536 words.

<Hints>
<Hint>
Each digit is one level of a decision tree, and each of its letters is a branch. A complete path is one word.
</Hint>
<Hint>
Keep the word so far in a `[Character]` array: append a letter, recurse for the next digit, then remove the letter again. Turn it into a `String` only when every digit has a letter.
</Hint>
</Hints>

## Solutions

<Approach title="Backtracking, one level per digit" time="O(n · 4ⁿ)" space="O(n) besides the output">

Every branch leads to a valid word, so there's nothing to prune: the work is proportional to the output. An array indexed by the digit's value holds the letters.

```swift
public enum KeypadLetterWords {
    private static let letters: [String] = ["", "", "abc", "def", "ghi", "jkl", "mno", "pqrs", "tuv", "wxyz"]

    public static func words(for digits: String) -> [String] {
        let keys = digits.compactMap { $0.wholeNumberValue }
        guard !keys.isEmpty else { return [] }
        var result: [String] = []
        var word: [Character] = []

        func explore(_ index: Int) {
            if index == keys.count {
                result.append(String(word))
                return
            }
            for letter in letters[keys[index]] {
                word.append(letter)                                 // choose
                explore(index + 1)                                  // explore
                word.removeLast()                                   // unchoose
            }
        }

        explore(0)
        return result
    }
}
```

</Approach>

<Approach title="Building the list digit by digit" time="O(n · 4ⁿ)" space="O(n · 4ⁿ)">

With no pruning, a loop works equally well: start with `[""]`, and for each digit replace every word so far with that word followed by each of the digit's letters.

```swift
public enum KeypadLetterWords {
    private static let letters: [String] = ["", "", "abc", "def", "ghi", "jkl", "mno", "pqrs", "tuv", "wxyz"]

    public static func words(for digits: String) -> [String] {
        guard !digits.isEmpty else { return [] }
        var words = [""]
        for digit in digits {
            let options = letters[digit.wholeNumberValue!]
            words = words.flatMap { word in options.map { word + String($0) } }
        }
        return words
    }
}
```

</Approach>
