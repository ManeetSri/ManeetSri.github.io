Two servers each keep their response times in a sorted array. Return the median of all the times together. If the total count is even, the median is the average of the two middle values.

`TwoArrayMedian.median(of first: [Int], and second: [Int]) -> Double`

Don't merge the arrays: aim for O(log min(m, n)), where m and n are the two lengths.

## Examples

| `first` | `second` | Output | Why |
| --- | --- | --- | --- |
| `[1, 4, 9]` | `[2, 3]` | `3.0` | together: 1, 2, **3**, 4, 9 |
| `[1, 4, 9]` | `[2, 3, 10]` | `3.5` | together: 1, 2, **3, 4**, 9, 10 |
| `[5]` | `[7]` | `6.0` | the average of 5 and 7 |
| `[]` | `[8]` | `8.0` | one array can be empty |
| `[1, 2, 3]` | `[10, 20, 30, 40]` | `10.0` | one array entirely before the other |
| `[-5, -1]` | `[-4, 0]` | `-2.5` | the average of -4 and -1 |

## Constraints

- `0 ≤ first.count, second.count ≤ 1,000,000`, and `first.count + second.count ≥ 1`
- Both arrays are sorted in non-decreasing order. Values can repeat, within and across the arrays.
- `-1,000,000,000 ≤` every value `≤ 1,000,000,000`

<Hints>
<Hint>
Start with the O(m + n) answer, merging (or merging halfway) to find the middle. Keep it: it's the perfect checker for small inputs. The tests pair a million-value array with thousands of short ones, so it's too slow for the large cases.
</Hint>
<Hint>
Split the combined values into a left half of `(m + n + 1) / 2` values and a right half. If the left half takes the first i values of `first`, it must take the first j = half − i values of `second`. The split is right when `first[i - 1] <= second[j]` and `second[j - 1] <= first[i]`.
</Hint>
<Hint>
Binary search over i in `0...m`, with `first` the shorter array (swap if not). If `first[i - 1] > second[j]`, you took too many from `first`; if `second[j - 1] > first[i]`, too few. Treat a missing value on the left as `Int.min` and on the right as `Int.max`. Once the split is right, the median is the largest left value (odd total), or its average with the smallest right value (even total).
</Hint>
</Hints>

## Solutions

<Approach title="Merge halfway" time="O(m + n)" space="O(1)">

Two pointers walk both arrays in order, as when merging, and stop at the middle. Only the last two values taken are kept.

```swift
public static func median(of first: [Int], and second: [Int]) -> Double {
    let total = first.count + second.count
    var i = 0
    var j = 0
    var previous = 0
    var current = 0
    for _ in 0...(total / 2) {
        previous = current
        if j == second.count || (i < first.count && first[i] <= second[j]) {
            current = first[i]
            i += 1
        } else {
            current = second[j]
            j += 1
        }
    }
    return total % 2 == 1 ? Double(current) : Double(previous + current) / 2
}
```

</Approach>

<Approach title="Binary search the cut" time="O(log min(m, n))" space="O(1)">

Choosing how many values come from the shorter array fixes how many come from the other. As i grows, `first[i - 1]` can only grow and `second[j]` can only shrink, so "took too many from first" is a monotonic question, and binary search finds the one cut where both checks pass. Searching the shorter array keeps j between 0 and n for every i.

```swift
public enum TwoArrayMedian {
    public static func median(of first: [Int], and second: [Int]) -> Double {
        if first.count > second.count {
            return median(of: second, and: first)    // search the shorter array
        }
        let m = first.count
        let n = second.count
        let leftSize = (m + n + 1) / 2
        var low = 0
        var high = m
        while low <= high {
            let i = low + (high - low) / 2           // values taken from first
            let j = leftSize - i                     // values taken from second
            let firstLeft = i > 0 ? first[i - 1] : Int.min
            let firstRight = i < m ? first[i] : Int.max
            let secondLeft = j > 0 ? second[j - 1] : Int.min
            let secondRight = j < n ? second[j] : Int.max
            if firstLeft > secondRight {
                high = i - 1                         // took too many from first
            } else if secondLeft > firstRight {
                low = i + 1                          // took too few from first
            } else {
                let leftMax = Swift.max(firstLeft, secondLeft)
                if (m + n) % 2 == 1 {
                    return Double(leftMax)
                }
                let rightMin = Swift.min(firstRight, secondRight)
                return Double(leftMax + rightMin) / 2    // values are within ±10⁹: no overflow
            }
        }
        preconditionFailure("Both arrays must be sorted, with at least one value between them")
    }
}
```

The sentinels never reach the answer: the left half always holds at least one real value, and when the total is even, so does the right half. `Swift.max` and `Swift.min` name the standard functions explicitly, which keeps them unambiguous inside a type.

</Approach>
