A market stall sells pies for 5 coins each. Customers queue up and buy one pie each, paying with a single note: a `5`, a `10` or a `20`. The till starts empty, and the stall can only give change from notes it has already taken. Return `true` if every customer, in order, can be given the right change.

`PieStallChange.canGiveChange(_ payments: [Int]) -> Bool`

## Examples

| `payments` | Output | Why |
| --- | --- | --- |
| `[5, 5, 10, 20]` | `true` | the 20 gets the 10 and a 5 back |
| `[5, 10, 5, 20, 20]` | `false` | the till is empty at the second 20 |
| `[10]` | `false` | no 5 to give back |
| `[5, 5, 5, 5, 10, 20, 10, 10]` | `true` | only if the 20 gets a 10 and a 5, not three 5s |
| `[]` | `true` | nobody to serve |

## Constraints

- `0 ≤ payments.count ≤ 100,000`
- Every payment is `5`, `10` or `20`.
- The tests compare your answer with an exhaustive search that tries both ways of changing every 20.

<Hints>
<Hint>
You only need to count the 5s and 10s in the till. Twenties are never given as change.
</Hint>
<Hint>
A 10 needs one 5 back: no choice there. A 20 needs 15 back, as a 10 and a 5 or as three 5s. Which note is more useful to keep for later customers?
</Hint>
<Hint>
Fives can change both 10s and 20s, but a 10 only helps with a 20, where two 5s could do its job. So pay a 10 and a 5 whenever you can, and three 5s only when you have no 10.
</Hint>
</Hints>

## Solutions

<Approach title="Try both ways of changing every 20" time="O(2ⁿ)" space="O(n)">

Recursion through the queue: 5s and 10s have only one option, and a 20 tries the ten-and-five option first, then three fives. Exponential in the number of 20s, so it's only a checker.

```swift
public static func canGiveChange(_ payments: [Int]) -> Bool {
    func serve(from index: Int, fives: Int, tens: Int) -> Bool {
        if index == payments.count { return true }
        switch payments[index] {
        case 5:
            return serve(from: index + 1, fives: fives + 1, tens: tens)
        case 10:
            return fives >= 1 && serve(from: index + 1, fives: fives - 1, tens: tens + 1)
        default:
            if tens >= 1 && fives >= 1 && serve(from: index + 1, fives: fives - 1, tens: tens - 1) {
                return true
            }
            return fives >= 3 && serve(from: index + 1, fives: fives - 3, tens: tens)
        }
    }
    return serve(from: 0, fives: 0, tens: 0)
}
```

</Approach>

<Approach title="Greedy: the 10 first" time="O(n)" space="O(1)">

After changing a 20, the greedy till holds two more 5s and one fewer 10 than the till that paid three 5s. Anything the other till can pay later, the greedy one can too, using two 5s wherever the other would use that 10. So the greedy till never fails first.

```swift
public enum PieStallChange {
    public static func canGiveChange(_ payments: [Int]) -> Bool {
        var fives = 0
        var tens = 0
        for note in payments {
            switch note {
            case 5:
                fives += 1
            case 10:
                guard fives >= 1 else { return false }
                fives -= 1
                tens += 1
            case 20:
                if tens >= 1 && fives >= 1 {
                    tens -= 1
                    fives -= 1
                } else if fives >= 3 {
                    fives -= 3
                } else {
                    return false
                }
            default:
                return false            // not a note the stall accepts
            }
        }
        return true
    }
}
```

</Approach>
