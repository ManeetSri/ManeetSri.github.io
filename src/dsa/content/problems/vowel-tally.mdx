Given a string, return how many vowels it contains. The vowels are `a`, `e`, `i`, `o` and `u`, in either lowercase or uppercase. `y` doesn't count, and neither do accented letters like `é`.

`VowelTally.count(in text: String) -> Int`

## Examples

| Input | Output |
| --- | --- |
| `"banana"` | `3` |
| `"Ice Cream"` | `4` |
| `"Hello, World! 123"` | `3` |
| `"rhythm"` | `0` |
| `""` | `0` |

## Constraints

- `0 ≤ text.count ≤ 100,000`
- `text` may contain any characters.

<Hints>
<Hint>
Loop over the characters of `text` with `for ch in text`, and count the ones that are vowels.
</Hint>
<Hint>
To treat `"A"` and `"a"` the same, lowercase the character first. Remember that `ch.lowercased()` returns a `String`, so compare it with strings, or wrap it in `Character(...)`.
</Hint>
<Hint>
A `Set<Character>` of the five lowercase vowels makes each check O(1): `vowels.contains(Character(ch.lowercased()))`. Check `ch.isASCII` first so only English letters are lowercased and compared.
</Hint>
</Hints>

## Solutions

<Approach title="Check against all ten vowels" time="O(n)" space="O(1)">

List both cases of every vowel in one string and ask whether it contains each character. `filter` keeps the vowels and `count` counts them.

```swift
public static func count(in text: String) -> Int {
    text.filter { "aeiouAEIOU".contains($0) }.count
}
```

`"aeiouAEIOU".contains($0)` scans 10 characters, which is a constant, so the whole thing is still O(n).

</Approach>

<Approach title="Lowercase, then look up in a set" time="O(n)" space="O(1)">

Lowercasing means only five vowels to list. The set lookup is O(1), and the set's size never changes, so the extra space is constant.

```swift
public enum VowelTally {
    public static func count(in text: String) -> Int {
        let vowels: Set<Character> = ["a", "e", "i", "o", "u"]
        var total = 0
        for character in text where character.isASCII {
            if vowels.contains(Character(character.lowercased())) {
                total += 1
            }
        }
        return total
    }
}
```

The `isASCII` check skips everything outside plain English text before lowercasing, so a character like `ß`, whose uppercase and lowercase forms differ in length, never reaches `Character(...)`.

</Approach>
