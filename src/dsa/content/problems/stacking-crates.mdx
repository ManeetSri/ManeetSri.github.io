Square crates are dropped, one at a time, onto a long flat floor, and you're watching from the side. Each crate falls straight down until it rests on the floor or on top of a crate below it. After each drop, report the height of the tallest stack so far.

`StackingCrates.tallestAfterEachDrop(_ crates: [[Int]]) -> [Int]`

Crate `[left, side]` is a square `side` wide and `side` tall, covering the horizontal positions from `left` to `left + side`. It lands on an earlier crate only if they overlap by a **positive** width: two crates whose edges just touch, one ending at 5 and the next starting at 5, don't hold each other up. A crate resting on several crates sits on the highest of them.

## Examples

| `crates` | Output |
| --- | --- |
| `[[1, 3], [2, 2], [7, 4], [4, 1], [3, 5]]` | `[3, 5, 5, 5, 10]` |
| `[[0, 2], [2, 3]]` | `[2, 3]` |
| `[[0, 10], [0, 10], [0, 10]]` | `[10, 20, 30]` |
| `[[0, 1], [1, 1], [2, 1], [0, 3]]` | `[1, 1, 1, 4]` |
| `[]` | `[]` |

In the first example, the second crate (2 to 4) lands on the first (1 to 4), so its top is 3 + 2 = 5. The crate covering 4 to 5 only touches the first two at position 4, so it lands on the floor. The last crate covers 3 to 8 and overlaps all four: it lands on the highest top under it, 5, and reaches 10. In the second example the crates only touch, so the second one sits on the floor.

## Constraints

- `0 ≤ crates.count ≤ 100,000`
- `0 ≤ left ≤ 10⁹` and `1 ≤ side ≤ 10⁶`
- The tests drop 100,000 crates onto a crowded stretch of floor, so comparing each crate with every earlier one, O(n²), is too slow.

<Hints>
<Hint>
Positions go up to a billion, but only the crates' edges matter: between two neighbouring edges, nothing changes. Collect every `left` and `left + side`, sort them, and replace each position by its rank. A crate then covers the gaps between consecutive edges, from rank(left) up to, but not including, rank(left + side).
</Hint>
<Hint>
Keep the height of the stack over each gap. A new crate lands on the **maximum** height over the gaps it covers, and afterwards every one of those gaps has the same height: that maximum plus `side`. So you need range maximum and "set a whole range to one value".
</Hint>
<Hint>
That's a lazy segment tree with an **assignment** tag. Pushing an assignment down sets both children's maximums and tags to the value. A newer assignment replaces an older one. The answer after each drop is the running maximum of the crates' tops.
</Hint>
</Hints>

## Solutions

<Approach title="Compare with every earlier crate" time="O(n²)" space="O(n)">

Each crate's top is its side plus the highest top among the earlier crates it overlaps. Two half-open intervals `[a, a + s)` and `[b, b + t)` overlap by a positive width when `a < b + t` and `b < a + s`.

```swift
public static func tallestAfterEachDrop(_ crates: [[Int]]) -> [Int] {
    var tops: [Int] = []
    var tallest = 0
    var result: [Int] = []
    for (i, crate) in crates.enumerated() {
        var base = 0
        for j in 0..<i where crates[j][0] < crate[0] + crate[1] && crate[0] < crates[j][0] + crates[j][1] {
            base = max(base, tops[j])
        }
        tops.append(base + crate[1])
        tallest = max(tallest, base + crate[1])
        result.append(tallest)
    }
    return result
}
```

</Approach>

<Approach title="Coordinate compression and a lazy segment tree" time="O(n log n)" space="O(n)">

Compress the edges, then use a tree of maximums with pending assignments, as in [Lazy propagation](/dsa/learn/seg-lazy). The assignment tag is an `Int?`, so "no pending assignment" can't be confused with a real height.

```swift
public enum StackingCrates {
    public static func tallestAfterEachDrop(_ crates: [[Int]]) -> [Int] {
        var edges: [Int] = []
        for crate in crates {
            edges.append(crate[0])
            edges.append(crate[0] + crate[1])
        }
        edges = Array(Set(edges)).sorted()
        func rank(_ x: Int) -> Int {                      // lower bound in the sorted edges
            var low = 0, high = edges.count
            while low < high {
                let mid = (low + high) / 2
                if edges[mid] < x { low = mid + 1 } else { high = mid }
            }
            return low
        }

        var heights = Heights(count: max(1, edges.count - 1))   // one slot per gap between edges
        var tallest = 0
        var result: [Int] = []
        for crate in crates {
            let first = rank(crate[0]), last = rank(crate[0] + crate[1]) - 1
            let top = heights.maximum(first, last) + crate[1]
            heights.assign(top, first, last)
            tallest = max(tallest, top)
            result.append(tallest)
        }
        return result
    }

    private struct Heights {
        private var maximums: [Int]
        private var assigned: [Int?]                      // a pending "set everything to this"
        private let count: Int

        init(count: Int) {
            self.count = count
            maximums = Array(repeating: 0, count: 4 * count)
            assigned = Array(repeating: nil, count: 4 * count)
        }

        mutating func maximum(_ left: Int, _ right: Int) -> Int {
            maximum(left, right, 1, 0, count - 1)
        }

        mutating func assign(_ value: Int, _ left: Int, _ right: Int) {
            assign(value, left, right, 1, 0, count - 1)
        }

        private mutating func apply(_ value: Int, _ node: Int) {
            maximums[node] = value
            assigned[node] = value
        }

        private mutating func push(_ node: Int) {
            guard let value = assigned[node] else { return }
            apply(value, 2 * node)
            apply(value, 2 * node + 1)
            assigned[node] = nil
        }

        private mutating func maximum(_ left: Int, _ right: Int, _ node: Int, _ low: Int, _ high: Int) -> Int {
            if right < low || high < left { return 0 }
            if left <= low && high <= right { return maximums[node] }
            push(node)
            let mid = (low + high) / 2
            return max(maximum(left, right, 2 * node, low, mid), maximum(left, right, 2 * node + 1, mid + 1, high))
        }

        private mutating func assign(_ value: Int, _ left: Int, _ right: Int, _ node: Int, _ low: Int, _ high: Int) {
            if right < low || high < left { return }
            if left <= low && high <= right {
                apply(value, node)
                return
            }
            push(node)
            let mid = (low + high) / 2
            assign(value, left, right, 2 * node, low, mid)
            assign(value, left, right, 2 * node + 1, mid + 1, high)
            maximums[node] = max(maximums[2 * node], maximums[2 * node + 1])
        }
    }
}
```

The gaps are what make "touching doesn't count" work for free: a crate ending at 5 and one starting at 5 cover different gaps. Because a crate's top is at least as high as everything under it, the assignment is also "raise to at least this", and such tags commute, so a version that never pushes tags at all also works.

</Approach>
