A tally counts how many times each element appears, like votes or ingredients. Make `Tally` buildable straight from literals, so `let votes: Tally = ["yes", "no", "yes"]` and `let stock: Tally = ["egg": 6, "milk": 1]` both work, and write the methods that read it.

`TallyLiterals.Tally<Element: Hashable>`, with `init(arrayLiteral:)`, `init(dictionaryLiteral:)`, `add(_:times:)`, `count(of:)`, `total`, `distinctCount`, `elements`, `mostCommon` and `merged(with:)`

The starter code already declares the conformances to `ExpressibleByArrayLiteral` and `ExpressibleByDictionaryLiteral`. Fill in:

- **`init(arrayLiteral:)`** counts each element once per appearance.
- **`init(dictionaryLiteral:)`** adds each count. Counts of zero or less are ignored, and a repeated key adds up.
- **`add(_:times:)`** adds `times` (1 by default) to an element's count, ignoring zero or negative `times`.
- **`count(of:)`** is an element's count, 0 if it was never counted. **`total`** is the sum of every count, and **`distinctCount`** the number of different elements.
- **`elements`** lists the different elements in the order each was first counted.
- **`mostCommon`** is the element with the highest count; on a tie, the one counted first. It's `nil` for an empty tally.
- **`merged(with:)`** returns a new tally holding both tallies' counts. Elements keep their first-arrival order, this tally's elements first.

## Examples

| Code | Result |
| --- | --- |
| `let t: Tally = ["tea", "coffee", "tea", "juice", "tea"]` | `t.count(of: "tea")` is 3; `t.elements` is `["tea", "coffee", "juice"]` |
| `let s: Tally = ["red": 3, "blue": 1, "green": 0]` | `s.total` is 4; `s.elements` is `["red", "blue"]` |
| `let n: Tally<Int> = [7: 2, 3: 1, 7: 5]` | `n.count(of: 7)` is 7 |
| `(["b", "a", "a", "b", "c"] as Tally).mostCommon` | `"b"` (tied with `"a"`, but counted first) |
| `(["a", "b"] as Tally).merged(with: ["c": 1, "b": 2])` | counts a 1, b 3, c 1, in the order a, b, c |
| `let e: Tally<String> = []` | `e.mostCommon` is `nil` |

## Constraints

- Up to 100,000 elements counted.
- Counts and totals stay well within `Int`.

<Hints>
<Hint>
Keep a `[Element: Int]` dictionary for the counts and an `[Element]` array for the order elements first arrived. Append to the array only when an element's count is still missing from the dictionary.
</Hint>
<Hint>
Write `add(_:times:)` first, with every rule in it. Then each literal initialiser is a loop calling `add`: inside `init(arrayLiteral elements: Element...)`, `elements` is an ordinary array, and the dictionary version receives an array of `(Element, Int)` pairs.
</Hint>
<Hint>
For `mostCommon`, walk `elements` in order and replace the best so far only when a count is strictly higher. Ties then keep the earlier element.
</Hint>

## Solutions

<Approach title="Both literals feed one add method" time="O(1) per add, O(d) for mostCommon and merged" space="O(d)">

A literal is only a convenient way to call an initialiser. Both initialisers pass their elements to `add`, so the rules about ignored counts and first-arrival order live in one place. Here d is the number of distinct elements.

```swift
public enum TallyLiterals {
    public struct Tally<Element: Hashable>: ExpressibleByArrayLiteral, ExpressibleByDictionaryLiteral {
        private var counts: [Element: Int] = [:]
        public private(set) var elements: [Element] = []

        public init() {}

        public init(arrayLiteral elements: Element...) {
            for element in elements {
                add(element)
            }
        }

        public init(dictionaryLiteral pairs: (Element, Int)...) {
            for (element, times) in pairs {
                add(element, times: times)
            }
        }

        public mutating func add(_ element: Element, times: Int = 1) {
            guard times > 0 else {
                return
            }
            if counts[element] == nil {
                elements.append(element)
            }
            counts[element, default: 0] += times
        }

        public func count(of element: Element) -> Int {
            counts[element] ?? 0
        }

        public var total: Int {
            counts.values.reduce(0, +)
        }

        public var distinctCount: Int {
            elements.count
        }

        public var mostCommon: Element? {
            var best: Element?
            var bestCount = 0
            for element in elements where count(of: element) > bestCount {
                best = element
                bestCount = count(of: element)
            }
            return best
        }

        public func merged(with other: Tally) -> Tally {
            var result = self
            for element in other.elements {
                result.add(element, times: other.count(of: element))
            }
            return result
        }
    }
}
```

Inside the struct, `Tally` on its own means `Tally<Element>`, which is why `merged(with:)` can accept a dictionary literal argument: Swift knows the parameter's type, so it builds a `Tally<String>` from `["c": 1, "b": 2]` directly.

</Approach>
