A file browser filters names with wildcard patterns. In a pattern, `?` matches exactly one character and `*` matches any sequence of characters, including none; every other character matches itself. Return whether the pattern matches the **whole** text.

`WildcardPatternMatcher.matches(_ text: String, pattern: String) -> Bool`

## Examples

| `text` | `pattern` | Output |
| --- | --- | --- |
| `"report.swift"` | `"*.swift"` | `true` |
| `"report.swift"` | `"*.sw?ft"` | `true` |
| `"report.swift"` | `"*.md"` | `false` |
| `"swiftly"` | `"s*t"` | `false` |
| `"abc"` | `"a**c"` | `true` |
| `""` | `"***"` | `true` |
| `""` | `"?"` | `false` |
| `"a"` | `""` | `false` |

`"s*t"` fails on `"swiftly"` because the text must end in t. Stars can match nothing, so any number of them matches the empty text, but `?` always needs a character.

## Constraints

- `text` has 0 to 700 characters and contains no `?` or `*`.
- `pattern` has 0 to 250 characters: letters, digits, punctuation, `?` and `*`.
- The tests include patterns such as `"*a*a*a*a*a*a*b"` against 700 a's, where plain recursion tries an astronomical number of ways to share the a's between the stars.

<Hints>
<Hint>
Let `M(i, j)` say whether the first i characters of the text match the first j of the pattern. `M(0, 0)` is true, and `M(i, 0)` is false for i > 0.
</Hint>
<Hint>
For a star at `pattern[j - 1]`: it matches nothing, `M(i, j - 1)`, or it takes `text[i - 1]` and stays available, `M(i - 1, j)`. For `?` or an equal character: `M(i - 1, j - 1)`.
</Hint>
<Hint>
The empty-text row, `M(0, j)`, is true while the pattern so far is all stars. If you apply the star rule with the guard `i > 0` on the "take a character" option, it fills that row correctly without special code.
</Hint>
</Hints>

## Solutions

<Approach title="Plain recursion" time="exponential" space="O(n + m)">

At a star, try "match nothing" and "take one more character". It's short and clearly right, and the tests compare against it on thousands of tiny cases, but with several stars and no match it repeats the same `(i, j)` questions over and over.

</Approach>

<Approach title="DP on prefixes, two rows" time="O(n · m)" space="O(m)">

Each row reads only itself and the row above, so two rows are enough.

```swift
public enum WildcardPatternMatcher {
    public static func matches(_ text: String, pattern: String) -> Bool {
        let t = Array(text), p = Array(pattern)
        var previous = Array(repeating: false, count: p.count + 1)       // row i - 1
        var current = previous
        for i in 0...t.count {
            for j in 0...p.count {
                if j == 0 {
                    current[j] = i == 0
                } else if p[j - 1] == "*" {
                    current[j] = current[j - 1] || (i > 0 && previous[j])
                } else if i > 0 && (p[j - 1] == "?" || p[j - 1] == t[i - 1]) {
                    current[j] = previous[j - 1]
                } else {
                    current[j] = false
                }
            }
            swap(&previous, &current)
        }
        return previous[p.count]
    }
}
```

The `else` that sets `false` matters here: `current` is reused, so every cell must be written on every row.

</Approach>
