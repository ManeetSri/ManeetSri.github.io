A Sudoku generator removes clues from a full grid one at a time, and after each removal asks one question: does the puzzle still have exactly one solution? Write that check, and the stricter test for a finished puzzle: is it **minimal**, so that every clue is needed?

`SudokuSolutionCount.solutions(_ rows: [String], limit: Int) -> Int` and `SudokuSolutionCount.isMinimal(_ rows: [String]) -> Bool`

The grid is 9 strings of 9 characters, one per row: `"1"` to `"9"` for a clue and `"."` for an empty cell. A solution fills every empty cell so that each row, column and 3 × 3 box holds every digit once, keeping the clues.

- `solutions` returns the number of solutions, but stops counting at `limit`: if there are more, it returns `limit`. Clues that already break the rules (two 5s in one row, say) mean 0.
- `isMinimal` is true when the puzzle has exactly one solution and removing **any one** of its clues allows a second.

## Examples

The puzzle the lesson's generator made from seed 74:

```text
5 . . . . . 7 4 .
. 4 . . . 2 . 1 .
. 6 . . . . . . 5
. 1 6 . 7 . 9 . .
. 3 . . . . . 8 7
. . . 8 4 . . . .
. . . . . 9 1 3 .
. . . . 8 1 . . .
. 2 . . . . . . .
```

| Grid | `solutions(grid, limit: 2)` | `isMinimal(grid)` | Why |
| --- | --- | --- | --- |
| the puzzle above | `1` | `true` | unique, and each of its 23 clues is needed |
| the puzzle without its top-left `5` | `2` | `false` | more than one solution: counting stopped at 2 |
| the puzzle with a `9` added at row 0, column 1 | `1` | `false` | still unique, but the new clue isn't needed |
| the puzzle with an `8` added at row 0, column 1 | `0` | `false` | it clashes with no clue directly, but no solution has an 8 there |
| nine rows of `"........."` | `2` | `false` | billions of solutions, and the count stops at the second |
| a first row starting `"55"` | `0` | `false` | the clues break the rules |
| a solved grid with an unavoidable rectangle blanked | `2` | `false` | four cells whose two digits can swap; `limit: 10` still gives 2 |

## Constraints

- `rows` is always 9 strings of 9 characters from `1` to `9` and `.`.
- `1 ≤ limit ≤ 1,000`.
- Puzzles in the tests can have anywhere from 17 to 81 clues; each call should take well under a second in a debug build.

<Hints>
<Hint>
Keep a bitmask of used digits for each row, column and box: bit `d` set means digit `d` is already there. A cell's candidates are `~(row | column | box)` limited to bits 1 to 9, and placing or removing a digit flips one bit in three masks. Reject clashing clues while you place the givens.
</Hint>
<Hint>
Search with backtracking, but always branch on the empty cell with the **fewest** candidates. A cell with none means this branch is dead; a cell with one is forced. This "fail first" choice is what makes even the empty grid fast.
</Hint>
<Hint>
Pass the remaining budget down: `found += count(limit: limit - found)`, and stop trying digits once `found` reaches `limit`. For `isMinimal`, blank each clue in turn and ask for `solutions(..., limit: 2)`: any answer of 1 means that clue wasn't needed.
</Hint>
</Hints>

## Solutions

<Approach title="Bitmask board, most-constrained cell, a counting budget" time="Exponential in the worst case; milliseconds in practice" space="O(81)">

The board is three arrays of nine masks. The search places and removes digits in place, so there's no copying, and its depth is at most the number of empty cells, so recursion is safe.

```swift
public enum SudokuSolutionCount {
    public static func solutions(_ rows: [String], limit: Int) -> Int {
        guard limit > 0, var board = Board(rows) else { return 0 }
        return board.count(limit: limit)
    }

    public static func isMinimal(_ rows: [String]) -> Bool {
        guard solutions(rows, limit: 2) == 1 else { return false }
        var grid = rows.map { Array($0) }
        for r in 0..<9 {
            for c in 0..<9 where grid[r][c] != "." {
                let clue = grid[r][c]
                grid[r][c] = "."
                let stillUnique = solutions(grid.map { String($0) }, limit: 2) == 1
                grid[r][c] = clue
                if stillUnique { return false }                 // that clue wasn't needed
            }
        }
        return true
    }

    private struct Board {
        var cells = [Int](repeating: 0, count: 81)              // 0 means empty
        var rowUsed = [Int](repeating: 0, count: 9)             // bit d set: digit d is in that row
        var columnUsed = [Int](repeating: 0, count: 9)
        var boxUsed = [Int](repeating: 0, count: 9)

        /// Nil when the grid isn't 9 × 9 of "1"..."9" and ".", or when two givens clash.
        init?(_ rows: [String]) {
            guard rows.count == 9 else { return nil }
            for (r, row) in rows.enumerated() {
                let characters = Array(row)
                guard characters.count == 9 else { return nil }
                for (c, character) in characters.enumerated() where character != "." {
                    guard let digit = character.wholeNumberValue, (1...9).contains(digit),
                          character.isASCII, candidates(r * 9 + c) & (1 << digit) != 0 else { return nil }
                    place(digit, at: r * 9 + c)
                }
            }
        }

        func candidates(_ cell: Int) -> Int {
            let r = cell / 9, c = cell % 9
            return ~(rowUsed[r] | columnUsed[c] | boxUsed[r / 3 * 3 + c / 3]) & 0b11_1111_1110
        }

        mutating func place(_ digit: Int, at cell: Int) {
            let r = cell / 9, c = cell % 9
            cells[cell] = digit
            rowUsed[r] |= 1 << digit
            columnUsed[c] |= 1 << digit
            boxUsed[r / 3 * 3 + c / 3] |= 1 << digit
        }

        mutating func remove(_ digit: Int, at cell: Int) {
            let r = cell / 9, c = cell % 9
            cells[cell] = 0
            rowUsed[r] &= ~(1 << digit)
            columnUsed[c] &= ~(1 << digit)
            boxUsed[r / 3 * 3 + c / 3] &= ~(1 << digit)
        }

        /// Counts completions, stopping at `limit`. Depth is at most 81, so recursion is safe.
        mutating func count(limit: Int) -> Int {
            var best = -1
            var bestMask = 0
            var fewest = 10
            for cell in 0..<81 where cells[cell] == 0 {
                let mask = candidates(cell)
                let options = mask.nonzeroBitCount
                if options < fewest {
                    (best, bestMask, fewest) = (cell, mask, options)
                    if options == 0 { return 0 }                 // a dead end: no digit fits here
                }
            }
            if best == -1 { return 1 }                           // no empty cell left: one solution
            var found = 0
            var mask = bestMask
            while mask != 0 && found < limit {
                let digit = mask.trailingZeroBitCount
                mask &= mask - 1
                place(digit, at: best)
                found += count(limit: limit - found)
                remove(digit, at: best)
            }
            return found
        }
    }
}
```

`isMinimal` is the definition run directly: one count per clue, each with a limit of 2. It also explains why the lesson's generator needs only one pass over the cells: removing clues can only add solutions, never take them away, so a clue that was needed when the generator tried to remove it is still needed in the finished puzzle. The lesson's solver adds constraint propagation (hidden singles) on top of this, which cuts the number of guesses further on the hardest puzzles.

</Approach>
