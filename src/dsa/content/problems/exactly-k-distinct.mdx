Count the contiguous subarrays of `values` that contain **exactly** `k` different values.

`ExactlyKDistinct.count(_ values: [Int], k: Int) -> Int`

## Examples

| `values` | `k` | Output |
| --- | --- | --- |
| `[4, 4, 7, 4, 9]` | `2` | `6` |
| `[3, 1, 3, 2, 1]` | `3` | `5` |
| `[5, 5, 5]` | `1` | `6` |
| `[1, 2, 3]` | `4` | `0` |

In the first example, the six subarrays are `[4, 7]`, `[4, 4, 7]`, `[7, 4]`, `[4, 7, 4]`, `[4, 4, 7, 4]` and `[4, 9]`. In the third, every one of the six subarrays has exactly one distinct value.

## Constraints

- `1 ≤ values.count ≤ 100,000`
- `1 ≤ k ≤ values.count`
- `-10⁹ ≤ values[i] ≤ 10⁹`
- The answer can be as large as about 5 × 10⁹, which fits in an `Int`.

<Hints>
<Hint>
A plain sliding window struggles with "exactly": for a fixed right end, the left ends that give exactly `k` distinct values form a range in the middle, not everything from some point on. "At most `k`" is much friendlier.
</Hint>
<Hint>
Count subarrays with **at most** `k` distinct values: grow on the right, shrink from the left while there are more than `k` distinct values, then every subarray ending at `right` and starting anywhere in `left...right` is valid. That's `right - left + 1` of them.
</Hint>
<Hint>
Subarrays with exactly `k` distinct values are the ones with at most `k`, minus the ones with at most `k - 1`.
</Hint>
</Hints>

## Solutions

<Approach title="Every start" time="O(n²)" space="O(n)">

From each start, extend to the right with a set of the values seen, counting each end where the set has exactly `k` values. It's a good brute force, and about 5 billion steps for 100,000 values.

```swift
public static func count(_ values: [Int], k: Int) -> Int {
    var total = 0
    for start in values.indices {
        var seen = Set<Int>()
        for end in start..<values.count {
            seen.insert(values[end])
            if seen.count == k { total += 1 }
            if seen.count > k { break }
        }
    }
    return total
}
```

</Approach>

<Approach title="At most k, minus at most k − 1" time="O(n)" space="O(k)">

`atMost` is a standard variable window with a dictionary of counts. Removing a key when its count reaches zero keeps `counts.count` equal to the number of distinct values in the window.

```swift
public enum ExactlyKDistinct {
    public static func count(_ values: [Int], k: Int) -> Int {
        atMost(values, k) - atMost(values, k - 1)
    }

    private static func atMost(_ values: [Int], _ k: Int) -> Int {
        guard k > 0 else { return 0 }
        var counts: [Int: Int] = [:]
        var left = 0
        var total = 0
        for right in 0..<values.count {
            counts[values[right], default: 0] += 1
            while counts.count > k {
                let leaving = values[left]
                counts[leaving, default: 0] -= 1
                if counts[leaving] == 0 {
                    counts[leaving] = nil
                }
                left += 1
            }
            total += right - left + 1
        }
        return total
    }
}
```

Each call makes one pass with both pointers moving forward, so two calls are still O(n). Dictionary operations are O(1) on average.

</Approach>
