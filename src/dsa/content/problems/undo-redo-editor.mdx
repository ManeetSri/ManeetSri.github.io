Build a text buffer with undo and redo, the way a notes app or code editor works. Edits insert or delete text anywhere. Undo steps back through the edits, redo steps forward again, and a new edit after some undos throws away what could have been redone. The history can be limited, and it must never store a copy of the whole text per edit.

`UndoRedoEditor.Editor`, with `init(undoLimit:)`, `text`, `canUndo`, `canRedo`, `insert(_:at:)`, `delete(from:count:)`, `undo() -> Bool` and `redo() -> Bool`

- Offsets count `Character`s from the start of the text.
- `insert(text, at: offset)` inserts so the new text starts at `offset` (0 to the current length). `delete(from: offset, count: n)` removes `n` characters starting at `offset`. Inserting `""` or deleting 0 characters changes nothing and is not an edit.
- `undo()` reverts the most recent edit that hasn't been undone and returns `true`, or returns `false` if there's none. `redo()` re-applies the most recently undone edit, or returns `false`. Both results are discardable.
- Any new edit empties the redo history.
- `init(undoLimit: Int = .max)`: only the most recent `undoLimit` edits can be undone; older ones are forgotten. A limit of 0 means nothing can be undone.

## Examples

With `var editor = Editor()`:

| Calls | `text` afterwards |
| --- | --- |
| `insert("Hello", at: 0)`, `insert(", world", at: 5)` | `"Hello, world"` |
| `delete(from: 5, count: 7)` | `"Hello"` |
| `undo()` | `"Hello, world"` |
| `undo()` | `"Hello"` |
| `redo()` | `"Hello, world"` |
| `insert("!", at: 12)`, then `redo()` | `"Hello, world!"`, and `redo()` returns `false` |

With `Editor(undoLimit: 2)`: insert "a", "b" and "c" at the end, then undo three times. The first two undos give `"ab"` and `"a"`; the third returns `false`, because the first edit fell off the history.

## Constraints

- Up to 100,000 edits; the text is made of ASCII characters.
- Offsets and counts are always in range.
- One test types 100,000 single characters, undoes them all and redoes them all.
- `Editor` is a struct: a copy is an independent editor with its own history.

<Hints>
<Hint>
Store the text as `[Character]`, so offsets are plain array indexes. Represent each edit as a value that knows how to apply itself: an `enum Edit` with `case insert(text:offset:)` and `case delete(text:offset:)`. A delete records the text it removed: that's what undo needs to put back.
</Hint>
<Hint>
Every edit has an inverse: an insert is undone by deleting the same text at the same offset, and a delete by inserting it back. Keep two stacks. A new edit is applied, pushed onto the undo stack, and the redo stack is emptied. Undo pops from the undo stack, applies the inverse, and pushes the edit onto the redo stack. Redo does the opposite.
</Hint>
<Hint>
For the limit, the oldest edit has to leave from the **bottom** of the undo stack. An array's `removeFirst()` is O(n); DSAKit's `Deque` has O(1) `popFirst()` and `popLast()`: `import DSAKit`.
</Hint>
</Hints>

## Solutions

<Approach title="A snapshot of the text per edit" time="O(text length) per edit" space="O(text length × edits)">

Push a copy of the whole text before every edit; undo swaps the current text with the top copy. It's the easiest to get right, and fine for short texts. Typing 100,000 characters one at a time stores 100,000 copies averaging 50,000 characters each: 5 billion characters.

```swift
public mutating func insert(_ text: String, at offset: Int) {
    guard !text.isEmpty else { return }
    undoTexts.append(buffer)               // O(n) copy, every time
    redoTexts.removeAll()
    buffer.insert(contentsOf: text, at: offset)
}
```

</Approach>

<Approach title="Commands on two stacks" time="O(size of the edit) per edit, undo and redo" space="O(total edited text)">

This is the **command pattern**: each edit is an object (here an enum value) that can be applied and inverted, so the history stores what changed rather than what everything looked like. Undo and redo cost the same as the edit itself.

```swift
import DSAKit

public enum UndoRedoEditor {
    public struct Editor {
        private enum Edit {
            case insert(text: [Character], offset: Int)
            case delete(text: [Character], offset: Int)

            var inverse: Edit {
                switch self {
                case let .insert(text, offset): return .delete(text: text, offset: offset)
                case let .delete(text, offset): return .insert(text: text, offset: offset)
                }
            }
        }

        private var buffer: [Character] = []
        private var undoStack = Deque<Edit>()          // newest at the back
        private var redoStack: [Edit] = []
        private let undoLimit: Int

        public init(undoLimit: Int = .max) {
            precondition(undoLimit >= 0, "The undo limit can't be negative")
            self.undoLimit = undoLimit
        }

        public var text: String {
            String(buffer)
        }

        public var canUndo: Bool {
            !undoStack.isEmpty
        }

        public var canRedo: Bool {
            !redoStack.isEmpty
        }

        public mutating func insert(_ text: String, at offset: Int) {
            precondition(offset >= 0 && offset <= buffer.count, "Offset \(offset) is outside the text")
            guard !text.isEmpty else { return }
            record(.insert(text: Array(text), offset: offset))
        }

        public mutating func delete(from offset: Int, count: Int) {
            precondition(offset >= 0 && count >= 0 && offset + count <= buffer.count, "The range is outside the text")
            guard count > 0 else { return }
            record(.delete(text: Array(buffer[offset..<offset + count]), offset: offset))
        }

        @discardableResult
        public mutating func undo() -> Bool {
            guard let edit = undoStack.popLast() else { return false }
            apply(edit.inverse)
            redoStack.append(edit)
            return true
        }

        @discardableResult
        public mutating func redo() -> Bool {
            guard let edit = redoStack.popLast() else { return false }
            apply(edit)
            undoStack.append(edit)                     // room is guaranteed: undo made it
            return true
        }

        private mutating func record(_ edit: Edit) {
            apply(edit)
            redoStack.removeAll()                      // the undone future can't be reached any more
            undoStack.append(edit)
            if undoStack.count > undoLimit {
                undoStack.popFirst()                   // forget the oldest step
            }
        }

        private mutating func apply(_ edit: Edit) {
            switch edit {
            case let .insert(text, offset):
                buffer.insert(contentsOf: text, at: offset)
            case let .delete(text, offset):
                buffer.removeSubrange(offset..<offset + text.count)
            }
        }
    }
}
```

Everything inside `Editor` is a value (arrays, a deque, enums), so copying an editor copies its history too, and the two never interfere.

</Approach>
