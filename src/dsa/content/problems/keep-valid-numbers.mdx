A form was filled in row by row, and some entries aren't numbers. Return every entry, from every row, that converts to an `Int`, in order: row by row, left to right.

`KeepValidNumbers.validNumbers(in rows: [[String]]) -> [Int]`

An entry counts as valid exactly when `Int(entry)` isn't `nil`. So `"+4"` and `"007"` are valid, while `"4.5"`, `" 5"` (with a space) and `""` aren't.

## Examples

| `rows` | Returns |
| --- | --- |
| `[["12", "seven", "5"], ["", "40"], ["-3", "x"]]` | `[12, 5, 40, -3]` |
| `[["+4", "4.5"], ["007"]]` | `[4, 7]` |
| `[["a", "b"], []]` | `[]` |
| `[]` | `[]` |

## Constraints

- At most 1,000 rows, and at most 100,000 entries in total.
- Each entry has at most 20 characters.
- Numbers that don't fit in an `Int` aren't valid, which `Int(_:)` already handles for you.

<Hints>
<Hint>
There are two jobs: get rid of the rows, so you have one flat list of entries, and convert the entries, dropping the ones that fail.
</Hint>
<Hint>
`flatMap { $0 }` flattens an array of arrays. `compactMap { Int($0) }` converts and drops the `nil`s. Chain them.
</Hint>
</Hints>

## Solutions

<Approach title="Nested loops" time="O(c)" space="O(n)">

Here c is the total number of characters, since converting an entry reads each of its characters. Loop over the rows, then over each row's entries, and append every entry that converts. `if let` keeps only the successes.

```swift
public static func validNumbers(in rows: [[String]]) -> [Int] {
    var numbers: [Int] = []
    for row in rows {
        for entry in row {
            if let number = Int(entry) {
                numbers.append(number)
            }
        }
    }
    return numbers
}
```

</Approach>

<Approach title="flatMap, then compactMap" time="O(c)" space="O(n)">

The same work in one line: flatten the rows, then convert and drop the failures. Each tool does exactly one of the two jobs.

```swift
public enum KeepValidNumbers {
    public static func validNumbers(in rows: [[String]]) -> [Int] {
        rows.flatMap { $0 }.compactMap { Int($0) }
    }
}
```

`rows.joined().compactMap { Int($0) }` works too. `joined()` flattens without building the intermediate array of entries.

</Approach>
