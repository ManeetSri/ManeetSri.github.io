Decide whether a string can read the same forwards and backwards after deleting **at most one** character. A string that's already a palindrome counts. Every character counts, including spaces and punctuation, and uppercase and lowercase letters are different.

`PalindromeOneDeletion.isAlmostPalindrome(_ text: String) -> Bool`

## Examples

| Input | Output | Why |
| --- | --- | --- |
| `"racecar"` | `true` | already a palindrome |
| `"kayaks"` | `true` | delete the final `s` |
| `"abccbxa"` | `true` | delete the `x` |
| `"cbbcc"` | `true` | delete the last `c`, leaving `cbbc` |
| `"abcda"` | `false` | `b` and `d` don't match, and neither deletion fixes it |
| `"Aba"` | `false` | `A` and `a` are different characters |
| `""` | `true` | |

## Constraints

- `0 ≤ text.count ≤ 100,000`
- Aim for O(n) time. Trying every deletion and checking the rest is O(n²), up to 10¹⁰ steps.

<Hints>
<Hint>
Start like a normal palindrome check, with two pointers on `Array(text)` moving inwards. While the characters match, there's nothing to decide.
</Hint>
<Hint>
At the first mismatch, the deletion has to remove one of the two mismatched characters: anything outside them already matches its partner. So there are only two options left.
</Hint>
<Hint>
Write a helper that checks whether `characters[low...high]` is a palindrome. At the first mismatch, return `isPalindrome(left + 1, right) || isPalindrome(left, right - 1)`. Test a case where only the left deletion works, and one where only the right does.
</Hint>
</Hints>

## Solutions

<Approach title="Try every deletion" time="O(n²)" space="O(n)">

Check the string as it is, then with each character removed in turn. It's a reliable oracle for testing, but each check is O(n), and there are n of them.

```swift
public static func isAlmostPalindrome(_ text: String) -> Bool {
    let characters = Array(text)
    if characters == Array(characters.reversed()) {
        return true
    }
    for skip in characters.indices {
        var shorter = characters
        shorter.remove(at: skip)
        if shorter == Array(shorter.reversed()) {
            return true
        }
    }
    return false
}
```

</Approach>

<Approach title="Two pointers, two chances at the first mismatch" time="O(n)" space="O(n)">

Matching pairs on the outside are settled: deleting one of them would only break a match. So the first mismatch is where the deletion must happen, and it must remove `characters[left]` or `characters[right]`. Each option leaves a middle part that must be a palindrome with no further deletions.

```swift
public enum PalindromeOneDeletion {
    public static func isAlmostPalindrome(_ text: String) -> Bool {
        let characters = Array(text)

        func isPalindrome(_ low: Int, _ high: Int) -> Bool {
            var left = low
            var right = high
            while left < right {
                if characters[left] != characters[right] {
                    return false
                }
                left += 1
                right -= 1
            }
            return true
        }

        var left = 0
        var right = characters.count - 1
        while left < right {
            if characters[left] != characters[right] {
                return isPalindrome(left + 1, right) || isPalindrome(left, right - 1)
            }
            left += 1
            right -= 1
        }
        return true
    }
}
```

The main loop and the helper together look at each character a constant number of times, so it's O(n). Trying only one of the two deletions is a classic mistake: `"cbbcc"` needs the right one, and `"ccbbc"` needs the left.

</Approach>
