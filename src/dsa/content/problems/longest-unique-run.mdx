Return the length of the longest stretch of consecutive characters in `text` in which no character appears twice.

`LongestUniqueRun.length(of text: String) -> Int`

## Examples

| `text` | Output |
| --- | --- |
| `"streets"` | `4` |
| `"mississippi"` | `3` |
| `"abba"` | `2` |
| `"aaaa"` | `1` |
| `""` | `0` |
| `"a😀b😀"` | `3` |

In `"streets"` the longest run is `"stre"`. In `"abba"`, both `"ab"` and `"ba"` work, but `"abba"` repeats both letters. The last example counts whole characters: the emoji is one character.

## Constraints

- `0 ≤ text.count ≤ 100,000`
- `text` can contain any characters, including emoji.

<Hints>
<Hint>
Keep a window `left...right` that never contains a repeat. Move `right` forward one character at a time. When the new character is already in the window, the window must shrink from the left until it isn't.
</Hint>
<Hint>
A `Set<Character>` of the window's characters tells you whether the new one is already inside. Remove `chars[left]` and move `left` forward until it's gone.
</Hint>
<Hint>
For a single jump instead of a loop, store the index where each character was last seen. If that index is inside the window (at least `left`), set `left` to one past it. Don't let `left` move backwards.
</Hint>
</Hints>

## Solutions

<Approach title="Every start, extended until a repeat" time="O(n · k)" space="O(k)">

From each start, add characters to a set until one is already there. Here k is the number of distinct characters. With few distinct characters that's quick, but with 20,000 different characters in a row it's hundreds of millions of steps.

```swift
public static func length(of text: String) -> Int {
    let chars = Array(text)
    var best = 0
    for start in chars.indices {
        var seen = Set<Character>()
        for end in start..<chars.count {
            if !seen.insert(chars[end]).inserted { break }
            best = max(best, end - start + 1)
        }
    }
    return best
}
```

</Approach>

<Approach title="Sliding window with a set" time="O(n)" space="O(k)">

The window grows on the right. When the new character is already inside, characters leave on the left until the old copy is gone. `left` only ever moves forward, so each character enters once and leaves at most once.

```swift
public static func length(of text: String) -> Int {
    let chars = Array(text)
    var seen = Set<Character>()
    var left = 0
    var best = 0
    for right in 0..<chars.count {
        while seen.contains(chars[right]) {
            seen.remove(chars[left])
            left += 1
        }
        seen.insert(chars[right])
        best = max(best, right - left + 1)
    }
    return best
}
```

</Approach>

<Approach title="Jump with last-seen indexes" time="O(n)" space="O(k)">

Instead of removing characters one at a time, remember where each character was last seen. If the new character's last position is inside the window, the window must start immediately after it.

```swift
public enum LongestUniqueRun {
    public static func length(of text: String) -> Int {
        let chars = Array(text)
        var lastSeen: [Character: Int] = [:]
        var left = 0
        var best = 0
        for right in 0..<chars.count {
            if let previous = lastSeen[chars[right]], previous >= left {
                left = previous + 1
            }
            lastSeen[chars[right]] = right
            best = max(best, right - left + 1)
        }
        return best
    }
}
```

The check `previous >= left` matters. In `"abba"`, the last `a` was seen at index 0, but by then `left` is 2. Without the check, `left` would jump back to 1 and the window `"bba"` would be counted.

</Approach>
