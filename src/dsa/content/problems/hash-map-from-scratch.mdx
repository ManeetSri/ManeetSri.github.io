Build a generic hash map yourself, using separate chaining, without `Dictionary` or `Set`.

`HashMapFromScratch.Map<Key: Hashable, Value>`, with `init()`, `subscript(key: Key) -> Value?` (get and set), `removeValue(forKey:) -> Value?`, `count: Int`, `isEmpty: Bool`, `bucketCount: Int` and `keys: [Key]`

The rules:

- Store entries in buckets: an array where each element is a list of key-value pairs.
- Start with **8 buckets**.
- Reading a missing key gives `nil`. Assigning a value to an existing key replaces it. Assigning `nil` removes the key.
- `removeValue(forKey:)` removes the key and returns its value, or returns `nil` if it wasn't there.
- After inserting a **new** key, if `count > bucketCount * 3 / 4`, double the number of buckets and move every entry into its new bucket. Replacing a value never grows the map.
- Never shrink.
- `keys` returns every key, in any order.

## Examples

| Code | Result |
| --- | --- |
| `var m = Map<String, Int>()`, then `m.bucketCount` | `8` |
| `m["apple"] = 3; m["apple"] = 10`, then `m["apple"]` and `m.count` | `10` and `1` |
| `m["pear"] = 5; m["pear"] = nil`, then `m["pear"]` | `nil` |
| inserting keys 1 to 6 into a new map, then `bucketCount` | `8` (6 ≤ 6) |
| inserting keys 1 to 7 into a new map, then `bucketCount` | `16` (7 > 6) |
| inserting 20,000 keys, then `bucketCount` | `32768` |

## Constraints

- Up to 100,000 operations. Each should be O(1) on average.
- Keys may have terrible hash functions: the tests include a key type that only hashes `value % 4`, so most keys collide. Your map must still be correct.
- Copying a map must give an independent map, as with any struct.

<Hints>
<Hint>
Store `private var buckets: [[(key: Key, value: Value)]] = Array(repeating: [], count: 8)` and a separate count. A key's bucket is `key.hashValue & (buckets.count - 1)`: the bucket count is always a power of two, and masking never gives a negative index.
</Hint>
<Hint>
Every operation starts the same way: find the bucket, then use `firstIndex(where: { $0.key == key })` to find the entry inside it. Compare keys with `==`, never hash values.
</Hint>
<Hint>
To grow, build a new array with twice as many empty buckets and append every entry to the bucket computed with the **new** count. The old bucket positions are useless after the count changes.
</Hint>
</Hints>

## Solutions

<Approach title="Separate chaining with doubling" time="O(1) average per operation; amortised when growing" space="O(n)">

Each bucket is an array of named tuples. The setter handles all three cases: replace an existing key, append a new one (and maybe grow), or remove the key when assigned `nil`. Growing doubles the bucket count, so the rehashes form a geometric series and inserts stay O(1) amortised.

```swift
public enum HashMapFromScratch {
    public struct Map<Key: Hashable, Value> {
        private var buckets: [[(key: Key, value: Value)]] = Array(repeating: [], count: 8)
        private var storedCount = 0

        public init() {}

        public var count: Int { storedCount }
        public var isEmpty: Bool { storedCount == 0 }
        public var bucketCount: Int { buckets.count }

        private func index(for key: Key) -> Int {
            key.hashValue & (buckets.count - 1)
        }

        public subscript(key: Key) -> Value? {
            get {
                buckets[index(for: key)].first { $0.key == key }?.value
            }
            set {
                guard let newValue else {
                    removeValue(forKey: key)
                    return
                }
                let bucket = index(for: key)
                if let position = buckets[bucket].firstIndex(where: { $0.key == key }) {
                    buckets[bucket][position].value = newValue
                    return
                }
                buckets[bucket].append((key, newValue))
                storedCount += 1
                if storedCount > buckets.count * 3 / 4 {
                    resize()
                }
            }
        }

        @discardableResult
        public mutating func removeValue(forKey key: Key) -> Value? {
            let bucket = index(for: key)
            guard let position = buckets[bucket].firstIndex(where: { $0.key == key }) else {
                return nil
            }
            storedCount -= 1
            return buckets[bucket].remove(at: position).value
        }

        public var keys: [Key] {
            buckets.flatMap { bucket in bucket.map { $0.key } }
        }

        private mutating func resize() {
            var newBuckets = [[(key: Key, value: Value)]](repeating: [], count: buckets.count * 2)
            for bucket in buckets {
                for entry in bucket {
                    newBuckets[entry.key.hashValue & (newBuckets.count - 1)].append(entry)
                }
            }
            buckets = newBuckets
        }
    }
}
```

`remove(at:)` shifts the rest of the chain, but chains average less than one entry, so it's O(1) in practice. The lesson's swap-with-last trick avoids even that.

Value semantics come for free: `buckets` is an array, so copying a `Map` shares the storage until one copy changes, and then copy-on-write duplicates it.

</Approach>
