An arcade machine keeps a top-k leaderboard. Scores arrive one at a time, and after each one the machine shows the **kth highest score so far**: the score a new player has to beat to get onto the board. Duplicates count separately, so with scores 50, 50, 50 the second highest is 50. Until k scores have arrived, there's no kth highest, so report `nil`.

`StreamKthLargest.KthLargestTracker`, with `init(k: Int)` and `add(_ score: Int) -> Int?`

Aim for O(log k) per score and O(k) memory, however many scores arrive.

## Examples

Each row creates a tracker and adds the scores in order, writing down what each `add` returns (`#` for `nil`).

| `k` | Scores | Returns |
| --- | --- | --- |
| `3` | `40, 10, 70, 20, 90, 60` | `# # 10 20 40 60` |
| `1` | `5, 3, 8, 8, 1` | `5 5 8 8 8` |
| `2` | `50, 50, 50, 10` | `# 50 50 50` |
| `4` | `-5, -1, -9` | `# # #` |

In the first row, after 90 arrives the three highest are 90, 70 and 40, so the board's entry mark is 40.

## Constraints

- `1 ≤ k ≤ 200,000`
- Up to 200,000 calls to `add`, with any `Int` scores.
- The tests use k = 50,000 with 200,000 scores, so keeping a sorted array of the best k (O(k) per insert) or sorting on every call is too slow.

<Hints>
<Hint>
Only the k highest scores so far can ever matter. A score that isn't among them now never will be: every later score only pushes it further down.
</Hint>
<Hint>
Keep those k scores in a **min**-heap. Its top is the lowest of the k highest, which is exactly the kth highest overall.
</Hint>
<Hint>
While the heap has fewer than k scores, insert. After that, a new score only gets in if it beats the top: replace the top with it (`replaceTop(with:)` in DSAKit does that in one sift).
</Hint>
</Hints>

## Solutions

<Approach title="Sort everything on every call" time="O(n log n) per score" space="O(n)">

Correct, and handy for testing, but the work per call keeps growing with the stream.

```swift
public mutating func add(_ score: Int) -> Int? {
    all.append(score)
    return all.count < k ? nil : all.sorted(by: >)[k - 1]
}
```

</Approach>

<Approach title="A min-heap of the k highest" time="O(log k) per score" space="O(k)">

The heap never holds more than k scores. Its top is the doorkeeper: anything at or below it is turned away.

```swift
import DSAKit

public enum StreamKthLargest {
    public struct KthLargestTracker {
        private let k: Int
        private var best = Heap<Int>.minHeap()       // the k highest scores, lowest on top

        public init(k: Int) {
            self.k = k
        }

        public mutating func add(_ score: Int) -> Int? {
            if best.count < k {
                best.insert(score)
            } else if let lowest = best.peek(), score > lowest {
                best.replaceTop(with: score)
            }
            return best.count == k ? best.peek() : nil
        }
    }
}
```

A score equal to the top is turned away too: swapping it in would change nothing.

</Approach>
