A recording studio has one booth and too many booking requests. Cancel as few bookings as possible so that no two of the remaining bookings overlap, and return how many you cancelled.

`FewestCancellations.minimumCancellations(_ bookings: [[Int]]) -> Int`

Each booking is a half-open pair `[start, end)`: a booking that ends at 3 and one that starts at 3 can both stay.

## Examples

| `bookings` | Output | Why |
| --- | --- | --- |
| `[[0, 4], [3, 6], [5, 9], [8, 12]]` | `2` | keep `[0, 4]` and `[5, 9]`, for example |
| `[[1, 2], [2, 3], [3, 4]]` | `0` | they only touch |
| `[[1, 10], [2, 3], [4, 5], [6, 7]]` | `1` | cancel the long one |
| `[[5, 8], [5, 8], [5, 8]]` | `2` | only one copy can stay |
| `[]` | `0` | |

## Constraints

- `0 ≤ bookings.count ≤ 100,000`
- Each booking has `start < end`, with values between −10⁹ and 10⁹.
- Aim for O(n log n) time. There are 2ⁿ subsets of bookings to choose from.

<Hints>
<Hint>
Count the bookings you **keep** instead. The answer is `bookings.count` minus the most you can keep without overlaps.
</Hint>
<Hint>
Which booking is always safe to keep? Think about the one that frees the booth soonest, and what it leaves room for.
</Hint>
<Hint>
Sort by end. Keep a booking if it starts at or after the end of the last booking you kept (half-open, so `>=`), and cancel it otherwise. Starting `lastEnd` at `Int.min` lets the first booking through.
</Hint>
</Hints>

## Solutions

<Approach title="Try every subset" time="O(2ⁿ · n²)" space="O(n)">

Only for a handful of bookings, but it makes a perfect checker for the greedy version: test both on many small random inputs.

```swift
public static func minimumCancellations(_ bookings: [[Int]]) -> Int {
    let n = bookings.count
    var mostKept = 0
    for mask in 0..<(1 << n) {
        let chosen = (0..<n).filter { mask & (1 << $0) != 0 }.map { bookings[$0] }
        var clash = false
        for i in chosen.indices {
            for j in chosen.indices where j > i {
                if chosen[i][0] < chosen[j][1] && chosen[j][0] < chosen[i][1] {
                    clash = true
                }
            }
        }
        if !clash {
            mostKept = max(mostKept, chosen.count)
        }
    }
    return n - mostKept
}
```

</Approach>

<Approach title="Greedy: keep the booking that ends first" time="O(n log n)" space="O(n)">

Sort by end and keep every booking that fits after the last one kept. Why it's safe: take any best selection and look at its first booking. It ends no earlier than the earliest-ending booking overall, so swapping it for that one keeps the selection valid and the same size. Repeat the argument on what's left, and the greedy keeps as many as any best selection.

```swift
public enum FewestCancellations {
    public static func minimumCancellations(_ bookings: [[Int]]) -> Int {
        let sorted = bookings.sorted { $0[1] < $1[1] }
        var kept = 0
        var lastEnd = Int.min
        for booking in sorted where booking[0] >= lastEnd {
            kept += 1
            lastEnd = booking[1]
        }
        return bookings.count - kept
    }
}
```

Sorting by start instead fails on the third example: `[1, 10]` comes first, and keeping it blocks the three short bookings.

</Approach>
