Write a higher-order function: given a function `transform`, a count `n` and a starting `value`, apply `transform` to the value `n` times in a row, each time to the previous result, and return what you end up with.

`ApplyNTimes.apply(_ transform: (Int) -> Int, times n: Int, to value: Int) -> Int`

## Examples

| `transform` | `n` | `value` | Returns | Why |
| --- | --- | --- | --- | --- |
| doubles its input | `3` | `1` | `8` | 1 → 2 → 4 → 8 |
| adds 1 | `5` | `10` | `15` | adding 1 five times |
| squares its input | `2` | `3` | `81` | 3 → 9 → 81 |
| halves its input (integer division) | `4` | `100` | `6` | 100 → 50 → 25 → 12 → 6 |
| anything | `0` | `7` | `7` | applying zero times changes nothing |

You could call it with a function you've defined: given `func double(_ n: Int) -> Int { n * 2 }`, the call `ApplyNTimes.apply(double, times: 3, to: 1)` returns `8`.

## Constraints

- `0 ≤ n ≤ 1,000`
- Call `transform` exactly `n` times. The tests count the calls.
- The tests never make the result overflow.

<Hints>
<Hint>
`transform` is a value of type `(Int) -> Int`. You call it like any function: `transform(x)`.
</Hint>
<Hint>
Keep a `var result = value`, and replace it with `transform(result)` on each pass of a loop that runs `n` times. `for _ in 0..<n` runs zero times when `n` is 0.
</Hint>
</Hints>

## Solutions

<Approach title="A loop that feeds each result back in" time="O(n)" space="O(1)">

The loop runs `n` times, and each pass passes the latest result back into `transform`. When `n` is 0, the range `0..<0` is empty, so the original value comes straight back.

```swift
public enum ApplyNTimes {
    public static func apply(_ transform: (Int) -> Int, times n: Int, to value: Int) -> Int {
        var result = value
        for _ in 0..<n {
            result = transform(result)
        }
        return result
    }
}
```

The time is O(n) calls to `transform`, assuming each call is quick.

</Approach>

<Approach title="Recursively" time="O(n)" space="O(n)">

Applying `transform` n times is the same as applying it once, then applying it n − 1 more times. Zero times is the base case. This version uses O(n) stack space, so the loop is the better choice here, but it's good practice for the recursion lesson.

```swift
public static func apply(_ transform: (Int) -> Int, times n: Int, to value: Int) -> Int {
    if n == 0 {
        return value
    }
    return apply(transform, times: n - 1, to: transform(value))
}
```

</Approach>
