A search engine shortens words to their roots so that "sunflowers" and "sunny" can match each other. Given a list of roots and a sentence, replace every word with the shortest root it starts with. A word that starts with no root stays as it is.

`RootReplacement.replace(in sentence: String, roots: [String]) -> String`

A word starts with a root when its first letters spell the root exactly, so a word can't be replaced by a root longer than itself, and a word equal to a root stays the same.

## Examples

| `sentence` | `roots` | Output |
| --- | --- | --- |
| `"sunflowers bloom under the moonlight"` | `["sun", "su", "moon", "bl"]` | `"su bl under the moon"` |
| `"rebuild the rerun"` | `["re", "reb"]` | `"re the re"` |
| `"a ab abc"` | `["abc", "ab"]` | `"a ab ab"` |
| `"s su sun"` | `["sun"]` | `"s su sun"` |
| `"cats chase mice"` | `["dog"]` | `"cats chase mice"` |

In the first example, "sunflowers" starts with both "su" and "sun", and the shorter root wins.

## Constraints

- `sentence` holds 1 to 50,000 words of lowercase letters, separated by single spaces, with no spaces at either end.
- `0 ≤ roots.count ≤ 50,000`, and each root holds 1 to 100 lowercase letters. Roots may repeat.
- The tests use 50,000 roots and a sentence of 50,000 words.

<Hints>
<Hint>
Checking every root against every word is 50,000 × 50,000 comparisons: far too many. You want each word to cost about its own length.
</Hint>
<Hint>
Put the roots in a trie, marking the node where each root ends. Then walk each word down the trie from the root.
</Hint>
<Hint>
The first marked node you reach is the shortest root, so stop there and keep that many letters. If the walk falls off the trie (no child for the next letter) or the word runs out first, no root fits.
</Hint>
</Hints>

## Solutions

<Approach title="A set of roots, trying every prefix" time="O(total length of roots + Σ L²)" space="O(total length of roots)">

Put the roots in a `Set`. For each word, try its prefixes from shortest to longest and stop at the first one in the set. Each check builds and hashes a prefix of up to L letters, and a word has L prefixes, so a word costs O(L²). That's fine for short words.

```swift
public enum RootReplacement {
    public static func replace(in sentence: String, roots: [String]) -> String {
        let rootSet = Set(roots)
        let words = sentence.split(separator: " ")
        return words.map { word -> String in
            for length in 1...word.count where rootSet.contains(String(word.prefix(length))) {
                return String(word.prefix(length))
            }
            return String(word)
        }.joined(separator: " ")
    }
}
```

</Approach>

<Approach title="A trie of roots" time="O(total length of roots + length of sentence)" space="O(total length of roots)">

Each word is walked down the trie once, one letter per step, and the walk stops at the first root it meets. Nothing is hashed, and no prefix strings are built until the answer is known.

```swift
public enum RootReplacement {
    final class Node {
        var children: [Character: Node] = [:]
        var isRoot = false
    }

    public static func replace(in sentence: String, roots: [String]) -> String {
        let trie = Node()
        for root in roots {
            var node = trie
            for character in root {
                if let next = node.children[character] {
                    node = next
                } else {
                    let next = Node()
                    node.children[character] = next
                    node = next
                }
            }
            node.isRoot = true
        }

        let words = sentence.split(separator: " ")
        let replaced = words.map { word -> Substring in
            var node = trie
            var length = 0
            for character in word {
                guard let next = node.children[character] else { return word }
                node = next
                length += 1
                if node.isRoot {
                    return word.prefix(length)           // the shortest root that fits
                }
            }
            return word
        }
        return replaced.joined(separator: " ")
    }
}
```

`split` gives `Substring` values that share the sentence's storage, and `word.prefix(length)` is a `Substring` too, so no new strings are made until `joined` builds the answer. See [Substring and memory](/dsa/learn/swift-substring).

</Approach>
