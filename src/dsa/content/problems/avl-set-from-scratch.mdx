Build a set of Ints on an AVL tree: insert, remove and contains, each O(log n), with every node's balance factor kept at −1, 0 or +1 by rotations.

`AVLSetFromScratch.AVLSet`, a class with `insert(_:) -> Bool`, `remove(_:) -> Bool`, `contains(_:) -> Bool` and `count: Int`

The stub gives you `AVLSetFromScratch.Node` (with `value`, `left`, `right` and a stored `height`) and, already written, `root`, `height`, `sorted` (the values in order) and `levelOrder` (the tree level by level, with `nil` for missing children, as `TreeNode.make` takes it). You write the rest:

- `insert` returns `true` if it added the value, or `false` if it was already there.
- `remove` returns `true` if it removed the value, or `false` if it wasn't there. A node with two children takes its **successor's** value (the smallest value in its right subtree), and the successor's node is removed instead.
- Every node's stored `height` must be correct after each operation: 1 for a leaf, and one more than its taller child otherwise.

The tests check exact shapes after inserts and removals, every stored height and balance factor after thousands of random operations, and the height after 100,000 sorted inserts.

## Examples

| Operations, starting empty | `levelOrder` afterwards |
| --- | --- |
| insert 3, 2, 1 | `[2, 1, 3]` |
| insert 1, 3, 2 | `[2, 1, 3]` |
| insert 10, 20, 30, 40, 50 | `[20, 10, 40, nil, nil, 30, 50]` |
| …then insert 25 | `[30, 20, 40, 10, 25, nil, 50]` |
| insert 2, 1, 4, 3, 5, then remove 1 | `[4, 2, 5, nil, 3]` |
| insert 20, 10, 30, 25, 40, then remove 30 | `[20, 10, 40, nil, nil, 25]` |

In the fifth example, removing 1 leaves 2 two levels lighter on the left, and its right child 4 is level (balance factor 0): a single left rotation fixes it. In the last, 30 has two children, so its successor 40 moves into its place and 25 stays on the left: still balanced, so nothing rotates.

## Constraints

- Up to 100,000 values, inserted in any order, including sorted.
- Values are any `Int`.
- After every operation, every node's stored `height` is correct and its balance factor is −1, 0 or +1.

<Hints>
<Hint>
Write small helpers first: `height(_ node: Node?) -> Int` (0 for nil), `balance(_ node: Node)` (left height minus right height), `update(_ node: Node)` (recompute the stored height from the children), and `rotateLeft` and `rotateRight`, each returning the subtree's new root and updating the two nodes' heights, lower one first.
</Hint>
<Hint>
Make insert and remove recursive, with each call returning the new root of its subtree, so the caller writes `node.left = insert(value, into: node.left)`. Then, on the way back up, every node calls one `rebalance` function: update its height, and if its balance is +2 or −2, rotate.
</Hint>
<Hint>
In `rebalance`, choose the case by the **child's** balance factor, not by the value you inserted: at +2, if the left child leans right (balance below 0), rotate it left first, then rotate the node right. That rule also handles a child with balance 0, which only removals produce, with a single rotation.
</Hint>
</Hints>

## Solutions

<Approach title="Recursive insert and remove with one rebalance" time="O(log n) per operation" space="O(log n) for the recursion">

This is the AVL tree from [AVL trees: insert and delete](/dsa/learn/bal-avl). Insert and remove are ordinary recursive BST operations that return each subtree's new root. Every node on the way back up goes through `rebalance`, which updates its height and performs the single or double rotation its balance factor calls for. The recursion is as deep as the tree, which is at most about 1.44 log2 n levels.

```swift
public enum AVLSetFromScratch {
    public final class Node {
        public var value: Int
        public var left: Node?
        public var right: Node?
        public var height = 1

        public init(_ value: Int) {
            self.value = value
        }
    }

    public final class AVLSet {
        public private(set) var root: Node?
        public private(set) var count = 0

        public init() {}

        public func contains(_ value: Int) -> Bool {
            var current = root
            while let node = current {
                if value == node.value { return true }
                current = value < node.value ? node.left : node.right
            }
            return false
        }

        @discardableResult
        public func insert(_ value: Int) -> Bool {
            guard !contains(value) else { return false }
            root = Self.insert(value, into: root)
            count += 1
            return true
        }

        @discardableResult
        public func remove(_ value: Int) -> Bool {
            guard contains(value) else { return false }
            root = Self.remove(value, from: root)
            count -= 1
            return true
        }

        private static func height(_ node: Node?) -> Int {
            node?.height ?? 0
        }

        private static func balance(_ node: Node) -> Int {
            height(node.left) - height(node.right)
        }

        private static func update(_ node: Node) {
            node.height = 1 + max(height(node.left), height(node.right))
        }

        private static func rotateRight(_ node: Node) -> Node {
            let pivot = node.left!
            node.left = pivot.right
            pivot.right = node
            update(node)                                 // node is below pivot now: update it first
            update(pivot)
            return pivot
        }

        private static func rotateLeft(_ node: Node) -> Node {
            let pivot = node.right!
            node.right = pivot.left
            pivot.left = node
            update(node)
            update(pivot)
            return pivot
        }

        private static func rebalance(_ node: Node) -> Node {
            update(node)
            let factor = balance(node)
            if factor > 1 {
                if balance(node.left!) < 0 {
                    node.left = rotateLeft(node.left!)      // left-right
                }
                return rotateRight(node)                    // left-left
            }
            if factor < -1 {
                if balance(node.right!) > 0 {
                    node.right = rotateRight(node.right!)   // right-left
                }
                return rotateLeft(node)                     // right-right
            }
            return node
        }

        private static func insert(_ value: Int, into node: Node?) -> Node {
            guard let node else { return Node(value) }
            if value < node.value {
                node.left = insert(value, into: node.left)
            } else {
                node.right = insert(value, into: node.right)
            }
            return rebalance(node)
        }

        private static func remove(_ value: Int, from node: Node?) -> Node? {
            guard let node else { return nil }
            if value < node.value {
                node.left = remove(value, from: node.left)
            } else if value > node.value {
                node.right = remove(value, from: node.right)
            } else {
                guard let left = node.left else { return node.right }
                guard let right = node.right else { return left }
                var successor = right
                while let smaller = successor.left {
                    successor = smaller
                }
                node.value = successor.value
                node.right = remove(successor.value, from: right)
            }
            return rebalance(node)
        }

        // height, sorted and levelOrder as in the stub
    }
}
```

Checking `contains` first keeps `count` honest and lets the recursive insert assume the value is new. It costs a second O(log n) walk; passing an `inout` flag down the recursion would avoid that.

</Approach>
