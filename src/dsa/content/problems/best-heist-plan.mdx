The burglar from [Rob a quiet street](/dsa/practice/quiet-street-heist) wants the plan itself this time, not just the total. `houses[i]` is the cash in house `i` of a straight street, and no two neighbouring houses may be robbed. Return the indexes of the houses to rob, in increasing order, so that the total is as large as possible. If several plans take the same amount, return any one of them.

`BestHeistPlan.bestPlan(houses: [Int]) -> [Int]`

## Examples

| `houses` | Output | Why |
| --- | --- | --- |
| `[5, 8, 6, 1, 2, 9]` | `[0, 2, 5]` | 5 + 6 + 9 = 20, the best possible |
| `[3, 10, 3, 1, 2]` | `[1, 4]` | 10 + 2 = 12 |
| `[2, 3, 1]` | `[1]` or `[0, 2]` | both take 3 |
| `[4]` | `[0]` | |
| `[]` | `[]` | |

## Constraints

- `0 ≤ houses.count ≤ 100,000`
- `0 ≤ houses[i] ≤ 10,000`
- Houses with no cash may be included in a plan or left out, as long as the total is the best and no two houses are neighbours.

<Hints>
<Hint>
First solve the value problem with a full table, `best[i]` = the most from the first i houses, without rolling it into two variables. The table remembers how every total was reached.
</Hint>
<Hint>
Walk back from `best[n]`. If `best[i]` equals `best[i − 1]`, a best plan can skip house i − 1: move to i − 1. Otherwise house i − 1 must have been robbed: record it and move to i − 2, since its neighbour wasn't.
</Hint>
<Hint>
The walk finds houses from the last to the first, so reverse the list before returning it. Alternatively, record each decision in a `[Bool]` as you fill the table, and follow those.
</Hint>
</Hints>

## Solutions

<Approach title="Fill, then walk back" time="O(n)" space="O(n)">

From [Reconstructing the answer, not just its value](/dsa/learn/dp-reconstruct). The fill is house robber's table; the walk asks, at each entry, which option of the transition produced it.

```swift
public enum BestHeistPlan {
    public static func bestPlan(houses: [Int]) -> [Int] {
        let n = houses.count
        var best = Array(repeating: 0, count: n + 1)
        for i in stride(from: 1, through: n, by: 1) {
            best[i] = max(best[i - 1], (i >= 2 ? best[i - 2] : 0) + houses[i - 1])
        }
        var robbed: [Int] = []
        var i = n
        while i >= 1 {
            if best[i] == best[i - 1] {
                i -= 1
            } else {
                robbed.append(i - 1)
                i -= 2
            }
        }
        return robbed.reversed()
    }
}
```

</Approach>

<Approach title="Rolling values with a decision array" time="O(n)" space="O(n) Bools">

Keep the totals in two rolling variables, as in [Rob a quiet street](/dsa/practice/quiet-street-heist), but record in `took[i]` whether the best for the first i houses robs house i − 1. A `Bool` is one byte against an `Int`'s eight, and the walk back just follows the decisions.

```swift
public static func bestPlan(houses: [Int]) -> [Int] {
    let n = houses.count
    var took = Array(repeating: false, count: n + 1)
    var (twoBack, oneBack) = (0, 0)
    for i in stride(from: 1, through: n, by: 1) {
        let take = twoBack + houses[i - 1]
        took[i] = take > oneBack
        (twoBack, oneBack) = (oneBack, max(oneBack, take))
    }
    var robbed: [Int] = []
    var i = n
    while i >= 1 {
        if took[i] {
            robbed.append(i - 1)
            i -= 2
        } else {
            i -= 1
        }
    }
    return robbed.reversed()
}
```

</Approach>
