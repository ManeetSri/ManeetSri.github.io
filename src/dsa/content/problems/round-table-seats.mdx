Seats are linked together: each `Seat` has a guest's name and a `next` seat. Following `next` leads either round a table and back to where you started, or along a row that ends with `nil`. Guests can share a name, so only identity tells two seats apart. Write four functions that walk the seats correctly.

`RoundTableSeats.guests(from:)`, `seatCount(from:)`, `isRoundTable(_:)` and `distinctSeats(in:)`

- **`guests(from:)`** returns the guests' names from `start` onwards, following `next`, listing each seat once. Stop at `nil`, or when you arrive back at `start` itself.
- **`seatCount(from:)`** returns how many seats that walk visits.
- **`isRoundTable(_:)`** returns `true` when following `next` from `start` arrives back at that very seat.
- **`distinctSeats(in:)`** returns how many different seat objects appear in an array of visits, where the same seat may appear many times.

## Examples

| Seats | Call | Result |
| --- | --- | --- |
| Asha → Ravi → Mina → Kofi → back to Asha | `guests(from: mina)` | `["Mina", "Kofi", "Asha", "Ravi"]` |
| Sam → Sam → Ali → Sam → back to the first Sam | `seatCount(from: firstSam)` | `4` |
| Asha → Ravi → Asha → `nil` | `isRoundTable(firstAsha)` | `false` |
| one seat whose `next` is itself | `seatCount(from: seat)`, `isRoundTable(seat)` | `1`, `true` |
| visits `[a, b, a, a, c, b]`, where `a` and `b` are both "Sam" | `distinctSeats(in: visits)` | `3` |

## Constraints

- Up to 10,000 seats.
- Following `next` from the starting seat either comes back to that seat or reaches `nil`. It never loops round without passing through `start`.

<Hints>
<Hint>
Why not stop when the name matches the first guest's name? Look at the Sam example: the walk would stop after one seat. You need "is this the same seat object?", which is `===`, or `!==` for the opposite.
</Hint>
<Hint>
Start with `start`'s name in the result and `var current = start.next`. Then `while let seat = current, seat !== start` appends `seat.guest` and moves to `seat.next`. That one loop stops at both kinds of ending.
</Hint>
<Hint>
For `distinctSeats(in:)`, put `ObjectIdentifier(seat)` for every seat into a `Set<ObjectIdentifier>`, then return the set's `count`.
</Hint>
</Hints>

## Solutions

<Approach title="Walk until nil or back at the same seat" time="O(n)" space="O(n) for the names, O(1) for isRoundTable">

The loop condition does the work. `while let` stops at the end of a row, and `seat !== start` stops when a round table brings you back. Comparing names instead would stop early whenever a name repeats. `seatCount` reuses `guests`, and `distinctSeats` turns each seat's identity into a value that a set can hold.

```swift
public enum RoundTableSeats {
    public final class Seat {
        public let guest: String
        public var next: Seat?

        public init(guest: String) {
            self.guest = guest
        }
    }

    public static func guests(from start: Seat) -> [String] {
        var names = [start.guest]
        var current = start.next
        while let seat = current, seat !== start {
            names.append(seat.guest)
            current = seat.next
        }
        return names
    }

    public static func seatCount(from start: Seat) -> Int {
        guests(from: start).count
    }

    public static func isRoundTable(_ start: Seat) -> Bool {
        var current = start.next
        while let seat = current {
            if seat === start {
                return true
            }
            current = seat.next
        }
        return false
    }

    public static func distinctSeats(in visits: [Seat]) -> Int {
        var seen = Set<ObjectIdentifier>()
        for seat in visits {
            seen.insert(ObjectIdentifier(seat))
        }
        return seen.count
    }
}
```

A round table's seats point at each other in a circle, which is a retain cycle: they're never freed. That's harmless here, and M11 shows how to avoid it.

</Approach>
