A graphics pipeline multiplies a chain of matrices. Matrix i (counting from 0) has `dims[i]` rows and `dims[i + 1]` columns, and multiplying a p × q matrix by a q × r matrix takes p · q · r scalar multiplications. The order of the matrices is fixed, but you choose how to bracket the chain. Return the fewest scalar multiplications needed, and a bracketing that achieves it.

`CheapestMatrixBracketing.minimumCost(dims: [Int]) -> Int`

`CheapestMatrixBracketing.bracketing(dims: [Int]) -> String`

Name the matrices `A1`, `A2`, … in order. Write each multiplication as an opening bracket, the left part, one space, the right part and a closing bracket, such as `((A1 A2) A3)`. A single matrix is written `A1`, with no brackets.

## Examples

| `dims` | `minimumCost` | A cheapest `bracketing` |
| --- | --- | --- |
| `[10, 30, 5, 60]` | `4500` | `((A1 A2) A3)` |
| `[10, 30, 5, 60, 10]` | `5000` | `((A1 A2) (A3 A4))` |
| `[5, 10, 2, 8]` | `180` | `((A1 A2) A3)` |
| `[2, 3, 4]` | `24` | `(A1 A2)` |
| `[7, 3]` | `0` | `A1` |

In the first example, `(A1 (A2 A3))` would cost 30 · 5 · 60 + 10 · 30 · 60 = 27,000.

## Constraints

- `2 ≤ dims.count ≤ 201`, so there are 1 to 200 matrices.
- `1 ≤ dims[i] ≤ 100`
- When several bracketings are cheapest, any of them is accepted: the tests read your bracketing, check that it multiplies A1 to An in order, and check that it costs the minimum.
- The tests use 160 matrices, so trying every bracketing is impossible.

<Hints>
<Hint>
However the chain is bracketed, one multiplication happens last. It joins the product of matrices i...k with the product of matrices k + 1...j. What does that last multiplication cost?
</Hint>
<Hint>
Let `cost[i][j]` be the cheapest way to multiply matrices i through j. Then `cost[i][j]` is the minimum over k of `cost[i][k] + cost[k + 1][j] + dims[i] * dims[k + 1] * dims[j + 1]`, and a single matrix costs 0.
</Hint>
<Hint>
Fill ranges in order of length, shortest first, so both parts are ready. To rebuild the bracketing, store the best k for each range and recurse: a range of one matrix is `A(i + 1)`, and anything longer is its two parts in brackets.
</Hint>
</Hints>

## Solutions

<Approach title="Try every bracketing" time="Exponential" space="O(n)">

Recursively try every last split and keep the cheapest. The number of bracketings is a Catalan number: 4,862 for 10 matrices and well over a billion for 20.

</Approach>

<Approach title="Interval DP with a split table" time="O(n³)" space="O(n²)">

Both functions share one helper that fills the cost table and remembers the best split for each range.

```swift
public enum CheapestMatrixBracketing {
    public static func minimumCost(dims: [Int]) -> Int {
        let (cost, _) = solve(dims)
        return cost[0][dims.count - 2]
    }

    public static func bracketing(dims: [Int]) -> String {
        let (_, split) = solve(dims)
        func bracket(_ i: Int, _ j: Int) -> String {
            if i == j { return "A\(i + 1)" }
            let k = split[i][j]
            return "(" + bracket(i, k) + " " + bracket(k + 1, j) + ")"
        }
        return bracket(0, dims.count - 2)
    }

    private static func solve(_ dims: [Int]) -> (cost: [[Int]], split: [[Int]]) {
        let n = dims.count - 1
        var cost = Array(repeating: Array(repeating: 0, count: n), count: n)
        var split = Array(repeating: Array(repeating: 0, count: n), count: n)
        if n >= 2 {
            for length in 2...n {
                for i in 0...(n - length) {
                    let j = i + length - 1
                    cost[i][j] = Int.max
                    for k in i..<j {
                        let total = cost[i][k] + cost[k + 1][j] + dims[i] * dims[k + 1] * dims[j + 1]
                        if total < cost[i][j] {
                            cost[i][j] = total
                            split[i][j] = k
                        }
                    }
                }
            }
        }
        return (cost, split)
    }
}
```

The `n >= 2` check matters: for a single matrix, `2...n` would be a range with its lower bound above its upper bound, which crashes.

</Approach>
