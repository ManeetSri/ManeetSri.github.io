Build an array of `Int`s that can take numbered snapshots of itself. Later, you can read any index as it was when any snapshot was taken. Snapshots must be cheap: copying the whole array each time is too slow and uses too much memory.

`SnapshotArrayDesign.SnapshotArray`, with `init(count:)`, `count`, `subscript(index:) -> Int`, `set(_:at:)`, `snapshot() -> Int` and `value(at:snapshot:) -> Int`

- A new array holds `count` zeros, and no snapshot has been taken.
- `set(_:at:)` changes the current value at an index. `array[i]` reads the current value, including changes not yet in any snapshot.
- `snapshot()` returns the new snapshot's id: 0 for the first, then 1, 2 and so on.
- `value(at: i, snapshot: id)` returns what `array[i]` was when snapshot `id` was taken. `id` is always one that `snapshot()` has returned.
- `set` and `snapshot()` should be O(1) (amortised), `value(at:snapshot:)` O(log c) for an index changed c times, and memory O(count + number of sets).

## Examples

| Calls on `SnapshotArray(count: 3)` | Result |
| --- | --- |
| `set(5, at: 0)`, `snapshot()` | `0` |
| `set(6, at: 0)`, `value(at: 0, snapshot: 0)` | `5` |
| `array[0]` | `6` |
| `snapshot()`, then `value(at: 0, snapshot: 1)` | `1`, then `6` |
| `value(at: 1, snapshot: 0)` | `0`: never set |
| new array of 1: `set(1, at: 0)`, `set(2, at: 0)`, `set(3, at: 0)`, `snapshot()`, `value(at: 0, snapshot: 0)` | `0`, then `3` |

In the last row, only the value at the moment of the snapshot matters: the 1 and the 2 were overwritten before any snapshot saw them.

## Constraints

- `0 ≤ count ≤ 50,000`.
- Up to 100,000 calls to `set`, 50,000 to `snapshot()` and 100,000 to `value(at:snapshot:)`.

<Hints>
<Hint>
Copying the array on every snapshot is O(count) per snapshot: 50,000 snapshots of 50,000 elements is 2.5 billion copies. Most indexes don't change between two snapshots, so store only the **changes**.
</Hint>
<Hint>
Keep a counter of snapshots taken so far. Changes made now belong to snapshot number `snapshotsTaken`, the one that hasn't been taken yet. For each index, keep a history of `(snapshot, value)` pairs: append a pair when the index changes, or overwrite the last pair if it already belongs to the current snapshot number.
</Hint>
<Hint>
Each history is sorted by snapshot number, because the counter only grows. The value at snapshot `id` is the **last** pair with `snapshot ≤ id`, found by binary search for the first pair with `snapshot > id`. If there's none before it, the index was still 0.
</Hint>
</Hints>

## Solutions

<Approach title="Copy the whole array at each snapshot" time="O(count) per snapshot, O(1) lookup" space="O(count × snapshots)">

The simplest design: `snapshots.append(current)`. Lookups are a plain index, but a snapshot copies everything, which is fine for a handful of snapshots and hopeless for 50,000.

```swift
public mutating func snapshot() -> Int {
    snapshots.append(current)          // O(count)
    return snapshots.count - 1
}

public func value(at index: Int, snapshot id: Int) -> Int {
    snapshots[id][index]
}
```

</Approach>

<Approach title="Per-index change histories and binary search" time="O(1) set and snapshot, O(log c) lookup" space="O(count + sets)">

A snapshot is now only a counter going up. The cost has moved to the lookup, which is a binary search over one index's changes, and the memory is proportional to the number of changes rather than to count × snapshots.

```swift
import DSAKit

public enum SnapshotArrayDesign {
    public struct SnapshotArray {
        /// For each index, the snapshots in which it changed, in order, with its value in each.
        private var history: [[(snapshot: Int, value: Int)]]
        private var snapshotsTaken = 0

        public init(count: Int) {
            precondition(count >= 0, "The count can't be negative")
            history = Array(repeating: [], count: count)
        }

        public var count: Int {
            history.count
        }

        public subscript(index: Int) -> Int {
            history[index].last?.value ?? 0
        }

        public mutating func set(_ value: Int, at index: Int) {
            // Changes made before the next snapshot belong to snapshot number `snapshotsTaken`
            if let last = history[index].last, last.snapshot == snapshotsTaken {
                history[index][history[index].count - 1].value = value   // changed twice: overwrite
            } else {
                history[index].append((snapshotsTaken, value))
            }
        }

        public mutating func snapshot() -> Int {
            snapshotsTaken += 1
            return snapshotsTaken - 1
        }

        public func value(at index: Int, snapshot id: Int) -> Int {
            precondition(id >= 0 && id < snapshotsTaken, "No snapshot \(id) has been taken")
            let changes = history[index]
            let later = changes.partitionPoint { $0.snapshot > id }     // first change after `id`
            return later == 0 ? 0 : changes[later - 1].value
        }
    }
}
```

The current value is the last entry of the history, whichever snapshot it belongs to, so `array[i]` stays O(1).

</Approach>
