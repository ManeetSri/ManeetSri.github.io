Build a queue with a fixed capacity, stored in a ring of slots that's created once and never grows. When the queue is full, `enqueue` refuses the new element: it returns `false` and changes nothing.

`CircularQueueDesign.CircularQueue<Element>`, with `init(capacity:)`, `capacity: Int`, `enqueue(_:) -> Bool`, `dequeue() -> Element?`, `front: Element?`, `back: Element?`, `count: Int`, `isEmpty: Bool` and `isFull: Bool`

`front` is the oldest element and `back` the newest; both are `nil` when the queue is empty, as is `dequeue()`. Every operation must be O(1), and nothing may shift or allocate after `init`.

## Examples

| Code | Result |
| --- | --- |
| capacity 3: enqueue 1, 2, 3, then `enqueue(4)` | `true`, `true`, `true`, then `false` |
| capacity 3 holding 1, 2, 3: `dequeue()`, then `enqueue(4)`, then `front` and `back` | `1`, `true`, then `2` and `4` |
| capacity 4: enqueue 1, 2, 3, dequeue twice, enqueue 4, 5, 6, then dequeue until empty | `3`, `4`, `5`, `6`, then `nil` |
| capacity 1: enqueue 7, then `isFull` and `enqueue(8)` | `true` and `false` |
| `CircularQueue<Int>(capacity: 2).front` | `nil` |

In the third example, 5 and 6 go into the slots that 1 and 2 left at the start of the array: the back has wrapped round.

## Constraints

- `1 ≤ capacity ≤ 100,000`
- Up to 200,000 operations.
- Copying a queue gives an independent queue, as with any struct.

<Hints>
<Hint>
Store `private var slots: [Element?]`, made with `Array(repeating: nil, count: capacity)` in `init`. Optional slots let you create the array without needing a value of type `Element`, and setting a slot back to `nil` releases what it held.
</Hint>
<Hint>
Keep `head`, the slot of the front element, and `count`. The element at position i from the front is in slot `(head + i) % capacity`, so a new element goes into slot `(head + count) % capacity`, and `back` is in slot `(head + count - 1) % capacity`.
</Hint>
<Hint>
Keeping a count settles the classic full-or-empty puzzle: empty means `count == 0` and full means `count == capacity`. After a dequeue, move the front with `head = (head + 1) % capacity`.
</Hint>
</Hints>

## Solutions

<Approach title="A ring of slots with a head and a count" time="O(1) per operation" space="O(capacity)">

The slots form a circle: after the last slot comes slot 0 again, which `%` takes care of. `head` marks the front, `count` says how many slots after it are in use, and neither enqueue nor dequeue ever moves another element.

```swift
public enum CircularQueueDesign {
    public struct CircularQueue<Element> {
        private var slots: [Element?]
        private var head = 0
        public private(set) var count = 0

        public init(capacity: Int) {
            precondition(capacity > 0, "A circular queue needs room for at least one element")
            slots = Array(repeating: nil, count: capacity)
        }

        public var capacity: Int {
            slots.count
        }

        public mutating func enqueue(_ element: Element) -> Bool {
            guard count < slots.count else { return false }
            slots[(head + count) % slots.count] = element    // the free slot right after the back
            count += 1
            return true
        }

        public mutating func dequeue() -> Element? {
            guard count > 0 else { return nil }
            let element = slots[head]
            slots[head] = nil                                // release it
            head = (head + 1) % slots.count
            count -= 1
            return element
        }

        public var front: Element? {
            count > 0 ? slots[head] : nil
        }

        public var back: Element? {
            count > 0 ? slots[(head + count - 1) % slots.count] : nil
        }

        public var isEmpty: Bool {
            count == 0
        }

        public var isFull: Bool {
            count == slots.count
        }
    }
}
```

`public private(set) var count` lets code outside read the count but only the queue change it. `slots[head]` already has type `Element?`, so `front` can return it directly.

</Approach>
