Write two small recursive functions. `digitSum` adds up the decimal digits of a number. `digitalRoot` keeps replacing a number with its digit sum until only one digit is left, and returns that digit. Use recursion, not loops: that's the skill this problem practises.

`RecursiveDigitSum.digitSum(_ n: Int) -> Int`

`RecursiveDigitSum.digitalRoot(_ n: Int) -> Int`

## Examples

| Call | Returns | Why |
| --- | --- | --- |
| `digitSum(123)` | `6` | 1 + 2 + 3 |
| `digitSum(9999)` | `36` | 9 + 9 + 9 + 9 |
| `digitSum(7)` | `7` | a single digit is its own sum |
| `digitSum(0)` | `0` | |
| `digitalRoot(38)` | `2` | 38 → 11 → 2 |
| `digitalRoot(987654321)` | `9` | 987654321 → 45 → 9 |
| `digitalRoot(5)` | `5` | already one digit |

## Constraints

- `0 ≤ n ≤ Int.max` (about 9.2 × 10¹⁸, so at most 19 digits)
- No loops. Each function should call itself.

<Hints>
<Hint>
`n % 10` is the last digit of `n`, and `n / 10` is `n` with its last digit removed. For 123, they're 3 and 12.
</Hint>
<Hint>
Base case for `digitSum`: a number below 10 is a single digit, so it's its own digit sum. Recursive case: the last digit plus the digit sum of the rest.
</Hint>
<Hint>
`digitalRoot` has the same base case. Otherwise, it's the digital root of the digit sum, which is a much smaller number.
</Hint>
</Hints>

## Solutions

<Approach title="Peel off the last digit" time="O(d)" space="O(d)">

Here d is the number of digits. Each call to `digitSum` removes one digit, so it makes d calls, and at most d frames are on the stack at once. For an `Int` that's never more than 19.

```swift
public enum RecursiveDigitSum {
    public static func digitSum(_ n: Int) -> Int {
        if n < 10 {
            return n                            // base case: a single digit
        }
        return n % 10 + digitSum(n / 10)        // last digit + digit sum of the rest
    }

    public static func digitalRoot(_ n: Int) -> Int {
        if n < 10 {
            return n
        }
        return digitalRoot(digitSum(n))
    }
}
```

Trace `digitSum(123)`: it waits on `digitSum(12)`, which waits on `digitSum(1)`. That returns 1, then `digitSum(12)` returns 2 + 1 = 3, then `digitSum(123)` returns 3 + 3 = 6.

`digitalRoot` recurses only a few times: the digit sum of any `Int` is at most 9 × 19 = 171, so one call shrinks a huge number to three digits or fewer.

</Approach>

<Approach title="A maths shortcut for the digital root" time="O(1)" space="O(1)">

A number and its digit sum always leave the same remainder when divided by 9. That gives a formula: the digital root of 0 is 0, and for any other `n` it's `1 + (n - 1) % 9`. It's a nice fact to know, but the recursive version is the point of this problem.

```swift
public static func digitalRoot(_ n: Int) -> Int {
    n == 0 ? 0 : 1 + (n - 1) % 9
}
```

</Approach>
