Two teammates each wrote an ordered list of steps as a string of letters. Build the shortest string that contains both as subsequences: each one's characters appear in it in order, not necessarily side by side. Return any shortest answer.

`ShortestCombinedSupersequence.shortest(_ first: String, _ second: String) -> String`

## Examples

| `first` | `second` | One answer | Length |
| --- | --- | --- | --- |
| `"abac"` | `"cab"` | `"cabac"` | `5` |
| `"swift"` | `"shift"` | `"shwift"` | `6` |
| `"geek"` | `"eke"` | `"geeke"` | `5` |
| `"abc"` | `"def"` | `"abcdef"` | `6` |
| `""` | `"xyz"` | `"xyz"` | `3` |

Several answers are often equally short (`"abcdef"` and `"dabecf"` both work for the fourth example). The tests check that both strings are subsequences of your answer and that it's as short as possible.

## Constraints

- Each string has 0 to 1,500 characters. Compare `Character`s.
- The tests include two random strings of 1,500 characters.

<Hints>
<Hint>
Characters both strings share, in the same order, can be written once for both. The most you can share is a longest common subsequence, so the shortest length is `first.count + second.count − LCS`.
</Hint>
<Hint>
Build the LCS table. Then walk back from the bottom-right cell: on equal characters, write it once and move diagonally; otherwise write the character of the direction you move, towards the larger neighbour.
</Hint>
<Hint>
When one index reaches 0, write whatever is left of the other string. You built the answer from the end, so reverse it.
</Hint>
</Hints>

## Solutions

<Approach title="Walk the LCS table" time="O(n · m)" space="O(n · m)">

Every step of the walk writes exactly one character. Matches cover two strings at once, so the total is n + m − LCS.

```swift
public enum ShortestCombinedSupersequence {
    public static func shortest(_ first: String, _ second: String) -> String {
        let a = Array(first), b = Array(second)
        let n = a.count, m = b.count
        var table = Array(repeating: Array(repeating: 0, count: m + 1), count: n + 1)
        for i in 0...n {
            for j in 0...m {
                if i == 0 || j == 0 {
                    table[i][j] = 0
                } else if a[i - 1] == b[j - 1] {
                    table[i][j] = table[i - 1][j - 1] + 1
                } else {
                    table[i][j] = max(table[i - 1][j], table[i][j - 1])
                }
            }
        }
        var result: [Character] = []
        var i = n, j = m
        while i > 0 && j > 0 {
            if a[i - 1] == b[j - 1] {
                result.append(a[i - 1])
                i -= 1
                j -= 1
            } else if table[i - 1][j] >= table[i][j - 1] {
                result.append(a[i - 1])
                i -= 1
            } else {
                result.append(b[j - 1])
                j -= 1
            }
        }
        while i > 0 {
            result.append(a[i - 1])
            i -= 1
        }
        while j > 0 {
            result.append(b[j - 1])
            j -= 1
        }
        return String(result.reversed())
    }
}
```

Moving towards the **smaller** neighbour still gives a common supersequence, but it gives up a shared character and comes out too long. Appending and reversing once avoids inserting at the front of a string, which is O(n) each time.

</Approach>
