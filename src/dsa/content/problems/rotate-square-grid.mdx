Rotate a square grid a quarter turn **clockwise**, in place. Think of turning a photo on its side: the top row becomes the right-hand column, and the left-hand column becomes the top row. Don't build a second grid.

`RotateSquareGrid.rotateClockwise(_ grid: inout [[Int]])`

## Examples

| `grid` before | `grid` after |
| --- | --- |
| `[[1, 2], [3, 4]]` | `[[3, 1], [4, 2]]` |
| `[[1, 2, 3], [4, 5, 6], [7, 8, 9]]` | `[[7, 4, 1], [8, 5, 2], [9, 6, 3]]` |
| `[[42]]` | `[[42]]` |
| `[]` | `[]` |

## Constraints

- The grid is square: n rows of n values, with `0 ≤ n ≤ 400`.
- O(n²) time and O(1) extra space: a few variables, no second grid and no copied rows.

<Hints>
<Hint>
The value at row `r`, column `c` ends up at row `c`, column `n - 1 - r`. Building a new grid with that rule is easy, and makes a good checker, but uses O(n²) extra space.
</Hint>
<Hint>
Split the move into two easy ones. First **transpose**: swap `grid[r][c]` with `grid[c][r]`, only for cells above the main diagonal (`c > r`), or every pair gets swapped twice.
</Hint>
<Hint>
After transposing, the first row is the original first column, top to bottom. Clockwise wants it the other way round, bottom to top, so reverse every row.
</Hint>
</Hints>

## Solutions

<Approach title="Build a rotated copy" time="O(n²)" space="O(n²)">

Every value moves from `(r, c)` to `(c, n - 1 - r)`. Write each one into a new grid, then replace the original. Correct, but not in place.

```swift
public static func rotateClockwise(_ grid: inout [[Int]]) {
    let size = grid.count
    var rotated = grid
    for row in 0..<size {
        for column in 0..<size {
            rotated[column][size - 1 - row] = grid[row][column]
        }
    }
    grid = rotated
}
```

</Approach>

<Approach title="Transpose, then reverse each row" time="O(n²)" space="O(1)">

Transposing flips the grid over its main diagonal, and reversing each row flips it left to right. One flip after the other is a quarter turn clockwise.

```swift
public enum RotateSquareGrid {
    public static func rotateClockwise(_ grid: inout [[Int]]) {
        let size = grid.count
        for row in 0..<size {
            for column in (row + 1)..<size {
                let saved = grid[row][column]
                grid[row][column] = grid[column][row]
                grid[column][row] = saved
            }
        }
        for row in 0..<size {
            grid[row].reverse()
        }
    }
}
```

The swap uses a temporary variable. `swap(&grid[row][column], &grid[column][row])` doesn't compile, because both arguments are inside `grid` and Swift's exclusivity rule forbids two overlapping changes to it.

</Approach>
