Count the **submatrices** of a grid that add up to exactly `target`. A submatrix is any non-empty rectangular block of neighbouring cells: some run of consecutive rows, crossed with some run of consecutive columns. Blocks at different positions count separately, even if they hold the same values.

`TargetSumSubmatrices.count(in grid: [[Int]], summingTo target: Int) -> Int`

## Examples

| `grid` | `target` | Output |
| --- | --- | --- |
| `[[1, -1], [-1, 1]]` | `0` | `5` |
| `[[2, 1, 3], [0, 3, 1]]` | `3` | `4` |
| `[[1, 2, -1, 3, -2, 2]]` | `3` | `4` |
| `[[4]]` | `3` | `0` |

In the first example, the two rows, the two columns and the whole grid each sum to 0. In the second, the blocks are the two cells holding 3, the pair `2, 1` in the top row and the pair `0, 3` in the bottom row. The third is a single row, so it's the 1D problem from [Target-sum subarrays](/dsa/practice/target-sum-subarrays).

## Constraints

- `1 ≤ rows, columns ≤ 100`, and every row has the same length.
- `-1,000 ≤ grid[r][c] ≤ 1,000` and `-10⁸ ≤ target ≤ 10⁸`
- Aim for O(rows² × columns). A 100 × 100 grid has over 25 million blocks, so checking each one, even in O(1), is slow.

<Hints>
<Hint>
Start with the brute force: try every top, bottom, left and right, and add up the block. Then make each block O(1) with a 2D prefix sum. That's O(rows² × columns²), which is correct but slow for 100 × 100.
</Hint>
<Hint>
Fix a top row and a bottom row. Collapse the rows between them into one array, where entry `c` is the sum of column `c` from `top` to `bottom`. Every block between those two rows is now a subarray of that array.
</Hint>
<Hint>
For each top row, start the column sums at zero and add one row at a time as `bottom` moves down. For each (top, bottom) pair, count the subarrays of the column sums that add up to `target` with a prefix sum and a dictionary seeded with `[0: 1]`.
</Hint>
</Hints>

## Solutions

<Approach title="A 2D prefix sum, trying every block" time="O(rows² × columns²)" space="O(rows × columns)">

Build the summed-area table from [2D prefix sums](/dsa/learn/prefix-2d), then try all four boundaries. Each block is four lookups.

```swift
public static func count(in grid: [[Int]], summingTo target: Int) -> Int {
    let rows = grid.count
    let columns = grid.first?.count ?? 0
    var prefix = Array(repeating: Array(repeating: 0, count: columns + 1), count: rows + 1)
    for r in 0..<rows {
        for c in 0..<columns {
            prefix[r + 1][c + 1] = grid[r][c] + prefix[r][c + 1] + prefix[r + 1][c] - prefix[r][c]
        }
    }
    var total = 0
    for top in 0..<rows {
        for bottom in top..<rows {
            for left in 0..<columns {
                for right in left..<columns {
                    let sum = prefix[bottom + 1][right + 1] - prefix[top][right + 1]
                        - prefix[bottom + 1][left] + prefix[top][left]
                    if sum == target {
                        total += 1
                    }
                }
            }
        }
    }
    return total
}
```

</Approach>

<Approach title="Collapse rows, then count subarrays" time="O(rows² × columns)" space="O(columns)">

A block is a choice of rows and a choice of columns. Fixing the rows (`top` and `bottom`) collapses the block's columns into a 1D array of column sums, and each run of columns is a subarray of it. The inner loop is exactly the count from [Prefix sum + hashmap](/dsa/learn/prefix-hashmap).

The column sums for `top...bottom` are the sums for `top...(bottom − 1)` plus row `bottom`, so they grow by one row at a time instead of being rebuilt.

```swift
public enum TargetSumSubmatrices {
    public static func count(in grid: [[Int]], summingTo target: Int) -> Int {
        let rows = grid.count
        let columns = grid.first?.count ?? 0
        var total = 0
        for top in 0..<rows {
            var columnSums = Array(repeating: 0, count: columns)
            for bottom in top..<rows {
                for c in 0..<columns {
                    columnSums[c] += grid[bottom][c]
                }
                var seen: [Int: Int] = [0: 1]
                var running = 0
                for value in columnSums {
                    running += value
                    total += seen[running - target, default: 0]
                    seen[running, default: 0] += 1
                }
            }
        }
        return total
    }
}
```

There are rows × (rows + 1) / 2 pairs of rows, each costing O(columns). If the grid had far more rows than columns, you'd fix pairs of columns instead and collapse the rows, so the squared factor is the smaller side.

</Approach>
