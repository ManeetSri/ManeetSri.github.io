Keep a value inside a range. If it's already inside, return it unchanged. If it's below the range, return the range's lower end; if it's above, return the upper end. This is called **clamping**, and apps do it constantly, for example to keep a volume slider between 0 and 100.

`RangeClamp.clamp(_ value: Int, to range: ClosedRange<Int>) -> Int`

`ClosedRange<Int>` is the type of a closed range of `Int` values, such as `0...100`. Inside the function, `range.lowerBound` and `range.upperBound` give you its two ends.

## Examples

| Call | Returns |
| --- | --- |
| `clamp(42, to: 0...100)` | `42` |
| `clamp(-5, to: 0...100)` | `0` |
| `clamp(250, to: 0...100)` | `100` |
| `clamp(100, to: 0...100)` | `100` |
| `clamp(0, to: -20...(-10))` | `-10` |
| `clamp(7, to: 4...4)` | `4` |

## Constraints

- `value` can be any `Int`, including `Int.min` and `Int.max`.
- `range` always has `lowerBound ≤ upperBound`. It may hold a single value.

<Hints>
<Hint>
There are three cases: below the range, above it, or inside it. `range.contains(value)` checks the last one.
</Hint>
<Hint>
With ternaries: if `value` is below `range.lowerBound`, the answer is `range.lowerBound`; otherwise, if it's above `range.upperBound`, the answer is `range.upperBound`; otherwise it's `value`.
</Hint>
<Hint>
There's a neater way with `min` and `max`. `max(value, range.lowerBound)` lifts anything too small up to the lower end. What does `min(that, range.upperBound)` then do?
</Hint>
</Hints>

## Solutions

<Approach title="Two ternaries" time="O(1)" space="O(1)">

Check the two outside cases in turn. The second ternary sits in the "otherwise" part of the first, which is about as much nesting as stays readable.

```swift
public enum RangeClamp {
    public static func clamp(_ value: Int, to range: ClosedRange<Int>) -> Int {
        let low = range.lowerBound
        let high = range.upperBound
        return value < low ? low : (value > high ? high : value)
    }
}
```

Naming `low` and `high` first keeps the last line short enough to read at a glance.

</Approach>

<Approach title="min of max" time="O(1)" space="O(1)">

`max(value, low)` replaces anything below the range with `low`. Then `min(…, high)` replaces anything above it with `high`. Values inside pass through both unchanged.

```swift
public enum RangeClamp {
    public static func clamp(_ value: Int, to range: ClosedRange<Int>) -> Int {
        return min(max(value, range.lowerBound), range.upperBound)
    }
}
```

This one-liner is the standard way to clamp in many languages. Read it from the inside out: first raise to at least the lower end, then lower to at most the upper end.

</Approach>
