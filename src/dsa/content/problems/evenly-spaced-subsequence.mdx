Pick some values from a list, keeping their order, so that every neighbouring pair you picked differs by the same amount. The step may be positive, negative or zero. Return the largest number of values you can pick.

`EvenlySpacedSubsequence.longest(_ values: [Int]) -> Int`

This is the length of the longest arithmetic subsequence. Any one or two values count as evenly spaced.

## Examples

| `values` | Output | One longest choice |
| --- | --- | --- |
| `[1, 7, 10, 13, 14, 19]` | `4` | `[1, 7, 13, 19]`, step 6 |
| `[20, 1, 15, 3, 10, 5, 8]` | `4` | `[20, 15, 10, 5]`, step −5 |
| `[9, 4, 7, 2, 10]` | `3` | `[4, 7, 10]`, step 3 |
| `[5, 5, 5, 5]` | `4` | step 0 |
| `[8, 3]` | `2` | |
| `[]` | `0` | |

## Constraints

- `0 ≤ values.count ≤ 1,000`
- `-1,000,000,000 ≤ values[i] ≤ 1,000,000,000`
- The largest tests use 800 values, which O(n²) handles. Values range widely, so an array indexed by the difference would be enormous.

<Hints>
<Hint>
"The longest evenly spaced run ending at i" isn't enough on its own: whether `values[i]` can extend a run ending at j depends on that run's step. Put the step into the state.
</Hint>
<Hint>
Let `ending[i][d]` be the longest evenly spaced run that ends at index i with step d. For each pair `j < i`, the step is `d = values[i] - values[j]`, and `values[i]` extends the run ending at j with step d.
</Hint>
<Hint>
Only the steps that actually occur matter, so give each index a dictionary from step to length. `ending[j][d, default: 1] + 1` treats "no run yet" as j on its own, so a fresh pair has length 2.
</Hint>
</Hints>

## Solutions

<Approach title="Fix the first two, then extend" time="O(n³)" space="O(n)">

Every evenly spaced run is determined by its first two values. For each pair, walk right looking for the next expected value each time. This is correct, and fine for a few hundred values, but 1,000 values and long runs make it slow.

</Approach>

<Approach title="One dictionary of steps per index" time="O(n²)" space="O(n²)">

Each pair is visited once and does one lookup and one update.

```swift
public enum EvenlySpacedSubsequence {
    public static func longest(_ values: [Int]) -> Int {
        guard values.count > 2 else { return values.count }
        var ending = Array(repeating: [Int: Int](), count: values.count)
        var best = 2
        for i in values.indices {
            for j in 0..<i {
                let step = values[i] - values[j]
                let length = ending[j][step, default: 1] + 1
                if length > ending[i][step, default: 0] {
                    ending[i][step] = length
                }
                best = max(best, length)
            }
        }
        return best
    }
}
```

The comparison before storing matters when values repeat: two earlier copies of the same value give the same step, and the longer run should win. Differences reach at most 2 × 10⁹, far from overflowing an `Int`.

</Approach>
