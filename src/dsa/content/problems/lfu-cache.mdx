Build a generic cache that holds at most `capacity` entries and, when it's full, evicts the entry used the **fewest** times. Among entries used equally often, it evicts the one used **least recently**. Every operation should be O(1) on average.

`LFUCache.Cache<Key: Hashable, Value>`, with `init(capacity:)`, `count`, `value(for:)`, `setValue(_:for:)`, `frequency(of:)` and `evictionOrder`

- Every entry has a use count. Setting a **new** key gives it a count of 1. **Reading** a key with `value(for:)`, or **setting** a key that's already cached, adds 1 to its count.
- `value(for:)` returns the value, or `nil` if the key isn't cached. A miss changes nothing.
- `setValue(_:for:)` stores or replaces the value. Replacing never evicts anything. Adding a new key to a full cache first evicts the entry with the lowest count, breaking ties by evicting the least recently used of them.
- `frequency(of:)` returns a key's count, or 0 if it isn't cached. It doesn't count as a use.
- `evictionOrder` lists every cached key in the order they'd be evicted: lowest count first, and within a count, least recently used first. It can be O(n).
- A capacity of 0 stores nothing.

## Examples

With `let cache = Cache<String, Int>(capacity: 3)`:

| Code | Result | `evictionOrder` afterwards |
| --- | --- | --- |
| `setValue` for `"smile"`, `"heart"`, `"thumbs"` | | `["smile", "heart", "thumbs"]` |
| `value(for: "smile")` twice, `value(for: "heart")` | `1`, `1`, `2` | `["thumbs", "heart", "smile"]` |
| `setValue(4, for: "fire")` | evicts `"thumbs"` (count 1) | `["fire", "heart", "smile"]` |
| `value(for: "fire")` | `4` | `["heart", "fire", "smile"]` |
| `setValue(5, for: "star")` | evicts `"heart"`: it ties with `"fire"` at 2 but was used less recently | `["star", "fire", "smile"]` |
| `frequency(of: "smile")` | `3` | unchanged |

## Constraints

- `0 ≤ capacity ≤ 50,000`.
- Up to a few hundred thousand operations. The tests make 50,000 evictions from a cache of 50,000 entries, so a scan for the victim (O(capacity) per eviction) takes billions of steps.
- The cache must not keep values alive after they're evicted, or after the cache itself is gone. The tests check, so mind the retain cycles.

<Hints>
<Hint>
A use always moves a key from count c to count c + 1, never further. So keep a separate list for every count, holding that count's nodes in order of use, most recent first, exactly like the list in an LRU cache. A dictionary from count to list finds the right one in O(1), and another dictionary maps each key to its node.
</Hint>
<Hint>
Keep a variable `minFrequency`, the lowest count in the cache. The victim is the least recent node of `buckets[minFrequency]`. You never need to search for the minimum: a new key sets it to 1, and a use that empties the lowest bucket raises it by exactly 1.
</Hint>
<Hint>
The node needs its key (so eviction can remove the dictionary entry), its count (so a use knows which bucket it's in) and its links. A generic cache can't make sentinel nodes, so each bucket keeps optional `head` and `tail`, and `previous` should be `weak`. Remove a bucket from the dictionary when it empties, and check for an existing key before checking whether the cache is full.
</Hint>
</Hints>

## Solutions

<Approach title="Scan for the victim" time="O(capacity) per eviction" space="O(capacity)">

Store each key's value, count and last-use time in a dictionary, and on eviction scan all of them for the smallest (count, last use). It's correct and short, but each eviction looks at every entry: with 50,000 entries and 50,000 evictions, that's 2.5 billion comparisons. A heap ordered by (count, last use) brings it down to O(log n), but every use must then find and re-sift the key's entry, which needs an indexed heap.

</Approach>

<Approach title="One LRU list per count" time="O(1) average" space="O(capacity)">

A dictionary finds a key's node; the node's count finds its bucket; unlinking and relinking at the front of the next bucket is O(1). Eviction takes the tail of the lowest bucket.

```swift
public enum LFUCache {
    public final class Cache<Key: Hashable, Value> {
        final class Node {
            let key: Key
            var value: Value
            var frequency = 1
            var next: Node?
            weak var previous: Node?

            init(key: Key, value: Value) {
                self.key = key
                self.value = value
            }
        }

        /// One count's nodes, most recently used at the head.
        final class Bucket {
            var head: Node?
            var tail: Node?

            var isEmpty: Bool { head == nil }

            func pushFront(_ node: Node) {
                node.next = head
                node.previous = nil
                head?.previous = node
                head = node
                if tail == nil { tail = node }
            }

            func unlink(_ node: Node) {
                let before = node.previous
                let after = node.next
                if let before { before.next = after } else { head = after }
                if let after { after.previous = before } else { tail = before }
                node.next = nil
                node.previous = nil
            }
        }

        public let capacity: Int
        private var nodes: [Key: Node] = [:]
        private var buckets: [Int: Bucket] = [:]
        private var minFrequency = 0

        public init(capacity: Int) {
            self.capacity = max(0, capacity)
        }

        public var count: Int { nodes.count }

        private func bucket(for frequency: Int) -> Bucket {
            if let bucket = buckets[frequency] { return bucket }
            let bucket = Bucket()
            buckets[frequency] = bucket
            return bucket
        }

        /// A use: move the node up one bucket. O(1).
        private func touch(_ node: Node) {
            let old = buckets[node.frequency]!
            old.unlink(node)
            if old.isEmpty {
                buckets[node.frequency] = nil
                if minFrequency == node.frequency { minFrequency += 1 }
            }
            node.frequency += 1
            bucket(for: node.frequency).pushFront(node)
        }

        public func value(for key: Key) -> Value? {
            guard let node = nodes[key] else { return nil }
            touch(node)
            return node.value
        }

        public func setValue(_ value: Value, for key: Key) {
            guard capacity > 0 else { return }
            if let node = nodes[key] {
                node.value = value
                touch(node)
                return
            }
            if nodes.count == capacity, let lowest = buckets[minFrequency], let victim = lowest.tail {
                lowest.unlink(victim)
                if lowest.isEmpty { buckets[minFrequency] = nil }
                nodes[victim.key] = nil
            }
            let node = Node(key: key, value: value)
            nodes[key] = node
            bucket(for: 1).pushFront(node)
            minFrequency = 1
        }

        public func frequency(of key: Key) -> Int {
            nodes[key]?.frequency ?? 0
        }

        public var evictionOrder: [Key] {
            var keys: [Key] = []
            for frequency in buckets.keys.sorted() {
                var current = buckets[frequency]!.tail
                while let node = current {
                    keys.append(node.key)
                    current = node.previous
                }
            }
            return keys
        }
    }
}
```

`evictionOrder` sorts the bucket counts, which is O(n log n) at worst; it's only for inspection. Eviction itself never sorts or scans anything.

</Approach>
