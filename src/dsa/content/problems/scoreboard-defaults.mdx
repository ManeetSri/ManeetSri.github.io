A `Scoreboard` protocol asks for very little: the scores, and a ranking from best to worst. Use a protocol extension to give every scoreboard a default ranking and three bonus members for free, let golf replace the default, and make a plain `[Int]` a scoreboard too.

`extension ScoreboardDefaults.Scoreboard` with `ranking()`, `totalScore`, `bestScore` and `topScores(_:)`; `GolfCard.ranking()`; and `extension Array: ScoreboardDefaults.Scoreboard where Element == Int`

The protocol and the two types are in the starter code:

```swift
public protocol Scoreboard {
    var scores: [Int] { get }
    func ranking() -> [Int]
}
```

- **`ranking()`**, the default: every score, highest first.
- **`totalScore`**: the sum of the scores.
- **`bestScore`**: the first score in the ranking, or `nil` if there are none.
- **`topScores(_ count:)`**: the first `count` scores of the ranking, all of them if there are fewer, and none if `count` is 0 or less.
- **`GolfCard`** replaces the default with its own `ranking()`, lowest score first, because in golf the lowest score wins. Its `bestScore` and `topScores` must follow its ranking.
- **`[Int]`** conforms through the extension at the bottom of the starter code: its `scores` are its own elements.

## Examples

| Code | Result |
| --- | --- |
| `ArcadeBoard(scores: [12, 40, 7, 33]).ranking()` | `[40, 33, 12, 7]` |
| `ArcadeBoard(scores: [12, 40, 7, 33]).totalScore` | `92` |
| `GolfCard(scores: [72, 68, 75, 70]).bestScore` | `68` |
| `GolfCard(scores: [72, 68, 75, 70]).topScores(3)` | `[68, 70, 72]` |
| `ArcadeBoard(scores: [3, 9, 4]).topScores(10)` | `[9, 4, 3]` |
| `[8, 1, 6].bestScore` | `8` |

## Constraints

- Up to 10,000 scores, each a whole number that may be negative.
- The tests also call these members through `any Scoreboard`, so a `GolfCard` must still rank lowest first there.

<Hints>
<Hint>
Write `bestScore` and `topScores` in terms of `ranking()`, not by sorting again yourself. Then `GolfCard` only has to replace `ranking()`, and the other two follow along.
</Hint>
<Hint>
`scores.sorted(by: >)` sorts highest first, and `scores.sorted()` lowest first. `Array(ranking().prefix(n))` takes the first n; `prefix` can't take a negative count, so use `max(count, 0)`.
</Hint>
<Hint>
Inside `extension Array ... where Element == Int`, `self` is the array of Ints, so `scores` can return `self`.
</Hint>
</Hints>

## Solutions

<Approach title="Defaults in a protocol extension" time="O(n log n) for anything that ranks" space="O(n)">

The extension supplies `ranking()` as a **default implementation** of a requirement, plus three members that aren't requirements at all. Because `ranking()` is listed in the protocol, a call to it from inside `bestScore` or `topScores` uses the real type's version, even through `any Scoreboard`. If `ranking()` were only in the extension, golf cards would rank highest first whenever they were used through the protocol.

```swift
public enum ScoreboardDefaults {
    public protocol Scoreboard {
        var scores: [Int] { get }
        func ranking() -> [Int]
    }

    public struct ArcadeBoard: Scoreboard {
        public var scores: [Int]

        public init(scores: [Int]) {
            self.scores = scores
        }
    }

    public struct GolfCard: Scoreboard {
        public var scores: [Int]

        public init(scores: [Int]) {
            self.scores = scores
        }

        public func ranking() -> [Int] {
            scores.sorted()
        }
    }
}

extension ScoreboardDefaults.Scoreboard {
    public func ranking() -> [Int] {
        scores.sorted(by: >)
    }

    public var totalScore: Int {
        scores.reduce(0, +)
    }

    public var bestScore: Int? {
        ranking().first
    }

    public func topScores(_ count: Int) -> [Int] {
        Array(ranking().prefix(max(count, 0)))
    }
}

extension Array: ScoreboardDefaults.Scoreboard where Element == Int {
    public var scores: [Int] {
        self
    }
}
```

The last extension makes a type you didn't write conform to a protocol you did, and only when its elements are `Int`. Every array of Ints now has `bestScore`, `topScores` and the rest, from code written once.

</Approach>
