A pile of stones has positive weights. On every turn, pick up the two **heaviest** stones and smash them together. If they weigh the same, both crumble to dust. If not, the lighter one crumbles, and the heavier one loses that much weight and goes back on the pile. When fewer than two stones are left, the game is over. Return the weight of the stone that's left, or `0` if there's none.

`HeaviestStones.lastStone(_ weights: [Int]) -> Int`

## Examples

| `weights` | Returns | Why |
| --- | --- | --- |
| `[10, 4, 3]` | `3` | 10 and 4 leave 6; 6 and 3 leave 3. |
| `[3, 9, 4, 2, 6]` | `0` | 9 and 6 leave 3; 4 and 3 leave 1; 3 and 2 leave 1; 1 and 1 crumble. |
| `[5, 5]` | `0` | Equal stones both crumble. |
| `[20, 3, 3, 3]` | `11` | 17, then 14, then 11. |
| `[7]` | `7` | Nothing to smash. |
| `[]` | `0` | No stones at all. |

## Constraints

- `0 ≤ weights.count ≤ 100,000`
- `1 ≤ weights[i] ≤ 1,000,000`
- Sorting the pile again on every turn is O(n² log n): far too slow for 100,000 stones.

<Hints>
<Hint>
Every turn needs the two largest values, and then adds one value back. Which structure hands you the largest value quickly and also accepts new values quickly?
</Hint>
<Hint>
A max-heap. Each turn is two pops and at most one insert, each O(log n).
</Hint>
<Hint>
Each turn removes at least one stone, so there are at most n − 1 turns. Build the heap from the whole array at once (O(n) heapify) rather than inserting stones one by one.
</Hint>
</Hints>

## Solutions

<Approach title="Re-sort every turn" time="O(n² log n)" space="O(n)">

Follow the rules literally. Correct, and useful as a check on small piles, but each of up to n turns sorts the whole pile.

```swift
public static func lastStone(_ weights: [Int]) -> Int {
    var pile = weights
    while pile.count > 1 {
        pile.sort()
        let heaviest = pile.removeLast()
        let next = pile.removeLast()
        if heaviest > next { pile.append(heaviest - next) }
    }
    return pile.first ?? 0
}
```

</Approach>

<Approach title="A max-heap" time="O(n log n)" space="O(n)">

The heaviest stone is always on top. Pop two, push back the difference if there is one, and repeat.

```swift
import DSAKit

public enum HeaviestStones {
    public static func lastStone(_ weights: [Int]) -> Int {
        var pile = Heap.maxHeap(weights)
        while pile.count > 1 {
            let heaviest = pile.pop()!
            let next = pile.pop()!
            if heaviest > next {
                pile.insert(heaviest - next)
            }
        }
        return pile.peek() ?? 0
    }
}
```

The force unwraps are safe: the loop only runs while there are at least two stones.

</Approach>
