A map is a grid of `"1"` (land) and `"0"` (water). Land cells that touch up, down, left or right belong to the same island; touching diagonally doesn't join them. Everything beyond the edge of the map is water.

Write two functions: one that counts the islands, and one that returns the number of cells in the biggest island (`0` if there's no land at all).

`IslandSurvey.count(_ grid: [[Character]]) -> Int`

`IslandSurvey.largestArea(_ grid: [[Character]]) -> Int`

## Examples

The tests build each map from strings, one per row, like `["110", "011"].map { Array($0) }`.

| Map | `count` | `largestArea` |
| --- | --- | --- |
| `["11000", "11000", "00100", "00011"]` | `3` | `4` |
| `["11110", "11010", "11000", "00000"]` | `1` | `9` |
| `["101", "010", "101"]` | `5` | `1` |
| `["111", "101", "111"]` | `1` | `8` |
| `[]` | `0` | `0` |

In the third example, the five pieces of land only touch at corners, so each is its own island. In the fourth, the ring of land goes all the way round the lake, so it's one island of 8 cells.

## Constraints

- `0 ≤ rows, columns ≤ 1,000`, every row has the same length, and every cell is `"1"` or `"0"`.
- The tests include a 1000 × 1000 map that's all land, a checkerboard with 500,000 islands, and a snake-shaped island of 500,500 cells. On the snake, a recursive DFS would go about 500,000 calls deep and crash the test thread: use an explicit stack or BFS.

<Hints>
<Hint>
Scan every cell. A land cell you haven't visited yet must belong to an island you haven't counted: count it, then visit the whole island so none of its other cells starts a new count.
</Hint>
<Hint>
Visiting an island is a DFS or BFS over its land cells. Mark each cell as you push it, and count cells as you pop them: that count is the island's area.
</Hint>
<Hint>
To mark cells, either keep a separate `[[Bool]]`, or write `var grid = grid` and turn visited land into `"0"`. Arrays are values in Swift, so changing your copy never changes the caller's map.
</Hint>
</Hints>

## Solutions

<Approach title="Scan, then sink each island with an explicit stack" time="O(rows × columns)" space="O(rows × columns)">

One helper returns the area of every island, and both functions read their answer from it. The grid is first turned into a `[[Bool]]` of unvisited land, which is quicker to test than `Character`s and is cleared as cells are visited.

```swift
public enum IslandSurvey {
    private static let directions = [(-1, 0), (1, 0), (0, -1), (0, 1)]

    public static func count(_ grid: [[Character]]) -> Int {
        islandAreas(grid).count
    }

    public static func largestArea(_ grid: [[Character]]) -> Int {
        islandAreas(grid).max() ?? 0
    }

    /// The area of every island, in the order their first cells are met
    private static func islandAreas(_ grid: [[Character]]) -> [Int] {
        var unvisited = grid.map { row in row.map { $0 == "1" } }
        var areas: [Int] = []
        for row in unvisited.indices {
            for column in unvisited[row].indices where unvisited[row][column] {
                unvisited[row][column] = false
                var stack = [(row, column)]
                var area = 0
                while let cell = stack.popLast() {
                    area += 1
                    for (dr, dc) in directions {
                        let r = cell.0 + dr
                        let c = cell.1 + dc
                        guard r >= 0, r < unvisited.count, c >= 0, c < unvisited[r].count else { continue }
                        guard unvisited[r][c] else { continue }
                        unvisited[r][c] = false
                        stack.append((r, c))
                    }
                }
                areas.append(area)
            }
        }
        return areas
    }
}
```

The outer scan touches every cell once, and each land cell is pushed and popped once, so the whole survey is linear in the size of the map, however many islands there are. Union-find, in M45, solves the counting half another way, and also copes with land being added one cell at a time.

</Approach>
