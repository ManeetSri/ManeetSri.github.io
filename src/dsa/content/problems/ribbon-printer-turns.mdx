A ribbon printer starts with a blank ribbon. Each turn, it prints a single letter over any stretch of consecutive positions you choose, covering whatever was there before. Return the fewest turns needed to produce `pattern`.

`RibbonPrinterTurns.fewestTurns(_ pattern: String) -> Int`

## Examples

| `pattern` | Output | One plan |
| --- | --- | --- |
| `"abcba"` | `3` | `aaaaa`, then `bbb` over the middle three, then `c` in the centre |
| `"aaabbb"` | `2` | `aaaaaa`, then `bbb` over the right half |
| `"abab"` | `3` | `aaaa`, then each `b` on its own |
| `"abcabc"` | `5` | |
| `"q"` | `1` | |
| `""` | `0` | |

## Constraints

- `0 ≤ pattern.count ≤ 200`
- The pattern holds only lowercase letters `a` to `z`.
- The tests use patterns of 120 and 200 letters.

<Hints>
<Hint>
A run of equal letters, like `aaa`, never needs more turns than a single letter: any turn that prints one of them can be stretched to print them all. Collapse runs first.
</Hint>
<Hint>
Let `turns[i][j]` be the fewest turns for letters i through j. The leftmost letter can get a turn of its own, costing `1 + turns[i + 1][j]`. What if it shares its turn with a later copy of the same letter?
</Hint>
<Hint>
If `s[i]` shares a turn with an equal letter at k, stretch the turn that prints `s[k]` leftwards to cover i, and print the letters between them on top afterwards: `turns[i + 1][k - 1] + turns[k][j]`, where an empty range costs 0. Take the minimum over all such k, and fill i from the bottom up.
</Hint>
</Hints>

## Solutions

<Approach title="Search every printing plan" time="Exponential" space="Exponential">

A breadth-first search over everything the ribbon could look like, one turn at a time, finds the true answer for ribbons of five or six letters. It's a good way to test a cleverer solution, and nothing more.

</Approach>

<Approach title="Interval DP on the leftmost letter" time="O(n³)" space="O(n²)">

After collapsing, neighbouring letters differ, so the first possible partner for `s[i]` is at `i + 2`.

```swift
public enum RibbonPrinterTurns {
    public static func fewestTurns(_ pattern: String) -> Int {
        var s: [Character] = []
        for letter in pattern where s.last != letter {
            s.append(letter)
        }
        let n = s.count
        guard n > 0 else { return 0 }
        var turns = Array(repeating: Array(repeating: 0, count: n), count: n)
        for i in stride(from: n - 1, through: 0, by: -1) {
            turns[i][i] = 1
            for j in stride(from: i + 1, to: n, by: 1) {
                var fewest = 1 + turns[i + 1][j]
                for k in stride(from: i + 2, through: j, by: 1) where s[k] == s[i] {
                    fewest = min(fewest, turns[i + 1][k - 1] + turns[k][j])
                }
                turns[i][j] = fewest
            }
        }
        return turns[0][n - 1]
    }
}
```

Why it's enough to consider these two cases: the turn that gives position i its final letter can be moved to the very front of the plan. Then either it stays visible only at i, or there's a first later position k where it stays visible. No other turn can cross position k, so the letters between i and k and the letters from k onwards are printed independently.

</Approach>
