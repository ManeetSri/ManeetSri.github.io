A water company has `n` pumping stations, numbered 0 to n − 1, joined by one-way pipes. Each pipe can carry at most a certain amount of water per second. Water may split and merge at stations, but every station except the source and the sink passes on exactly as much as it receives. Return the most water per second that can flow from `source` to `sink`.

`PipelineMaxFlow.maxFlow(_ n: Int, _ pipes: [[Int]], from source: Int, to sink: Int) -> Int`

Each pipe is `[from, to, capacity]`. There may be several pipes between the same two stations, in the same or opposite directions.

## Examples

| `n` | `pipes` | `source`, `sink` | Returns |
| --- | --- | --- | --- |
| `6` | `[[0, 1, 7], [0, 2, 9], [1, 2, 3], [1, 3, 6], [2, 4, 8], [4, 3, 2], [3, 5, 8], [4, 5, 7]]` | `0`, `5` | `14` |
| `4` | `[[0, 1, 1], [0, 2, 1], [1, 2, 1], [1, 3, 1], [2, 3, 1]]` | `0`, `3` | `2` |
| `3` | `[[0, 1, 3], [0, 1, 4], [1, 2, 5]]` | `0`, `2` | `5` |
| `4` | `[[0, 1, 5], [2, 3, 5]]` | `0`, `3` | `0`: no route at all |

In the first example, the pipes 1 → 3 and 2 → 4 together carry at most 6 + 8 = 14, and everything has to pass through one of them. In the second, sending one unit along 0 → 1 → 2 → 3 first leaves no second path, unless that flow through 1 → 2 can be undone.

## Constraints

- `2 ≤ n ≤ 500`, up to 5,000 pipes, `source ≠ sink`.
- `0 ≤ capacity ≤ 1,000,000,000`, and the answer fits in an `Int`.
- One test uses capacities of a billion. Plain Ford–Fulkerson with an unlucky choice of paths can need one augmentation per unit of flow there. Edmonds–Karp's bound, O(V · E²), doesn't depend on the capacities.

<Hints>
<Hint>
Keep a residual capacity for every pipe, plus a backward residual that starts at 0. Pushing f units along a pipe lowers its residual by f and raises the backward one by f, so later paths can cancel that flow.
</Hint>
<Hint>
Repeat: find a path from the source to the sink using only edges with residual capacity left, push the smallest residual on it (the bottleneck) along the whole path, and add that to the total. Stop when no path exists.
</Hint>
<Hint>
Find each path with BFS, remembering the edge that first reached each station, so you can walk back from the sink. Storing each pipe's forward edge at an even index `i` and its backward edge at `i ^ 1` makes "the reverse of edge e" a single XOR.
</Hint>
</Hints>

## Solutions

<Approach title="Ford–Fulkerson with DFS" time="O(E · F) for a maximum flow F" space="O(V + E)">

Find any augmenting path with DFS and push its bottleneck. With integer capacities each push adds at least 1, so it stops, but the number of pushes can be as large as the answer itself: two billion on the test with huge capacities, if the paths are chosen badly.

</Approach>

<Approach title="Edmonds–Karp" time="O(V · E²)" space="O(V + E)">

BFS finds the augmenting path with the fewest pipes. Shortest paths never get shorter as the algorithm runs, which caps the number of augmentations at O(V · E) whatever the capacities.

```swift
public enum PipelineMaxFlow {
    public static func maxFlow(_ n: Int, _ pipes: [[Int]], from source: Int, to sink: Int) -> Int {
        var head: [Int] = []                           // head[e]: the station edge e leads to
        var residual: [Int] = []                       // residual[e]: how much more e can carry
        var edgesOut = [[Int]](repeating: [], count: n)
        for pipe in pipes {
            edgesOut[pipe[0]].append(head.count)
            head.append(pipe[1])
            residual.append(pipe[2])
            edgesOut[pipe[1]].append(head.count)       // the backward edge starts with nothing to undo
            head.append(pipe[0])
            residual.append(0)
        }

        var total = 0
        while true {
            // BFS from the source, remembering the edge that first reached each station
            var reachedBy = [Int](repeating: -1, count: n)
            var reached = [Bool](repeating: false, count: n)
            reached[source] = true
            var queue = [source]
            var front = 0
            while front < queue.count && !reached[sink] {
                let u = queue[front]
                front += 1
                for e in edgesOut[u] where residual[e] > 0 && !reached[head[e]] {
                    reached[head[e]] = true
                    reachedBy[head[e]] = e
                    queue.append(head[e])
                }
            }
            if !reached[sink] { return total }         // no augmenting path: the flow is maximum

            // Walk back from the sink to find the bottleneck, then push that much along the path
            var bottleneck = Int.max
            var station = sink
            while station != source {
                let e = reachedBy[station]
                bottleneck = min(bottleneck, residual[e])
                station = head[e ^ 1]
            }
            station = sink
            while station != source {
                let e = reachedBy[station]
                residual[e] -= bottleneck
                residual[e ^ 1] += bottleneck
                station = head[e ^ 1]
            }
            total += bottleneck
        }
    }
}
```

`head[e ^ 1]` is where edge e starts: its partner points the other way. Parallel and opposite pipes each get their own pair of edges, so they need no special handling.

</Approach>

<Approach title="Dinic's algorithm" time="O(V² · E)" space="O(V + E)">

Each phase runs one BFS to label stations by distance from the source, then pushes flow with DFS only along edges that go one level further, until no more gets through. `nextEdge` remembers, per station, the first edge not yet proven useless in this phase, so no edge is retried in vain.

```swift
public enum PipelineMaxFlow {
    public static func maxFlow(_ n: Int, _ pipes: [[Int]], from source: Int, to sink: Int) -> Int {
        var head: [Int] = [], residual: [Int] = []
        var edgesOut = [[Int]](repeating: [], count: n)
        for pipe in pipes {
            edgesOut[pipe[0]].append(head.count); head.append(pipe[1]); residual.append(pipe[2])
            edgesOut[pipe[1]].append(head.count); head.append(pipe[0]); residual.append(0)
        }
        var level = [Int](repeating: -1, count: n)
        var nextEdge = [Int](repeating: 0, count: n)

        func push(_ u: Int, _ limit: Int) -> Int {
            if u == sink { return limit }
            while nextEdge[u] < edgesOut[u].count {
                let e = edgesOut[u][nextEdge[u]]
                if residual[e] > 0 && level[head[e]] == level[u] + 1 {
                    let pushed = push(head[e], min(limit, residual[e]))
                    if pushed > 0 {
                        residual[e] -= pushed
                        residual[e ^ 1] += pushed
                        return pushed
                    }
                }
                nextEdge[u] += 1                       // this edge is useless for the rest of the phase
            }
            return 0
        }

        var total = 0
        while true {
            // BFS: label every station with its distance from the source in the residual graph
            level = [Int](repeating: -1, count: n)
            level[source] = 0
            var queue = [source]
            var front = 0
            while front < queue.count {
                let u = queue[front]
                front += 1
                for e in edgesOut[u] where residual[e] > 0 && level[head[e]] == -1 {
                    level[head[e]] = level[u] + 1
                    queue.append(head[e])
                }
            }
            if level[sink] == -1 { return total }
            // DFS: push flow along level-increasing edges until none gets through (a blocking flow)
            nextEdge = [Int](repeating: 0, count: n)
            while true {
                let pushed = push(source, Int.max)
                if pushed == 0 { break }
                total += pushed
            }
        }
    }
}
```

The DFS is at most one call per level deep, so at most V calls.

</Approach>
