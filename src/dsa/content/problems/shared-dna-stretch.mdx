Two DNA strands are written as strings of the letters `A`, `C`, `G` and `T`. Return the length of the longest stretch of consecutive letters that appears in both. If they share no letter at all, return 0.

`SharedDNAStretch.longest(_ first: String, _ second: String) -> Int`

This is the longest common substring problem from [Longest common substring](/dsa/learn/dps-common-substring), at a size where its O(n · m) table can't be built.

## Examples

| `first` | `second` | Output |
| --- | --- | --- |
| `"ACGTACGT"` | `"TACG"` | `4`: `TACG` |
| `"GATTACA"` | `"TACAGAT"` | `4`: `TACA` |
| `"CCCCGATTCC"` | `"GATT"` | `4` |
| `"AAAA"` | `"CCCC"` | `0` |
| `""` | `"ACGT"` | `0` |

## Constraints

- Each strand holds 0 to 100,000 letters, all `A`, `C`, `G` or `T`.
- The tests include two strands of 100,000 letters. The dynamic programming table would have 10¹⁰ cells.

<Hints>
<Hint>
If the strands share a stretch of length L, they share a stretch of every shorter length too (cut letters off the end). So binary search on L.
</Hint>
<Hint>
To test a length L: is any window of length L in the first strand equal to some window of length L in the second? Put every window of the first strand in a set and look up every window of the second. To make each window O(1), use its hash rather than its letters.
</Hint>
<Hint>
Prefix hashes and powers give the hash of any window in O(1). Hash both strands with the same base and modulus, so equal stretches get equal hashes. Use the prime 2⁶¹ − 1: up to 100,000 hashes go into one set, and a small modulus would produce false matches.
</Hint>
</Hints>

## Solutions

<Approach title="Dynamic programming" time="O(n · m)" space="O(m)">

`run[i][j]` is the length of the common stretch ending at `first[i - 1]` and `second[j - 1]`: one more than `run[i - 1][j - 1]` when the letters match, 0 otherwise. Keeping one row at a time makes the memory small, but the time is 10¹⁰ steps for the large tests.

</Approach>

<Approach title="Binary search with rolling hashes" time="O((n + m) log min(n, m))" space="O(n + m)">

Binary search on the length, testing each length with a set of window hashes from the first strand.

```swift
public enum SharedDNAStretch {
    public static func longest(_ first: String, _ second: String) -> Int {
        let a = Array(first.utf8), b = Array(second.utf8)
        let base = UInt64.random(in: 256..<modulus)
        let hashesA = PrefixHashes(a, base: base)
        let hashesB = PrefixHashes(b, base: base)

        func shared(_ length: Int) -> Bool {
            var seen = Set<UInt64>(minimumCapacity: a.count - length + 1)
            for start in 0...(a.count - length) {
                seen.insert(hashesA.hash(start, start + length))
            }
            for start in 0...(b.count - length) where seen.contains(hashesB.hash(start, start + length)) {
                return true
            }
            return false
        }

        var low = 0, high = min(a.count, b.count)       // the answer is in low...high
        while low < high {
            let mid = (low + high + 1) / 2
            if shared(mid) { low = mid } else { high = mid - 1 }
        }
        return low
    }

    static let modulus: UInt64 = (1 << 61) - 1

    static func mulMod(_ x: UInt64, _ y: UInt64) -> UInt64 {
        let (high, low) = x.multipliedFullWidth(by: y)
        let sum = ((high << 3) | (low >> 61)) + (low & modulus)
        return sum >= modulus ? sum - modulus : sum
    }

    struct PrefixHashes {
        private var prefix: [UInt64], power: [UInt64]

        init(_ s: [UInt8], base: UInt64) {
            prefix = [UInt64](repeating: 0, count: s.count + 1)
            power = [UInt64](repeating: 1, count: s.count + 1)
            for i in s.indices {
                let value = SharedDNAStretch.mulMod(prefix[i], base) + UInt64(s[i])
                prefix[i + 1] = value >= SharedDNAStretch.modulus ? value - SharedDNAStretch.modulus : value
                power[i + 1] = SharedDNAStretch.mulMod(power[i], base)
            }
        }

        /// The hash of s[from..<to], in O(1).
        func hash(_ from: Int, _ to: Int) -> UInt64 {
            let shifted = SharedDNAStretch.mulMod(prefix[from], power[to - from])
            return prefix[to] >= shifted ? prefix[to] - shifted : prefix[to] + SharedDNAStretch.modulus - shifted
        }
    }
}
```

`mid` is never 0 inside the loop, so `0...(a.count - length)` is always a valid range. The search uses the upper middle, `(low + high + 1) / 2`, because the true branch sets `low = mid`.

</Approach>

<Approach title="Suffix array of both strands" time="O((n + m) log(n + m))" space="O(n + m)">

Join the strands with a separator that is neither `A`, `C`, `G` nor `T`, and build the suffix array and LCP array of the result. A shared stretch is a common prefix of two suffixes, one starting in each strand, and the best such pair is a pair of sorted neighbours. So the answer is the largest `lcp[p]` where `sa[p - 1]` and `sa[p]` start on different sides of the separator. The separator stops any common prefix from running across the join.

</Approach>

<Approach title="Suffix automaton" time="O(n + m)" space="O(n)">

Build the suffix automaton of the first strand, then walk the second through it, tracking the current state and the matched length. When a letter has no transition, follow suffix links, shortening the match to each state's `len`, until one exists or you're back at the start. The longest match seen is the answer.

</Approach>
