A coastline has several lighthouse beacons. Beacon i flashes at every whole second t ≥ 0 with `t % periods[i] == offsets[i]`. Return the first second at which every beacon flashes at once, or `nil` if that never happens.

`BeaconAlignment.firstSharedFlash(offsets: [Int], periods: [Int]) -> Int?`

## Examples

| `offsets` | `periods` | Output | Why |
| --- | --- | --- | --- |
| `[2, 3, 2]` | `[3, 5, 7]` | `23` | 23 = 7 × 3 + 2 = 4 × 5 + 3 = 3 × 7 + 2 |
| `[2, 4]` | `[4, 6]` | `10` | the beacons flash at 2, 6, 10, … and 4, 10, …; then every 12 seconds |
| `[1, 2]` | `[4, 6]` | `nil` | the first flashes at odd seconds, the second at even ones |
| `[5, 7, 2]` | `[6, 10, 15]` | `17` | periods that share factors still have a common time |
| `[5]` | `[9]` | `5` | one beacon: its first flash |
| `[3, 0]` | `[7, 1]` | `3` | a beacon with period 1 flashes every second |

## Constraints

- `1 ≤ offsets.count == periods.count ≤ 10,000`
- `1 ≤ periods[i] ≤ 10¹⁸` and `0 ≤ offsets[i] < periods[i]`
- The least common multiple of all the periods is at most 10¹⁸, whether or not the beacons ever align.
- The tests include two periods of about 10⁶ and 10¹², so intermediate products can reach 10²⁴.

<Hints>
<Hint>
You're solving a system of congruences t ≡ offsets[i] (mod periods[i]). The Chinese remainder theorem says there's one answer per lcm of the periods, if there's any. But the periods needn't be coprime, so the product formula won't do: merge the congruences two at a time.
</Hint>
<Hint>
To merge t ≡ a (mod m) with t ≡ b (mod n), write t = a + m·k. Then m·k ≡ b − a (mod n). With g = gcd(m, n), that needs g to divide b − a, or the beacons never align. Otherwise k ≡ ((b − a)/g) × (m/g)⁻¹ (mod n/g), and the merged congruence is t ≡ a + m·k (mod lcm(m, n)).
</Hint>
<Hint>
Extended Euclid on (m, n) gives both g and the inverse of m/g modulo n/g. The product ((b − a)/g) × inverse can need 120 bits: compute it with `multipliedFullWidth(by:)` and `dividingFullWidth(_:)`. Everything else stays below the lcm, so it fits.
</Hint>
</Hints>

## Solutions

<Approach title="Walk through one beacon's flashes" time="O(lcm / largest period × beacons)" space="O(1)">

Start at the first flash of the beacon with the largest period and step forward by that period, checking every other beacon each time, until all agree or you've passed the lcm. It's a fine check for small periods, but the lcm can be 10¹⁸.

</Approach>

<Approach title="Merge the congruences one at a time" time="O(beacons · log P)" space="O(1)">

Keep the current answer as t ≡ time (mod cycle), starting from t ≡ 0 (mod 1), which every second satisfies. Merge in each beacon with the steps from the hints. Because `time` stays below `cycle`, the answer at the end is already the smallest one.

```swift
public enum BeaconAlignment {
    public static func firstSharedFlash(offsets: [Int], periods: [Int]) -> Int? {
        var time = 0                                    // t ≡ 0 (mod 1) allows every time
        var cycle = 1
        for (offset, period) in zip(offsets, periods) {
            let (g, p, _) = extendedGCD(cycle, period)  // cycle·p + period·q = g
            let difference = offset - time
            guard difference % g == 0 else { return nil }
            let step = period / g                       // k only matters modulo period / g
            let target = ((difference / g) % step + step) % step
            let inverse = ((p % step) + step) % step    // (cycle / g)·p ≡ 1 (mod period / g)
            let k = mulMod(target, inverse, step)
            time += cycle * k                           // below lcm(cycle, period), so it fits
            cycle = cycle / g * period                  // the new lcm
        }
        return time
    }

    private static func extendedGCD(_ a: Int, _ b: Int) -> (g: Int, x: Int, y: Int) {
        var (oldR, r) = (a, b)
        var (oldS, s) = (1, 0)
        var (oldT, t) = (0, 1)
        while r != 0 {
            let q = oldR / r
            (oldR, r) = (r, oldR - q * r)
            (oldS, s) = (s, oldS - q * s)
            (oldT, t) = (t, oldT - q * t)
        }
        return (oldR, oldS, oldT)
    }

    private static func mulMod(_ a: Int, _ b: Int, _ m: Int) -> Int {
        m.dividingFullWidth(a.multipliedFullWidth(by: b)).remainder
    }
}
```

Why nothing else overflows: `time` is below `cycle` and k is below period / g, so time + cycle × k is at most lcm(cycle, period) − 1. And `cycle / g * period` divides before it multiplies, as in [GCD, LCM and Euclid's algorithm](/dsa/learn/math-gcd-lcm), so it's the lcm itself, at most 10¹⁸ by the constraints.

</Approach>
