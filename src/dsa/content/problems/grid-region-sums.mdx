Build a table that answers "what's the sum of this rectangle of cells?" for a fixed grid. Preparing the table may take one pass over the grid; after that, every query must be O(1).

`GridRegionSums.Table`, with `init(_ grid: [[Int]])` and `sum(top: Int, left: Int, bottom: Int, right: Int) -> Int`

The grid is indexed `grid[row][column]`, with row 0 at the top. A query covers every cell from row `top` to row `bottom` and from column `left` to column `right`, all **inclusive**.

## Examples

For this grid:

```text
3  0  1  4
5  6  3  2
1  2  0  1
```

| Query | Output | Cells |
| --- | --- | --- |
| `sum(top: 1, left: 1, bottom: 2, right: 2)` | `11` | 6 + 3 + 2 + 0 |
| `sum(top: 0, left: 0, bottom: 2, right: 3)` | `28` | the whole grid |
| `sum(top: 0, left: 3, bottom: 1, right: 3)` | `6` | 4 + 2 |
| `sum(top: 1, left: 0, bottom: 1, right: 3)` | `16` | the middle row |
| `sum(top: 0, left: 0, bottom: 0, right: 0)` | `3` | one cell |

## Constraints

- `0 ≤ rows, columns ≤ 300`, and every row has the same length.
- `-10⁴ ≤ grid[r][c] ≤ 10⁴`
- Every query has `0 ≤ top ≤ bottom < rows` and `0 ≤ left ≤ right < columns`.
- Up to 100,000 queries on one table. Building should be O(rows × columns) and each query O(1).

<Hints>
<Hint>
Adding up every cell in the rectangle costs up to 90,000 steps per query. As in 1D, precompute sums so each query is a few lookups. Store a table with one extra row and one extra column of zeros.
</Hint>
<Hint>
Let `prefix[r][c]` be the sum of rows `0..<r` and columns `0..<c`. Then `prefix[r + 1][c + 1]` is `grid[r][c]`, plus the block above it, plus the block to its left, minus the block above-left, which was counted twice.
</Hint>
<Hint>
For a query, take the block ending at the rectangle's bottom-right corner, `prefix[bottom + 1][right + 1]`. Subtract the strip above, `prefix[top][right + 1]`, and the strip to the left, `prefix[bottom + 1][left]`. The block above-left was subtracted twice, so add `prefix[top][left]` back.
</Hint>
</Hints>

## Solutions

<Approach title="Prefix sums along each row" time="O(rows × columns) to build, O(rows) per query" space="O(rows × columns)">

A halfway step: a 1D prefix array for every row turns each row of the rectangle into one subtraction. It's simpler to get right than the 2D table, and a useful check, but a tall rectangle still costs one step per row.

```swift
public struct Table {
    private let rowPrefix: [[Int]]

    public init(_ grid: [[Int]]) {
        rowPrefix = grid.map { row in
            var prefix = [0]
            for value in row {
                prefix.append(prefix[prefix.count - 1] + value)
            }
            return prefix
        }
    }

    public func sum(top: Int, left: Int, bottom: Int, right: Int) -> Int {
        var total = 0
        for r in top...bottom {
            total += rowPrefix[r][right + 1] - rowPrefix[r][left]
        }
        return total
    }
}
```

</Approach>

<Approach title="A summed-area table" time="O(rows × columns) to build, O(1) per query" space="O(rows × columns)">

The extra row and column of zeros are the 2D sentinel: a rectangle touching the top or left edge uses the same formula as any other. Rows are filled top to bottom and left to right, so the three values each cell needs are always ready.

```swift
public enum GridRegionSums {
    public struct Table {
        private let prefix: [[Int]]

        public init(_ grid: [[Int]]) {
            let rows = grid.count
            let columns = grid.first?.count ?? 0
            var prefix = Array(repeating: Array(repeating: 0, count: columns + 1), count: rows + 1)
            for r in 0..<rows {
                for c in 0..<columns {
                    prefix[r + 1][c + 1] = grid[r][c] + prefix[r][c + 1] + prefix[r + 1][c] - prefix[r][c]
                }
            }
            self.prefix = prefix
        }

        public func sum(top: Int, left: Int, bottom: Int, right: Int) -> Int {
            prefix[bottom + 1][right + 1] - prefix[top][right + 1] - prefix[bottom + 1][left] + prefix[top][left]
        }
    }
}
```

`grid.first?.count ?? 0` keeps an empty grid from crashing, since `grid[0]` doesn't exist then.

</Approach>
