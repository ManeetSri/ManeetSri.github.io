You're given equations between integer variables. Each is three strings: a variable name, either `"=="` or `"!="`, and another variable name, such as `["speed", "==", "rate"]`. Return true if you can give every variable an integer value so that all the equations are true at the same time.

`EquationConsistency.canSatisfy(_ equations: [[String]]) -> Bool`

## Examples

| `equations` | Returns | Why |
| --- | --- | --- |
| `[["a", "==", "b"], ["b", "!=", "c"]]` | true | a = b = 1, c = 2 |
| `[["a", "==", "b"], ["b", "==", "c"], ["a", "!=", "c"]]` | false | a, b and c must be equal |
| `[["a", "!=", "c"], ["a", "==", "b"], ["b", "==", "c"]]` | false | the same, with the inequality first |
| `[["p", "!=", "q"], ["q", "!=", "r"], ["r", "!=", "p"]]` | true | 1, 2 and 3 |
| `[["x", "!=", "x"]]` | false | nothing differs from itself |

## Constraints

- `0 ≤ equations.count ≤ 100,000`.
- Variable names are non-empty strings of lowercase letters, and the middle string is always `"=="` or `"!="`.
- The tests include a chain of 100,000 equalities.

<Hints>
<Hint>
If `a == b` and `b == c`, then `a == c`. Do inequalities chain the same way?
</Hint>
<Hint>
The equalities split the variables into groups that must share one value. An inequality can only fail, and it fails exactly when both its sides end up in the same group.
</Hint>
<Hint>
Give each name an index with a dictionary. Union every `==` first, and only then check every `!=`.
</Hint>
</Hints>

## Solutions

<Approach title="Union-find in two passes" time="O(m α(m))" space="O(m)">

Equality is transitive, so union-find's sets are exactly the groups of variables that must be equal. Inequality isn't transitive, so it never forces anything: it's broken only if its two sides share a group. Checking an inequality before all the equalities are in could miss a later equality that breaks it.

```swift
import DSAKit

public enum EquationConsistency {
    public static func canSatisfy(_ equations: [[String]]) -> Bool {
        var indexOf: [String: Int] = [:]
        for equation in equations {
            for name in [equation[0], equation[2]] where indexOf[name] == nil {
                indexOf[name] = indexOf.count
            }
        }
        var sets = UnionFind(count: indexOf.count)
        for equation in equations where equation[1] == "==" {
            sets.union(indexOf[equation[0]]!, indexOf[equation[2]]!)
        }
        for equation in equations where equation[1] == "!=" {
            if sets.connected(indexOf[equation[0]]!, indexOf[equation[2]]!) {
                return false
            }
        }
        return true
    }
}
```

If the checks pass, numbering the groups 1, 2, 3, … gives a valid assignment, so true really is true. For m equations, the cost is O(m) dictionary operations and O(m α(m)) for the unions and finds.

</Approach>
