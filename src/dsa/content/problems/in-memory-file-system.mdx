Build a small file system that lives entirely in memory: directories that contain directories and files, files that hold text, and the usual operations on absolute paths.

`InMemoryFileSystem.FileSystem` (a class), with `init()`, `makeDirectory(_:)`, `list(_:) -> [String]`, `append(_:toFile:)`, `read(_:) -> String?` and `remove(_:) -> Bool`

- A new file system holds only the empty root directory, `"/"`.
- `makeDirectory(path)` creates the directory and any missing directories above it, like `mkdir -p`. Making one that already exists changes nothing.
- `list(path)`: for a directory, the names of everything directly inside it, directories and files together, sorted with Swift's `<`. For a file, an array holding only its own name. For a path that doesn't exist, `[]`.
- `append(content, toFile: path)` adds text to the end of a file, creating the file (empty) and any missing directories above it first.
- `read(path)` returns a file's contents, or `nil` if there's no file at that path (including when it's a directory).
- `remove(path)` deletes a file, or a directory with everything inside it, and returns `true`; it returns `false` if nothing is there. The root can't be removed.

## Examples

| Calls on a new `FileSystem` | Result |
| --- | --- |
| `list("/")` | `[]` |
| `makeDirectory("/notes/swift")`, `append("Heaps.", toFile: "/notes/swift/heaps.txt")`, `append(" Tries.", toFile: "/notes/swift/heaps.txt")`, `append("milk", toFile: "/todo.txt")` | |
| `list("/")` | `["notes", "todo.txt"]` |
| `list("/notes/swift/heaps.txt")` | `["heaps.txt"]` |
| `read("/notes/swift/heaps.txt")` | `"Heaps. Tries."` |
| `read("/notes")` | `nil`: a directory, not a file |
| `remove("/notes")`, then `list("/")` | `true`, then `["todo.txt"]` |
| `remove("/")` | `false` |

## Constraints

- Paths are absolute: `"/"`, or `"/"` followed by names separated by single slashes, with no trailing slash. Names are 1 to 20 characters of letters, digits, `.`, `-` and `_`, and are never `.` or `..`.
- Calls never mix things up: no path is ever used as a file in one call and a directory in another while both exist.
- Up to 100,000 calls; directories can be 200 levels deep and hold 20,000 entries.

<Hint>
Split a path into its names with `path.split(separator: "/")`. It skips the empty piece before the first slash, so `"/"` gives no names at all, which is exactly the root. (For paths with `.` and `..`, see [Decode string and simplify path](/dsa/learn/stack-decode-simplify).)
</Hint>
<Hint>
Make each directory a class instance holding two dictionaries: `directories: [String: Directory]` and `files: [String: String]`. A class, because a directory is shared: the parent holds it, and your walking code holds it while it makes changes inside it.
</Hint>
<Hint>
Write one helper that walks a list of names from the root and returns the directory it reaches, optionally creating missing ones. Then every operation is "walk to the parent, then look at the last name". `files[name, default: ""] += content` appends in place.
</Hint>
</Hints>

## Solutions

<Approach title="One flat dictionary of full paths" time="O(total entries) per list" space="O(total path characters)">

Store every file as `[String: String]` from its full path to its contents, and every directory path in a `Set<String>`. Reading and appending are single lookups. But listing a directory has to scan **every** path in the whole system to find the ones whose parent it is, and removing a directory has to scan everything for the paths inside it.

```swift
public func list(_ path: String) -> [String] {
    let prefix = path == "/" ? "/" : path + "/"
    let children = (directories.union(files.keys)).filter {
        $0.hasPrefix(prefix) && $0 != path && !$0.dropFirst(prefix.count).contains("/")
    }
    return children.map { String($0.dropFirst(prefix.count)) }.sorted()
}
```

</Approach>

<Approach title="A tree of directory objects" time="O(path length) per walk, plus O(k log k) to sort k names" space="O(total entries)">

The tree matches the structure of the problem, so each operation touches only the directories on its path. Removing a directory is one dictionary removal: everything inside it goes with it, freed by ARC.

```swift
public enum InMemoryFileSystem {
    public final class FileSystem {
        private final class Directory {
            var directories: [String: Directory] = [:]
            var files: [String: String] = [:]
        }

        private let root = Directory()

        public init() {}

        public func makeDirectory(_ path: String) {
            _ = directory(at: names(in: path)[...], creating: true)
        }

        public func list(_ path: String) -> [String] {
            let parts = names(in: path)
            if let name = parts.last, let parent = directory(at: parts.dropLast(), creating: false),
               parent.files[name] != nil {
                return [name]                                    // a file lists itself
            }
            guard let folder = directory(at: parts[...], creating: false) else { return [] }
            return (Array(folder.directories.keys) + Array(folder.files.keys)).sorted()
        }

        public func append(_ content: String, toFile path: String) {
            let parts = names(in: path)
            guard let name = parts.last else { return }          // "/" is a directory, not a file
            let parent = directory(at: parts.dropLast(), creating: true)!
            parent.files[name, default: ""] += content           // appends in place
        }

        public func read(_ path: String) -> String? {
            let parts = names(in: path)
            guard let name = parts.last, let parent = directory(at: parts.dropLast(), creating: false) else {
                return nil
            }
            return parent.files[name]
        }

        @discardableResult
        public func remove(_ path: String) -> Bool {
            let parts = names(in: path)
            guard let name = parts.last, let parent = directory(at: parts.dropLast(), creating: false) else {
                return false                                     // the root can't be removed
            }
            if parent.files.removeValue(forKey: name) != nil {
                return true
            }
            return parent.directories.removeValue(forKey: name) != nil   // takes everything inside
        }

        /// "/a/b/c" gives ["a", "b", "c"], and "/" gives [].
        private func names(in path: String) -> [String] {
            path.split(separator: "/").map(String.init)
        }

        /// The directory reached by following `names` from the root, making missing ones if asked.
        private func directory(at names: ArraySlice<String>, creating: Bool) -> Directory? {
            var current = root
            for name in names {
                if let next = current.directories[name] {
                    current = next
                } else if creating {
                    let made = Directory()
                    current.directories[name] = made
                    current = made
                } else {
                    return nil
                }
            }
            return current
        }
    }
}
```

If `list` were called far more often than anything else, each directory could keep its names in an ordered structure (such as DSAKit's `SortedMap`) instead of sorting on every call.

</Approach>
