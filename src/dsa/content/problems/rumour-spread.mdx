An office seating plan is a grid of desks. `"K"` is someone who knows a rumour, `"U"` is someone who doesn't know it yet, and `"."` is an empty desk. Every minute, everyone who knows tells the people directly above, below, left and right of them. Empty desks pass nothing on.

Return the number of minutes until nobody is left unaware. Return `0` if nobody is unaware to begin with, and `-1` if someone will never hear it.

`RumourSpread.minutesUntilEveryoneKnows(_ seating: [String]) -> Int`

## Examples

| `seating` | Output |
| --- | --- |
| `["KUU", "UU.", ".UU"]` | `4` |
| `["KUUUK"]` | `2` |
| `["K.K", "UUU", "K.K"]` | `2` |
| `["KK", "K."]` | `0` |
| `["K.U"]` | `-1` |
| `["UU", "UU"]` | `-1` |

In the first example, the bottom-right person is 4 steps from the `K`: right, down, down, right. In the second, the two `K`s spread at the same time and meet in the middle after 2 minutes. In the third, the middle person sits between two empty desks, so they only hear in the second minute, from the people beside them.

## Constraints

- `0 ≤ seating.count ≤ 300`, and every row has the same length, at most 300.
- Every character is `"K"`, `"U"` or `"."`.
- An office with no rows, or with nobody unaware, needs `0` minutes.

<Hints>
<Hint>
A minute-by-minute simulation works: each minute, scan the whole grid and find every unaware person next to someone who knows. But on a 300 × 300 office, the rumour can take about 600 minutes, and each minute rescans 90,000 desks.
</Hint>
<Hint>
Only people who heard **last minute** can tell anyone new this minute. Keep them in a queue. Put every `K` in the queue at the start: this is BFS with several starting points at once.
</Hint>
<Hint>
Process the queue one ring at a time: note `queue.count`, dequeue exactly the people added before that point, and enqueue each unaware neighbour (changing them to `"K"` straight away, so nobody is enqueued twice). Each ring that tells someone new is one minute. Count the unaware people at the start, and subtract as they hear: if any are left when the queue runs dry, return `-1`.
</Hint>
</Hints>

## Solutions

<Approach title="Simulate minute by minute" time="O((rows × columns)²)" space="O(rows × columns)">

Each minute, build a list of unaware people with a neighbour who knows, then tell them all at once (telling them during the scan would let the rumour travel several desks in one minute). Stop when nobody new hears. The number of minutes can be proportional to the number of desks, and each minute scans every desk.

</Approach>

<Approach title="Multi-source BFS, one ring per minute" time="O(rows × columns)" space="O(rows × columns)">

Everyone who knows at the start is a source. BFS from all of them together reaches each person by the shortest route from their nearest source, and processing the queue ring by ring turns distances into minutes. Each person enters the queue once, when they first hear.

```swift
public enum RumourSpread {
    public static func minutesUntilEveryoneKnows(_ seating: [String]) -> Int {
        var desks = seating.map { Array($0) }
        var queue: [(row: Int, column: Int)] = []
        var unaware = 0
        for row in desks.indices {
            for column in desks[row].indices {
                if desks[row][column] == "K" {
                    queue.append((row, column))
                } else if desks[row][column] == "U" {
                    unaware += 1
                }
            }
        }

        let directions = [(-1, 0), (1, 0), (0, -1), (0, 1)]
        var head = 0
        var minutes = 0
        while head < queue.count && unaware > 0 {
            let ringEnd = queue.count                // everyone who heard by the end of this minute
            while head < ringEnd {
                let (row, column) = queue[head]
                head += 1
                for (dr, dc) in directions {
                    let r = row + dr
                    let c = column + dc
                    guard r >= 0, r < desks.count, c >= 0, c < desks[r].count else { continue }
                    guard desks[r][c] == "U" else { continue }
                    desks[r][c] = "K"                // mark as they hear: never enqueued twice
                    unaware -= 1
                    queue.append((r, c))
                }
            }
            minutes += 1
        }
        return unaware == 0 ? minutes : -1
    }
}
```

The loop stops as soon as `unaware` reaches 0, so a final ring that tells nobody new isn't counted as a minute. The queue is an array with a head index, as in the head-index queue lesson; DSAKit's `Queue` would work as well.

</Approach>
