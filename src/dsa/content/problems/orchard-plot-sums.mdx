An orchard is laid out as a grid of plots, each holding a count of fruit. Counts change as plots are harvested or replanted, and in between, the farm asks for the total over rectangles of plots. Build a structure that handles both, with every change so far reflected in every total.

`OrchardPlotSums.Orchard`, with `init(_ grid: [[Int]])`, `set(row: Int, column: Int, to value: Int)` and `total(top: Int, left: Int, bottom: Int, right: Int) -> Int`

The grid is indexed `grid[row][column]`, with row 0 at the top. A total covers every plot from row `top` to row `bottom` and from column `left` to column `right`, all **inclusive**. `set` replaces a plot's count; it doesn't add to it. This is [Grid region sums](/dsa/practice/grid-region-sums) from M20, with changes allowed.

## Examples

For this orchard, one call after another:

```text
3  0  1  4
5  6  3  2
1  2  0  1
```

| Call | Output | Plots |
| --- | --- | --- |
| `total(top: 0, left: 0, bottom: 2, right: 3)` | `28` | the whole orchard |
| `total(top: 1, left: 1, bottom: 2, right: 2)` | `11` | 6 + 3 + 2 + 0 |
| `set(row: 1, column: 2, to: 10)` | | the 3 becomes 10 |
| `total(top: 1, left: 1, bottom: 2, right: 2)` | `18` | 6 + 10 + 2 + 0 |
| `total(top: 0, left: 3, bottom: 2, right: 3)` | `7` | the last column: 4 + 2 + 1 |

## Constraints

- `1 ≤ rows, columns ≤ 500`, and every row has the same length.
- `0 ≤` every count, old or new, `≤ 10⁹`
- Every call has `0 ≤ top ≤ bottom < rows`, `0 ≤ left ≤ right < columns`, and a valid `row` and `column`.
- Up to 100,000 calls, mixed in any order. The tests use a 500 × 500 orchard with large rectangles, so adding up every plot of each rectangle is too slow.

<Hints>
<Hint>
2D prefix sums answer a rectangle in O(1), but one changed plot alters every prefix value below and to the right of it. A prefix-sum array per row is a middle ground: a change rebuilds one row, and a total costs one subtraction per row.
</Hint>
<Hint>
For O(log rows × log columns) per call, use a 2D Fenwick tree: slot (i, j) covers the rows i is responsible for crossed with the columns j is responsible for. Both loops are the 1D loops, one nested inside the other.
</Hint>
<Hint>
A Fenwick tree adds; it doesn't set. Keep a copy of the grid and add the difference between the new count and the old one. A rectangle is four prefix rectangles: the big one to its bottom-right corner, minus the strip above, minus the strip to the left, plus the corner block that was removed twice.
</Hint>
</Hints>

## Solutions

<Approach title="Prefix sums along each row" time="O(columns) per change, O(rows) per total" space="O(rows × columns)">

One prefix-sum array per row. A change rebuilds its row; a total adds one difference per row of the rectangle. On a 500 × 500 orchard, both are a few hundred steps, which is fast enough here, and a good stepping stone.

```swift
public struct Orchard {
    private var grid: [[Int]]
    private var prefixes: [[Int]]

    public init(_ grid: [[Int]]) {
        self.grid = grid
        prefixes = grid.map { row in
            var prefix = [0]
            for value in row { prefix.append(prefix.last! + value) }
            return prefix
        }
    }

    public mutating func set(row: Int, column: Int, to value: Int) {
        grid[row][column] = value
        var running = 0
        for c in 0..<grid[row].count {
            running += grid[row][c]
            prefixes[row][c + 1] = running
        }
    }

    public func total(top: Int, left: Int, bottom: Int, right: Int) -> Int {
        (top...bottom).reduce(0) { $0 + prefixes[$1][right + 1] - prefixes[$1][left] }
    }
}
```

</Approach>

<Approach title="2D Fenwick tree" time="O(rows × columns) to build, O(log rows × log columns) per call" space="O(rows × columns)">

The tree from [2D BIT](/dsa/learn/bit-2d). The build uses the O(n) parent-passing trick twice: along every row, then along every column. That works because the 2D tree is the 1D tree applied in each direction.

```swift
public enum OrchardPlotSums {
    public struct Orchard {
        private var tree: [[Int]]                  // 1-indexed in both directions
        private var plots: [[Int]]
        private let rows: Int
        private let columns: Int

        public init(_ grid: [[Int]]) {
            plots = grid
            rows = grid.count
            columns = grid.first?.count ?? 0
            tree = Array(repeating: Array(repeating: 0, count: columns + 1), count: rows + 1)
            for r in 0..<rows {
                for c in 0..<columns {
                    tree[r + 1][c + 1] = grid[r][c]
                }
            }
            for i in 1..<(rows + 1) {              // pass totals up along every row...
                for j in 1..<(columns + 1) {
                    let parent = j + (j & -j)
                    if parent <= columns { tree[i][parent] += tree[i][j] }
                }
            }
            for i in 1..<(rows + 1) {              // ...then along every column
                let parent = i + (i & -i)
                if parent <= rows {
                    for j in 1..<(columns + 1) {
                        tree[parent][j] += tree[i][j]
                    }
                }
            }
        }

        public mutating func set(row: Int, column: Int, to value: Int) {
            let delta = value - plots[row][column]
            plots[row][column] = value
            var i = row + 1
            while i <= rows {
                var j = column + 1
                while j <= columns {
                    tree[i][j] += delta
                    j += j & -j
                }
                i += i & -i
            }
        }

        private func prefix(_ rowCount: Int, _ columnCount: Int) -> Int {   // rows 0..<rowCount, columns 0..<columnCount
            var total = 0
            var i = rowCount
            while i > 0 {
                var j = columnCount
                while j > 0 {
                    total += tree[i][j]
                    j -= j & -j
                }
                i -= i & -i
            }
            return total
        }

        public func total(top: Int, left: Int, bottom: Int, right: Int) -> Int {
            prefix(bottom + 1, right + 1) - prefix(top, right + 1) - prefix(bottom + 1, left) + prefix(top, left)
        }
    }
}
```

At this size both approaches pass. On a 5,000 × 5,000 orchard, a total over a tall rectangle would cost thousands of steps with row prefixes but under 200 with the 2D tree, though the grid alone would then take 200 MB.

</Approach>
