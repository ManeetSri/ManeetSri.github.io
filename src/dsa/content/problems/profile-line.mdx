Build a one-line profile from a name, an age and a city, including the person's age next year.

`ProfileLine.describe(name: String, age: Int, city: String) -> String` returns `"<name> is <age> and lives in <city>. Next year: <age + 1>."`

You haven't written functions yet, and you don't need to: the exercise file already has the function. Inside it, `name`, `age` and `city` work like constants that already hold the values. Replace `return ""` with `return` followed by your string.

## Examples

| Call | Returns |
| --- | --- |
| `describe(name: "Maneet", age: 29, city: "Pune")` | `"Maneet is 29 and lives in Pune. Next year: 30."` |
| `describe(name: "Grace", age: 85, city: "New York")` | `"Grace is 85 and lives in New York. Next year: 86."` |
| `describe(name: "Sam", age: 0, city: "Oslo")` | `"Sam is 0 and lives in Oslo. Next year: 1."` |

## Constraints

- `0 ≤ age ≤ 150`
- `name` and `city` are non-empty, at most 50 characters, and may contain spaces.
- The full stops, spaces and capital letters must match exactly.

<Hints>
<Hint>
String interpolation puts a value inside text: `"\(name) is ..."`.
</Hint>
<Hint>
Interpolation accepts any expression, not only a name. What goes inside `\( )` to get next year's age?
</Hint>
<Hint>
`\(age + 1)` works out the sum and inserts it. The whole answer is one `return` with one string.
</Hint>
</Hints>

## Solutions

<Approach title="One interpolated string" time="O(n)" space="O(n)">

Every part of the line goes into a single string. The last interpolation does the arithmetic inside the parentheses.

```swift
public enum ProfileLine {
    public static func describe(name: String, age: Int, city: String) -> String {
        return "\(name) is \(age) and lives in \(city). Next year: \(age + 1)."
    }
}
```

Building the string copies each character once, so time and space grow with the length of the result, *n*.

</Approach>

<Approach title="Name the sum first" time="O(n)" space="O(n)">

If the expression inside `\( )` gets long, work it out on its own line and give it a clear name. Here it's a matter of taste, but it's a good habit for longer calculations.

```swift
public enum ProfileLine {
    public static func describe(name: String, age: Int, city: String) -> String {
        let nextAge = age + 1
        return "\(name) is \(age) and lives in \(city). Next year: \(nextAge)."
    }
}
```

</Approach>
