Work with two's complement bit patterns as strings of `0` and `1`, for any width from 1 to 64 bits. In a pattern of width w, the leftmost bit is worth −2^(w − 1) and every other bit k (counting from the right, starting at 0) is worth +2ᵏ.

`TwosComplementStrings.pattern(of value: Int, width: Int) -> String` returns the exactly `width`-character pattern that stores `value`.

`TwosComplementStrings.value(of pattern: String) -> Int` reads a pattern back, taking its width from its length.

`TwosComplementStrings.negated(_ pattern: String) -> String` flips every bit and adds 1, keeping the same width and dropping any carry off the left end.

## Examples

| Call | Output | Why |
| --- | --- | --- |
| `pattern(of: 5, width: 8)` | `"00000101"` | |
| `pattern(of: -5, width: 8)` | `"11111011"` | −128 + 123 |
| `pattern(of: -1, width: 16)` | `"1111111111111111"` | −1 is all ones at every width |
| `pattern(of: 300, width: 16)` | `"0000000100101100"` | 256 + 32 + 8 + 4 |
| `value(of: "11111011")` | `-5` | |
| `value(of: "0101")` | `5` | the leftmost bit is 0 |
| `value(of: "1000")` | `-8` | only the negative bit |
| `negated("00000101")` | `"11111011"` | −5 |
| `negated("10000000")` | `"10000000"` | −128 has no positive partner in 8 bits |

## Constraints

- `1 ≤ width ≤ 64`, and `value` fits in `width` bits: −2^(width − 1) ≤ value ≤ 2^(width − 1) − 1.
- Patterns have 1 to 64 characters, all `0` or `1`.
- Careful: `String(-5, radix: 2)` gives `"-101"`, not the stored bits.

<Hints>
<Hint>
The lowest `width` bits of a value's 64-bit pattern are its `width`-bit pattern: two's complement agrees at every width on those bits. `UInt64(bitPattern: Int64(value))` gives you those 64 bits as an ordinary unsigned number, with no minus sign. Its binary digits come out lowest first with `% 2` and `/ 2`, so collect `width` of them and reverse.
</Hint>
<Hint>
To read a pattern, use the place values directly. The bits after the first one are an ordinary binary number: double a running total and add each bit. The first bit, if it's `1`, adds −2^(width − 1). Get that weight by starting at −1 and doubling width − 1 times: for width 64 it reaches −2⁶³, which is exactly `Int.min`, so nothing overflows.
</Hint>
<Hint>
For `negated`, follow the lesson's recipe on the characters themselves. Flip every character, then add 1 from the right: each `1` becomes `0` and carries left, and the first `0` becomes `1` and stops the carry. If the carry runs off the left end, drop it. No arithmetic, so the minimum value can't overflow.
</Hint>
</Hints>

## Solutions

<Approach title="Place values and character arithmetic" time="O(width)" space="O(width)">

`pattern` peels binary digits off the unsigned reading of the stored bits, which never traps, even for `Int.min`. `value` adds up place values exactly as the lesson's table does, with the leftmost bit's weight built by doubling −1, so even 64 bits stay inside `Int`. `negated` does "flip, then add 1" with characters, carrying from the right.

```swift
public enum TwosComplementStrings {
    public static func pattern(of value: Int, width: Int) -> String {
        var bits = UInt64(bitPattern: Int64(value))
        var digits: [Character] = []
        for _ in 0..<width {
            digits.append(bits % 2 == 1 ? "1" : "0")
            bits /= 2
        }
        return String(digits.reversed())
    }

    public static func value(of pattern: String) -> Int {
        let characters = Array(pattern)
        var rest = 0
        for character in characters.dropFirst() {
            rest = rest * 2 + (character == "1" ? 1 : 0)
        }
        guard characters[0] == "1" else {
            return rest
        }
        var weight = -1
        for _ in 1..<characters.count {
            weight *= 2
        }
        return weight + rest
    }

    public static func negated(_ pattern: String) -> String {
        var characters = Array(pattern).map { $0 == "1" ? Character("0") : Character("1") }
        var index = characters.count - 1
        while index >= 0 && characters[index] == "1" {
            characters[index] = "0"
            index -= 1
        }
        if index >= 0 {
            characters[index] = "1"
        }
        return String(characters)
    }
}
```

There's a shortcut for `negated` worth knowing: scanning from the right, keep every bit up to and including the first `1`, and flip everything to its left. The flipped trailing zeros all carry, which is why they come back unchanged. Check your functions against each other: `value(of: pattern(of: x, width: w))` should give back x, and negating twice should return the original pattern.

</Approach>
