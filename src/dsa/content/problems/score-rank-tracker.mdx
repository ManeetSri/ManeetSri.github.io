Scores arrive one at a time, and the same score can arrive many times. At any moment, you must be able to say how many recorded scores are at most some value, and which score is the kth smallest, counting repeats.

`ScoreRankTracker.Tracker`, a class with `init()`, `record(_:)`, `countAtMost(_:) -> Int`, `kthSmallest(_:) -> Int?` and `count: Int`

`kthSmallest(1)` is the smallest score. It returns `nil` if k is below 1 or more than the number of scores recorded. Aim for O(log n) per operation.

## Examples

| Calls | Results |
| --- | --- |
| `record` 50, 20, 70, 20 | |
| `countAtMost(20)`, `countAtMost(49)`, `countAtMost(50)` | `2`, `2`, `3` |
| `countAtMost(0)`, `countAtMost(100)` | `0`, `4` |
| `kthSmallest(1)`, `kthSmallest(2)`, `kthSmallest(3)`, `kthSmallest(4)` | `20`, `20`, `50`, `70` |
| `kthSmallest(0)`, `kthSmallest(5)` | `nil`, `nil` |

Both 20s count: two scores are at most 20, and they're the first and second smallest.

## Constraints

- Up to 200,000 scores, with a query after every `record` in the largest test.
- Scores are any `Int`, from `Int.min` to `Int.max`.

<Hints>
<Hint>
A sorted array answers both questions quickly: `countAtMost(x)` is an upper-bound binary search, and `kthSmallest(k)` is `sorted[k - 1]`. The trouble is `record`, which must insert in the middle: O(n) shifts each time, billions of moves in all for 200,000 scores. It's worth writing first, as a checker, but aim for O(log n).
</Hint>
<Hint>
Use a balanced BST, and store in every node the **size** of its subtree: how many scores it and its descendants hold. Keep sizes correct whenever children change, in rotations, or in split and merge if you use a treap. With repeats, give each node a `copies` count and include it in the size.
</Hint>
<Hint>
With sizes, one walk from the root answers each query. For `countAtMost(x)`: at a node with score ≤ x, add its left subtree's size and its copies, then go right; otherwise go left. For `kthSmallest(k)`: if k is at most the left size, go left; if it's within the node's copies, this is the answer; otherwise subtract both and go right.
</Hint>
</Hints>

## Solutions

<Approach title="A sorted array" time="O(n) per record, O(log n) per query" space="O(n)">

Insert each score at its upper bound, so equal scores stay together. Queries are binary searches. It's short and correct, but `insert(_:at:)` shifts about half the array on average: around 10¹⁰ element moves for 200,000 scores. Swift moves them with fast bulk memory copies, so this version gets through the tests in a second or two, but its cost grows with n²: ten times as many scores means a hundred times the shifting, where the treap below does a little over ten times the work.

```swift
public final class Tracker {
    private var sorted: [Int] = []

    public init() {}

    /// The number of scores ≤ score: the first index whose score is greater.
    private func upperBound(_ score: Int) -> Int {
        var low = 0
        var high = sorted.count
        while low < high {
            let mid = low + (high - low) / 2
            if sorted[mid] <= score { low = mid + 1 } else { high = mid }
        }
        return low
    }

    public func record(_ score: Int) {
        sorted.insert(score, at: upperBound(score))
    }

    public func countAtMost(_ score: Int) -> Int {
        upperBound(score)
    }

    public func kthSmallest(_ k: Int) -> Int? {
        k >= 1 && k <= sorted.count ? sorted[k - 1] : nil
    }

    public var count: Int {
        sorted.count
    }
}
```

</Approach>

<Approach title="A treap with subtree sizes" time="O(log n) expected per operation" space="O(n)">

This is the treap from [Treaps: split and merge](/dsa/learn/bal-treap), with a `size` and a `copies` count in each node. A new score is inserted with split and merge, which recompute sizes as they relink nodes. A repeated score adds one copy, and one to the size of every node on its search path. Priorities come from a seeded generator, so the tree's shape is the same on every run.

```swift
public enum ScoreRankTracker {
    public final class Tracker {
        private final class Node {
            let score: Int
            let priority: UInt64
            var copies = 1
            var size = 1                                     // scores in this subtree, repeats included
            var left: Node?
            var right: Node?

            init(score: Int, priority: UInt64) {
                self.score = score
                self.priority = priority
            }
        }

        private var root: Node?
        private var seed: UInt64 = 2_024
        public private(set) var count = 0

        public init() {}

        public func record(_ score: Int) {
            count += 1
            if contains(score) {
                var current = root                           // one more score below every node on the path
                while let node = current {
                    node.size += 1
                    if score == node.score {
                        node.copies += 1
                        return
                    }
                    current = score < node.score ? node.left : node.right
                }
            }
            let (smaller, rest) = Self.split(root, below: score)
            root = Self.merge(Self.merge(smaller, Node(score: score, priority: nextPriority())), rest)
        }

        public func countAtMost(_ score: Int) -> Int {
            var total = 0
            var current = root
            while let node = current {
                if node.score <= score {
                    total += Self.size(node.left) + node.copies   // all of these are ≤ score
                    current = node.right
                } else {
                    current = node.left
                }
            }
            return total
        }

        public func kthSmallest(_ k: Int) -> Int? {
            guard k >= 1 && k <= count else { return nil }
            var remaining = k
            var current = root
            while let node = current {
                let leftSize = Self.size(node.left)
                if remaining <= leftSize {
                    current = node.left
                } else if remaining <= leftSize + node.copies {
                    return node.score
                } else {
                    remaining -= leftSize + node.copies
                    current = node.right
                }
            }
            return nil
        }

        private func contains(_ score: Int) -> Bool {
            var current = root
            while let node = current {
                if score == node.score { return true }
                current = score < node.score ? node.left : node.right
            }
            return false
        }

        /// SplitMix64: a seeded generator, so priorities are random-looking but repeatable.
        private func nextPriority() -> UInt64 {
            seed &+= 0x9E37_79B9_7F4A_7C15
            var z = seed
            z = (z ^ (z >> 30)) &* 0xBF58_476D_1CE4_E5B9
            z = (z ^ (z >> 27)) &* 0x94D0_49BB_1331_11EB
            return z ^ (z >> 31)
        }

        private static func size(_ node: Node?) -> Int {
            node?.size ?? 0
        }

        private static func update(_ node: Node) {
            node.size = size(node.left) + node.copies + size(node.right)
        }

        /// Splits into scores below `key` and scores at or above it.
        private static func split(_ node: Node?, below key: Int) -> (Node?, Node?) {
            guard let node else { return (nil, nil) }
            if node.score < key {
                let (smaller, larger) = split(node.right, below: key)
                node.right = smaller
                update(node)
                return (node, larger)
            } else {
                let (smaller, larger) = split(node.left, below: key)
                node.left = larger
                update(node)
                return (smaller, node)
            }
        }

        /// Joins two treaps where every score in `a` is below every score in `b`.
        private static func merge(_ a: Node?, _ b: Node?) -> Node? {
            guard let a else { return b }
            guard let b else { return a }
            if a.priority > b.priority {
                a.right = merge(a.right, b)
                update(a)
                return a
            } else {
                b.left = merge(a, b.left)
                update(b)
                return b
            }
        }
    }
}
```

An AVL tree from [AVL trees: insert and delete](/dsa/learn/bal-avl) works equally well: update `size` next to `height` in the same places, including both nodes of every rotation. If all the scores were known in advance, a Fenwick tree over their sorted positions would be shorter still; you'll meet those later in the course.

</Approach>
