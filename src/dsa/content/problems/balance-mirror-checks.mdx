Write four small checks and changes for binary trees:

- `BalanceMirrorChecks.isBalanced(_ root: TreeNode?) -> Bool`: true when, at every node, the heights of the left and right subtrees differ by at most 1.
- `BalanceMirrorChecks.isSymmetric(_ root: TreeNode?) -> Bool`: true when the tree is its own mirror image, in shape and values.
- `BalanceMirrorChecks.mirrored(_ root: TreeNode?) -> TreeNode?`: turn the tree into its mirror image in place, by swapping the children of every node, and return the root. Reuse the nodes.
- `BalanceMirrorChecks.contains(_ pattern: TreeNode?, in tree: TreeNode?) -> Bool`: true when some node of `tree`, together with everything below it, is exactly `pattern`.

`TreeNode` comes from DSAKit. Trees are written in level order, with `nil` for a missing child, the way `TreeNode.make` takes them. The empty tree is balanced and symmetric, and an empty pattern is inside every tree.

## Examples

| Call | Output |
| --- | --- |
| `isBalanced([5, 2, 8, nil, nil, 6, 9])` | `true` |
| `isBalanced([1, 2, 2, 3, nil, nil, 3, 4, nil, nil, 4])` | `false` |
| `isSymmetric([1, 2, 2, 3, 4, 4, 3])` | `true` |
| `isSymmetric([1, 2, 2, nil, 3, nil, 3])` | `false` |
| `mirrored([6, 3, 8, 1, 4, 7, 9])` | `[6, 8, 3, 9, 7, 4, 1]` |
| `mirrored([5, 3, nil, nil, 4])` | `[5, nil, 3, 4]` |
| `contains([2, 1, 5], in: [7, 2, 9, 1, 5])` | `true` |
| `contains([2, 1], in: [7, 2, 9, 1, 5])` | `false` |
| `contains([9], in: [7, 2, 9, 1, 5])` | `true` |

The second tree is two chains of three below the root. The root's subtrees both have height 3, but each 2 has a subtree of height 2 on one side and nothing on the other, so the tree isn't balanced.

`[2, 1]` isn't inside `[7, 2, 9, 1, 5]` because the tree's 2 also has a right child, 5. A match must include everything below the node.

## Constraints

- Trees have at most 131,071 nodes and are at most 25 levels deep.
- Values are any `Int`, and can repeat.
- Aim for O(n) for the first three. For `contains`, trying every node is fine.

<Hints>
<Hint>
For `isBalanced`, a top-down check that measures heights at every node repeats work. Instead, write one function that returns a subtree's height as an `Int?`, with `nil` meaning "unbalanced somewhere below". A `guard let` on both children's results passes a `nil` straight up.
</Hint>
<Hint>
For `isSymmetric`, compare the root's two subtrees as mirrors: their values must match, the left's left must mirror the right's right, and the left's right must mirror the right's left. For `mirrored`, `(node.left, node.right) = (node.right, node.left)` swaps safely, then do the same below.
</Hint>
<Hint>
For `contains`, write a same-tree check (switch on the pair of optionals) and try it at every node of the big tree. It stops at the first difference, so most attempts are quick.
</Hint>
</Hints>

## Solutions

<Approach title="Bottom-up heights, mirror pairs and a same-tree search" time="O(n); contains is O(m · n) worst case" space="O(h)">

Each check is a short recursion. `contains` visits the big tree with a stack and tries the pattern wherever the root value matches.

```swift
import DSAKit

public enum BalanceMirrorChecks {
    public static func isBalanced(_ root: TreeNode?) -> Bool {
        // The height of node's subtree, or nil if some subtree inside it is unbalanced
        func checkedHeight(_ node: TreeNode?) -> Int? {
            guard let node else { return 0 }
            guard let left = checkedHeight(node.left),
                  let right = checkedHeight(node.right),
                  abs(left - right) <= 1 else { return nil }
            return 1 + max(left, right)
        }
        return checkedHeight(root) != nil
    }

    public static func isSymmetric(_ root: TreeNode?) -> Bool {
        func areMirrors(_ a: TreeNode?, _ b: TreeNode?) -> Bool {
            switch (a, b) {
            case (nil, nil):
                return true
            case let (a?, b?):
                return a.value == b.value && areMirrors(a.left, b.right) && areMirrors(a.right, b.left)
            default:
                return false
            }
        }
        return areMirrors(root?.left, root?.right)
    }

    @discardableResult
    public static func mirrored(_ root: TreeNode?) -> TreeNode? {
        guard let root else { return nil }
        let oldLeft = root.left
        root.left = mirrored(root.right)
        root.right = mirrored(oldLeft)
        return root
    }

    public static func contains(_ pattern: TreeNode?, in tree: TreeNode?) -> Bool {
        guard let pattern else { return true }
        func isSame(_ a: TreeNode?, _ b: TreeNode?) -> Bool {
            switch (a, b) {
            case (nil, nil):
                return true
            case let (a?, b?):
                return a.value == b.value && isSame(a.left, b.left) && isSame(a.right, b.right)
            default:
                return false
            }
        }
        var pending: [TreeNode] = tree.map { [$0] } ?? []
        while let node = pending.popLast() {
            if node.value == pattern.value && isSame(node, pattern) {
                return true
            }
            if let left = node.left { pending.append(left) }
            if let right = node.right { pending.append(right) }
        }
        return false
    }
}
```

<Approach title="contains in linear time: number every distinct subtree" time="O(m + n) on average" space="O(m + n)">

A subtree is described exactly by its root value and the IDs of its two subtrees. A dictionary from that triple to an ID gives identical subtrees identical IDs, so the pattern is inside the tree exactly when its ID is one of the tree's.

```swift
struct Shape: Hashable {
    let value: Int
    let left: Int                                   // 0 is the empty tree
    let right: Int
}

public static func contains(_ pattern: TreeNode?, in tree: TreeNode?) -> Bool {
    guard pattern != nil else { return true }
    var ids: [Shape: Int] = [:]
    var idsInTree: Set<Int> = []
    var recording = true
    func id(of node: TreeNode?) -> Int {
        guard let node else { return 0 }
        let shape = Shape(value: node.value, left: id(of: node.left), right: id(of: node.right))
        let number = ids[shape] ?? ids.count + 1
        ids[shape] = number
        if recording { idsInTree.insert(number) }
        return number
    }
    _ = id(of: tree)
    recording = false
    return idsInTree.contains(id(of: pattern))
}
```

</Approach>
