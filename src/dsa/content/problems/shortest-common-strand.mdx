A lab has read several short fragments of one long strand of letters, and wants the shortest strand that could contain them all. Given the fragments, return the length of the shortest string that contains every fragment as a contiguous piece. The fragments are all different, and no fragment appears inside another one.

`ShortestCommonStrand.shortestLength(_ fragments: [String]) -> Int`

## Examples

| `fragments` | Output |
| --- | --- |
| `["CATG", "TGCA", "GCAT"]` | `6` |
| `["CDE", "ABC", "EFG"]` | `7` |
| `["ABC", "XYZ"]` | `6` |
| `["ABAB", "BABA"]` | `5` |
| `["SNOW"]` | `4` |

In the first example, `"TGCATG"` holds all three: `TGCA` at the start, `GCAT` from the second letter and `CATG` from the third. Gluing them in the order given, `"CATGCAT"`, needs 7. In the second, `"ABCDEFG"` shares a C and an E. In the third, nothing overlaps, so the strand is the two fragments side by side.

## Constraints

- `1 ≤ fragments.count ≤ 12`
- Each fragment has `1` to `20` capital letters, `A` to `Z`.
- The fragments are distinct, and none is a substring of another.
- With 12 fragments there are 479 million orders, so trying them all is far too slow.

<Hints>
<Hint>
Since no fragment sits inside another, the fragments appear in the strand one after another, each starting later than the one before. For a fixed order, the shortest strand overlaps each neighbouring pair as much as it can.
</Hint>
<Hint>
Precompute `overlap[a][b]`: the longest suffix of fragment a that's also a prefix of fragment b. The strand's length is the total length minus the overlaps along the chosen order, so you want the order that saves the most.
</Hint>
<Hint>
That's an open path through every fragment, as in TSP: `saved[mask][last]` = the most letters saved by a chain using exactly the fragments in `mask` and ending with `last`. Any fragment can start the chain, and the answer is the total length minus the best `saved[full][last]`.
</Hint>
</Hints>

## Solutions

<Approach title="Every order" time="O(n! · n · L)" space="O(n · L)">

Try every order of the fragments, gluing each one on with the largest overlap, and keep the shortest result. That's what the tests do on up to six fragments. With twelve it would take far too long.

</Approach>

<Approach title="Bitmask DP over the order" time="O(n² · L² + 2ⁿ · n²)" space="O(2ⁿ · n)">

First the overlaps, checking each length from the longest possible down. Then a TSP-style DP with no fixed start and no return trip. The table is one flat array indexed by `mask * n + last`, and -1 marks a chain that doesn't exist yet.

```swift
public enum ShortestCommonStrand {
    public static func shortestLength(_ fragments: [String]) -> Int {
        let words = fragments.map { Array($0.utf8) }
        let n = words.count
        if n == 0 { return 0 }

        // overlap[i][j]: the longest suffix of i that is also a prefix of j
        var overlap = [[Int]](repeating: [Int](repeating: 0, count: n), count: n)
        for i in 0..<n {
            for j in 0..<n where i != j {
                let a = words[i], b = words[j]
                for k in stride(from: min(a.count, b.count) - 1, through: 1, by: -1)
                where a[(a.count - k)...] == b[..<k] {
                    overlap[i][j] = k
                    break
                }
            }
        }

        let full = 1 << n
        var saved = [Int](repeating: -1, count: full * n)      // -1: no chain like that yet
        for v in 0..<n {
            saved[(1 << v) * n + v] = 0
        }
        for mask in 1..<full {
            for last in 0..<n where mask & (1 << last) != 0 {
                let here = saved[mask * n + last]
                if here < 0 { continue }
                for next in 0..<n where mask & (1 << next) == 0 {
                    let grown = (mask | (1 << next)) * n + next
                    saved[grown] = max(saved[grown], here + overlap[last][next])
                }
            }
        }
        let bestSaving = (0..<n).map { saved[(full - 1) * n + $0] }.max()!
        return words.reduce(0) { $0 + $1.count } - bestSaving
    }
}
```

Comparing `ArraySlice`s with `==` compares their elements, whatever their indexes, so `a[(a.count - k)...] == b[..<k]` checks a suffix against a prefix directly. The overlap never needs to be the whole of either fragment, because neither fragment contains the other. To build the strand itself, not just its length, record which `last` produced each best state and walk back, as M47 did in [Hamiltonian paths and TSP](/dsa/learn/ag-hamiltonian).

</Approach>
