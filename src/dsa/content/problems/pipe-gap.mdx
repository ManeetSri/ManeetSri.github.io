Two straight pipes run under a street. An engineer needs to know how much clearance there is between them: the shortest distance from a point of one pipe to a point of the other.

`PipeGap.shortestGap(_ first: [[Int]], _ second: [[Int]]) -> Double`

Each pipe is a segment `[[x1, y1], [x2, y2]]` with whole-number ends; its two ends may be the same point. Return the shortest distance between the two segments, which is `0` if they touch or cross. Answers within a relative or absolute error of 10⁻⁹ are accepted, but a touching pair must give exactly `0`.

## Examples

| `first` | `second` | Output |
| --- | --- | --- |
| `[[0, 0], [4, 4]]` | `[[0, 4], [4, 0]]` | `0.0` |
| `[[0, 0], [4, 0]]` | `[[1, 1], [5, 1]]` | `1.0` |
| `[[0, 0], [4, 0]]` | `[[2, 1], [2, 5]]` | `1.0` |
| `[[0, 0], [1, 1]]` | `[[4, 5], [7, 9]]` | `5.0` |
| `[[0, 0], [2, 0]]` | `[[5, 0], [9, 0]]` | `3.0` |
| `[[0, 0], [4, 4]]` | `[[4, 0], [6, -2]]` | `2.8284271247...` |

The first pipes cross. The third almost form a T but stop one unit short. In the fourth, the closest points are the ends (1, 1) and (4, 5). In the last, the closest point to the first pipe is the end (4, 0), and it's 2√2 from (2, 2).

## Constraints

- `-10⁶ ≤ x, y ≤ 10⁶`
- One test places a single-point pipe about 3.5 × 10⁻⁷ from a long pipe. Deciding "touching" with a tolerance, or from a `Double` crossing point, gets it wrong.

<Hints>
<Hint>
First decide, exactly, whether the pipes touch or cross: the integer segment intersection test from the lesson. If they do, return 0.
</Hint>
<Hint>
If they don't, the closest pair of points always includes an end of one pipe. So the answer is the smallest of four point-to-segment distances.
</Hint>
<Hint>
For a point p and segment ab, the sign of `(p - a) · (b - a)` says whether p's foot falls before a, and comparing it with `(b - a) · (b - a)` whether it falls past b. If it's in between, the distance is `|cross(b - a, p - a)| / |b - a|`: a parallelogram's area divided by its base. Only that last division needs `Double`.
</Hint>
</Hints>

## Solutions

<Approach title="Search numerically" time="O(k²)" space="O(1)">

The distance from a point sliding along one pipe to a point sliding along the other is a convex function of the two positions, so nested ternary searches with k steps each close in on the minimum. That's a fine way to check answers in tests, but it only ever approaches 0 for touching pipes, and it's slow.

</Approach>

<Approach title="Exact touching test, then four distances" time="O(1)" space="O(1)">

Integers decide; `Double` only measures.

```swift
public enum PipeGap {
    struct Point {
        var x: Int
        var y: Int
        static func - (lhs: Point, rhs: Point) -> Point { Point(x: lhs.x - rhs.x, y: lhs.y - rhs.y) }
        func cross(_ other: Point) -> Int { x * other.y - y * other.x }
        func dot(_ other: Point) -> Int { x * other.x + y * other.y }
        var length: Double { Double(dot(self)).squareRoot() }
    }

    static func sign(_ value: Int) -> Int { value > 0 ? 1 : (value < 0 ? -1 : 0) }

    static func within(_ p: Point, _ a: Point, _ b: Point) -> Bool {
        min(a.x, b.x) <= p.x && p.x <= max(a.x, b.x) && min(a.y, b.y) <= p.y && p.y <= max(a.y, b.y)
    }

    static func touch(_ a: Point, _ b: Point, _ c: Point, _ d: Point) -> Bool {
        let o1 = sign((b - a).cross(c - a)), o2 = sign((b - a).cross(d - a))
        let o3 = sign((d - c).cross(a - c)), o4 = sign((d - c).cross(b - c))
        if o1 * o2 < 0 && o3 * o4 < 0 { return true }
        return (o1 == 0 && within(c, a, b)) || (o2 == 0 && within(d, a, b))
            || (o3 == 0 && within(a, c, d)) || (o4 == 0 && within(b, c, d))
    }

    static func distance(from p: Point, to a: Point, _ b: Point) -> Double {
        let ab = b - a, ap = p - a
        let along = ap.dot(ab)
        if along <= 0 { return ap.length }                    // the foot is at or before a
        if along >= ab.dot(ab) { return (p - b).length }      // at or past b
        return Double(abs(ab.cross(ap))) / ab.length          // the height of a parallelogram
    }

    public static func shortestGap(_ first: [[Int]], _ second: [[Int]]) -> Double {
        let a = Point(x: first[0][0], y: first[0][1]), b = Point(x: first[1][0], y: first[1][1])
        let c = Point(x: second[0][0], y: second[0][1]), d = Point(x: second[1][0], y: second[1][1])
        if touch(a, b, c, d) {
            return 0
        }
        return min(distance(from: a, to: c, d), distance(from: b, to: c, d),
                   distance(from: c, to: a, b), distance(from: d, to: a, b))
    }
}
```

A single-point pipe needs no special case: with a = b, `along` is 0, so the distance is to a. The cross-product form of the perpendicular distance divides once, at the end, so it stays accurate even when the answer is tiny.

</Approach>
