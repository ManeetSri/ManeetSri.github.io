A 24-hour clock shows hours from 0 to 23. Given the hour it shows now and a number of hours to move, return the hour it will show afterwards. A negative number of hours means going back in time.

`ClockWrap.hour(from start: Int, adding hours: Int) -> Int`

## Examples

| Call | Returns | Why |
| --- | --- | --- |
| `hour(from: 9, adding: 3)` | `12` | no wrapping needed |
| `hour(from: 22, adding: 5)` | `3` | 27 o'clock wraps past midnight to 3 |
| `hour(from: 9, adding: 24)` | `9` | a whole day later, same hour |
| `hour(from: 3, adding: -5)` | `22` | five hours before 3 is 22 the previous day |
| `hour(from: 0, adding: -24)` | `0` | a whole day earlier |

## Constraints

- `0 ≤ start ≤ 23`
- `-1,000,000,000 ≤ hours ≤ 1,000,000,000`
- The result must always be between 0 and 23.

<Hints>
<Hint>
Going forward is the remainder after dividing by 24: `(start + hours) % 24`. Try it on the examples. Which ones does it get wrong?
</Hint>
<Hint>
For `start = 3` and `hours = -5`, the total is -2, and in Swift `-2 % 24` is `-2`, because the remainder keeps the sign of the left-hand number. How could you turn -2 into 22?
</Hint>
<Hint>
Adding 24 to a negative remainder fixes it, but would push a positive one past 23. Take `% 24` once more at the end: `((total % 24) + 24) % 24`.
</Hint>
</Hints>

## Solutions

<Approach title="Remainder, then fix the sign" time="O(1)" space="O(1)">

The first `% 24` brings any total, however large, into the range -23 to 23. Adding 24 moves that into 1 to 47, all positive. The final `% 24` brings it back into 0 to 23.

```swift
public enum ClockWrap {
    public static func hour(from start: Int, adding hours: Int) -> Int {
        let total = start + hours
        return ((total % 24) + 24) % 24
    }
}
```

Trace it for `hour(from: 3, adding: -5)`: the total is -2, then `-2 % 24` is -2, then -2 + 24 is 22, and `22 % 24` is 22. For `hour(from: 22, adding: 5)`: 27, then 3, then 27, then 3. The same formula handles both directions.

This "wrap into 0 to n − 1" formula is worth memorising. You'll use it for circular arrays, rotating lists and ring buffers later in the course. In languages like Python, `%` already returns a non-negative result here, which is why code translated from Python to Swift often breaks on negative inputs.

</Approach>
