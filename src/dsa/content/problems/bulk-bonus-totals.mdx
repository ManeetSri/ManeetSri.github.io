An office has a row of desks, each with an amount already paid to it. Payroll then works in bulk: it pays the same bonus to every desk in a range, and every so often asks for the total paid so far to a range of desks. Answer the questions.

`BulkBonusTotals.process(initial: [Int], operations: [[Int]]) -> [Int]`

Desk i starts with `initial[i]`. Each operation is one of:

- `[0, left, right, amount]`: pay `amount` more to every desk in `left...right` (the amount can be negative, for a correction);
- `[1, left, right]`: ask for the total paid so far to the desks in `left...right`, starting amounts included.

Return the answers to the questions, in order.

## Examples

With `initial = [10, 0, 5, 0, 20]`:

| Operation | Output | Amounts afterwards |
| --- | --- | --- |
| `[1, 0, 4]` | `35` | `[10, 0, 5, 0, 20]` |
| `[0, 1, 3, 4]` | | `[10, 4, 9, 4, 20]` |
| `[1, 2, 4]` | `33` | unchanged |
| `[0, 0, 4, -1]` | | `[9, 3, 8, 3, 19]` |
| `[1, 0, 1]` | `12` | unchanged |
| `[1, 3, 3]` | `3` | unchanged |

So the result is `[35, 33, 12, 3]`.

## Constraints

- `1 ≤ initial.count ≤ 100,000`, and `-10⁹ ≤ initial[i] ≤ 10⁹`
- Up to 100,000 operations, with `0 ≤ left ≤ right < initial.count` and `-10⁶ ≤ amount ≤ 10⁶`.
- Totals fit comfortably in Swift's 64-bit `Int`.
- The tests use 100,000 desks and 100,000 wide operations, so paying or adding up desk by desk is too slow.

<Hints>
<Hint>
The starting amounts never change, so a prefix-sum array handles their share of every total. The hard part is the bonuses: range additions mixed with range sums.
</Hint>
<Hint>
Record the bonuses in a difference array d: paying v to `l...r` adds v at l and −v at r + 1, and a desk's bonus is the prefix sum of d up to it. The total bonus of the first p desks is then a sum of prefix sums. Count how many times each `d[j]` appears in it.
</Hint>
<Hint>
`d[j]` appears in desks j through p, which is `p − j + 1` times. So the total is `(p + 1) × Σ d[j] − Σ j × d[j]` over `j ≤ p`. Keep `d[j]` in one Fenwick tree and `j × d[j]` in another.
</Hint>
</Hints>

## Solutions

<Approach title="Pay desk by desk" time="O(n · q)" space="O(n)">

Keep every desk's amount and loop over each range. It's the rules written out, and the tests' reference for small cases.

```swift
public static func process(initial: [Int], operations: [[Int]]) -> [Int] {
    var paid = initial
    var answers: [Int] = []
    for operation in operations {
        if operation[0] == 0 {
            for desk in operation[1]...operation[2] { paid[desk] += operation[3] }
        } else {
            answers.append(paid[operation[1]...operation[2]].reduce(0, +))
        }
    }
    return answers
}
```

</Approach>

<Approach title="Prefix sums plus two Fenwick trees" time="O(n + q log n)" space="O(n)">

The trick from [Range updates, and range queries with two BITs](/dsa/learn/bit-range-updates), with the starting amounts kept out of the trees in a plain prefix-sum array. Inside, positions are 1-indexed, and the trees have room for position n + 1, where the last desk's "step back down" lands.

```swift
public enum BulkBonusTotals {
    public static func process(initial: [Int], operations: [[Int]]) -> [Int] {
        let n = initial.count
        var start = [0]                                   // start[p] = the first p starting amounts
        for amount in initial {
            start.append(start.last! + amount)
        }
        var plain = Array(repeating: 0, count: n + 2)     // Fenwick trees over positions 1...n + 1
        var weighted = Array(repeating: 0, count: n + 2)

        func add(_ tree: inout [Int], _ delta: Int, at position: Int) {
            var i = position
            while i < tree.count {
                tree[i] += delta
                i += i & -i
            }
        }
        func prefix(_ tree: [Int], _ position: Int) -> Int {
            var i = position, total = 0
            while i > 0 {
                total += tree[i]
                i -= i & -i
            }
            return total
        }
        func paid(through p: Int) -> Int {                // desks 1...p, starting amounts included
            start[p] + (p + 1) * prefix(plain, p) - prefix(weighted, p)
        }

        var answers: [Int] = []
        for operation in operations {
            let left = operation[1] + 1, right = operation[2] + 1
            if operation[0] == 0 {
                let amount = operation[3]
                add(&plain, amount, at: left)
                add(&plain, -amount, at: right + 1)
                add(&weighted, amount * left, at: left)
                add(&weighted, -amount * (right + 1), at: right + 1)
            } else {
                answers.append(paid(through: right) - paid(through: left - 1))
            }
        }
        return answers
    }
}
```

A lazy segment tree with range add and range sum, from M60, also passes, and DSAKit's `LazySegmentTree` does it in a few lines: `add(amount, to: left...right)` and `sum(in: left...right)`.

</Approach>
