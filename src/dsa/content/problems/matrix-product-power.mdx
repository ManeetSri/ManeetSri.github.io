Build the three matrix tools behind matrix exponentiation. Matrices are `[[Int]]` arrays of rows, always rectangular and at least 1 × 1.

`MatrixProductPower.product(_ a: [[Int]], _ b: [[Int]]) -> [[Int]]?` returns a × b, or `nil` if the shapes don't fit (a's column count must equal b's row count).

`MatrixProductPower.identity(size: Int) -> [[Int]]` returns the size × size identity matrix.

`MatrixProductPower.power(_ m: [[Int]], _ exponent: Int, modulo: Int) -> [[Int]]` returns the square matrix m raised to the power `exponent`, with every entry reduced modulo `modulo`.

## Examples

| Call | Output |
| --- | --- |
| `product([[2, 0, 1]], [[1], [4], [3]])` | `[[5]]` |
| `product([[1], [2]], [[3, 4]])` | `[[3, 4], [6, 8]]` |
| `product([[1, 2], [3, 4]], [[1, 2], [3, 4], [5, 6]])` | `nil` |
| `identity(size: 2)` | `[[1, 0], [0, 1]]` |
| `power([[1, 1], [1, 0]], 10, modulo: 1_000_000_007)` | `[[89, 55], [55, 34]]` |
| `power([[2, 0], [0, 3]], 10, modulo: 1000)` | `[[24, 0], [0, 49]]` |
| `power([[5, 7], [1, 9]], 0, modulo: 13)` | `[[1, 0], [0, 1]]` |

The first is a 1 × 3 row times a 3 × 1 column: 2 × 1 + 0 × 4 + 1 × 3 = 5. The second goes the other way, a column times a row, and gives a 2 × 2 matrix.

## Constraints

- `product`: at most 60 rows and columns each, entries between −10⁴ and 10⁴.
- `identity`: `1 ≤ size ≤ 100`.
- `power`: m is square, at most 10 × 10, with entries in `0..<modulo`; `0 ≤ exponent ≤ 10¹⁸` and `2 ≤ modulo ≤ 10⁹ + 7`. Multiplying m by itself 10¹⁸ times is out of the question.

<Hints>
<Hint>
Entry (i, j) of a × b walks along row i of a and down column j of b at the same time: the sum of `a[i][t] * b[t][j]` over t. The result has a's row count and b's column count. Check `a[0].count == b.count` first.
</Hint>
<Hint>
For `power`, use fast exponentiation exactly as for numbers, with the identity matrix in place of 1: keep a `result` and a `square`, and for each bit of the exponent, multiply `result` by `square` when the bit is 1, then square `square`. That's about 60 multiplications for an exponent of 10¹⁸.
</Hint>
<Hint>
Reduce modulo after every multiply-and-add: `c[i][j] = (c[i][j] + a[i][t] * b[t][j]) % modulo`. Each product is below (10⁹ + 7)², about 10¹⁸, which fits, but a sum of several of them wouldn't. Don't forget that an exponent of 0 gives the identity, and that 1 % modulo is still 1 since modulo is at least 2.
</Hint>
</Hints>

## Solutions

<Approach title="Multiply exponent times" time="O(exponent × k³)" space="O(k²)">

Starting from the identity and multiplying by m once per unit of the exponent is correct, and fine for small exponents. For 10¹⁸ it would never finish.

</Approach>

<Approach title="Square and multiply" time="O(k³ log exponent)" space="O(k²)">

Matrix multiplication is associative, so mᵉ can be built from the squares m, m², m⁴, m⁸, … picked out by the binary digits of e, just like fast power for numbers. Each step is one k × k multiplication, O(k³), and there are about log₂ e steps.

```swift
public enum MatrixProductPower {
    public static func product(_ a: [[Int]], _ b: [[Int]]) -> [[Int]]? {
        guard a[0].count == b.count else {
            return nil
        }
        var c = Array(repeating: Array(repeating: 0, count: b[0].count), count: a.count)
        for i in 0..<a.count {
            for j in 0..<b[0].count {
                for t in 0..<b.count {
                    c[i][j] += a[i][t] * b[t][j]
                }
            }
        }
        return c
    }

    public static func identity(size: Int) -> [[Int]] {
        var m = Array(repeating: Array(repeating: 0, count: size), count: size)
        for i in 0..<size {
            m[i][i] = 1
        }
        return m
    }

    static func multiply(_ a: [[Int]], _ b: [[Int]], modulo: Int) -> [[Int]] {
        let k = a.count
        var c = Array(repeating: Array(repeating: 0, count: k), count: k)
        for i in 0..<k {
            for j in 0..<k {
                for t in 0..<k {
                    c[i][j] = (c[i][j] + a[i][t] * b[t][j]) % modulo
                }
            }
        }
        return c
    }

    public static func power(_ m: [[Int]], _ exponent: Int, modulo: Int) -> [[Int]] {
        var result = identity(size: m.count)
        var square = m
        var e = exponent
        while e > 0 {
            if e % 2 == 1 {
                result = multiply(result, square, modulo: modulo)
            }
            square = multiply(square, square, modulo: modulo)
            e /= 2
        }
        return result
    }
}
```

With m = `[[1, 1], [1, 0]]`, entry `[0][1]` of mⁿ is the nth Fibonacci number, so `power` computes Fibonacci numbers modulo 10⁹ + 7 for n up to 10¹⁸ in about 60 squarings. M66 builds on exactly this.

</Approach>
