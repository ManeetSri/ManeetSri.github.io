Build a tree whose nodes remember their parent, then use those parent pointers to climb from any node to the root. The parent pointer must not keep the parent alive.

`WeakParentTree.Node`, with `addChild(_ child: Node)`, `depth: Int`, `pathToRoot: [Int]` and `root: Node`

- `addChild` appends `child` to this node's `children` and makes this node the child's `parent`. If the child already had a parent, it's **moved**: remove it from the old parent's `children` first.
- `depth` is the number of steps up to the root. A root has depth 0.
- `pathToRoot` lists values from this node up to the root, both included.
- `root` is the topmost ancestor, or the node itself if it has no parent.
- A node keeps its children alive. A child must not keep its parent alive: when a parent is freed, its children's `parent` becomes `nil`.

## Examples

For this tree, built with `addChild`:

```text
    1
   / \
  2   3
  |
  4
```

| Expression | Result |
| --- | --- |
| `node4.depth` | `2` |
| `node4.pathToRoot` | `[4, 2, 1]` |
| `node3.pathToRoot` | `[3, 1]` |
| `node4.root` | node 1 |
| `node1.depth` | `0` |
| `node3.addChild(node4)`, then `node4.pathToRoot` | `[4, 3, 1]`, and node 2 has no children |

## Constraints

- Trees can be up to 1,000 levels deep.
- Keep the property names and types; you may change how `parent` is declared.

<Hints>
<Hint>
Which direction owns which? A parent owns its children, so `children` stays strong. That makes `parent` the back-reference, so it should be `weak`. `private(set) weak var` is allowed.
</Hint>
<Hint>
To climb, keep a variable `current: Node?` and repeat `current = current.parent` until it's `nil`. `while let node = current { … }` is the loop you want.
</Hint>
<Hint>
To move a child, remove it from its old parent before appending it: `child.parent?.children.removeAll { $0 === child }`. Use `===` because you're looking for this exact object.
</Hint>
</Hints>

## Solutions

<Approach title="Weak parent pointers, climb with a loop" time="O(depth)" space="O(1)">

Each query walks up the parent pointers one step at a time, so it takes as many steps as the node's depth. `depth` and `root` use constant extra space; `pathToRoot` needs space for its result. Because `parent` is weak, a tree is freed as soon as nothing holds its root, and a child that outlives its parent sees `parent` become `nil`.

```swift
public enum WeakParentTree {
    public final class Node {
        public let value: Int
        public private(set) var children: [Node] = []
        public private(set) weak var parent: Node?

        public init(_ value: Int) {
            self.value = value
        }

        public func addChild(_ child: Node) {
            child.parent?.children.removeAll { $0 === child }
            children.append(child)
            child.parent = self
        }

        public var depth: Int {
            var steps = 0
            var current = parent
            while let node = current {
                steps += 1
                current = node.parent
            }
            return steps
        }

        public var pathToRoot: [Int] {
            var path: [Int] = []
            var current: Node? = self
            while let node = current {
                path.append(node.value)
                current = node.parent
            }
            return path
        }

        public var root: Node {
            var top = self
            while let next = top.parent {
                top = next
            }
            return top
        }
    }
}
```

`removeAll { $0 === child }` scans the old parent's children, which is fine for small trees. You'll meet faster ways to store children when you study trees in Part V.

</Approach>
