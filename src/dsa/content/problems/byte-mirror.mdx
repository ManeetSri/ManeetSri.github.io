Reverse the order of the bits in a byte: bit 0 swaps places with bit 7, bit 1 with bit 6, bit 2 with bit 5, and bit 3 with bit 4. Work with the bits directly, without converting to a `String`.

`ByteMirror.mirrored(_ byte: UInt8) -> UInt8`

## Examples

| Input | In binary | Output | In binary |
| --- | --- | --- | --- |
| `1` | `00000001` | `128` | `10000000` |
| `13` | `00001101` | `176` | `10110000` |
| `202` | `11001010` | `83` | `01010011` |
| `255` | `11111111` | `255` | `11111111` |
| `0` | `00000000` | `0` | `00000000` |

## Constraints

- `byte` can be any `UInt8`, from 0 to 255.

<Hints>
<Hint>
Build the answer one bit at a time. For each `k` from 0 to 7, if bit `k` of the input is set, set bit `7 - k` of the result.
</Hint>
<Hint>
Another way to say the same thing: eight times over, shift the result left by one, bring in the input's lowest bit with `| (input & 1)`, and shift the input right by one. The first bit you take ends up furthest left.
</Hint>
<Hint>
For a trick with no loop at all: swap the two halves of the byte, then swap neighbouring pairs of bits within each half, then swap neighbouring single bits. The masks `0xF0`, `0xCC` and `0xAA` pick out the left side of each swap.
</Hint>
</Hints>

## Solutions

<Approach title="Check one bit, set another" time="O(1)" space="O(1)">

Go through the eight positions. Whenever bit `k` is set in the input, set the mirror-image bit, `7 - k`, in the result. It's the check and set moves, eight times.

```swift
public enum ByteMirror {
    public static func mirrored(_ byte: UInt8) -> UInt8 {
        var result: UInt8 = 0
        for k in 0..<8 where byte & (1 << k) != 0 {
            result |= 1 << (7 - k)
        }
        return result
    }
}
```

The loop always runs eight times, whatever the input, so it's constant time.

</Approach>

<Approach title="Swap halves, then pairs, then bits" time="O(1)" space="O(1)">

Reversing eight bits is the same as three swaps at different scales. Swap the left four bits with the right four. Then, inside each half, swap the left two with the right two. Then swap each neighbouring pair of bits. Each swap is "keep one side with a mask and shift it across, do the same for the other side, and OR them together".

```swift
public static func mirrored(_ byte: UInt8) -> UInt8 {
    var b = byte
    b = ((b & 0xF0) >> 4) | ((b & 0x0F) << 4)
    b = ((b & 0xCC) >> 2) | ((b & 0x33) << 2)
    b = ((b & 0xAA) >> 1) | ((b & 0x55) << 1)
    return b
}
```

Trace it on `00001101`: swapping halves gives `11010000`, swapping pairs gives `01110000`, and swapping single bits gives `10110000`, which is 176. `0xCC` is `11001100` and `0xAA` is `10101010`: they pick the left member of every pair. The same three-step idea, with more steps, reverses the bits of a `UInt32` or `UInt64`. When speed matters most, programs sometimes precompute all 256 answers in a table and look them up.

</Approach>
