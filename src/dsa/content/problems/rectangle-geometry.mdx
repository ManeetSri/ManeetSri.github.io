Finish a `Rectangle` struct on a grid by adding three computed properties and a method that checks whether a point lies inside it. `(x, y)` is the top-left corner; `x` grows to the right and `y` grows downwards.

`RectangleGeometry.Rectangle(x:y:width:height:)`, with `area: Int`, `perimeter: Int`, `isSquare: Bool` and `contains(x:y:) -> Bool`

A point is inside when `x ≤ pointX < x + width` and `y ≤ pointY < y + height`. The left and top edges count as inside; the right and bottom edges don't, just like the cells of a grid.

## Examples

| Rectangle (x, y, width, height) | Call | Result |
| --- | --- | --- |
| `(0, 0, 4, 3)` | `area` | `12` |
| `(0, 0, 4, 3)` | `perimeter` | `14` |
| `(2, 2, 5, 5)` | `isSquare` | `true` |
| `(2, 1, 3, 2)` | `contains(x: 4, y: 2)` | `true` |
| `(2, 1, 3, 2)` | `contains(x: 5, y: 1)` | `false`: x = 5 is the right edge |
| `(0, 0, 0, 5)` | `contains(x: 0, y: 0)` | `false`: no width, so nothing is inside |

## Constraints

- `0 ≤ width, height ≤ 10,000`
- `-10,000 ≤ x, y, pointX, pointY ≤ 10,000`
- The properties must stay correct after `width` or `height` changes, so compute them rather than storing them.

<Hints>
<Hint>
Each property is a single expression in terms of `width` and `height`. A computed property recalculates on every read, so it can never be out of date.
</Hint>
<Hint>
Inside `contains`, the parameters are named `pointX` and `pointY`, so plain `x` and `y` still mean the rectangle's own corner.
</Hint>
<Hint>
A half-open range already means "from here up to but not including there": `(x..<x + width).contains(pointX)`. Do the same for `y`, and combine the two with `&&`.
</Hint>
</Hints>

## Solutions

<Approach title="Computed properties and half-open ranges" time="O(1)" space="O(1)">

Each property is one expression, recalculated whenever it's read. `contains` checks the two axes separately: a point is inside only if it's inside on both.

```swift
public enum RectangleGeometry {
    public struct Rectangle {
        public var x: Int
        public var y: Int
        public var width: Int
        public var height: Int

        public init(x: Int, y: Int, width: Int, height: Int) {
            self.x = x
            self.y = y
            self.width = width
            self.height = height
        }

        public var area: Int {
            width * height
        }

        public var perimeter: Int {
            2 * (width + height)
        }

        public var isSquare: Bool {
            width == height
        }

        public func contains(x pointX: Int, y pointY: Int) -> Bool {
            (x..<x + width).contains(pointX) && (y..<y + height).contains(pointY)
        }
    }
}
```

When the width is 0, `x..<x` is an empty range, so `contains` correctly returns `false` with no special case. Comparisons written out in full, `pointX >= x && pointX < x + width && …`, work just as well.

</Approach>
