Rearrange the letters of a string so that all copies of each letter sit together, with the **most frequent letter first**. Letters that appear the same number of times go in alphabetical order. The string holds only lowercase English letters.

`LettersByFrequency.arrange(_ text: String) -> String`

## Examples

| `text` | Returns |
| --- | --- |
| `"banana"` | `"aaannb"` |
| `"letter"` | `"eettlr"` |
| `"mississippi"` | `"iiiissssppm"` |
| `"zzyx"` | `"zzxy"` |
| `"cba"` | `"abc"` |
| `""` | `""` |

In `"letter"`, e and t both appear twice, so e comes first; l and r appear once each, so l comes before r.

## Constraints

- `0 ≤ text.count ≤ 200,000`
- Only the letters `a` to `z`.
- Aim for O(n) time.

<Hints>
<Hint>
Count the letters with 26 slots, as in counting sort. Now the problem is ordering at most 26 letters by their counts.
</Hint>
<Hint>
Every count is between 1 and n. Make buckets indexed by count: `buckets[f]` holds the letters that appear exactly f times. Fill them by visiting the letters from a to z, and each bucket is already in alphabetical order.
</Hint>
<Hint>
Walk the buckets from n down to 1, and for each letter in a bucket, add it to the result f times. Building the result as `[UInt8]` and converting once at the end is faster than adding to a `String` one character at a time.
</Hint>
</Hints>

## Solutions

<Approach title="Count, then sort the 26 letters" time="O(n)" space="O(n)">

There are only 26 possible letters, so sorting them by count is a fixed amount of work, however long the text is. Count, sort the letters that appear by (count, highest first, then letter), and repeat each one.

```swift
public static func arrange(_ text: String) -> String {
    var counts = [Int](repeating: 0, count: 26)
    for byte in text.utf8 {
        counts[Int(byte - 97)] += 1
    }
    let order = (0..<26).filter { counts[$0] > 0 }.sorted { first, second in
        counts[first] != counts[second] ? counts[first] > counts[second] : first < second
    }
    var result: [UInt8] = []
    for letter in order {
        result += repeatElement(UInt8(97 + letter), count: counts[letter])
    }
    return String(decoding: result, as: UTF8.self)
}
```

Sorting 26 items costs the same for a string of 10 letters as for one of a million, so the whole thing is O(n). But it leans on the alphabet being tiny.

</Approach>

<Approach title="Frequency buckets" time="O(n)" space="O(n)">

Buckets indexed by count work for any alphabet, even all of Unicode, without sorting anything. This is the same trick as finding the k most frequent words.

```swift
public enum LettersByFrequency {
    public static func arrange(_ text: String) -> String {
        let bytes = Array(text.utf8)
        var counts = [Int](repeating: 0, count: 26)
        for byte in bytes {
            counts[Int(byte - 97)] += 1
        }
        // buckets[f] holds the letters (as 0 to 25) that appear exactly f times, a to z
        var buckets = [[Int]](repeating: [], count: bytes.count + 1)
        for letter in 0..<26 where counts[letter] > 0 {
            buckets[counts[letter]].append(letter)
        }
        var result: [UInt8] = []
        result.reserveCapacity(bytes.count)
        for frequency in stride(from: bytes.count, through: 1, by: -1) {
            for letter in buckets[frequency] {
                result.append(contentsOf: repeatElement(UInt8(97 + letter), count: frequency))
            }
        }
        return String(decoding: result, as: UTF8.self)
    }
}
```

The bucket array has n + 1 entries, most of them empty, and walking it is O(n). For an empty string, `stride(from: 0, through: 1, by: -1)` produces nothing, so the result is `""`.

</Approach>
