Undo run-length compression. In the compressed code, every character is followed by an optional count: no count means the character appears once, and a count says how many times it appears. Counts can have several digits. Return the original text.

`RunCodeExpander.expand(_ code: String) -> String`

## Examples

| `code` | Output |
| --- | --- |
| `"a2bc6"` | `"aabcccccc"` |
| `"m10n2"` | `"mmmmmmmmmmnn"` |
| `"xyz"` | `"xyz"` |
| `"k1"` | `"k"` |
| `"w3!2"` | `"www!!"` |
| `""` | `""` |

`"m10"` means ten `m`s, not one `m`, then a `1` and a `0`: the original text never contains digits, so every digit belongs to a count.

## Constraints

- `0 ≤ code.count ≤ 100,000`, and the expanded text has at most 200,000 characters.
- The code is well formed: it's empty or starts with a non-digit, every count follows a character, and counts are between 1 and 200,000 with no leading zeros.

<Hints>
<Hint>
Read the code one character at a time. A digit extends the current count; anything else starts a new run, which means the previous run is complete and can be written out.
</Hint>
<Hint>
Build a count from its digits the way you'd parse a number: `count = count * 10 + digit`, using `wholeNumberValue` to turn a digit character into an `Int`. A run that ends with no digits at all has a count of 1.
</Hint>
<Hint>
The last run has no character after it to trigger writing it out, so write it after the loop. `String(repeating:count:)` builds a whole run in one step.
</Hint>
</Hints>

## Solutions

<Approach title="Finish each run when the next one starts" time="O(n + L)" space="O(L)">

Keep the current character, as an optional because there's none before the first, and the count built so far, where 0 means "no digits yet". L is the length of the expanded text, which the answer has to hold anyway.

```swift
public enum RunCodeExpander {
    public static func expand(_ code: String) -> String {
        var result = ""
        var current: Character? = nil
        var count = 0
        for character in code {
            if let digit = character.wholeNumberValue {
                count = count * 10 + digit
            } else {
                if let previous = current {
                    result += String(repeating: previous, count: max(count, 1))
                }
                current = character
                count = 0
            }
        }
        if let previous = current {
            result += String(repeating: previous, count: max(count, 1))   // the last run
        }
        return result
    }
}
```

`max(count, 1)` turns "no digits" into a run of one. Since counts never start with 0, a count of 0 can only mean that no digits were read.

</Approach>

<Approach title="Look ahead for the digits" time="O(n + L)" space="O(n + L)">

Turn the code into an array and handle one run per step: take its character, then move a second index over the digits that follow. Nothing is left over when the loop ends, so there's no last run to remember.

```swift
public static func expand(_ code: String) -> String {
    let chars = Array(code)
    var result = ""
    var i = 0
    while i < chars.count {
        let character = chars[i]
        var j = i + 1
        var count = 0
        while j < chars.count, let digit = chars[j].wholeNumberValue {
            count = count * 10 + digit
            j += 1
        }
        result += String(repeating: character, count: j == i + 1 ? 1 : count)
        i = j
    }
    return result
}
```

</Approach>
