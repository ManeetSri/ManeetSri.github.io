Given an array sorted in non-decreasing order, which may contain negative numbers, return the squares of its elements, also in non-decreasing order. Aim for O(n), using the fact that the input is already sorted.

`SortedSquares.squares(of sorted: [Int]) -> [Int]`

## Examples

| Input | Output |
| --- | --- |
| `[-7, -3, -1, 2, 4, 6]` | `[1, 4, 9, 16, 36, 49]` |
| `[-5, -4, -2]` | `[4, 16, 25]` |
| `[0, 3, 8]` | `[0, 9, 64]` |
| `[-2, -2, 2]` | `[4, 4, 4]` |
| `[]` | `[]` |

## Constraints

- `0 ≤ sorted.count ≤ 100,000`, in non-decreasing order
- `-10⁴ ≤ sorted[i] ≤ 10⁴`
- Aim for O(n) time.

<Hints>
<Hint>
Squaring then sorting is correct, O(n log n), and makes a good oracle. Look at the squares before sorting: they go down while the values are negative, then up.
</Hint>
<Hint>
The smallest square is somewhere in the middle, but the largest is always at one end: it belongs to whichever value is furthest from zero.
</Hint>
<Hint>
Point `left` and `right` at the two ends, and fill the result from its last slot backwards. Each time, write the bigger of the two end squares and move that pointer inwards. Loop while `left <= right`, so the last element gets written too.
</Hint>
</Hints>

## Solutions

<Approach title="Square, then sort" time="O(n log n)" space="O(n)">

```swift
public static func squares(of sorted: [Int]) -> [Int] {
    sorted.map { $0 * $0 }.sorted()
}
```

Short and clearly correct, but it ignores the fact that the input was sorted.

</Approach>

<Approach title="Two pointers, filling from the back" time="O(n)" space="O(1) extra">

Both ends are candidates for the largest square still unplaced, and nothing in the middle can beat them. So the result is built from the largest square down, writing into the last empty slot each time.

```swift
public enum SortedSquares {
    public static func squares(of sorted: [Int]) -> [Int] {
        var result = Array(repeating: 0, count: sorted.count)
        var left = 0
        var right = sorted.count - 1
        var write = sorted.count - 1
        while left <= right {
            let leftSquare = sorted[left] * sorted[left]
            let rightSquare = sorted[right] * sorted[right]
            if leftSquare > rightSquare {
                result[write] = leftSquare
                left += 1
            } else {
                result[write] = rightSquare
                right -= 1
            }
            write -= 1
        }
        return result
    }
}
```

Every element is written exactly once. Ties can go either way: equal squares are interchangeable.

</Approach>
