A delivery robot follows a route of waypoints on a map where y grows upwards. At every waypoint except the first and the last, it turns left, turns right, carries straight on, or turns round and heads back the way it came. Return one letter per waypoint in between, in order: `L`, `R`, `S` or `U`.

`WaypointTurns.turns(_ waypoints: [[Int]]) -> String`

Each waypoint is `[x, y]`. Any change of direction counts as a turn, however slight: only exactly the same direction is `S`, and only exactly the opposite direction is `U`.

## Examples

| `waypoints` | Output |
| --- | --- |
| `[[0, 0], [4, 0], [4, 3], [1, 3]]` | `"LL"` |
| `[[0, 0], [2, 2], [4, 0], [6, 2]]` | `"RL"` |
| `[[1, 1], [2, 2], [5, 5]]` | `"S"` |
| `[[0, 0], [3, 0], [1, 0], [1, 4]]` | `"UR"` |
| `[[-1000000000, -1000000000], [0, 0], [1000000000, 999999999]]` | `"R"` |
| `[[5, 5]]` | `""` |

In the fourth example, the robot heads east to (3, 0), then turns round to head west to (1, 0): a U-turn. Heading west, it then turns to head north, which is a right turn. In the fifth, the second leg drifts one unit below the first one's direction over a distance of a billion: still a right turn.

## Constraints

- `0 ≤ waypoints.count ≤ 100,000`
- `-10⁹ ≤ x, y ≤ 10⁹`
- No two consecutive waypoints are the same.

<Hints>
<Hint>
At waypoint i, compare the direction you arrive in, `waypoints[i] - waypoints[i - 1]`, with the direction you leave in, `waypoints[i + 1] - waypoints[i]`.
</Hint>
<Hint>
The sign of the cross product of those two directions says left (positive) or right (negative). Zero means they're parallel.
</Hint>
<Hint>
When they're parallel, the sign of the dot product says whether they point the same way (`S`) or opposite ways (`U`). Check the sizes: each coordinate difference is at most 2 × 10⁹, so each product is at most 4 × 10¹⁸, and a cross or dot product at most 8 × 10¹⁸. Does that fit in an `Int`?
</Hint>
</Hints>

## Solutions

<Approach title="Angles with atan2" time="O(n)" space="O(n)">

Work out each leg's heading with `atan2(dy, dx)` and compare consecutive headings. It reads naturally, but the headings are `Double`s: two legs that differ by one unit over a billion differ in angle by about 5 × 10⁻¹⁰ radians, close to the rounding error, and an exactly straight route can come out a hair off. The fifth example is designed to catch it. Avoid angles when signs will do.

</Approach>

<Approach title="Cross product, then dot product" time="O(n)" space="O(n)">

Everything stays in exact `Int` arithmetic. The cross product decides left or right; when it's zero, the dot product separates straight on from a U-turn. The answer string itself is the O(n) space.

```swift
public enum WaypointTurns {
    public static func turns(_ waypoints: [[Int]]) -> String {
        guard waypoints.count >= 3 else { return "" }
        var letters: [Character] = []
        for i in 1..<(waypoints.count - 1) {
            let inX = waypoints[i][0] - waypoints[i - 1][0], inY = waypoints[i][1] - waypoints[i - 1][1]
            let outX = waypoints[i + 1][0] - waypoints[i][0], outY = waypoints[i + 1][1] - waypoints[i][1]
            let cross = inX * outY - inY * outX
            if cross > 0 {
                letters.append("L")
            } else if cross < 0 {
                letters.append("R")
            } else {
                letters.append(inX * outX + inY * outY > 0 ? "S" : "U")
            }
        }
        return String(letters)
    }
}
```

The dot product can't be 0 when the cross product is: that would need one of the directions to be zero, and consecutive waypoints always differ.

</Approach>
