Here are two recursive functions. For each, return how many times it gets called in total, **including the first call**, when you call it with `n`. Don't run the recursion: find the count another way.

`RecursiveCallCount.splitCalls(_ n: Int) -> Int` counts the calls of:

```swift
func split(_ n: Int) {
    if n <= 1 {
        return
    }
    split(n / 2)
    split(n - n / 2)
}
```

`RecursiveCallCount.fibonacciCalls(_ n: Int) -> Int` counts the calls of naive Fibonacci:

```swift
func fibonacci(_ n: Int) -> Int {
    if n < 2 {
        return n
    }
    return fibonacci(n - 1) + fibonacci(n - 2)
}
```

## Examples

| Call | Output | Why |
| --- | --- | --- |
| `splitCalls(1)` | `1` | the first call returns straight away |
| `splitCalls(3)` | `5` | `split(3)` calls `split(1)` and `split(2)`, which calls `split(1)` twice |
| `splitCalls(8)` | `15` | |
| `fibonacciCalls(2)` | `3` | `fibonacci(2)`, `fibonacci(1)`, `fibonacci(0)` |
| `fibonacciCalls(5)` | `15` | |
| `fibonacciCalls(10)` | `177` | |

## Constraints

- `splitCalls`: `0 ≤ n ≤ 10¹⁸`. Answer in O(1).
- `fibonacciCalls`: `0 ≤ n ≤ 85`. Answer in O(n): running `fibonacci(85)` itself would make about 8.4 × 10¹⁷ calls.
- Every answer fits in an `Int`.

</Hint>

Compute C(n) bottom-up, from C(2) to C(n), keeping only the last two values, in the same way you'd compute Fibonacci numbers in a loop. Calling a recursive helper for C(n) would be as slow as the original.

## Solutions

<Approach title="Run the recursions and count" time="O(n) and about O(1.62ⁿ)" space="O(log n) and O(n)">

Add a counter to each function. It's the right way to check your formulas for small n, but `fibonacci(85)` would take years and `split(10¹⁸)` would make 2 × 10¹⁸ calls.

```swift
static func countSplit(_ n: Int, calls: inout Int) {
    calls += 1
    if n <= 1 { return }
    countSplit(n / 2, calls: &calls)
    countSplit(n - n / 2, calls: &calls)
}
```

</Approach>

<Approach title="Count the tree, solve the recurrence" time="O(1) and O(n)" space="O(1)">

**`split`.** For n ≥ 2, both halves, n / 2 and n − n / 2, are at least 1, so the recursion only stops at calls of size 1. Each call splits its n into two parts that add up to n, so the leaves' sizes add up to n: there are exactly **n leaves**. Every other call has exactly two children, and a tree like that has one fewer inner node than leaves: **n − 1** inner calls. Total: n + (n − 1) = **2n − 1**. The one exception is n = 0, where the first call stops immediately: 1 call. This is the T(n) = 2T(n/2) + 1 recurrence, and the answer confirms it's O(n).

**`fibonacci`.** A call on n ≥ 2 is one call plus everything `fibonacci(n - 1)` and `fibonacci(n - 2)` do: C(n) = 1 + C(n − 1) + C(n − 2), with C(0) = C(1) = 1. Computing that bottom-up takes n steps, even though the counts themselves grow exponentially. (In fact C(n) = 2 × fibonacci(n + 1) − 1.)

```swift
public enum RecursiveCallCount {
    public static func splitCalls(_ n: Int) -> Int {
        n == 0 ? 1 : 2 * n - 1
    }

    public static func fibonacciCalls(_ n: Int) -> Int {
        if n < 2 {
            return 1
        }
        var beforePrevious = 1   // C(0)
        var previous = 1         // C(1)
        for _ in 2...n {
            (beforePrevious, previous) = (previous, 1 + previous + beforePrevious)
        }
        return previous
    }
}
```

</Approach>
