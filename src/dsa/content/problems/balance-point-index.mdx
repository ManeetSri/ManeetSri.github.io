Return the **leftmost** index where the sum of the elements before it equals the sum of the elements after it. The element at that index belongs to neither side, and an empty side sums to 0. Return `nil` if no index balances.

`BalancePointIndex.balancePoint(in numbers: [Int]) -> Int?`

## Examples

| Input | Output | Why |
| --- | --- | --- |
| `[2, 3, -1, 8, 4]` | `3` | 2 + 3 + -1 = 4 on the left, 4 on the right |
| `[3, -3, 7]` | `2` | 3 + -3 = 0 on the left, nothing on the right |
| `[7, 3, -3]` | `0` | nothing on the left, 3 + -3 = 0 on the right |
| `[0, 0, 0]` | `0` | every index balances; return the leftmost |
| `[5]` | `0` | both sides are empty |
| `[1, 2, 3]` | `nil` | |
| `[]` | `nil` | there are no indexes |

## Constraints

- `0 ≤ numbers.count ≤ 100,000`
- `-10⁴ ≤ numbers[i] ≤ 10⁴`
- Aim for O(n) time and O(1) extra space.

<Hints>
<Hint>
The brute force adds up both sides for every index, O(n²). A prefix array makes each side O(1), but you can do without the array.
</Hint>
<Hint>
Work out the total first. If `leftSum` is the sum of the elements before `i`, then the right side is `total - leftSum - numbers[i]`.
</Hint>
<Hint>
Compare first, then add `numbers[i]` to `leftSum`. Adding first would put the element itself on the left side.
</Hint>
</Hints>

## Solutions

<Approach title="Add up both sides at every index" time="O(n²)" space="O(1)">

Straight from the definition. Slices make each side readable, and `numbers[(i + 1)...]` is empty, not a crash, when `i` is the last index.

```swift
public static func balancePoint(in numbers: [Int]) -> Int? {
    for i in numbers.indices {
        if numbers[..<i].reduce(0, +) == numbers[(i + 1)...].reduce(0, +) {
            return i
        }
    }
    return nil
}
```

</Approach>

<Approach title="Total minus the left side" time="O(n)" space="O(1)">

One pass for the total, then one pass with a running left sum. The right side comes from the total by subtraction, so no prefix array is needed. Returning at the first match gives the leftmost balance point.

```swift
public enum BalancePointIndex {
    public static func balancePoint(in numbers: [Int]) -> Int? {
        let total = numbers.reduce(0, +)
        var leftSum = 0
        for (i, value) in numbers.enumerated() {
            if leftSum == total - leftSum - value {
                return i
            }
            leftSum += value
        }
        return nil
    }
}
```

Negative numbers mean `leftSum` can go down as well as up, so you can't stop early when the left side "passes" the right one. Check every index.

</Approach>
