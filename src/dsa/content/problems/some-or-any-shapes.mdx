Three shape types share a `Shape` protocol. Write four functions whose signatures each pick a different tool from the lesson: an `any` box for a result whose type depends on the input, a generic for two values of the same type, and `some` for a result whose type is fixed but kept private.

`SomeOrAnyShapes.parse(_:) -> (any Shape)?`, `totalArea(of:)`, `larger(_:_:)` and `squareTiles(count:) -> some Sequence<Square>`

The protocol and the `Square`, `Rectangle` and `Circle` types are in the starter code. A shape's `name` is `"square"`, `"rectangle"` or `"circle"`, and `area()` returns its area.

- **`parse(_:)`** reads `"square 3"`, `"rectangle 2 5"` (width, then height) or `"circle 1.5"` (the radius): a lowercase name, then its measurements, separated by spaces. It returns `nil` if the name is unknown, the number of measurements is wrong, or a measurement isn't a positive number.
- **`totalArea(of:)`** adds up the areas of the lines that parse, skipping the rest.
- **`larger(_:_:)`** takes two shapes of the **same** type and returns the one with the larger area, or the first on a tie.
- **`squareTiles(count:)`** returns squares with sides 1, 2, 3, …, `count`, in that order, and nothing when `count` is 0.

## Examples

| Call | Result |
| --- | --- |
| `parse("rectangle 2 5")` | a `Rectangle` with width 2 and height 5, area 10 |
| `parse("circle 1")?.area()` | `3.14159…` (π) |
| `parse("hexagon 2")`, `parse("square 2 3")`, `parse("square 0")`, `parse("square x")` | `nil` each time |
| `totalArea(of: ["square 1", "rectangle 2 3", "triangle 4", "square 2"])` | `11.0` |
| `larger(Rectangle(width: 6, height: 1), Rectangle(width: 2, height: 4))` | the 2 × 4 rectangle |
| `squareTiles(count: 4).map { $0.side }` | `[1.0, 2.0, 3.0, 4.0]` |

## Constraints

- Lines are at most 100 characters, and `count` is between 0 and 10,000.
- Keep the signatures as they are: `larger` must not accept a square and a circle together.

<Hints>
<Hint>
`parse` may return a `Square` for one line and a `Circle` for the next, so its result can't be `some Shape`: every `return` in a `some` function must give the same type. A box, `any Shape`, holds whichever you return.
</Hint>
<Hint>
Split the line with `split(separator: " ")`. Turn each measurement into a number with `Double(word)`, rejecting the line if that's `nil` or the number isn't above 0. Then `switch` on the name and the number of measurements.
</Hint>
<Hint>
`squareTiles` always returns squares, so `some Sequence<Square>` fits: return an array such as `(0..<count).map { Square(side: Double($0 + 1)) }`, and callers only learn that it's a sequence of squares. `1...count` would crash when `count` is 0.
</Hint>
</Hints>

## Solutions

<Approach title="any for parse, a generic for larger, some for squareTiles" time="O(L) per line, O(n) for the rest" space="O(n) for the tiles">

Each signature says something different. `parse` really does return different types, so it needs the flexibility of a box. `larger` is generic over one type `S`, which forces both arguments to match and gives back that same type, with no box at all. `squareTiles` hides the concrete type of its result behind `some`, so it could later return a lazy sequence instead of an array without changing any caller.

```swift
public enum SomeOrAnyShapes {
    // Shape, Square, Rectangle and Circle as in the starter code

    public static func parse(_ line: String) -> (any Shape)? {
        let words = line.split(separator: " ")
        guard let kind = words.first else {
            return nil
        }
        var sizes: [Double] = []
        for word in words.dropFirst() {
            guard let size = Double(word), size > 0 else {
                return nil
            }
            sizes.append(size)
        }
        switch (kind, sizes.count) {
        case ("square", 1):
            return Square(side: sizes[0])
        case ("rectangle", 2):
            return Rectangle(width: sizes[0], height: sizes[1])
        case ("circle", 1):
            return Circle(radius: sizes[0])
        default:
            return nil
        }
    }

    public static func totalArea(of lines: [String]) -> Double {
        var total = 0.0
        for line in lines {
            if let shape = parse(line) {
                total += shape.area()
            }
        }
        return total
    }

    public static func larger<S: Shape>(_ first: S, _ second: S) -> S {
        second.area() > first.area() ? second : first
    }

    public static func squareTiles(count: Int) -> some Sequence<Square> {
        (0..<max(count, 0)).map { Square(side: Double($0 + 1)) }
    }
}
```

Through the `any Shape` that `parse` returns, only `name` and `area()` are available. A caller that needs the width has to ask with `as? Rectangle`, which is exactly the information a box gives up.

</Approach>
