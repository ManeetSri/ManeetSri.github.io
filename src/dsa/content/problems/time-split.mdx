A video is a number of seconds long. Split that number into whole hours, the minutes left over and the seconds left over, and return all three as a named tuple.

`TimeSplitter.split(seconds: Int) -> (hours: Int, minutes: Int, seconds: Int)`

The minutes and seconds in the result are always between 0 and 59. The hours keep counting, so a video longer than a day has 24 hours or more.

## Examples

| Call | Returns |
| --- | --- |
| `split(seconds: 3725)` | `(hours: 1, minutes: 2, seconds: 5)` |
| `split(seconds: 59)` | `(hours: 0, minutes: 0, seconds: 59)` |
| `split(seconds: 3600)` | `(hours: 1, minutes: 0, seconds: 0)` |
| `split(seconds: 86_399)` | `(hours: 23, minutes: 59, seconds: 59)` |
| `split(seconds: 90_061)` | `(hours: 25, minutes: 1, seconds: 1)` |

## Constraints

- `0 ≤ seconds ≤ 1,000,000,000`

<Hints>
<Hint>
An hour has 3,600 seconds. Integer division, `seconds / 3600`, counts the whole hours and drops the rest.
</Hint>
<Hint>
`seconds % 3600` is what's left after taking out the whole hours. Divide that by 60 for the minutes. The leftover seconds are `seconds % 60`.
</Hint>
<Hint>
Return a tuple with the labels from the signature: `return (hours: h, minutes: m, seconds: s)`. Inside the function, `seconds` is the input, so give your leftover seconds a different name.
</Hint>
</Hints>

## Solutions

<Approach title="Divide, then keep the remainder" time="O(1)" space="O(1)">

Integer division counts how many whole units fit, and `%` keeps what's left over. Apply them twice: once for hours, once for minutes.

```swift
public enum TimeSplitter {
    public static func split(seconds: Int) -> (hours: Int, minutes: Int, seconds: Int) {
        let hours = seconds / 3600
        let minutes = seconds % 3600 / 60
        let leftoverSeconds = seconds % 60
        return (hours: hours, minutes: minutes, seconds: leftoverSeconds)
    }
}
```

For 3,725 seconds: `3725 / 3600` is 1 hour. `3725 % 3600` is 125, and `125 / 60` is 2 minutes. `3725 % 60` is 5 seconds. `seconds % 3600 / 60` works left to right, because `%` and `/` have the same precedence, so the remainder is taken first.

Why does `seconds % 60` give the right leftover seconds, even though it skips the hours step? Because 3,600 is a multiple of 60: taking out whole hours never changes the remainder after dividing by 60.

</Approach>

<Approach title="Peel off one unit at a time" time="O(1)" space="O(1)">

The same idea in a different order: first split into whole minutes and seconds, then split the minutes into hours and minutes. Decomposition unpacks each step's tuple.

```swift
public enum TimeSplitter {
    public static func split(seconds: Int) -> (hours: Int, minutes: Int, seconds: Int) {
        let (totalMinutes, leftoverSeconds) = seconds.quotientAndRemainder(dividingBy: 60)
        let (hours, minutes) = totalMinutes.quotientAndRemainder(dividingBy: 60)
        return (hours: hours, minutes: minutes, seconds: leftoverSeconds)
    }
}
```

This "divide by the unit size, keep the remainder, repeat with the quotient" pattern is exactly how you'll take a number apart digit by digit, dividing by 10 each time.

</Approach>
