Find the length of the longest run of consecutive integers, such as 4, 5, 6, 7, whose values all appear in an unsorted array.

`LongestConsecutiveRun.length(in numbers: [Int]) -> Int`

The values can appear in any order, and duplicates count once. An empty array has a longest run of 0.

## Examples

| `numbers` | Result |
| --- | --- |
| `[12, 4, 200, 1, 3, 2]` | `4` |
| `[7, 7, 8, 9, 9, 20]` | `3` |
| `[0, -1, -3, -2, 5]` | `4` |
| `[10, 30, 20]` | `1` |
| `[]` | `0` |

In the first example, the run is 1, 2, 3, 4. In the third, it's −3, −2, −1, 0.

## Constraints

- `0 ≤ numbers.count ≤ 100,000`
- `-10⁹ ≤ numbers[i] ≤ 10⁹`
- Aim for O(n) on average. A test repeats the start of a long run 20,000 times.

<Hints>
<Hint>
Sorting first gives a correct O(n log n) answer. To beat it, put the numbers in a `Set` so "is x here?" is O(1).
</Hint>
<Hint>
Counting upwards from every number repeats work. Only count from a number that **starts** a run: one whose predecessor, `x - 1`, isn't in the set.
</Hint>
<Hint>
Loop over the set, not the array. If the array holds a start many times, looping over the array walks the same run again for every copy.
</Hint>
</Hints>

## Solutions

<Approach title="Sort, then scan" time="O(n log n)" space="O(n)">

After removing duplicates and sorting, consecutive values sit next to each other, so one scan finds the longest stretch where each value is one more than the previous.

```swift
public static func length(in numbers: [Int]) -> Int {
    let sorted = Array(Set(numbers)).sorted()
    guard !sorted.isEmpty else {
        return 0
    }
    var best = 1
    var current = 1
    for index in sorted.indices.dropFirst() {
        current = sorted[index] == sorted[index - 1] + 1 ? current + 1 : 1
        best = max(best, current)
    }
    return best
}
```

</Approach>

<Approach title="A set, counting only from starts" time="O(n)" space="O(n)">

Each distinct value is examined once by the `for` loop. The `while` loop runs only from starts, and each run has exactly one start, so over the whole algorithm it steps over each value at most once. The total is O(n) on average.

```swift
public enum LongestConsecutiveRun {
    public static func length(in numbers: [Int]) -> Int {
        let present = Set(numbers)
        var longest = 0
        for start in present where !present.contains(start - 1) {
            var end = start
            while present.contains(end + 1) {
                end += 1
            }
            longest = max(longest, end - start + 1)
        }
        return longest
    }
}
```

</Approach>
