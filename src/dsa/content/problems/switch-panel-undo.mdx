A panel has `switchCount` switches, all starting off. You're given a list of operations. An operation from `0` to `switchCount - 1` flips that switch (off becomes on, on becomes off). An operation of `-1` means **undo**: it reverses the most recent flip that hasn't been undone yet. Undo can be repeated to step further back, and an undo with nothing left to undo changes nothing. Return the state of the panel after **every** operation, as a list of snapshots.

`SwitchPanelUndo.history(switchCount: Int, operations: [Int]) -> [[Bool]]`

Each snapshot is an array of `switchCount` values, `true` for on.

## Examples

`history(switchCount: 3, operations: [0, 2, -1, 1, -1, -1, -1])`:

| Operation | Snapshot |
| --- | --- |
| flip 0 | `[true, false, false]` |
| flip 2 | `[true, false, true]` |
| undo (the flip of 2) | `[true, false, false]` |
| flip 1 | `[true, true, false]` |
| undo (the flip of 1) | `[true, false, false]` |
| undo (the flip of 0) | `[false, false, false]` |
| undo (nothing left) | `[false, false, false]` |

So the result has seven snapshots, one per operation. Other examples:

| `switchCount` | `operations` | Output |
| --- | --- | --- |
| `2` | `[1, 1]` | `[[false, true], [false, false]]` |
| `2` | `[-1, 0]` | `[[false, false], [true, false]]` |
| `4` | `[]` | `[]` |

## Constraints

- `1 ≤ switchCount ≤ 100`
- `0 ≤ operations.count ≤ 1,000`
- Every operation is `-1` or a valid switch number.

<Hints>
<Hint>
Keep the current panel in a `var` array of `Bool`. After each operation, append it to the result. Because arrays are values, each `append` stores the panel **as it is at that moment**, and later flips don't change the snapshots you've already saved.
</Hint>
<Hint>
For undo, keep a second list: before each flip, save a copy of the panel to it. That's just `saved.append(panel)`, and again value semantics makes it a real snapshot.
</Hint>
<Hint>
To undo, take the most recent saved panel with `saved.popLast()` and make it the current panel. `popLast()` returns `nil` when there's nothing to undo, so `if let previous = saved.popLast()` handles that case for free.
</Hint>
</Hints>

## Solutions

<Approach title="A stack of saved panels" time="O(m · s)" space="O(m · s)">

Here m is the number of operations and s the number of switches. Save the whole panel before every flip, and an undo simply restores the last saved panel. The code never copies an array by hand: `saved.append(panel)`, `panel = previous` and `result.append(panel)` each give the receiver its own independent value.

```swift
public enum SwitchPanelUndo {
    public static func history(switchCount: Int, operations: [Int]) -> [[Bool]] {
        var panel = Array(repeating: false, count: switchCount)
        var saved: [[Bool]] = []
        var result: [[Bool]] = []
        for operation in operations {
            if operation == -1 {
                if let previous = saved.popLast() {
                    panel = previous
                }
            } else {
                saved.append(panel)
                panel[operation].toggle()
            }
            result.append(panel)
        }
        return result
    }
}
```

`toggle()` flips a `Bool` in place; `panel[operation] = !panel[operation]` does the same. Copy-on-write keeps this cheaper than it looks: each `append` shares storage until the next flip writes to `panel`, and only then is one copy of s values made.

In Python, Java or JavaScript, appending the same list object every time would fill the result with references to **one** list, and every snapshot would show the final state. In Swift, the straightforward code is already correct.

</Approach>

<Approach title="Remember which switch, not the whole panel" time="O(m · s)" space="O(m · s)">

Flipping a switch twice puts it back, so an undo doesn't need the old panel at all: it only needs to know **which** switch was flipped last. A stack of switch numbers is enough.

```swift
public static func history(switchCount: Int, operations: [Int]) -> [[Bool]] {
    var panel = Array(repeating: false, count: switchCount)
    var flipped: [Int] = []
    var result: [[Bool]] = []
    for operation in operations {
        if operation == -1 {
            if let last = flipped.popLast() {
                panel[last].toggle()
            }
        } else {
            panel[operation].toggle()
            flipped.append(operation)
        }
        result.append(panel)
    }
    return result
}
```

The undo history now costs O(1) per flip instead of O(s). The result still holds m snapshots of s values each, so the total stays O(m · s); but when only the final panel is needed, this version uses O(m) extra space where the first needs O(m · s). Saving whole states is simplest; saving just the change is leaner. Undo systems in real apps use both ideas.

</Approach>
