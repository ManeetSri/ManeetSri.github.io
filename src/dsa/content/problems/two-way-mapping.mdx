Two checks that share one idea: a mapping that works in **both directions**.

- `isomorphic` returns `true` if you can replace each character of `first` with a character to get `second`, where every copy of a character is replaced the same way and no two different characters are replaced by the same one.
- `followsPattern` returns `true` if the words of `sentence` (separated by single spaces) follow `pattern` in the same way: each letter stands for exactly one word, and each word for exactly one letter.

`TwoWayMapping.isomorphic(_ first: String, _ second: String) -> Bool`

`TwoWayMapping.followsPattern(_ pattern: String, _ sentence: String) -> Bool`

## Examples

| Call | Output |
| --- | --- |
| `isomorphic("paper", "title")` | `true` |
| `isomorphic("noon", "deed")` | `true` |
| `isomorphic("ab", "cc")` | `false` |
| `isomorphic("a", "ab")` | `false` |
| `followsPattern("xyyx", "sun moon moon sun")` | `true` |
| `followsPattern("xyyx", "sun moon moon star")` | `false` |
| `followsPattern("xy", "sun sun")` | `false` |
| `followsPattern("xyz", "red green")` | `false` |

In `"paper"` → `"title"`, p becomes t, a becomes i, e becomes l and r becomes e. In `"ab"` → `"cc"`, both `a` and `b` would have to become `c`, which isn't allowed. `"xy"` against `"sun sun"` fails for the same reason in the other direction.

## Constraints

- `0 ≤ first.count, second.count ≤ 100,000`; they can contain any characters.
- `1 ≤ pattern.count ≤ 20,000`, lowercase letters only.
- `sentence` is lowercase words separated by single spaces, with no leading or trailing space.

<Hints>
<Hint>
If the lengths differ (characters, or letters against words), the answer is `false` straight away.
</Hint>
<Hint>
Walk both sequences together and record what each symbol maps to. A symbol that's already mapped must map to the same thing again.
</Hint>
<Hint>
One dictionary only catches half the mistakes: `"ab"` → `"cc"` maps a to c and b to c without ever contradicting itself. Keep a second dictionary for the reverse direction.
</Hint>
</Hints>

## Solutions

<Approach title="Two dictionaries" time="O(n)" space="O(k)">

For each pair, check both directions before recording them. k is the number of distinct symbols.

```swift
public enum TwoWayMapping {
    public static func isomorphic(_ first: String, _ second: String) -> Bool {
        let a = Array(first)
        let b = Array(second)
        guard a.count == b.count else { return false }
        var forward: [Character: Character] = [:]
        var backward: [Character: Character] = [:]
        for (x, y) in zip(a, b) {
            if let mapped = forward[x], mapped != y { return false }
            if let mapped = backward[y], mapped != x { return false }
            forward[x] = y
            backward[y] = x
        }
        return true
    }

    public static func followsPattern(_ pattern: String, _ sentence: String) -> Bool {
        let letters = Array(pattern)
        let words = sentence.split(separator: " ").map(String.init)
        guard letters.count == words.count else { return false }
        var wordFor: [Character: String] = [:]
        var letterFor: [String: Character] = [:]
        for (letter, word) in zip(letters, words) {
            if let mapped = wordFor[letter], mapped != word { return false }
            if let mapped = letterFor[word], mapped != letter { return false }
            wordFor[letter] = word
            letterFor[word] = letter
        }
        return true
    }
}
```

</Approach>

<Approach title="First-occurrence signatures" time="O(n)" space="O(n)">

Replace every symbol with the position where that symbol first appeared: `"paper"` becomes `[0, 1, 0, 3, 4]`, and so does `"title"`. Two sequences fit a two-way mapping exactly when their signatures are equal. A generic helper works for characters and words alike.

```swift
static func signature<T: Hashable>(_ items: [T]) -> [Int] {
    var firstSeen: [T: Int] = [:]
    var result: [Int] = []
    for (index, item) in items.enumerated() {
        if firstSeen[item] == nil {
            firstSeen[item] = index
        }
        result.append(firstSeen[item]!)
    }
    return result
}

public static func isomorphic(_ first: String, _ second: String) -> Bool {
    signature(Array(first)) == signature(Array(second))
}

public static func followsPattern(_ pattern: String, _ sentence: String) -> Bool {
    signature(Array(pattern)) == signature(sentence.split(separator: " ").map(String.init))
}
```

Arrays of different lengths are never equal, so the length check comes for free.

</Approach>
