This time the houses stand around a ring road, so the last house is next to the first. `houses[i]` is the cash in house `i`, and robbing any two neighbouring houses sets off the alarm. Return the most cash you can take.

`RingRoadHeist.maximumLoot(houses: [Int]) -> Int`

## Examples

| `houses` | Output | Why |
| --- | --- | --- |
| `[5, 8, 6, 1, 2, 9]` | `18` | houses 1, 3 and 5; houses 0, 2 and 5 would give 20, but 0 and 5 are neighbours |
| `[7, 2, 4, 9]` | `11` | 7 + 4, because 7 and 9 can't both be taken |
| `[3, 5]` | `5` | two houses are neighbours both ways round |
| `[4]` | `4` | a single house has no neighbours |
| `[]` | `0` | |

## Constraints

- `0 ≤ houses.count ≤ 100,000`
- `0 ≤ houses[i] ≤ 10,000`
- The tests use rings of 100,000 houses.

<Hints>
<Hint>
The straight-street DP doesn't work as it stands, because whether you may rob the last house depends on what you did with the first. Is there a house you can be sure is left alone?
</Hint>
<Hint>
Not one particular house, but a pair: a plan can't rob both house 0 and the last house, so it leaves at least one of them alone. Each case is an ordinary straight street.
</Hint>
<Hint>
Run the straight-street solution on houses 1...n − 1 and on houses 0...n − 2, and return the larger. `dropFirst()` and `dropLast()` give those as slices; loop over their values rather than indexing them. Handle a single house separately.
</Hint>
</Hints>

## Solutions

<Approach title="Two straight streets" time="O(n)" space="O(1)">

Every valid plan on the ring leaves house 0 alone or leaves the last house alone, so it's a valid plan on one of the two straight streets, and every plan on those streets is valid on the ring. The best of the two runs is the answer. A single house is the exception: both streets are empty, but the house itself can be robbed.

```swift
public enum RingRoadHeist {
    public static func maximumLoot(houses: [Int]) -> Int {
        if houses.count == 1 {
            return houses[0]
        }
        return max(straightStreet(houses.dropFirst()), straightStreet(houses.dropLast()))
    }

    /// House robber on a row. Loops over values, so a slice's original indexes don't matter.
    private static func straightStreet(_ houses: ArraySlice<Int>) -> Int {
        var (twoBack, oneBack) = (0, 0)
        for cash in houses {
            (twoBack, oneBack) = (oneBack, max(oneBack, twoBack + cash))
        }
        return oneBack
    }
}
```

An empty ring gives two empty streets and returns 0 without a special case.

</Approach>

<Approach title="Fix the first house, then run one DP" time="O(n)" space="O(1)">

Another way to break the ring: decide house 0 first. Run a DP that tracks two states per house, "robbed" and "not robbed", starting from the decision about house 0. If house 0 was robbed, the last house must end "not robbed". Doing this for both decisions is the same two passes in a different form, and it's the shape you'll use for longer constraints around a circle.

```swift
public static func maximumLoot(houses: [Int]) -> Int {
    let n = houses.count
    if n <= 1 {
        return houses.first ?? 0
    }
    var best = 0
    for robFirst in [false, true] {
        let impossible = Int.min / 2
        var (robbed, notRobbed) = robFirst ? (houses[0], impossible) : (impossible, 0)
        for i in 1..<n {
            (robbed, notRobbed) = (notRobbed + houses[i], max(robbed, notRobbed))
        }
        best = max(best, robFirst ? notRobbed : max(robbed, notRobbed))
    }
    return best
}
```

`Int.min / 2` marks a state that can't happen, with room to add to it without overflowing.

</Approach>
