A video editor's timeline holds clips that are added, trimmed and deleted while the playhead keeps asking "what's on screen now?". Build a dynamic set of closed intervals with ids that answers overlap queries quickly however the intervals arrive.

`IntervalOverlapTree.Tree`, a class with `init()`, `count`, `insert(start:end:id:)`, `remove(id:)`, `overlapping(start:end:)` and `containing(_:)`

- Intervals are closed: `[start, end]` includes both ends, and `start ≤ end`.
- `insert(start:end:id:)` adds an interval and returns `true`, or returns `false` and changes nothing if `id` is already in use. A removed id can be used again.
- `remove(id:)` removes that interval and returns `true`, or returns `false` if there isn't one.
- `overlapping(start:end:)` returns the ids of every interval sharing at least one point with `[start, end]`, in increasing order.
- `containing(_ point:)` is `overlapping(start: point, end: point)`.

## Examples

After inserting the clips `[240, 719]` (id 1), `[0, 239]` (2), `[1080, 1199]` (3), `[0, 1199]` (4), `[400, 520]` (5), `[0, 47]` (6) and `[1100, 1199]` (7):

| Code | Result | Notes |
| --- | --- | --- |
| `containing(450)` | `[1, 4, 5]` | |
| `overlapping(start: 700, end: 1090)` | `[1, 3, 4]` | 1 ends at 719; 3 starts at 1080 |
| `containing(1200)` | `[]` | everything has ended |
| `containing(0)` | `[2, 4, 6]` | |
| `insert(start: 5, end: 9, id: 4)` | `false` | id 4 is taken |
| `remove(id: 4)`, then `containing(450)` | `true`, `[1, 5]` | |

## Constraints

- Up to 100,000 intervals, with coordinates between −10⁹ and 10⁹.
- Several intervals may share a start, or be identical apart from their ids.
- The tests insert 60,000 intervals **in increasing order of start**, then query and remove. An unbalanced binary search tree becomes a chain on that input, and each insert costs O(n).

<Hints>
<Hint>
Order the intervals in a search tree by (start, id), so equal starts are fine and every interval has a unique place. Give each node one more field: `maxEnd`, the largest end in its subtree. A query can skip any subtree whose `maxEnd` is less than the query's start, and the right subtree of any node whose start is greater than the query's end.
</Hint>
<Hint>
You need balance. A treap is the shortest route: random priorities, and `split` and `merge` as in the treap lesson. Insert is split at (start, id), then merge, merge; remove is two splits around the key, then a merge. Recompute `maxEnd = max(end, left.maxEnd, right.maxEnd)` every time split or merge changes a node's children. An AVL tree works too, recomputing `maxEnd` wherever it recomputes heights.
</Hint>
<Hint>
Keep a dictionary from id to interval, so `remove(id:)` knows the (start, id) key to split at, and so `insert` can reject an id that's in use. Collect the query's ids in any order and sort them at the end.
</Hint>
</Hints>

## Solutions

<Approach title="Check every interval" time="O(n) per query" space="O(n)">

Keep the intervals in a dictionary and test each one against the query: `start ≤ queryEnd && queryStart ≤ end`. It's the right model for testing, and fine for a few hundred intervals, but a timeline of 60,000 clips queried thousands of times is too slow.

</Approach>

<Approach title="Interval tree on a treap" time="O(log n) expected per change; about O(log n + k) per query" space="O(n)">

The treap stays balanced for any insertion order, and `maxEnd` is maintained inside split and merge, the only places a node's children change.

```swift
public enum IntervalOverlapTree {
    public final class Tree {
        final class Node {
            let start: Int
            let end: Int
            let id: Int
            let priority: UInt64
            var maxEnd: Int
            var left: Node?
            var right: Node?

            init(start: Int, end: Int, id: Int, priority: UInt64) {
                self.start = start
                self.end = end
                self.id = id
                self.priority = priority
                maxEnd = end
            }

            func update() {
                maxEnd = Swift.max(end, left?.maxEnd ?? Int.min, right?.maxEnd ?? Int.min)
            }
        }

        private var root: Node?
        private var intervals: [Int: (start: Int, end: Int)] = [:]
        private var state: UInt64 = 0x5EED_1234             // SplitMix64, for the priorities

        public init() {}

        public var count: Int { intervals.count }

        private func nextPriority() -> UInt64 {
            state &+= 0x9E37_79B9_7F4A_7C15
            var z = state
            z = (z ^ (z >> 30)) &* 0xBF58_476D_1CE4_E5B9
            z = (z ^ (z >> 27)) &* 0x94D0_49BB_1331_11EB
            return z ^ (z >> 31)
        }

        /// Splits into (keys before `key`, the rest), or (keys up to and including `key`, the rest).
        private func split(_ node: Node?, _ key: (Int, Int), includingKey: Bool) -> (Node?, Node?) {
            guard let node else { return (nil, nil) }
            let nodeKey = (node.start, node.id)
            let goesLeft = includingKey ? nodeKey <= key : nodeKey < key
            if goesLeft {
                let (middle, right) = split(node.right, key, includingKey: includingKey)
                node.right = middle
                node.update()
                return (node, right)
            }
            let (left, middle) = split(node.left, key, includingKey: includingKey)
            node.left = middle
            node.update()
            return (left, node)
        }

        /// Joins two treaps where every key in `a` is smaller than every key in `b`.
        private func merge(_ a: Node?, _ b: Node?) -> Node? {
            guard let a else { return b }
            guard let b else { return a }
            if a.priority > b.priority {
                a.right = merge(a.right, b)
                a.update()
                return a
            }
            b.left = merge(a, b.left)
            b.update()
            return b
        }

        @discardableResult
        public func insert(start: Int, end: Int, id: Int) -> Bool {
            guard intervals[id] == nil else { return false }
            intervals[id] = (start, end)
            let node = Node(start: start, end: end, id: id, priority: nextPriority())
            let (left, right) = split(root, (start, id), includingKey: false)
            root = merge(merge(left, node), right)
            return true
        }

        @discardableResult
        public func remove(id: Int) -> Bool {
            guard let interval = intervals.removeValue(forKey: id) else { return false }
            let key = (interval.start, id)
            let (left, rest) = split(root, key, includingKey: false)
            let (_, right) = split(rest, key, includingKey: true)
            root = merge(left, right)
            return true
        }

        public func overlapping(start: Int, end: Int) -> [Int] {
            var result: [Int] = []
            func search(_ node: Node?) {
                guard let node, node.maxEnd >= start else { return }
                search(node.left)
                if node.start <= end && start <= node.end {
                    result.append(node.id)
                }
                if node.start <= end {
                    search(node.right)
                }
            }
            search(root)
            return result.sorted()
        }

        public func containing(_ point: Int) -> [Int] {
            overlapping(start: point, end: point)
        }
    }
}
```

`remove` splits off the keys before (start, id), then the keys up to and including it, which isolates exactly one node: no `id + 1` that could overflow at `Int.max`. Swift compares the `(Int, Int)` tuples lexicographically, start first and id second.

</Approach>
