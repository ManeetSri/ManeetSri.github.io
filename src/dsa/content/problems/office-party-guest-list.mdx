A company's org chart is a binary tree: every person has at most two direct reports, and each node's value is how much fun that person adds to a party. Some values are negative. Nobody will come if their direct manager (their parent in the tree) is also invited. Return the largest total fun any guest list can reach. Inviting nobody is allowed and scores 0.

`OfficePartyGuestList.maximumFun(_ root: TreeNode?) -> Int`

## Examples

| `root` (level order) | Output |
| --- | --- |
| `[6, 4, 9, 7, 2, nil, 1, nil, nil, 5, 8]` | `29` |
| `[5, 3, 4, nil, 1, nil, 2]` | `8` |
| `[10, 1, 1, 6, 7, 3]` | `26` |
| `[-3, -1, -2]` | `0` |
| `[]` | `0` |

In the first example, the best list is 7, 5, 8 and 9: it leaves out the top manager, 6, and the 4 above the 7. In the third, the top manager comes with everyone two levels below. In the fourth, every value is negative, so the best party is no party.

## Constraints

- The chart has `0` to `150,000` people, and its height is at most `500`.
- `-10,000 ≤ value ≤ 10,000`
- The tests compare your answer with a brute force over every guest list on hundreds of small charts, then try charts of 131,071 and 100,000 people.

<Hints>
<Hint>
For one person, there are two cases: they're invited, or they aren't. What does each case force, or allow, for their direct reports?
</Hint>
<Hint>
A single number per subtree isn't enough for the parent to decide. Return two: the best total for this person's subtree if they're invited, and if they aren't.
</Hint>
<Hint>
Invited: their value plus each report's "not invited" total. Not invited: each report's better total. An empty subtree returns `(0, 0)`, and the answer is the larger of the root's two numbers.
</Hint>
</Hints>

## Solutions

<Approach title="Try every guest list" time="O(2ⁿ · n)" space="O(n)">

List the people, and for each subset check that no one is invited with their manager. It's the brute force the tests use on small charts, and it's hopeless beyond about 20 people.

</Approach>

<Approach title="Return a pair from every subtree" time="O(n)" space="O(h)">

A post-order pass where each call returns `(invited, leftOut)` for its subtree. Leaving someone out is always allowed, which takes care of negative values and of the empty list at the same time. The recursion is as deep as the tree's height, at most 500 here.

```swift
import DSAKit

public enum OfficePartyGuestList {
    public static func maximumFun(_ root: TreeNode?) -> Int {
        func best(_ node: TreeNode?) -> (invited: Int, leftOut: Int) {
            guard let node else { return (0, 0) }
            let left = best(node.left)
            let right = best(node.right)
            let invited = node.value + left.leftOut + right.leftOut
            let leftOut = max(left.invited, left.leftOut) + max(right.invited, right.leftOut)
            return (invited, leftOut)
        }
        let answer = best(root)
        return max(answer.invited, answer.leftOut)
    }
}
```

The answer is never negative: the root's `leftOut` value adds up `max` values that start from 0 at the empty subtrees, so it's at least 0.

</Approach>
