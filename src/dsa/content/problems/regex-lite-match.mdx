Implement the heart of a regular-expression engine. In a pattern, `.` matches any one character, a letter matches itself, and `*` means **zero or more copies of the element just before it** (a letter or `.`). Return whether the pattern matches the **whole** text.

`RegexLiteMatcher.matches(_ text: String, pattern: String) -> Bool`

## Examples

| `text` | `pattern` | Output |
| --- | --- | --- |
| `"colour"` | `"colou*r"` | `true` |
| `"color"` | `"colou*r"` | `true` |
| `"aab"` | `"c*a*b"` | `true` |
| `"swift"` | `"s.*t"` | `true` |
| `"swift"` | `"s.ft"` | `false` |
| `""` | `"a*b*"` | `true` |
| `"ab"` | `".*c"` | `false` |
| `"aaa"` | `"a*a"` | `true` |

`"u*"` makes the u optional, so both spellings match. `"c*"` can mean zero c's, which is how `"c*a*b"` matches `"aab"`. `".*"` matches any run of characters.

## Constraints

- `text` has 0 to 700 lowercase letters.
- `pattern` has 0 to 250 characters: lowercase letters, `.` and `*`. It's always valid: a `*` never comes first and never follows another `*`.
- The tests include patterns like `"a*a*a*a*a*a*b"` against 700 a's, where plain recursion never finishes.

<Hints>
<Hint>
Treat `x*` as one unit. Let `M(i, j)` say whether the first i characters of the text match the first j of the pattern; the empty pattern matches only the empty text.
</Hint>
<Hint>
If `pattern[j - 1]` is a star, the unit is `pattern[j - 2]` plus the star. Zero copies: `M(i, j - 2)`. One more copy, if `pattern[j - 2]` matches `text[i - 1]`: `M(i - 1, j)`.
</Hint>
<Hint>
Otherwise, `.` or an equal letter gives `M(i - 1, j - 1)`. The empty-text row is true while the pattern is made of `x*` units that can all vanish, and the zero-copies rule fills it for you.
</Hint>
</Hints>

## Solutions

<Approach title="Plain recursion" time="exponential" space="O(n + m)">

Look at the pattern's next element. If a star follows it, try zero copies (skip two pattern characters) or, if it matches, one copy (advance the text, keep the pattern). Otherwise match one character. The tests use this on thousands of short random cases.

</Approach>

<Approach title="DP on prefixes" time="O(n · m)" space="O(n · m)">

```swift
public enum RegexLiteMatcher {
    public static func matches(_ text: String, pattern: String) -> Bool {
        let t = Array(text), p = Array(pattern)
        var match = Array(repeating: Array(repeating: false, count: p.count + 1), count: t.count + 1)
        for i in 0...t.count {
            for j in 0...p.count {
                if j == 0 {
                    match[i][j] = i == 0
                } else if p[j - 1] == "*" {
                    let none = j >= 2 && match[i][j - 2]
                    let oneMore = j >= 2 && i > 0 && (p[j - 2] == "." || p[j - 2] == t[i - 1]) && match[i - 1][j]
                    match[i][j] = none || oneMore
                } else if i > 0 && (p[j - 1] == "." || p[j - 1] == t[i - 1]) {
                    match[i][j] = match[i - 1][j - 1]
                }
            }
        }
        return match[t.count][p.count]
    }
}
```

The `j >= 2` checks only guard against invalid patterns; with a valid one, a star is never at index 0. A memoised recursion over `(i, j)` is just as good, and goes at most n + m calls deep.

</Approach>
