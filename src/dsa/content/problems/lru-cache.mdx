Build a generic cache that holds at most `capacity` entries. When a new key arrives and the cache is full, it first throws out the entry that has gone longest without being used. Reading a key or setting it counts as using it. Every operation should be O(1) on average.

`LRUCache.Cache<Key: Hashable, Value>`, with `init(capacity:)`, `count`, `value(for:)`, `setValue(_:for:)`, `removeValue(for:)` and `keysByRecency`

- `value(for:)` returns the value, or `nil` if the key isn't cached. Finding it makes the key the most recently used; a miss changes nothing.
- `setValue(_:for:)` stores or replaces the value and makes the key the most recently used. Replacing never evicts anything; adding a new key to a full cache evicts the least recently used entry.
- `removeValue(for:)` removes a key and returns its value, or returns `nil` if it isn't cached.
- `keysByRecency` lists every cached key, most recently used first. It can be O(n).

## Examples

With `let cache = Cache<String, Int>(capacity: 2)`:

| Code | Result | `keysByRecency` afterwards |
| --- | --- | --- |
| `setValue(1, for: "a")`, `setValue(2, for: "b")` | | `["b", "a"]` |
| `value(for: "a")` | `1` | `["a", "b"]` |
| `setValue(3, for: "c")` | evicts `"b"` | `["c", "a"]` |
| `value(for: "b")` | `nil` | `["c", "a"]` |
| `setValue(10, for: "a")` | replaces, no eviction | `["a", "c"]` |
| `removeValue(for: "c")` | `3` | `["a"]` |

## Constraints

- `capacity ≥ 1`, up to 50,000.
- Up to a few hundred thousand operations; aim for O(1) average time each.
- The cache must not keep values alive after they're evicted or removed, or after the cache itself is gone. The tests check, so mind the retain cycles.

<Hints>
<Hint>
Use two structures together: a dictionary from keys to nodes, for O(1) lookup, and a doubly linked list of those nodes in order of use, for O(1) reordering. Most recent at the head, least recent at the tail. Each node stores its key as well as its value, so that evicting the tail node can also remove its dictionary entry.
</Hint>
<Hint>
Write two private helpers: `unlink(_:)`, which joins a node's neighbours (updating `head` or `tail` when the node is at an end), and `pushFront(_:)`. A generic cache can't create sentinel nodes, because there's no spare `Key` or `Value` to put in them, so `head` and `tail` are optionals and the helpers handle `nil` neighbours.
</Hint>
<Hint>
In `setValue`, check whether the key already exists before checking whether the cache is full. Make the node's `previous` reference `weak`: the dictionary and the `next` chain already own every node, and two strong directions would make neighbours keep each other alive.
</Hint>
</Hints>

## Solutions

<Approach title="Array of keys in order of use" time="O(capacity) per operation" space="O(capacity)">

A dictionary for the values plus an array of keys, most recent first, is easy to get right. But every use has to find the key in the array, remove it and insert it at the front: O(capacity) work. With 50,000 entries, the tests' long run becomes billions of steps.

```swift
private var values: [Key: Value] = [:]
private var order: [Key] = []          // most recent first

public func value(for key: Key) -> Value? {
    guard let value = values[key] else { return nil }
    order.removeAll { $0 == key }      // O(capacity)
    order.insert(key, at: 0)           // O(capacity)
    return value
}
```

</Approach>

<Approach title="Dictionary plus doubly linked list" time="O(1) average" space="O(capacity)">

The dictionary hands you the node, and the doubly linked list lets you move or remove a node you hold in O(1). The least recently used node is always the tail.

```swift
public enum LRUCache {
    public final class Cache<Key: Hashable, Value> {
        final class Node {
            let key: Key
            var value: Value
            var next: Node?
            weak var previous: Node?

            init(key: Key, value: Value) {
                self.key = key
                self.value = value
            }
        }

        public let capacity: Int
        private var nodes: [Key: Node] = [:]
        private var head: Node?      // most recently used
        private var tail: Node?      // least recently used

        public init(capacity: Int) {
            precondition(capacity > 0, "An LRU cache needs room for at least one entry")
            self.capacity = capacity
        }

        public var count: Int { nodes.count }

        private func unlink(_ node: Node) {
            let before = node.previous
            let after = node.next
            if let before {
                before.next = after
            } else {
                head = after
            }
            if let after {
                after.previous = before
            } else {
                tail = before
            }
            node.next = nil
            node.previous = nil
        }

        private func pushFront(_ node: Node) {
            node.next = head
            head?.previous = node
            head = node
            if tail == nil {
                tail = node
            }
        }

        public func value(for key: Key) -> Value? {
            guard let node = nodes[key] else { return nil }
            if node !== head {
                unlink(node)
                pushFront(node)
            }
            return node.value
        }

        public func setValue(_ value: Value, for key: Key) {
            if let node = nodes[key] {
                node.value = value
                if node !== head {
                    unlink(node)
                    pushFront(node)
                }
                return
            }
            let node = Node(key: key, value: value)
            nodes[key] = node
            pushFront(node)
            if nodes.count > capacity, let oldest = tail {
                unlink(oldest)
                nodes[oldest.key] = nil
            }
        }

        @discardableResult
        public func removeValue(for key: Key) -> Value? {
            guard let node = nodes.removeValue(forKey: key) else { return nil }
            unlink(node)
            return node.value
        }

        public var keysByRecency: [Key] {
            var keys: [Key] = []
            var current = head
            while let node = current {
                keys.append(node.key)
                current = node.next
            }
            return keys
        }
    }
}
```

This version inserts the new node first and then evicts if the cache has overflowed, which is equivalent to evicting first. An evicted node has no owners left once it's unlinked and out of the dictionary, so ARC frees it, and its value, straight away. And because `previous` is weak, neighbouring nodes don't keep each other alive, so when the cache itself goes, every node goes with it.

</Approach>
