A grid of `rows × columns` cells starts as all water. Cells rise out of the sea one at a time: `land[i] = [row, column]` turns that cell into land. After each one, report how many **islands** there are. An island is a group of land cells connected up, down, left or right; diagonal neighbours don't count. A cell can appear more than once, and rising again changes nothing.

`RisingIslands.counts(rows: Int, columns: Int, _ land: [[Int]]) -> [Int]`

## Examples

| `rows`, `columns` | `land` | Returns |
| --- | --- | --- |
| 3, 4 | `[[0, 0], [0, 1], [2, 2], [1, 3], [2, 3], [1, 0], [0, 3], [1, 2], [1, 1]]` | `[1, 1, 2, 3, 2, 2, 2, 2, 1]` |
| 2, 2 | `[[0, 0], [1, 1], [0, 1]]` | `[1, 2, 1]` |
| 3, 3 | `[[0, 1], [1, 0], [1, 2], [2, 1], [1, 1]]` | `[1, 2, 3, 4, 1]` |
| 1, 1 | `[[0, 0], [0, 0]]` | `[1, 1]` |

In the first example, (2, 3) joins the islands at (2, 2) and (1, 3). (1, 2) touches (2, 2) and (1, 3), which are already one island, so the count stays at 2. Then (1, 1) joins the last two islands. In the third, the centre cell joins four islands at once.

## Constraints

- `1 ≤ rows, columns ≤ 300`, and `0 ≤ land.count ≤ 100,000`.
- Every cell is inside the grid.
- The tests fill a 300 × 300 grid as a checkerboard first, then the remaining cells: 90,000 additions. Counting the islands from scratch after each one would take billions of steps.

<Hints>
<Hint>
When a water cell becomes land, it's a new island of one cell, until you look at its neighbours.
</Hint>
<Hint>
Number the cells `row * columns + column` and keep a union-find over all of them, plus a Bool per cell saying whether it's land. For each of the new cell's land neighbours, union the two cells.
</Hint>
<Hint>
Subtract one from the count only when `union` returns true. Two neighbours might already be in the same island.
</Hint>
</Hints>

## Solutions

<Approach title="Flood fill after every addition" time="O(k · rows · columns)" space="O(rows · columns)">

Mark the cell, then count the islands in the whole grid with a DFS or BFS, as in [Number of islands and island area](/dsa/learn/gt-islands). Simple, and right, but each of the k additions costs a full scan.

</Approach>

<Approach title="Union-find, one cell at a time" time="O(rows · columns + k α)" space="O(rows · columns)">

A new land cell adds one island. Each union with a land neighbour that joins two different islands removes one. A cell that's already land changes nothing.

```swift
import DSAKit

public enum RisingIslands {
    public static func counts(rows: Int, columns: Int, _ land: [[Int]]) -> [Int] {
        var islands = UnionFind(count: rows * columns)
        var isLand = Array(repeating: false, count: rows * columns)
        var count = 0
        var result: [Int] = []
        result.reserveCapacity(land.count)
        for cell in land {
            let row = cell[0]
            let column = cell[1]
            let index = row * columns + column
            if !isLand[index] {
                isLand[index] = true
                count += 1
                for (dr, dc) in [(-1, 0), (1, 0), (0, -1), (0, 1)] {
                    let r = row + dr
                    let c = column + dc
                    guard r >= 0, r < rows, c >= 0, c < columns, isLand[r * columns + c] else { continue }
                    if islands.union(index, r * columns + c) {
                        count -= 1
                    }
                }
            }
            result.append(count)
        }
        return result
    }
}
```

Creating the union-find costs O(rows · columns) once. If the grid were huge and mostly water, you'd create elements only for cells that rise, with a dictionary from cell to index and DSAKit's `addElement()`.

</Approach>
