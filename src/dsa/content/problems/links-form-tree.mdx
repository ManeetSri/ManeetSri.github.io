Nodes are numbered 0 to n − 1, and you're given a list of undirected links, each `[a, b]`. Return true if the links form a single **tree**: every node can reach every other through the links, and there are no cycles.

`LinksFormTree.check(_ n: Int, _ links: [[Int]]) -> Bool`

## Examples

| `n` | `links` | Returns | Why |
| --- | --- | --- | --- |
| 5 | `[[0, 1], [0, 2], [0, 3], [1, 4]]` | true | connected, no cycle |
| 5 | `[[0, 1], [1, 2], [2, 3], [1, 3], [1, 4]]` | false | 1–2–3 is a cycle |
| 4 | `[[0, 1], [2, 3]]` | false | two separate pieces |
| 4 | `[[0, 1], [1, 2], [2, 0]]` | false | right count, but a cycle, and 3 is alone |
| 1 | `[]` | true | one node on its own is a tree |

## Constraints

- `1 ≤ n ≤ 100,000` and `0 ≤ links.count ≤ 100,000`.
- Each link joins two different nodes in `0..<n`. The same link may appear twice, which makes a cycle.
- The tests include a random tree on 100,000 nodes.

<Hints>
<Hint>
How many links does a tree on n nodes have? If the count is wrong, you can answer straight away.
</Hint>
<Hint>
With exactly n − 1 links, a graph with no cycle must be connected: each link that doesn't close a cycle joins two pieces, so n − 1 of them leave one piece.
</Hint>
<Hint>
So check the count, then union every link. A union that returns false means the link closes a cycle.
</Hint>
</Hints>

## Solutions

<Approach title="Count, then a search" time="O(n)" space="O(n)">

Check that there are n − 1 links, build an adjacency list, and run a BFS or DFS from node 0. With exactly n − 1 links, the links form a tree exactly when the search reaches all n nodes.

</Approach>

<Approach title="Count, then union-find" time="O(n α(n))" space="O(n)">

A tree has exactly n − 1 links and no cycle. Union every link; if one finds its ends already connected, there's a cycle.

```swift
import DSAKit

public enum LinksFormTree {
    public static func check(_ n: Int, _ links: [[Int]]) -> Bool {
        guard links.count == n - 1 else { return false }
        var nodes = UnionFind(count: n)
        for link in links where !nodes.union(link[0], link[1]) {
            return false
        }
        return true
    }
}
```

Without the count check, `[[0, 1], [2, 3]]` on 4 nodes would pass: it has no cycle, but it isn't connected.

</Approach>
