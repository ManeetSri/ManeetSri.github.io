## Why it matters

In Swift, a function is a value, just like a number or a string. You can store it in a constant, keep several in an array, pass one to another function or return one from a function. That's how `sorted(by:)` lets you choose the order, how a button knows what to run when it's tapped in an iOS app, and how the whole family of `map`, `filter` and `reduce` in the next module works. This lesson is the bridge to closures.

## Every function has a type

You know that `5` has the type `Int` and `"hi"` has the type `String`. A function has a type too, made from its parameter types and its return type:

| Function | Its type |
| --- | --- |
| `func add(_ a: Int, _ b: Int) -> Int` | `(Int, Int) -> Int` |
| `func isEven(_ n: Int) -> Bool` | `(Int) -> Bool` |
| `func greet(_ name: String)` | `(String) -> Void` |
| `func rollCall() -> Int` | `() -> Int` |

Read `(Int, Int) -> Int` as "takes two `Int`s and returns an `Int`". Notice that:

- the parentheses are always there, even for one parameter, `(Int) -> Bool`, or none, `() -> Int`;
- a function that returns nothing has the return type `Void`;
- argument labels and parameter names are **not** part of the type. `add` and `multiply` below have the same type, whatever their labels.

## Storing a function in a constant

Write the function's name **without** parentheses, and you get the function itself rather than calling it:

```swift run
func add(_ a: Int, _ b: Int) -> Int {
    a + b
}

func multiply(_ a: Int, _ b: Int) -> Int {
    a * b
}

var operation: (Int, Int) -> Int = add
print(operation(6, 3))

operation = multiply
print(operation(6, 3))
```

```output
9
18
```

What to notice:

- `operation` is a variable whose type is `(Int, Int) -> Int`. It can hold any function of that type.
- `= add` stores the function. `= add(6, 3)` would call it and try to store the number 9, which is the wrong type.
- Calling through the variable looks like an ordinary call: `operation(6, 3)`. You never write argument labels when calling through a variable, because labels aren't part of the type.

## Passing a function to a function

Since a function is a value, it can be an argument. Here, the caller decides *what* to do and `applyToAll` decides *how* to do it to every element:

```swift run
func applyToAll(_ numbers: [Int], _ transform: (Int) -> Int) -> [Int] {
    var result: [Int] = []
    for number in numbers {
        result.append(transform(number))
    }
    return result
}

func double(_ n: Int) -> Int { n * 2 }
func square(_ n: Int) -> Int { n * n }
func negate(_ n: Int) -> Int { -n }

let numbers = [1, 2, 3, 4]
print(applyToAll(numbers, double))
print(applyToAll(numbers, square))
print(applyToAll(numbers, negate))
```

```output
[2, 4, 6, 8]
[1, 4, 9, 16]
[-1, -2, -3, -4]
```

What to notice:

- The parameter `transform` has the type `(Int) -> Int`, so any function of that shape can be passed in.
- Inside, `transform(number)` calls whichever function the caller chose.
- One loop, written once, does three different jobs. Without function values, you'd write three nearly identical loops.

A function that takes or returns another function is called a **higher-order function**. `applyToAll` is a home-made version of the standard library's `map`, which you'll use all the time from M06 on.

### Passing a yes-or-no test

Another very common shape is a function that takes a **test**, a function returning `Bool`, and uses it to decide which elements count:

```swift run
func count(_ numbers: [Int], where test: (Int) -> Bool) -> Int {
    var total = 0
    for number in numbers {
        if test(number) {
            total += 1
        }
    }
    return total
}

func isNegative(_ n: Int) -> Bool { n < 0 }
func isEven(_ n: Int) -> Bool { n % 2 == 0 }

let readings = [4, -2, 7, -9, 0, 12]
print(count(readings, where: isNegative))
print(count(readings, where: isEven))
```

```output
2
4
```

The call `count(readings, where: isNegative)` reads like a sentence, thanks to the `where:` label. A function that returns `Bool` like this is often called a **predicate**. The standard library's `filter`, `contains(where:)` and `first(where:)`, all coming in M06, take predicates in exactly this way.

### The standard library already does this

`sorted(by:)` takes a function of type `(Int, Int) -> Bool` that answers "should the first come before the second?":

```swift run
func isGreater(_ a: Int, _ b: Int) -> Bool {
    a > b
}

let scores = [40, 95, 70, 12]
print(scores.sorted(by: isGreater))
print(scores.sorted(by: >))
```

```output
[95, 70, 40, 12]
[95, 70, 40, 12]
```

Operators are functions too. `>` for integers has the type `(Int, Int) -> Bool`, so you can pass it straight in. The sorting algorithm stays the same, and only the comparison changes.

## Returning a function

A function can also hand back a function. The return type is then a function type, so you'll see two arrows:

```swift run
func operation(for symbol: Character) -> (Int, Int) -> Int {
    func add(_ a: Int, _ b: Int) -> Int { a + b }
    func subtract(_ a: Int, _ b: Int) -> Int { a - b }
    func multiply(_ a: Int, _ b: Int) -> Int { a * b }

    switch symbol {
    case "+": return add
    case "-": return subtract
    default: return multiply
    }
}

let chosen = operation(for: "-")
print(chosen(10, 4))
print(operation(for: "*")(10, 4))
```

```output
6
40
```

Read `-> (Int, Int) -> Int` as "returns a function that takes two `Int`s and returns an `Int`". The second call does both steps at once: `operation(for: "*")` returns `multiply`, and `(10, 4)` calls it. The nested helpers from the previous lesson are perfect here: they're hidden, and only handed out on request.

## Arrays of functions

Values can go in arrays, so functions can too. Here's a small pipeline that applies a list of steps in order:

```swift run
func addOne(_ n: Int) -> Int { n + 1 }
func double(_ n: Int) -> Int { n * 2 }
func square(_ n: Int) -> Int { n * n }

let steps: [(Int) -> Int] = [addOne, double, square]

var value = 3
for step in steps {
    value = step(value)
    print(value)
}
```

```output
4
8
64
```

The type `[(Int) -> Int]` means "an array of functions from `Int` to `Int`". Changing the order of the array changes the result, without touching the loop.

## Naming function types

Function types get long. A `typealias` gives one a readable name:

```swift
typealias Comparison = (Int, Int) -> Bool

func isSmaller(_ a: Int, _ b: Int) -> Bool { a < b }
let rule: Comparison = isSmaller
```

<Callout kind="gotcha" title="Swift gotcha: name versus call">
`let f = double` stores the function. `let f = double(4)` calls it and stores `8`. If Swift complains that a function type doesn't match an `Int`, or the other way round, check for missing or extra parentheses.
</Callout>

<Callout kind="gotcha" title="Swift gotcha: no labels through a variable">
If `operation` holds `add`, call it as `operation(6, 3)`, never `operation(a: 6, b: 3)`. Labels belong to the function's declaration, not its type, so they disappear once the function is stored as a value.
</Callout>
