## Why it matters

`"paper"` and `"title"` look nothing alike, but they have the same **shape**: first letter, second letter, the first letter again, then two new ones. Strings with the same shape are called **isomorphic**. Puzzle apps solve cryptograms with this idea, since a substitution cipher replaces each letter with exactly one other; search tools use it to find words matching a pattern like "ABCA". The lesson is really about **one-to-one mappings**, and about a mistake almost everyone makes the first time: checking the mapping in only one direction.

## What isomorphic means

Two strings are isomorphic when you can turn one into the other by replacing characters, following two rules:

1. **Consistent:** every copy of a character is replaced by the same character.
2. **One-to-one:** two different characters are never replaced by the same character.

`"paper"` becomes `"title"` with p → t, a → i, e → l and r → e. That's fine: each letter has one replacement, and no two letters share one. `"ab"` and `"cc"` are **not** isomorphic: a → c and b → c breaks rule 2.

A mapping that obeys both rules is called a **bijection**. Its key property: it can be reversed, so the second string maps back to the first too.

## One dictionary isn't enough

The natural first attempt records each replacement in a dictionary and checks it's used consistently:

```swift run
func isomorphicOneWay(_ first: String, _ second: String) -> Bool {
    let a = Array(first)
    let b = Array(second)
    guard a.count == b.count else { return false }
    var forward: [Character: Character] = [:]
    for (x, y) in zip(a, b) {
        if let mapped = forward[x], mapped != y {
            return false
        }
        forward[x] = y
    }
    return true
}

print(isomorphicOneWay("paper", "title"))
print(isomorphicOneWay("ab", "cc"))
```

```output
true
true
```

The second answer is wrong. The dictionary enforces rule 1, so `a` always becomes `c` and `b` always becomes `c`, but nothing notices that two letters now share a replacement. Swap the arguments, `("cc", "ab")`, and this version correctly says `false`, which is the clue: the check must work in **both** directions.

## Two dictionaries

Keep a second dictionary for the reverse direction. Before recording a pair, check that neither side contradicts what's already known:

```swift run
func isomorphic(_ first: String, _ second: String) -> Bool {
    let a = Array(first)
    let b = Array(second)
    guard a.count == b.count else { return false }
    var forward: [Character: Character] = [:]
    var backward: [Character: Character] = [:]
    for (x, y) in zip(a, b) {
        if let mapped = forward[x], mapped != y { return false }
        if let mapped = backward[y], mapped != x { return false }
        forward[x] = y
        backward[y] = x
    }
    return true
}

print(isomorphic("paper", "title"), isomorphic("ab", "cc"), isomorphic("cc", "ab"), isomorphic("noon", "deed"))
```

```output
true false false true
```

`zip(a, b)` walks the two arrays side by side, giving one pair per position. It's **O(n)** time, and O(k) space for the k distinct characters. Using `Character` keys means accented letters and emoji work too.

## A shape you can compare: first-occurrence signatures

There's a neat way to capture a string's shape as a value. Replace every character with the position where that character **first** appeared:

```swift run
func signature<T: Hashable>(_ items: [T]) -> [Int] {
    var firstSeen: [T: Int] = [:]
    var result: [Int] = []
    for (index, item) in items.enumerated() {
        if firstSeen[item] == nil {
            firstSeen[item] = index
        }
        result.append(firstSeen[item]!)
    }
    return result
}

print(signature(Array("paper")))
print(signature(Array("title")))
print(signature(Array("ab")), signature(Array("cc")))
print(signature("sun moon moon sun".split(separator: " ").map(String.init)))
```

```output
[0, 1, 0, 3, 4]
[0, 1, 0, 3, 4]
[0, 1] [0, 0]
[0, 1, 1, 0]
```

Two sequences are isomorphic exactly when their signatures are equal. The signature only records *which positions repeat which*, and that's precisely the shape. Arrays of different lengths are never equal, so the length check comes for free.

The function is **generic**, from [Generic functions and constraints](/dsa/learn/swift-generic-functions): it works for any `Hashable` element, so the same code handles characters and whole words.

## Word pattern: the same idea with words

A close cousin: does a sentence follow a pattern of letters? `"xyyx"` matches `"sun moon moon sun"`: x stands for "sun" and y for "moon". It's the isomorphism check with words on one side, so it needs both directions too:

```swift run
func followsPattern(_ pattern: String, _ sentence: String) -> Bool {
    let letters = Array(pattern)
    let words = sentence.split(separator: " ").map(String.init)
    guard letters.count == words.count else { return false }
    var wordFor: [Character: String] = [:]
    var letterFor: [String: Character] = [:]
    for (letter, word) in zip(letters, words) {
        if let mapped = wordFor[letter], mapped != word { return false }
        if let mapped = letterFor[word], mapped != letter { return false }
        wordFor[letter] = word
        letterFor[word] = letter
    }
    return true
}

print(followsPattern("xyyx", "sun moon moon sun"))
print(followsPattern("xyyx", "sun moon moon star"))
print(followsPattern("xy", "sun sun"))
print(followsPattern("xyz", "red green"))
```

```output
true
false
false
false
```

`"xy"` against `"sun sun"` fails the reverse check: x and y would both stand for "sun". The last example fails the length check: three letters, two words.

## Grouping words by shape

Because a signature is an `[Int]`, and arrays are `Hashable`, it can be a dictionary key, exactly like the anagram keys in [Anagrams and group anagrams](/dsa/learn/str-anagrams). Here are words grouped by shape:

```swift run
func signature<T: Hashable>(_ items: [T]) -> [Int] {
    var firstSeen: [T: Int] = [:]
    var result: [Int] = []
    for (index, item) in items.enumerated() {
        if firstSeen[item] == nil {
            firstSeen[item] = index
        }
        result.append(firstSeen[item]!)
    }
    return result
}

let words = ["paper", "title", "noon", "deed", "level", "radar", "apple"]
var groupIndex: [[Int]: Int] = [:]
var groups: [[String]] = []
for word in words {
    let key = signature(Array(word))
    if let index = groupIndex[key] {
        groups[index].append(word)
    } else {
        groupIndex[key] = groups.count
        groups.append([word])
    }
}
print(groups)
```

```output
[["paper", "title"], ["noon", "deed"], ["level", "radar"], ["apple"]]
```

A cryptogram solver uses exactly this: an encrypted word can only stand for dictionary words with the same signature.

<Callout kind="gotcha" title="Common mistakes">
- **Checking only one direction.** One dictionary catches inconsistent replacements but not two characters sharing a replacement. Use two dictionaries, or compare signatures.
- **Skipping the length check.** `zip` silently stops at the end of the shorter sequence, so `"ab"` against `"abc"` would look fine without it.
- **Splitting words with `components(separatedBy:)`** when the input could have double spaces: it produces empty words. `split(separator: " ")` drops them.
</Callout>
