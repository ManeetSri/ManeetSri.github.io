## Why it matters

A 64-bit `Int` stops at 9,223,372,036,854,775,807, about 9.2 × 10¹⁸. That's huge until it isn't: 21! is already too big, and encryption works with numbers hundreds of digits long. When a number doesn't fit, you store its **digits** and do arithmetic the way you learned at school, one column at a time. "Add strings" and "multiply strings" are interview classics, and the digit-array technique comes back in M25, where the digits live in a linked list instead.

## Digits, least significant first

Store a number as an array of its digits, **reversed**, so the ones digit comes first: `"907"` becomes `[7, 0, 9]`. Then index i holds the 10ⁱ place in every number, the columns line up without any offset arithmetic, and a carry into a new column is an `append` at the end.

```swift run
func digits(_ number: String) -> [Int] {
    number.utf8.reversed().map { Int($0 - UInt8(ascii: "0")) }
}

func text(_ digits: [Int]) -> String {
    digits.reversed().map { String($0) }.joined()
}

let d = digits("907")
print(d)
print(d[0], d[2])
print(text(d))
```

```output
[7, 0, 9]
7 9
907
```

`digits` reads bytes, since a digit's byte minus the byte of `"0"` is its value, as in [Converting characters, digits and numbers](/dsa/learn/swift-char-digit-conversion). `text` turns the digits back into a string, most significant first.

## Adding with a carry

Column by column from the ones place: add the two digits and the carry, keep `total % 10` as this column's digit, and pass `total / 10` to the next column. A number that's run out of digits contributes 0.

```swift run
func digits(_ number: String) -> [Int] {
    number.utf8.reversed().map { Int($0 - UInt8(ascii: "0")) }
}

func text(_ digits: [Int]) -> String {
    digits.reversed().map { String($0) }.joined()
}

func add(_ a: String, _ b: String) -> String {
    let x = digits(a)
    let y = digits(b)
    var result: [Int] = []
    var carry = 0
    for place in 0..<max(x.count, y.count) {
        let total = (place < x.count ? x[place] : 0) + (place < y.count ? y[place] : 0) + carry
        result.append(total % 10)
        carry = total / 10
    }
    if carry > 0 {
        result.append(carry)             // the sum can have one more digit
    }
    return text(result)
}

print(add("999", "1"))
print(add("12345678901234567890", "98765432109876543210"))
print(add("0", "0"))
```

```output
1000
111111111011111111100
0
```

What to notice:

- `total` is at most 9 + 9 + 1 = 19, so the carry is always 0 or 1.
- The final `if carry > 0` is easy to forget, and `"999" + "1"` is the test that catches it.
- The second sum is far beyond `Int.max`, and nothing in the code cares. It's **O(m + n)** for numbers of m and n digits.

## Multiplying: digit i times digit j goes to place i + j

In long multiplication, the digit at place i of one number times the digit at place j of the other contributes to place **i + j**: tens times hundreds gives thousands. So add every product into the right slot, and sort out the carries in one sweep at the end.

Here's `12 × 34`, with `x = [2, 1]` and `y = [4, 3]`:

| Product | Goes to place | Slots after adding |
| --- | --- | --- |
| 2 × 4 = 8 | 0 | `[8, 0, 0, 0]` |
| 2 × 3 = 6 | 1 | `[8, 6, 0, 0]` |
| 1 × 4 = 4 | 1 | `[8, 10, 0, 0]` |
| 1 × 3 = 3 | 2 | `[8, 10, 3, 0]` |

The carry sweep turns `[8, 10, 3, 0]` into `[8, 0, 4, 0]`, which reads as 0408, so 408 once the leading zero is dropped.

```swift run
func digits(_ number: String) -> [Int] {
    number.utf8.reversed().map { Int($0 - UInt8(ascii: "0")) }
}

func text(_ digits: [Int]) -> String {
    digits.reversed().map { String($0) }.joined()
}

func multiply(_ a: String, _ b: String) -> String {
    let x = digits(a)
    let y = digits(b)
    var product = [Int](repeating: 0, count: x.count + y.count)
    for i in x.indices {
        for j in y.indices {
            product[i + j] += x[i] * y[j]
        }
    }
    var carry = 0
    for place in product.indices {
        let total = product[place] + carry
        product[place] = total % 10
        carry = total / 10
    }
    while product.count > 1 && product.last == 0 {
        product.removeLast()             // leading zeros sit at the end
    }
    return text(product)
}

print(multiply("12", "34"))
print(multiply("123456789", "987654321"), 123456789 * 987654321)
print(multiply("0", "12345"))
```

```output
408
121932631112635269 121932631112635269
0
```

The second line checks the method against `Int` arithmetic on a product that still fits. Some details:

- **Why m + n slots?** An m-digit number is less than 10ᵐ and an n-digit one less than 10ⁿ, so their product is less than 10ᵐ⁺ⁿ: at most m + n digits. The carry sweep can never run off the end.
- **Why carry at the end?** Each slot collects at most min(m, n) products of at most 81, which is tiny for an `Int`. One sweep afterwards is simpler than carrying inside the double loop.
- **Leading zeros.** The top slot is often 0, and multiplying by `"0"` makes every slot 0. Trimming while more than one digit is left keeps a single `0` for zero.

The double loop makes multiplication **O(m · n)**. Faster methods exist, such as Karatsuba's divide-and-conquer multiplication, which you'll meet in Part VII.

### Numbers too big for Int

With `multiply`, factorials stop being a problem. 21! overflows `Int`, but strings don't mind:

```swift run
func digits(_ number: String) -> [Int] {
    number.utf8.reversed().map { Int($0 - UInt8(ascii: "0")) }
}

}

        for j in y.indices {
            product[i + j] += x[i] * y[j]
        }

```

```output
33 digits
```

## Subtraction and signs

Subtraction is addition's mirror: instead of carrying 1 into the next column, you **borrow** 1 from it. For x ≥ y, column by column: subtract the digits and any borrow; if the result is negative, add 10 and borrow from the next column.

```swift run
func digits(_ number: String) -> [Int] {
    number.utf8.reversed().map { Int($0 - UInt8(ascii: "0")) }
}

func text(_ digits: [Int]) -> String {
    digits.reversed().map { String($0) }.joined()
}

// Requires x ≥ y. Both least significant first.
func subtractMagnitudes(_ x: [Int], _ y: [Int]) -> [Int] {
    var result: [Int] = []
    var borrow = 0
    for place in 0..<x.count {
        var digit = x[place] - borrow - (place < y.count ? y[place] : 0)
        borrow = 0
        if digit < 0 {
            digit += 10
            borrow = 1
        }
        result.append(digit)
    }
    while result.count > 1 && result.last == 0 {
        result.removeLast()
    }
    return result
}

print(text(subtractMagnitudes(digits("1000"), digits("1"))))
print(text(subtractMagnitudes(digits("5203"), digits("4917"))))
```

```output
999
286
```

With subtraction in hand, signed numbers follow the rules you already know:

- **Adding, same signs:** add the magnitudes and keep the sign. −7 + −8 = −(7 + 8).
- **Adding, different signs:** subtract the smaller magnitude from the larger and take the larger one's sign. −15 + 10 = −(15 − 10).
- **Multiplying:** multiply the magnitudes; the result is negative when exactly one input is.
- **Never write −0:** if the result is zero, drop the sign.

To find the larger magnitude without converting to `Int`, compare digit counts first (more digits means bigger, with no leading zeros), and if they're equal, compare digits from the most significant end.

<Callout kind="gotcha" title="Common mistakes">
- **Converting to `Int` "to check".** `Int(a)!` traps or returns `nil` for the very numbers this technique exists for.
- **Forgetting the final carry.** `"999" + "1"` needs a fourth digit.
- **Leading zeros and zero itself.** Trim zeros from the top, but always keep one digit, and never output `"-0"`.
- **Mixing up the order.** Work least significant first internally, and reverse only when turning digits back into a string.
</Callout>
