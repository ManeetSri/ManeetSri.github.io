## Why it matters

"Reverse the order of the words in a sentence" sounds like a one-liner, and in Swift it nearly is. But interviewers often add two twists: the spacing is messy, and you must do it **in place**, using no extra array. The in-place method, reverse the whole thing and then reverse each word, is a small piece of magic worth knowing. It's the same trick that rotates arrays in [Reverse and rotate in place](/dsa/learn/arrays-reverse-rotate), and it shows up again whenever you need to move blocks around without a second buffer.

## The easy way: split, reverse, join

`split(separator:)` breaks the text into words, `reversed()` flips their order and `joined(separator:)` glues them back together. As [Splitting, joining and trimming](/dsa/learn/swift-split-trim) showed, `split` drops empty pieces by default, so runs of spaces disappear for free:

```swift run
let text = "  the sky   is blue "
let words = text.split(separator: " ")
print(words.count)
print(words.reversed().joined(separator: " "))
```

```output
4
blue is sky the
```

Leading, trailing and doubled spaces are all gone, and the words are separated by single spaces. This is O(n) time and O(n) extra space: the pieces and the new string. For everyday code, this is the right answer.

If you solved [Reverse the word order](/dsa/practice/reverse-word-order) in M08 this way, you've already done it. The rest of the lesson does it again without the extra space.

## In place: reverse everything, then each word

Here's the trick. Reverse the **whole** character array: the words come out in the right order, but each one is spelled backwards. Then reverse each word on its own to fix the spelling.

| Step | Characters |
| --- | --- |
| start | `the sky is blue` |
| reverse everything | `eulb si yks eht` |
| reverse each word | `blue is sky the` |

You need one helper: reverse the stretch between two indexes, with two pointers and `swapAt`.

```swift run
func reverse(_ chars: inout [Character], from start: Int, to end: Int) {
    var left = start
    var right = end
    while left < right {
        chars.swapAt(left, right)
        left += 1
        right -= 1
    }
}

var chars = Array("the sky is blue")
reverse(&chars, from: 0, to: chars.count - 1)
print(String(chars))

var start = 0
for index in 0...chars.count {
    if index == chars.count || chars[index] == " " {
        reverse(&chars, from: start, to: index - 1)     // one word: start...index - 1
        start = index + 1
    }
}
print(String(chars))
```

```output
eulb si yks eht
blue is sky the
```

What to notice:

- `inout` lets the helper change the caller's array, as in [inout, swap and swapAt](/dsa/learn/swift-inout-swap), and `&chars` passes it.
- The loop runs one past the end, to `chars.count`, so the last word is reversed too. `index == chars.count ||` comes first, so `chars[index]` is never read out of range.
- Each character is swapped at most twice, once in each pass: **O(n)** time and **O(1)** extra space beyond the array itself.

## Squeezing the spaces in place

With messy spacing, first tidy the array so there's exactly one space between words and none at the ends. That's the **read/write pointer** pattern from [Read/write pointers](/dsa/learn/tp-read-write): `read` scans every character, and `write` marks where the next kept character goes. Then reverse as before.

```swift run
func reverse(_ chars: inout [Character], from start: Int, to end: Int) {
    var left = start
    var right = end
    while left < right {
        chars.swapAt(left, right)
        left += 1
        right -= 1
    }
}

func reverseWords(_ text: String) -> String {
    var chars = Array(text)

    // 1. Squeeze: one space between words, none at the ends
    var write = 0
    var read = 0
    while read < chars.count {
        if chars[read] == " " {
            read += 1
            continue
        }
        if write > 0 {
            chars[write] = " "              // separator before every word but the first
            write += 1
        }
        while read < chars.count && chars[read] != " " {
            chars[write] = chars[read]
            write += 1
            read += 1
        }
    }
    chars.removeLast(chars.count - write)

    // 2. Reverse everything, then 3. reverse each word
    reverse(&chars, from: 0, to: chars.count - 1)
    var start = 0
    for index in 0...chars.count where index == chars.count || chars[index] == " " {
        reverse(&chars, from: start, to: index - 1)
        start = index + 1
    }
    return String(chars)
}

print("[" + reverseWords("  the sky   is blue ") + "]")
print("[" + reverseWords("one") + "]")
print("[" + reverseWords("   ") + "]")
```

```output
[blue is sky the]
[one]
[]
```

The brackets make the spaces visible. Writing never overtakes reading: a separator is only written after `read` has skipped at least one space, so nothing unread is overwritten. `removeLast` then trims the leftover characters past `write`.

## A variation: reverse each word, keep the order

Sometimes the task is the opposite: keep the words where they are but spell each one backwards. That's only the second pass. With `split`, keep the empty pieces so that the original spacing survives:

```swift run
func reverseEachWord(_ text: String) -> String {
    text.split(separator: " ", omittingEmptySubsequences: false)
        .map { String($0.reversed()) }
        .joined(separator: " ")
}

print(reverseEachWord("Swift is fun"))
print("[" + reverseEachWord("two  spaces") + "]")
```

```output
tfiwS si nuf
[owt  secaps]
```

`$0.reversed()` is a lazy, reversed view of the word, and `String(...)` turns it into a real string.

## The same trick rotates

Reversing parts and then the whole moves blocks of an array around in place. To rotate `"abcdefg"` left by 2, reverse the first 2 characters, reverse the rest, then reverse everything:

```swift run
func reverse(_ chars: inout [Character], from start: Int, to end: Int) {
    var left = start
    var right = end
    while left < right {
        chars.swapAt(left, right)
        left += 1
        right -= 1
    }
}

var letters = Array("abcdefg")
reverse(&letters, from: 0, to: 1)                    // "ba" + "cdefg"
reverse(&letters, from: 2, to: letters.count - 1)    // "ba" + "gfedc"
reverse(&letters, from: 0, to: letters.count - 1)    // "cdefg" + "ab"
print(String(letters))
```

```output
cdefgab
```

Reversing the words of a sentence is the same idea with many blocks instead of two.

## Which version to use

| Approach | Time | Extra space | Spacing |
| --- | --- | --- | --- |
| `split`, `reversed`, `joined` | O(n) | O(n) | normalised automatically |
| reverse all, then each word | O(n) | O(1) | needs a squeeze pass first if messy |

In app code, use the first: it's short and clearly right. Reach for the in-place version when an interviewer asks for O(1) extra space, or when you're already working on a character buffer.

<Callout kind="gotcha" title="Swift gotchas">
- **`reversed()` is lazy.** On an array or string it returns a reversed *view*, not a new array. Wrap it, `Array(x.reversed())` or `String(x.reversed())`, when you need a real one.
- **`components(separatedBy: " ")` keeps empty pieces.** `"a  b"` gives `["a", "", "b"]`, so joining puts the double space back. Foundation's method behaves like `split` with `omittingEmptySubsequences: false`.
- **No in-place editing through `String` itself.** A Swift `String` has no integer subscripts, so in-place algorithms work on `Array(text)` and convert back with `String(chars)` at the end.
- **Bytes and Unicode.** Reversing `Array(text.utf8)` breaks multi-byte characters, as M08 showed. Reverse `[Character]` unless the input is guaranteed ASCII.
</Callout>
