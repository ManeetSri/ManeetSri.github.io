## Why it matters

Type `inte` into a search box and the suggestions are "interview", "internet" and "interval". The text field can safely fill in `inter`, because every suggestion starts with it. That's the **longest common prefix**, and shells use the same idea for tab completion of file names. It's a small problem, but it shows how the order you scan in decides how early you can stop, and it's the seed of the trie, a tree of prefixes you'll build in Part V.

## Vertical scan: one column at a time

Line the words up and read **down** the columns. Column 0 holds every word's first character, column 1 every second character, and so on. The prefix grows while a column is all the same character, and stops at the first column where some word differs or has run out.

| column | 0 | 1 | 2 | 3 | 4 | 5 |
| --- | --- | --- | --- | --- | --- | --- |
| interview | i | n | t | e | r | v |
| internet | i | n | t | e | r | n |
| interval | i | n | t | e | r | v |

Column 5 disagrees, so the answer is the first five characters: `inter`.

Use the first word as the reference, and convert every word to an array once, so `chars[column]` is O(1):

```swift run
func longestCommonPrefix(_ words: [String]) -> String {
    guard let first = words.first else { return "" }
    let reference = Array(first)
    let others = words.dropFirst().map { Array($0) }
    for column in 0..<reference.count {
        for chars in others where column == chars.count || chars[column] != reference[column] {
            return String(reference[0..<column])
        }
    }
    return first
}

print(longestCommonPrefix(["interview", "internet", "interval", "internal"]))
print(longestCommonPrefix(["swift", "swiftui", "swiftly"]))
print(longestCommonPrefix(["apple", "banana"]).isEmpty)
print(longestCommonPrefix([]).isEmpty)
```

```output
inter
swift
true
true
```

What to notice:

- `column == chars.count` is tested first. `||` stops as soon as its left side is true, so a shorter word is never read past its end.
- If the loop finishes, every column of the first word matched, so the first word itself is the answer.
- The prefix can never be longer than the shortest word: the column loop stops as soon as any word runs out.

## Horizontal scan: shrink a candidate

The other natural order reads **across**: start with the whole first word as the candidate, and cut it down against each other word in turn.

```swift run
func longestCommonPrefixHorizontal(_ words: [String]) -> String {
    guard let first = words.first else { return "" }
    var prefix = Array(first)
    for word in words.dropFirst() {
        let chars = Array(word)
        var length = 0
        while length < min(prefix.count, chars.count) && prefix[length] == chars[length] {
            length += 1
        }
        prefix.removeLast(prefix.count - length)
        if prefix.isEmpty {
            break
        }
    }
    return String(prefix)
}

print(longestCommonPrefixHorizontal(["interview", "internet", "interval", "internal"]))
print(longestCommonPrefixHorizontal(["abc", "ab", "abcd"]))
```

```output
inter
ab
```

Both scans are O(S), where S is the total number of characters, in the worst case, when all the words are identical. Neither needs more than the arrays.

## Which one stops sooner

The difference shows when the answer is **short** but the words are **long**. Vertical scanning stops at the first bad column, having compared only a few characters of each word. Horizontal scanning may compare the long words in full before a later word cuts the prefix down to nothing:

```swift run
func verticalComparisons(_ words: [[Character]]) -> Int {
    var count = 0
    for column in 0..<words[0].count {
        for chars in words.dropFirst() {
            count += 1
            if column == chars.count || chars[column] != words[0][column] {
                return count
            }
        }
    }
    return count
}

func horizontalComparisons(_ words: [[Character]]) -> Int {
    var count = 0
    var prefixLength = words[0].count
    for chars in words.dropFirst() {
        var length = 0
        while length < min(prefixLength, chars.count) {
            count += 1
            if chars[length] != words[0][length] {
                break
            }
            length += 1
        }
        prefixLength = length
    }
    return count
}

let long = [Character](repeating: "a", count: 1_000)
let words = [long, long, long, Array("b")]
print(verticalComparisons(words), horizontalComparisons(words))
```

```output
3 2001
```

The vertical scan looks at one column and is done. The horizontal scan compares two thousand characters before the `"b"` reveals that the answer is empty. Vertical scanning never does more than (answer length + 1) × (number of words) comparisons.

## A neat trick: sort first

After sorting the words alphabetically, the common prefix of **all** of them is the common prefix of the **first and last** alone. Any character where those two agree, everything between them agrees on too, because sorting groups words by their starting characters.

```swift run
let words = ["interval", "internet", "interview", "internal"]
let sorted = words.sorted()
print(sorted.first!, sorted.last!)
```

```output
internal interview
```

`internal` and `interview` share `inter`, which is the answer for all four. It's elegant, but sorting costs O(n log n) comparisons, each of which can read many characters, so it's slower than a vertical scan. Know it as a fact, not as the solution.

## Built-in helpers

For two strings, Foundation has one already, and the standard library can check a prefix you already know:

```swift run
import Foundation

print("interview".commonPrefix(with: "internet"))
print("swiftly".hasPrefix("swift"))
print([1, 2, 3, 4].starts(with: [1, 2]))
```

```output
inter
true
true
```

`starts(with:)` works on any sequence, not only strings.

<Callout kind="gotcha" title="Swift gotcha: bytes can split a character">
A byte-by-byte prefix is fine for ASCII, but with accented letters it can stop halfway through a character:

```swift run
let a = Array("café".utf8)
let b = Array("cafè".utf8)
var length = 0
while length < min(a.count, b.count) && a[length] == b[length] {
    length += 1
}
print(length)
print(String(decoding: a[0..<length], as: UTF8.self))
```

```output
4
caf�
```

`é` and `è` are two bytes each and share their first byte, so the byte prefix keeps half of a character, which shows up as the replacement symbol. Comparing `Array(word)` characters gives `"caf"`, the right answer. Use bytes only when the input is promised to be ASCII.
</Callout>
