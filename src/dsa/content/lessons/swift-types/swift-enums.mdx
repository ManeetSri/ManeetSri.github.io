## Why it matters

Many values come from a fixed menu of options: a direction is north, east, south or west; a traffic light is red, amber or green. An **enum** (short for enumeration) lists those options as a type, so a typo or a missing case becomes a compile error instead of a bug. Enums can also carry data with each case. You've used one all along: `Optional` is an enum.

## Defining an enum and switching on it

```swift run
enum Direction {
    case north
    case east
    case south
    case west
}

let heading = Direction.east
var next: Direction = .south
next = .west

switch heading {
case .north, .south:
    print("Moving vertically")
case .east, .west:
    print("Moving horizontally")
}
print(next)
```

```output
Moving horizontally
west
```

What to notice:

- Each `case` is one possible value. You can also list them on one line: `case north, east, south, west`.
- Once Swift knows a value's type is `Direction`, you can write the short form `.west`.
- The `switch` has no `default`. Swift knows every case is covered, so the switch is **exhaustive**. Add a fifth direction later and every switch that forgot it stops compiling, pointing you to each place to update. Avoid `default` on your own enums so you keep that safety net.

## Methods and computed properties

Enums can have methods and computed properties, just like structs. Inside them, `self` is the current case:

```swift run
enum Direction {
    case north, east, south, west

    var turnedRight: Direction {
        switch self {
        case .north: return .east
        case .east: return .south
        case .south: return .west
        case .west: return .north
        }
    }

    var step: (row: Int, column: Int) {
        switch self {
        case .north: return (-1, 0)
        case .east: return (0, 1)
        case .south: return (1, 0)
        case .west: return (0, -1)
        }
    }

    mutating func turnRight() {
        self = turnedRight
    }
}

var facing = Direction.north
var row = 2
var column = 2
for _ in 0..<4 {
    row += facing.step.row
    column += facing.step.column
    facing.turnRight()
}
print("Ended at (\(row), \(column)) facing \(facing)")
```

```output
Ended at (2, 2) facing north
```

The robot steps north, east, south and west, turning right after each step, and ends back where it started, facing north again. Grid problems in DSA do exactly this: a `step` per direction makes moving around a 2D array tidy and hard to get wrong. A `mutating` method on an enum changes `self` to a different case.

## Raw values

Sometimes each case needs a fixed underlying value, such as a number for storage or a string for display. Give the enum a **raw value type** after a colon:

```swift run
enum Planet: Int {
    case mercury = 1, venus, earth, mars
}

enum Suit: String {
    case hearts, spades
    case diamonds = "♦"
}

print(Planet.earth.rawValue)
print(Suit.hearts.rawValue)
print(Suit.diamonds.rawValue)
```

```output
3
hearts
♦
```

- With `Int` raw values, each case counts up from the previous one: `mercury` is 1, so `venus` is 2 and `earth` is 3. Without `= 1`, counting starts at 0.
- With `String` raw values, a case's raw value is its own name unless you give another.

Going the other way, from a raw value to a case, uses `init?(rawValue:)`. It's failable, because not every number is a planet:

```swift run
enum Planet: Int {
    case mercury = 1, venus, earth, mars
}

if let planet = Planet(rawValue: 4) {
    print("Found", planet)
}
print(Planet(rawValue: 9) == nil)
```

```output
Found mars
true
```

## CaseIterable: every case in a list

Add `CaseIterable` after the colon and Swift creates `allCases`, an array of every case in declaration order:

```swift run
enum Coin: Int, CaseIterable {
    case penny = 1, nickel = 5, dime = 10, quarter = 25
}

print(Coin.allCases.count)
for coin in Coin.allCases {
    print(coin, coin.rawValue)
}
let total = Coin.allCases.reduce(0) { $0 + $1.rawValue }
print("One of each:", total)
```

```output
4
penny 1
nickel 5
dime 10
quarter 25
One of each: 41
```

`allCases` is handy whenever you need to try every option, such as the four directions from a grid cell.

## Associated values

So far, each case is a bare label. **Associated values** let each case carry its own data, and different cases can carry different kinds:

```swift run
enum Shape {
    case circle(radius: Double)
    case rectangle(width: Double, height: Double)
    case square(side: Double)

    var area: Double {
        switch self {
        case .circle(let radius):
            return 3.0 * radius * radius
        case let .rectangle(width, height):
            return width * height
        case .square(let side):
            return side * side
        }
    }
}

let shapes: [Shape] = [.circle(radius: 2), .rectangle(width: 3, height: 4), .square(side: 5)]
for shape in shapes {
    print(shape.area)
}
```

```output
12.0
12.0
25.0
```

(The circle uses 3 for π so the output stays tidy. Real code would use `Double.pi`.)

What to notice:

- `.circle(radius: 2)` creates a value of the `circle` case carrying a radius.
- In a `switch`, `case .circle(let radius)` matches the case and **binds** its data to a new constant. You met binding in [switch and pattern matching](/dsa/learn/swift-switch).
- `case let .rectangle(width, height)` puts one `let` in front to bind every value. Both spellings do the same thing.

To check for just one case, use `if case`:

```swift run
enum Shape {
    case circle(radius: Double)
    case square(side: Double)
}

let item = Shape.square(side: 3)
if case .square(let side) = item {
    print("A square with side \(side)")
}
if case .circle = item {
    print("A circle")
} else {
    print("Not a circle")
}
```

```output
A square with side 3.0
Not a circle
```

### Optional is an enum

Now you can see what `Optional` really is. Swift's standard library defines it roughly like this:

```swift
enum Optional<Wrapped> {
    case none
    case some(Wrapped)
}
```

`nil` is a shorthand for `.none`, and a present value is `.some(value)`, an associated value. The `<Wrapped>` part makes it work for any type; that's a **generic**, coming in M10. `if let` is a convenient way to switch on this enum.

## Enums or structs?

A struct says "this value has *all* of these parts": a point has an x **and** a y. An enum says "this value is *one* of these options": a shape is a circle **or** a rectangle **or** a square, each with the data that option needs.

| Use | When the value… | Example |
| --- | --- | --- |
| struct | has several parts at once | `Point(x:y:)` |
| enum | is exactly one of a fixed set of options | `Direction`, `Shape` |

<Callout kind="gotcha" title="Swift gotcha: raw values and associated values don't mix">
An enum can have raw values (`enum Planet: Int`) or associated values (`case circle(radius: Double)`), but not both. Raw values are fixed per case and known in advance; associated values are chosen each time you create a value.
</Callout>
