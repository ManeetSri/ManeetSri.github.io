## Why it matters

Everything in this module so far works on a line of numbers. Grids need the same tricks. Image processing uses a 2D prefix sum, often called a **summed-area table**, to average any rectangle of pixels in constant time, which is how fast box blurs and some classic face detectors work. Games use it to total the resources in a region of a map, and heatmaps use it to count the events in a rectangle. This lesson builds 2D prefix sums for rectangle queries and 2D difference arrays for rectangle updates. Both come down to one idea: **inclusion–exclusion**, adding regions and then subtracting the part you counted twice.

You'll need the grid basics from [2D arrays](/dsa/learn/swift-2d-arrays): `grid[row][column]`, with rows counted from the top.

## What each cell of the table holds

In 1D, `prefix[i]` was the sum of the first `i` items. In 2D:

> `prefix[r][c]` is the sum of every grid cell above row `r` and left of column `c`: rows `0..<r`, columns `0..<c`.

So `prefix` has **one extra row and one extra column**, all zeros along the top and left edge, which are the 2D version of the sentinel. For this 3 × 4 grid:

```text
grid               prefix
3  0  1  4         0  0  0  0  0
5  6  3  2         0  3  3  4  8
1  2  0  1         0  8 14 18 24
                   0  9 17 21 28
```

`prefix[2][3]` is 18: the sum of the top two rows' first three columns, `3 + 0 + 1 + 5 + 6 + 3`. The bottom-right value, 28, is the whole grid.

## Building it: add two, subtract the overlap

How do you get `prefix[r + 1][c + 1]` from values you already have? Take the grid cell `grid[r][c]`, plus the block above it, `prefix[r][c + 1]`, plus the block to its left, `prefix[r + 1][c]`. Those two blocks overlap in the top-left block, `prefix[r][c]`, which you've now added twice, so subtract it once:

> `prefix[r + 1][c + 1] = grid[r][c] + prefix[r][c + 1] + prefix[r + 1][c] − prefix[r][c]`

```text
 A  A  B          A + B   is prefix[r][c + 1]    (the block above)
 A  A  B          A + C   is prefix[r + 1][c]    (the block to the left)
 C  C  x          A       is prefix[r][c]        (counted twice, so subtract it)
                  x       is grid[r][c]
```

Filling row by row, left to right, guarantees those three values are ready when you need them:

```swift run
let grid = [
    [3, 0, 1, 4],
    [5, 6, 3, 2],
    [1, 2, 0, 1],
]
let rows = grid.count
let columns = grid[0].count
var prefix = Array(repeating: Array(repeating: 0, count: columns + 1), count: rows + 1)
for r in 0..<rows {
    for c in 0..<columns {
        prefix[r + 1][c + 1] = grid[r][c] + prefix[r][c + 1] + prefix[r + 1][c] - prefix[r][c]
    }
}
for row in prefix {
    print(row)
}
```

```output
[0, 0, 0, 0, 0]
[0, 3, 3, 4, 8]
[0, 8, 14, 18, 24]
[0, 9, 17, 21, 28]
```

Building takes O(rows × columns), one pass over the grid.

## Any rectangle with four lookups

To sum the rectangle from `(top, left)` to `(bottom, right)`, inclusive, start from the big block that ends at its bottom-right corner, then cut away what you don't want:

> sum = `prefix[bottom + 1][right + 1]` − `prefix[top][right + 1]` − `prefix[bottom + 1][left]` + `prefix[top][left]`

```text
 A  A  B  B          prefix[bottom + 1][right + 1]  = A + B + C + R
 C  C  R  R          minus prefix[top][right + 1]   = A + B   (everything above)
 C  C  R  R          minus prefix[bottom + 1][left] = A + C   (everything to the left)
                     plus prefix[top][left]         = A       (removed twice, so add it back)
                     leaves R
```

The top-left block `A` sits in both strips you subtracted, so it was taken away twice. Adding it back once leaves exactly the rectangle `R`. That's inclusion–exclusion.

```swift run
let grid = [
    [3, 0, 1, 4],
    [5, 6, 3, 2],
    [1, 2, 0, 1],
]
var prefix = Array(repeating: Array(repeating: 0, count: 5), count: 4)
for r in 0..<3 {
    for c in 0..<4 {
        prefix[r + 1][c + 1] = grid[r][c] + prefix[r][c + 1] + prefix[r + 1][c] - prefix[r][c]
    }
}

func regionSum(top: Int, left: Int, bottom: Int, right: Int) -> Int {
    prefix[bottom + 1][right + 1] - prefix[top][right + 1] - prefix[bottom + 1][left] + prefix[top][left]
}

print(regionSum(top: 1, left: 1, bottom: 2, right: 2))
print(regionSum(top: 0, left: 0, bottom: 2, right: 3))
print(regionSum(top: 0, left: 3, bottom: 1, right: 3))
```

```output
11
28
6
```

The first query is `6 + 3 + 2 + 0`, the middle 2 × 2 block. The second is the whole grid, and the third is the two cells `4` and `2` in the last column. Every query is O(1), whatever the rectangle's size, against O(rows × columns) for adding it up cell by cell.

Every `+ 1` in the formula comes from the extra row and column, exactly like the `+ 1` in `prefix[j + 1]` in [1D prefix sums](/dsa/learn/prefix-1d). The sentinel row and column mean a rectangle touching the top or left edge needs no special case.

## 2D difference arrays

The difference array from [the last lesson](/dsa/learn/prefix-difference-array) generalises the same way. To add `v` to every cell of a rectangle, mark its four corners, then run a 2D prefix sum at the end:

- `diff[top][left] += v`: the addition starts here and spreads right and down.
- `diff[top][right + 1] -= v`: stop it spreading past the right edge.
- `diff[bottom + 1][left] -= v`: stop it spreading past the bottom edge.
- `diff[bottom + 1][right + 1] += v`: that corner was cancelled twice, so add it back.

The signs are the rectangle-query formula's signs, mirrored. Give `diff` one extra row and column so `bottom + 1` and `right + 1` are always valid:

```swift run
let rows = 4
let columns = 5
var diff = Array(repeating: Array(repeating: 0, count: columns + 1), count: rows + 1)

func addToRegion(top: Int, left: Int, bottom: Int, right: Int, _ value: Int) {
    diff[top][left] += value
    diff[top][right + 1] -= value
    diff[bottom + 1][left] -= value
    diff[bottom + 1][right + 1] += value
}

addToRegion(top: 0, left: 1, bottom: 1, right: 3, 2)
addToRegion(top: 1, left: 2, bottom: 3, right: 4, 5)

// A 2D prefix sum over diff turns the corner marks into values
var grid = Array(repeating: Array(repeating: 0, count: columns), count: rows)
for r in 0..<rows {
    for c in 0..<columns {
        let above = r > 0 ? grid[r - 1][c] : 0
        let left = c > 0 ? grid[r][c - 1] : 0
        let aboveLeft = r > 0 && c > 0 ? grid[r - 1][c - 1] : 0
        grid[r][c] = diff[r][c] + above + left - aboveLeft
    }
}
for row in grid {
    print(row)
}
```

```output
[0, 2, 2, 2, 0]
[0, 2, 7, 7, 5]
[0, 0, 5, 5, 5]
[0, 0, 5, 5, 5]
```

The 2 covers rows 0 to 1 and columns 1 to 3, the 5 covers rows 1 to 3 and columns 2 to 4, and where they overlap you see 7. Each update cost four writes; the final pass is O(rows × columns). Here the prefix sum writes into a grid without a sentinel row, so it checks the edges instead. Either style works; pick one and be consistent.

## Beyond rectangles: collapsing rows

Some grid problems need more than a fixed rectangle. **Counting the submatrices that sum to a target** is the hard problem in this module, and it combines this lesson with [the dictionary pattern](/dsa/learn/prefix-hashmap):

1. Fix a top row and a bottom row.
2. Collapse the rows between them into one array: entry `c` is the sum of column `c` from top to bottom. You can grow it one row at a time as `bottom` moves down.
3. Every submatrix between those two rows is a subarray of that array, so count the subarrays with the target sum, exactly as in 1D.

There are about rows² / 2 top-and-bottom pairs, and each one costs O(columns), so the total is O(rows² × columns), much better than trying every rectangle.

<Callout kind="gotcha" title="Common mistakes">
- **Mixing grid and prefix coordinates.** `grid[r][c]` corresponds to `prefix[r + 1][c + 1]`. Name your loop variables clearly and write the offset in one place.
- **A sign wrong in the query.** Two minuses and one plus. If your answers are off by the top-left block, the plus is missing.
- **An empty grid.** `grid[0].count` crashes when there are no rows. Guard with `grid.first?.count ?? 0`.
- **Building in the wrong order.** Each cell needs the cells above and to the left, so fill rows top to bottom and each row left to right.
</Callout>
