## Why it matters

Some values naturally come in groups: a position on a grid has a row *and* a column, and a division has a quotient *and* a remainder. A **tuple** bundles a few values together without any ceremony. In DSA, you'll use tuples to return two answers from one function, such as the smallest and largest values, to store grid coordinates, and to swap two values in a single line. `typealias` then lets you give a tuple type a meaningful name.

## Grouping values into a tuple

Write the values in parentheses, separated by commas:

```swift run
let point = (3, 4)
print(point)
print(point.0)
print(point.1)
```

```output
(3, 4)
3
4
```

You reach each element by its position, starting from **0**: `point.0` is the first element and `point.1` the second. Swift infers the tuple's type as `(Int, Int)`.

The elements don't have to share a type. `(1, "one", true)` is a perfectly good tuple of type `(Int, String, Bool)`.

## Naming the elements

Positions like `.0` and `.1` are easy to mix up. You can **name** the elements instead, and then use the names:

```swift run
let screen = (width: 1920, height: 1080)
print(screen)
print(screen.width * screen.height)
let person = (name: "Ada", age: 36)
print("\(person.name) is \(person.age).")
```

```output
(width: 1920, height: 1080)
2073600
Ada is 36.
```

Named elements make code self-explanatory: `screen.width` says what it means, `screen.0` doesn't. The positions still work too, so `screen.0` is also 1920. Prefer names whenever a tuple travels more than a line or two.

You can write the type with names in an annotation, too: `let corner: (x: Int, y: Int) = (2, 3)`.

## Decomposing a tuple

You can unpack a tuple into separate constants in one step. This is called **decomposition**:

```swift run
let (quotient, remainder) = (17 / 5, 17 % 5)
print(quotient)
print(remainder)

let (_, minutesLeft) = (125 / 60, 125 % 60)
print(minutesLeft)
```

```output
3
2
5
```

The names on the left match the elements on the right, in order. An underscore, `_`, means "I don't need this one", so the second example keeps only the remainder.

## Changing a tuple

A `var` tuple can have its elements changed, one at a time or all at once:

```swift run
var position = (row: 0, col: 0)
position.row += 2
position.col = position.col + 3
print(position)
```

```output
(row: 2, col: 3)
```

The *shape* of the tuple can't change, though. You can't add a third element to a pair, and each element keeps its type.

### Swapping in one line

Assigning a tuple to a tuple gives Swift's neatest trick: swapping two variables without a temporary third one:

```swift run
var first = 1
var second = 2
(first, second) = (second, first)
print(first, second)
```

```output
2 1
```

The right side is built first, from the current values `(2, 1)`, and then unpacked into `first` and `second`. Swapping is at the heart of many sorting algorithms. For swapping two elements *inside* an array, you'll use `swapAt`, coming in M05.

### Moving around a grid

Grid problems, such as finding a path through a maze, describe each square by its row and column, and each move by how much it changes them. Tuples fit this perfectly:

```swift run
let position = (row: 2, col: 3)
let up = (row: -1, col: 0)
let next = (row: position.row + up.row, col: position.col + up.col)
print(next)
```

```output
(row: 1, col: 3)
```

Moving up a row decreases the row number by 1 and leaves the column alone. In the grid and graph modules later in the course, you'll keep a list of the four possible moves, up, down, left and right, as tuples like this, and try each one from every square.

## Comparing tuples

Tuples can be compared with `==` and `!=`, and with `<` and `>` too, as long as every element can be compared. Comparison goes element by element, from the left, and stops at the first difference, just like alphabetical order compares words letter by letter:

```swift run
print((1, 2) == (1, 2))
print((1, "zebra") < (2, "apple"))
print((3, "b") > (3, "a"))
print((2, 1) < (1, 9))
```

```output
true
true
true
false
```

`(1, "zebra") < (2, "apple")` is true because 1 is less than 2, so the second elements are never looked at. In `(3, "b") > (3, "a")` the first elements tie, so the second elements decide. This makes tuples handy for sorting by more than one thing, for example by score and then by name. Swift supports these comparisons for tuples of up to six elements.

## Several results from one calculation

Tuples are how Swift returns several values at once. The standard library does it too: `quotientAndRemainder(dividingBy:)` gives both results of a division as a named tuple:

```swift run
let result = 17.quotientAndRemainder(dividingBy: 5)
print(result)
print(result.quotient, result.remainder)
```

```output
(quotient: 3, remainder: 2)
3 2
```

You'll write your own functions in M05, and returning a tuple will be one of the first things you do. Here's a preview, to show the shape:

```swift run
func smallerAndLarger(_ x: Int, _ y: Int) -> (smaller: Int, larger: Int) {
    return x < y ? (x, y) : (y, x)
}

let pair = smallerAndLarger(9, 4)
print(pair.smaller, pair.larger)
```

```output
4 9
```

The part after `->` is the return type: a tuple with two named `Int` elements. The time-splitting problem below has a signature just like it.

## typealias: a new name for a type

`typealias` gives an existing type another name. It doesn't create a new type; it's a label that makes code easier to read:

```swift run
typealias GridPosition = (row: Int, col: Int)
let start: GridPosition = (row: 0, col: 0)
let goal: GridPosition = (row: 4, col: 7)
print(goal.row - start.row, goal.col - start.col)

typealias Score = Int
let myScore: Score = 10
let bonus: Int = 5
print(myScore + bonus)
```

```output
4 7
15
```

`GridPosition` reads much better than `(row: Int, col: Int)` repeated throughout a grid algorithm. And because `Score` is only another name for `Int`, adding a `Score` to an `Int` works with no conversion. Type names start with a capital letter, so a typealias does too.

<Callout kind="gotcha" title="Swift gotcha: when a tuple is the wrong tool">
Tuples are for small, short-lived groups: two or three values passed around briefly. If you find yourself with five elements, or wanting to add behaviour such as a `distance(to:)` method, you want a **struct**, which you'll learn in M09. A struct also gives the type a real name that error messages and documentation can use.
</Callout>
