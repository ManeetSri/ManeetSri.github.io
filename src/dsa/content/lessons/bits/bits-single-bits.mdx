## Why it matters

A single integer can hold dozens of yes-or-no facts, one per bit: which permissions a file has, which options a view uses, which items are in a set. Working with those facts comes down to four moves on bit `k`: check it, set it, clear it, toggle it. Learn the four one-liners here and you'll recognise them everywhere, from Swift's `OptionSet` to the solutions of interview problems.

## The mask for bit k

Every move starts with the same mask: `1 << k`, a number with only bit `k` set. For `k = 3`, that's `00001000`. Combine the mask with one of the operators from the last lesson, and you touch bit `k` and nothing else.

| Goal | Expression | Why it works |
| --- | --- | --- |
| Check bit k | `x & (1 << k) != 0` | AND keeps only bit k; the result is non-zero exactly when that bit was 1 |
| Set bit k | `x \| (1 << k)` | OR with 1 makes the bit 1; OR with 0 leaves the others alone |
| Clear bit k | `x & ~(1 << k)` | the flipped mask is all ones except bit k, so AND clears just that bit |
| Toggle bit k | `x ^ (1 << k)` | XOR with 1 flips the bit; XOR with 0 leaves the others alone |

Here are all four on one value:

```swift run
func binary(_ x: UInt8) -> String {
    let digits = String(x, radix: 2)
    return String(repeating: "0", count: 8 - digits.count) + digits
}

let x: UInt8 = 0b0101_0010
print(binary(x), "start")
print(x & (1 << 1) != 0, x & (1 << 3) != 0)
print(binary(x | (1 << 3)), "set bit 3")
print(binary(x & ~(1 << 4)), "clear bit 4")
print(binary(x ^ (1 << 0)), "toggle bit 0")
```

```output
01010010 start
true false
01011010 set bit 3
01000010 clear bit 4
01010011 toggle bit 0
```

Read the clear step slowly, because it combines two operators. `1 << 4` is `00010000`. `~` flips it to `11101111`. ANDing `x` with that keeps every bit of `x` except bit 4, which becomes 0.

Another way to check a bit is to shift it down to position 0 and look at it: `(x >> k) & 1` is 1 if bit `k` is set and 0 if not. Both forms are common, so learn to read both.

<Callout kind="tip" title="Setting and clearing are safe to repeat">
Setting a bit that's already set changes nothing, and so does clearing one that's already clear. Toggling is the odd one out: do it twice and you're back where you started. Choose set or clear when you know which value you want, and toggle only when you really mean "the opposite of whatever it is now".
</Callout>

## Several bits at once

A mask can hold more than one bit. With `mask = 0b0110`, which covers bits 1 and 2:

- `x & mask == mask`: are **all** the mask's bits set?
- `x & mask != 0`: is **any** of them set?
- `x | mask`, `x & ~mask` and `x ^ mask` set, clear or toggle all of them together.

```swift run
let wanted = 0b0110
print(0b1110 & wanted == wanted)
print(0b1010 & wanted == wanted)
print(0b1010 & wanted != 0)
```

```output
true
false
true
```

`0b1010` has bit 1 but not bit 2, so it passes the "any" test and fails the "all" test.

## Pulling out a group of bits

Colours are often stored as one number, `0xRRGGBB`: 8 bits each of red, green and blue, which is why a hex colour in a design tool looks like `#FF8800`. To pull out one channel, shift it down to the bottom, then AND with `0xFF` to keep just 8 bits:

```swift run
let colour = 0xFF8800
let red = (colour >> 16) & 0xFF
let green = (colour >> 8) & 0xFF
let blue = colour & 0xFF
print(red, green, blue)

let rebuilt = (red << 16) | (green << 8) | blue
print(rebuilt == colour)
```

```output
255 136 0
true
```

Going the other way, shift each part up into place and OR them together. That's exactly what code that turns a hex string into a `UIColor` does. In general, `(x >> start) & ((1 << width) - 1)` extracts `width` bits starting at bit `start`: `(1 << width) - 1` is a run of `width` ones, such as `11111111` for 8.

## Flags, the Swift way

Unix file permissions are a classic use of bit flags: read is worth 4, write 2 and execute 1, so 6 means "read and write", and 7 means all three. You could juggle those numbers by hand, but Swift has a type made for the job, **`OptionSet`**. It stores the bits in a `rawValue` and gives you set-like methods:

```swift run
struct Permissions: OptionSet {
    let rawValue: Int
    static let read = Permissions(rawValue: 1 << 2)
    static let write = Permissions(rawValue: 1 << 1)
    static let execute = Permissions(rawValue: 1 << 0)
}

var file: Permissions = [.read, .write]
print(file.rawValue)
print(file.contains(.write), file.contains(.execute))

file.insert(.execute)
file.remove(.write)
print(file.rawValue)
```

```output
6
true false
5
```

Under the hood, `insert` is OR, `remove` is AND with the flipped mask, and `contains` is the AND check. This is how UIKit defines options like `UIView.AutoresizingMask`. In app code, prefer an `OptionSet` to raw bits: you get names and type checking for free. In algorithm code, raw `Int` masks are lighter and just as clear once you know the four moves.

## Odd or even, with a bit

Bit 0 is the only bit worth an odd amount, so `x & 1` is 1 for odd numbers and 0 for even ones. Unlike `x % 2`, it works the same way for negative numbers:

```swift run
print(-3 & 1)
print(-3 % 2)
```

```output
1
-1
```

That's two's complement at work: -3 is `...11111101`, and its bit 0 is 1.

<Callout kind="gotcha" title="Swift gotcha: the mask's type">
`1 << k` takes its type from the other side of the expression. With `x` a `UInt8`, the mask is a `UInt8` too, and `k` must be 0 to 7: `UInt8(1) << 8` is 0, so a check against it is always false, silently. With an `Int`, bits 0 to 63 are available. If a bit test mysteriously never fires, check the width.
</Callout>

## Practice

Byte mirror asks you to reverse the order of the bits in a byte. It's all checking one bit and setting another, eight times over.

```cards

  back: "Check: `x & (1 << k) != 0`. Set: `x | (1 << k)`. Clear: `x & ~(1 << k)`. Toggle: `x ^ (1 << k)`."
- id: clear-mask
  front: "Why does `x & ~(1 << k)` clear bit k?"
  back: "`~(1 << k)` is all ones except bit k, so ANDing keeps every other bit and forces bit k to 0."
- id: extract-bits
  front: "How do you pull the green channel out of a colour stored as 0xRRGGBB?"
  back: "`(colour >> 8) & 0xFF`: shift the channel down to the bottom, then keep its 8 bits."
- id: optionset-bits
  front: "What does Swift's OptionSet do with bits?"
  back: "It stores flags as bits in a `rawValue`: `insert` sets bits, `remove` clears them and `contains` checks them."
```
