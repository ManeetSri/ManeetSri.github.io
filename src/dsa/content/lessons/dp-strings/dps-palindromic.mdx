## Why it matters

In [Palindromes and expand-around-centre](/dsa/learn/str-palindromes) you found the longest palindromic **substring** by growing outwards from every centre. Allow skipping characters, and the question becomes the longest palindromic **subsequence**, which expansion can't answer. Its twin, "the fewest characters to insert to make a palindrome", is a classic interview problem, and RNA-folding algorithms in biology are built on the same kind of table. This lesson solves it two ways: by reducing it to LCS, and with your first **interval DP**, a table over ranges `i...j` of one string.

## Subsequence, not substring

For `"character"`:

| Question | Answer |
| --- | --- |
| Longest palindromic substring | 3: `"ara"` |
| Longest palindromic subsequence (LPS) | 5: `"carac"` |

`"carac"` uses positions 0, 2, 3, 4 and 5 of `"character"`, skipping the h. A subsequence may skip characters, so it can be much longer than any palindromic substring.

## Way one: LCS with the reverse

A palindrome reads the same backwards. So a palindromic subsequence of s is also a subsequence of `reversed(s)`, which makes it a **common** subsequence of the two, and the LPS can't be longer than `LCS(s, reversed(s))`. The other direction, that some palindrome always reaches that full length, needs a cleverer argument, but it holds: the two lengths are always equal. So the table from [the LCS lesson](/dsa/learn/dps-lcs) answers the question:

```swift run
func lcsLength(_ a: [Character], _ b: [Character]) -> Int {
    var table = Array(repeating: Array(repeating: 0, count: b.count + 1), count: a.count + 1)
    for i in 0...a.count {
        for j in 0...b.count {
            if i == 0 || j == 0 {
                table[i][j] = 0
            } else if a[i - 1] == b[j - 1] {
                table[i][j] = table[i - 1][j - 1] + 1
            } else {
                table[i][j] = max(table[i - 1][j], table[i][j - 1])
            }
        }
    }
    return table[a.count][b.count]
}

for word in ["character", "banana", "racecar", "abcd"] {
    let s = Array(word)
    print(word, lcsLength(s, s.reversed()))
}
```

```output
character 5
banana 5
racecar 7
abcd 1
```

The reduction is quick to write once you have LCS. Two words of caution, though.

- **Lengths, yes; strings, careful.** Not every LCS of s and its reverse is itself a palindrome. For `"abcab"`, the LCS with `"bacba"` has length 3, and `"acb"` is one of them, but `"acb"` isn't a palindrome. The length is always right; if you need the palindrome itself, the next method builds one directly.
- **It hides the structure.** The direct DP below works on ranges of a single string, a pattern you'll need for palindrome partitioning and many other problems.

## Way two: the interval DP

Think about the outermost characters of a range, as expand-around-centre does, but from the outside in.

- **State.** `P(i, j)` = the length of the longest palindromic subsequence inside `s[i...j]`.
- **Transition.** Compare the two ends:
  - if `s[i] == s[j]`, they can wrap whatever is best inside: `P(i, j) = P(i + 1, j - 1) + 2`;
  - otherwise they can't both be used, so drop one end or the other: `P(i, j) = max(P(i + 1, j), P(i, j - 1))`.
- **Base cases.** A single character is a palindrome: `P(i, i) = 1`. An empty range (i greater than j) is 0. That covers two equal neighbours, `P(i, i + 1) = P(i + 1, i) + 2 = 2`.
- **Order.** `P(i, j)` reads row `i + 1`, so rows must be filled from the **bottom up**: i from n − 1 down to 0, and j from left to right within a row. (Filling by range length, shortest first, works too.)
- **Answer.** `P(0, n - 1)`, the whole string.

```swift run
/// best[i][j]: the longest palindromic subsequence inside s[i...j]
func palindromeTable(_ s: [Character]) -> [[Int]] {
    let n = s.count
    var best = Array(repeating: Array(repeating: 0, count: n), count: n)
    for i in stride(from: n - 1, through: 0, by: -1) {     // i downwards: rows below are ready
        best[i][i] = 1                                       // one letter is a palindrome
        for j in stride(from: i + 1, to: n, by: 1) {
            if s[i] == s[j] {
                best[i][j] = best[i + 1][j - 1] + 2          // wrap the inside in the matching pair
            } else {
                best[i][j] = max(best[i + 1][j], best[i][j - 1])   // drop one end or the other
            }
        }
    }
    return best
}

for word in ["character", "banana", "racecar", "abcd", "a"] {
    let s = Array(word)
    print(word, palindromeTable(s)[0][s.count - 1])
}
let s = Array("banana")
let t = palindromeTable(s)
print("  " + s.map(String.init).joined(separator: " "))
for i in 0..<s.count {
    let cells = (0..<s.count).map { $0 < i ? "." : String(t[i][$0]) }
    print(String(s[i]) + " " + cells.joined(separator: " "))
}
```

```output
character 5
banana 5
racecar 7
abcd 1
a 1
  b a n a n a
b 1 1 1 3 3 5
a . 1 1 3 3 5
n . . 1 1 3 3
a . . . 1 1 3
n . . . . 1 1
a . . . . . 1
```

What to notice:

- Only the upper triangle is used: a range needs `i ≤ j`. The dots are empty ranges, left at 0.
- When j is `i + 1`, the code reads `best[i + 1][i]`, a cell below the diagonal. It's 0, standing for the empty inside, so two equal neighbours correctly get 2.
- The top-right cell is the answer, 5 for `"anana"`. Row 0 says "starting at b", and the b never helps.

It's O(n²) time and O(n²) memory, the same as the LCS route, and a little faster in practice because it fills only half a table. You'll meet many more interval DPs in M56, starting with [Matrix chain multiplication](/dsa/learn/dpi-matrix-chain); [Palindrome partitioning: minimum cuts](/dsa/learn/dpi-palindrome-cuts) uses a palindrome table like this one.

## Fewest insertions to make a palindrome

Now the interview question: what's the fewest characters you must insert, anywhere, to turn s into a palindrome?

The answer is **n − LPS**.

- **That many is enough.** Keep the letters of a longest palindromic subsequence as the skeleton. Every other letter gets a partner inserted in the mirror position. That's n − LPS insertions.
- **You can't do better.** In the finished palindrome, pair each original letter with its mirror image. Original letters paired with each other (or sitting in the centre) form a palindromic subsequence of s, so there are at most LPS of them. Every other original letter is paired with an inserted one, so at least n − LPS insertions were needed.

The same reasoning shows that the fewest **deletions** to leave a palindrome is also n − LPS: delete everything outside the skeleton.

To build the palindrome itself, walk the table from the outside in. Matching ends are kept as a pair. Otherwise the end you "drop" in the DP is the one that needs a partner, so write it on both sides:

```swift run
func palindromeTable(_ s: [Character]) -> [[Int]] {
    let n = s.count
    var best = Array(repeating: Array(repeating: 0, count: n), count: n)
    for i in stride(from: n - 1, through: 0, by: -1) {
        best[i][i] = 1
        for j in stride(from: i + 1, to: n, by: 1) {
            if s[i] == s[j] {
                best[i][j] = best[i + 1][j - 1] + 2
            } else {
                best[i][j] = max(best[i + 1][j], best[i][j - 1])
            }
        }
    }
    return best
}

/// Builds a shortest palindrome that contains `word` as a subsequence, from the outside in
func shortestPalindrome(containing word: String) -> String {
    let s = Array(word)
    if s.isEmpty { return "" }
    let best = palindromeTable(s)
    var left: [Character] = []                 // the outer letters, left half
    var middle: [Character] = []
    var i = 0, j = s.count - 1
    while i <= j {
        if i == j {
            middle = [s[i]]                    // a single centre letter
            break
        }
        if s[i] == s[j] {
            left.append(s[i])                  // a matched pair: both ends already agree
            i += 1
            j -= 1
        } else if best[i + 1][j] >= best[i][j - 1] {
            left.append(s[i])                  // s[i] gets a partner inserted on the right
            i += 1
        } else {
            left.append(s[j])                  // s[j] gets a partner inserted on the left
            j -= 1
        }
    }
    return String(left + middle + left.reversed())
}

for word in ["race", "abca", "banana", "swift", "noon"] {
    let s = Array(word)
    let insertions = s.count - palindromeTable(s)[0][s.count - 1]
    print(word, insertions, shortestPalindrome(containing: word))
}
```

```output
race 3 racecar
abca 1 abcba
banana 1 bananab
swift 4 swiftfiws
noon 0 noon
```

Each result is the original word with exactly n − LPS letters added: `"race"` gains e, c, a to become `"racecar"`, and `"banana"` gains one b. As before, ties mean other answers are equally short: `"abca"` could also become `"acbca"`.

<Callout kind="gotcha" title="Common mistakes">
- **Substring thinking.** Expand-around-centre finds palindromic substrings. For subsequences you need the DP.
- **Filling rows top-down.** `P(i, j)` reads row `i + 1`. With i going upwards, that row is still all zeros, and every answer comes out too small. Loop i downwards, or by range length.
- **Calling `palindromeTable` on an empty string.** The answer cell `[0][n - 1]` doesn't exist when n is 0. Return 0 first.
- **Printing an LCS of s and its reverse as "the palindrome".** The length is right, but that string isn't guaranteed to be a palindrome. Build it from the interval table.
- **`for j in i + 1..<n` when i is the last index.** That's `n..<n`, which is empty and fine; but `(i + 1)...(n - 1)` would crash. `stride(from: i + 1, to: n, by: 1)` is safe either way.
</Callout>
