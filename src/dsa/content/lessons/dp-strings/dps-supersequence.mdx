## Why it matters

Two teammates each wrote an ordered checklist, and you want one combined list that contains both, in each person's order, with nothing repeated that doesn't have to be. Two edit histories need merging into one timeline. A DNA assembler needs the shortest strand containing two fragments' sequences in order. All of them ask for the **shortest common supersequence** (SCS). It's a favourite interview follow-up to LCS, because the whole solution is the table from [Longest common subsequence, and printing it](/dsa/learn/dps-lcs), read a different way.

## Supersequences and their length

A **supersequence** of a string contains it as a subsequence: `"swift"` is inside `"shwift"`, if you skip the h. A **common** supersequence contains two strings. Gluing them together always works, `"abac" + "cab" = "abaccab"`, but it wastes characters both strings could share.

How short can it be? Every character of a and every character of b must appear. A character of the supersequence can serve both strings at once only if the shared characters are in the same order in both, which makes them a common subsequence. So the most you can share is an LCS, and:

**SCS length = n + m − LCS length**

For `"abac"` and `"cab"`, the LCS is `"ab"`, length 2, so the SCS has 4 + 3 − 2 = 5 characters: `"cabac"`. Check it: `"cabac"` contains abac (skip the first c) and cab (its first three letters).

You can also write a DP for the length directly, with the same shape as edit distance: `S(i, 0) = i`, `S(0, j) = j`; on a match `S(i - 1, j - 1) + 1`, otherwise `1 + min(S(i - 1, j), S(i, j - 1))`. It gives the same numbers as the formula. The interesting part is building the string.

## Building it from the LCS table

Walk back from the corner of the LCS table, exactly as for printing the LCS, but write **every** character you pass, not only the matches:

- **Match** (`a[i - 1] == b[j - 1]`): the character is shared. Write it once and step diagonally.
- **Mismatch, the value came from above**: `a[i - 1]` isn't part of the LCS. Write it and step up.
- **Mismatch, from the left**: write `b[j - 1]` and step left.
- **One string runs out** (i or j reaches 0): write whatever is left of the other.

Then reverse, since you built it from the end.

```swift run
func lcsTable(_ a: [Character], _ b: [Character]) -> [[Int]] {
    let n = a.count, m = b.count
    var table = Array(repeating: Array(repeating: 0, count: m + 1), count: n + 1)
    for i in 0...n {
        for j in 0...m {
            if i == 0 || j == 0 {
                table[i][j] = 0
            } else if a[i - 1] == b[j - 1] {
                table[i][j] = table[i - 1][j - 1] + 1
            } else {
                table[i][j] = max(table[i - 1][j], table[i][j - 1])
            }
        }
    }
    return table
}

/// A shortest string that contains both `first` and `second` as subsequences
func shortestSupersequence(_ first: String, _ second: String) -> String {
    let a = Array(first), b = Array(second)
    let table = lcsTable(a, b)
    var result: [Character] = []
    var i = a.count, j = b.count
    while i > 0 && j > 0 {
        if a[i - 1] == b[j - 1] {
            result.append(a[i - 1])            // shared letter: write it once
            i -= 1
            j -= 1
        } else if table[i - 1][j] >= table[i][j - 1] {
            result.append(a[i - 1])            // a[i - 1] isn't shared: write it on its own
            i -= 1
        } else {
            result.append(b[j - 1])            // b[j - 1] isn't shared
            j -= 1
        }
    }
    while i > 0 {                              // whatever is left of either string
        result.append(a[i - 1])
        i -= 1
    }
    while j > 0 {
        result.append(b[j - 1])
        j -= 1
    }
    return String(result.reversed())
}

func isSubsequence(_ small: String, of big: String) -> Bool {
    var remaining = small[...]
    for character in big where character == remaining.first {
        remaining = remaining.dropFirst()
    }
    return remaining.isEmpty
}

for (first, second) in [("abac", "cab"), ("brute", "groot"), ("swift", "shift"), ("", "xyz"), ("aaa", "aaa")] {
    let merged = shortestSupersequence(first, second)
    print(first, second, merged, merged.count, isSubsequence(first, of: merged) && isSubsequence(second, of: merged))
}
```

```output
abac cab cabac 5 true
brute groot gbrooute 8 true
swift shift shwift 6 true
 xyz xyz 3 true
aaa aaa aaa 3 true
```

What to notice:

- Every step writes exactly one character. Matches move both indices, so each LCS character is written once for two; every other character is written once for itself. That's n + m − LCS characters, the shortest possible.
- The mismatch rule is the LCS traceback's rule: step towards the bigger neighbour. Stepping towards the smaller one still produces a common supersequence, but loses a shared character and comes out longer.
- The leftover loops matter. Without them, `("", "xyz")` would return `""`.
- `isSubsequence` is the two-pointer check from [Read/write pointers](/dsa/learn/tp-read-write), written with a `Substring` that shrinks as characters are found.

The cost is the LCS table, **O(n · m)** time and memory, plus an O(n + m) walk.

## Many right answers

`"brute"` and `"groot"` share `"rt"`, so the SCS has 8 characters. `"gbrooute"` is one; `"bgrooute"` and `"gbrouote"` are others. Whenever the walk meets a tie, or two unshared characters that could go in either order, a different choice gives a different but equally short string.

That changes how you check a solution, in an interview or in tests. Comparing with one expected string is wrong. Check three properties instead:

1. a is a subsequence of the answer;
2. b is a subsequence of the answer;
3. its length is n + m − LCS.

The tests for this lesson's problem do exactly that.

## SCS and edit distance side by side

The supersequence walk and the edit-script walk are close cousins. In both, a diagonal step handles a character both strings agree on, and up and left steps handle characters only one string has:

| Step | Edit script (a into b) | Supersequence |
| --- | --- | --- |
| diagonal, match | keep | write the shared character once |
| up | delete `a[i - 1]` | write `a[i - 1]` |
| left | insert `b[j - 1]` | write `b[j - 1]` |
| diagonal, mismatch | replace | not allowed: write both, as an up and a left step |

That's why SCS, LCS and "edit distance with only insert and delete" all come from the same table: the SCS length is n + m − LCS, and that edit distance is n + m − 2 × LCS.

<Callout kind="gotcha" title="Common mistakes">
- **Forgetting the leftovers.** When one index reaches 0, the rest of the other string still has to be written.
- **Writing a match twice.** A shared character goes in once; that's the whole point.
- **Forgetting to reverse.** The walk builds the string from the end.
- **Building with `String` insertions at the front.** Inserting at index 0 shifts everything, O(n) each time. Append to an array and reverse once.
- **Expecting one particular answer.** Several shortest supersequences usually exist; check properties, not equality.
</Callout>
