## Why it matters

A **dictionary** connects keys to values: a username to a profile, a product code to a price, a word to how often it appears. Apps use them constantly, for caches, settings and JSON. In DSA, the dictionary (often called a **hash map**) is probably the single most useful structure in interviews. It turns "search the whole list for this" into an instant lookup, and that one trick turns many slow O(n²) solutions into fast O(n) ones.

## What a dictionary is

A dictionary stores **key–value pairs**. Every key is unique and maps to exactly one value. Like a set, it has **no order**, and its keys must be **Hashable**, because it uses the same hashing trick to find keys quickly.

The type is written `[Key: Value]`. A dictionary from `String` names to `Int` counts is `[String: Int]`.

```swift
var stock = ["apple": 5, "pear": 2, "fig": 0]   // [String: Int]
var prices: [String: Double] = [:]              // empty: say the type
var ages = [String: Int]()                      // also empty
```

`[:]` is the empty dictionary literal, the dictionary version of `[]`.

<Callout kind="analogy">
A real dictionary maps a word to its definition. You don't read every page to find "zebra": you jump straight to it. A Swift dictionary does the same with any Hashable key, in O(1) time on average.
</Callout>

## Lookups return optionals

Subscript a dictionary with a key to look up its value. The key might not be there, so the result is always an **optional**:

```swift run
let stock = ["apple": 5, "pear": 2, "fig": 0]

if let apples = stock["apple"] {
    print("apples: \(apples)")
}

if let kiwis = stock["kiwi"] {
    print("kiwis: \(kiwis)")
} else {
    print("no kiwis listed")
}

print(stock["kiwi"] ?? 0)
```

```output
apples: 5
no kiwis listed
0
```

`stock["apple"]` has type `Int?`, not `Int`. This is the "optionals from lookups" idea from M04: you must unwrap it with `if let`, `guard let` or `??` before using it.

Notice the difference between a key that's missing and a key whose value is `0`. `stock["fig"]` is `Optional(0)`: fig is listed, with none in stock. `stock["kiwi"]` is `nil`: kiwi isn't listed at all.

### The default: subscript

When a missing key should count as some value, there's a shortcut. Add `default:` to the subscript and you get a plain, non-optional value back:

```swift run
let stock = ["apple": 5, "pear": 2]
print(stock["apple", default: 0])
print(stock["kiwi", default: 0])
```

```output
5
0
```

Reading with `default:` doesn't add the key to the dictionary. It's the same as `?? 0`, but it becomes much more powerful when you **write** with it, which is the whole of the next lesson.

## Adding, updating and removing

Assigning to a key adds the pair if the key is new, or replaces the value if it exists. Assigning `nil` removes the pair.

```swift run
var stock = ["apple": 5, "pear": 2, "fig": 0]

stock["kiwi"] = 7
stock["apple"] = 6
stock["fig"] = nil

print(stock.count)
print(stock["apple"] ?? 0, stock["kiwi"] ?? 0)
print(stock["fig"] ?? -1)
```

```output
3
6 7
-1
```

There are also methods that tell you what was there before:

```swift run
var stock = ["apple": 5, "pear": 2]

let oldPears = stock.updateValue(10, forKey: "pear")
print(oldPears ?? -1)

let oldPlums = stock.updateValue(1, forKey: "plum")
print(oldPlums ?? -1)

let removed = stock.removeValue(forKey: "apple")
print(removed ?? -1, stock.count)
```

```output
2
-1
5 2
```

- `updateValue(_:forKey:)` sets the value and returns the **old** one, or `nil` if the key was new.
- `removeValue(forKey:)` removes the pair and returns the removed value, or `nil` if there was nothing to remove.

## count, keys and values

```swift run
let stock = ["pear": 2, "apple": 5, "kiwi": 7]

print(stock.count)
print(stock.isEmpty)
print(stock.keys.sorted())
print(stock.values.sorted())
print(stock.values.reduce(0, +))
```

```output
3
false
["apple", "kiwi", "pear"]
[2, 5, 7]
14
```

`keys` and `values` are collections you can loop over, sort, or pass to `reduce`. Like the dictionary itself, they come in an unpredictable order, so sort them before printing.

## Looping over a dictionary

A `for-in` loop over a dictionary gives you each pair as a `(key, value)` tuple. But the order is unpredictable and can change between runs, so when order matters, sort first:

```swift run
let stock = ["pear": 2, "apple": 5, "kiwi": 7]

for name in stock.keys.sorted() {
    print(name, stock[name] ?? 0)
}

for (name, count) in stock.sorted(by: { $0.key < $1.key }) {
    print("\(name): \(count)")
}
```

```output
apple 5
kiwi 7
pear 2
apple: 5
kiwi: 7
pear: 2
```

`stock.sorted(by:)` returns an array of pairs, and each pair has `.key` and `.value`. You can sort by value too: `stock.sorted { $0.value > $1.value }` puts the biggest counts first. If two values tie, their order is unpredictable again, so add a tie-breaker when it matters.

<Callout kind="gotcha" title="Swift gotcha: dictionary order changes between runs">
Never `print` a whole dictionary and expect the same output twice, and never rely on the order of `keys`, `values` or a `for-in` loop. Swift randomises it per run, partly as a security measure. Sort the keys, or look up single values.
</Callout>

## Building a dictionary from two arrays

When you have keys in one array and values in another, `zip` (from M06) pairs them up, and `Dictionary(uniqueKeysWithValues:)` builds the dictionary:

```swift run
let names = ["ada", "grace", "linus"]
let years = [1815, 1906, 1969]
let born = Dictionary(uniqueKeysWithValues: zip(names, years))
print(born["grace"] ?? 0)
print(born.keys.sorted())
```

```output
1906
["ada", "grace", "linus"]
```

As the name warns, the keys must be unique. A repeated key crashes with `Fatal error: Duplicate values for key: 'ada'`.

## Values can be collections

A dictionary's values can be anything, including arrays. `[String: [String]]` maps each key to a list, which is exactly how you'll represent graphs later: each place maps to the places you can reach from it.

```swift run
var routes: [String: [String]] = [:]
routes["home", default: []].append("park")
routes["home", default: []].append("shop")
routes["park", default: []].append("home")

for place in routes.keys.sorted() {
    print(place, routes[place] ?? [])
}
```

```output
home ["park", "shop"]
park ["home"]
```

`routes["home", default: []].append(...)` means "start from an empty array if the key is missing, then append". You'll see why that works in the next lesson.

<Callout kind="gotcha" title="Swift gotcha: optional chaining can silently do nothing">
You might try to add one to a count with `stock["kiwi"]? += 1`. If `"kiwi"` is missing, optional chaining (from M04) skips the whole statement: no error, no new key, nothing. And `stock["kiwi"]! += 1` crashes on a missing key. To update a value that may not exist yet, use `stock["kiwi", default: 0] += 1`.
</Callout>
