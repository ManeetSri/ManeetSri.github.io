## Why it matters

Counting how often things appear is one of the most common steps in all of DSA. Are these two words anagrams? Count their letters. Which element appears most? Count them all. Which character is the first that never repeats? Count, then scan. Grouping is counting's sibling: put every word in a bucket by its first letter, or every order by its customer. Swift has two tools that make both a single line: the `default:` subscript and `Dictionary(grouping:by:)`.

## Counting the long way

Here's a dictionary of counts built with only what you knew before this lesson:

```swift run
let votes = ["tea", "coffee", "tea", "juice", "tea", "coffee"]
var counts: [String: Int] = [:]

for vote in votes {
    if let current = counts[vote] {
        counts[vote] = current + 1
    } else {
        counts[vote] = 1
    }
}

for drink in counts.keys.sorted() {
    print(drink, counts[drink] ?? 0)
}
```

```output
coffee 2
juice 1
tea 3
```

It works, but five lines for "add one" is a lot, and the `if let` dance hides what's going on.

## Counting with default:

The `default:` subscript from the last lesson collapses those five lines into one:

```swift run
let votes = ["tea", "coffee", "tea", "juice", "tea", "coffee"]
var counts: [String: Int] = [:]

for vote in votes {
    counts[vote, default: 0] += 1
}

for drink in counts.keys.sorted() {
    print(drink, counts[drink] ?? 0)
}
```

```output
coffee 2
juice 1
tea 3
```

Read `counts[vote, default: 0] += 1` as three steps:

1. **Read** the current count, or `0` if `vote` isn't a key yet.
2. **Add** one.
3. **Write** the result back under `vote`, creating the key if it's new.

This line is worth memorising. You'll type it hundreds of times.

### Counting characters

A `String` is a collection of `Character` values, so a `for-in` loop visits each character (M08 goes much deeper into this). Counting letters looks exactly the same:

```swift run
var letterCounts: [Character: Int] = [:]
for letter in "banana" {
    letterCounts[letter, default: 0] += 1
}

for letter in letterCounts.keys.sorted() {
    print(letter, letterCounts[letter] ?? 0)
}
```

```output
a 3
b 1
n 2
```

The keys are `Character`s, so the type is `[Character: Int]`.

### Counting with reduce(into:)

In M06 you met `reduce(into:)`, which builds up a value as it walks a collection. It's a popular one-expression way to count:

```swift run
let votes = ["tea", "coffee", "tea", "juice", "tea", "coffee"]
let counts = votes.reduce(into: [String: Int]()) { counts, vote in
    counts[vote, default: 0] += 1
}
print(counts["tea"] ?? 0, counts["coffee"] ?? 0)
```

```output
3 2
```

It does the same work as the loop. Use whichever reads more clearly to you; in an interview, the loop is never wrong.

## Using the counts

Counting is usually the first of two steps. The second step asks a question of the counts.

### The most frequent value

Sort the pairs by count, biggest first. If two values tie, their order would be unpredictable, so break ties by key to keep the answer deterministic:

```swift run
let votes = ["tea", "coffee", "tea", "juice", "tea", "coffee", "juice"]
var counts: [String: Int] = [:]
for vote in votes {
    counts[vote, default: 0] += 1
}

let ranked = counts.sorted { a, b in
    if a.value != b.value {
        return a.value > b.value
    }
    return a.key < b.key
}
for (drink, count) in ranked {
    print(drink, count)
}
```

```output
tea 3
coffee 2
juice 2
```

Coffee and juice both have 2, and the tie-breaker puts them in alphabetical order.

### The first value that appears once

Here the counts alone aren't enough, because a dictionary has no order. So make **two passes**: count everything, then walk the original array, which does have an order, and stop at the first value with a count of 1.

```swift run
func firstUnique(_ numbers: [Int]) -> Int? {
    var counts: [Int: Int] = [:]
    for number in numbers {
        counts[number, default: 0] += 1
    }
    for number in numbers where counts[number] == 1 {
        return number
    }
    return nil
}

print(firstUnique([4, 5, 4, 6, 5, 7]) ?? -1)
print(firstUnique([1, 1]) ?? -1)
```

```output
6
-1
```

Two passes over n numbers is still O(n). A `where` clause on a `for` loop runs the body only for the elements that match. And `counts[number] == 1` compares an `Int?` with `1`, which is `false` for `nil`, so no unwrapping is needed.

## Grouping

Grouping uses the same idea with a different default: start each key with an empty array and append.

```swift run
let words = ["apple", "avocado", "banana", "blueberry", "cherry", "apricot"]
var byLetter: [Character: [String]] = [:]

for word in words {
    if let first = word.first {
        byLetter[first, default: []].append(word)
    }
}

for letter in byLetter.keys.sorted() {
    print(letter, byLetter[letter] ?? [])
}
```

```output
a ["apple", "avocado", "apricot"]
b ["banana", "blueberry"]
c ["cherry"]
```

`byLetter[first, default: []].append(word)` reads the array for that letter, or an empty one, appends the word, and writes it back. Each group keeps the words in their original order.

### Dictionary(grouping:by:)

Grouping is common enough that Swift has it built in. Give `Dictionary(grouping:by:)` a collection and a closure that works out each element's key:

```swift run
let words = ["apple", "avocado", "banana", "blueberry", "cherry", "apricot"]
let byLength = Dictionary(grouping: words, by: { $0.count })

for length in byLength.keys.sorted() {
    print(length, byLength[length] ?? [])
}
```

```output
5 ["apple"]
6 ["banana", "cherry"]
7 ["avocado", "apricot"]
9 ["blueberry"]
```

The result is a `[Int: [String]]`: each key maps to the array of elements that produced it, in their original order.

To turn groups into counts, `mapValues` transforms every value and keeps the keys:

```swift run
let words = ["apple", "avocado", "banana", "blueberry", "cherry", "apricot"]
let byLength = Dictionary(grouping: words, by: { $0.count })
let howMany = byLength.mapValues { $0.count }

for length in howMany.keys.sorted() {
    print(length, howMany[length] ?? 0)
}
```

```output
5 1
6 2
7 2
9 1
```

## Three ways to add one, and only one is right

<Callout kind="gotcha" title="Swift gotcha: ! and ? when counting">
For a key that isn't in the dictionary yet:

- `counts[key]! += 1` **crashes**, because force-unwrapping `nil` is fatal.
- `counts[key]? += 1` **silently does nothing**, because optional chaining skips the statement. Your counts stay empty and no error tells you why.
- `counts[key, default: 0] += 1` **works**, creating the key with a count of 1.

When you see counts that are mysteriously missing, look for a `?` on a subscript.
</Callout>
