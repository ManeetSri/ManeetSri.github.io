## Why it matters

In the last lesson the window's size was given to you. Most window problems ask you to **find** the size instead: the longest stretch that obeys some rule, or the shortest one that reaches some goal. A music app that wants the longest run of plays with no song repeated is asking exactly that. This lesson solves the most famous example, the longest substring without repeating characters, and in doing so introduces the **variable-size window**: one that grows on the right and shrinks on the left. It's one of the most-asked interview questions there is.

## The brute force repeats itself

The straightforward approach: from every start, extend to the right until a character repeats, using a `Set` to spot the repeat.

```swift run
func longestBrute(_ text: String) -> Int {
    let chars = Array(text)
    var best = 0
    for start in chars.indices {
        var seen = Set<Character>()
        for end in start..<chars.count {
            if seen.contains(chars[end]) {
                break
            }
            seen.insert(chars[end])
            best = max(best, end - start + 1)
        }
    }
    return best
}

print(longestBrute("streets"))
print(longestBrute("abcbcad"))
```

```output
4
4
```

It's correct, but look at what it throws away. From start 0 in `"abcbcad"`, it learns that `"abc"` has no repeats, then hits the second `b`. Then it starts again from index 1 and re-checks `b` and `c`, which it already knew were fine. With many different characters, every start rescans a long stretch: O(n²) in the worst case.

## A window that grows and shrinks

Keep two indexes, `left` and `right`, and the characters between them in a set. The rule, or **invariant**, is:

> After each step, `chars[left...right]` contains no repeated character.

Each step moves `right` forward by one. If the new character is already in the window, the window is about to break the rule, so `left` moves forward, removing characters, until the old copy is gone. Then the new character goes in and the window's length is a candidate.

```swift run
func longestUniqueRun(_ text: String) -> Int {
    let chars = Array(text)
    var seen = Set<Character>()
    var left = 0
    var best = 0
    for right in 0..<chars.count {
        while seen.contains(chars[right]) {
            seen.remove(chars[left])
            left += 1
        }
        seen.insert(chars[right])
        best = max(best, right - left + 1)
    }
    return best
}

print(longestUniqueRun("streets"))
print(longestUniqueRun("abcbcad"))
print(longestUniqueRun("aaaa"))
print(longestUniqueRun(""))
```

```output
4
4
1
0
```

Step through `"abcbcad"`. When the second `b` arrives, the window drops `a` and then `b` from the left, leaving `"c"`, and carries on from there:

```visual arrayTrace

  text: abcbcad
```

<Callout kind="analogy">
It's like a caterpillar crawling along a branch. The head always moves forward. When the head lands somewhere it can't stay, the tail pulls in until the body is comfortable again. The tail never moves backwards, and neither does the head.
</Callout>

## Why a loop inside a loop is still O(n)

A `while` inside a `for` usually means O(n²). Not here. `left` only ever moves forward, and it can't pass `right`, so across the **whole run** it moves at most n times. Every character is inserted into the set once and removed at most once. That's the aggregate argument from [Amortised analysis](/dsa/learn/bigo-amortised): count the total work over the whole loop, not the worst single pass.

```swift run
func countOperations(_ text: String) -> (inserts: Int, removes: Int, best: Int) {
    let chars = Array(text)
    var seen = Set<Character>()
    var left = 0
    var best = 0
    var inserts = 0
    var removes = 0
    for right in 0..<chars.count {
        while seen.contains(chars[right]) {
            seen.remove(chars[left])
            removes += 1
            left += 1
        }
        seen.insert(chars[right])
        inserts += 1
        best = max(best, right - left + 1)
    }
    return (inserts, removes, best)
}

let letters = Array("abcdefghijklmnopqrstuvwxyz")
let text = String((0..<100_000).map { letters[$0 % 26] })
print(countOperations(text))
```

```output
(inserts: 100000, removes: 99974, best: 26)
```

100,000 inserts and fewer than 100,000 removes: under 2n set operations in total, each O(1) on average. The whole thing is **O(n)** time, and O(k) space for the k distinct characters the set can hold.

## Jump instead of crawling

The `while` loop removes characters one at a time until the old copy is gone. You can skip straight there if you remember **where** each character was last seen. When the new character's last position is inside the window, the window must start immediately after it:

```swift run
func longestUniqueRun(_ text: String) -> Int {
    let chars = Array(text)
    var lastSeen: [Character: Int] = [:]
    var left = 0
    var best = 0
    for right in 0..<chars.count {
        if let previous = lastSeen[chars[right]], previous >= left {
            left = previous + 1
        }
        lastSeen[chars[right]] = right
        best = max(best, right - left + 1)
    }
    return best
}

print(longestUniqueRun("streets"))
print(longestUniqueRun("abba"))
print(longestUniqueRun("a😀b😀"))
```

```output
4
2
3
```

Each step is now a single dictionary lookup and update. Working with `Character` values means emoji and accented letters count as one character each, as M08 explained.

### Why previous >= left matters

The dictionary never forgets, so it can return a position that's already **outside** the window. Trace `"abba"` with and without the check:

```swift run
func trace(_ text: String, checkInside: Bool) {
    let chars = Array(text)
    var lastSeen: [Character: Int] = [:]
    var left = 0
    var best = 0
    for right in 0..<chars.count {
        if let previous = lastSeen[chars[right]], !checkInside || previous >= left {
            left = previous + 1
        }
        lastSeen[chars[right]] = right
        best = max(best, right - left + 1)
        print("right \(right) '\(chars[right])': left \(left), best \(best)")
    }
}

trace("abba", checkInside: true)
print("---")
trace("abba", checkInside: false)
```

```output
right 0 'a': left 0, best 1
right 1 'b': left 0, best 2
right 2 'b': left 2, best 2
right 3 'a': left 2, best 2
---
right 0 'a': left 0, best 1
right 1 'b': left 0, best 2
right 2 'b': left 2, best 2
right 3 'a': left 1, best 3
```

At the last `a`, its previous copy is at index 0, but the window already starts at 2. Without the check, `left` jumps **back** to 1, and the window `"bba"` (which repeats `b`) is counted as 3. The left edge of a window must never move backwards. Writing `left = max(left, previous + 1)` is an equivalent fix.

## Arrays beat dictionaries for ASCII

When the input is promised to be ASCII, as many problems are, each character is one byte from 0 to 127. A 128-slot array of last positions replaces the dictionary, with no hashing at all, like the 26-slot counts in [Frequency counting with 26 slots](/dsa/learn/swift-frequency-arrays):

```swift run
func longestUniqueRunASCII(_ text: String) -> Int {
    let bytes = Array(text.utf8)
    var lastSeen = [Int](repeating: -1, count: 128)   // -1 means "not seen yet"
    var left = 0
    var best = 0
    for right in 0..<bytes.count {
        let code = Int(bytes[right])
        if lastSeen[code] >= left {
            left = lastSeen[code] + 1
        }
        lastSeen[code] = right
        best = max(best, right - left + 1)
    }
    return best
}

print(longestUniqueRunASCII("mississippi"))
print(longestUniqueRunASCII("a b c a"))
```

```output
3
3
```

Starting every slot at −1 means "never seen" is automatically outside the window, since `left` is never negative. Spaces are characters like any other: in `"a b c a"` the longest run is `"a b"` or `"b c"`, and `" c "` repeats the space.

<Callout kind="gotcha" title="Common mistakes">
- **Letting `left` move backwards.** Always check that the remembered position is inside the window, or use `max(left, previous + 1)`.
- **Recording too early.** Update `best` only after the window is valid again. Recording before shrinking counts windows that contain a repeat.
- **Bytes for Unicode text.** `Array(text.utf8)` splits `é` and emoji into several bytes. Use it only when the problem promises ASCII; otherwise use `Array(text)` and a `[Character: Int]` dictionary.
</Callout>
