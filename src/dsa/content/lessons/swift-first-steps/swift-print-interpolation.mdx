## Why it matters

`print` is your window into a running program. When an algorithm gives the wrong answer, printing the values at each step is often the fastest way to see where it goes wrong. String interpolation, putting values inside text, is how you build every label, message and description, from "3 items in your basket" in an iOS app to the debugging lines you'll write all through this course.

## print, in more detail

You've already used `print` with a single string. It can print any value, not only text:

```swift run
print("Hello")
print(42)
print(3.5)
print(true)
```

```output
Hello
42
3.5
true
```

Each `print` ends with a **newline**, so the next output starts on a fresh line.

### Several values at once

Give `print` several values separated by commas and it prints them on one line, with a space between each:

```swift run
print("Score:", 90, "out of", 100)
print("a", "b", "c", separator: "-")
print("Loading", terminator: "")
print("... done")
```

```output
Score: 90 out of 100
a-b-c
Loading... done
```

- `separator:` changes what goes *between* the values. The default is a single space.
- `terminator:` changes what goes at the *end*. The default is a newline, so `terminator: ""` keeps the next output on the same line.

These words followed by a colon are **argument labels**. They name what each extra value is for. You'll write your own in M05.

## String interpolation

To put a value inside a string, write a backslash and wrap the value in parentheses: `\(value)`. Swift replaces it with the value, turned into text.

```swift run
let name = "Maneet"
let lessonsDone = 3
print("\(name) has finished \(lessonsDone) lessons.")
```

```output
Maneet has finished 3 lessons.
```

Inside the parentheses you can write any **expression**, not only a name. Swift works it out first, then inserts the result:

```swift run
let width = 7
let height = 4
print("A \(width) by \(height) rectangle has area \(width * height).")
print("Next year you'll have done \(width + 1) lessons.")
```

```output
A 7 by 4 rectangle has area 28.
Next year you'll have done 8 lessons.
```

Keep the expressions short. If the maths inside `\( )` gets long, work it out on its own line first, give it a name, and interpolate the name. Your future self will thank you.

### Joining strings with +

You can also join strings with `+`, which is called **concatenation**:

```swift run
let first = "Ada"
let last = "Lovelace"
print(first + " " + last)
```

```output
Ada Lovelace
```

But `+` only joins a string to another string. Mixing in a number is a compile error:

```swift
let age = 30
print("Age: " + age)
```

```text title="What you'll see"
error: binary operator '+' cannot be applied to operands of type 'String' and 'Int'
```

Swift won't quietly turn the number into text for you. Interpolation does that conversion for you, which is why `"Age: \(age)"` is the usual way to write it. You'll learn why Swift is this strict in *Type inference and type annotations*, later in this module.

## Escape sequences: special characters in strings

The double quote ends a string, so how do you put a quote *inside* one? You **escape** it with a backslash. A backslash followed by certain characters means something special:

| You write | You get |
| --- | --- |
| `\"` | a double quote |
| `\\` | a single backslash |
| `\n` | a new line |
| `\t` | a tab |
| `\(x)` | the value of `x` |

```swift run
print("She said \"hello\" and waved.")
print("A backslash looks like this: \\")
print("Line one\nLine two")
```

```output
She said "hello" and waved.
A backslash looks like this: \
Line one
Line two
```

`\n` is one character, the newline, even though you type it as two. The third `print` produces two lines of output.

## Multi-line strings

For text that spans several lines, wrap it in three double quotes, `"""`, each on its own line:

```swift run
let card = """
    Dear Ada,
    Thanks for the "Analytical Engine" notes.
      Indented lines keep their extra spaces.
    Maneet
    """
print(card)
```

```output
Dear Ada,
Thanks for the "Analytical Engine" notes.
  Indented lines keep their extra spaces.
Maneet
```

Three rules make multi-line strings work:

1. The opening `"""` ends its line, and the text starts on the next line.
2. The **closing** `"""` decides the indentation. Whatever spaces come before it are removed from every line. Here that's four spaces, so `Dear Ada,` starts at the left edge, and the third line keeps its two extra spaces.
3. Quotes don't need escaping inside, so `"Analytical Engine"` is fine as it is. Escapes like `\n` and interpolation like `\(name)` still work.

## Raw strings: when backslashes should stay

Sometimes you want backslashes to appear exactly as typed, for example in a Windows file path or when showing someone how escapes work. Put a `#` on each side of the string to make it a **raw string**. Inside it, a backslash is just a backslash:

```swift run
let folder = "Documents"
print(#"C:\Users\Maneet"#)
print(#"Type \n to start a new line."#)
print(#"Saved in \#(folder)"#)
```

```output
C:\Users\Maneet
Type \n to start a new line.
Saved in Documents
```

To interpolate inside a raw string, add the same `#` after the backslash: `\#(folder)`. You won't need raw strings often, but you'll recognise them when you see them, especially in text-matching code later on.

## Choosing the right tool

| You want to… | Use |
| --- | --- |
| put values inside text | interpolation, `"Score: \(score)"` |
| join two strings you already have | `+`, as in `first + " " + last` |
| write text over several lines | a multi-line string, `"""` |
| keep backslashes exactly as typed | a raw string, `#"..."#` |
| print several values with a custom gap | `print(a, b, separator: ", ")` |

Interpolation is the one you'll use most. It works with any type, it reads naturally, and it never fails to compile because of a number in the middle.

## Printing to understand code

Printing is the oldest debugging tool there is, and it still works. When you're not sure what code is doing, print the values at each step, with a label so you can tell the lines apart:

```swift run
let start = 10
print("start = \(start)")
let doubled = start * 2
print("after doubling = \(doubled)")
let result = doubled - 3
print("after subtracting 3 = \(result)")
```

```output
start = 10
after doubling = 20
after subtracting 3 = 17
```

When an algorithm in later modules misbehaves, you'll print the values inside a loop in exactly this way and compare them with what you expected. The first line that differs shows you where the bug is.

<Callout kind="gotcha" title="Swift gotcha: forgetting the backslash">
`print("Hello, (name)!")` prints `Hello, (name)!` with the brackets and the word *name*. It's not an error, so Swift won't warn you. Interpolation needs the backslash: `\(name)`. If your output contains a variable's name instead of its value, look for a missing backslash.
</Callout>
