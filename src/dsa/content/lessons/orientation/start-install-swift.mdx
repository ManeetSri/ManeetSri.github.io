## Why it matters

Reading about code teaches you very little. Running it teaches you a lot. Before the first real lesson you need three ways to run Swift: **Xcode** for full projects, **Swift Playgrounds** for quick experiments, and the **`swift` command** in Terminal for the companion package. All three come from Apple and are free.

## 1. Install Xcode

Xcode is Apple's development environment, and it includes the Swift compiler.

1. Open the **App Store** on your Mac, search for **Xcode** and install it. It's large, so give it time.
2. Open Xcode once. It asks to install extra components: accept.
3. Check that Terminal uses this Xcode. Open **Terminal** and run:

```bash
xcode-select -p
```

```output
/Applications/Xcode.app/Contents/Developer
```

If it prints a different path, point it at Xcode with `sudo xcode-select -s /Applications/Xcode.app` and enter your Mac password when asked.

## 2. Check the Swift version

```bash
swift --version
```

```output
Apple Swift version 6.x (…)
Target: arm64-apple-macosx…
```

Any Swift 6 version works for this course. The exact numbers will differ on your Mac.

<Callout kind="note">
Swift 6 brought **strict concurrency checking**, which catches data races at compile time. It's excellent for apps but noisy when you're learning. The companion package uses Swift 5 *language mode* on the Swift 6 compiler, so you get modern Swift without errors about concurrency you haven't learned yet. You'll meet concurrency properly in Part IX.
</Callout>

## 3. Your first Swift in three places

### Swift Playgrounds or an Xcode playground

In Xcode choose **File › New › Playground…**, pick **Blank**, and replace its contents with:

```swift title="MyFirst.playground"
let language = "Swift"
let lessonsAhead = 627
print("Learning DSA in \(language): \(lessonsAhead) lessons to go!")
```

```output
Learning DSA in Swift: 627 lessons to go!
```

Press the **▶ Run** button. The output appears in the console at the bottom. Playgrounds are perfect for trying out an idea in seconds.

### The REPL

Type `swift repl` in Terminal for an interactive prompt. Each line runs as soon as you press Return. Type `:quit` to leave.

### A Swift package

For anything with tests, which is everything in this course, you'll use a Swift package. That's the next lesson.

## Which tool when

| Tool | Best for |
| --- | --- |
| **Playground** | Quick experiments, trying an API, checking an idea |
| **REPL** | One-line questions like "what does `7 / 2` give?" |
| **Swift package** | Exercises with tests, anything longer than a screen |
| **Xcode project** | Full apps, like the capstone projects in Part X |

<Callout kind="tip">
Keep a scratch playground open while you study. Whenever a lesson says "this prints…", type it in and check. Predicting the output before you run it is one of the fastest ways to learn.
</Callout>
