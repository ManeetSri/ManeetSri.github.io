## Why it matters

Plenty of problems return a string: encode this message, compress these characters, reverse these words, format this number. How you build that string matters. Done carelessly, assembling a 100,000-character answer one piece at a time can quietly take billions of steps. Swift gives you a few tools that keep it fast, and they're easy once you know which to reach for.

## Appending to a var string

Swift strings are values, like arrays. A `var` string can grow in place, and there are three common ways to add to it:

```swift run
var greeting = "Hello"
greeting += ", "
greeting.append("world")

let bang: Character = "!"
greeting.append(bang)

print(greeting)
```

```output
Hello, world!
```

- `+=` adds a string to the end.
- `append(_:)` adds either a `String` or a single `Character`.
- `+` joins two strings into a new one, as in `first + " " + last`.

Appending to a `var` string works like appending to an array: Swift keeps spare room at the end and grows the storage in big jumps when it runs out. So each `+=` or `append` costs roughly the length of the piece you add, not the length of the whole string. A loop that builds an n-character string with `+=` is **O(n)** overall.

```swift run
var digits = ""
for n in 1...9 {
    digits += String(n)
}
print(digits)
```

```output
123456789
```

`String(n)` turns an `Int` into its text. You'll see more conversions in the last lesson of this module.

<Callout kind="gotcha" title="Swift gotcha: s = s + piece">
`result = result + piece` looks the same as `result += piece`, but it isn't. It builds a brand-new string from `result` and `piece`, then replaces `result` with it, which can mean copying everything built so far, every time. In a loop that's O(n²). Always write `result += piece` or `result.append(piece)`.
</Callout>

### You can't add a Character with +

`+` only joins strings. Adding a `Character` to a `String` doesn't compile:

```swift
let letter: Character = "x"
let word = "ab" + letter
```

```text title="What you'll see"
error: cannot convert value of type 'Character' to expected argument type 'String'
```

Either convert it, `"ab" + String(letter)`, or use `append`, which accepts characters directly.

## Repeating: String(repeating:count:)

To repeat a character or a string, don't loop: ask for it.

```swift run
print(String(repeating: "=", count: 12))
print(String(repeating: "ab", count: 3))

let done = 7
let total = 10
let bar = "[" + String(repeating: "#", count: done) + String(repeating: ".", count: total - done) + "]"
print(bar)
```

```output
============
ababab
[#######...]
```

This is handy for padding, drawing grids and making test inputs.

## Joining: joined(separator:)

When you have an array of strings, `joined(separator:)` glues them together with a separator between each pair, and none at the ends:

```swift run
let words = ["swift", "is", "fun"]
print(words.joined(separator: " "))
print(words.joined(separator: ", "))
print(words.joined())
```

```output
swift is fun
swift, is, fun
swiftisfun
```

`joined()` with no separator glues them together with nothing in between.

`joined` only works on strings, so to join numbers, turn each one into a string first with `map` (from M06):

```swift run
let numbers = [3, 1, 4, 1, 5]
print(numbers.map(String.init).joined(separator: "-"))
print(numbers.map { String($0) }.joined(separator: " + "))
```

```output
3-1-4-1-5
3 + 1 + 4 + 1 + 5
```

`map(String.init)` passes the `String` initialiser itself as the closure: a neat use of functions as values from M05. `{ String($0) }` does the same thing.

<Callout kind="tip">
"Collect the pieces in an array, then join once" is a great habit. It avoids fiddly "do I need a separator here?" logic: no stray comma at the start or end.
</Callout>

## Building from an array of characters

When you're producing a string character by character, especially if you need to change characters you've already added, collect them in a `[Character]` and convert at the end with `String(chars)`:

```swift run
var chars: [Character] = []
for ch in "hello" {
    chars.append(ch)
    chars.append("-")
}
chars.removeLast()
print(String(chars))
```

```output
h-e-l-l-o
```

An array lets you `removeLast()` the extra dash, swap characters or overwrite `chars[i]`, all O(1). Then `String(chars)` builds the final string in one O(n) step.

## reserveCapacity: say how big it will be

If you know roughly how long the result will be, `reserveCapacity(_:)` sets aside that much room up front, so the string never has to grow and move along the way:

```swift run
let names = ["Ada", "Grace", "Linus"]
var line = ""
line.reserveCapacity(64)
for name in names {
    line += name
    line += ";"
}
print(line)
```

```output
Ada;Grace;Linus;
```

The output is the same with or without it; it's purely a speed hint. The number is measured in UTF-8 bytes, which for ASCII text is the same as characters. Arrays have `reserveCapacity` too. You'll rarely need it, but it's a nice touch when building a large result whose size you know exactly.

## Putting it together: run-length encoding

Run-length encoding compresses repeated characters: `"aaabccdddd"` becomes `"a3b1c2d4"`, each character followed by how many times it repeats in a row. It uses an array for fast access and appends to the result as it goes:

```swift run
func encode(_ text: String) -> String {
    let chars = Array(text)
    var result = ""
    var i = 0
    while i < chars.count {
        var j = i
        while j < chars.count && chars[j] == chars[i] {
            j += 1
        }
        result.append(chars[i])
        result += String(j - i)
        i = j
    }
    return result
}

print(encode("aaabccdddd"))
print(encode("x"))
print(encode("").isEmpty)
```

```output
a3b1c2d4
x1
true
```

What to notice:

- `j` runs ahead to the end of the current run, so `j - i` is the run's length.
- Then `i` jumps to `j`. Every character is visited by `j` exactly once, so although there are two loops, the whole thing is **O(n)**.
- The result is built with `append` and `+=`, never `result = result + ...`.

You'll come back to compression problems in M23.
