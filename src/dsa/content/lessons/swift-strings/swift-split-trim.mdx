## Why it matters

A huge amount of real-world code takes text apart and puts it back together: turning a sentence into words, a line of a file into numbers, a CSV row into fields, a title into a URL slug. Interview problems do the same, and so does reading input in competitive programming. Swift splits strings in its standard library, but some of the most familiar tools, `components(separatedBy:)` and `trimmingCharacters(in:)`, actually come from **Foundation**, Apple's larger framework. Knowing which is which saves you from mysterious "has no member" errors.

## split(separator:)

`split(separator:)` breaks a string into pieces wherever the separator appears. It returns an array of **substrings**, from the last lesson:

```swift run
let sentence = "  the quick   brown fox "
let words = sentence.split(separator: " ")
print(words)
print(words.count)
```

```output
["the", "quick", "brown", "fox"]
4
```

Notice what didn't happen: there are no empty strings, even though the sentence starts with two spaces, has three spaces between "quick" and "brown", and ends with a space. By default, `split` **omits empty pieces**. For splitting text into words, that's exactly what you want, and it means `split` also takes care of extra spaces at the ends.

### Keeping the empty pieces

Sometimes empty pieces carry meaning. In a CSV row, `"ada,,grace"` has an empty field in the middle. Pass `omittingEmptySubsequences: false` to keep them:

```swift run
let row = "ada,,grace,linus,"
print(row.split(separator: ","))
print(row.split(separator: ",", omittingEmptySubsequences: false))
```

```output
["ada", "grace", "linus"]
["ada", "", "grace", "linus", ""]
```

### Splitting only once

`maxSplits:` limits how many times to split, leaving the rest in one piece. That's handy for "a command followed by its arguments":

```swift run
let command = "move 10 20 fast"
let parts = command.split(separator: " ", maxSplits: 1)
print(parts)
```

```output
["move", "10 20 fast"]
```

### Splitting on several separators

`split(whereSeparator:)` takes a closure that decides, character by character, what counts as a separator:

```swift run
let messy = "one, two;three  four"
print(messy.split(whereSeparator: { $0 == "," || $0 == ";" || $0 == " " }))

let text = "line one\nline two\tend"
print(text.split(whereSeparator: { $0.isWhitespace }))
```

```output
["one", "two", "three", "four"]
["line", "one", "line", "two", "end"]
```

Using `isWhitespace` (from the character properties lesson) splits on spaces, tabs and newlines in one go.

<Callout kind="note">
Since Swift 5.7 you can also split on a multi-character separator, like `"a--b--c".split(separator: "--")`. It's part of the standard library on recent platforms, including the companion package's macOS 14 target.
</Callout>

## Turning pieces into numbers

Each piece is a `Substring`, and `Int(_:)` accepts substrings directly, returning `nil` when the text isn't a valid number. `compactMap` (from M06) converts and drops the failures in one step:

```swift run
let input = "3 14 15 92 x 6"
let numbers = input.split(separator: " ").compactMap { Int($0) }
print(numbers)
print(numbers.reduce(0, +))
```

```output
[3, 14, 15, 92, 6]
130
```

Use `map` instead of `compactMap` when every piece is guaranteed to be a number and you'd rather know if one isn't.

## Joining the pieces back

You met `joined(separator:)` in the building-strings lesson. It works on arrays of substrings too, so splitting and joining chain nicely:

```swift run
let title = "learn   swift today"
let slug = title.split(separator: " ").joined(separator: "-")
print(slug)

let capitalised = title.split(separator: " ").map { $0.prefix(1).uppercased() + $0.dropFirst() }
print(capitalised.joined(separator: " "))
```

```output
learn-swift-today
Learn Swift Today
```

The second example capitalises each word: `prefix(1).uppercased()` is the first letter in uppercase (a `String`), and `dropFirst()` is the rest (a `Substring`). `+` can join the two.

The pattern **split, transform the array, join** solves a whole family of problems. Between the split and the join you have an ordinary array, so everything from M06 and M07 is available: `map`, `filter`, `reversed`, sorting, counting.

## Foundation's tools: components and trimming

Two methods you'll see in a lot of Swift code aren't in the standard library at all. They come from **Foundation**, so a file must start with `import Foundation` to use them. Without it:

```swift
let row = "ada,grace"
let names = row.components(separatedBy: ",")
```

```text title="What you'll see"
error: value of type 'String' has no member 'components'
```

In an iOS app, `import UIKit` or `import SwiftUI` brings Foundation along, so you might never notice. In a plain Swift file, an interview editor or a competitive programming judge, you need the import yourself.

### components(separatedBy:)

```swift run
import Foundation

let row = "ada,,grace,linus,"
print(row.components(separatedBy: ","))

let date = "2024--06--15"
print(date.components(separatedBy: "--"))
```

```output
["ada", "", "grace", "linus", ""]
["2024", "06", "15"]
```

Compared with `split`:

| | `split(separator:)` | `components(separatedBy:)` |
| --- | --- | --- |
| Needs `import Foundation` | no | yes |
| Returns | `[Substring]` | `[String]` |
| Empty pieces | omitted by default | always kept |

### trimmingCharacters(in:)

`trimmingCharacters(in:)` removes characters from both **ends** of a string, never the middle:

```swift run
import Foundation

let padded = "   hello world  \n"
print("[" + padded.trimmingCharacters(in: .whitespacesAndNewlines) + "]")
print("[" + "  hi  ".trimmingCharacters(in: .whitespaces) + "]")
```

```output
[hello world]
[hi]
```

The square brackets in the output show where the string really starts and ends. `.whitespaces` covers spaces and tabs; `.whitespacesAndNewlines` adds line breaks, which is what you usually want for lines read from input.

### Trimming without Foundation

If you'd rather not depend on Foundation, the string index tools from earlier in this module are enough: find the first and last characters that aren't whitespace, and slice between them.

```swift run
func trimmed(_ text: String) -> Substring {
    guard let start = text.firstIndex(where: { !$0.isWhitespace }),
          let end = text.lastIndex(where: { !$0.isWhitespace }) else {
        return ""
    }
    return text[start...end]
}

print("[" + trimmed("   hello world  ") + "]")
print("[" + trimmed("     ") + "]")
```

```output
[hello world]
[]
```

If the string is all whitespace, `firstIndex(where:)` finds nothing and the `guard` returns an empty substring.

<Callout kind="gotcha" title="Swift gotcha: split and components disagree about empties">
`"a  b".split(separator: " ")` gives `["a", "b"]`, but `"a  b".components(separatedBy: " ")` gives `["a", "", "b"]`, with an empty string for the gap between the two spaces. If your word count is mysteriously too high, you're probably using `components` on text with repeated spaces.
</Callout>
