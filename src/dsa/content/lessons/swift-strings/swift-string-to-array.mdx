## Why it matters

Most string algorithms need to jump around: compare the first and last characters, look at a window of five characters, check `s[i]` against `s[i - 1]`. With `String.Index`, every one of those jumps is clumsy and some are slow. The standard Swift move is to **convert the string to an array once**, at the start, and then work with integer indexes at O(1) per access. It's the single most useful technique in this module, and you'll see it in nearly every string solution in this course.

## Array(s): an array of Characters

A `String` is a collection of `Character` values, so `Array(s)` turns it into a `[Character]`:

```swift run
let word = "swift"
let chars = Array(word)

print(chars)
print(chars[0], chars[4], chars.count)
print(type(of: chars))
```

```output
["s", "w", "i", "f", "t"]
s t 5
Array<Character>
```

`Array<Character>` is the long way of writing `[Character]`. Now `chars[i]` is an ordinary array subscript: **O(1)**, no index-walking. And `chars.count` is O(1) too, unlike a string's `count`.

The cost is paid once, up front: building the array walks the string a single time, O(n), and stores every character, O(n) extra memory. For almost every problem, that trade is well worth it.

<Callout kind="analogy">
Converting a string to an array is like cutting a paper strip of text into separate tiles and laying them in numbered boxes. Cutting takes one pass, but afterwards you can pick up tile 37 instantly instead of counting along the strip each time.
</Callout>

### Two pointers with integer indexes

Compare this reversal with the index-juggling of the last lesson. It reads like the array code you already know:

```swift run
func reversed(_ text: String) -> String {
    var chars = Array(text)
    var left = 0
    var right = chars.count - 1
    while left < right {
        chars.swapAt(left, right)
        left += 1
        right -= 1
    }
    return String(chars)
}

print(reversed("stressed"))
print(reversed("a"))
print(reversed("").isEmpty)
```

```output
desserts
a
true
```

What to notice:

- `swapAt` (from M05) swaps two array elements in place.
- `String(chars)` turns a `[Character]` back into a `String`.
- An empty string gives `right = -1`, so `left < right` is false straight away and the loop never runs. No special case needed.

### Windows of characters

Slicing an array with an integer range is easy too. Here's every run of three consecutive characters, a first taste of the **sliding window** pattern (M22):

```swift run
let chars = Array("abcdefg")
var windows: [String] = []
for start in 0...(chars.count - 3) {
    windows.append(String(chars[start..<start + 3]))
}
print(windows)
```

```output
["abc", "bcd", "cde", "def", "efg"]
```

`chars[start..<start + 3]` is an `ArraySlice<Character>`, and `String(...)` accepts it directly.

## Array(s.utf8): an array of bytes

`Array(s)` is Unicode-correct, but each `Character` is a fairly heavy value: Swift has to handle the possibility that it's a 25-byte emoji. When a problem promises the text is **ASCII**, you can go one level lower and work with raw bytes. `s.utf8` is the string's UTF-8 view, and `Array(s.utf8)` copies it into a `[UInt8]`:

```swift run
let bytes = Array("cat".utf8)
print(bytes)
print(type(of: bytes))
```

```output
[99, 97, 116]
Array<UInt8>
```

`UInt8` is an unsigned 8-bit integer, a whole number from 0 to 255 (you met sized integers in M02). Each byte here is an ASCII code: `c` is 99, `a` is 97, `t` is 116.

Comparing and storing small integers is about as fast as a computer gets, so byte arrays are the fastest way to process ASCII text in Swift. Competitive programmers use them all the time.

### Writing byte literals

Remembering that `a` is 97 is error-prone. `UInt8(ascii:)` turns a character literal into its byte:

```swift run
print(UInt8(ascii: "a"), UInt8(ascii: "A"), UInt8(ascii: " "))

var bytes = Array("hello world".utf8)
for i in bytes.indices where bytes[i] == UInt8(ascii: "o") {
    bytes[i] = UInt8(ascii: "0")
}
print(String(decoding: bytes, as: UTF8.self))
```

```output
97 65 32
hell0 w0rld
```

`String(decoding:as:)` turns bytes back into a string. `UTF8.self` tells it how to read them.

## When bytes go wrong

Bytes and characters only line up for ASCII. Outside it, one character can be several bytes, and treating bytes as characters breaks the text:

```swift run
let word = "héllo"
print(Array(word).count, Array(word.utf8).count)
print(String(Array(word).reversed()))
print(String(decoding: Array(word.utf8).reversed(), as: UTF8.self))
```

```output
5 6
olléh
oll��h
```

`é` is two bytes. Reversing the **characters** gives `olléh`, correct. Reversing the **bytes** splits `é` into two invalid half-characters, which Swift shows as the replacement symbol `�`. The text is corrupted.

<Callout kind="gotcha" title="Swift gotcha: check the constraints before using bytes">
Only use `Array(s.utf8)` when the problem guarantees ASCII, for example "s consists of lowercase English letters" or "printable ASCII characters". If the input could contain accents or emoji, use `Array(s)`. When in doubt, `Array(s)` is always correct; bytes are an optimisation.
</Callout>

## Which one to use

| You need | Use | Cost |
| --- | --- | --- |
| Each character once, in order | `for ch in s` | O(n), no extra memory |
| Positions as numbers, in order | `for (i, ch) in s.enumerated()` | O(n), no extra memory |
| Random access, two pointers, windows | `let chars = Array(s)` | O(n) once, then O(1) per access |
| The same, fastest, ASCII-only input | `let bytes = Array(s.utf8)` | O(n) once, then O(1) per access |

A typical solution starts with one line of conversion and then never touches the original string again:

```swift
func solve(_ s: String) -> Int {
    let chars = Array(s)      // or Array(s.utf8) for ASCII input
    // ... work with chars[i] ...
    return 0
}
```

<Callout kind="gotcha" title="Swift gotcha: Character, not String">
`Array("abc")` is a `[Character]`, not a `[String]`. Comparing `chars[0] == "a"` works because Swift reads the literal `"a"` as a `Character` there. But to join characters back up, use `String(chars)`; `chars.joined()` only works on arrays of strings. Swift has no single-quote character literals: `'a'` doesn't compile.
</Callout>
