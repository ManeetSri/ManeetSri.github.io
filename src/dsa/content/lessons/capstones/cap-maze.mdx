## Why it matters

A maze looks like a puzzle, but it's a graph problem twice over. The cells of a grid are vertices, and the walls you knock down are edges. A **perfect maze**, with exactly one path between any two cells, is a **spanning tree** of the grid: connected, with no loops. So generating a maze means building a *random* spanning tree, which you can do with randomised depth-first search, or with [Kruskal's algorithm](/dsa/learn/mst-kruskal) and union-find on shuffled walls. Solving it is [BFS](/dsa/learn/gt-bfs). In this project you build both generators and a solver, measure how differently their mazes feel, and render everything in SwiftUI with `Canvas`, including a playable mode where you swipe your way out. Procedural generation from a seed is how games ship endless levels in a few kilobytes, and how players share a level with a short code.

## What you'll build

- `MazeCore`, a package with a maze model, two seeded generators (randomised DFS and randomised Kruskal), a BFS solver, statistics, and a check that a maze is perfect.
- A SwiftUI app that draws mazes of any size with `Canvas`, animates their generation and solution, and has a play mode: swipe to move from the top-left corner to the bottom-right against the clock. A seed field reproduces any maze.

Budget about two hours. It's a good final project: small enough to finish, and it touches graphs, trees, union-find, BFS, randomness and drawing.

## The architecture

```text
 seed, size, algorithm
          │
          ▼
 Generator (pure Swift, seeded) ──▶ Maze: rows × columns, openRight[r][c], openDown[r][c]
   depth-first: explicit stack           │
   Kruskal: shuffled walls + union-find  ├──▶ Solver: BFS from (0, 0) ──▶ path
          │                              ├──▶ Stats: passages, dead ends, path length
          ▼                              ▼
   steps (optional, for animation)   MazeView: Canvas draws walls, path and player
                                         ▲
                     swipe ─▶ GameModel: player cell, moves, timer, solved?
```

- **The maze stores passages, not walls.** `openRight[r][c]` says whether you can walk from cell (r, c) to the cell on its right; `openDown[r][c]` the same for the cell below. Every other wall is up. Two Boolean grids are all the state there is.
- **The generator knows nothing about drawing**, and the view knows nothing about generating. As in the visualiser, a generator can also record each knocked-down wall as a step, for animation.
- **A seed reproduces a maze exactly**, so a player can share "maze 4071, 30 × 30" in a message.

## Milestones

### 1. The model and a perfect-maze check

Write `Maze` with `around(_:)` (neighbours inside the grid), `isOpen(_:_:)`, `knockDown(_:_:)` and `exits(_:)`, plus an ASCII renderer for debugging. Then write `isPerfect`: a maze of n cells is a spanning tree exactly when it has n − 1 passages **and** every cell is reachable from the first.

- **Acceptance:** an untouched grid isn't perfect (no passages); a hand-built snake through every cell is.
- **Exercises:** the definition of a tree: connected with n − 1 edges, which together rule out loops.

### 2. Randomised depth-first search

Start at a cell, mark it visited, and repeatedly walk to a random unvisited neighbour, knocking down the wall between. When the current cell has no unvisited neighbours, back up along the stack. Use an explicit stack.

- **Acceptance:** perfect mazes for 100 seeds; a 300 × 300 maze generates without crashing, which a recursive version 90,000 calls deep might not.
- **Exercises:** DFS, and turning recursion into an explicit stack, as in [Turning recursion into an explicit stack](/dsa/learn/rec-explicit-stack).

### 3. Randomised Kruskal

List every internal wall, shuffle the list, and knock down each wall whose two cells aren't yet connected, which union-find answers in nearly O(1).

- **Acceptance:** perfect mazes for 100 seeds; exactly n − 1 unions succeed.
- **Exercises:** Kruskal's algorithm with random weights, and union-find.

### 4. Solve it

BFS from the top-left cell, recording each cell's predecessor, then walk back from the bottom-right cell.

- **Acceptance:** consecutive cells on the path are open neighbours; the path's length equals the BFS distance; a 1 × 1 maze gives a path of one cell.
- **Exercises:** BFS, and a surprise: in a perfect maze there's only one path, so DFS would find the same one. BFS starts to matter in the stretch goal, when loops appear.

### 5. Draw and animate

A `Canvas` that draws the outer border, every wall still standing, the solution as a thick line through cell centres, and the player as a dot. Record the generator's steps and play them back with the visualiser's player, so you can watch the depth-first search snake forward and back up, and Kruskal's scattered fragments join.

- **Acceptance:** a 60 × 60 maze draws without stutter; generation and solving can be played, paused and scrubbed.
- **Exercises:** recording an algorithm's steps without changing the algorithm.

### 6. Play, and measure textures

Swipe to move, one cell per swipe, only through open passages; a timer starts on the first move. Add a statistics panel: dead ends, the solution's length, and the average over 20 seeds for each generator.

- **Acceptance:** you can finish a maze by swiping; the statistics show the difference between the two generators that you can already see.
- **Exercises:** turning an impression ("depth-first mazes feel like long corridors") into numbers.

## Key code: two generators and a solver

Both generators produce a perfect maze from the same seeded `Dice`; BFS solves each; `stats` counts passages, dead ends and the solution length. The last line averages 20 mazes of 20 × 20 from each generator.

```swift run
// The course's seeded generator
struct Dice {
    private var state: UInt64
    init(seed: UInt64) { state = seed }
    mutating func roll(_ range: ClosedRange<Int>) -> Int {
        state = state &* 6364136223846793005 &+ 1442695040888963407
        return range.lowerBound + Int((state >> 33) % UInt64(range.count))
    }
    mutating func shuffle<T>(_ items: inout [T]) {
        for i in stride(from: items.count - 1, to: 0, by: -1) {
            items.swapAt(i, roll(0...i))
        }
    }
}

/// Union-find with path halving and union by size, as in "Path compression and union by rank"
struct UnionFind {
    private var parent: [Int]
    private var size: [Int]
    init(count: Int) {
        parent = Array(0..<count)
        size = Array(repeating: 1, count: count)
    }
    mutating func find(_ x: Int) -> Int {
        var x = x
        while parent[x] != x {
            parent[x] = parent[parent[x]]
            x = parent[x]
        }
        return x
    }
    mutating func union(_ a: Int, _ b: Int) -> Bool {
        var (ra, rb) = (find(a), find(b))
        if ra == rb { return false }
        if size[ra] < size[rb] { swap(&ra, &rb) }
        parent[rb] = ra
        size[ra] += size[rb]
        return true
    }
}

/// A grid of cells; cell r * columns + c. A passage is a wall that has been knocked down.
struct Maze {
    let rows: Int
    let columns: Int
    private(set) var openRight: [[Bool]]       // a passage from (r, c) to (r, c + 1)
    private(set) var openDown: [[Bool]]        // a passage from (r, c) to (r + 1, c)

    init(rows: Int, columns: Int) {
        self.rows = rows
        self.columns = columns
        openRight = Array(repeating: Array(repeating: false, count: columns), count: rows)
        openDown = openRight
    }

    var cellCount: Int { rows * columns }

    /// Neighbouring cells inside the grid, whether or not a wall is in the way
    func around(_ cell: Int) -> [Int] {
        let r = cell / columns, c = cell % columns
        var result: [Int] = []
        if r > 0 { result.append(cell - columns) }
        if c < columns - 1 { result.append(cell + 1) }
        if r < rows - 1 { result.append(cell + columns) }
        if c > 0 { result.append(cell - 1) }
        return result
    }

    /// Neighbours in the same row share a right-hand wall. Comparing rows, not `high - low == 1`, keeps a
    /// one-column maze right: there, the cell below is also one number up.
    func isOpen(_ a: Int, _ b: Int) -> Bool {
        let (low, high) = (min(a, b), max(a, b))
        return low / columns == high / columns ? openRight[low / columns][low % columns] : openDown[low / columns][low % columns]
    }

    mutating func knockDown(_ a: Int, _ b: Int) {
        let (low, high) = (min(a, b), max(a, b))
        if low / columns == high / columns {
            openRight[low / columns][low % columns] = true
        } else {
            openDown[low / columns][low % columns] = true
        }
    }

    func exits(_ cell: Int) -> [Int] { around(cell).filter { isOpen(cell, $0) } }
}

/// Randomised depth-first search: walk to a random unvisited neighbour; back up when there's none
func depthFirstMaze(rows: Int, columns: Int, dice: inout Dice) -> Maze {
    var maze = Maze(rows: rows, columns: columns)
    var visited = Array(repeating: false, count: maze.cellCount)
    var stack = [0]                                       // an explicit stack: no recursion depth limit
    visited[0] = true
    while let cell = stack.last {
        let fresh = maze.around(cell).filter { !visited[$0] }
        if fresh.isEmpty {
            stack.removeLast()
            continue
        }
        let next = fresh[dice.roll(0...(fresh.count - 1))]
        maze.knockDown(cell, next)
        visited[next] = true
        stack.append(next)
    }
    return maze
}

/// Randomised Kruskal: knock down walls in random order, unless the two sides are already connected
func kruskalMaze(rows: Int, columns: Int, dice: inout Dice) -> Maze {
    var maze = Maze(rows: rows, columns: columns)
    var walls: [(Int, Int)] = []
    for cell in 0..<maze.cellCount {
        for other in maze.around(cell) where other > cell {
            walls.append((cell, other))
        }
    }
    dice.shuffle(&walls)
    var sets = UnionFind(count: maze.cellCount)
    for (a, b) in walls where sets.union(a, b) {
        maze.knockDown(a, b)
    }
    return maze
}

/// BFS from the top-left cell: the shortest path to the bottom-right one
func solve(_ maze: Maze) -> [Int] {
    var previous = Array(repeating: -1, count: maze.cellCount)
    var queue = [0], head = 0
    previous[0] = 0
    while head < queue.count {
        let cell = queue[head]
        head += 1
        for next in maze.exits(cell) where previous[next] == -1 {
            previous[next] = cell
            queue.append(next)
        }
    }
    var path = [maze.cellCount - 1]
    while path.last! != 0 { path.append(previous[path.last!]) }
    return path.reversed()
}

func draw(_ maze: Maze, path: [Int]) {
    let onPath = Set(path)
    print("+" + String(repeating: "---+", count: maze.columns))
    for r in 0..<maze.rows {
        var cells = "|", floor = "+"
        for c in 0..<maze.columns {
            let cell = r * maze.columns + c
            cells += (onPath.contains(cell) ? " o " : "   ") + (maze.openRight[r][c] ? " " : "|")
            floor += (maze.openDown[r][c] ? "   " : "---") + "+"
        }
        print(cells)
        print(floor)
    }
}

func stats(_ maze: Maze) -> (passages: Int, deadEnds: Int, pathLength: Int) {
    let passages = (0..<maze.cellCount).reduce(0) { $0 + maze.exits($1).count } / 2
    let deadEnds = (0..<maze.cellCount).filter { maze.exits($0).count == 1 }.count
    return (passages, deadEnds, solve(maze).count - 1)
}

var dice = Dice(seed: 10)
for (name, maze) in [("depth-first", depthFirstMaze(rows: 5, columns: 8, dice: &dice)),
                     ("Kruskal", kruskalMaze(rows: 5, columns: 8, dice: &dice))] {
    let s = stats(maze)
    print("\(name): \(s.passages) passages for \(maze.cellCount) cells, \(s.deadEnds) dead ends, path \(s.pathLength) steps")
    draw(maze, path: solve(maze))
}

// Texture over many mazes: 20 seeds of 20 × 20 each
var totals = (depthFirst: (0, 0), kruskal: (0, 0))
for seed in 1...20 {
    var d = Dice(seed: UInt64(seed))
    let a = stats(depthFirstMaze(rows: 20, columns: 20, dice: &d))
    let b = stats(kruskalMaze(rows: 20, columns: 20, dice: &d))
    totals.depthFirst = (totals.depthFirst.0 + a.deadEnds, totals.depthFirst.1 + a.pathLength)
    totals.kruskal = (totals.kruskal.0 + b.deadEnds, totals.kruskal.1 + b.pathLength)
}
print("20 × 20, average of 20 seeds: depth-first \(totals.depthFirst.0 / 20) dead ends, path \(totals.depthFirst.1 / 20);",
      "Kruskal \(totals.kruskal.0 / 20) dead ends, path \(totals.kruskal.1 / 20)")
```

What to notice:

- **39 passages for 40 cells, both times.** That's the spanning-tree count: n − 1 edges, and BFS reached the far corner, so the maze is connected. Kruskal knocked down 39 of the 67 internal walls; every other wall would have closed a loop, and union-find refused it.
- **The textures are different, and the numbers say so.** Depth-first search runs as far as it can before backing up, so it makes long corridors with few branches: on 20 × 20 grids, about 42 dead ends and a solution of about 153 steps out of a possible 399. Kruskal grows many small fragments all over the grid and joins them, so it makes lots of short dead ends (about 120) and a much more direct solution (about 55 steps).
- **The DFS has no recursion.** The stack is an array, so a huge maze needs a big array, not a deep call stack.
- **The solver doesn't care how the maze was made.** It only asks `exits(_:)`, so it works unchanged on any maze, including the ones with loops in the stretch goals.

## The SwiftUI layer

```swift title="MazeView.swift"
import MazeCore
import SwiftUI

struct MazeView: View {
    let maze: Maze
    let path: [Int]
    let player: Int

    var body: some View {
        Canvas { context, size in
            let side = min(size.width / CGFloat(maze.columns), size.height / CGFloat(maze.rows))
            func centre(_ cell: Int) -> CGPoint {
                CGPoint(x: (CGFloat(cell % maze.columns) + 0.5) * side, y: (CGFloat(cell / maze.columns) + 0.5) * side)
            }

            var walls = Path(CGRect(x: 0, y: 0, width: side * CGFloat(maze.columns), height: side * CGFloat(maze.rows)))
            for r in 0..<maze.rows {
                for c in 0..<maze.columns {
                    let x = CGFloat(c) * side, y = CGFloat(r) * side
                    if c < maze.columns - 1 && !maze.openRight[r][c] {
                        walls.move(to: CGPoint(x: x + side, y: y))
                        walls.addLine(to: CGPoint(x: x + side, y: y + side))
                    }
                    if r < maze.rows - 1 && !maze.openDown[r][c] {
                        walls.move(to: CGPoint(x: x, y: y + side))
                        walls.addLine(to: CGPoint(x: x + side, y: y + side))
                    }
                }
            }
            context.stroke(walls, with: .color(.primary), style: StrokeStyle(lineWidth: 2, lineCap: .round))

            var route = Path()
            route.addLines(path.map(centre))
            context.stroke(route, with: .color(.orange.opacity(0.7)), lineWidth: side / 4)

            let dot = CGRect(origin: centre(player), size: .zero).insetBy(dx: -side / 3, dy: -side / 3)
            context.fill(Path(ellipseIn: dot), with: .color(.accentColor))
        }
        .aspectRatio(CGFloat(maze.columns) / CGFloat(maze.rows), contentMode: .fit)
        .padding()
    }
}
```

All the walls go into one `Path` and are stroked once, which keeps even a 100 × 100 maze cheap to draw: one draw call instead of thousands of views.

Swiping moves the player one cell, if the passage is open:

```swift title="GameModel.swift"
import MazeCore
import Observation
import SwiftUI

@MainActor @Observable
final class GameModel {
    private(set) var maze: Maze
    private(set) var player = 0
    private(set) var moves = 0
    var isSolved: Bool { player == maze.cellCount - 1 }

    init(seed: UInt64, rows: Int, columns: Int) {
        var dice = Dice(seed: seed)
        maze = depthFirstMaze(rows: rows, columns: columns, dice: &dice)
    }

    func swipe(_ translation: CGSize) {
        let step: Int
        if abs(translation.width) > abs(translation.height) {
            step = translation.width > 0 ? 1 : -1
        } else {
            step = translation.height > 0 ? maze.columns : -maze.columns
        }
        let next = player + step
        guard maze.around(player).contains(next), maze.isOpen(player, next) else { return }
        player = next
        moves += 1
    }
}
```

The `around(player).contains(next)` check matters: from the last cell of a row, `player + 1` is the first cell of the next row, which isn't a neighbour at all. Attach it with `.gesture(DragGesture(minimumDistance: 20).onEnded { game.swipe($0.translation) })`.

## Stretch goals

- **Braid mazes.** Knock down one wall at each dead end to create loops. The maze is no longer a tree, several paths exist, and now BFS's guarantee of the *shortest* one matters. Compare BFS with DFS's first-found path.
- **Wilson's algorithm.** Depth-first search and Kruskal both favour certain shapes. Wilson's algorithm, built from loop-erased random walks, picks uniformly among *all* spanning trees of the grid. Implement it and compare its statistics with the other two.
- **Prim's algorithm** with random weights: another texture, with many short branches radiating from the start.
- **Other shapes.** Hexagonal or circular grids only change `around(_:)` and the drawing; the generators and the solver don't change at all. That's the payoff of separating the graph from its picture.
- **Tilt to play.** Use Core Motion's device attitude to roll a ball through the maze, with haptics when it hits a wall.
