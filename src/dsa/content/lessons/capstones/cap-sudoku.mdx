## Why it matters

Sudoku apps are a staple of the App Store, and every one of them needs two algorithms: a **solver**, to check answers and give hints, and a **generator**, to make an endless supply of puzzles that each have exactly one solution. Both are backtracking with good pruning, which you met in [Sudoku solver](/dsa/learn/bk-sudoku). This project adds the two things a real app needs on top: **constraint propagation**, so most puzzles solve with almost no guessing, and **solution counting**, so the generator can prove a puzzle is fair. You'll finish with a playable SwiftUI game with pencil marks, hints that explain themselves, undo, and puzzles that are reproducible from a seed.

## What you'll build

- `SudokuCore`, a package with a bitmask board, a solver (propagation plus most-constrained-cell backtracking), a solution counter that stops at 2, a seeded generator, and a difficulty rating.
- A SwiftUI game: tap a cell, enter digits or pencil marks, see conflicts, ask for a hint, undo, and start a new puzzle by difficulty.

Budget about two and a half hours: one for the core, one for the game, and the rest for hints and difficulty.

## The architecture

```text
                       ┌─────────────── SudokuCore (package, no UI) ───────────────┐
 seed, difficulty ───▶ │ Generator ── full grid ──▶ remove cells ──▶ count(limit: 2) │
                       │                                  ▲               │         │
                       │ Board: cells + 27 unit masks     │               ▼         │
                       │ Solver: propagate ─▶ most constrained cell ─▶ try digits   │
                       │ Difficulty: what did the solver need?                      │
                       └────────────────────────────────────────────────────────────┘
                                         │ puzzle, solution
                                         ▼
 GameModel (@Observable): givens, entries, notes, selection, undo stack
                                         │
                                         ▼
 BoardView (9 × 9 cells, conflicts highlighted) + NumberPad + HintBanner
```

- **The board stores 27 bitmasks**, one per row, column and box, with bit `d` set when digit `d` is placed in that unit. A cell's candidates are the digits missing from all three of its units: one `|`, one `~` and one `&`.
- **The solver copies the board** at each level of the search instead of undoing changes. A board is 81 cells plus 27 masks, so a copy is cheap, and propagation can fill dozens of cells per step without any undo bookkeeping.
- **The game model never solves anything itself.** It asks the core for the solution (to check entries), for a hint, and for new puzzles.

## Milestones

### 1. The bitmask board

Write `Board` with its cells, the 27 unit masks, `candidates(_:)` and `place(_:at:)`. Reject givens that clash (two 5s in a row) when a board is created.

- **Acceptance:** tests check the unit index of corner and middle cells, the candidates of a few cells in a known puzzle, and that clashing givens are rejected.
- **Exercises:** bitmasks as sets of digits, as in [Bitmasks for subsets and submasks](/dsa/learn/bits-subsets).

### 2. Propagation and search

Add `propagate()`: repeatedly fill every **naked single** (a cell with one candidate) and every **hidden single** (a digit that fits in only one cell of some unit), and report a contradiction when a cell has no candidates or a digit has nowhere to go. Then backtrack on the most constrained cell, copying the board for each guess.

- **Acceptance:** solves the 17-clue puzzle from the [Sudoku solver](/dsa/learn/bk-sudoku) practice problem; in a release build, 100 hard puzzles take well under a second in total.
- **Exercises:** constraint propagation and "fail first". Each forced placement removes options elsewhere, which forces more.

### 3. Counting solutions, with a limit

Make the search count solutions and stop as soon as it reaches a limit. The generator only needs to know "zero, one, or more than one", so it asks with a limit of 2.

- **Acceptance:** returns 0 for an impossible puzzle, 1 for a proper puzzle, and 2 for an empty grid, instantly, although an empty grid has billions of solutions.
- **Exercises:** early termination. A search for "is there a second solution?" can stop at the second.

### 4. The generator

Make a random full grid by running the solver on an empty board with each cell's candidates tried in a shuffled order. Then visit the 81 cells in a shuffled order, and remove each one unless that lets the puzzle have a second solution.

- **Acceptance:** the same seed always gives the same puzzle; for 20 seeds, every puzzle has exactly one solution, and removing any one of its clues allows a second.
- **Exercises:** randomised construction plus verification: a Las Vegas algorithm, random in its running path, always right in its result.

### 5. The game

An `@Observable` game model with the givens, the player's entries and pencil marks, the selected cell and an undo stack. A board view that thickens the lines between boxes, highlights the selected cell's row, column and box, and marks entries that clash. A number pad with a pencil toggle.

- **Acceptance:** you can play a whole puzzle; undo reverses entries and pencil marks in order; finishing shows a summary.
- **Exercises:** an undo stack of commands, as in [Undo and redo manager](/dsa/learn/ds-undo-redo).

### 6. Hints and difficulty

A hint runs one step of propagation and reports it in words: "Only 7 fits in row 3, column 5" (naked single) or "In box 4, only one cell can take a 2" (hidden single). Rate difficulty by what the solver needed: propagation alone is **easy**, a few guesses is **medium**, many is **hard**. Generate with different seeds until a puzzle of the requested rating appears.

- **Acceptance:** every hint is a correct move and its explanation can be checked by eye; the "easy" puzzles never need a guess.
- **Exercises:** using an algorithm's trace as well as its answer.

## Key code: propagate, count, generate

The board keeps 27 masks; `propagate()` fills forced cells until nothing changes; `search` picks the most constrained cell, tries each candidate on a copy, and stops counting at `limit`. The generator is the same search with shuffled digits, followed by cell removal with a uniqueness check after each one.

```swift run
// The course's seeded generator: the same seed gives the same puzzle on every run
struct Dice {
    private var state: UInt64
    init(seed: UInt64) { state = seed }
    mutating func roll(_ range: ClosedRange<Int>) -> Int {
        state = state &* 6364136223846793005 &+ 1442695040888963407
        return range.lowerBound + Int((state >> 33) % UInt64(range.count))
    }
    mutating func shuffle<T>(_ items: inout [T]) {           // Fisher–Yates
        for i in stride(from: items.count - 1, to: 0, by: -1) {
            items.swapAt(i, roll(0...i))
        }
    }
}

// The 27 units: 9 rows, 9 columns, 9 boxes, each a list of 9 cell indexes (0...80)
let units: [[Int]] = (0..<9).map { r in (0..<9).map { r * 9 + $0 } }
    + (0..<9).map { c in (0..<9).map { $0 * 9 + c } }
    + (0..<9).map { b in (0..<9).map { (b / 3 * 3 + $0 / 3) * 9 + b % 3 * 3 + $0 % 3 } }

struct Board {
    var cells: [Int]                                   // 0 means empty
    var used = Array(repeating: 0, count: 27)          // per unit, bit d set when digit d is placed

    init(_ cells: [Int]) {
        self.cells = Array(repeating: 0, count: 81)
        for (i, digit) in cells.enumerated() where digit != 0 {
            place(digit, at: i)
        }
    }

    static func unitsOf(_ i: Int) -> (Int, Int, Int) {
        (i / 9, 9 + i % 9, 18 + i / 27 * 3 + i % 9 / 3)
    }

    /// Bits 1...9 set for the digits that could still go in cell i
    func candidates(_ i: Int) -> Int {
        let (r, c, b) = Board.unitsOf(i)
        return ~(used[r] | used[c] | used[b]) & 0b11_1111_1110
    }

    mutating func place(_ digit: Int, at i: Int) {
        cells[i] = digit
        let (r, c, b) = Board.unitsOf(i)
        for unit in [r, c, b] { used[unit] |= 1 << digit }
    }

    /// Fills forced cells until nothing changes. Returns false on a contradiction.
    mutating func propagate() -> Bool {
        var changed = true
        while changed {
            changed = false
            for i in 0..<81 where cells[i] == 0 {               // naked single: one digit fits the cell
                let mask = candidates(i)
                if mask == 0 { return false }
                if mask.nonzeroBitCount == 1 {
                    place(mask.trailingZeroBitCount, at: i)
                    changed = true
                }
            }
            for (u, unit) in units.enumerated() {               // hidden single: one cell fits the digit
                for digit in 1...9 where used[u] & (1 << digit) == 0 {
                    let spots = unit.filter { cells[$0] == 0 && candidates($0) & (1 << digit) != 0 }
                    if spots.isEmpty { return false }
                    if spots.count == 1 {
                        place(digit, at: spots[0])
                        changed = true
                    }
                }
            }
        }
        return true
    }
}

var guesses = 0

/// Counts solutions, stopping at `limit`. Copies the board per call, so undoing is free.
func search(_ start: Board, limit: Int, first: inout [Int]?, order: (inout [Int]) -> Void) -> Int {
    var board = start
    guard board.propagate() else { return 0 }
    var best = -1, fewest = 10
    for i in 0..<81 where board.cells[i] == 0 {                 // the most constrained cell
        let count = board.candidates(i).nonzeroBitCount
        if count < fewest { (best, fewest) = (i, count) }
    }
    if best == -1 {
        if first == nil { first = board.cells }
        return 1
    }
    var digits = (1...9).filter { board.candidates(best) & (1 << $0) != 0 }
    order(&digits)
    var found = 0
    for digit in digits where found < limit {
        guesses += 1
        var next = board
        next.place(digit, at: best)
        found += search(next, limit: limit - found, first: &first, order: order)
    }
    return found
}

func solutions(_ cells: [Int], limit: Int) -> Int {
    var ignored: [Int]? = nil
    return search(Board(cells), limit: limit, first: &ignored, order: { _ in })
}

/// A random full grid (the solver with shuffled digits), then remove cells while the answer stays unique
func generate(seed: UInt64) -> (puzzle: [Int], solution: [Int]) {
    var dice = Dice(seed: seed)
    var full: [Int]? = nil
    _ = search(Board(Array(repeating: 0, count: 81)), limit: 1, first: &full, order: { dice.shuffle(&$0) })
    var puzzle = full!
    var order = Array(0..<81)
    dice.shuffle(&order)
    for i in order {
        let kept = puzzle[i]
        puzzle[i] = 0
        if solutions(puzzle, limit: 2) != 1 {
            puzzle[i] = kept                                     // removing it allowed a second answer
        }
    }
    return (puzzle, full!)
}

func show(_ cells: [Int]) {
    for r in 0..<9 {
        print(cells[(r * 9)..<(r * 9 + 9)].map { $0 == 0 ? "." : String($0) }.joined(separator: " "))
    }
}

let (puzzle, solution) = generate(seed: 74)
show(puzzle)
print("clues:", puzzle.filter { $0 != 0 }.count, "solutions:", solutions(puzzle, limit: 2))

var solved: [Int]? = nil
guesses = 0
_ = search(Board(puzzle), limit: 1, first: &solved, order: { _ in })
print("solved matches the generated grid:", solved! == solution, "guesses:", guesses)

var oneTooMany = puzzle
let lastClue = oneTooMany.lastIndex { $0 != 0 }!
oneTooMany[lastClue] = 0
print("without its last clue:", solutions(oneTooMany, limit: 2), "solutions (stopped counting at 2)")
```

```output
. 4 . . . 2 . 1 .
. 6 . . . . . . 5
. 1 6 . 7 . 9 . .
. 3 . . . . . 8 7
. . . 8 4 . . . .
. . . . . 9 1 3 .
. . . . 8 1 . . .
. 2 . . . . . . .
clues: 23 solutions: 1
solved matches the generated grid: true guesses: 4

```

What to notice:

- **23 clues, one solution, and only 4 guesses** to solve it. Propagation does nearly all the work: each placement narrows other cells' candidates until most of them are forced.
- **The solver doubles as a generator.** Running it on an empty board with digits in a shuffled order gives a random complete grid. With `order: { _ in }`, the same function solves puzzles deterministically.
- **The puzzle is minimal.** Each clue that survived did so because removing it, at its turn, allowed a second solution. Removing clues can only add solutions, never take them away, so removing it later would still allow one. The last line checks this for the last clue.
- **Counting stops at 2.** "Without its last clue" may have dozens of solutions, but the generator only needs to know there's more than one, so it stops at the second.
- **`Dice` shuffles with its own Fisher–Yates.** Swift's `shuffle(using:)` with a seeded generator also repeats, but the standard library doesn't document exactly which random numbers its shuffle draws, so a future Swift could produce different puzzles from the same seed. Tests that pin exact puzzles are safer with your own shuffle.

## The SwiftUI layer

```swift title="GameModel.swift"
import Observation
import SudokuCore

@MainActor @Observable
final class GameModel {
    enum Move {
        case entry(cell: Int, old: Int, new: Int)
        case note(cell: Int, digit: Int)                     // toggling twice undoes it
    }

    let givens: [Int]
    let solution: [Int]
    private(set) var entries: [Int]
    private(set) var notes = Array(repeating: 0, count: 81)  // pencil marks as bitmasks, like the solver's
    var selected: Int?
    var pencil = false
    private var history: [Move] = []

    init(seed: UInt64) {
        let generated = generate(seed: seed)
        givens = generated.puzzle
        solution = generated.solution
        entries = generated.puzzle
    }

    func enter(_ digit: Int) {
        guard let cell = selected, givens[cell] == 0 else { return }
        if pencil {
            notes[cell] ^= 1 << digit
            history.append(.note(cell: cell, digit: digit))
        } else {
            history.append(.entry(cell: cell, old: entries[cell], new: digit))
            entries[cell] = digit
        }
    }

    func undo() {
        switch history.popLast() {
        case .entry(let cell, let old, _): entries[cell] = old
        case .note(let cell, let digit): notes[cell] ^= 1 << digit
        case nil: break
        }
    }

    func isWrong(_ cell: Int) -> Bool { entries[cell] != 0 && entries[cell] != solution[cell] }
    var isSolved: Bool { entries == solution }
}
```

```swift title="BoardView.swift"
import SwiftUI

struct BoardView: View {
    @Bindable var game: GameModel

    var body: some View {
        Grid(horizontalSpacing: 1, verticalSpacing: 1) {
            ForEach(0..<9, id: \.self) { row in
                GridRow {
                    ForEach(0..<9, id: \.self) { column in
                        let cell = row * 9 + column
                        CellView(digit: game.entries[cell], notes: game.notes[cell],
                                 isGiven: game.givens[cell] != 0, isWrong: game.isWrong(cell),
                                 isSelected: game.selected == cell)
                            .onTapGesture { game.selected = cell }
                            .padding(.trailing, column % 3 == 2 && column < 8 ? 2 : 0)
                            .padding(.bottom, row % 3 == 2 && row < 8 ? 2 : 0)
                    }
                }
            }
        }
        .aspectRatio(1, contentMode: .fit)
        .background(Color.primary)
    }
}
```

The extra padding after every third row and column lets the dark background show through as the thicker lines between boxes. `CellView` shows the digit, or a 3 × 3 mini-grid of pencil marks read from the bitmask.

## Tests to write

```swift title="Tests/SudokuCoreTests/GeneratorTests.swift"
import Testing
@testable import SudokuCore

@Suite struct GeneratorTests {
    @Test("Generated puzzles are unique and minimal", arguments: Array(1...20) as [UInt64])
    func uniqueAndMinimal(seed: UInt64) {
        let (puzzle, solution) = generate(seed: seed)
        #expect(solutions(puzzle, limit: 2) == 1)
        for cell in puzzle.indices where puzzle[cell] != 0 {
            var fewer = puzzle
            fewer[cell] = 0
            #expect(solutions(fewer, limit: 2) == 2, "clue at \(cell) isn't needed")
        }
        for cell in puzzle.indices where puzzle[cell] != 0 {
            #expect(solution[cell] == puzzle[cell])              // the solution keeps every given
        }
    }

    @Test("The same seed gives the same puzzle")
    func reproducible() {
        #expect(generate(seed: 74).puzzle == generate(seed: 74).puzzle)
        #expect(generate(seed: 74).puzzle != generate(seed: 75).puzzle)
    }
}
```

More to cover:

- **A valid solution** has every digit exactly once in each of the 27 units: check with the masks, which must all equal `0b11_1111_1110`.
- **Known answers:** a few published puzzles with their solutions, including the 17-clue one.
- **Contradictions:** a puzzle where propagation finds a cell with no candidates returns 0 solutions without guessing.
- **Hints are moves of the solution:** for 100 random positions taken from real games, the hinted digit equals the solution's digit in that cell.

## Stretch goals

- **Symmetric puzzles.** Remove cells in pairs, `i` and `80 - i`, for the rotational symmetry printed puzzles traditionally have. Fewer removals succeed, so expect a few more clues.
- **More techniques.** Naked pairs, pointing pairs and X-wings make hints richer and the difficulty rating closer to how people actually solve. Rate by the hardest technique needed rather than by guesses.
- **Dancing links.** Sudoku is an exact cover problem; implement Knuth's Algorithm X with dancing links and compare its speed with your solver on a few thousand puzzles.
- **A daily puzzle.** Derive the seed from the date, so every player gets the same puzzle each day without a server.

## Done when

- The solver uses propagation and the most constrained cell, and solves hard puzzles in milliseconds in a release build.
- The solution counter stops at its limit, and the generator proves each puzzle unique.
- Seeds reproduce puzzles exactly, and tests show generated puzzles are unique and minimal.
