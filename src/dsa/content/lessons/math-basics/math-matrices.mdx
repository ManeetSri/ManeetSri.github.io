## Why it matters

A photo is a grid of pixels. A chessboard, a spreadsheet and a game level are grids too. In iOS, every `CGAffineTransform` that rotates or scales a view is a small matrix, and graphics hardware multiplies matrices millions of times a second. In DSA, grids are a whole topic of their own (M19), graphs can be stored as matrices (Part VI), and dynamic programming fills in tables. This lesson covers the maths: what a matrix is, how to add, transpose and multiply matrices in Swift, and a glimpse of a beautiful trick that computes Fibonacci numbers using matrix powers.

## What a matrix is

A **matrix** is a rectangle of numbers arranged in rows and columns. A matrix with r rows and c columns is an **r × c** matrix, always rows first:

```text
A = | 1  0  2 |      a 2 × 3 matrix
    | 0  3  1 |
```

The entry in row i and column j is written A[i][j]. In code we count from 0, so here A[0][2] is 2 and A[1][1] is 3.

In Swift, a matrix is an array of rows, `[[Int]]`, exactly the 2D arrays from [2D arrays](/dsa/learn/swift-2d-arrays). `matrix[i]` is row i, and `matrix[i][j]` is the entry in that row's column j:

```swift run
let a = [[1, 0, 2], [0, 3, 1]]
print(a.count, a[0].count)
print(a[0][2], a[1][1])

var zeros = Array(repeating: Array(repeating: 0, count: 3), count: 2)
zeros[1][2] = 7
print(zeros)
```

```output
2 3
2 3
[[0, 0, 0], [0, 0, 7]]
```

`a.count` is the number of rows and `a[0].count` the number of columns.

## Adding and transposing

Two matrices of the **same shape** add entry by entry:

```swift run
let a = [[1, 2], [3, 4]]
let b = [[5, 6], [7, 8]]
let sum = zip(a, b).map { rowA, rowB in
    zip(rowA, rowB).map { $0 + $1 }
}
print(sum)
```

```output
[[6, 8], [10, 12]]
```

The outer `zip` pairs up the rows; the inner `zip` pairs up the entries within each pair of rows.

The **transpose** of a matrix, written Aᵀ, flips it along its diagonal: row i becomes column i. An r × c matrix becomes c × r:

```swift run
func transpose(_ m: [[Int]]) -> [[Int]] {
    var t = Array(repeating: Array(repeating: 0, count: m.count), count: m[0].count)
    for i in 0..<m.count {
        for j in 0..<m[0].count {
            t[j][i] = m[i][j]
        }
    }
    return t
}

print(transpose([[1, 0, 2], [0, 3, 1]]))
```

```output
[[1, 0], [0, 3], [2, 1]]
```

Notice the result has `m[0].count` rows of `m.count` entries each: the shape swaps.

## Multiplying matrices

Matrix multiplication isn't entry by entry. To get the entry in row i, column j of A × B, walk along **row i of A** and down **column j of B** at the same time, multiply the pairs, and add up:

```text
| 1  2 |   | 5  6 |   | 1×5 + 2×7   1×6 + 2×8 |   | 19  22 |
| 3  4 | × | 7  8 | = | 3×5 + 4×7   3×6 + 4×8 | = | 43  50 |
```

The top-left 19 comes from row 0 of A, (1, 2), and column 0 of B, (5, 7): 1 × 5 + 2 × 7 = 19.

For this to work, a row of A must be as long as a column of B. So **A must have as many columns as B has rows**. An r × k matrix times a k × c matrix gives an r × c matrix. The inner sizes, k and k, must match, and the outer sizes give the shape of the answer.

```swift run
func multiply(_ a: [[Int]], _ b: [[Int]]) -> [[Int]] {
    let rows = a.count
    let inner = b.count
    let cols = b[0].count
    var c = Array(repeating: Array(repeating: 0, count: cols), count: rows)
    for i in 0..<rows {
        for j in 0..<cols {
            for t in 0..<inner {
                c[i][j] += a[i][t] * b[t][j]
            }
        }
    }
    return c
}

print(multiply([[1, 2], [3, 4]], [[5, 6], [7, 8]]))
print(multiply([[1, 0, 2], [0, 3, 1]], [[1, 2], [0, 1], [4, 0]]))
```

```output
[[19, 22], [43, 50]]
[[9, 2], [4, 3]]
```

The second line multiplies a 2 × 3 matrix by a 3 × 2 one, giving 2 × 2. The three nested loops do r × c × k multiplications, so multiplying two n × n matrices is **O(n³)**. For n = 1,000 that's a billion steps, which is slow. Cleverer algorithms exist, but in DSA the matrices you multiply are usually tiny.

### Order matters

With numbers, 3 × 5 = 5 × 3. With matrices, **A × B and B × A are usually different**:

```swift run
func multiply(_ a: [[Int]], _ b: [[Int]]) -> [[Int]] {
    var c = Array(repeating: Array(repeating: 0, count: b[0].count), count: a.count)
    for i in 0..<a.count {
        for j in 0..<b[0].count {
            for t in 0..<b.count {
                c[i][j] += a[i][t] * b[t][j]
            }
        }
    }
    return c
}

let a = [[1, 2], [3, 4]]
let b = [[5, 6], [7, 8]]
print(multiply(a, b))
print(multiply(b, a))
```

```output
[[19, 22], [43, 50]]
[[23, 34], [31, 46]]
```

In iOS terms, "rotate then move" and "move then rotate" put a view in different places, and that's matrix order at work.

What *does* hold is that matrix multiplication is **associative**: (A × B) × C = A × (B × C). You can regroup a chain of multiplications freely, as long as you don't reorder it. That's exactly what fast exponentiation needs.

## The identity matrix

The **identity matrix** I has 1s down its main diagonal and 0s everywhere else. It's the matrix version of the number 1: I × A = A × I = A for any square matrix A of the same size.

```swift run
func identity(_ n: Int) -> [[Int]] {
    var m = Array(repeating: Array(repeating: 0, count: n), count: n)
    for i in 0..<n {
        m[i][i] = 1
    }
    return m
}

print(identity(3))
```

```output
[[1, 0, 0], [0, 1, 0], [0, 0, 1]]
```

As a power of a number starts from 1, a power of a matrix starts from I. A⁰ = I.

## Fibonacci with matrices: a preview

The Fibonacci numbers start 0, 1, 1, 2, 3, 5, 8, 13…, each the sum of the two before. Here's a surprising fact. Take the matrix

```text
M = | 1  1 |
    | 1  0 |
```

Its powers contain the Fibonacci numbers: Mⁿ is `[[F(n+1), F(n)], [F(n), F(n−1)]]`. Watch them appear:

```swift run
func multiply(_ a: [[Int]], _ b: [[Int]]) -> [[Int]] {
    var c = Array(repeating: Array(repeating: 0, count: b[0].count), count: a.count)
    for i in 0..<a.count {
        for j in 0..<b[0].count {
            for t in 0..<b.count {
                c[i][j] += a[i][t] * b[t][j]
            }
        }
    }
    return c
}

let m = [[1, 1], [1, 0]]
var power = m
for n in 2...6 {
    power = multiply(power, m)
    print(n, power)
}
```

```output
2 [[2, 1], [1, 1]]
3 [[3, 2], [2, 1]]
4 [[5, 3], [3, 2]]
5 [[8, 5], [5, 3]]
6 [[13, 8], [8, 5]]
```

Why? Multiplying by M turns a pair (F(n+1), F(n)) into (F(n+1) + F(n), F(n+1)), which is (F(n+2), F(n+1)): one step of the Fibonacci rule. Raising M to the nth power takes n steps at once.

Now combine this with [Fast exponentiation](/dsa/learn/math-fast-power). Because matrix multiplication is associative, the same square-and-multiply loop works, with the identity in place of 1. Mⁿ then takes O(log n) multiplications of 2 × 2 matrices, and reducing modulo 10⁹ + 7 keeps the entries small:

```swift run
let mod = 1_000_000_007

func multiplyMod(_ a: [[Int]], _ b: [[Int]]) -> [[Int]] {
    var c = [[0, 0], [0, 0]]
    for i in 0..<2 {
        for j in 0..<2 {
            for t in 0..<2 {
                c[i][j] = (c[i][j] + a[i][t] * b[t][j]) % mod
            }
        }
    }
    return c
}

func fibonacci(_ n: Int) -> Int {
    var result = [[1, 0], [0, 1]]
    var square = [[1, 1], [1, 0]]
    var e = n
    while e > 0 {
        if e % 2 == 1 {
            result = multiplyMod(result, square)
        }
        square = multiplyMod(square, square)
        e /= 2
    }
    return result[0][1]
}

print(fibonacci(10))
print(fibonacci(1000))
print(fibonacci(1_000_000_000_000_000_000))
```

```output
55
517691607
209783453
```

The quintillionth Fibonacci number, modulo 10⁹ + 7, in about 60 matrix squarings. The same idea speeds up any sequence where each term is a fixed combination of the previous few. M66 develops it properly as **matrix exponentiation**. For now, enjoy the preview: three lessons of this module (modular arithmetic, fast power and matrices) working together.

<Callout kind="gotcha" title="Common mistakes with matrices">
- **Shapes that don't fit.** A × B needs A's column count to equal B's row count. Check before multiplying, or the inner loop reads past the end of a row and crashes.
- **Rows first.** `m[i][j]` is row i, column j. On a screen, rows go down (y) and columns go across (x), so `grid[y][x]`, not `grid[x][y]`.
- **Assuming A × B = B × A.** It's usually false, so keep the order exactly as the problem states it.
</Callout>

<Callout kind="tip" title="Swift tip: repeating rows is safe">
In Python, `[[0] * 3] * 2` makes two references to the *same* row, so changing one changes both. Swift arrays are values, so `Array(repeating: row, count: 2)` gives two independent copies, as you saw in [Collections are values](/dsa/learn/swift-collections-are-values).
</Callout>
