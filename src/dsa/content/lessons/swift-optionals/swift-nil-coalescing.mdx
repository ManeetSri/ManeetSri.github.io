## Why it matters

Often the right response to a missing value is simply a sensible default: no nickname means "Guest", no saved volume means 50, a word you haven't counted yet has a count of 0. The `??` operator says that in one short expression. In DSA you'll use it every time you count things with a dictionary.

## The ?? operator

`a ?? b` means "the value inside `a`, or `b` if `a` is nil". It's called the **nil-coalescing operator**:

```swift run
let savedName: String? = nil
let displayName = savedName ?? "Guest"
print("Welcome, \(displayName)")

let typedAge = Int("29") ?? 0
let badAge = Int("old") ?? 0
print(typedAge, badAge)
```

```output
Welcome, Guest
29 0
```

The important detail is the type of the result. `savedName` is a `String?`, but `savedName ?? "Guest"` is a plain `String`, because whichever side is chosen, there's definitely a string. That's what makes `??` so convenient: it unwraps and supplies a default in one step, and what comes out is never optional.

It's a shorter way of writing an `if let` with an `else`:

```swift
let displayName: String
if let savedName {
    displayName = savedName
} else {
    displayName = "Guest"
}
```

## Counting with a dictionary

Here's the use you'll see most in DSA. To count how often each word appears, look up the current count, treat a missing word as 0, add 1 and store the result:

```swift run
let votes = ["tea", "coffee", "tea", "water", "tea", "coffee"]
var counts: [String: Int] = [:]

for vote in votes {
    counts[vote] = (counts[vote] ?? 0) + 1
}

for (drink, count) in counts.sorted(by: <) {
    print("\(drink): \(count)")
}
```

```output
coffee: 2
tea: 3
water: 1
```

`[:]` is an empty dictionary. The first time `"tea"` appears, `counts["tea"]` is nil, so `?? 0` supplies 0 and the count becomes 1. After that, the lookup finds the stored count. This **frequency counting** pattern appears in hundreds of problems, from finding duplicates to checking whether two words are anagrams. (Swift also has a built-in shortcut for it, `counts[vote, default: 0] += 1`, which you'll meet in M07.)

## Chaining defaults

You can chain `??` to try several optionals in turn. The first one that holds a value wins:

```swift run
let userSetting: Int? = nil
let teamSetting: Int? = 14
let fontSize = userSetting ?? teamSetting ?? 12
print(fontSize)
```

```output
14
```

The user didn't choose a size, so Swift tries the team's setting, which exists. If both were nil, the final default, 12, would be used.

## The default isn't computed unless it's needed

The right-hand side of `??` only runs when the left side is nil. Swift skips it otherwise, just as `&&` and `||` skip their right side when the answer is already known. This rarely matters for a simple value like `0`, but it means an expensive default costs nothing when it isn't used.

## Both sides must match

The default has to be the same type as the value inside the optional. An `Int?` needs an `Int` default:

```swift
let pages: Int? = nil
let label = pages ?? "unknown"   // error
```

```text title="What you'll see"
error: binary operator '??' cannot be applied to operands of type 'Int?' and 'String'
```

If you want text either way, convert first. One way is to turn the number into text with optional `map`, which you'll meet later in this module. Another is to keep it simple with `if let`.

<Callout kind="gotcha" title="Swift gotcha: ?? binds loosely">
`??` has **lower** precedence than arithmetic, so `count ?? 0 + 1` means `count ?? (0 + 1)`, not `(count ?? 0) + 1`. When `count` holds 5, it gives 5, not 6. Whenever you do arithmetic with the result of `??`, put the `??` part in parentheses.
</Callout>

```swift run
let count: Int? = 5

print(count ?? 0 + 1)
print((count ?? 0) + 1)
```

```output
5
6
```

The first line reads as "count, or else 1", which is why the counting loop above wraps `(counts[vote] ?? 0)` in parentheses.

## Choose defaults that are honest

A default should be a value that's *genuinely correct* when the real one is missing. A missing word count really is 0. A missing nickname really can be shown as "Guest".

Be careful when no default is truly right. If a product's price is missing, `price ?? 0` quietly gives it away for free. In cases like that, it's better to handle the missing value explicitly with `if let` or `guard let`, or to return an optional and let the caller decide.
