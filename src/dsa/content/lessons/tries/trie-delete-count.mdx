## Why it matters

A search box often says how many results a prefix has before it lists them: "Ca: 23 contacts". A contacts app has to forget a name when you delete it, and a word game has to take a word out of play once it's used. Both need two operations the basic trie doesn't have yet: **counting the words under a prefix** quickly, and **removing a word** without leaving junk behind. One extra number per node handles both.

## Counting words under a prefix

The direct way: walk to the prefix's node, then visit every node below it and count the end-of-word flags. That's correct, but it costs O(size of the subtree). For a prefix like "s" in an English dictionary, that's a big chunk of the whole trie, every time you ask.

Better: let every node remember how many stored words **pass through** it, meaning words that end at the node or anywhere below it. Call it `passCount`. Then the answer for a prefix is the `passCount` of its node, found in O(L).

Keeping the counts right is easy. When a new word goes in, every node on its path, the root included, gains one word passing through, so `insert` adds 1 to each `passCount` it walks past. The one trap is a word that's already stored: inserting it again mustn't change any count. So check first:

```swift run
final class CountingTrie {
    final class Node {
        var children: [Character: Node] = [:]
        var isWord = false
        var passCount = 0                        // stored words that end here or below
    }

    private let root = Node()

    func search(_ word: String) -> Bool {
        node(for: word)?.isWord ?? false
    }

    func insert(_ word: String) {
        if search(word) { return }               // already stored: no count may change
        var node = root
        node.passCount += 1
        for character in word {
            if node.children[character] == nil {
                node.children[character] = Node()
            }
            node = node.children[character]!
            node.passCount += 1
        }
        node.isWord = true
    }

    func count(withPrefix prefix: String) -> Int {
        node(for: prefix)?.passCount ?? 0
    }

    private func node(for text: String) -> Node? {
        var node = root
        for character in text {
            guard let next = node.children[character] else { return nil }
            node = next
        }
        return node
    }
}

let trie = CountingTrie()
for word in ["car", "card", "care", "careful", "cat", "dog", "car"] {
    trie.insert(word)
}
for prefix in ["", "c", "car", "care", "cards", "d"] {
    print("\"\(prefix)\":", trie.count(withPrefix: prefix))
}
```

```output
"": 6
"c": 5
"car": 4
"care": 2
"cards": 0
"d": 1
```

What to notice:

- The second "car" changed nothing, so the root's count, the answer for the empty prefix, is 6 words, not 7.
- "car" counts itself as well as card, care and careful: a word starts with itself.
- "cards" has no node, so the walk falls off and the answer is 0.

If you want to store **duplicates**, like a bag of words where "car" can be in twice, replace the `isWord` flag with an `endCount` and drop the check: every insert then adds 1 along the path and 1 to `endCount`. This module's practice problem works that way.

## Deleting the lazy way

The tempting way to delete a word: walk to its node and set `isWord = false`. Searches for the word now fail, so it looks done. But the nodes it created are still there:

```swift run
final class Node {
    var children: [Character: Node] = [:]
    var isWord = false
}

let root = Node()

func insert(_ word: String) {
    var node = root
    for character in word {
        if node.children[character] == nil {
            node.children[character] = Node()
        }
        node = node.children[character]!
    }
    node.isWord = true
}

func walk(_ text: String) -> Node? {
    var node = root
    for character in text {
        guard let next = node.children[character] else { return nil }
        node = next
    }
    return node
}

func countNodes(_ node: Node) -> Int {
    node.children.values.reduce(0) { $0 + 1 + countNodes($1) }
}

insert("car")
insert("cart")
walk("cart")?.isWord = false                     // "delete" cart by clearing its flag
print("search cart:", walk("cart")?.isWord ?? false)
print("startsWith cart:", walk("cart") != nil)
print("nodes below the root:", countNodes(root))
```

```output
search cart: false
startsWith cart: true
nodes below the root: 4
```

`startsWith("cart")` still says yes, though no stored word starts with "cart": a wrong answer. And the "t" node is dead weight. In a trie where words come and go, such as recent searches, dead branches pile up forever.

## Deleting properly: three cases

When you remove a word, one of three things is true:

| Case | Example, with car and cart stored | What to do |
| --- | --- | --- |
| The word isn't stored | remove "ca" | nothing, and report false |
| Its node has other words below it | remove "car" | clear the flag; every node is still needed |
| Part of its path is used by no other word | remove "cart" | clear the flag and cut that part off |

Pass counts tell you exactly where the unused part begins. Walk down the word, subtracting 1 from each node's `passCount`. If a node's count reaches 0, no stored word goes through it any more, so none goes through anything below it either. Remove it from its parent's children, and the whole branch goes at once:

```swift
func remove(_ word: String) -> Bool {
    guard search(word) else { return false }     // check first, or the counts go wrong
    var node = root
    node.passCount -= 1
    for character in word {
        let child = node.children[character]!
        child.passCount -= 1
        if child.passCount == 0 {
            node.children[character] = nil       // no other word uses this branch: cut it off
            return true
        }
        node = child
    }
    node.isWord = false                          // still needed by longer words: only unmark it
    return true
}
```

The check at the top matters. Without it, removing "ca" from a trie holding "car" and "cat" would subtract 1 from the root, "c" and "a", then report success: the trie would claim one word starts with "ca" when there are two. Removing "cab" would crash on the force unwrap. With the check, the force unwrap is safe: the search has already proved every child exists.

Watch it work on four words:

```swift run
final class Node {
    var children: [Character: Node] = [:]
    var isWord = false
    var passCount = 0
}

let root = Node()

func walk(_ text: String) -> Node? {
    var node = root
    for character in text {
        guard let next = node.children[character] else { return nil }
        node = next
    }
    return node
}

func insert(_ word: String) {
    if walk(word)?.isWord == true { return }
    var node = root
    node.passCount += 1
    for character in word {
        if node.children[character] == nil {
            node.children[character] = Node()
        }
        node = node.children[character]!
        node.passCount += 1
    }
    node.isWord = true
}

func remove(_ word: String) -> Bool {
    guard walk(word)?.isWord == true else { return false }
    var node = root
    node.passCount -= 1
    for character in word {
        let child = node.children[character]!
        child.passCount -= 1
        if child.passCount == 0 {
            node.children[character] = nil
            return true
        }
        node = child
    }
    node.isWord = false
    return true
}

func countNodes(_ node: Node) -> Int {
    node.children.values.reduce(0) { $0 + 1 + countNodes($1) }
}

for word in ["car", "cart", "care", "dog"] {
    insert(word)
}
print("start: nodes", countNodes(root))
for word in ["cart", "ca", "car", "dog", "care"] {
    let removed = remove(word)
    print("remove \(word): \(removed), nodes \(countNodes(root)), words under car: \(walk("car")?.passCount ?? 0)")
}
```

```output
start: nodes 8
remove cart: true, nodes 7, words under car: 2
remove ca: false, nodes 7, words under car: 2
remove car: true, nodes 7, words under car: 1
remove dog: true, nodes 4, words under car: 1
remove care: true, nodes 0, words under car: 0
```

Step through the same removals. The number beside each node is its pass count, and red is the branch about to be cut:

```visual trie
words: [car, cart, care, dog]
remove: [cart, ca, car, dog, care]
```

Each line shows one of the cases. "cart" loses its private "t". "ca" was never a word, so nothing changes. "car" keeps every node, because "care" still runs through them. "dog" takes its three nodes with it. And when "care" goes, the last word under "c", the whole branch disappears at once, from its top node down.

Removal is **O(L)**: one walk to check, one walk to subtract. Afterwards the trie is exactly what it would be if the word had never been added.

## Pruning without counts

If your nodes don't have pass counts, you can still prune, with recursion from [Base case and recursive case](/dsa/learn/rec-what-is-recursion). Go down to the word's end and clear its flag. Then, as each call returns, delete the child it came from if that child now has no flag and no children:

```swift
/// Returns true when the caller should delete `node`: it ends no word and leads nowhere.
func remove(_ letters: [Character], at depth: Int, from node: Node) -> Bool {
    if depth == letters.count {
        node.isWord = false
    } else if let child = node.children[letters[depth]], remove(letters, at: depth + 1, from: child) {
        node.children[letters[depth]] = nil
    }
    return !node.isWord && node.children.isEmpty
}
```

Call it with `remove(Array(word), at: 0, from: root)` after checking that the word is stored. It's O(L) too, and elegant. But without pass counts, counting by prefix goes back to visiting the whole subtree, so most real tries keep the count: one integer per node buys both operations.

<Callout kind="gotcha" title="The two slips that corrupt counts">
**Counting a duplicate twice.** If `insert` adds to every `passCount` without first checking whether the word is stored, inserting "car" twice makes the trie claim two words start with "car". Check first, or store an `endCount` on purpose.

**Subtracting for a word that isn't there.** Removing "ca" when only "car" is stored must change nothing. Always confirm the word exists before the subtracting walk.
</Callout>
