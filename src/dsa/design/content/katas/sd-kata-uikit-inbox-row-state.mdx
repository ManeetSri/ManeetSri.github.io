An inbox cell shows a sender, a subject, a preview, an age, an unread dot, a couple of symbols, and reads one sentence to VoiceOver. Every one of those involves a decision: what to show when there's no name, how to clean up a preview, when "5m" becomes "1h". Put those decisions in the cell and they're untested and copied to the next screen that lists messages. Write them as one pure mapper, so the cell only copies values into its views.

`UIKitInboxRowMapper.row(for:now:) -> RowState`

Given a `Message` and the current time, return the `RowState` a cell shows:

- **`id`**: the message's identifier.
- **`sender`**: the sender's name with surrounding whitespace and newlines trimmed, or the address if the trimmed name is empty.
- **`subject`**: the subject, trimmed, or `(No subject)` if it's empty.
- **`preview`**: the body with every run of whitespace (spaces, tabs, newlines) turned into one space, and trimmed. If that's longer than 80 characters, keep the first 79, drop any trailing spaces, and add `…`.
- **`age`**: from the seconds between `sentAt` and `now`, the largest whole unit that fits: under 60 seconds (or in the future) is `Now`, then `Xm` for minutes, `Xh` for hours, `Xd` for days, and `Xw` for weeks from 7 days on. Round down.
- **`showsUnreadDot`**: whether the message is unread.
- **`symbols`**: `flag.fill` if flagged, then `paperclip` if it has attachments.
- **`accessibilityLabel`**: these parts joined with `, `: `Unread` (if unread), `Flagged` (if flagged), `From` and the sender, the subject, the age spoken (`Just now`, or `5 minutes ago`, `1 hour ago`, `2 days ago`, `3 weeks ago`), and `1 attachment` or `2 attachments` if there are any.

The short ages and spoken phrases are fixed English here so the rules can be tested exactly; a shipping app would localise them in the same place.

## Examples

| Message | Row |
| --- | --- |
| Name `"  Anna Lee \n"`, subject `"Lunch on Friday?"`, sent 5 minutes ago, unread, flagged, 2 attachments | sender `Anna Lee`, age `5m`, unread dot, symbols `[flag.fill, paperclip]`, label `Unread, Flagged, From Anna Lee, Lunch on Friday?, 5 minutes ago, 2 attachments` |
| Name `""`, address `anna@example.com`, subject `" "`, sent 10 seconds ago, read | sender `anna@example.com`, subject `(No subject)`, age `Now`, label `From anna@example.com, (No subject), Just now` |
| Body `"Hi Anna,\n\n  Lunch  on\tFriday?  "` | preview `Hi Anna, Lunch on Friday?` |
| Body of 200 characters | preview of the first 79 characters plus `…`, 80 in all |
| Sent 3,600 seconds ago, 1 attachment | age `1h`, label ends `1 hour ago, 1 attachment` |
| Sent 604,800 seconds ago | age `1w` |

## Constraints

- Count characters as Swift does (`String.count`), so an emoji is one character.
- Use only the `now` you're given: no `Date()`, so tests are exact.
- Pure Foundation: the mapper must not import UIKit.

<Hints>
<Hint>
`body.split(whereSeparator: \.isWhitespace).joined(separator: " ")` collapses every run of whitespace and trims both ends in one step.
</Hint>
<Hint>
For the age, try the units from largest to smallest (604,800, 86,400, 3,600, 60 seconds) and use the first one that fits. Returning the count with both its short suffix and its spoken name lets one function serve `age` and the accessibility label.
</Hint>
<Hint>
Build the accessibility label as an array of parts and join it at the end, so optional parts are a simple `if … append`.
</Hint>
</Hints>

## Solutions

<Approach title="Decide each field, then assemble the spoken label from parts" time="O(length of the body)" space="O(length of the body)">

```swift
private static func age(of seconds: TimeInterval) -> (count: Int, short: String, spoken: String)? {
    let units: [(seconds: TimeInterval, short: String, spoken: String)] = [
        (604_800, "w", "week"), (86_400, "d", "day"), (3_600, "h", "hour"), (60, "m", "minute"),
    ]
    for unit in units where seconds >= unit.seconds {
        return (Int(seconds / unit.seconds), unit.short, unit.spoken)
    }
    return nil
}

private static func counted(_ count: Int, _ noun: String) -> String {
    "\(count) \(noun)\(count == 1 ? "" : "s")"
}

public static func row(for message: Message, now: Date) -> RowState {
    let name = message.senderName.trimmingCharacters(in: .whitespacesAndNewlines)
    let sender = name.isEmpty ? message.senderAddress : name

    let trimmedSubject = message.subject.trimmingCharacters(in: .whitespacesAndNewlines)
    let subject = trimmedSubject.isEmpty ? "(No subject)" : trimmedSubject

    var preview = message.body.split(whereSeparator: \.isWhitespace).joined(separator: " ")
    if preview.count > 80 {
        var cut = String(preview.prefix(79))
        while cut.last == " " { cut.removeLast() }
        preview = cut + "…"
    }

    let elapsed = age(of: now.timeIntervalSince(message.sentAt))
    let shortAge = elapsed.map { "\($0.count)\($0.short)" } ?? "Now"
    let spokenAge = elapsed.map { counted($0.count, $0.spoken) + " ago" } ?? "Just now"

    var symbols: [String] = []
    if message.isFlagged { symbols.append("flag.fill") }
    if message.attachmentCount > 0 { symbols.append("paperclip") }

    var spoken: [String] = []
    if !message.isRead { spoken.append("Unread") }
    if message.isFlagged { spoken.append("Flagged") }
    spoken += ["From \(sender)", subject, spokenAge]
    if message.attachmentCount > 0 { spoken.append(counted(message.attachmentCount, "attachment")) }

    return RowState(id: message.id, sender: sender, subject: subject, preview: preview, age: shortAge,
                    showsUnreadDot: !message.isRead, symbols: symbols, accessibilityLabel: spoken.joined(separator: ", "))
}
```

Why cap the preview when a `UILabel` truncates anyway? Because the row state is more than pixels: an email body can be 50 KB, and that string would otherwise be kept in every row state, compared on every update, and (without care) read in full by VoiceOver. Deciding the preview once, here, keeps all of that small and consistent.

The cell that uses this is a dozen lines of assignments, with nothing to test but its layout. Every screen that lists messages (the inbox, search results, a thread's sidebar) shares the mapper, so a rule changes in one place, and a rewrite of the cell in SwiftUI keeps every rule and test.

</Approach>
