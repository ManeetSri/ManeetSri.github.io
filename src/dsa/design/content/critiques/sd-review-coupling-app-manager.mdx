<Brief>

Every feature in this social app calls `AppManager.shared`. Four teams edit the file, most pull requests that touch it conflict, and two bugs are open against it: dates sometimes show up blank, and people who sign out are signed in again after relaunching. Review it for **cohesion**: what belongs together, what doesn't, and how you'd take it apart without stopping feature work.

```swift check ios title="AppManager.swift"
import UIKit

@MainActor
final class AppManager {
    static let shared = AppManager()

    var currentUserID: String?
    var imageCache: [URL: UIImage] = [:]
    private let haptics = UIImpactFeedbackGenerator(style: .medium)
    private let dateFormatter = DateFormatter()

    // Call first, from application(_:didFinishLaunchingWithOptions:)
    func bootstrap() {
        currentUserID = UserDefaults.standard.string(forKey: "uid")
        dateFormatter.dateFormat = "d MMM yyyy"
        UINavigationBar.appearance().tintColor = .systemPink
        if currentUserID != nil {
            UIApplication.shared.registerForRemoteNotifications()
        }
        track("app_open")
    }

    func perform(_ action: String, payload: [String: Any] = [:]) async throws {
        switch action {
        case "login":
            var request = URLRequest(url: URL(string: "https://api.example.com/login")!)
            request.httpMethod = "POST"
            request.httpBody = try JSONEncoder().encode(["email": payload["email"] as! String])
            let (data, _) = try await URLSession.shared.data(for: request)
            currentUserID = String(decoding: data, as: UTF8.self)
            UserDefaults.standard.set(currentUserID, forKey: "uid")
            track("login")
        case "logout":
            currentUserID = nil
            imageCache.removeAll()
            UserDefaults.standard.removeObject(forKey: "userID")
            track("logout")
        case "like":
            haptics.impactOccurred()
            let postID = payload["postID"] as! String
            var request = URLRequest(url: URL(string: "https://api.example.com/posts/\(postID)/like")!)
            request.httpMethod = "POST"
            _ = try await URLSession.shared.data(for: request)
            track("like_post")
        default:
            break
        }
    }

    func image(at url: URL) async throws -> UIImage? {
        if let cached = imageCache[url] { return cached }
        let (data, _) = try await URLSession.shared.data(from: url)
        imageCache[url] = UIImage(data: data)
        return imageCache[url]
    }

    func displayDate(_ date: Date) -> String {
        dateFormatter.string(from: date)
    }

    func track(_ event: String) {
        print("analytics", event, currentUserID ?? "anonymous")
    }
}
```

<ReferenceReview>

**Most important first.** Fix the sign-out bug today, on its own: it's one constant shared by the three places that use the key, plus a test, and it stops signed-out users being signed back in. The blank dates come from the same root cause as everything else here, hidden order inside a grab-bag type, and they're fixed by configuring the formatter when it's created.

**The design problem underneath** is that `AppManager` has no single job. Its parts are related only by convenience (coincidental), by being "actions" (logical) or by running at launch (temporal), which are the three weakest kinds of cohesion. That's why every team edits it, why its bugs come from strings and ordering, and why nothing in it can be tested alone.

**How I'd take it apart, without a big-bang rewrite:**

1. Write the new types one island at a time: `SessionStore` (`signIn(email:)`, `signOut()`, `restore()`, owning the key), `ImagePipeline` (`NSCache` plus one task per URL), `DateLabels` (a formatter configured at creation, or `Date.formatted`), `LikesService` (`like(postID:)`) and an `AnalyticsTracking` protocol that takes typed events.
2. Keep `AppManager` for now as a thin facade that forwards to them, so existing call sites keep compiling while teams migrate. Each migration is a small pull request in one team's code.
3. Replace each `perform("…", payload:)` call with the typed method, then delete `perform`. The `as!` crashes go with it.
4. Move haptics to the like button, and appearance to a theme step.
5. Turn `bootstrap` into a list of named launch steps run in order by the app delegate, with session restore first.
6. Once nothing calls `AppManager`, create the new types in the composition root and inject them; delete the singleton.

**Tests to add:** `SessionStore` against an isolated `UserDefaults(suiteName:)` and a stub HTTP client: sign in, sign out, relaunch, and check the user is signed out. `DateLabels` formats correctly with no launch code run. `ImagePipeline` returns cached images and downloads a URL once when two callers ask together. A mapping test from each typed analytics event to the vendor's event name.

</ReferenceReview>
