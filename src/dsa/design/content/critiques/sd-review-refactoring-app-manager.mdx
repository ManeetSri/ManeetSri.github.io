<Brief>

Every screen of this shopping app talks to one object, `AppManager.shared`. It started as a place to keep the logged-in user, and three years later it holds the basket, preferences, analytics and error alerts too. Since the Swift 6 migration, support has seen crashes nobody can reproduce, and one customer reported checking out someone else's basket on a shared iPad. Review the file as you would a pull request.

```swift check ios title="AppManager.swift"
import UIKit

struct User: Codable {
    let id: String
}

struct CartItem: Codable {
    let productID: String
    let price: Double
    let quantity: Int
}

final class AppManager: @unchecked Sendable {
    static let shared = AppManager()

    var currentUser: User?
    var cart: [CartItem] = []
    var prefersCompactLayout = false

    private init() {}

    func logIn(email: String, password: String, completion: @escaping @Sendable (Bool) -> Void) {
        var request = URLRequest(url: URL(string: "https://api.example.com/login")!)
        request.httpMethod = "POST"
        request.httpBody = try? JSONEncoder().encode(["email": email, "password": password])
        URLSession.shared.dataTask(with: request) { data, _, _ in
            self.currentUser = data.flatMap { try? JSONDecoder().decode(User.self, from: $0) }
            completion(self.currentUser != nil)
        }.resume()
    }

    func logOut() {
        currentUser = nil
    }

    func add(_ item: CartItem) {
        cart.append(item)
        NotificationCenter.default.post(name: Notification.Name("cartChanged"), object: nil)
        track("add_to_cart")
    }

    func cartTotal() -> Double {
        cart.reduce(0) { $0 + $1.price * Double($1.quantity) }
    }

    func track(_ event: String) {
        print("analytics:", event, currentUser?.id ?? "anonymous")
    }

    @MainActor func showError(_ message: String) {
        let scene = UIApplication.shared.connectedScenes.first as? UIWindowScene
        let alert = UIAlertController(title: "Error", message: message, preferredStyle: .alert)
        alert.addAction(UIAlertAction(title: "OK", style: .default))
        scene?.windows.first?.rootViewController?.present(alert, animated: true)
    }
}

final class CartViewController: UIViewController {
    override func viewDidLoad() {
        super.viewDidLoad()
        title = "Basket (\(AppManager.shared.cart.count))"
    }

    @objc func checkout() {
        guard AppManager.shared.currentUser != nil else {
            AppManager.shared.showError("Please log in")
            return
        }
        AppManager.shared.track("checkout_started")
    }
}
```

<ReferenceReview>

**Most important first.** Two problems hurt customers today. The login completion writes shared state from a background queue, a data race that `@unchecked Sendable` hid from Swift 6. And `logOut()` leaves the basket behind, so one customer can see and buy another's: that's a privacy bug, not a style problem.

**The design problem underneath** is a god object with global access. Its parts share almost no state, which is good news: they can come apart one at a time. Global access is why tests can't isolate it, why screens hide their dependencies, and why logout has to remember every field.

**How I'd fix it, in small steps** (each one shippable, the app working after every merge):

1. Make `AppManager` `@MainActor` and delete `@unchecked Sendable`. Rewrite `logIn` with `try await URLSession.shared.data(for:)` from a main-actor method. The compiler now points at every off-main access; fix them.
2. Introduce a `UserSession` that holds the user and the basket, created at login and discarded at logout. `logOut()` becomes "drop the session", and the leak can't come back as fields are added.
3. Extract `Basket` (the most used part) behind a small protocol. During the move, `AppManager.cart` forwards to it, so every call site keeps compiling. Switch it to `Decimal` or pence while it's on its own.
4. Inject into screens with defaults first, `init(basket: Basket = AppManager.shared.basket)`, so nothing breaks. Then build the screens in the scene's composition root, pass real instances, and remove the defaults.
5. Move alert presentation into the screens. Replace `"cartChanged"` with an `@Observable` basket the title observes, and analytics strings with an `AnalyticsEvent` enum behind an injected tracker.
6. Add a lint rule that rejects new uses of `AppManager.shared` while the migration runs, and delete the type when the last use goes.

**Tests to add:** logout gives the next session an empty basket; a basket of `0.10 + 0.20`-style prices totals exactly; the cart screen (or its view model) with an injected basket shows the right count and updates when it changes; each extracted service tested on its own instance, in parallel, with no shared state.

</ReferenceReview>
